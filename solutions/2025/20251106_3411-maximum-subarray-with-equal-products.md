# #3411. 等乘积子数组的最大长度 / Maximum Subarray With Equal Products

## 题目（英文原版）

**Description**

You are given an array of positive integers nums.
An array arr is called product equivalent if prod(arr) == lcm(arr) * gcd(arr), where:
Return the length of the longest product equivalent subarray of nums.

**Examples**

**Example 1:**

```
Input: nums = [1,2,1,2,1,1,1]
Output: 5
Explanation:
The longest product equivalent subarray is [1, 2, 1, 1, 1] , where prod([1, 2, 1, 1, 1]) = 2 , gcd([1, 2, 1, 1, 1]) = 1 , and lcm([1, 2, 1, 1, 1]) = 2 .
```

**Example 2:**

```
Input: nums = [2,3,4,5,6]
Output: 3
Explanation:
The longest product equivalent subarray is [3, 4, 5].
```

**Example 3:**

```
Input: nums = [1,2,3,1,4,5,1]
Output: 5
```

**Constraints**

- 2 <= nums.length <= 100
- 1 <= nums[i] <= 10

## 题目（中文翻译）

给定一个只包含正整数的数组 `nums`。  
如果一个数组 `arr` 满足 `prod(arr) == lcm(arr) * gcd(arr)`，则称其为**等乘积子数组**（product equivalent），其中：

- `prod(arr)` 表示数组所有元素的乘积（product），
- `gcd(arr)` 表示数组所有元素的最大公约数（greatest common divisor），
- `lcm(arr)` 表示数组所有元素的最小公倍数（least common multiple）。

请返回 `nums` 中最长的等乘积子数组的长度。

`prod([1, 2, 1, 1, 1]) = 2`，`gcd([1, 2, 1, 1, 1]) = 1`，`lcm([1, 2, 1, 1, 1]) = 2`。

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是**枚举所有子数组**，对每一个子数组分别计算：

* `prod`   子数组所有元素的乘积  
* `gcd`   子数组所有元素的最大公约数  
* `lcm`   子数组所有元素的最小公倍数  

只要 `prod == lcm * gcd`，说明这个子数组满足题意，记录下它的长度，最后取最大值即可。

> **数据结构类比**  
> - **乘积、最大公约数、最小公倍数**可以想象成“烹饪原料”。乘积是把所有原料直接相乘得到的“混合味”，而 `gcd` 是所有原料里共同的“基底味”，`lcm` 则是把所有原料的“最大味道”拼在一起。只要“混合味”恰好等于“基底味 × 最大味道”，就算是“味道匹配”。  
> - **枚举子数组**就像把一条长队的每一段人都排成小队，逐个检查。

**为什么正确**  
因为我们把**所有可能的连续子数组**都检查了一遍，只要有符合条件的子数组就一定会被找到。  

**时间/空间复杂度**  
- 枚举子数组有 `O(n²)` 种（左端点 `i`，右端点 `j`），每个子数组需要遍历一次来累计乘积、求 `gcd`、`lcm`，这也是 `O(n)`（因为子数组长度最多 `n`），整体是 `O(n³)`。  
  为了稍微降低一点，我们可以在枚举时 **滚动更新**（把右端点向右扩展时，只需要把新元素合并进已有的 `prod/gcd/lcm`），这样每个左端点的循环只需要 `O(n)`，总计 `O(n²)`。  
- 只使用了常数个整数变量，空间 `O(1)`。  

> **大白话解释**  
> - `O(n²)` 就像“你有 `n` 本书，要检查每两本之间的距离”，如果 `n=100`，最多要检查 10 000 次，算得起。  
> - `O(1)` 表示不管数组多长，额外占用的内存几乎不变，只有几个数字罢了。

#### 代码（Python）

```python
import math
from typing import List

def longest_product_equivalent(nums: List[int]) -> int:
    n = len(nums)
    ans = 0                         # 记录最长长度

    # 枚举左端点
    for i in range(n):
        prod = 1                     # 子数组乘积
        g = 0                        # 子数组 gcd，0 表示还没有元素
        l = 1                        # 子数组 lcm

        # 枚举右端点（不断往右扩展）
        for j in range(i, n):
            x = nums[j]
            prod *= x                # 累乘
            g = math.gcd(g, x) if g else x   # 更新 gcd
            # lcm(a,b) = a // gcd(a,b) * b
            l = l // math.gcd(l, x) * x        # 更新 lcm

            # 检查条件
            if prod == g * l:
                ans = max(ans, j - i + 1)

    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n²)`  
  - 解释：我们有两层循环，外层 `n` 次，内层平均也遍历 `n/2` 次，总共约 `n²/2` 次操作。  
- **空间复杂度**：`O(1)`  
  - 解释：只用了几个整数 (`prod、g、l、ans`) 来保存中间结果，和输入规模无关。

### 2. 最优解

#### 思路  

从暴力解出发，**瓶颈在于枚举所有子数组**——即使我们用了滚动更新，仍然是 `O(n²)`。  
我们需要 **一次遍历**（或接近一次遍历）就能得到答案。要做到这一点，必须利用题目给出的 **数值范围** 与 **数学性质**。

---

#### 2.1 关键数学观察  

对任意 **两个正整数** `a、b`，都有  
```
a * b = lcm(a, b) * gcd(a, b)
```  
因为 `lcm * gcd` 正好把公共因子算一次，剩下的因子各算一次。

对 **三个或更多** 的数，等式 **不一定成立**。  
设子数组为 `a1, a2, …, ak`，记  

- `g = gcd(a1,…,ak)`  
- `bi = ai / g` （把每个数都除去公共因子）

则 `gcd(b1,…,bk) = 1`（已经没有公共因子了）。  
等式要成立：

```
∏ ai = lcm(ai) * gcd(ai)
⇔ g^k * ∏ bi = (g * lcm(bi)) * g
⇔ g^{k-2} * ∏ bi = lcm(bi)
```

- 当 `k = 2` 时，左边的 `g^{k-2}` 为 `g⁰ = 1`，等式始终成立——**任意长度为 2 的子数组都是合法的**。  
- 当 `k > 2` 时，需要 `g = 1`（否则左边会出现 `g` 的幂 > 1）并且 `∏ bi = lcm(bi)`。  
  `∏ bi = lcm(bi)` 当且仅当 `b1,…,bk` **两两互质**（没有共同的质因子），因为此时最小公倍数就是把所有质因子乘起来。

**结论**  
> 对长度 ≥ 3 的子数组，必须满足：
> 1. 整体 `gcd = 1`  
> 2. 所有元素两两互质（即同一个质因子不能出现在两个不同的元素里）

> 对长度 = 2 的子数组，始终合法。

---

#### 2.2 利用约束  

- `1 ≤ nums[i] ≤ 10`  
  只可能出现的质因子有 `2, 3, 5, 7`（`10 = 2·5`），共 **4 个**。  
- 因此我们可以用 **4 位二进制掩码** 来记录当前窗口里已经出现过的质因子。  
  - 比如掩码 `0101` 表示已经出现了质因子 `2`（第 0 位）和 `5`（第 2 位）。  

当我们尝试把新元素 `x` 加入窗口时：

1. **分解质因子**（因为 `x ≤ 10`，直接查表或遍历四个质数即可）。  
2. 检查这些质因子对应的位在当前掩码中是否已经被占用。  
   - 若 **未冲突**，把对应位设为 `1`，窗口继续扩大。  
   - 若 **冲突**（同一个质因子已在窗口中出现），必须把左指针 `left` 向右移动，**直到冲突消失**。移动时要把左端点对应的质因子位清零。  

同时我们维护 **窗口的 gcd**（使用 `math.gcd`），但如上所述，只要没有质因子冲突，`gcd` 必然为 `1`（因为若所有数都有公共因子 `p`，那 `p` 必然在掩码中出现多次，会产生冲突）。因此只需要在窗口长度 ≥ 3 时检查 `gcd == 1`，实际可以省略这一步。

**滑动窗口**（双指针）正好可以在 **O(n)** 的时间完成：

- 右指针 `right` 只向右走一次。  
- 左指针 `left` 也只向右走至 `n`，每次移动都对应一次“弹出”操作。  
- 每个元素的质因子最多 2 个（例如 `6 = 2·3`），所以整体复杂度仍是线性。

---

#### 2.3 算法步骤  

1. 预先准备一个字典 `prime_mask`，把 `1~10` 每个数映射到它的质因子位掩码。例如 `6 → (1<<0)|(1<<1) = 0b0011`。  
2. 初始化 `left = 0，mask = 0，ans = 2`（因为任意相邻两数必合法，最小答案是 2）。  
3. 遍历 `right` 从 `0` 到 `n-1`：  
   - `cur = prime_mask[nums[right]]`。  
   - **冲突检测**：`while mask & cur:`  
        * 需要把左端点 `nums[left]` 的掩码从 `mask` 中移除：`mask ^= prime_mask[nums[left]]`。  
        * `left += 1`。  
   - 把当前元素的掩码加入窗口：`mask |= cur`。  
   - 计算窗口长度 `len = right - left + 1`。  
   - 若 `len >= 3`，此时已经保证两两互质且 `gcd = 1`，更新答案 `ans = max(ans, len)`。  
4. 返回 `ans`。

---

#### 代码（Python）

```python
import math
from typing import List

# 预处理：把 1~10 每个数映射成质因子位掩码
# 质因子顺序：2, 3, 5, 7  ->  bit 0,1,2,3
def build_mask_table() -> List[int]:
    primes = [2, 3, 5, 7]
    table = [0] * 11                # index 0~10
    for num in range(1, 11):
        mask = 0
        x = num
        for i, p in enumerate(primes):
            if x % p == 0:
                mask |= 1 << i      # 该质因子出现一次（次数不重要，只要出现过）
                while x % p == 0:   # 去掉所有相同因子，防止重复计数
                    x //= p
        table[num] = mask
    return table

MASK_TABLE = build_mask_table()

def longest_product_equivalent(nums: List[int]) -> int:
    n = len(nums)
    # 任意两个数的子数组一定合法，答案至少为 2
    ans = 2 if n >= 2 else 1

    left = 0          # 窗口左端点
    mask = 0          # 当前窗口里已经出现的质因子位掩码

    for right in range(n):
        cur_mask = MASK_TABLE[nums[right]]

        # 如果出现了已经在窗口中的质因子，需要收缩左端点
        while mask & cur_mask:               # 有交集 → 冲突
            # 把左端点对应的质因子从 mask 中移除
            mask ^= MASK_TABLE[nums[left]]
            left += 1

        # 加入当前元素
        mask |= cur_mask

        # 当前窗口长度
        length = right - left + 1
        if length >= 3:                      # 长度 2 已经计入 ans，长度 >=3 需要满足两两互质
            ans = max(ans, length)

    return ans
```

> **代码注释说明**  
> - `MASK_TABLE`：把每个数映射成「出现了哪些小质因子」的 4 位二进制数。  
> - `mask & cur_mask`：位运算检查「窗口里是否已经有相同的质因子」；`&` 为“与”，只要有 `1` 重叠就说明冲突。  
> - `mask ^= old_mask`：使用异或把左端点的质因子位从窗口中“弹出”。因为左端点的质因子在窗口里只出现一次，异或恰好把对应位清零。  

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 每个元素的右指针只进入一次，左指针最多也只移动 `n` 次。位运算和 `gcd`（本实现里不需要显式求）都是常数时间。  
  - 与暴力的 `O(n²)` 相比，线性时间在 `n=100` 时几乎瞬间完成。  

- **空间复杂度**：`O(1)`  
  - 只用了几个整数变量和一个长度为 11 的常量表，和输入规模无关。

## 心得  

- **核心技巧**：利用 **数论性质**（两数乘积 = lcm·gcd）把原问题转化为「子数组两两互质且整体 gcd 为 1」的判定，再用 **位掩码 + 滑动窗口** 完成线性求解。  
- **适用场景**：  
  1. 需要判断子数组内部 **没有重复质因子**（如「所有元素互质」的题目）。  
  2. 约束数值范围很小，可用 **位掩码** 表示状态（如「数组元素 ≤ 30」的子数组问题）。  
  3. 需要 **最长满足某种“冲突不出现”条件** 的子数组，典型的「滑动窗口」模板。  

> **一句话总结**：  
> 把「乘积 = lcm·gcd」化简为「两两互质且 gcd=1」后，用位掩码快速检测冲突，滑动窗口一次遍历即可得到最长合法子数组。

## 反思  

- **第一反应**：直接暴力枚举所有子数组，计算乘积、gcd、lcm。虽然能跑通小样例，但很快发现 `O(n²)`（甚至 `O(n³)`）在 `n=100` 时已接近上限。  
- **最容易踩的坑**：  
  1. **漏掉长度为 2 的子数组**——根据数学推导，它们总是合法的，答案下限必须设为 2。  
  2. **质因子冲突的判断**：如果只检查 `gcd>1` 而不检查两两互质，会错过如 `[2,3,6]`（gcd=1，但 6 与 2、3 共享质因子）。  
  3. **位掩码的清除**：窗口左移时必须把对应的质因子位恢复为 0，使用异或或按位与取反都可以，写错会导致误判。  
- **下次思路**：遇到「乘积、gcd、lcm」混合的等式时，先**推导数学等价**，看看能否把条件简化为「互质」或「无公共因子」之类的更易检查的属性；随后结合 **数值范围** 考虑 **位掩码** 或 **计数数组**，最后套用 **滑动窗口** 的通用框架。
