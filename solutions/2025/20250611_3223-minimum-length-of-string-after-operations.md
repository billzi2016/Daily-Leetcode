## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是 **模拟题目给出的操作**：  
- 先统计每个字符出现的次数（可以把 26 个字母想成一本字典，`key` 是字母，`value` 是出现的页码数）。  
- 然后只要有字母的出现次数 **≥ 3**，就把它的出现次数减 **2**（相当于把这两个相同的字母从书里撕掉）。  
- 重复上一步，直到所有字母的出现次数都不大于 2 为止。  
- 最后把所有剩余的次数相加，就是可以得到的最短长度。

为什么这种方法是对的？  
因为题目只允许 **“把同一种字符的任意两个”** 删除，而每次删除都只会让该字符的出现次数 **-2**。只要还有 **≥3** 次，就一定还能再删一次；当次数降到 **0、1 或 2** 时，就再也找不到可以删除的两对相同字符了。于是这个过程一定会把每个字符的次数压到 **≤2**，而这正是题目要求的 “最小可能长度”。

**时间/空间复杂度分析（用大白话解释）**  
- 统计一次字符频率需要遍历整个字符串，**O(n)**（n 是字符串长度）。  
- 接下来每次循环都要遍历 26 个字母去找是否还有 ≥3 次的字符。如果字符串全部是同一个字母，比如 `"aaaaa...a"`（长度 2·10⁵），每次循环都会把它的计数减 2，循环大概会执行 **n/2** 次。于是总的循环次数是 **O(n)**，每次遍历 26 个字母是常数时间，整体仍是 **O(n)**。  
- 但如果我们写成 “每次都重新统计整个字符串的频率”，时间会变成 **O(n²)**，这在最坏情况下会非常慢。下面的代码会避免这种低效写法，但仍算是“暴力模拟”，因为我们没有直接用数学公式求答案，只是一步步把次数减到 2。

空间方面，只需要存放 26 个计数，**O(1)**（常数级别的空间）。

#### 代码（Python）

```python
def minimumLength(s: str) -> int:
    # 1️⃣ 统计每个字符出现的次数
    freq = [0] * 26                     # 26 个字母的计数表，像一本字典
    for ch in s:
        freq[ord(ch) - ord('a')] += 1   # 把对应字母的页码数+1

    # 2️⃣ 暴力模拟：只要有字符出现次数 ≥3，就删掉两个
    changed = True
    while changed:                      # 循环直到一次也没有删掉
        changed = False
        for i in range(26):             # 遍历 26 个字母（常数时间）
            if freq[i] >= 3:            # 还能删两个人吗？
                freq[i] -= 2            # 删除两个相同字符
                changed = True         # 标记本轮有改动，需继续检查

    # 3️⃣ 剩下的就是最终字符串的长度
    return sum(freq)                    # 把所有剩余的页码数相加
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  - 统计一次字符频率是 `O(n)`，后面的循环最多也只会执行 `n/2` 次，每次遍历 26 个字母是常数时间，总体仍是线性级别。  
  - 用大白话讲，就是“我们只需要看一遍字符串，之后每次都只检查 26 次，和字符串长短成正比”。

- **空间复杂度**：`O(1)`  
  - 只用了 26 个整数来记录字母出现次数，和输入大小无关，属于常数空间。

### 2. 最优解

#### 思路  

从暴力解可以看到，**真正决定最终长度的只有每个字符的出现次数**，而不是字符之间的相对位置。  
- 如果某个字符出现 **0、1 或 2** 次，根本无法进行任何删除操作。  
- 如果出现 **≥3 次**，我们可以 **无限次** 地把它的次数减 2，直到只剩 **0、1 或 2** 次为止。  
- 换句话说，**每个字符最终最多只能保留 2 个**，而我们总是希望保留得越少越好（因为要最小化长度），于是对每个字符我们只需要保留 `min(cnt, 2)` 个。

所以最优解只要一步：

1. **一次遍历**统计所有字符的频率。  
2. 对每个字符把出现次数取 `min(cnt, 2)`，把这些最小值相加，即得到最短可能的长度。

这一步不需要任何循环去“删两次”，因为数学上已经把“删两次”归纳成了 “保留最多两个”。整个过程只遍历一次字符串，时间 **O(n)**，空间只需 26 个计数，**O(1)**。

> **类比**：想象你有若干盒子，每盒子里装的是同一种颜色的球。规则允许你每次从同一盒子里拿走 **两颗** 球，只要盒子里还有 **至少三颗** 球。显然，最终每盒子里最多只能剩下 **两颗** 球。我们不必真的一次次去拿球，只要直接算出每盒子里剩几颗（`min(cnt,2)`）就行了。

#### 代码（Python）

```python
def minimumLength(s: str) -> int:
    # 只需要一次遍历统计频率
    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - ord('a')] += 1

    # 对每个字符保留至多两个，直接相加即为答案
    ans = 0
    for cnt in freq:
        ans += min(cnt, 2)   # 保留 0、1 或 2 个
    return ans
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  - 只遍历字符串一次，`n` 是字符串长度。用大白话说，就是“看一眼字符串，立刻算出答案”。

- **空间复杂度**：`O(1)`  
  - 只用了 26 个整数来记录每个字母的出现次数，和字符串长短无关。

与暴力解对比：  
- 暴力解虽然也能做到 `O(n)`，但代码里用了 `while` 循环和 `changed` 标记，逻辑稍显冗余；  
- 最优解直接用数学归纳一步得到答案，代码更简洁、更易读，且完全避免了循环中可能出现的 “找不到可以删的字符” 的重复检查。

## 心得

- **核心技巧**：把“每次删除两个相同字符”抽象为“每个字符最终最多保留两个”。这是一种**计数归约**的思路——只关心出现次数，而不关心具体位置。
- **适用的题型**  
  1. **删除/合并操作只和出现次数有关** 的题目，例如 “删除相同字符使字符串长度最短” 类似的 LeetCode 2696。  
  2. **限制每种元素出现次数** 的问题，如 “把数组中每个数字的出现次数限制在 k 次” 之类的题。  
  3. **使用哈希表/计数数组** 进行频率统计的场景，常见于 “出现次数最多的字符” 系列。
- **一句话总结解题钥匙**：**“把每个字符的出现次数压到 ≤2，答案即所有压后次数之和”。**

## 反思

- **第一反应**：看到“可以任意次数地删除两个相同字符”，第一想法是“模拟删除”。于是写了循环不停删的代码。  
- **最容易踩的坑**  
  - **忘记只要出现次数 ≥3 才能删**，导致把出现 2 次的字符也错误地删掉。  
  - **边界条件**：空字符串或全部相同字符的极端情况。虽然题目保证长度 ≥1，但仍要确保代码在 `cnt=0` 时也能正常工作。  
  - **计数溢出**：在 Python 中整数不会溢出，但如果用固定宽度的整数（如 C++ 的 `int`），大量删除可能导致负数，需要小心检查 `cnt >= 3` 再减 2。  
- **下次遇到同类题**，第一步应该先 **思考：操作只和字符出现次数有关吗？** 如果答案是肯定的，就立刻尝试把“操作过程”抽象成“对频率的约束”，直接用计数来求答案，而不是模拟整个过程。这样往往能一次得到最优解。
