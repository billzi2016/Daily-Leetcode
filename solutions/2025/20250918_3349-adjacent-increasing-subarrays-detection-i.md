## 题目（中文翻译）

给定一个长度为 `n` 的整数数组 `nums` 和一个整数 `k`，判断是否存在两个相邻的长度为 `k` 的子数组（subarray），使得这两个子数组都是 **严格递增**（strictly increasing）的。具体而言，检查是否存在起始下标为 `a` 和 `b`（`a < b`）的两个子数组，其中：

- 第一个子数组为 `nums[a .. a + k - 1]`，第二个子数组为 `nums[b .. b + k - 1]`；
- 两个子数组相邻，即 `a + k = b`；
- 两个子数组内部的元素严格递增。

如果能够找到满足上述条件的两个子数组，返回 `true`；否则返回 `false`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是把所有可能的 **相邻** 长度为 `k` 的子数组全部枚举一遍，逐个检查它们是不是严格递增的。

- **枚举方式**：  
  设子数组的左端点为 `a`，则第二个子数组的左端点只能是 `a + k`（必须相邻）。`a` 的取值范围是 `0 … n - 2·k`（因为要保证两个子数组都在数组内部）。
- **递增判定**：  
  对每个子数组，遍历其中的 `k‑1` 对相邻元素，检查 `nums[i] < nums[i+1]` 是否成立。  
  这一步可以类比为 **查字典**：我们把每一对相邻的数字看成“词”，如果词典里（即数组里）前面的词比后面的词小，就算这对“词”是有序的；所有 `k‑1` 对都有序，整个子数组才算递增。

- **为什么一定对**：  
  只要找到了满足条件的 `a`，题目要求的两个相邻递增子数组就出现了；如果遍历完所有 `a` 都没有成功，则不存在这样的一对子数组。

#### 代码（Python）

```python
def containsTwoIncreasingSubarrays(nums, k):
    n = len(nums)

    # 遍历所有可能的左端点 a
    for a in range(n - 2 * k + 1):
        # 检查第一个子数组 nums[a : a+k] 是否严格递增
        inc1 = True
        for i in range(a, a + k - 1):
            if nums[i] >= nums[i + 1]:   # 只要出现不小于，就不递增
                inc1 = False
                break

        if not inc1:                     # 第一个子数组不递增，直接跳到下一个 a
            continue

        # 检查第二个子数组 nums[a+k : a+2k] 是否严格递增
        inc2 = True
        for i in range(a + k, a + 2 * k - 1):
            if nums[i] >= nums[i + 1]:
                inc2 = False
                break

        if inc2:                         # 两个子数组都递增，直接返回 True
            return True

    # 所有 a 都检查完仍未找到，返回 False
    return False
```

#### 复杂度  

- **时间复杂度：** `O(n * k)`  
  - 解释：我们最多遍历 `n‑2k+1 ≈ n` 个起点 `a`，每次要检查两个子数组各 `k‑1` 对相邻元素，合计约 `2·k` 次比较。于是整体大约是 `n·k` 次操作。  
  - 用大白话说，就是如果数组有 1000 个数，`k` 是 10，那最多要比较 10 000 次，仍然可以接受。

- **空间复杂度：** `O(1)`  
  - 只用了常数个额外变量（`a、inc1、inc2` 等），不随输入规模增长。

### 2. 最优解

#### 思路  

暴力解的**瓶颈**在于每次都要遍历 `k‑1` 对相邻元素来判断递增，导致 `O(n·k)` 的时间。我们可以把“递增”这一信息提前算好，保存到一个辅助数组里，这样每次只要 **常数时间** 就能判断一个子数组是否递增。

**核心技巧——前缀递增长度**  
- 设 `inc_len[i]` 为 **以 `i` 为结尾的递增子数组的最大长度**。  
  - 例如 `nums = [2,5,7,8]`，则 `inc_len = [1,2,3,4]`（因为每个位置向左都能延伸形成递增序列）。  
  - 计算方式非常直观：  
    ```python
    inc_len[0] = 1
    for i in range(1, n):
        if nums[i-1] < nums[i]:
            inc_len[i] = inc_len[i-1] + 1   # 前面是递增的，就把长度加 1
        else:
            inc_len[i] = 1                  # 否则只能自己单独成长度 1
    ```
  - 这里把 `inc_len` 看成 **“递增的记分牌”**：每走一步如果仍然递增，分数就加一；否则重新计分。

- **如何利用 `inc_len` 判断子数组递增**  
  - 长度为 `k`、左端点为 `a` 的子数组递增 ⇔ 以右端点 `a+k-1` 为结尾的递增长度 **不少于 `k`**。也就是 `inc_len[a+k-1] >= k`。  
  - 同理，第二个子数组递增 ⇔ `inc_len[a+2*k-1] >= k`。

- **整体流程**  
  1. 先用一次遍历算出 `inc_len`（`O(n)`）。  
  2. 再遍历所有可能的左端点 `a`（`0 … n-2k`），每次只检查两个不等式，时间 `O(1)`。  
  3. 若任意 `a` 同时满足两个不等式，直接返回 `True`；遍历结束仍未满足则返回 `False`。

这样，时间从 `O(n·k)` 降到了 `O(n)`，空间使用 `O(n)`（存 `inc_len`），在本题约 100 的规模下几乎是瞬间完成。

#### 代码（Python）

```python
def containsTwoIncreasingSubarrays(nums, k):
    n = len(nums)

    # 1️⃣ 预处理：计算以每个位置 i 为结尾的递增子数组的最大长度
    inc_len = [1] * n                 # 初始都为 1（自己本身算长度 1）
    for i in range(1, n):
        if nums[i - 1] < nums[i]:     # 前后严格递增，长度可以延伸
            inc_len[i] = inc_len[i - 1] + 1
        # else: 已经在列表里默认是 1，无需额外操作

    # 2️⃣ 检查相邻的两个长度为 k 的子数组
    # a 为第一个子数组的左端点，范围保证两个子数组都在数组内部
    for a in range(n - 2 * k + 1):
        # 第一个子数组递增的判定：右端点是 a + k - 1
        if inc_len[a + k - 1] < k:
            continue                   # 第一个子数组不满足，直接跳过

        # 第二个子数组递增的判定：右端点是 a + 2*k - 1
        if inc_len[a + 2 * k - 1] >= k:
            return True                # 两个都满足，答案为 True

    # 遍历完都没有找到，返回 False
    return False
```

#### 复杂度  

- **时间复杂度：** `O(n)`  
  - 解释：一次遍历算 `inc_len`（`n` 次比较），再一次遍历检查所有起点 `a`（至多 `n` 次），每次检查只做常数次比较。整体随数组长度线性增长。  
  - 与暴力解相比，从 “每次都要看 `k` 条数据” 降到了 “只看一次就知道所有信息”，快了大约 `k` 倍。

- **空间复杂度：** `O(n)`  
  - 需要额外的 `inc_len` 数组来记录递增长度。`n ≤ 100`，占用的内存非常小。

## 心得

- **核心技巧**：利用**前缀递增长度**（或类似的前缀信息）把局部“是否递增”这类**区间属性**提前算好，后续查询可以 `O(1)` 完成。  
- **适用的题型**  
  1. “判断是否存在长度为 `k` 的递增（或递减）子数组”  
  2. “判断是否存在两个相邻子数组满足某种单调性/相等性”  
  3. “区间是否满足某种连续性条件”——例如 LeetCode 896 *Monotonic Array* 的变形。  
- **一句话总结解题钥匙**：**把“区间是否单调”转化为“以右端点为中心的递增长度是否足够”。**

## 反思

- **第一反应**：直接枚举所有相邻的 `k` 长度子数组，逐个检查递增——这就是暴力思路。  
- **最容易踩的坑**  
  - **边界条件**：`a + 2*k - 1` 必须小于 `n`，否则会越界。  
  - **严格递增**：`<` 而不是 `<=`，否则会把相等的情况误判为递增。  
  - **输入合法性**：题目保证 `2*k ≤ n`，但仍需在代码里写好循环上界，防止 `n-2*k+1` 为负数导致循环不执行。  
- **下次类似题的第一步**：**先思考能否用前缀/后缀信息把区间属性预处理**，如果可以，就把时间从 “每次遍历区间” 降到 “常数查询”。这样往往能直接得到线性时间的最优解。
