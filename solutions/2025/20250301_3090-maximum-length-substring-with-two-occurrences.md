## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有可能的子串都枚举出来，然后检查每个子串在原字符串里出现了几次，只要出现 **至少两次**（可以重叠），就记录它的长度，最后取最长的那个。

- **枚举子串**：我们可以用两层循环，外层确定子串的左端点 `i`，内层确定右端点 `j`（`i ≤ j`），子串就是 `s[i:j+1]`。  
- **计数出现次数**：把子串再在原字符串里滑动一次，统计它出现的次数（重叠也算），只要次数 ≥ 2 就算成功。  
- **为什么正确**：我们把 **所有** 子串都检查了一遍，只要有满足条件的子串，必然会被发现；取最长的自然就是答案。

> **类比**：把每个子串想成一本书的章节，暴力解就是把所有章节都搬到图书馆里，然后逐一去找“这本章节出现了几次”。虽然慢，但一定能找到答案。

#### 代码（Python）

```python
def maxLengthSubstringTwoOccurrences(s: str) -> int:
    n = len(s)
    best = 0                     # 当前找到的最长长度

    # i 为子串左端点，j 为右端点（包含）
    for i in range(n):
        for j in range(i, n):
            sub = s[i:j + 1]     # 取出子串 s[i..j]
            cnt = 0              # 统计 sub 在 s 中出现的次数

            # 用滑动窗口在 s 上再次遍历，判断是否匹配
            for k in range(n - (j - i)):   # 只需要遍历到还能放下 sub 的位置
                if s[k:k + (j - i + 1)] == sub:
                    cnt += 1
                # 若已经出现两次，直接停止计数
                if cnt >= 2:
                    break

            # 如果出现次数 ≥ 2，更新答案
            if cnt >= 2:
                best = max(best, j - i + 1)

    return best
```

> **代码要点注释**  
> - `for i in range(n):` → 把左端点固定在每一个位置。  
> - `for j in range(i, n):` → 把右端点往右推，形成所有可能的子串。  
> - `for k in range(n - (j - i)):` → 在原串上滑动检查匹配，`k` 只跑到还能容下子串的最右位置。  
> - `if cnt >= 2: break` → 一旦找到两次就不必继续计数，省点时间。

#### 复杂度

- **时间复杂度**：`O(n³)`  
  - 两层循环产生 `O(n²)` 个子串；对每个子串又要在原串里遍历一次 `O(n)` 来计数。  
  - 用大白话说：如果字符串长度是 10，最坏情况要检查 10·10·10 = 1000 次字符比较。  
- **空间复杂度**：`O(1)`  
  - 只用了常数个额外变量（`best、cnt、i、j、k`），不随 `n` 增长。

> 由于题目限制 `2 ≤ len(s) ≤ 100`，`O(n³)` 在最坏 100³ = 1,000,000 次比较仍然可以接受，但我们仍然可以把它进一步提速。

### 2. 最优解

#### 思路  

暴力解慢的根源在于**重复检查相同长度的子串**。如果我们只关心子串的长度，而不在意它到底是哪一个子串，那么可以把同一长度的所有子串一次性放进集合（哈希表）里，利用哈希表的“查字典”特性快速判断是否出现过。

核心思路：

1. **二分搜索长度**  
   - 最大可能的长度不超过 `len(s) // 2`（两次出现至少要占两倍空间）。  
   - 对长度 `L` 做二分查找：如果存在长度为 `L` 的子串出现 ≥ 2 次，就尝试更长；否则只能尝更短。

2. **利用哈希集合判断重复**  
   - 对固定的长度 `L`，遍历所有长度为 `L` 的子串，把它们的 **哈希值**（这里直接用子串本身做键）放进集合。  
   - 当某个子串已经在集合里出现过时，说明它出现了至少两次，直接返回 `True`。

3. **时间复杂度的提升**  
   - 每次检查某个长度 `L` 的过程是 `O(n)`（遍历一次字符串，插入/查询集合都是 `O(1)` 均摊）。  
   - 二分搜索需要 `log₂(n)` 次检查，总体 `O(n log n)`，比 `O(n³)` 快很多。

> **类比**：把所有长度为 `L` 的子串想成一本本小书，放进图书馆的书架（集合）里。只要把同一本书放第二次，就能立刻知道“这本书出现了两次”。二分搜索相当于先猜猜最大的书本厚度，然后逐步逼近答案。

#### 代码（Python）

```python
def maxLengthSubstringTwoOccurrences(s: str) -> int:
    n = len(s)

    # ---------- 检查某个长度 L 是否满足 “出现 ≥2 次” ----------
    def exists_len(L: int) -> bool:
        seen = set()                 # 已经出现过的子串集合
        for i in range(n - L + 1):   # 所有长度为 L 的子串起点
            sub = s[i:i + L]
            if sub in seen:          # 第二次出现，直接返回 True
                return True
            seen.add(sub)
        return False

    # ---------- 二分搜索最长合法长度 ----------
    lo, hi = 1, n // 2               # 长度不可能超过 n//2
    ans = 0
    while lo <= hi:
        mid = (lo + hi) // 2
        if exists_len(mid):          # mid 可行，尝试更长
            ans = mid
            lo = mid + 1
        else:                        # mid 不可行，缩短
            hi = mid - 1

    return ans
```

> **代码要点注释**  
> - `exists_len(L)`：遍历一次字符串，利用集合的 `O(1)` 插入/查询实现“是否已经出现”。  
> - `for i in range(n - L + 1):` → 只遍历能够完整取出长度 `L` 子串的起点。  
> - 二分区间 `[1, n//2]`：因为要出现两次，子串最长只能是字符串长度的一半。  
> - `ans` 记录当前找到的最大合法长度。

#### 复杂度

- **时间复杂度**：`O(n log n)`  
  - 检查单个长度 `L` 用时 `O(n)`；二分搜索最多 `log₂(n)` 次检查。  
  - 用大白话说：如果 `n = 100`，最多只需要约 `7` 次遍历全串，每次遍历 100 次字符，总共 700 次，比暴力的 1,000,000 次要少得多。

- **空间复杂度**：`O(n)`  
  - 最坏情况下集合里会存放所有不同的长度为 `L` 的子串，数量不超过 `n`。  
  - 这相当于我们在记忆“已经读过哪些小书”，需要的空间随字符串长度线性增长。

## 心得

- **核心技巧**：**利用哈希集合快速判断子串是否出现过**，结合 **二分搜索** 把“找最长”转化为“判断是否可行”。  
- **适用的题型**  
  1. “最长重复子串” 类问题（如 LeetCode 1044、LCP 等）。  
  2. “满足某种条件的最长子数组/子串” （如最多 K 种字符、子数组和 ≤ K 等）。  
- **一句话总结解题钥匙**：**先把“能否做到”抽象成一个 O(n) 的判定函数，再用二分搜索把答案逼到最大**。

## 反思

- **第一反应**：看到“出现两次”，立刻想到枚举所有子串并计数——最直观但慢的暴力方法。  
- **最容易踩的坑**  
  - **长度上界**：忘记两次出现至少需要占两倍空间，导致二分上界写成 `n` 而不是 `n//2`。  
  - **重叠计数**：如果要求“非重叠出现”，判定函数需要额外检查起点间距；本题允许重叠，直接用集合即可。  
  - **集合冲突**：在 Python 中直接把子串放进 `set`，无需手写哈希函数，但要注意子串本身是不可变的（hashable）。  
- **下次类似题**：第一步先 **写出 O(n) 判定函数**（用哈希、滑动窗口或前缀和），再决定是否需要二分、滑动窗口或双指针来把答案扩展到最大。
