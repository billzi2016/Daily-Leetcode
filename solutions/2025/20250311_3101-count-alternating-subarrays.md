# #3101. 计数交替子数组 / Count Alternating Subarrays

> 难度：中等 · 标签：Array、Math · [LeetCode 链接](https://leetcode.com/problems/count-alternating-subarrays/)

## 题目（英文原版）

**Description**

You are given a binary array nums.
We call a subarray alternating if no two adjacent elements in the subarray have the same value.
Return the number of alternating subarrays in nums.

**Examples**

**Example 1:**

```
Input: nums = [0,1,1,1]
Output: 5
Explanation:
The following subarrays are alternating: [0] , [1] , [1] , [1] , and [0,1] .
```

**Example 2:**

```
Input: nums = [1,0,1,0]
Output: 10
Explanation:
Every subarray of the array is alternating. There are 10 possible subarrays that we can choose.
```

**Constraints**

- 1 <= nums.length <= 105
- nums[i] is either 0 or 1.

## 题目（中文翻译）

给定一个二进制数组（binary array）`nums`。  
如果子数组（subarray）中相邻的两个元素值不同，则称该子数组为**交替**（alternating）。  
返回 `nums` 中交替子数组的数量。

## 示例

### 示例 1
**输入**：`nums = [0,1,1,1]`  
**输出**：`5`  
**解释**：以下子数组是交替的：`[0]`、`[1]`、`[1]`、`[1]` 和 `[0,1]`。

### 示例 2
**输入**：`nums = [1,0,1,0]`  
**输出**：`10`  
**解释**：数组的所有子数组都是交替的。共有 10 种可能的子数组。

## 约束条件

- `1 <= nums.length <= 10^5`
- `nums[i]` 只能是 `0` 或 `1`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**枚举所有子数组**，检查它们是否满足“相邻元素不同”。  

- **枚举子数组**：用两个嵌套循环，外层 `i` 表示子数组的左端点，内层 `j` 表示右端点。  
- **检查交替性**：在确定了 `[i, j]` 之后，再用一次循环遍历这个子数组的每一对相邻元素，看看是否有相等的情况。  

> **类比**：把数组想成一排灯泡（只能是开 `1` 或关 `0`），我们要找所有“灯泡颜色交替”的连续段。暴力法就是把每一种可能的起点和终点都写下来，然后逐个检查灯泡的颜色是否真的交替。

**为什么正确**：只要遍历了所有可能的 `[i, j]`，并且对每一个都做了严格的交替性判断，就一定不会漏掉任何合法子数组，也不会把不合法的算进去。

#### 代码（Python）

```python
def countAlternatingSubarrays_bruteforce(nums):
    n = len(nums)
    ans = 0                       # 用来累计合法子数组的个数

    # i 为子数组的左端点
    for i in range(n):
        # j 为子数组的右端点（包含 i 本身）
        for j in range(i, n):
            ok = True               # 假设子数组 [i, j] 是交替的
            # 检查子数组内部每一对相邻元素
            for k in range(i, j):
                if nums[k] == nums[k + 1]:   # 发现相同的相邻元素
                    ok = False
                    break                     # 立即停止检查，直接判为不合法
            if ok:
                ans += 1            # 统计一个合法子数组
    return ans
```

#### 复杂度

- **时间复杂度**：`O(n³)`  
  - 外层两个循环各 `O(n)`，内部检查相邻元素的循环最坏也要遍历 `O(n)`，于是整体是 `n * n * n`。  
  - **大白话**：如果数组长度是 1000，暴力法大约要跑 `1000³ = 10⁹` 次操作，明显太慢。

- **空间复杂度**：`O(1)`  
  - 只用了常数个额外变量，不会随输入规模增长而增加内存。

### 2. 最优解

#### 思路  

从暴力解出发，**瓶颈**在于我们每次都要重新遍历子数组内部去检查交替性。实际上，**如果我们已经知道以位置 `i‑1` 结尾的交替子数组有多少个，那么以 `i` 结尾的子数组可以很快算出来**。

设 `dp[i]` 表示**以 `i` 为右端点的交替子数组的个数**。  

- 当 `i = 0` 时，只有 `[0]` 一个子数组，显然 `dp[0] = 1`。  
- 对于 `i > 0`，只要 `nums[i]` 与 `nums[i‑1]` 不相等，**所有以 `i‑1` 结尾的交替子数组**（它们的右端点是 `i‑1`）**都可以再向右延伸一个元素**，再加上单独的 `[i]` 本身。于是  
  `dp[i] = dp[i‑1] + 1`。  
- 否则（`nums[i] == nums[i‑1]`），只能单独成子数组，`dp[i] = 1`。  

最终答案是所有 `dp[i]` 的和，因为每个 `dp[i]` 已经把以 `i` 结尾的所有合法子数组计数了。

> **类比**：想象我们在走楼梯。若前一步（`i‑1`）和这一步（`i`）颜色不同，就可以把前面走过的所有合法“步数”都延伸到这一步；若颜色相同，就只能重新开始计数。

**一步步推导**  
1. **观察**：交替子数组的长度只受相邻元素是否相等影响。  
2. **递推**：利用前一个位置的结果 `dp[i‑1]`，如果可以继续交替，就把它加一；否则重新开始。  
3. **累加**：所有 `dp[i]` 加起来就是答案，因为每个子数组恰好在它的右端点被计数一次。

#### 代码（Python）

```python
def countAlternatingSubarrays(nums):
    """
    使用动态规划（DP）一次遍历求解交替子数组的总数。
    dp[i] 表示以 i 为右端点的交替子数组个数。
    """
    n = len(nums)
    dp = [0] * n          # dp 数组保存每个位置的计数
    dp[0] = 1             # 第一个元素单独构成一个合法子数组
    total = dp[0]         # 累计答案

    for i in range(1, n):
        if nums[i] != nums[i - 1]:
            # 可以在前面的交替子数组基础上再加一个元素
            dp[i] = dp[i - 1] + 1
        else:
            # 与前一个相同，只能单独成子数组
            dp[i] = 1
        total += dp[i]    # 将以 i 结尾的子数组全部加入答案

    return total
```

> **代码要点**  
- `dp[i] = dp[i-1] + 1` 是核心递推式。  
- `total` 在遍历时同步累加，避免最后再遍历一次 `dp`。  
- 整个过程只用了 **一次线性扫描**。

#### 复杂度

- **时间复杂度**：`O(n)`  
  - 只遍历数组一次，每个位置做常数时间的计算。  
  - **大白话**：如果数组有 100,000 个元素，只需要大约 100,000 次操作，轻松跑完。

- **空间复杂度**：`O(1)`（如果不把 `dp` 数组显式保存）  
  - 实际上只需要前一个 `dp` 的值即可，用一个变量 `prev` 替代整个数组，进一步省空间。  
  - 这里保留 `dp` 仅为教学方便，仍然是线性大小 `O(n)`，但可以改写成 `O(1)`。

## 心得

- **核心技巧**：利用**前缀信息 + 动态规划**，把“以 i 结尾的子数组数”转化为对前一位置的递推。  
- **适用题型**：  
  1. “以 i 结尾的子数组满足某种性质” 的计数问题（如连续递增子数组、相同字符子串等）。  
  2. “最长/最多满足条件的子段” 类问题（如最长递增子序列的线性 DP 版）。  
- **一句话总结**：**把子数组的计数交给右端点，让每一步只看前一步能否继续**。

## 反思

- **第一反应**：直接想到枚举所有子数组检查交替性，写出暴力解。  
- **最容易踩的坑**：  
  - 忘记把单元素子数组也计入答案（它们天然交替）。  
  - 在递推时误写成 `dp[i] = dp[i-1]`（少加 1），导致少统计单独的 `[i]`。  
  - 边界条件：数组长度为 1 时要直接返回 1。  
- **下次类似题的第一步**：先思考**“以当前位置为结束点的子结构有多少？”**，看能否用前一个位置的结果递推，这往往能把 `O(n²)` 或 `O(n³)` 降到 `O(n)`。
