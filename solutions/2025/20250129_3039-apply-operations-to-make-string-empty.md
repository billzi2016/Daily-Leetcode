## 题目（中文翻译）

给定一个字符串 `s`。

考虑对 `s` 反复执行如下操作，直至 `s` 变为空：

- 在当前字符串中找到任意一对相邻且相同的字符（例如 `"aa"`、`"bb"` 等），将这两个字符一起删除，剩余字符保持相对顺序不变。

当不存在可以删除的相邻相同字符时，执行一次“最后的操作”：将当前字符串全部删除，使其变为空。

返回在执行 **最后一次操作之前** 的字符串，即在没有相邻相同字符的那一刻的 `s`。

**示例 1**

```text
输入: s = "aabcbbca"
输出: "ba"
解释:
- 首先删除相邻的 "aa" → s = "bcbbca"
- 再删除相邻的 "bb" → s = "bcca"
- 再删除相邻的 "cc" → s = "ba"
此时不存在相邻相同字符，进行最后一次操作把 "ba" 全部删除。
返回最后一次操作前的字符串 "ba"。
```

```text

解释:
- 初始字符串中没有相邻相同字符，直接进行最后一次操作把整个字符串删除。
返回最后一次操作前的字符串，即原字符串 "abcd"。
```

**约束条件**

- `1 <= s.length <= 5 * 10^5`
- `s` 仅由小写英文字母组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**一步一步模拟题目描述的操作**：

1. 统计当前字符串里每个字符出现的次数（可以用「哈希表」——就像查字典，键是字母，值是出现次数）。
2. 找出出现次数**最多**的字符集合 `maxChars`（可能不止一个）。
3. 把字符串中所有属于 `maxChars` 的字符全部删掉，得到新字符串。
4. 重复 1~3，直到字符串为空。  
5. 在循环结束前保存一次「即将删除前」的字符串，就是答案。

> **为什么正确？**  
> 题目要求的正是「每一次都删除出现次数最高的字符」的过程，暴力模拟恰好完整执行了所有步骤，自然会得到正确的结果。

> **时间/空间复杂度**  
> - 每一次循环我们都要遍历整个字符串来统计频次并生成新字符串。最坏情况下，字符一次只被删除一个，循环次数会是 `n`（字符串长度），每次遍历的代价是 `O(n)`，于是总时间是 `O(n²)`。  
> - 哈希表里只保存 26 个小写字母的计数，空间是 `O(1)`（常数级）。

> **大白话解释**：  
> `O(n²)` 可以想象成「把一张长方形的纸（长度 n）折叠 n 次，每次都要把整张纸重新检查一遍」，工作量会非常大，尤其当 `n` 接近 5×10⁵ 时几乎不可能跑完。

#### 代码（Python）

```python
def lastStringBeforeEmpty_bruteforce(s: str) -> str:
    # 用来记录上一次（即将被删除前）的字符串
    prev = s

    while s:                     # 当字符串不为空时继续
        # 1. 统计每个字符出现次数，类似查字典
        freq = {}
        for ch in s:
            freq[ch] = freq.get(ch, 0) + 1

        # 2. 找出最大的出现次数
        max_cnt = max(freq.values())

        # 3. 收集所有出现次数等于 max_cnt 的字符
        max_chars = {ch for ch, cnt in freq.items() if cnt == max_cnt}

        # 4. 删除这些字符，生成新字符串
        prev = s                  # 记录本轮操作前的字符串
        s = ''.join(ch for ch in s if ch not in max_chars)

    # 循环结束时，prev 正是最后一次操作前的字符串
    return prev
```

#### 复杂度

- **时间复杂度**：`O(n²)`  
  每轮遍历整个字符串（`O(n)`），最坏需要 `n` 轮。

- **空间复杂度**：`O(1)`  
  只用了 26 个字母的计数表，和生成新字符串的临时变量，均为常数空间。

### 2. 最优解

#### 思路  

从暴力解出发，我们发现**瓶颈在于每轮都要重新遍历整个字符串**。实际上，题目只要求**“最后一次操作前的字符串”**，并不需要完整模拟所有过程。

观察题目提示：

> *在最后一次操作前，原字符串中出现次数最高的字符会全部保留下来，只保留它们的**最后一次出现**。*

这句话暗示了答案只和**字符出现次数**以及**它们的最后出现位置**有关。

**推导过程**：

1. 统计原字符串中每个字符的出现次数 `cnt[ch]`（一次遍历完成）。
2. 找出最大出现次数 `max_cnt`。只有出现次数等于 `max_cnt` 的字符会在倒数第二轮仍然存在，其他字符在更早的轮次就会被删除。
3. 对于这些「最频繁字符」(`max_cnt` 的字符)，只保留它们在原字符串中的**最右侧**（最后一次出现）的位置，其余出现都已经在更早的操作中被删除了。
4. 将这些保留下来的字符按它们在原字符串中的顺序拼接，即得到**倒数第二轮**的字符串，也就是答案。

**核心数据结构**：

- **哈希表**（字典）`cnt`：统计每个字符出现次数，类似查字典，key 是字母，value 是出现次数。
- **数组/列表** `last_pos`：记录每个字符最后一次出现的下标。下标可以看作「书的页码」，字母对应「词条」，我们只保留「最后一页」的词条。

**步骤细化**：

| 步骤 | 说明 |
|------|------|
|① 统计频次 & 记录最后下标 | 遍历一次字符串，`cnt[ch] += 1`，`last_pos[ch] = i`（`i` 为当前下标）。 |
|② 求最大频次 `max_cnt` | `max(cnt.values())`，一次遍历哈希表（最多 26 项）。 |
|③ 收集满足条件的字符 | 对每个字母 `ch`，如果 `cnt[ch] == max_cnt`，把 `(last_pos[ch], ch)` 加入列表 `candidates`。 |
|④ 按下标排序 | `candidates.sort()`，确保字符按它们在原串中的出现顺序排列。 |
|⑤ 拼接答案 | 把排序后的字符拼成字符串返回。 |

> **为什么只保留最后一次出现？**  
> 在每一次操作中，所有出现次数最高的字符都会被一次性删除。假设字符 `x` 的出现次数是全局最高 `max_cnt`，那么在倒数第二轮之前，它们仍然存活。此时，`x` 在字符串中出现 `max_cnt` 次，按照操作规则，这一轮会把 **所有** `x` 删除，导致字符串空。要得到“空之前的那一次”，我们只能保留 `x` 的**最后一次**出现——因为在倒数第二轮，`x` 仍然在，且只剩下它们的最后一次出现（其他出现已经在更早的轮次被删除）。同理对所有出现次数等于 `max_cnt` 的字符都成立。

> **时间/空间复杂度**  
> - 只遍历一次字符串 → `O(n)`。  
> - 只维护 26 个字母的计数和下标 → `O(1)`（常数空间）。  
> - 额外的 `candidates` 最多也只有 26 项，排序成本可视为常数。

> **大白话解释**：  
> `O(n)` 就像只需要一次“扫地”，把所有垃圾一次性收集完，而不是每扫一次都要重新检查全屋。

#### 代码（Python）

```python
def lastStringBeforeEmpty_optimal(s: str) -> str:
    """
    返回在执行最后一次删除操作前的字符串。
    思路：只保留出现次数最高的字符的最后一次出现。
    """
    # 1. 统计每个字符的出现次数，并记录它们最后出现的位置
    cnt = {}          # 哈希表：字符 -> 出现次数
    last_pos = {}     # 哈希表：字符 -> 最后一次出现的下标
    for i, ch in enumerate(s):
        cnt[ch] = cnt.get(ch, 0) + 1
        last_pos[ch] = i      # 每遍历一次就更新为最新的下标

    # 2. 找出全局最大的出现次数
    max_cnt = max(cnt.values())

    # 3. 收集所有出现次数等于 max_cnt 的字符以及它们的最后下标
    candidates = []   # 列表中每个元素是 (下标, 字符)
    for ch, c in cnt.items():
        if c == max_cnt:
            candidates.append((last_pos[ch], ch))

    # 4. 按下标升序排列，确保字符顺序与原字符串中出现的顺序一致
    candidates.sort(key=lambda x: x[0])

    # 5. 拼接字符得到答案
    answer = ''.join(ch for _, ch in candidates)
    return answer
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  只需要一次遍历字符串（`n` 为字符串长度），后面处理的都是最多 26 个字母的常数工作。

- **空间复杂度**：`O(1)`  
  使用的哈希表最多存 26 条记录，`candidates` 最多 26 项，都是常数级别的额外空间。

## 心得

- **核心技巧**：**统计字符频次 + 只保留最高频字符的最后一次出现**。  
- **适用的题型**：  
  1. “删除出现次数最高的字符直到空” 类似的模拟题。  
  2. “只保留出现次数最多的字符的最后一次出现” 这类需要一次遍历求解的题。  
  3. “找出出现次数最多的字符并按特定顺序输出” （如 LeetCode 451 `Sort Characters By Frequency` 的变形）。
- **一句话总结**：**先找出最高频字符，再只取它们的最右侧位置即可得到倒数第二轮的字符串。**

## 反思

- **第一反应**：看到“重复操作直至空”，自然想到**循环模拟**，因为这样最直接对应题目描述。
- **最容易踩的坑**：  
  - 忘记只保留**最后一次出现**，导致答案多出重复字符。  
  - 误以为所有最高频字符都要完整保留，实际上只需要它们的**最右侧**一次出现。  
  - 边界情况：当所有字符出现次数相同（如 `"abcd"`），此时所有字符都是最高频，答案应该是原字符串本身，需要正确处理排序。
- **下次类似题的第一步**：先**统计频次**，看是否可以直接从“出现次数”推导出答案，而不是盲目模拟全部过程。这样往往能把时间复杂度从 `O(n²)` 降到 `O(n)`。
