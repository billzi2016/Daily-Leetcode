# #3079. 求加密整数的和 / Find the Sum of Encrypted Integers

> 难度：简单 · 标签：Array、Math · [LeetCode 链接](https://leetcode.com/problems/find-the-sum-of-encrypted-integers/)

---

## 题目（英文原版）

**Description**

You are given an integer array nums containing positive integers. We define a function encrypt such that encrypt(x) replaces every digit in x with the largest digit in x. For example, encrypt(523) = 555 and encrypt(213) = 333.
Return the sum of encrypted elements.

**Examples**

**Example 1:**

```
Input: nums = [1,2,3]
Output: 6
Explanation: The encrypted elements are [1,2,3] . The sum of encrypted elements is 1 + 2 + 3 == 6 .
```

**Example 2:**

```
Input: nums = [10,21,31]
Output: 66
Explanation: The encrypted elements are [11,22,33] . The sum of encrypted elements is 11 + 22 + 33 == 66 .
```

**Constraints**

- 1 <= nums.length <= 50
- 1 <= nums[i] <= 1000

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**对数组里的每一个整数，都把它的每一位数字换成该整数里出现的最大数字**，得到“加密后”的数，再把所有加密后的数相加。

- **数据结构**：只需要遍历普通的 Python 列表 `nums`。  
- **生活化类比**：把每个整数想成一本小书的章节，每一页上都有一个数字。我们要把这本书里出现的最高页码（最大数字）抄写到每一页上，最后把所有书的页码相加。  
- **正确性**：因为题目明确规定“把每一位都换成该整数的最大数字”，只要我们按位找到最大数字并用它替换每一位，就一定得到题目要求的加密数。把所有加密数相加自然就是答案。  

**时间复杂度**：  
- 对每个整数，我们要遍历它的每一位（最多 4 位，因为 `nums[i] ≤ 1000`）。所以总体时间是 `O(n * d)`，这里 `n` 是数组长度，`d` 是数字位数。由于 `d ≤ 4`，可以直接写成 `O(n)`。  
- 用大白话说，就是“遍历一次数组，每个元素最多检查几次就好”，不会出现指数级的增长。

**空间复杂度**：  
- 只用了常数级的额外变量（最大数字、加密后的值），不随 `n` 增长，所以是 `O(1)`，即“只占用很少的内存”。

#### 代码（Python）

```python
from typing import List

def sumEncrypted(nums: List[int]) -> int:
    total = 0                     # 用来累计所有加密后的数
    for x in nums:                # 逐个遍历数组里的整数
        # 1）找出 x 的最大数字
        max_digit = 0
        tmp = x
        while tmp > 0:            # 按位检查，每次取出最低位
            digit = tmp % 10      # 取出当前位的数字
            if digit > max_digit:
                max_digit = digit # 更新最大数字
            tmp //= 10            # 去掉已经检查过的最低位

        # 2）把所有位都换成 max_digit，构造加密后的数
        # 例如 max_digit=5, x 有 3 位 => 555 = 5 * 111
        # 计算 111 可以用 (10**len - 1) // 9
        length = len(str(x))                     # x 有多少位
        ones = (10 ** length - 1) // 9           # 111…1（length 个 1）
        encrypted = max_digit * ones             # 加密后的数

        total += encrypted                       # 累加到答案
    return total
```

#### 复杂度

- **时间复杂度**：`O(n)` —— 只需要遍历一次数组，每个数最多检查 4 位，实际运行时间和数组长度成正比。  
- **空间复杂度**：`O(1)` —— 只用了几个整型变量，和数组大小无关。

### 2. 最优解

#### 思路  

从暴力解出发，我们已经找到了每个数的最大数字 `max_digit`，并用公式 `max_digit * 111…1` 生成加密数。其实，这已经是 **最优** 的做法，因为：

- **瓶颈在哪里？**  
  暴力解的每一步（遍历数组、逐位找最大数字）都是必须的。没有任何可以省去的循环，因为每个数的最大数字必须被计算出来。  
- **可以进一步简化吗？**  
  - 直接把整数转成字符串，然后用 `max()` 找最大字符，再用 `int()` 把字符转回数字。字符串操作在 Python 中实现更简洁，且时间仍是 `O(d)`。  
  - 计算 `111…1`（由 `length` 个 `1` 组成）可以直接用 `int('1' * length)`，避免数学公式。  
  - 由于 `nums[i] ≤ 1000`，`length ≤ 4`，所以这两种实现方式在实际运行时间上几乎相同，都是线性 `O(n)`。  

**核心技巧**：  
- **逐位求最大**（可以用整数取余 `%` 或字符串 `max`）  
- **构造全 1 数**（`int('1'*len)`）  
- **一次遍历累计**（双指针思想的最简形态）

**类比**：把每个数字想成一块拼图，先找出拼图里最大的颜色块（最大数字），然后把整块拼图都涂成这个颜色，最后把所有拼图的面积（数值）相加。

#### 代码（Python）

```python
from typing import List

def sumEncrypted(nums: List[int]) -> int:
    total = 0
    for x in nums:
        s = str(x)                       # 把整数转成字符串，方便逐位操作
        max_digit = int(max(s))          # 字符串 max 能直接得到最大字符，再转成整数
        ones = int('1' * len(s))         # 生成 length 位的 111…1，例如 "111"
        total += max_digit * ones        # 加密数 = max_digit * 111…1
    return total
```

#### 复杂度

- **时间复杂度**：`O(n)` —— 仍然只遍历一次数组，每个数的字符串长度最多 4，整体随 `n` 成线性关系。相较于暴力解，常数因子更小（少了手动取余的循环）。  
- **空间复杂度**：`O(1)` —— 只使用了几个临时变量，额外空间不随 `n` 增长。

## 心得

- **核心技巧**：**逐位找最大数字 + 用全 1 构造乘数**。这两步组合即可把任意正整数“统一加密”。  
- **适用的题型**：  
  1. “把每位数字替换成某个函数值” 类题（如把每位数字换成其平方或翻转等）。  
  2. “根据数字的位数或特征构造新数” 类题（如把每位都换成 9，或把每位都换成 0）。  
- **一句话总结**：**先找出局部最大（或目标），再把整个位数统一为该目标**，就是解这类“位替换”题的钥匙。

## 反思

- **第一反应**：把每个数拆成数字，手动找最大，再重新拼接。  
- **最容易踩的坑**：  
  - 忘记处理 **一位数** 的情况（仍然要生成 `1`，公式仍然适用）。  
  - 对 `0` 的处理（本题所有数均为正整数，故不必担心）。  
  - 当使用整数取余循环时，忘记在 `while tmp > 0` 前处理 `tmp == 0` 的情况。  
- **下次遇到同类题**：第一步先 **把数字转换为可遍历的形式（字符串或列表）**，再 **找出需要的关键值（最大、最小、奇偶等）**，最后 **用该关键值统一生成新数**。这样思路清晰，代码也更简洁。
