## 题目（中文翻译）

给定整数数组 `nums` 和整数 `k`，长度为 `x` 的子序列 `sub`（subsequence）被称为**有效**，如果 `sub` 中任意相邻的两个元素 `a` 和 `b` 满足  

\[
(a + b) \bmod k \neq 0
\]

换句话说，任意相邻元素的和不能被 `k` 整除。

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法就是把 **所有可能的子序列** 都枚举出来，逐个检查它们是否满足题目要求，然后记录最长的合法长度。  

- **子序列**：可以把数组看成一串珠子，拿走若干珠子（保持原来的顺序），剩下的就是一个子序列。  
- **合法性**：题目说一个子序列 `subs` 的 **相邻两数之和 modulo k** 必须保持一致。也就是说，设  
  \[
  val = (subs[0] + subs[1]) \% k
  \]  
  那么对于子序列中任意相邻的 `a, b` 都要满足  
  \[
  (a + b) \% k = val
  \]  
  这就像把每个数的 “余数” 当作颜色，要求相邻两个颜色的组合总是得到同一个结果 `val`。  

要实现暴力，我们可以：

1. 用二进制掩码 `mask`（长度为 `n`）遍历 `0 … 2^n‑1`，每一种掩码对应一种取舍方案。  
2. 把被选中的元素按原顺序拼成子序列 `subs`。  
3. 如果 `len(subs) < 2`（只有 0/1 个元素）直接算合法，因为没有相邻对可以违背规则。  
4. 否则计算 `val = (subs[0] + subs[1]) % k`，检查所有相邻对是否都满足同样的余数。  
5. 合法就更新答案的最大长度。  

**为什么一定对？**  
因为我们把「所有可能的子序列」都遍历了一遍，必然会包含最优的那一个。只要检查的条件和题目描述完全一致，答案自然正确。

**时间/空间复杂度**  
- 时间：遍历 `2^n` 种子序列，每种子序列最坏要扫描一次数组来收集元素并检查相邻关系，时间复杂度是 **O(n·2ⁿ)**。  
  - 大白话：如果数组有 20 个元素，2ⁿ≈1 048 576，乘上 20 仍然是几千万次操作，已经远远超出一般机器在 1 秒内能完成的量。  
- 空间：只用到常数级别的额外变量（掩码、临时列表），**O(1)**。  

显然，这种办法只能在 `n` 很小（比如 ≤20）时才可行，题目里 `n` 可以到 1000，暴力根本不可取。

#### 代码（Python）  

```python
from itertools import compress

def maxLength_bruteforce(nums, k):
    n = len(nums)
    best = 0

    # 2^n 种取舍方式，用整数的二进制位表示是否取第 i 个元素
    for mask in range(1 << n):
        # 通过 mask 生成子序列（保持原顺序）
        subseq = [nums[i] for i in range(n) if mask >> i & 1]

        if len(subseq) <= 1:                # 长度 0/1 的子序列天然合法
            best = max(best, len(subseq))
            continue

        # 计算第一个相邻对的余数，作为全局要求的 val
        val = (subseq[0] + subseq[1]) % k
        ok = True
        # 检查后面的每一对是否满足同样的余数
        for a, b in zip(subseq, subseq[1:]):
            if (a + b) % k != val:
                ok = False
                break

        if ok:
            best = max(best, len(subseq))

    return best
```

> **注意**：这段代码仅用于说明思路，实际提交会因为超时而被判为错误。

#### 复杂度  

- **时间复杂度**：`O(n·2ⁿ)` —— 解释见上文。  
- **空间复杂度**：`O(1)` —— 只用了常数级的临时变量。

### 2. 最优解  

#### 思路  

暴力的瓶颈在于 **枚举所有子序列**。我们需要一种方法，只在 **一次遍历**（或者少数次遍历）中直接得到最长合法长度。  

关键观察：

1. **只关心余数**  
   对于合法子序列，只需要知道每个元素 `x` 对 `k` 的余数 `r = x % k`，因为判断 `(a + b) % k` 只涉及余数。  

2. **固定目标余数 `val`**  
   整个子序列的相邻和的余数是唯一的 `val`（0 … k‑1）。如果我们先 **假设** 这个 `val` 为某个具体值，就可以把问题转化为：  
   > “在只允许相邻余数满足 `(prev + cur) % k == val` 的前提下，最长子序列有多长？”  

3. **动态规划 + 余数分桶**  
   - 设 `dp[i]` 为 **以余数 `i` 结尾的合法子序列的最大长度**（在当前假设的 `val` 下）。  
   - 当遍历到新元素 `y`（余数 `r = y % k`）时，只有 **前一个元素余数 `pre`** 能满足  
     \[
     (pre + r) \% k = val \quad\Longleftrightarrow\quad pre = (val - r) \bmod k
     \]  
     才能把 `y` 接在后面。于是可以把 `dp[pre]` 的长度加一得到以 `y` 结尾的新长度。  
   - 用公式写成代码就是  
     ```python
     pre = (k + val - r) % k          # 保证非负
     cand = dp[pre] + 1               # 以 y 结尾的候选长度
     dp[r] = max(dp[r], cand)         # 取最大，保持 dp 的定义
     ```  
   - 对每个 `val` 都做一次完整的遍历，记录期间出现的最大 `dp[*]`，即为该 `val` 下的答案。  

4. **遍历所有 `val`**  
   `val` 共有 `k` 种可能（0 … k‑1），所以总时间是 `O(k·n)`，在题目限制（n、k ≤ 10³）下完全可接受。  

5. **为什么不需要记住“第一个元素”**  
   动态规划从左到右自然保证子序列的顺序；一开始 `dp[*]` 都是 `0`，当第一次看到某个余数 `r` 时，它会尝试把自己当作 **长度为 1 的子序列**（因为 `dp[pre]` 为 0），这正好对应“任意单个元素都是合法的”。随后所有的相邻约束都通过 `val` 自动生效。  

**类比**：把余数看成不同颜色的球，`val` 决定了“前后两个颜色要配成特定的配方”。`dp[i]` 记录了“以颜色 i 结尾、配方已经满足的最长链”。遍历每个配方，尝试把新球接在合适的颜色后面，最终得到最长链的长度。

#### 代码（Python）  

```python
def maxLength(nums, k):
    """
    返回满足“相邻两数之和 modulo k 恒定”的最长子序列长度。
    思路：枚举 val = (a_i + a_{i+1}) % k，使用 dp 记录以每个余数结尾的最长长度。
    """
    ans = 0                     # 全局最优

    # 余数范围是 0 … k-1
    for val in range(k):        # 假设目标余数为 val
        dp = [0] * k            # dp[i] = 以余数 i 结尾的最长合法子序列长度

        for x in nums:
            r = x % k                           # 当前元素的余数
            pre = (k + val - r) % k             # 前一个元素必须拥有的余数
            cand = dp[pre] + 1                  # 把 x 接在前面的子序列后面

            if cand > dp[r]:                    # 更新 dp[r]（取最大）
                dp[r] = cand

            # 维护全局答案
            if dp[r] > ans:
                ans = dp[r]

    return ans
```

> **代码要点解释**  
> 1. `pre = (k + val - r) % k`：在 Python 中负数取模会得到非负结果，但加上 `k` 更直观，确保 `pre` 在 `[0, k-1]`。  
> 2. `dp[pre] + 1`：如果当前余数 `r` 能接在余数 `pre` 后面，就把长度加一。若 `dp[pre]` 为 0，说明这是子序列的第一个元素，得到长度 1。  
> 3. 每次遍历完所有 `nums`，`dp` 中的最大值就是在固定 `val` 下的最长合法长度。我们在外层循环里取所有 `val` 的最大值即为答案。  

#### 复杂度  

- **时间复杂度**：`O(k·n)`。  
  - 大白话：我们把「目标余数」的可能性（最多 1000 种）和「数组元素」的遍历（最多 1000 次）做了笛卡尔积，一共最多一百万次简单的整数运算，几乎在毫秒级就能跑完。  
- **空间复杂度**：`O(k)`。  
  - 只需要一个长度为 `k` 的数组 `dp` 来记录余数对应的最长长度，随着 `k` 最大为 1000，空间占用微乎其微。

## 心得  

- **核心技巧**：把「相邻两数之和 modulo k 相同」转化为「余数之间的固定配方」并用 **动态规划 + 余数分桶** 来求最长链。  
- **适用场景**：  
  1. 需要在序列中维护「相邻元素之间的某种固定关系」的最长子序列（如相邻差固定、相邻乘积固定等）。  
  2. 任何可以把元素映射到「有限类别」(余数、颜色、状态) 并且转移只依赖前一个类别的 DP 题目。  
- **一句话总结**：**把全局约束先固定为某个值，然后用余数做状态，动态规划一次遍历即可得到最长合法子序列。**

## 反思  

- **第一反应**：看到“相邻两数之和 % k 相同”，本能想到枚举所有子序列或直接暴力检查，随后意识到会超时。  
- **最容易踩的坑**：  
  1. **余数取模的负数问题**——在计算 `pre = (val - r) % k` 时，若直接写 `val - r` 可能得到负数，需要加 `k` 再取模。  
  2. **忘记把单个元素也算作合法子序列**——在 DP 初始化时 `dp[*] = 0`，但在更新时要让 `dp[r] = max(dp[r], 1)`，否则长度会一直停留在 0。  
  3. **忘记遍历所有 `val`**——只固定一种 `val` 会漏掉其他可能的更长序列。  
- **下次类似题的第一步**：  
  1. 把题目中的「相邻关系」抽象成「状态转移」——找出只和前一个元素有关的表达式。  
  2. 判断状态空间是否可以压缩（如余数、颜色、模数），然后尝试 **状态 DP**。
