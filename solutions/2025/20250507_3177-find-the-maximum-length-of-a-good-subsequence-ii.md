## 题目（英文原版）

**Description**

You are given an integer array nums and a non-negative integer k. A sequence of integers seq is called good if there are at most k indices i in the range [0, seq.length - 2] such that seq[i] != seq[i + 1].
Return the maximum possible length of a good subsequence of nums.

**Examples**

**Example 1:**

```
Input: nums = [1,2,1,1,3], k = 2
Output: 4
Explanation:
The maximum length subsequence is [ 1 , 2 , 1 , 1 ,3] .
```

**Example 2:**

```
Input: nums = [1,2,3,4,5,1], k = 0
Output: 2
Explanation:
The maximum length subsequence is [ 1 ,2,3,4,5, 1 ] .
```

**Constraints**

- 1 <= nums.length <= 5 * 103
- 1 <= nums[i] <= 109
- 0 <= k <= min(50, nums.length)

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把每一种可能的子序列都枚举一遍**，看它是否满足「相邻不相等的次数 ≤ k」并记录最长的长度。  

- **子序列**可以想象成把原数组的若干元素挑出来，保持原来的相对顺序，就像从一本书里挑出若干页码，页码之间的顺序不变。  
- 为了判断一段挑出来的序列是否「good」，我们只需要遍历一次这段序列，统计相邻两位不相等的次数。如果次数 ≤ k，说明这段序列合法。  

显然，这种「全枚举」的办法在概念上最容易理解——只要把所有可能的挑选方式都试一遍，就一定能找到最长的合法子序列。  

> **为什么它是正确的？**  
> 因为我们没有遗漏任何一种可能的挑选方式，所有合法的子序列都会被检查到，最大长度自然会被记录下来。

> **时间/空间复杂度**  
> - 枚举子序列的数量是 $2^{n}$（每个元素要么选要么不选），对每一种子序列我们还要再遍历一次来统计不相等的次数，时间复杂度是指数级的 **O(2ⁿ)**，在实际里根本跑不完。  
> - 只需要常数级的额外空间来保存当前子序列和计数器，空间复杂度是 **O(1)**。  

用大白话来说，`O(2ⁿ)` 就像把 20 个人的全部组合全部列出来，组合数已经是 **1,048,576**，而 n 最多可达 **5000**，组合数天文般大，根本不可能在电脑里跑完。

#### 代码（Python）

下面的代码仅用于演示「全枚举」的思路，**不推荐在正式提交时使用**，因为会超时甚至内存炸掉。

```python
from itertools import combinations

def max_good_subseq_bruteforce(nums, k):
    n = len(nums)
    best = 0

    # 对每一种可能的子序列长度从大到小遍历，遇到合法的就直接返回
    for length in range(n, 0, -1):
        # 组合出所有长度为 length 的子序列（保持顺序）
        for idxs in combinations(range(n), length):
            # 取出对应的元素构成子序列
            seq = [nums[i] for i in idxs]

            # 统计相邻不相等的次数
            diff = sum(1 for i in range(len(seq) - 1) if seq[i] != seq[i + 1])

            if diff <= k:                # 合法
                return length           # 因为是从大到小枚举，第一次合法就是最大长度
    return 0
```

> 关键行解释（中文注释已经写在代码里）  
> - `combinations(range(n), length)`：把下标看成“一本书的页码”，挑出 `length` 页，保持顺序。  
> - `diff = sum(1 for i …)`：遍历子序列，像数数一样统计「相邻不相等」的次数。  

#### 复杂度

- **时间复杂度**：`O(2ⁿ)` —— 需要遍历所有可能的子序列，指数级增长，几乎不可能在 5 000 长度的数据上跑完。  
- **空间复杂度**：`O(1)` —— 只用常数级的临时变量。

### 2. 最优解

#### 思路  

从暴力解可以看到 **「枚举所有子序列」** 是最大的瓶颈。  
我们需要一种 **只看一次数组**、**用局部信息就能决定是否可以把当前元素加入答案** 的方法。  

> **关键观察**  
> 在一个「good」子序列里，**相邻不相等的次数 ≤ k**，等价于「这个子序列被划分成的相同数值块的个数 ≤ k+1」。  
> 例如 `1 1 2 2 2 5 5` 中有 3 块（`1`、`2`、`5`），所以不相等的次数是 2（块之间的切换次数）。  

> **如果我们知道子序列的最后一个数是什么**，并且知道已经用了多少次「切换」(即不相等的次数)，那么**加入新元素的决策就只和这两个信息有关**。  
> - 若新元素等于当前最后一个数，则可以直接把它接在后面，不会产生新的切换。  
> - 若不等，则必须消耗一次「切换」的配额（即 `k` 减 1），才能把它接在后面。  

因此我们可以用 **动态规划** 来记录「以某个数结尾、已经用了 i 次切换」的最长子序列长度。

---

#### 2.1 DP 定义  

- 先把数组中的所有不同数值 **压缩映射** 到 `[0, m-1]`（`m` ≤ `n`），这样我们可以用数组下标直接表示数值。  
- `dp[t][v]`：**在已处理完左侧若干元素后**，**以数值 `v` 结尾、并且已经用了恰好 `t` 次切换**（即相邻不相等的次数为 `t`）的最长子序列长度。  

`0 ≤ t ≤ k`，`0 ≤ v < m`。

---

#### 2.2 转移  

遍历原数组，从左到右依次处理每个元素 `x`（已映射为 `vx`）：

1. **继续相同数值块**  
   - 如果我们把 `x` 加到已经以 `vx` 结尾、切换次数仍为 `t` 的子序列后面，长度可以加 1。  
   - `dp[t][vx] = max(dp[t][vx], dp[t][vx] + 1)` → 实际上只需要把 `dp[t][vx]` 加 1。

2. **切换到不同数值**（需要消耗一次切换）  
   - 需要找出 **在切换次数为 `t‑1` 时，结尾不是 `vx` 的子序列中最长的那一个**，记作 `best_except_vx[t‑1]`。  
   - 把 `x` 接在其后会产生一次新的切换，长度同样加 1。  
   - `dp[t][vx] = max(dp[t][vx], best_except_vx[t‑1] + 1)`  

如果我们每次都遍历所有 `y != vx` 来求 `best_except_vx[t‑1]`，时间会是 `O(k * m²)`，对 `m≈5000` 来说仍然偏慢。  
**优化技巧**：对每个 `t` 只维护 **最大值** 和 **次大值**（以及对应的数值），这样在更新 `dp[t][vx]` 时：

- 若 `vx` 不是当前最大值对应的数值，直接使用最大值。  
- 否则使用次大值（因为我们要求「不是 `vx`」的最大）。  

这样每个元素只需要 **O(k)** 的时间，整体复杂度 **O(k·n)**。

---

#### 2.3 初始化  

- 所有 `dp` 初始化为 `0`（表示还没有选任何元素）。  
- 当我们第一次看到某个数 `vx` 时，**可以把它单独当作一个子序列**，此时切换次数为 `0`，长度为 `1`。  
- 这一步可以统一在遍历时通过 `dp[0][vx] = max(dp[0][vx], 1)` 完成。

---

#### 2.4 结果  

遍历结束后，答案是所有 `dp[t][v]` 中的最大值（`0 ≤ t ≤ k`，`0 ≤ v < m`），因为我们不要求恰好用了 `k` 次切换，只要不超过即可。

---

#### 代码（Python）

```python
from typing import List

def max_good_subsequence(nums: List[int], k: int) -> int:
    n = len(nums)
    # ---------- 1. 把数值压缩到 0..m-1 ----------
    # 这里使用字典模拟“查字典”，把原始的大整数映射到小整数
    uniq = {}
    mapped = []
    for x in nums:
        if x not in uniq:
            uniq[x] = len(uniq)          # 新的映射值
        mapped.append(uniq[x])
    m = len(uniq)                       # 不同数值的个数

    # ---------- 2. 动态规划表 ----------
    # dp[t][v]：切换次数恰好为 t，且以数值 v 结尾的最长长度
    dp = [[0] * m for _ in range(k + 1)]

    # 为每个 t 维护「最大值」和「次大值」以及它们对应的数值
    # best1[t] = (value, length)   # 长度最大的
    # best2[t] = (value, length)   # 次大的（value 必须不同于 best1[t][0]）
    best1 = [(-1, 0)] * (k + 1)   # (value, length)
    best2 = [(-1, 0)] * (k + 1)

    for vx in mapped:                     # 从左到右遍历每个元素
        # 必须倒序遍历 t，防止本轮更新影响到 t-1 的状态
        for t in range(k, -1, -1):
            # ---- ① 继续相同数值块（不消耗切换）----
            if dp[t][vx] > 0:                # 已经有以 vx 结尾的子序列
                new_len = dp[t][vx] + 1
            else:
                new_len = 1                  # 第一次出现 vx，可以单独成子序列
            if new_len > dp[t][vx]:
                dp[t][vx] = new_len

            # ---- ② 切换到不同数值块（需要消耗一次切换）----
            if t > 0:
                # 从 best1[t-1] / best2[t-1] 中挑选「不是 vx 的最大值」
                if best1[t - 1][0] != vx:
                    cand_len = best1[t - 1][1] + 1
                else:
                    cand_len = best2[t - 1][1] + 1
                if cand_len > dp[t][vx]:
                    dp[t][vx] = cand_len

            # ---- ③ 更新 best1 / best2 for this t ----
            cur_len = dp[t][vx]
            b1_val, b1_len = best1[t]
            b2_val, b2_len = best2[t]

            if cur_len > b1_len:
                # 当前成为新的最大，原最大下沉为次大
                best2[t] = best1[t]
                best1[t] = (vx, cur_len)
            elif vx != b1_val and cur_len > b2_len:
                # 只比次大好，且不是当前最大对应的数值
                best2[t] = (vx, cur_len)

    # ---------- 4. 取最大 ----------
    ans = 0
    for t in range(k + 1):
        ans = max(ans, best1[t][1])   # best1[t][1] 已经是该层的最大长度
    return ans


# ---------- 示例 ----------
if __name__ == "__main__":
    print(max_good_subsequence([1, 2, 1, 1, 3], 2))   # 4
    print(max_good_subsequence([1, 2, 3, 4, 5, 1], 0))   # 2
```

**代码要点（中文注释已在代码中）**

- **压缩映射**：把大整数变成小整数，像把一本字典里的单词换成序号，查找更快。  
- **倒序遍历 `t`**：防止本轮更新把「本轮还未使用的切换次数」的状态提前覆盖。  
- **维护最大/次大**：每层 `t` 只记两条「最好的」记录，查询「除 `vx` 之外的最大」时 O(1) 完成。  

---

#### 复杂度

- **时间复杂度**：`O(k · n)`  
  - 对每个元素我们遍历 `k+1` 次（`k ≤ 50`），每次只做常数级的操作。  
  - 与暴力解的 `O(2ⁿ)`、`O(n²·k)` 相比，提升了 **指数级**（几乎瞬间完成），在最坏 `n=5000, k=50` 时也只要约 `2.5e5` 次运算，毫秒级可跑完。  

- **空间复杂度**：`O(k · m)`（`m ≤ n`）  
  - `dp` 表大小为 `(k+1) × m`，最多约 `51 × 5000 ≈ 2.5e5` 个整数，约 2 MB 左右。  
  - 额外的 `best1、best2` 只占 `O(k)` 空间。

## 心得

- **核心技巧**：把「相邻不相等的次数」转化为「块的个数」 → 用 **状态 =（已用切换次数, 结尾数值）** 的 DP。  
- **适用的题型**  
  1. **限制相邻变化次数的最长子序列**（本题）。  
  2. **最多 `k` 次删除/替换后最长递增子序列**（思路相似：状态里记录已用的操作次数）。  
  3. **最多 `k` 次颜色切换的最长路径**（图论或网格 DP 中的类似状态压缩）。  

- **一句话总结解题钥匙**：  
  > “只要知道子序列的最后一个数和已经用了多少次切换，就能在 O(1) 时间决定是否把下一个数接上去。”

## 反思

- **第一反应**：看到「最多 k 次不相等」立刻想到「枚举所有子序列」或「暴力搜索」。  
- **最容易踩的坑**  
  - **忘记压缩数值**：直接用原始 `nums[i]` 作为数组下标会导致内存爆炸（`nums[i]` 可达 1e9）。  
  - **更新顺序错误**：如果正序遍历 `t`，本轮对 `dp[t][vx]` 的更新会错误地影响 `dp[t+1]` 的转移，导致多算一次切换。  
  - **边界条件**：`k = 0` 时只能选同一个数的所有出现，需要确保「切换」的判断不会误触。  

- **下次类似题的第一步**：  
  > “先把问题抽象成‘状态 = 已用资源 + 当前状态’，然后检查转移是否只依赖于前一层的少数信息”。
