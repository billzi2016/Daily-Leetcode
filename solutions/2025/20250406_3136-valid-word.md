# #3136. **有效单词** / Valid Word

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/valid-word/)

---

## 题目（英文原版）

**Description**

A word is considered valid if:
You are given a string word.
Return true if word is valid, otherwise, return false.
Notes:

**Examples**

**Example 1:**

```
Input: word = "234Adas"
Output: true
Explanation:
This word satisfies the conditions.
```

**Example 2:**

```
Input: word = "b3"
Output: false
Explanation:
The length of this word is fewer than 3, and does not have a vowel.
```

**Example 3:**

```
Input: word = "a3$e"
Output: false
Explanation:
This word contains a '$' character and does not have a consonant.
```

**Constraints**

- 1 <= word.length <= 20
- word consists of English uppercase and lowercase letters, digits, '@', '#', and '$'.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有要求一次一次地检查出来：

1. **长度**  
   - 必须不少于 3 个字符。可以直接 `len(word) >= 3` 判断。  

2. **合法字符**  
   - 题目只允许英文字母和数字。  
   - 把每个字符拿出来判断：如果出现了 `@ # $` 或其它非字母数字的字符，就直接返回 `False`。  
   - 这里可以把 **字典** 想象成一本“查字典”。我们把合法字符当成字典的 **key**，只要在字典里找得到，就说明合法。  

3. **是否包含元音**（a、e、i、o、u，大小写均可）  
   - 再遍历一次字符串，只要遇到元音就记下来。  

4. **是否包含辅音**（除元音之外的字母）  
   - 同上，只要遇到字母且不是元音就记下来。  

5. **是否包含数字**（0‑9）  
   - 再遍历一次，只要遇到数字就记下来。  

只要 **5 条条件** 都满足，就返回 `True`，否则返回 `False`。  
这种写法思路清晰，容易实现，适合刚学会 `if‑else`、`for` 循环的同学。

#### 代码（Python）

```python
def isValidWord(word: str) -> bool:
    # 1. 长度检查
    if len(word) < 3:
        return False

    # 2. 合法字符检查（只接受字母和数字）
    for ch in word:
        if not ch.isalnum():          # isalnum() 等价于 “是字母或数字”
            return False

    # 3. 元音、辅音、数字标记
    has_vowel = False      # 是否出现过元音
    has_consonant = False  # 是否出现过辅音
    has_digit = False      # 是否出现过数字

    vowels = set('aeiouAEIOU')   # 把元音放进集合，查找 O(1)

    for ch in word:
        if ch.isdigit():
            has_digit = True
        elif ch.isalpha():          # 是字母
            if ch in vowels:
                has_vowel = True
            else:
                has_consonant = True

    # 4. 必须同时满足三类字符
    return has_vowel and has_consonant and has_digit
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  解释：我们最多遍历字符串两遍（`n` 为字符数），所以时间随字符数线性增长。  
  大白话：如果单词有 10 个字符，就检查 10 次；20 个字符，就检查 20 次，依此类推。

- **空间复杂度**：`O(1)`  
  解释：只用了几个布尔变量和常数大小的集合，和输入长度无关。  
  大白话：不管单词有多长，程序占用的额外内存基本不变。

### 2. 最优解

#### 思路  

从暴力解可以看到，**主要的性能瓶颈**在于我们对同一个字符串做了多次遍历。  
其实，只要在 **一次遍历** 中同步记录下：

- 是否已经看到元音  
- 是否已经看到辅音  
- 是否已经看到数字  
- 是否出现了非法字符  

就可以在遍历结束后直接判断所有条件。这样既省了时间，也让代码更简洁。

核心技巧是 **一次遍历 + 多状态标记**，这在很多“字符合法性”题目里都非常有用。可以把它想象成在检查一条生产线的产品时，工人一路走下来，同时检查尺寸、颜色、重量等多个指标，只要有一个不合格就立刻停下来。

#### 代码（Python）

```python
def isValidWord(word: str) -> bool:
    # 长度直接返回结果，省去后面的遍历
    if len(word) < 3:
        return False

    vowels = set('aeiouAEIOU')
    has_vowel = has_consonant = has_digit = False

    for ch in word:
        if ch.isdigit():
            has_digit = True
        elif ch.isalpha():
            if ch in vowels:
                has_vowel = True
            else:
                has_consonant = True
        else:               # 只要出现非字母数字字符，立即不合法
            return False

        # 已经全部满足时可以提前结束循环（可选优化）
        if has_vowel and has_consonant and has_digit:
            # 仍需检查后面的字符是否全是合法的
            continue

    return has_vowel and has_consonant and has_digit
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  解释：只遍历一次字符串。相比暴力解省掉了第二遍遍历的常数因子，实际运行更快。  
  大白话：不管单词有多少字符，程序只看一遍。

- **空间复杂度**：`O(1)`  
  解释：同样只用了几个布尔变量和一个固定大小的集合。  
  大白话：占用的额外内存和单词长度无关。

## 心得

- **核心技巧**：一次遍历同步记录多个状态（元音、辅音、数字、合法字符）。  
- **适用的题型**：  
  1. 判断密码强度（需要大写字母、小写字母、数字、特殊字符等）。  
  2. 检查电话号码合法性（数字、区号、分隔符）。  
  3. 验证身份证号/学号格式（长度、数字、字母组合）。  
- **解题钥匙**：**“一次遍历，状态位”**——只要能在遍历中把所有需要的信息收集完，就不必再额外扫描。

## 反思

- **第一反应**：先把每条规则写成单独的 `if`，然后逐个检查。  
- **最容易踩的坑**：  
  - 忘记检查 **非法字符**（如 `@ # $`），导致错误通过。  
  - 把 **元音/辅音** 的判断写成只检查小写，忽略了大写字母。  
  - 对长度的判断写成 `<= 3`，导致恰好 3 个字符的合法单词被误判。  
- **下次思路**：一看到“需要同时满足多条字符属性”时，第一步就想到 **一次遍历 + 多标记**，再根据需求决定是否提前返回。
