Return the number of partitions where the difference between the sum of the left and right subarrays is even.

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是把每一个可能的分割点 `i`（`0 ≤ i < n‑1`）都枚举一遍，  
计算左边子数组 `nums[0…i]` 的和 `left_sum`，以及右边子数组 `nums[i+1…n‑1]` 的和 `right_sum`，  
判断两者的差 `left_sum - right_sum` 是否为偶数。  

- **用到的数据结构**：  
  - **数组**：存放原始数字。  
  - **前缀和**（Prefix Sum）可以类比成“累计的账本”，我们在遍历时把已经看到的数字的总和记下来，后面再需要左边子数组的和时，直接查账本就能得到，省去重新求和的时间。  

- **为什么正确**：  
  - 对每一个合法的分割点，都明确算出左、右两段的和，只有当差值是偶数时计数。遍历完所有 `i`，计数的总和即为答案。  

- **时间/空间复杂度**：  
  - **时间**：我们要遍历 `n‑1` 个分割点，每个点如果不使用前缀和，需要再遍历一次子数组求和，最坏会出现 `1 + 2 + … + (n‑1) ≈ n²/2` 次加法。用大白话说，就是 **“大约要算 n 的平方次”**，记作 `O(n²)`。  
  - **空间**：只用了常数个额外变量（如 `left_sum、right_sum`），所以是 `O(1)`，即 **“几乎不占额外空间”**。  

#### 代码（Python）  

```python
def countPartitions_bruteforce(nums):
    n = len(nums)
    ans = 0                       # 计数器，记录满足条件的分割点个数
    # i 表示左子数组的最后一个下标，右子数组从 i+1 开始
    for i in range(n - 1):
        left_sum = 0
        # 计算左子数组的和
        for j in range(i + 1):
            left_sum += nums[j]   # 累加左边的元素
        right_sum = 0
        # 计算右子数组的和
        for j in range(i + 1, n):
            right_sum += nums[j]  # 累加右边的元素
        # 判断差值是否为偶数
        if (left_sum - right_sum) % 2 == 0:
            ans += 1
    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n²)` —— 需要两层循环，外层 `n‑1` 次，内层累计求和，整体大约是 `n` 的平方次数。  
- **空间复杂度**：`O(1)` —— 只使用了若干整数变量，没有额外的数组或列表。

### 2. 最优解  

#### 思路  

从暴力解可以看到，**瓶颈**在于每次分割都要重新求左、右两段的和。  
其实我们只需要 **一次**遍历就能判断所有分割点是否满足条件，关键在于**奇偶性**（parity）的性质：

1. 设 `L` 为左子数组和，`R` 为右子数组和。  
2. `L - R` 为偶数 ⇔ `L` 与 `R` 同奇同偶（因为偶数减偶数、奇数减奇数都是偶数）。  
3. `L + R` 就是整个数组的总和 `S`。  
4. 若 `S` 为 **奇数**，则不管 `L`、`R` 怎么分配，必有一种奇偶不同，`L - R` 永远是奇数，**没有合法分割**。  
5. 若 `S` 为 **偶数**，则 `L` 与 `R` 必然同奇同偶（因为 `L = S - R`，偶数减奇数得到奇数，偶数减偶数得到偶数，只有两者奇偶相同才能让结果仍为偶数），**所有分割点都合法**。

因此答案只取决于总和的奇偶性：

- `S` 为偶数 → 有 `n-1` 种分割（每个位置都可以）。  
- `S` 为奇数 → 0 种分割。

只需要一次遍历求总和，时间 `O(n)`，空间 `O(1)`。

> **类比**：把整个数组看成一本书，总页数是 `S`。如果总页数是偶数，那么把书在任意位置折开，左边和右边的页数奇偶必然相同；如果总页数是奇数，则不管怎么折，左、右页数的奇偶必然不同，无法得到“差是偶数”。  

#### 代码（Python）  

```python
def countPartitions(nums):
    """
    返回满足左、右子数组和差为偶数的分割点个数。
    思路：只看整个数组的和的奇偶性。
    """
    total = sum(nums)          # 一次遍历求总和
    n = len(nums)
    # 总和为偶数时，每个分割点都合法；奇数时没有合法分割点
    return n - 1 if total % 2 == 0 else 0
```

#### 复杂度  

- **时间复杂度**：`O(n)` —— 只遍历一次数组求总和。相比暴力的 `O(n²)`，速度提升了 **“从平方级下降到线性级”**。  
- **空间复杂度**：`O(1)` —— 只用了几个整数变量，不随输入规模增长。

## 心得  

- **核心技巧**：利用**奇偶性**（parity）进行**全局判断**，把看似需要逐个检查的局部问题转化为只看整体属性的全局问题。  
- **适用的题型**：  
  1. “数组分割后两段的和满足某种奇偶关系”——如本题。  
  2. “把数组分成两部分，使两部分的乘积/和为偶数”——同样可以先判断整体奇偶性。  
  3. “判断是否可以把数组划分成若干子段，每段和为偶数”——先看总和是否为偶数，再决定是否可能。  
- **一句话总结解题钥匙**：**“先看总和的奇偶，奇数全无，偶数全部”。**  

## 反思  

- **第一反应**：看到“左子数组和与右子数组和的差要是偶数”，本能想到逐个分割点计算，两段求和后取模。  
- **最容易踩的坑**：忘记 **“两个数差为偶数 ⇔ 两数奇偶相同”**，导致写出复杂的枚举代码而不是利用整体奇偶性简化。  
- **下次遇到同类题**：第一步先 **“考虑整个数组的总和奇偶性”**，看是否可以直接推出所有分割点都合法或全不合法，再决定是否需要更细致的遍历。
