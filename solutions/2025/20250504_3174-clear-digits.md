# #3174. 清除数字 / Clear Digits

> 难度：简单 · 标签：String、Stack、Simulation · [LeetCode 链接](https://leetcode.com/problems/clear-digits/)

---

## 题目（英文原版）

**Description**

You are given a string s.
Your task is to remove all digits by doing this operation repeatedly:
Return the resulting string after removing all digits.
Note that the operation cannot be performed on a digit that does not have any non-digit character to its left.

**Examples**

**Example 1:**

```
Input: s = "abc"
Output: "abc"
Explanation:
There is no digit in the string.
```

**Example 2:**

```
Input: s = "cb34"
Output: ""
Explanation:
First, we apply the operation on s[2] , and s becomes "c4" .
Then we apply the operation on s[1] , and s becomes "" .
```

**Constraints**

- 1 <= s.length <= 100
- s consists only of lowercase English letters and digits.
- The input is generated such that it is possible to delete all digits.

## 题目（中文翻译）

**描述**  
给定一个字符串 `s`。  
你需要通过重复以下操作来移除所有数字（digit）：

- 选择一个数字（digit），且它左侧恰好有一个非数字字符（non-digit character），
- 同时删除该数字以及它左侧的那个非数字字符。

当不存在满足条件的数字时停止操作。返回所有数字被移除后得到的字符串。  
注意，若某个数字左侧没有任何非数字字符，则无法对其执行上述操作。

**示例**  

*示例 1*  
```text
Input: s = "abc"
Output: "abc"
Explanation:
字符串中不存在数字（digit），因此无需进行任何操作。
```

*示例 2*  
```text
Input: s = "cb34"
Output: ""
Explanation:
首先，对下标为 2 的数字 `3` 执行操作，字符串变为 "c4"。  
随后，对下标为 1 的数字 `4` 再次执行操作，字符串变为空字符串 ""。
```

**约束条件**  

- `1 <= s.length <= 100`
- `s` 仅由小写英文字母和数字组成。
- 输入保证可以通过上述操作删除所有数字。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**不停地遍历整条字符串**，每次找到一个满足条件的数字，就把它和它左边最近的字母一起删除。  
可以把字符串想象成一行纸条，用 **列表** 来保存每个字符。  
- 当我们看到一个数字 `d`，往左找第一个仍在列表里的字母 `c`（左边可能已经被删除了），把 `c` 和 `d` 同时移除。  
- 这一步相当于“把纸条上对应的两个字符撕掉”。  
- 重复上述过程，直到字符串里不再出现数字为止。

> **为什么能得到正确答案？**  
> 题目规定每次只能把数字和左边最近的字母一起删掉，而我们每次都严格按照这个规则操作，且循环直到没有数字为止——这正是题目要求的全部过程。

> **时间/空间分析**  
> - 每次删除都要**从左到右遍历**一次来寻找最近的字母，最坏情况下会遍历 `n` 次，而最多会进行 `n/2` 次删除（每次删掉 2 个字符），所以时间复杂度是 `O(n²)`。  
> - 我们用一个列表保存字符，最多存 `n` 个字符，空间复杂度是 `O(n)`。

#### 代码（Python）

```python
def clearDigits_bruteforce(s: str) -> str:
    # 把字符串转成列表，方便删除操作
    chars = list(s)

    # 只要列表里还有数字，就继续循环
    while any(ch.isdigit() for ch in chars):
        i = 0
        # 从左到右找第一个满足条件的数字
        while i < len(chars):
            if chars[i].isdigit():
                # 向左找最近的字母
                j = i - 1
                while j >= 0 and not chars[j].isalpha():
                    j -= 1
                # 必然能找到（题目保证），删除字母和数字
                del chars[j]      # 删除左侧字母
                del chars[i-1]    # 删除原来的数字（因为左侧已被删，索引左移1）
                break             # 删除一次后重新检查整个列表
            i += 1

    # 剩下的都是字母，合并成字符串返回
    return ''.join(chars)
```

#### 复杂度  

- **时间复杂度**：`O(n²)` — 想象一下你每次都要从头数到第 `i` 个位置，`i` 会从 1 增长到 `n`，所以总共要数 `1 + 2 + … + n ≈ n²/2` 次。  
- **空间复杂度**：`O(n)` – 需要一个和原字符串等长的列表来存放字符。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**每次都要重新遍历**寻找左侧的字母。  
其实我们可以**一次遍历**就把“左侧最近的字母”记录下来——这正是**栈**（后进先出）的用武之地。

- **栈**可以想象成一本“待删除的字母本子”。  
- 当我们遇到 **字母** 时，把它压入栈，表示它目前还没有被删除。  
- 当我们遇到 **数字** 时，按照题目要求必须把它左侧最近的字母一起删掉。栈顶正好就是最近的未被删除的字母，于是 **弹出栈顶**（相当于把这两个字符一起撕掉），数字本身不需要保存。  

遍历完所有字符后，栈中剩下的就是**永远不会被删除的字母**，按顺序拼成结果即可。

> **为什么只需要一次遍历就能完成？**  
> 栈始终维护了“当前左侧最近的未删除字母”。每当出现数字时，直接弹出栈顶即可，无需再回头查找。

> **核心数据结构：栈**  
> - **栈**就像一本只允许在最上面添加或移除纸条的笔记本，最新加入的纸条总是最先被取走。  
> - 这里的“纸条”是字母，数字只负责触发一次弹出操作。

#### 代码（Python）

```python
def clearDigits(s: str) -> str:
    stack = []                     # 用列表模拟栈，存放未被删除的字母

    for ch in s:                   # 从左到右一次遍历
        if ch.isalpha():           # 如果是字母，压入栈顶
            stack.append(ch)
        else:                      # ch 是数字
            # 根据题目保证，栈里一定有左侧最近的字母
            if stack:               # 防御性写法，实际不会为空
                stack.pop()        # 弹出左侧最近的字母，数字本身不保存

    # 栈中剩下的都是最终保留下来的字母，按顺序拼接成字符串
    return ''.join(stack)
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 只遍历一次字符串，每个字符最多压栈或弹栈一次，类似于一次“数数”而不是“来回数”。  
- **空间复杂度**：`O(n)` – 最坏情况下（全是字母）栈会保存所有字符，需要 `n` 的空间。

## 心得

- **核心技巧**：利用栈一次遍历实现“左侧最近未删除字符”的快速定位。  
- **适用题型**：  
  1. **配对删除**（如 “删除相邻相同字符”）  
  2. **括号匹配**（判断合法括号序列）  
  3. **简化路径**（Unix 风格路径简化）  
- **解题钥匙**：把“左侧最近的未删除字符”抽象成栈顶，遇到需要删除的字符时直接弹栈。

## 反思

- **第一反应**：看到“左侧最近的字母”会想到“往左找”，于是想到循环搜索——这就是暴力思路。  
- **最容易踩的坑**：  
  - 忘记题目保证每个数字左边一定有未被删除的字母，导致在实现时出现空栈弹出错误。  
  - 处理完所有字符后忘记把栈中的字母拼回字符串。  
- **下次遇到同类题**：第一步想到“用栈维护最近的候选元素”，再根据题目规则决定是压入还是弹出。这样往往可以把 `O(n²)` 降到 `O(n)`。
