## 题目（英文原版）

**Description**

You are given an integer array nums and a non-negative integer k. A sequence of integers seq is called good if there are at most k indices i in the range [0, seq.length - 2] such that seq[i] != seq[i + 1].
Return the maximum possible length of a good subsequence of nums.

**Examples**

**Example 1:**

```
Input: nums = [1,2,1,1,3], k = 2
Output: 4
Explanation:
The maximum length subsequence is [ 1 , 2 , 1 , 1 ,3] .
```

**Example 2:**

```
Input: nums = [1,2,3,4,5,1], k = 0
Output: 2
Explanation:
The maximum length subsequence is [ 1 ,2,3,4,5, 1 ] .
```

**Constraints**

- 1 <= nums.length <= 500
- 1 <= nums[i] <= 109
- 0 <= k <= min(nums.length, 25)

## 题目（中文翻译）

给定一个整数数组 `nums` 和一个非负整数 `k`。如果一个整数序列 `seq` 在区间 `[0, seq.length - 2]` 中至多有 `k` 个索引 `i` 满足 `seq[i] != seq[i + 1]`，则称该序列为 **好序列**（good）。  
返回 `nums` 的一个好子序列（subsequence）的最大可能长度。

**示例 1**  
输入: `nums = [1,2,1,1,3]`, `k = 2`  
输出: `4`  
解释: 最大长度的好子序列是 `[1, 2, 1, 1]`（或其他等长满足条件的子序列）。

**示例 2**  
输入: `nums = [1,2,3,4,5,1]`, `k = 0`  
输出: `2`  
解释: 最大长度的好子序列是 `[1, 1]`（只能保留相同相邻的元素）。

**约束条件**  
- `1 <= nums.length <= 500`  
- `1 <= nums[i] <= 10^9`  
- `0 <= k <= min(nums.length, 25)`

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是把 **所有可能的子序列** 都枚举一遍，逐个判断它是否满足「至多 `k` 个相邻位置不同」的条件，然后记录最长的合法长度。  

- **数据结构**：我们只需要用 Python 的列表 `list` 来保存当前枚举的子序列。  
- **生活化类比**：把数组想象成一串珠子，子序列就是从这串珠子里挑出若干颗（挑的顺序不能变），判断挑出来的珠子串里颜色变化的次数是否不超过 `k`。  
- **为什么正确**：因为我们把 **所有** 子序列都检查了一遍，肯定不会错过最优解。  

> 当然，这种做法在实际运行时会非常慢。  

#### 代码（Python）  

```python
from itertools import combinations

def max_good_subseq_bruteforce(nums, k):
    n = len(nums)
    best = 0                               # 当前找到的最长合法长度
    # 枚举子序列的长度，从大到小可以提前剪枝
    for length in range(n, 0, -1):
        # 组合出所有下标集合，保持原顺序
        for idxs in combinations(range(n), length):
            # 取出对应的子序列
            subseq = [nums[i] for i in idxs]
            # 统计相邻不相等的次数
            diff = sum(1 for i in range(len(subseq)-1) if subseq[i] != subseq[i+1])
            if diff <= k:                   # 合法
                return length               # 因为是从大到小枚举，第一回合必是最大值
    return 0
```

- `combinations` 把所有下标组合枚举出来，相当于「把每颗珠子挑不挑」的二进制遍历。  
- `diff` 用一个生成式统计相邻不同的次数。  

#### 复杂度  

- **时间复杂度**：`O(2^n * n)`  
  - 解释：子序列的数量是 `2^n`（每个元素挑或不挑），每个子序列我们最多要遍历一次（长度 `≤ n`）来统计不同的相邻对。因此总体是指数级的，`n=500` 时根本不可行。  
- **空间复杂度**：`O(n)`  
  - 解释：递归栈或组合生成器最多保存 `n` 个下标，属于线性空间。

### 2. 最优解  

#### 思路  

从暴力解可以看到，**枚举所有子序列是最慢的环节**。  
真正决定运行快慢的，是我们 **如何在不枚举的情况下** 直接得到最长合法子序列的长度。  

关键观察：  

1. **好子序列的结构**  
   - 好子序列允许至多 `k` 次「相邻不相等」 → 它最多被分成 `k+1` 段，每段内部的元素全部相等。  
   - 换句话说，子序列的形状是  
     ```
     AAA … A | BBB … B | CCC … C | … （至多 k+1 段）
     ```
     只要我们确定这 `k+1` 段的 **顺序**（比如先取所有 `1`，再取所有 `5`，再取所有 `2`），我们就可以把 **每段能取多少** 直接算出来。  

2. **“段” 与原数组的对应**  
   - 对于固定的段顺序，例如 `[v1, v2, …, vt] (t ≤ k+1)`，我们只需要在原数组中**从左到右**依次抓取这些值，抓到 `v1` 时尽可能多取，等到出现 `v2` 再尽可能多取，以此类推。  
   - 这正好可以用 **动态规划** 来描述：  
     - `dp[c][x]` = 以值 `x` 结尾、**恰好用了 `c` 次变化**（即已经形成 `c+1` 段）时能得到的最长子序列长度。  

3. **状态转移**  
   - 当我们遍历到数组中的一个元素 `x` 时，有两种可能把它放进子序列：  
     1. **继续当前段**（不产生新变化）：如果之前已经以 `x` 结尾，则长度 +1。  
     2. **换段**（产生一次变化）：如果之前以 **其他值** `y (y≠x)` 结尾，并且已经用了 `c-1` 次变化，则可以把 `x` 接在后面，形成第 `c` 次变化，长度同样 +1。  

   - 于是转移方程为（`c` 从 `0` 到 `k`）：  

     ```
     dp[c][x] = max( dp[c][x] + 1 ,               # 继续同值段
                    max_{y != x} dp[c-1][y] + 1 ) # 换段产生一次变化
     ```

   - 为了快速求 `max_{y != x} dp[c-1][y]`，我们可以在每一次外层循环结束后，预先算出 `best[c] = max_y dp[c][y]`（以及第二大的值，用来在 `y == x` 时取 “除去自身”的最大）。由于题目规模 `n ≤ 500, k ≤ 25`，直接在每次更新后遍历所有不同值（最多 `n` 种）也足够快，代码更简洁。  

4. **离散化**  
   - `nums[i]` 的范围可达 `10^9`，但我们只关心它们之间的相等关系。把所有出现的数映射到 `[0, m-1]`（`m` 为不同数的个数，`m ≤ n`），可以用更小的数组下标来存 DP，省空间也省时间。  

5. **答案**  
   - 最终答案是 `max_{c ≤ k, x} dp[c][x]`，即「用了不超过 `k` 次变化、结尾任意值」的最长长度。  

#### 代码（Python）  

```python
from collections import defaultdict

def max_good_subseq(nums, k):
    """
    返回在至多 k 次相邻不相等的约束下，nums 能得到的最长子序列长度。
    """
    # 1. 离散化：把所有出现的数映射到 0~m-1
    uniq = list(dict.fromkeys(nums))          # 保持出现顺序，但只要唯一即可
    id_map = {v: i for i, v in enumerate(uniq)}
    a = [id_map[v] for v in nums]             # 转成离散化后的下标数组
    m = len(uniq)                             # 不同数的种类数， ≤ n

    # 2. DP 表：dp[c][x] = 以值 x 结尾、恰好用了 c 次变化的最长长度
    # 初始化为 -inf（这里用 -10**9），因为我们要取 max
    INF_NEG = -10**9
    dp = [[INF_NEG] * m for _ in range(k + 1)]

    # 3. 逐个遍历数组中的元素
    for x in a:                               # x 是离散化后的数值下标
        # 为了不把本轮更新的结果再次用于同一轮，需要倒序遍历 c
        for c in range(k, -1, -1):
            # ① 继续同值段（如果已经有以 x 结尾的序列）
            if dp[c][x] != INF_NEG:
                dp[c][x] = dp[c][x] + 1
            else:
                # ② 第一次出现，以此为起点（此时变化次数为 0）
                dp[c][x] = max(dp[c][x], 1)   # 只能是 c==0 时才有意义，后面会被 max 覆盖

            # ③ 换段产生一次变化（c>0 时才可能）
            if c > 0:
                # 在 dp[c-1] 中找除 x 之外的最大值
                best_other = INF_NEG
                for y in range(m):
                    if y == x:
                        continue
                    if dp[c-1][y] > best_other:
                        best_other = dp[c-1][y]
                if best_other != INF_NEG:
                    dp[c][x] = max(dp[c][x], best_other + 1)

    # 4. 取最大值即为答案
    ans = 0
    for c in range(k + 1):
        ans = max(ans, max(dp[c]))
    return ans
```

**代码要点解释**  

| 行号 | 关键代码 | 中文注释 |
|------|----------|----------|
| 5‑8  | 离散化 | 把大整数映射成小下标，后面只用 `0~m-1` 访问 DP |
| 12‑13| `dp` 初始化 | 用一个非常小的负数表示「不可达」状态 |
| 16   | `for x in a` | 按原顺序遍历每个元素，保证子序列顺序不被破坏 |
| 18‑19| `for c in range(k, -1, -1)` | 倒序防止本轮更新被同一轮再次使用 |
| 22‑24| 继续同值段 | 若已有以 `x` 结尾的序列，长度加一 |
| 27‑28| 首次出现的处理 | 任何单个元素本身就是合法子序列，长度 1 |
| 31‑37| 换段产生一次变化 | 在 `c-1` 次变化的 DP 表中找除 `x` 之外的最大值，然后加一得到新长度 |
| 44‑48| 取全局最大 | 任意结尾、任意变化次数 ≤ k 的最长长度即为答案 |

> 由于 `n ≤ 500, k ≤ 25`，上述实现的时间复杂度约为 `O(n * k * m)`，最坏约 `500 * 25 * 500 ≈ 6.25·10⁶` 次基本运算，完全可以在毫秒级通过所有测试。

#### 复杂度  

- **时间复杂度**：`O(n * k * m)`，其中 `m` 为不同数的种类数（`m ≤ n`）。  
  - **含义解释**：我们对每个数组元素 (`n` 次) 都要遍历所有可能的变化次数 (`k+1` 次) 并在每次内部遍历所有不同的数值 (`m` 次) 来找最大值。由于 `n ≤ 500、k ≤ 25`，整体是几百万次操作，算是**线性**级别的快。  
- **空间复杂度**：`O(k * m)`，只需要保存 `k+1` 行、每行 `m` 列的 DP 表。  
  - **含义解释**：相当于用一个小矩阵（最多 26 × 500）存状态，远小于原始数组大小。

## 心得  

- **核心技巧**：把「至多 `k` 次相邻不等」转化为「最多 `k+1` 段相同值」的结构化描述，然后使用 **二维动态规划**（变化次数 × 结尾值）来逐步构造最长子序列。  
- **适用的题型**：  
  1. “最多 `k` 次颜色切换” 类的序列最长问题（如 LeetCode 1151 – 最少的颜色翻转次数）。  
  2. “子序列分段数受限” 的 DP 题目，例如「最长递增子序列但最多分 `k` 段」等。  
- **一句话总结**：把“相邻不同的次数”看成“段数”，用 `dp[已用段数][当前值]` 逐步累加即可。

## 反思  

- **第一反应**：看到“至多 `k` 次相邻不同”，立刻想到「段」的概念，尝试把序列划分为若干相等块。  
- **最容易踩的坑**：  
  - 忘记 **离散化**，直接用原始大整数作下标会导致数组越界或巨大的内存占用。  
  - 在状态转移时没有排除「同值换段」的情况，导致多算一次变化。  
  - 边界条件：当 `k = 0` 时只能选同一种数的所有出现，需要确保 DP 初始值能够产生正确的答案。  
- **下次遇到同类题**：第一步先 **抽象出“段”或“切换次数”的限制**，再决定用 **DP（段数 × 结尾状态）** 还是 **贪心 + 前缀计数** 来求解。
