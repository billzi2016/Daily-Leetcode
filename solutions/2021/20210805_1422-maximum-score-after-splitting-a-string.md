# #1422. 拆分字符串后的最大得分 / Maximum Score After Splitting a String

> 难度：简单 · 标签：String、Prefix Sum · [LeetCode 链接](https://leetcode.com/problems/maximum-score-after-splitting-a-string/)

---

## 题目（英文原版）

**Description**

Given a string s of zeros and ones, return the maximum score after splitting the string into two non-empty substrings (i.e. left substring and right substring).
The score after splitting a string is the number of zeros in the left substring plus the number of ones in the right substring.

**Examples**

**Example 1:**

```
Input: s = "011101"
Output: 5 
Explanation: 
All possible ways of splitting s into two non-empty substrings are:
left = "0" and right = "11101", score = 1 + 4 = 5 
left = "01" and right = "1101", score = 1 + 3 = 4 
left = "011" and right = "101", score = 1 + 2 = 3 
left = "0111" and right = "01", score = 1 + 1 = 2 
left = "01110" and right = "1", score = 2 + 1 = 3
```

**Example 2:**

```
Input: s = "00111"
Output: 5
Explanation: When left = "00" and right = "111", we get the maximum score = 2 + 3 = 5
```

**Example 3:**

```
Input: s = "1111"
Output: 3
```

**Constraints**

- 2 <= s.length <= 500
- The string s consists of characters '0' and '1' only.

## 题目（中文翻译）

给定一个仅包含字符 `'0'` 和 `'1'` 的字符串 `s`，将其划分为两个非空子字符串（即左子串（left substring）和右子串（right substring）），返回能够得到的最大得分。  
划分后的得分定义为：左子串中 `'0'` 的个数 加上 右子串中 `'1'` 的个数。

**示例 1**  
输入: `s = "011101"`  
输出: `5`  
解释:  
所有可能的划分方式如下：  
- left = `"0"`，right = `"11101"`，得分 = 1 + 4 = 5  
- left = `"01"`，right = `"1101"`，得分 = 1 + 3 = 4  
- left = `"011"`，right = `"101"`，得分 = 1 + 2 = 3  
- left = `"0111"`，right = `"01"`，得分 = 1 + 1 = 2  
- left = `"01110"`，right = `"1"`，得分 = 2 + 1 = 3  

**示例 2**  
输入: `s = "00111"`  
输出: `5`  
解释: 当 left = `"00"`，right = `"111"` 时，得到的最大得分为 2 + 3 = 5  

**示例 3**  
输入: `s = "1111"`  
输出: `3`  

**约束条件**  
- `2 <= s.length <= 500`  
- 字符串 `s` 仅由字符 `'0'` 和 `'1'` 组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把字符串的每一个可能的切分点都试一遍，算出对应的 **得分**，取最大的即可。  
- **切分点**：在下标 `i`（`1 ≤ i < len(s)`）的位置把字符串分成左子串 `s[:i]` 和右子串 `s[i:]`。  
- **得分** = 左子串中 `0` 的个数  +  右子串中 `1` 的个数。  

这里我们需要的两个数据结构非常简单：  
- **计数器**（`int` 变量）用来统计左边出现了多少个 `0`。  
- **计数器**（`int` 变量）用来统计右边出现了多少个 `1`。  

可以把 “数 `0` 的过程” 想象成在厨房里数盘子里有多少空碗，数 `1` 的过程则像在书架上数有多少本书。只要遍历一次，就能得到每个切分点的分数。

**为什么这个方法一定能得到正确答案？**  
因为我们把所有合法的切分方式都枚举了一遍，最大分数必然在其中。

**时间/空间复杂度**  
- **时间复杂度**：我们需要遍历所有切分点（`n-1` 个）并且对每一次都重新统计左边的 `0` 与右边的 `1`。最笨的实现是每次都重新遍历左子串和右子串，导致 `O(n²)`。  
  - `O(n²)` 可以理解为“如果 n 是 100，程序大概要跑 10,000 次基本操作”。  
- **空间复杂度**：只用了几个计数器，`O(1)`（常数级别的额外空间）。

#### 代码（Python）

```python
def maxScore_brute(s: str) -> int:
    n = len(s)
    best = 0                         # 保存当前找到的最大得分
    # i 为切分点左侧子串的长度，必须保证两边都非空
    for i in range(1, n):
        left = s[:i]                  # 左子串
        right = s[i:]                 # 右子串

        # 统计左子串中 0 的个数
        zeros = 0
        for ch in left:
            if ch == '0':
                zeros += 1

        # 统计右子串中 1 的个数
        ones = 0
        for ch in right:
            if ch == '1':
                ones += 1

        score = zeros + ones          # 当前切分的得分
        best = max(best, score)       # 更新最大得分
    return best
```

#### 复杂度

- **时间复杂度**：`O(n²)` — 对每个切分点都要遍历一次左子串和一次右子串，整体操作次数约等于 `n * n/2`，随 `n` 的平方增长。  
- **空间复杂度**：`O(1)` — 只用了常数个整数变量。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈** 出在每次切分都要重新遍历子串来统计 `0` 与 `1`。其实我们可以在一次遍历中把这些统计信息**预先算好**，随后每次切分只做 **O(1)** 的查表操作。

关键点如下：

1. **前缀和（Prefix Sum）**  
   - 把字符串里出现的 `1` 的累计数量存进一个数组 `pref_one[i]`，表示 **从左边开始到下标 i（不含 i）** 的 `1` 的个数。  
   - 类比：就像在一本厚厚的电话簿里，每翻一页就记录下已经看到的电话号码总数，这样以后想知道前几页有多少号码，只需要直接看对应的记录，不用重新数一遍。

2. **遍历一次求左侧的 `0`**  
   - 从左到右移动切分点，同时维护一个计数器 `zeros`，它记录当前左子串（已经遍历过的部分）里 `0` 的个数。  
   - 当切分点位于下标 `i`（`1 ≤ i < n`）时，左子串是 `s[:i]`，右子串是 `s[i:]`。  
   - 右子串中 `1` 的个数可以通过前缀和快速得到：`total_ones - pref_one[i]`，其中 `total_ones = pref_one[n]`（整个字符串的 `1` 总数）。

3. **实时更新答案**  
   - 对每个合法切分点，计算 `score = zeros + (total_ones - pref_one[i])`，并保持最大值。

这样，**所有切分点的得分只用 O(1) 时间计算**，整体只遍历两遍字符串，时间降到 `O(n)`，空间降到 `O(n)`（前缀和数组），甚至可以把前缀和压缩成一个整数，达到 `O(1)` 空间（这里为了易懂仍保留前缀和数组）。

#### 代码（Python）

```python
def maxScore(s: str) -> int:
    n = len(s)

    # 1) 预计算前缀和：pref_one[i] = s[:i] 中 '1' 的数量
    pref_one = [0] * (n + 1)          # 多一个位置，方便直接使用 pref_one[i]
    for i in range(n):
        pref_one[i + 1] = pref_one[i] + (s[i] == '1')   # 如果是 '1'，累计 +1

    total_ones = pref_one[n]          # 整个字符串里 '1' 的总数

    zeros = 0                         # 左子串中已经出现的 '0' 的计数
    best = 0

    # 2) 从左到右尝试每一个切分点（切分点必须在 1..n-1）
    for i in range(1, n):            # i 为左子串的长度
        if s[i - 1] == '0':          # 新加入的字符属于左子串
            zeros += 1

        # 右子串中 '1' 的数量 = 总的 '1' 减去左子串已经包含的 '1'
        ones_right = total_ones - pref_one[i]

        score = zeros + ones_right   # 当前切分的得分
        best = max(best, score)      # 维护最大得分

    return best
```

> **代码解释**  
> - 第 5 行创建前缀和数组，长度为 `n+1`，第 `i` 位存的是前 `i` 个字符里 `1` 的数量。  
> - 第 9 行 `pref_one[i + 1] = pref_one[i] + (s[i] == '1')` 中 `(s[i] == '1')` 的结果是布尔值 `True/False`，在算术运算时会自动转成 `1/0`，相当于“如果是 1 就加 1”。  
> - 循环第 14 行 `if s[i-1] == '0': zeros += 1` 用来实时更新左侧 `0` 的计数。  
> - `ones_right = total_ones - pref_one[i]` 把右侧 `1` 的数量直接算出来，避免再次遍历。  

#### 复杂度

- **时间复杂度**：`O(n)` — 只遍历了两遍字符串（一次构前缀和，一次遍历切分点），每一步都是常数时间操作。  
  - 对比暴力的 `O(n²)`，如果 `n=500`，暴力需要约 250,000 次基本操作，而最优解只需要约 1,000 次，快了好几百倍。  
- **空间复杂度**：`O(n)` — 前缀和数组占用了 `n+1` 个整数。若把前缀和压缩成一个变量，也可以做到 `O(1)`，但这里保留数组更易于理解。

## 心得

- **核心技巧**：利用前缀和把区间统计从 **重复遍历** 降到 **常数时间查询**。  
- **适用的题型**  
  1. “子数组/子串的最大/最小和” 类题（如 LeetCode 53 最大子数组和的前缀和思路）。  
  2. “区间统计” 题目（如统计区间内的奇数个数、字母出现次数等）。  
  3. “分割字符串/数组后求和最大化” 的变体（如《分割数组的最大和》）。  
- **一句话总结**：**“先把全局信息预先算好，后面每次只用 O(1) 查表”。**

## 反思

- **第一反应**：看到“把字符串切成两段，左边算 0，右边算 1”，自然想到遍历每个切分点并直接统计。  
- **最容易踩的坑**  
  - **切分点必须保证两边非空**，所以循环的下标范围是 `1 … n-1`，而不是 `0 … n`。  
  - **统计右侧 1 的方式**：如果只算左侧的 0 而忘记右侧的 1，得分会不完整。  
  - **字符比较时的等号**：要记得使用字符串 `'0'`、`'1'`，而不是整数 `0、1`。  
- **下次遇到同类题**：第一步想到“**前缀和**”或“**累计计数**”，把需要重复计算的量一次性准备好，再在遍历过程中快速查询。
