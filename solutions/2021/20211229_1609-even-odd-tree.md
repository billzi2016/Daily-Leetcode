# #1609. 奇偶树 / Even Odd Tree

## 题目（英文原版）

**Description**

A binary tree is named Even-Odd if it meets the following conditions:
Given the root of a binary tree, return true if the binary tree is Even-Odd, otherwise return false.

**Examples**

**Example 1:**

```
Input: root = [1,10,4,3,null,7,9,12,8,6,null,null,2]
Output: true
Explanation: The node values on each level are:
Level 0: [1]
Level 1: [10,4]
Level 2: [3,7,9]
Level 3: [12,8,6,2]
Since levels 0 and 2 are all odd and increasing and levels 1 and 3 are all even and decreasing, the tree is Even-Odd.
```

**Example 2:**

```
Input: root = [5,4,2,3,3,7]
Output: false
Explanation: The node values on each level are:
Level 0: [5]
Level 1: [4,2]
Level 2: [3,3,7]
Node values in level 2 must be in strictly increasing order, so the tree is not Even-Odd.
```

**Example 3:**

```
Input: root = [5,9,1,3,5,7]
Output: false
Explanation: Node values in the level 1 should be even integers.
```

**Constraints**

- The number of nodes in the tree is in the range [1, 105].
- 1 <= Node.val <= 106

## 题目（中文翻译）

给定一棵二叉树（binary tree）的根节点 `root`，如果这棵树满足 **奇偶树** 的所有条件则返回 `true`，否则返回 `false`。

**奇偶树的定义**  
- 树的根节点所在的层（Level 0）被视为第 0 层，根的子节点为第 1 层，依此类推。  
- 偶数层（第 0、2、4… 层）的所有节点值必须是 **奇数**，且这些值必须严格递增。  
- 奇数层（第 1、3、5… 层）的所有节点值必须是 **偶数**，且这些值必须严格递减。

### 示例

#### 示例 1
```
Input: root = [1,10,4,3,null,7,9,12,8,6,null,null,2]
Output: true
Explanation: 各层的节点值如下：
Level 0: [1]                     // 奇数且递增
Level 1: [10,4]                  // 偶数且递减
Level 2: [3,7,9]                 // 奇数且递增
Level 3: [12,8,6,2]              // 偶数且递减
满足所有奇偶层的要求，因此返回 true。
```

#### 示例 2
```
Input: root = [5,4,2,3,3,7]
Output: false
Explanation: 各层的节点值如下：
Level 0: [5]                     // 奇数且递增
Level 1: [4,2]                   // 偶数且递减
Level 2: [3,3,7]                 // 奇数层必须严格递增，但出现了相等的 3
因此不满足奇偶树的条件，返回 false。
```

#### 示例 3
```
Input: root = [5,9,1,3,5,7]
Output: false
Explanation: 第 1 层的节点值应为偶数，但出现了奇数 9 和 1，故不满足条件，返回 false。
```

### 约束条件
- 树中节点的数量在范围 `[1, 10^5]` 内。  
- `1 <= Node.val <= 10^6`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是 **层序遍历**（Breadth‑First Search，简称 BFS），也就是“一层一层”地把树里的节点全部访问一遍。  
我们可以把每一层的节点值放进一个列表里，然后检查该层是否满足题目要求：

- 偶数层（根所在的层记作第 0 层）只能出现 **奇数**，并且这些奇数必须 **严格递增**（后一个比前一个大）。
- 奇数层只能出现 **偶数**，并且这些偶数必须 **严格递减**（后一个比前一个小）。

> **类比**：  
> 把树想象成一本分章节的书，根节点是第 0 章的标题。我们用 **队列**（像排队买票的队伍）一次性把同一层的所有节点“叫号”出来，记录它们的值，再按照题目要求检查这章节的标题顺序是否符合规则。

**为什么正确**  
层序遍历保证我们一次只处理同一层的节点，层与层之间不会交叉。只要每层都满足奇偶性和严格单调的要求，整棵树自然就是 Even‑Odd 树。

**复杂度分析（大白话）**  
- **时间**：我们要访问树里的每一个节点一次，访问一次的时间记作 1，树有 *n* 个节点，所以总时间是 **n 次操作**，记作 `O(n)`。  
- **空间**：队列里最多同时保存同一层的所有节点。最宽的一层可能有 `n/2`（几乎一半）个节点，所以最坏情况下需要 **和树宽度成正比的空间**，记作 `O(w)`，这里 `w ≤ n`，所以也可以写成 `O(n)`。

#### 代码（Python）

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def isEvenOdd(root: TreeNode) -> bool:
    """
    暴力版：先把每层的值收集到 list 中，再统一检查奇偶性和单调性
    """
    from collections import deque

    q = deque([root])          # 队列用于层序遍历，初始只放根节点
    level = 0                  # 记录当前是第几层，根层是 0

    while q:
        level_size = len(q)    # 本层有多少节点
        cur_level_vals = []    # 用来存放本层所有节点的值

        # 依次弹出本层的所有节点，并把子节点加入队列（为下一层做准备）
        for _ in range(level_size):
            node = q.popleft()
            cur_level_vals.append(node.val)

            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)

        # ---------- 检查本层 ----------
        # 1. 奇偶性检查
        if level % 2 == 0:          # 偶数层：只能是奇数
            if any(v % 2 == 0 for v in cur_level_vals):
                return False
            # 2. 严格递增检查
            for i in range(1, len(cur_level_vals)):
                if cur_level_vals[i] <= cur_level_vals[i - 1]:
                    return False
        else:                       # 奇数层：只能是偶数
            if any(v % 2 == 1 for v in cur_level_vals):
                return False
            # 2. 严格递减检查
            for i in range(1, len(cur_level_vals)):
                if cur_level_vals[i] >= cur_level_vals[i - 1]:
                    return False

        level += 1   # 进入下一层

    return True
```

#### 复杂度

- **时间复杂度**：`O(n)` —— 每个节点恰好被访问一次，`n` 为节点总数。  
- **空间复杂度**：`O(w)`（最坏 `O(n)`）——队列里最多存放同一层的所有节点，宽度 `w` 可能接近 `n`。

### 2. 最优解

#### 思路  

从上面的暴力解可以看到，**收集整层再检查** 的过程其实可以省掉：  
在遍历每个节点的同时，**直接和前一个节点的值比较**，并立刻判断奇偶性。这样就不需要额外的 `cur_level_vals` 列表，空间可以降到只存队列本身。

**瓶颈所在**  
- 暴力解在每层结束后会遍历一次 `cur_level_vals` 来检查单调性，这是一种“二次遍历”。  
- 实际上我们只需要在遍历节点的 **同一层** 时，**记住前一个节点的值**，随手比较即可。

**核心技巧：一次遍历完成所有检查**  

1. 使用 **队列** 进行层序遍历（同前）。  
2. 进入每一层时，记录一个变量 `prev` 表示本层上一个节点的值。  
   - 对于偶数层（要求严格递增），`prev` 初始设为 `-inf`（负无穷），每次检查 `node.val > prev`。  
   - 对于奇数层（要求严格递减），`prev` 初始设为 `+inf`（正无穷），每次检查 `node.val < prev`。  
3. 同时检查奇偶性：偶数层要求奇数，奇数层要求偶数。  
4. 若任意检查不满足，立刻返回 `False`，不必继续遍历。

> **类比**：  
> 想象你在检查一本书的章节标题是否符合“递增/递减”规则，你不必先把全部标题写下来再检查，而是 **一看到标题就和上一个标题比较**，如果不符合立刻停下来。这样省时省力。

#### 代码（Python）

```python
def isEvenOdd(root: TreeNode) -> bool:
    """
    最优版：在层序遍历的过程中直接完成奇偶性和单调性检查，省去额外的列表
    """
    from collections import deque
    import math

    q = deque([root])
    level = 0

    while q:
        level_size = len(q)
        # 根据层的奇偶性设定初始的 prev
        if level % 2 == 0:          # 偶数层：要严格递增，先设成负无穷
            prev = -math.inf
        else:                       # 奇数层：要严格递减，先设成正无穷
            prev = math.inf

        for _ in range(level_size):
            node = q.popleft()
            val = node.val

            # --------- 奇偶性检查 ----------
            if level % 2 == 0:          # 偶数层只能是奇数
                if val % 2 == 0:
                    return False
                # 严格递增检查
                if val <= prev:
                    return False
            else:                       # 奇数层只能是偶数
                if val % 2 == 1:
                    return False
                # 严格递减检查
                if val >= prev:
                    return False

            prev = val                  # 更新本层的前一个值

            # 加入子节点，为下一层做准备
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)

        level += 1

    return True
```

#### 复杂度

- **时间复杂度**：`O(n)` —— 仍然只遍历每个节点一次，只是省掉了每层的二次遍历。与暴力解相比，常数因子更小。  
- **空间复杂度**：`O(w)`（最坏 `O(n)`）—— 只保留层序遍历的队列，不再额外存储每层的值列表。

## 心得

- **核心技巧**：层序遍历（BFS）配合**即时比较**（一次遍历完成奇偶性与单调性检查）。  
- **适用的题型**：  
  1. **层序条件题**（如 “检查二叉树每层是否单调递增/递减”）。  
  2. **层次遍历求最值**（如 “每层的最大值 / 最小值”）。  
  3. **层序分组问题**（如 “二叉树的锯齿形层序遍历”）。  
- **一句话总结解题钥匙**：**在遍历每层时“边走边比较”，不要等全部收集完再检查**。

## 反思

- **第一反应**：看到“层”字眼，立刻想到 BFS；随后想到要检查奇偶性和单调性。  
- **最容易踩的坑**：  
  - 忘记**严格**的比较（`>` / `<` 而不是 `>=` / `<=`），导致相等的值误判为合法。  
  - 没有正确处理根节点所在的第 0 层（偶数层）需要奇数。  
  - 边界情况：只有一个节点的树，直接返回 `True`。  
- **下次类似题的第一步**：**先确定层序遍历的框架**，然后在每层遍历的循环里**立即加入题目要求的检查**，避免额外的存储和二次遍历。
