# #1190. **翻转每对括号之间的子串** / Reverse Substrings Between Each Pair of Parentheses

> 难度：中等 · 标签：String、Stack · [LeetCode 链接](https://leetcode.com/problems/reverse-substrings-between-each-pair-of-parentheses/)

---

## 题目（英文原版）

**Description**

You are given a string s that consists of lower case English letters and brackets.
Reverse the strings in each pair of matching parentheses, starting from the innermost one.
Your result should not contain any brackets.

**Examples**

**Example 1:**

```
Input: s = "(abcd)"
Output: "dcba"
```

**Example 2:**

```
Input: s = "(u(love)i)"
Output: "iloveu"
Explanation: The substring "love" is reversed first, then the whole string is reversed.
```

**Example 3:**

```
Input: s = "(ed(et(oc))el)"
Output: "leetcode"
Explanation: First, we reverse the substring "oc", then "etco", and finally, the whole string.
```

**Constraints**

- 1 <= s.length <= 2000
- s only contains lower case English characters and parentheses.
- It is guaranteed that all parentheses are balanced.

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是 **一次只处理最里层的一对括号**，把它们之间的子串反转，然后把这对括号删掉，继续对剩下的字符串做同样的操作，直到没有括号为止。  

- **数据结构**：我们只需要一个普通的 Python 字符串（或列表），因为每次都要 **定位** 最里层的 '(' 与对应的 ')'。可以把字符串想象成一行文字，找左边最近的左括号 `(`，再往右找最近的右括号 `)`，这两者之间的内容就是“最里层”。  
- **为什么正确**：题目要求“从内到外依次反转”，而我们每次都把当前最里层的括号对处理完，就相当于模拟了题目给出的顺序。所有括号最终都会被处理，剩下的就是答案。  

**步骤**  

1. 在字符串中查找最左边的 `'('`（记作 `l`）。  
2. 从 `l` 往右找第一个 `')'`（记作 `r`），这对就是当前最里层。  
3. 把 `s[l+1:r]` 这段子串反转得到 `rev`。  
4. 用 `rev` 替换原来的 `s[l:r+1]`（包括括号），得到新的字符串。  
5. 重复 1~4，直至字符串中不再出现 `'('`。  

#### 代码（Python）  

```python
def reverseParentheses_bruteforce(s: str) -> str:
    # 将字符串转换为列表，方便原地修改（列表的切片操作更直观）
    s = list(s)
    while '(' in s:                     # 只要还有左括号，就继续
        # 1. 找最左边的 '('
        l = s.index('(')                # 第一次出现的位置
        # 2. 找它对应的最近的 ')'
        r = s.index(')', l)             # 从 l 往后找第一个 ')'
        # 3. 取出中间子串并反转
        rev = s[l+1:r][::-1]            # 切片取中间，再逆序
        # 4. 用反转后的子串替换掉包括括号的那段
        s = s[:l] + rev + s[r+1:]       # 前半段 + 反转子串 + 后半段
        # 循环结束后，最里层的括号已经被去掉
    # 最终 s 已经没有任何括号，转回字符串返回
    return ''.join(s)
```

#### 复杂度  

- **时间复杂度**：`O(n²)`  
  - 每一次循环我们都要 `index` 两次去找括号，这相当于一次线性扫描 `O(n)`。  
  - 最坏情况下会进行 `n/2` 次循环（每次去掉一对括号），于是总时间是 `O(n) * O(n) = O(n²)`。  
  - 用大白话说，就是“如果字符串长 2000，最慢要做大约 4 百万 次字符检查”。  

- **空间复杂度**：`O(n)`  
  - 我们用列表保存字符并在每次循环生成新的列表，最坏需要和原字符串同等大小的额外空间。

### 2. 最优解  

#### 思路  

暴力解的瓶颈在于 **每次都要重新扫描整个字符串去找括号**，导致时间呈二次方增长。  
我们可以一次遍历就把所有括号的匹配关系全部弄清楚，然后在遍历的过程中**直接跳转**，不必再回头查找。  

核心技巧是 **栈（stack）**：  

- 当遍历到 `'('` 时，把它的下标压入栈中，表示“等着找配对的右括号”。  
- 当遍历到 `')'` 时，弹出栈顶的左括号下标 `l`，此时 `l` 与当前下标 `r` 正好是一对匹配的括号。  
- 我们把 `l` 与 `r` 这两个位置记录下来，互相指向对方（`pair[l] = r, pair[r] = l`）。  

有了 **配对表** `pair`，我们可以 **模拟一次“来回走”**：

1. 设指针 `i = 0`，方向 `step = 1`（向右）。  
2. 当 `i` 在字符串范围内时：  
   - 如果 `s[i]` 是括号，则跳到它的配对位置 `pair[i]`，并把方向反转 `step = -step`（因为括号内部的字符需要逆序读取）。  
   - 否则，把当前字符加入答案。  
   - 最后 `i += step`，继续前进（可能是向左，也可能是向右）。  

这样只需要 **一次线性遍历**（`O(n)`）就能得到最终字符串，所有括号自然被忽略。  

**为什么这样会得到正确答案**  

- 配对表保证我们每次遇到左括号都会直接跳到对应的右括号，反之亦然。  
- 方向的翻转正好对应“在括号内部要倒着读”。比如 `"(ab)"`：  
  - 从左往右走到 `'('`，跳到对应的 `')'` 并把方向改成左移，随后会依次读取 `b`、`a`。  
- 由于所有括号都被配对，整个过程相当于 **在原字符串上做了一次“折叠 + 反转”**，恰好等价于题目要求的“先内层后外层”。  

#### 代码（Python）  

```python
def reverseParentheses_optimal(s: str) -> str:
    n = len(s)
    pair = [0] * n          # pair[i] 保存下标 i 对应的配对括号下标
    stack = []              # 用来记录左括号的下标

    # 第一步：一次遍历，建立配对表
    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)               # 左括号入栈
        elif ch == ')':
            j = stack.pop()               # 弹出匹配的左括号下标
            pair[i] = j                   # 右括号指向左括号
            pair[j] = i                   # 左括号指向右括号
        # 其他字符不做处理

    # 第二步：模拟遍历，按需要翻转方向
    res = []                # 用列表收集答案，最后再 join 成字符串
    i = 0                   # 当前指针位置
    step = 1                # 前进方向，1 表示向右，-1 表示向左
    while 0 <= i < n:
        if s[i] == '(' or s[i] == ')':
            # 碰到括号：跳到配对位置并翻转方向
            i = pair[i]
            step = -step
        else:
            # 普通字符直接加入答案
            res.append(s[i])
        i += step           # 按当前方向移动指针

    return ''.join(res)
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 第一次遍历建立配对表是线性 `O(n)`，第二次模拟遍历同样是线性 `O(n)`，没有嵌套循环。  
  - 用大白话说，“即使字符串有 2000 个字符，也只需要大约 4000 次操作”。  

- **空间复杂度**：`O(n)`  
  - 需要 `pair` 数组保存每个位置的配对下标，以及栈在最坏情况下会存放所有左括号的下标（最多 `n/2`），答案列表也需要 `O(n)` 空间。

## 心得  

- **核心技巧**：利用栈一次遍历构建括号配对表，然后在遍历时通过「跳转 + 方向翻转」一次性完成所有逆序操作。  
- **适用的题型**：  
  1. **带括号的字符串逆序**（本题）。  
  2. **表达式求值**（如中缀转后缀，利用栈处理运算符优先级）。  
  3. **匹配括号/合法括号序列**（判断括号是否匹配、求最长有效括号等）。  
- **解题钥匙**：**“把配对关系预先算好，再用一次遍历完成所有操作”。**

## 反思  

- **第一反应**：看到“括号”和“反转”，马上想到递归或不停地找最里层括号来处理。  
- **最容易踩的坑**：  
  - **忘记把括号本身从答案中剔除**，导致结果中残留 `(`、`)`。  
  - **方向翻转写反了**，比如在遇到右括号时仍然向右走，导致顺序不对。  
  - **边界条件**：空字符串、全是字符没有括号、只有一对括号等都要能正确返回。  
- **下次类似题的第一步**：**先用栈把配对信息收集完整**，再决定是递归、分治还是一次遍历完成。这样可以避免重复扫描，直接走向最优解。
