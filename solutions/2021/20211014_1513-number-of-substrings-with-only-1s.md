# #1513. 仅包含 1 的子串个数 / Number of Substrings With Only 1s

> 难度：中等 · 标签：Math、String · [LeetCode 链接](https://leetcode.com/problems/number-of-substrings-with-only-1s/)

---

## 题目（英文原版）

**Description**

Given a binary string s, return the number of substrings with all characters 1's. Since the answer may be too large, return it modulo 109 + 7.

**Examples**

**Example 1:**

```
Input: s = "0110111"
Output: 9
Explanation: There are 9 substring in total with only 1's characters.
"1" -> 5 times.
"11" -> 3 times.
"111" -> 1 time.
```

**Example 2:**

```
Input: s = "101"
Output: 2
Explanation: Substring "1" is shown 2 times in s.
```

**Example 3:**

```
Input: s = "111111"
Output: 21
Explanation: Each substring contains only 1's characters.
```

**Constraints**

- 1 <= s.length <= 105
- s[i] is either '0' or '1'.

---

## 题目（中文翻译）

给定一个二进制字符串 `s`，返回所有字符均为 `1` 的子串（substring）数量。由于答案可能非常大，请返回其对 `10^9 + 7` 取模后的结果。

**示例 1**  
**输入**: `s = "0110111"`  
**输出**: `9`  
**解释**: 总共有 9 个仅包含 `1` 的子串。  
- `"1"` 出现 5 次。  
- `"11"` 出现 3 次。  
- `"111"` 出现 1 次。

**示例 2**  
**输入**: `s = "101"`  
**输出**: `2`  
**解释**: 子串 `"1"` 在 `s` 中出现了 2 次。

**示例 3**  
**输入**: `s = "111111"`  
**输出**: `21`  
**解释**: 所有子串均只包含 `1`。

**约束条件**  
- `1 <= s.length <= 10^5`  
- `s[i]` 只能是 `'0'` 或 `'1'`。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是：枚举所有可能的子串，检查它是否只包含字符 `'1'`，如果是就计数。  

- **枚举子串**：我们可以用两层循环，外层固定子串的左边界 `i`，内层遍历右边界 `j (i ≤ j)`，这样就能得到所有 `O(n²)` 个子串。  
- **检查合法性**：对每个子串逐字符判断是否出现 `'0'`，出现一次就可以直接放弃（提前退出），因为只要有一个 `'0'` 就不符合要求。  

> **类比**：把字符串想象成一本书的连续页码，暴力法就像把每一页和之后的每一页都配对检查，看看这段文字里有没有出现“不想要的词”。  

这个方法一定能得到正确答案，因为它穷举了所有可能的子串，只要子串满足“全是 1”，我们就把它算进去。

#### 代码（Python）
```python
def numberOfSubstrings_bruteforce(s: str) -> int:
    MOD = 10**9 + 7          # 题目要求取模
    n = len(s)
    ans = 0

    # 枚举左边界 i
    for i in range(n):
        # 记录从 i 开始往右是否仍然全是 1
        all_one = True
        # 枚举右边界 j
        for j in range(i, n):
            if s[j] == '0':          # 一旦碰到 0，就不可能再是全 1 的子串了
                all_one = False
                break               # 提前结束内层循环，省点时间
            # 如果到这里仍然 all_one 为 True，说明 s[i:j+1] 全是 1
            ans = (ans + 1) % MOD    # 计数并取模
    return ans
```

#### 复杂度
- **时间复杂度**：`O(n²)`  
  解释：外层遍历 `n` 次，内层最坏情况下也要遍历 `n` 次（例如全是 `'1'` 的字符串），所以总操作数约等于 `n × n`，即平方级别。对初学者来说，可以把 `O(n²)` 想象成“如果 `n` 是 1000，运行时间大约是 1000×1000=100万 次”。
- **空间复杂度**：`O(1)`  
  只用了常数级别的额外变量 `ans、i、j、all_one`，不随输入规模增长。

### 2. 最优解

#### 思路  
暴力解的瓶颈在于 **重复检查相同的字符**。例如字符串 `"111"`，子串 `"11"` 会被检查两次（一次作为 `i=0,j=1`，一次作为 `i=1,j=2`），而我们只需要统计每段连续 `'1'` 能产生多少合法子串。

**关键观察**：  
- 连续的 `'1'` 形成一个“块”。比如 `"0110111"` 中有三块 `1`，长度分别是 `1, 2, 3`。  
- 对于长度为 `k` 的块，所有只含 `'1'` 的子串数量等于 **等差数列求和**：`1 + 2 + … + k = k·(k+1)/2`。  
  - 解释：长度为 `1` 的子串有 `k` 个（每个字符各算一次），长度为 `2` 的子串有 `k-1` 个，…，长度为 `k` 的子串只有 `1` 个。把这些数量相加就是等差数列求和公式。

**实现步骤**  
1. **一次遍历** 整个字符串，用一个计数器 `cnt` 记录当前连续 `'1'` 的个数。  
2. 当遇到 `'0'`（或遍历结束）时，把已经统计的 `cnt` 按公式 `cnt*(cnt+1)//2` 加到答案中，然后把 `cnt` 清零，继续向后走。  
3. 最后记得对答案取模 `10^9+7`。

> **类比**：把每段连续的 `'1'` 看作一排排的砖块，`cnt` 是这排砖块的长度。我们要统计从这排砖块里挑出任意连续子段的种类数，正好等于把 1 到 `cnt` 的所有数字相加。

#### 代码（Python）
```python
def numberOfSubstrings(s: str) -> int:
    MOD = 10**9 + 7
    ans = 0          # 最终答案
    cnt = 0          # 当前连续 '1' 的长度

    for ch in s:
        if ch == '1':
            cnt += 1               # 继续累计连续 1 的长度
        else:
            # 遇到 0，说明上一段连续 1 结束，计算贡献并清零
            ans = (ans + cnt * (cnt + 1) // 2) % MOD
            cnt = 0

    # 循环结束后，字符串可能以 1 结尾，需要再算一次
    ans = (ans + cnt * (cnt + 1) // 2) % MOD
    return ans
```

#### 复杂度
- **时间复杂度**：`O(n)`  
  只需要一次线性扫描，每个字符处理一次。对比暴力的 `O(n²)`，我们把“每个字符都被检查 `n` 次”降到了“每个字符只被检查一次”。  
- **空间复杂度**：`O(1)`  
  只用了几个整数变量，和输入大小无关。

## 心得

- **核心技巧**：把“只含 1 的子串计数”转化为“连续 1 块的长度求和”。利用等差数列求和公式 `k·(k+1)/2` 可以在一次遍历中完成计数。  
- **适用场景**：  
  1. 统计连续相同字符子串的数量（例如只含 `'0'` 的子串）。  
  2. 统计满足某种“连续出现次数”条件的子数组/子串（如 LeetCode 1513 “Number of Substrings With Only 1's and 0's”。）  
- **一句话总结**：把问题抽象成“每段连续 1 的长度 → 等差求和”，一次遍历即可搞定。

## 反思

- **第一反应**：看到“全是 1 的子串”，自然会想到暴力枚举所有子串并检查。  
- **最容易踩的坑**：  
  - 忘记在遍历结束后处理最后一段连续的 `'1'`（因为可能没有后面的 `'0'` 触发计数）。  
  - 结果可能非常大，需要及时对 `10^9+7` 取模，防止整数溢出（在 Python 虽然不会溢出，但取模是题目要求）。  
- **下次遇到同类题**：第一步先思考“是否可以把整体划分为若干独立块”，如果可以，就尝试用块的属性（长度、和等）直接算出答案，而不是逐个子结构枚举。
