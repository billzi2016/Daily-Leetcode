## 题目（英文原版）

**Description**

Given a m * n matrix of ones and zeros, return how many square submatrices have all ones.

**Examples**

**Example 1:**

```
Input: matrix =
[
  [0,1,1,1],
  [1,1,1,1],
  [0,1,1,1]
]
Output: 15
Explanation: 
There are 10 squares of side 1.
There are 4 squares of side 2.
There is  1 square of side 3.
Total number of squares = 10 + 4 + 1 = 15.
```

**Example 2:**

```
Input: matrix = 
[
  [1,0,1],
  [1,1,0],
  [1,1,0]
]
Output: 7
Explanation: 
There are 6 squares of side 1.  
There is 1 square of side 2. 
Total number of squares = 6 + 1 = 7.
```

**Constraints**

- 1 <= arr.length <= 300
- 1 <= arr[0].length <= 300
- 0 <= arr[i][j] <= 1

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把每一个可能的正方形子矩阵都枚举出来，检查它里面的所有元素是不是全为 1**。  
这一步可以分成两层循环：

1. **遍历左上角** `(i, j)`，它可以是矩阵的任意位置。  
2. **遍历正方形的边长** `size`（从 1 开始），只要 `i+size-1`、`j+size-1` 没超出矩阵范围，就说明这个大小的正方形是合法的。  

对于每一个候选正方形，我们再 **逐个格子** 检查它的值是否全是 1；只要出现一次 0，就可以立刻停止检查，认为这个正方形不满足要求。

> **类比**：把矩阵想象成一张棋盘，暴力解相当于把棋盘上每一个格子当作左上角，然后用尺子量出所有可能的正方形，逐格检查有没有黑子（0）出现。

这种方法一定能得到正确答案，因为我们把**所有可能的正方形**都检查了一遍，凡是满足条件的自然会被计数。

#### 代码（Python）

```python
from typing import List

def countSquares_bruteforce(matrix: List[List[int]]) -> int:
    m, n = len(matrix), len(matrix[0])
    ans = 0

    # ① 遍历每一个左上角 (i, j)
    for i in range(m):
        for j in range(n):
            # ② 正方形的最大可能边长受到矩阵边界限制
            max_len = min(m - i, n - j)
            # ③ 逐个尝试不同的边长
            for size in range(1, max_len + 1):
                all_one = True
                # ④ 检查当前正方形的每一个格子
                for x in range(i, i + size):
                    for y in range(j, j + size):
                        if matrix[x][y] == 0:      # 遇到 0 立刻退出
                            all_one = False
                            break
                    if not all_one:
                        break
                if all_one:          # 完全为 1，计数
                    ans += 1
    return ans
```

#### 复杂度  

- **时间复杂度：** `O(m * n * min(m, n)^2)`  
  - 最外层两个循环遍历左上角，`m*n` 次。  
  - 第三个循环尝试所有可能的边长，最多是 `min(m, n)`。  
  - 最内层的两层遍历检查正方形内部，最多再遍历 `size^2`（即 `min(m,n)^2`）个格子。  
  - 粗略来看，就是**三次方级别**的工作量。用大白话说，就是“如果矩阵是 100×100，大概要检查 100⁴=1亿 次”，会明显慢。

- **空间复杂度：** `O(1)`  
  - 只用了常数个额外变量，和输入规模无关。

### 2. 最优解

#### 思路  

暴力解的瓶颈在 **每次检查正方形内部都要逐格遍历**，这导致了 `O(k²)`（k 为边长）的额外工作。  
我们可以利用**动态规划**的思想，把“正方形是否全为 1”这一信息 **在遍历时逐步累积**，从而把检查的成本降到 `O(1)`。

核心观察：

- 对于任意位置 `(i, j)`（下标从 0 开始），如果 `matrix[i][j] == 1`，它可以作为 **以该格子为右下角的** 正方形的右下角。  
- 设 `dp[i][j]` 表示**以 `(i, j)` 为右下角的最大正方形的边长**。  
- 那么 `dp[i][j]` 的递推式是：

```
dp[i][j] = 0                         if matrix[i][j] == 0
dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])   otherwise
```

解释：

- 如果当前格子是 0，显然不可能组成任何全 1 正方形，`dp = 0`。  
- 如果是 1，则它本身至少能形成一个边长为 1 的正方形。  
- 要想再往大了扩展（边长 > 1），左边、上边、左上角三个方向的 **最大正方形** 必须都足够大。  
  - `dp[i-1][j]`：左边格子能向上延伸的最大边长。  
  - `dp[i][j-1]`：上边格子能向左延伸的最大边长。  
  - `dp[i-1][j-1]`：左上角格子能向右下延伸的最大边长。  
- 这三者的 **最小值** 决定了我们还能向外扩展多少步，再加上当前格子本身的 1，得到 `dp[i][j]`。

**计数方式**：`dp[i][j]` 不仅是最大边长，还暗含了所有更小的正方形。  
例如 `dp[i][j] = 3`，说明以 `(i, j)` 为右下角的正方形有边长 1、2、3 三种可能，累计计数为 3。  
所以答案只需要把所有 `dp[i][j]` 加起来即可。

> **类比**：把 `dp` 看成“水位计”。每个格子记录了在它左、上、左上三条水渠里最短的水位，加上自己这条水管的水，得到能灌满的最大正方形面积。累计所有水位，就是所有可以灌满的正方形数量。

#### 代码（Python）

```python
from typing import List

def countSquares(matrix: List[List[int]]) -> int:
    """
    动态规划解法
    dp[i][j] 表示以 (i, j) 为右下角的全 1 正方形的最大边长
    """
    m, n = len(matrix), len(matrix[0])
    # 使用同样大小的 dp 表，初始化全 0
    dp = [[0] * n for _ in range(m)]
    ans = 0

    for i in range(m):
        for j in range(n):
            if matrix[i][j] == 1:                     # 只有格子本身是 1 才可能构成正方形
                if i == 0 or j == 0:                  # 第一行或第一列没有左上、上、左的格子
                    dp[i][j] = 1                     # 只能形成 1×1 的正方形
                else:
                    # 取左、上、左上的最小值，再加上自己
                    dp[i][j] = 1 + min(dp[i-1][j],
                                      dp[i][j-1],
                                      dp[i-1][j-1])
                ans += dp[i][j]                       # 累计所有边长 ≤ dp[i][j] 的正方形
            # 若 matrix[i][j] == 0，dp[i][j] 本来就是 0，不需要额外处理
    return ans
```

#### 复杂度  

- **时间复杂度：** `O(m * n)`  
  - 我们只遍历矩阵一次，每个格子只做 `O(1)` 的常数操作（取最小值、加法）。  
  - 用大白话说，就是“矩阵里有多少格子，就算多少次”，即使是最大 300×300（9 万格）也非常快。

- **空间复杂度：** `O(m * n)`（也可以改写成 `O(n)`）  
  - 需要额外的 `dp` 表存放每个格子的最大边长。  
  - 如果只保留前一行的数据，可以把空间压缩到 `O(n)`，但为了初学者的易懂，这里使用完整的二维数组。

## 心得

- **核心技巧**：**动态规划** —— 用 `dp[i][j]` 记录“以当前格子为右下角的最大正方形边长”，把子问题的答案复用到更大的问题中。  
- **适用的题型**：  
  1. “最大正方形” (`Maximal Square`)——同样用 `dp[i][j] = 1 + min(...)` 求最大面积。  
  2. “最大矩形” (`Largest Rectangle of 1s`)——思路相似，只是改为单调栈求直方图。  
  3. “计数全 1 子矩阵”——可以把正方形换成任意矩形，使用前缀和或 DP 累计。  
- **一句话总结解题钥匙**：**把“检查全部格子”转化为“利用相邻格子的已有信息”，让每一步只做常数时间的更新。**

## 反思

- **第一反应**：看到“全部为 1 的正方形”，本能想到“枚举左上角、枚举大小、逐格检查”。这就是暴力解。  
- **最容易踩的坑**：  
  - 边界处理：第一行或第一列没有左上、上、左三个相邻格子，需要单独处理。  
  - 计数方式：`dp[i][j]` 表示最大边长，**不要只把它当作 1 次计数**，而是把它的数值直接累加进答案。  
  - 矩阵只有 0/1，若输入中出现非 0/1 的值，需要先做好数据校验（本题保证不出现）。  
- **下次类似题目第一步**：**先问自己“能否把子问题的答案保留下来并在更大范围复用？”**——这一步往往能快速指向动态规划或前缀和的思路。
