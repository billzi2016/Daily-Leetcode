# #1518. 水瓶 / Water Bottles

> 难度：简单 · 标签：Math、Simulation · [LeetCode 链接](https://leetcode.com/problems/water-bottles/)

---

## 题目（英文原版）

**Description**

There are numBottles water bottles that are initially full of water. You can exchange numExchange empty water bottles from the market with one full water bottle.
The operation of drinking a full water bottle turns it into an empty bottle.
Given the two integers numBottles and numExchange, return the maximum number of water bottles you can drink.

**Examples**

**Example 1:**

```
Input: numBottles = 9, numExchange = 3
Output: 13
Explanation: You can exchange 3 empty bottles to get 1 full water bottle.
Number of water bottles you can drink: 9 + 3 + 1 = 13.
```

**Example 2:**

```
Input: numBottles = 15, numExchange = 4
Output: 19
Explanation: You can exchange 4 empty bottles to get 1 full water bottle. 
Number of water bottles you can drink: 15 + 3 + 1 = 19.
```

**Constraints**

- 1 <= numBottles <= 100
- 2 <= numExchange <= 100

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把喝水的过程一步步模拟下来**。  
我们有 `numBottles` 瓶满水的瓶子，喝完后会变成空瓶子。只要手里累计的空瓶子数达到 `numExchange`，就可以去换一瓶满的水，再继续喝。  
这就像玩儿“换瓶子喝饮料”的游戏：  
- **空瓶子**相当于“积分”，每凑满 `numExchange` 积分就能兑换一瓶新饮料。  
- **满瓶子**相当于“可消费的资源”，喝掉后会变成积分。

只要我们一直循环：  
1. 喝掉所有满瓶子，累计空瓶子数。  
2. 用空瓶子换新满瓶子（`exchange = empty // numExchange`），剩余空瓶子保留下来。  
3. 重复上述步骤，直到空瓶子不足以再兑换一瓶。  

这样模拟下来，得到的喝的总瓶数一定是最大值，因为每一次我们都不浪费任何可以兑换的空瓶子。

#### 代码（Python）

```python
def maxWaterBottles_bruteforce(numBottles: int, numExchange: int) -> int:
    # 已经喝过的瓶子总数
    total_drunk = 0
    # 当前手里有的满瓶子数量
    full = numBottles
    # 当前手里有的空瓶子数量
    empty = 0

    while full > 0:                     # 只要还有满的就继续喝
        total_drunk += full              # 把这些满瓶子全喝掉
        empty += full                    # 喝完后全变成空瓶子
        # 用空瓶子换新满瓶子
        full = empty // numExchange      # 能换多少瓶
        empty = empty % numExchange      # 换走后剩下的空瓶子

    return total_drunk
```

#### 复杂度  

- **时间复杂度**：`O(k)`，其中 `k` 是循环的次数。每一次循环都把空瓶子数量至少除以 `numExchange`（`≥2`），所以循环次数不会超过 `log₂(numBottles)`，在本题的约束（`numBottles ≤ 100`）下几乎可以看作常数时间。  
- **空间复杂度**：`O(1)`，只用了几条整数变量，和输入规模无关。

### 2. 最优解

#### 思路  

虽然上面的模拟已经够快，但我们可以进一步**用数学公式一次算出答案**，不必真的一次次循环。

观察模拟过程：

| 步骤 | 喝掉的瓶数 | 剩余空瓶子 | 换来的新满瓶子 |
|------|------------|------------|----------------|
| 初始 | `numBottles` | `numBottles` | `numBottles // numExchange` |
| …    | …          | …          | …                |

每喝掉一瓶，空瓶子数就会增加 1。要想再得到一瓶新水，**需要额外的 `numExchange - 1` 个空瓶子**（因为换一瓶时会消耗 `numExchange`，但喝掉这瓶后又会再得到 1 个空瓶子）。换句话说，**每多喝 `numExchange - 1` 瓶，才会多得到 1 瓶**。

于是总喝的瓶数可以用下面的等式表示：

```
total = numBottles + (numBottles - 1) // (numExchange - 1)
```

解释：

- `numBottles`：最开始直接能喝的瓶子数。  
- `(numBottles - 1) // (numExchange - 1)`：在最开始的 `numBottles` 瓶喝完后，累计的空瓶子是 `numBottles`。每 `numExchange - 1` 个多余的空瓶子可以再换来一瓶满的，`-1` 是因为最后剩下的空瓶子不足以再换瓶子时会被“浪费”。  

这个公式一次性算出答案，省去了循环。

#### 代码（Python）

```python
def maxWaterBottles_optimal(numBottles: int, numExchange: int) -> int:
    # 直接用数学公式计算：初始瓶数 + 能额外换来的瓶数
    # (numBottles - 1) // (numExchange - 1) 表示每凑满 (numExchange-1) 个额外空瓶子可以再喝一瓶
    return numBottles + (numBottles - 1) // (numExchange - 1)
```

#### 复杂度  

- **时间复杂度**：`O(1)`，只做了常数次算术运算，和输入规模完全无关。  
- **空间复杂度**：`O(1)`，仅使用了几个整数变量。

## 心得

- **核心技巧**：把“每喝一瓶得到一个空瓶子”转化为“每 `numExchange‑1` 个空瓶子可以额外再喝一瓶”。这是一种**等价转换**的思路，常用于“换物”“剩余计数”类问题。  
- **适用的题型**：  
  1. **换瓶子**类：如 “Candies (糖果换礼物)”。  
  2. **折扣/积分**类：如 “Maximum Number of Consecutive Days You Can Eat Bananas”。  
  3. **递归/循环求和**类：如 “Maximum Number of Apples You Can Eat”。  
- **一句话总结解题钥匙**：把“喝 + 换”过程抽象为“每消耗 `numExchange‑1` 个空瓶子多喝一瓶”，直接用整数除法一次算完。

## 反思

- **第一反应**：看到“喝完变空瓶子，再换新瓶子”，立刻想到**循环模拟**。  
- **最容易踩的坑**：  
  - 忘记把**喝完后得到的空瓶子**计入下一轮的兑换，导致答案偏小。  
  - 边界情况 `numExchange = 2` 时，公式仍然成立，但如果手动写循环，容易出现**无限循环**（因为每喝一瓶就能立刻换一瓶，需要正确更新空瓶子数量）。  
- **下次遇到同类题**，第一步应该思考**“每次操作后资源的增量/减量”**，看能否用**等价的整数除法**一次性算出累计结果，而不是逐步模拟。
