# #1542. 寻找最长的精彩子串 / Find Longest Awesome Substring

> 难度：困难 · 标签：Hash Table、String、Bit Manipulation · [LeetCode 链接](https://leetcode.com/problems/find-longest-awesome-substring/)

---

## 题目（英文原版）

**Description**

You are given a string s. An awesome substring is a non-empty substring of s such that we can make any number of swaps in order to make it a palindrome.
Return the length of the maximum length awesome substring of s.

**Examples**

**Example 1:**

```
Input: s = "3242415"
Output: 5
Explanation: "24241" is the longest awesome substring, we can form the palindrome "24142" with some swaps.
```

**Example 2:**

```
Input: s = "12345678"
Output: 1
```

**Example 3:**

```
Input: s = "213123"
Output: 6
Explanation: "213123" is the longest awesome substring, we can form the palindrome "231132" with some swaps.
```

**Constraints**

- 1 <= s.length <= 105
- s consists only of digits.

给定一个字符串 `s`。如果一个非空子串（substring）可以通过任意次数的字符交换（swap）后变成回文串（palindrome），则称其为 **精彩子串**（awesome substring）。返回 `s` 中最长精彩子串的长度。

**示例 1**  
**输入**: `s = "3242415"`  
**输出**: `5`  
**解释**: `"24241"` 是最长的精彩子串，经过若干次交换后可以构成回文串 `"24142"`。

**输入**: `s = "12345678"`  
**输出**: `1`

**示例 3**  
**输入**: `s = "213123"`  
**输出**: `6`  
**解释**: `"213123"` 是最长的精彩子串，经过若干次交换后可以构成回文串 `"231132"`。

**约束条件**  
- `1 <= s.length <= 10^5`  
- `s` 仅由数字字符组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是枚举所有可能的子串，判断每个子串能否通过任意次交换得到回文。如果可以，就更新答案的最大长度。

- **枚举子串**：两层循环，外层确定子串的左端点 `l`，内层遍历右端点 `r`（`l ≤ r`），子串即 `s[l:r+1]`。  
- **判断能否变成回文**：统计子串里每个数字出现的次数（因为字符只有 `'0'~'9'`，用长度为 10 的数组或字典），然后检查出现奇数次的数字个数。回文的条件是：**至多只能有一个数字出现奇数次**（奇数个的字符只能放在回文的中间），其余全部出现偶数次。  
- **更新答案**：如果满足条件，就把当前子串长度 `r-l+1` 与全局最大值比较，取较大者。

> **类比**：把子串看成一堆字母的拼图，想要拼成回文，就像把字母装进两边对称的盒子，只有一个字母可以单独放在盒子中间。统计每个字母的出现次数，就像查字典——字典的“键”是数字，值是出现次数。

这个方法一定能得到正确答案，因为它穷举了所有可能的子串并逐一验证。

#### 代码（Python）

```python
def longestAwesome_bruteforce(s: str) -> int:
    n = len(s)
    ans = 0
    # 枚举左端点
    for l in range(n):
        cnt = [0] * 10                 # 统计 0~9 出现次数
        # 枚举右端点
        for r in range(l, n):
            digit = int(s[r])
            cnt[digit] += 1           # 更新当前子串的计数
            # 判断是否可以变成回文
            odd = sum(c % 2 for c in cnt)   # 出现奇数次的数字个数
            if odd <= 1:              # 至多一个奇数即可
                ans = max(ans, r - l + 1)
    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n² * 10)` → 简写为 `O(n²)`。  
  两层循环遍历所有子串，内部遍历 10 个数字统计奇偶，`n` 最多 `10⁵` 时会超时。  
- **空间复杂度**：`O(10)` → `O(1)`。  
  只用一个长度为 10 的计数数组，和常数级的临时变量。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**重复统计子串内部的字符出现次数**。我们可以把“奇偶信息”用更紧凑的方式保存，并在遍历一次字符串的过程中直接得到任意前缀的奇偶状态，从而快速判断以当前字符结尾的最长合法子串。

**关键观察**  

1. 对于任意子串 `s[l:r]`（左闭右闭），如果我们知道前缀 `[0, r]` 与前缀 `[0, l-1]` 中每个数字出现次数的奇偶性，就可以判断该子串是否满足回文条件。  
2. 用一个 10 位的二进制数 `mask` 来表示奇偶性：第 `i` 位为 `1` 表示数字 `i` 在当前前缀中出现了奇数次，为 `0` 表示出现偶数次。  
   - 初始 `mask = 0`（所有数字出现偶数次，即 0 次）。  
   - 处理字符 `s[i]` 时，`mask ^= (1 << int(s[i]))`，即翻转对应位的奇偶性。  
3. 子串 `s[l:r]` 能变成回文的充要条件是：`mask_l-1` 与 `mask_r` 的异或结果 **至多只有一位是 1**。因为两者的异或恰好表示在区间 `[l, r]` 中奇数次出现的数字集合。  
   - “至多一位是 1” 等价于 `xor == 0`（没有奇数出现）或 `xor` 是 **2 的幂**（只有一个 1），即 `xor & (xor - 1) == 0`。  

**如何快速得到最长长度**  

遍历字符串时，维护当前的 `mask` 并把每一次出现的 `mask` 位置（索引）存入哈希表 `first_pos`，只记录该 `mask` 最早出现的位置。因为我们希望子串尽可能长，左端点越靠左越好。

对于每个位置 `i`（对应前缀 `s[0:i]`，`i` 从 0 开始计数），我们检查：

1. **完全匹配**：如果同样的 `mask` 之前出现过，说明区间之间的奇偶差为 0，子串可以直接构成回文。长度 = `i - first_pos[mask]`。  
2. **差一个位**：尝试把 `mask` 的每一位翻转一次（共 10 种可能），得到 `mask ^ (1 << d)`，如果该变形在哈希表中出现过，说明区间的奇偶差恰好只有数字 `d` 出现奇数次，同样合法。长度 = `i - first_pos[mask ^ (1 << d)]`。  

取上述两种情况的最大值，即为以 `i` 为右端点的最长合法子串。全局最大即答案。

> **类比**：把每个前缀的奇偶状态想象成一本“奇偶日记”。如果两天的日记完全相同，说明这两天之间的数字出现次数都变了偶数次，内部可以配成回文；如果只相差一本“奇偶页”（只有一位不同），说明只有一种数字出现奇数次，放在中间同样可以配成回文。

#### 代码（Python）

```python
def longestAwesome(s: str) -> int:
    """
    使用位掩码 + 哈希表求最长 awesome 子串
    时间复杂度 O(n * 10) ≈ O(n)，空间复杂度 O(n)（哈希表最多存 n+1 条记录）
    """
    first_pos = {0: -1}          # mask 0 在下标 -1 处出现，方便计算以 0 开头的子串
    mask = 0                     # 当前前缀的奇偶掩码
    ans = 0

    for i, ch in enumerate(s):
        digit = int(ch)
        mask ^= (1 << digit)    # 翻转对应位的奇偶性

        # 1) 完全相同的 mask -> 区间内所有数字出现偶数次
        if mask in first_pos:
            ans = max(ans, i - first_pos[mask])
        else:
            # 只记录第一次出现的位置，保证左端点尽可能靠左
            first_pos[mask] = i

        # 2) 只相差一位的 mask -> 区间内恰好有一个数字出现奇数次
        for d in range(10):      # 枚举可能的单个奇数数字
            candidate = mask ^ (1 << d)
            if candidate in first_pos:
                ans = max(ans, i - first_pos[candidate])

    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n * 10)` → 实际上是线性 `O(n)`，因为常数 10（数字种类）是固定的。  
  对每个字符我们做一次位翻转、一次哈希查询以及 10 次“翻转一次位后查询”，均为 O(1)。  
- **空间复杂度**：`O(n)`。  
  哈希表 `first_pos` 最多保存每个不同的 `mask` 的最早出现位置，`mask` 的取值范围是 `2¹⁰ = 1024`，所以最坏情况下只会存 1024 条记录，实际上可以视为 `O(1)`；但从代码实现角度，用字典保存至多 `n+1` 条（因为我们只在首次出现时写入），整体仍是线性空间。

## 心得

- **核心技巧**：**位掩码 + 前缀哈希**，把“每个数字出现奇偶性”压缩到 10 位二进制数，利用哈希表快速定位相同或相差一位的前缀，从而在 O(n) 时间内得到答案。  
- **适用题型**：  
  1. “最长子数组/子串满足奇偶或出现次数条件”——如 *“Find Longest Awesome Substring”*、*“Longest Subarray with Even Counts”*。  
  2. “只允许出现至多 K 种奇数次数的字符”——如 *“Maximum Length of Subarray With At Most K Odd Numbers”*（可以把 K=1 的情况套用同样思路）。  
  3. “求满足某种位运算条件的最长子数组”——如 *“Maximum Size Subarray Sum Equals K”* 的位版本。  
- **一句话总结**：**把“出现奇偶”映射成 10 位二进制，利用哈希表找最早相同或只差一位的前缀，即可线性扫描得到最长 awesome 子串。**

## 反思

- **第一反应**：看到“可以随意交换字符后得到回文”，立刻想到回文的奇偶计数条件，然后想到枚举子串并统计字符频次的暴力办法。  
- **最容易踩的坑**：  
  1. **漏掉子串为空的情况**（本题要求非空，代码里要确保不把 `0` 长度计入）。  
  2. **边界处理**：初始化 `first_pos[0] = -1` 很关键，能够处理从字符串开头就满足条件的子串。  
  3. **位翻转的范围**：数字只有 `0~9`，必须只遍历这 10 位，否则会产生错误的候选掩码。  
- **下次类似题的第一步**：先把“满足条件”转化为**“前缀之间的某种关系”**（如相等或只差一位），再考虑使用**哈希表**或**数组**记录最早出现的前缀状态，实现一次遍历。
