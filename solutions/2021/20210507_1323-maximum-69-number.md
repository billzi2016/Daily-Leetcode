# #1323. 最大 69 数 / Maximum 69 Number

> 难度：简单 · 标签：Math、Greedy · [LeetCode 链接](https://leetcode.com/problems/maximum-69-number/)

---

## 题目（英文原版）

**Description**

You are given a positive integer num consisting only of digits 6 and 9.
Return the maximum number you can get by changing at most one digit (6 becomes 9, and 9 becomes 6).

**Examples**

**Example 1:**

```
Input: num = 9669
Output: 9969
Explanation: 
Changing the first digit results in 6669.
Changing the second digit results in 9969.
Changing the third digit results in 9699.
Changing the fourth digit results in 9666.
The maximum number is 9969.
```

**Example 2:**

```
Input: num = 9996
Output: 9999
Explanation: Changing the last digit 6 to 9 results in the maximum number.
```

**Example 3:**

```
Input: num = 9999
Output: 9999
Explanation: It is better not to apply any change.
```

**Constraints**

- 1 <= num <= 104
- num consists of only 6 and 9 digits.

## 题目（中文翻译）

**描述**  
给定一个只包含数字 6 和 9 的正整数 `num`。  
你最多可以修改 **一个** 数位（将 6 变成 9，或将 9 变成 6），返回能够得到的最大数值。

**示例 1**  
**输入**: `num = 9669`  
**输出**: `9969`  
**解释**:  
- 将第一位改为 6 得到 `6669`。  
- 将第二位改为 9 得到 `9969`。  
- 将第三位改为 9 得到 `9699`。  
- 将第四位改为 6 得到 `9666`。  
最大数为 `9969`。

**示例 2**  
**输入**: `num = 9996`  
**输出**: `9999`  
**解释**: 将最后一位的 6 改为 9，即可得到最大数。

**示例 3**  
**输入**: `num = 9999`  
**输出**: `9999`  
**解释**: 此时不进行任何修改更好。

**约束条件**  
- `1 <= num <= 10^4`  
- `num` 仅由数字 6 和 9 组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是把整数 `num` 拆成每一位的字符，逐个尝试「把这位 6 换成 9」或「把这位 9 换成 6」——因为题目只允许改动 **至多** 一个数字，所以只需要枚举每一位的两种可能（不改动、改动），把得到的所有新数记录下来，最后返回最大的那个。

- **数据结构**：把数字转成字符数组（`list(str(num))`），相当于把数字拆成一排小卡片，每张卡片上写的是 6 或 9。类似查字典时我们把词拆成字母，逐个检查、修改。
- **正确性**：因为我们把每一位都尝试了一遍（包括不改动的情况），所以所有合法的「改动不超过一次」的结果都会被产生，取最大值自然就是答案。

#### 代码（Python）
```python
def maximum69Number_brute(num: int) -> int:
    # 把整数转成字符列表，方便逐位修改
    digits = list(str(num))          # 例如 9669 -> ['9','6','6','9']
    best = num                       # 初始答案设为原数（不改动）

    # 枚举每一位
    for i in range(len(digits)):
        original = digits[i]         # 记住原来的字符，后面要恢复

        # 如果当前是 6，改成 9；如果是 9，改成 6
        digits[i] = '9' if digits[i] == '6' else '6'

        # 把修改后的字符列表重新拼成整数
        candidate = int(''.join(digits))
        # 更新最大值
        best = max(best, candidate)

        # 恢复原来的字符，准备尝试下一个位置
        digits[i] = original

    return best
```

#### 复杂度
- **时间复杂度**：`O(n)`，其中 `n` 是数字的位数。我们只遍历一次每一位，并在每次遍历中做 `O(1)` 的字符串拼接（`join` 与 `int` 在位数上是线性，但相当于一次遍历），总体仍是线性。  
  大白话：如果数字有 5 位，就最多检查 5 次，每次都很快，所以时间随位数线性增长。
- **空间复杂度**：`O(n)`，需要存放字符列表 `digits`（长度等于位数）以及临时的字符串。  
  大白话：我们把原来的数字拆成一串字符，跟原数字一样多的空间。

### 2. 最优解

#### 思路  
暴力解已经是 `O(n)`，已经很快了。但我们可以 **一步到位**，不必枚举所有位，只需要找到「最左边的 6」并把它换成 9，即可得到最大值。原因如下：

- 在十进制数中，左边的位权重更大（千位 > 百位 > 十位）。把左侧的 6 换成 9 能让整体数值增加最多。
- 如果所有位都是 9，已经是最大数，直接返回原数即可。
- 因此，只要遍历一次找到最左侧的 6，改成 9 后直接返回；如果遍历结束都没有 6，则返回原数。

核心技巧是 **贪心**（greedy）：每一步都做局部最优（把左边第一个可以提升的位提升），最终得到全局最优。

#### 代码（Python）
```python
def maximum69Number(num: int) -> int:
    # 把整数转成字符列表，方便原地修改
    digits = list(str(num))

    # 从左到右找第一个 '6'
    for i, ch in enumerate(digits):
        if ch == '6':
            digits[i] = '9'          # 把它换成 '9'，其余保持不变
            break                    # 只改动一次，立刻退出循环

    # 把修改后的字符列表拼回整数返回
    return int(''.join(digits))
```

#### 复杂度
- **时间复杂度**：`O(n)`，仍然只遍历一次字符列表。相较于暴力解，它少了 `int` 转换的重复操作，常数更小。  
  大白话：不管有多少位，只需要看一遍，找到第一个 6 就停下来。
- **空间复杂度**：`O(n)`，需要存放字符列表，同样和位数成正比。  

> 与暴力解相比，最优解的时间常数更小，实际运行更快；空间上没有额外提升，因为我们仍需把数字拆成字符。

## 心得

- 这道题考察的核心技巧是 **贪心**：把左边第一个可以提升的位改成更大的数字即可得到全局最优。
- 该技巧适用的题型  
  1. “把数字中某一位改成更大/更小的数，使整体最大/最小”（如 LeetCode 1323 `Maximum 69 Number`）。  
  2. “把二进制/十进制字符串中最左侧的 0 换成 1，使数值最大”（类似 1903 `Largest Odd Number in String`）。  
  3. “在字符串中把最左侧的某字符替换为字典序更大的字符，得到字典序最大的字符串”。
- **解题钥匙**：**左侧位的权重最大 → 只要左边有可以提升的位，改动它就能得到最大值**。

## 反思

- **第一反应**：把数字拆成字符，逐位尝试改动，取最大——这就是暴力思路。
- **最容易踩的坑**  
  - 忘记 “至多一次” 的限制，导致对同一位多次改动。  
  - 忽略全部为 9 的情况，错误地总是尝试改动。  
  - 在实现时把 `int` 与 `str` 的转换写在循环里，导致不必要的额外时间消耗。
- **下次遇到同类题**，第一步应该问自己：“哪一位的改变会对整体价值产生最大影响？”如果是位权重递减的数值问题，往往只需要 **找最左侧可以改动的位** 并一次性完成。
