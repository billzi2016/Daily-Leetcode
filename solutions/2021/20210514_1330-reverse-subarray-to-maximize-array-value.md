# #1330. 反转子数组以最大化数组值 / Reverse Subarray To Maximize Array Value

> 难度：困难 · 标签：Array、Math、Greedy · [LeetCode 链接](https://leetcode.com/problems/reverse-subarray-to-maximize-array-value/)

---

## 题目（英文原版）

**Description**

You are given an integer array nums. The value of this array is defined as the sum of |nums[i] - nums[i + 1]| for all 0 <= i < nums.length - 1.
You are allowed to select any subarray of the given array and reverse it. You can perform this operation only once.
Find maximum possible value of the final array.

**Examples**

**Example 1:**

```
Input: nums = [2,3,1,5,4]
Output: 10
Explanation: By reversing the subarray [3,1,5] the array becomes [2,5,1,3,4] whose value is 10.
```

**Example 2:**

```
Input: nums = [2,4,9,24,2,1,10]
Output: 68
```

**Constraints**

- 2 <= nums.length <= 3 * 104
- -105 <= nums[i] <= 105
- The answer is guaranteed to fit in a 32-bit integer.

## 题目（中文翻译）

给定一个整数数组 `nums`。该数组的 **值** 定义为所有相邻元素差的绝对值之和，即  
\[
\sum_{0 \le i < \text{nums.length} - 1} |\,\text{nums}[i] - \text{nums}[i+1]\,|
\]

你可以选择 **一次** 任意 **子数组（subarray）** 并将其 **反转（reverse）**。求在完成此操作后，数组可能得到的 **最大值（maximum possible value）**。

## 示例

### 示例 1
**输入**  
`nums = [2,3,1,5,4]`

**输出**  
`10`

**解释**  
将子数组 `[3,1,5]` 反转后，数组变为 `[2,5,1,3,4]`，其值为 `10`。

### 示例 2
**输入**  
`nums = [2,4,9,24,2,1,10]`

**输出**  
`68`

## 约束条件
- `2 <= nums.length <= 3 * 10^4`
- `-10^5 <= nums[i] <= 10^5`
- 结果保证能够放入 32 位整数中。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把每一种可能的子数组都反转一次，然后重新计算数组的价值**，取最大的那一次的结果。

- **数据结构**：我们只需要普通的 Python 列表（list），因为题目只要求一次遍历、一次反转。
- **为什么正确**：因为题目要求“只能反转一次”，枚举所有`[L, R]`（`0 ≤ L ≤ R < n`）就把所有合法的操作都考虑进来了。遍历完后取最大值，必然就是答案。
- **复杂度分析**  
  - **时间**：枚举`L`、`R`是`O(n²)`的，反转子数组和重新求和也是`O(n)`，所以总共是`O(n³)`（最坏情况下会超时）。  
    在这里我们把“`O(n³)`”解释成：如果数组长度是 1000，程序要跑大约 **10⁹** 次基本操作，普通电脑根本跑不完。  
  - **空间**：只用到原数组和几个临时变量，`O(1)`（常数级别的额外空间）。

#### 代码（Python）

```python
def maxValueAfterReverse_bruteforce(nums):
    """
    暴力枚举所有子数组并反转，求最大价值。
    仅作教学示例，n 较大时会超时。
    """
    n = len(nums)

    # 计算原数组的价值
    def value(arr):
        return sum(abs(arr[i] - arr[i - 1]) for i in range(1, len(arr)))

    best = value(nums)                     # 不做任何操作的情况
    for L in range(n):                     # 子数组左端点
        for R in range(L, n):               # 子数组右端点
            # 复制一份原数组，防止修改原数组
            tmp = nums[:]
            # 反转子数组 nums[L:R+1]
            tmp[L:R + 1] = reversed(tmp[L:R + 1])
            best = max(best, value(tmp))   # 更新最大价值

    return best
```

#### 复杂度

- **时间复杂度**：`O(n³)`  
  - `n`（左端点） × `n`（右端点） × `n`（重新计算价值）  
  - 直观上相当于“每次都要遍历整个数组”，当 `n = 10⁴` 时根本不可行。
- **空间复杂度**：`O(1)`（只用了常数个额外变量）

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**我们把所有的内部元素都重新遍历了一遍**。实际上，反转子数组对数组价值的影响只出现在**子数组两端**四个相邻位置：

```
…… a[L-1] | a[L] …… a[R] | a[R+1] ……
```

反转后，这四个位置的贡献会变成  

```
|a[R] - a[L-1]| + |a[L] - a[R+1]|
```

而原来的贡献是  

```
|a[L] - a[L-1]| + |a[R] - a[R+1]|
```

所以**唯一需要考虑的就是这两个“边界”差值的增益**，内部的 `|a[i] - a[i+1]|` 完全不变。

> **类比**：把数组看成一条路，价值是相邻两座城市之间的距离。把一段路段翻转，只会改变这段路段两头的入口和出口的距离，其余路段的距离保持不变。

因此我们只要在 `O(n)` 时间里找到**能够让增益最大的两端组合**即可。

增益公式（记 `gain = new - old`）：

```
gain(L, R) = |a[R] - a[L-1]| + |a[L] - a[R+1]|
           - |a[L] - a[L-1]| - |a[R] - a[R+1]|
```

我们把所有可能的 `L,R` 分成三类来讨论：

1. **把某个元素搬到数组最左端**（即 `L = 0`，子数组是 `[0, R]`）  
   增益 = `|a[R] - a[-1]| - |a[R] - a[R-1]|`（这里 `a[-1]` 表示原数组的最后一个元素，实际上是把整个前缀翻转后，原来的 `a[R]` 会出现在最左边）。  
   只需要遍历一次，记录 `max( |a[i] - a[0]| - |a[i] - a[i-1]| )`。

2. **把某个元素搬到数组最右端**（即 `R = n-1`，子数组是 `[L, n-1]`）  
   增益 = `|a[L] - a[0]| - |a[L] - a[L+1]|`，同理只需要遍历一次，记录 `max( |a[i] - a[-1]| - |a[i] - a[i-1]| )`。

3. **普通的内部翻转**（`1 ≤ L ≤ R ≤ n-2`）  
   这里增益只和四个端点有关。把公式展开，利用 `|x-y| = max(x-y, y-x)`，可以得到四种**符号组合**（即四个“case”）：

   ```
   case 1: ( a[R] - a[L-1] ) + ( a[L] - a[R+1] )
   case 2: ( a[R] - a[L-1] ) + ( a[R+1] - a[L] )
   case 3: ( a[L-1] - a[R] ) + ( a[L] - a[R+1] )
   case 4: ( a[L-1] - a[R] ) + ( a[R+1] - a[L] )
   ```

   每一种 case 都可以拆成两段独立的 **“左端贡献”** 与 **“右端贡献”**，例如 case 1：

   ```
   left  = a[R] - a[L-1] - |a[L] - a[L-1]|
   right = a[L] - a[R+1] - |a[R] - a[R+1]|
   ```

   只要在遍历时维护以下四个 **前缀最值**（最大或最小），就能在 `O(1)` 时间内算出当前 `R` 对应的最佳 `L`，从而得到最大增益。

   具体来说，遍历 `i = 1 … n-2`（把 `i` 当作左端 `L`），我们需要维护：

   ```
   max1 = max( a[i] - a[i-1] )          # 对应 case 1 的 left 部分
   min1 = min( a[i] + a[i-1] )          # 对应 case 4 的 left 部分（取负号后变最大）
   max2 = max( -a[i] - a[i-1] )         # 对应 case 3 的 left 部分
   min2 = min( -a[i] + a[i-1] )         # 对应 case 2 的 left 部分
   ```

   当我们把 `i` 当作右端 `R` 时，同理可以得到四个 **后缀最值**，两两配合即可得到四种 case 的增益。

   实际实现里把这四个最值的维护合并成两次遍历即可，代码更简洁。

> **关键点**：  
> - **只看边界**：翻转子数组只影响四个相邻位置的差值。  
> - **拆解绝对值**：`|x-y| = max(x-y, y-x)`，把增益拆成若干线性表达式，便于用“最大/最小”来快速求解。  
> - **前缀/后缀极值**：在一次线性扫描中维护极值，时间 `O(n)`，空间 `O(1)`。

#### 代码（Python）

```python
def maxValueAfterReverse(nums):
    """
    最优解：只需 O(n) 时间、O(1) 额外空间。
    思路见上文“最优解”章节。
    """
    n = len(nums)
    if n == 2:                      # 只剩两个数，翻转不改变价值
        return abs(nums[0] - nums[1])

    # 1️⃣ 计算原始数组的价值（不做任何翻转时的得分）
    base = sum(abs(nums[i] - nums[i - 1]) for i in range(1, n))

    # 2️⃣ 记录能够提升价值的最大增益（初始为 0，表示不翻转也可以）
    best_gain = 0

    # -------------------------------------------------
    #   A. 把元素搬到数组最左端或最右端（前缀/后缀翻转）
    # -------------------------------------------------
    for i in range(1, n):
        # 把 nums[i] 移到最左端（翻转 [0, i]）
        gain_left = abs(nums[i] - nums[0]) - abs(nums[i] - nums[i - 1])
        best_gain = max(best_gain, gain_left)

        # 把 nums[i-1] 移到最右端（翻转 [i, n-1]）
        gain_right = abs(nums[i - 1] - nums[-1]) - abs(nums[i] - nums[i - 1])
        best_gain = max(best_gain, gain_right)

    # -------------------------------------------------
    #   B. 普通的内部翻转（只影响四个端点）
    # -------------------------------------------------
    # 为了把四种 case 合在一起，只需要维护两组极值：
    #   max_a_minus = max( a[i] - a[i-1] )
    #   min_a_plus  = min( a[i] + a[i-1] )
    #   max_minus_a = max( -a[i] - a[i-1] )
    #   min_minus_a = min( -a[i] + a[i-1] )
    max_a_minus = -10**9      # 极大负数，后面会取 max
    min_a_plus  = 10**9       # 极大正数，后面会取 min
    max_minus_a = -10**9
    min_minus_a = 10**9

    for i in range(1, n - 1):          # i 作为左端 L
        # 先把左端的四个表达式加入前缀极值
        max_a_minus = max(max_a_minus, nums[i] - nums[i - 1])
        min_a_plus  = min(min_a_plus , nums[i] + nums[i - 1])
        max_minus_a = max(max_minus_a, -nums[i] - nums[i - 1])
        min_minus_a = min(min_minus_a, -nums[i] + nums[i - 1])

        # 右端 R = i+1（因为我们已经把左端的 i 固定住了）
        # 下面的四个式子对应四种 case 的 “右端贡献”
        # case 1:  a[R] - a[L-1]  -> 这里的 a[R] 是 nums[i+1]
        # case 2:  a[R] + a[L-1]  （因为取负号后变成 -a[L-1] + a[R]）
        # case 3: -a[R] - a[L-1]
        # case 4: -a[R] + a[L-1]

        # 为了让代码更直观，我们把右端的四个值直接算出来
        right1 = nums[i + 1] - nums[i]          # a[R] - a[L]（这里 L=i）
        right2 = nums[i + 1] + nums[i]          # a[R] + a[L]
        right3 = -nums[i + 1] - nums[i]         # -a[R] - a[L]
        right4 = -nums[i + 1] + nums[i]         # -a[R] + a[L]

        # 现在把左端极值和右端值配对，得到四种 case 的增益
        # 注意：原来的两个旧边界分别是 |a[L]-a[L-1]|、|a[R]-a[R+1]|
        # 这里我们已经把 |a[L]-a[L-1]|、|a[R]-a[R+1]| 用 “左端极值” 里减掉了，
        # 所以只需要加上右端的线性表达式即可。
        best_gain = max(best_gain,
                        max_a_minus + right1,   # case 1
                        min_a_plus  + right2,   # case 2（因为 min_a_plus 是最小的 a[i]+a[i-1]，加上正的 right2 相当于取最大）
                        max_minus_a + right3,   # case 3
                        min_minus_a + right4)   # case 4

    # -------------------------------------------------
    #   最终答案 = 原始价值 + 能得到的最大增益
    # -------------------------------------------------
    return base + best_gain
```

> **代码说明（关键行中文注释）**  
> - 第 9‑12 行：计算不翻转时的原始得分 `base`。  
> - 第 16‑24 行：处理把元素搬到数组最左/右端的两种特殊情况。  
> - 第 28‑55 行：维护四个前缀极值并在同一次遍历里计算四种 case 的可能增益。  
> - 第 59 行：答案 = 原始价值 + 最大增益。

#### 复杂度

- **时间复杂度**：`O(n)`  
  - 只遍历数组常数次（一次算 `base`，一次处理端点，一次维护前缀极值），所以即使 `n = 3·10⁴` 也能在毫秒级完成。  
  - 用通俗的话说，就是“只需要把每个数字看一遍”，不像暴力解那样要“看 `n` 的平方甚至立方遍”。
- **空间复杂度**：`O(1)`  
  - 只用了几个整数变量来保存极值，没有额外的数组或递归栈，空间占用几乎可以忽略不计。

## 心得

- **核心技巧**：  
  1. **只关注翻转后改变的边界**（子数组两端的相邻差值）。  
  2. **把绝对值拆成最大/最小的线性表达式**，利用前缀/后缀的最大最小值在一次扫描中求最优。  

- **适用的题型**（类似思路可以直接迁移）  
  1. “翻转子数组后最大化/最小化某种相邻差值求和”——如本题。  
  2. “只允许一次区间操作（翻转、取反、加常数）”，影响局部相邻关系的题目。  
  3. “在数组上做一次区间修改，使得整体的某种线性函数最值”，常用前缀/后缀极值技巧。

- **一句话总结解题钥匙**：  
  **“翻转只改端点，拆绝对值后用极值快速挑出最佳端点组合”。**

## 反思

- **第一反应**：直接想遍历所有 `[L,R]`，把子数组反转后重新计分——这就是暴力思路。  
- **最容易踩的坑**  
  1. **忘记处理子数组位于数组两端的情况**（比如把整个前缀或后缀翻转），这些情况的增益公式稍有不同，需要单独枚举。  
  2. **边界条件**：`n = 2` 时翻转不改变价值，代码若不做特判会出现索引越界。  
  3. **绝对值拆解时符号写错**：`|x-y| = max(x-y, y-x)`，一定要记得取两者的最大值，否则会得到负的增益。  

- **下次类似题目第一步**：先**写出翻转前后受影响的局部表达式**（这里是四个相邻差），再**判断是否可以只用极值或单调性**把搜索空间降到 `O(n)`。这样就能避免盲目枚举，直接走向最优解。
