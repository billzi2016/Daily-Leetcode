## 题目（中文翻译）

**描述**  
给定一个整数 `n`，计算其各位数字的乘积（product）与各位数字的和（sum）之差。返回 `product - sum` 的结果。

**示例 1**  
**输入**: `n = 234`  
**输出**: `15`  
**解释**:  
- 各位数字的乘积 = 2 × 3 × 4 = 24  
- 各位数字的和 = 2 + 3 + 4 = 9  
- 结果 = 24 - 9 = 15  

**示例 2**  
**输入**: `n = 4421`  
**输出**: `21`  
**解释**:  
- 各位数字的乘积 = 4 × 4 × 2 × 1 = 32  
- 各位数字的和 = 4 + 4 + 2 + 1 = 11  
- 结果 = 32 - 11 = 21  

**约束条件**  
- `1 ≤ n ≤ 10^5`   (整数范围)

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把整数 `n` 的每一位数字都找出来，分别累加得到**和**，再把它们相乘得到**积**，最后返回 `积 - 和`。  

- **获取每一位数字**：可以把 `n` 当成一串“糖果”，每次用 `% 10`（取余）拿走最右边的那颗糖果（即最后一位），用 `// 10`（整除）把它从原数里除去，循环直到没有糖果为止。  
- **为什么正确**：%10 能准确得到十进制数的最低位，//10 能把最低位剔除，反复操作就能遍历所有位。把遍历到的每位数字分别累加和累乘，最后的差就是题目要求的答案。  

**时间/空间复杂度**  
- 时间复杂度：`O(d)`，其中 `d` 是数字的位数。因为每一位只会被处理一次。位数 `d` 最多是 6（因为 `n ≤ 10^5`），所以在实际运行中几乎是常数时间。这里的 `O(d)` 可以想象成“和糖果数量成正比”。  
- 空间复杂度：`O(1)`，只用到几个整型变量，不会随 `n` 的大小增长。  

#### 代码（Python）

```python
def subtractProductAndSum(n: int) -> int:
    """
    计算整数各位数字的乘积与和的差。
    """
    product = 1      # 用来累乘，各位数字的乘积，初始值为 1（乘法的中性元）
    summation = 0    # 用来累加，各位数字的和

    while n > 0:                 # 当还有未处理的数字时循环
        digit = n % 10           # 取出最低位数字（比如 234 % 10 = 4）
        product *= digit         # 把这个数字乘到 product 上
        summation += digit       # 把这个数字加到 summation 上
        n //= 10                 # 删除最低位数字（比如 234 // 10 = 23）

    return product - summation   # 最终返回 “积 - 和”
```

#### 复杂度

- **时间复杂度**：`O(d)`，这里的 `d` 是数字的位数。因为每一位只遍历一次，实际运行时间几乎是常数。  
- **空间复杂度**：`O(1)`，只用了固定数量的变量（`product、summation、digit、n`），不随输入大小增长。

### 2. 最优解

#### 思路  

对这道题来说，暴力解已经是最优的线性遍历，没有更快的办法可以在不遍历每一位的前提下得到所有位的和与积。  
唯一可以思考的“瓶颈”是**每次取余和整除的操作**，但这两步本身就是 O(1) 的基本算术操作，且必须执行 `d` 次才能得到全部位信息。因此，**最优解**仍然是**一次遍历**，只是在实现细节上保持代码简洁、易读。

核心技巧仍然是**取余 `%` 与整除 `//`**，这两者在十进制系统里相当于“把数字拆成糖果一颗颗吃”。下面给出同样思路的更简洁写法，直接在循环里累加/累乘，最后返回结果。

#### 代码（Python）

```python
def subtractProductAndSum(n: int) -> int:
    product, summation = 1, 0

    while n:
        digit = n % 10      # 取出当前最低位
        product *= digit    # 累乘
        summation += digit  # 累加
        n //= 10            # 去掉最低位

    return product - summation
```

#### 复杂度

- **时间复杂度**：`O(d)`，与暴力解相同，只是实现更紧凑。`d` 为数字位数，最多 6 位，几乎是常数时间。  
- **空间复杂度**：`O(1)`，只用了常数个变量。

- **核心技巧**：利用 `% 10` 与 `// 10` 逐位提取十进制数字，这是一种“数字分解”技术，几乎是所有涉及**位运算**或**数位统计**题目的必备工具。  
- **适用题型**：  
  1. “各位数字之和” / “各位数字之积” 类题目（如 LeetCode 2585、2544）。  
  2. 判断数字是否满足某种位数属性的题目（如回文数、幸运数）。  
- **一句话总结**：**“把整数当作糖果袋，一颗颗取出来计算”**，把取余和整除当成“拿糖果”和“倒掉糖果”的动作。

## 反思

- **第一反应**：看到“数字的乘积”和“数字的和”，立刻想到逐位遍历并累计。  
- **最容易踩的坑**：  
  - **初始乘积值**必须是 1（乘法的中性元），如果写成 0 则所有后续乘积都会变成 0。  
  - **循环结束条件**：使用 `while n > 0` 或 `while n`，防止因为负数或 0 进入死循环。  
  - **位数为 0 的情况**：虽然题目保证 `n ≥ 1`，但若不确定，需额外处理 `n == 0`（此时乘积应为 0，和为 0，差为 0）。  
- **下次类似题的第一步**：先想 **“怎么把每一位数字取出来？”**——使用 `% 10` 与 `// 10` 的循环模板，然后在循环体里完成需要的累计或判断。
