# #1461. 检查字符串是否包含所有长度为 K 的二进制码 / Check If a String Contains All Binary Codes of Size K

> 难度：中等 · 标签：Hash Table、String、Bit Manipulation、Rolling Hash、Hash Function · [LeetCode 链接](https://leetcode.com/problems/check-if-a-string-contains-all-binary-codes-of-size-k/)

---

## 题目（英文原版）

**Description**

Given a binary string s and an integer k, return true if every binary code of length k is a substring of s. Otherwise, return false.

**Examples**

**Example 1:**

```
Input: s = "00110110", k = 2
Output: true
Explanation: The binary codes of length 2 are "00", "01", "10" and "11". They can be all found as substrings at indices 0, 1, 3 and 2 respectively.
```

**Example 2:**

```
Input: s = "0110", k = 1
Output: true
Explanation: The binary codes of length 1 are "0" and "1", it is clear that both exist as a substring.
```

**Example 3:**

```
Input: s = "0110", k = 2
Output: false
Explanation: The binary code "00" is of length 2 and does not exist in the array.
```

**Constraints**

- 1 <= s.length <= 5 * 105
- s[i] is either '0' or '1'.
- 1 <= k <= 20

## 题目（中文翻译）

给定一个二进制字符串 `s` 和一个整数 `k`，如果 `s` 的所有长度为 `k` 的二进制码（binary code）都出现为 `s` 的子串（substring），返回 `true`；否则返回 `false`。

**示例 1**  
**输入**: `s = "00110110"`, `k = 2`  
**输出**: `true`  
**解释**: 长度为 2 的二进制码有 `"00"、"01"、"10"、"11"`。它们分别出现在下标 `0、1、3、2` 处的子串中。

**示例 2**  
**输入**: `s = "0110"`, `k = 1`  
**输出**: `true`  
**解释**: 长度为 1 的二进制码有 `"0"` 和 `"1"`，显然二者都出现在子串中。

**示例 3**  
**输入**: `s = "0110"`, `k = 2`  
**输出**: `false`  
**解释**: 二进制码 `"00"` 长度为 2，但在 `s` 中不存在。

**约束条件**  
- `1 <= s.length <= 5 * 10^5`  
- `s[i]` 只能是 `'0'` 或 `'1'`  
- `1 <= k <= 20`

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是把字符串 `s` 中所有长度为 `k` 的子串都枚举出来，放进一个**集合**（相当于“词典”，可以快速判断某个子串有没有出现过），最后看集合的大小是否等于 `2^k`（因为二进制长度为 `k` 的所有可能组合一共有 `2^k` 种）。  

- **数据结构**：  
  - **集合（`set`）**：类似于生活中的“收藏卡片盒”，每放进一张卡片（子串），如果已经有了，就不会再占用额外空间。集合可以在 O(1) 时间内判断一张卡片是否已经在盒子里。  
- **为什么正确**：  
  - 只要把所有长度为 `k` 的子串全部收集起来，若其中已经包含了所有可能的二进制组合（即 `2^k` 种），说明每一种二进制码都能在 `s` 中找到，返回 `True`；否则缺少某些组合，返回 `False`。  
- **复杂度分析（大白话）**：  
  - **时间**：我们要遍历 `s` 的每一个起始位置，最多有 `|s|-k+1` 次，每次都要切出一个长度为 `k` 的子串（这一步在 Python 中是 O(k)），所以总体是 **O((n‑k+1)·k)**，在最坏情况下约等于 **O(n·k)**。如果把切子串的时间算作常数（因为 `k ≤ 20` 很小），可以说是 **O(n)**。  
  - **空间**：集合里最多会存 `2^k` 条不同的子串，`k ≤ 20`，所以最多 1,048,576 条，空间是 **O(2^k)**。  

#### 代码（Python）  

```python
def hasAllCodes_bruteforce(s: str, k: int) -> bool:
    """
    暴力解：遍历所有长度为 k 的子串，放进集合，最后比较集合大小是否等于 2^k
    """
    n = len(s)
    if n < k:          # 子串根本不够长，直接返回 False
        return False

    seen = set()       # 用集合保存出现过的子串，类似“词典”
    for i in range(n - k + 1):
        sub = s[i:i + k]          # 取出长度为 k 的子串
        seen.add(sub)             # 加入集合，重复的会被自动去重
    # 所有可能的二进制码数量是 2^k
    return len(seen) == (1 << k)   # 1 << k 等价于 2**k
```

#### 复杂度  

- **时间复杂度**：`O(n·k)`（实际因为 `k ≤ 20`，可视为 `O(n)`）。  
  - 这里的 `n` 是字符串长度。遍历每个起始位置一次，每次切片长度为 `k`。  
- **空间复杂度**：`O(2^k)`。  
  - 最多需要存放所有可能的二进制码，`k` 越大，空间需求指数级增长。

### 2. 最优解  

#### 思路  

暴力解的**瓶颈**在于每次都要创建新的子串对象（`s[i:i+k]`），这会产生大量的字符串拷贝，导致时间和空间都有额外开销。  
我们可以把二进制子串 **看成一个整数**，并利用**滚动窗口**（滑动窗口）一次性把它们算出来，避免重复切片。  

核心想法：  

1. 把长度为 `k` 的二进制串视作一个 `k` 位的二进制数。例如 `"0110"` → `0b0110 = 6`。  
2. 用一个 **整数变量 `mask`** 保存当前窗口对应的数值。向右滑动窗口时：  
   - 先把左边的最高位移出（相当于 `mask << 1` 再加上新进来的字符），  
   - 再用位运算 `& ((1 << k) - 1)` 只保留低 `k` 位，等价于把窗口大小固定在 `k`。  
3. 每得到一个完整的 `k` 位窗口，就把对应的整数加入集合 `seen`。  
4. 最后检查集合大小是否等于 `2^k`。  

为什么这样更快？  

- **不再创建子串**：只维护一个整数，更新一步完成，时间是 **O(1)**。  
- **位运算极快**：在 Python 中整数的位运算非常高效，尤其 `k ≤ 20`，整数始终在机器字长以内。  
- **空间仍是 `O(2^k)`**：因为仍需要记录出现过的不同码，只是每个元素是一个整数而不是字符串，实际占用更小。  

**类比**：想象你在看一条移动的跑道灯光，灯光每秒切换一次颜色（0/1），你只需要记下最近 `k` 秒的颜色组合。用手指在灯光上滑动，每次只看最右边的新颜色并把左边最旧的颜色抹掉，这就是滚动窗口的思想。  

#### 代码（Python）  

```python
def hasAllCodes_optimal(s: str, k: int) -> bool:
    """
    最优解：使用滚动窗口 + 位运算，把每个长度为 k 的子串直接映射成整数。
    """
    n = len(s)
    if n < k:
        return False

    need = 1 << k               # 需要的不同子串数量 = 2^k
    seen = set()                # 用集合记录出现过的整数码
    mask = 0                    # 当前窗口对应的整数值，初始为 0
    limit = (1 << k) - 1        # 用来保留低 k 位的掩码，例如 k=3 时 limit=0b111

    for i, ch in enumerate(s):
        # 把新字符加入窗口：左移一位后加上当前字符（'0'->0, '1'->1）
        mask = ((mask << 1) & limit) | (ch == '1')
        # 当窗口长度已经达到 k 时，记录当前码
        if i >= k - 1:
            seen.add(mask)

        # 早停优化：如果已经收集到所有 2^k 种码，直接返回 True
        if len(seen) == need:
            return True

    # 循环结束后，检查是否收齐所有码
    return len(seen) == need
```

> **代码要点解释**  
> - `mask << 1`：相当于在二进制数后面追加一个空位。  
> - `& limit`：把超过 `k` 位的高位全部清零，只保留最近的 `k` 位。  
> - `(ch == '1')`：布尔值 `True/False` 在数值上下会自动转成 `1/0`，所以可以直接与 `mask` 做或运算。  
> - `i >= k - 1`：只有窗口长度已经满 `k` 才开始记录。  

#### 复杂度  

- **时间复杂度**：`O(n)`。  
  - 只遍历一次字符串，每一步的位运算和集合插入都是 **O(1)**（集合的均摊复杂度）。  
- **空间复杂度**：`O(2^k)`。  
  - 仍需保存所有出现过的不同码，但每个码是一个整数（占用更少内存），且 `k ≤ 20` 时最多约一百万个，完全可接受。

## 心得  

- **核心技巧**：滚动窗口 + 位运算（把二进制子串映射为整数）。  
- **适用的题型**：  
  1. “找出所有长度为 K 的子串”类问题（如 LeetCode 567. Permutation in String）。  
  2. “子数组/子串的唯一计数”类（如 LeetCode 1100. Find K-Length Substrings With No Repeating Characters）。  
  3. “固定长度的子序列哈希”类（如 LeetCode 187. Repeated DNA Sequences）。  
- **一句话总结**：**把子串看成整数，用滑动窗口一次算完**，既省时又省空间。

## 反思  

- **第一反应**：直接遍历所有子串，用集合去重——最自然的暴力思路。  
- **最容易踩的坑**：  
  - **边界条件**：`s 长度 < k` 时直接返回 `False`。  
  - **位运算的掩码**：忘记在左移后做 `& limit`，会导致整数位数无限增长，结果错误。  
  - **布尔转整数**：`ch == '1'` 得到 `True/False`，需要确保它能正确当作 `1/0` 使用。  
- **下次第一步**：先思考“是否可以把子串压缩成固定大小的数值”，如果可以，尝试使用**滚动窗口 + 位运算**或**哈希**来避免重复切片。
