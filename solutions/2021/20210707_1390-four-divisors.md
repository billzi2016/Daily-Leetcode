# #1390. 四个约数 / Four Divisors

> 难度：中等 · 标签：Array、Math · [LeetCode 链接](https://leetcode.com/problems/four-divisors/)

---

## 题目（英文原版）

**Description**

Given an integer array nums, return the sum of divisors of the integers in that array that have exactly four divisors. If there is no such integer in the array, return 0.

**Examples**

**Example 1:**

```
Input: nums = [21,4,7]
Output: 32
Explanation: 
21 has 4 divisors: 1, 3, 7, 21
4 has 3 divisors: 1, 2, 4
7 has 2 divisors: 1, 7
The answer is the sum of divisors of 21 only.
```

**Example 2:**

```
Input: nums = [21,21]
Output: 64
```

**Example 3:**

```
Input: nums = [1,2,3,4,5]
Output: 0
```

**Constraints**

- 1 <= nums.length <= 104
- 1 <= nums[i] <= 105

---

## 题目（中文翻译）

给定一个整数数组（integer array）`nums`，返回数组中 **恰好拥有四个约数（divisors）** 的整数的所有约数之和。如果数组中不存在这样的整数，返回 `0`。

Example 1:  
Input: `nums = [21,4,7]`  
Output: `32`  
**Explanation:**  
- `21` 有 4 个约数：`1, 3, 7, 21`  
- `4` 有 3 个约数：`1, 2, 4`  
- `7` 有 2 个约数：`1, 7`  
答案只取 `21` 的约数之和。

Example 2:  
Input: `nums = [21,21]`  
Output: `64`  
**Explanation:**  
每个 `21` 都有 4 个约数，`1 + 3 + 7 + 21 = 32`，两者相加得到 `64`。

Example 3:  
Input: `nums = [1,2,3,4,5]`  
Output: `0`  
**Explanation:**  
数组中没有任何整数恰好拥有四个约数，故返回 `0`。

约束条件：

- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^5`

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把每个数字的所有约数都找出来**，然后看约数的个数是不是恰好 4。  
- **约数**就像是“能够整除这个数的因子”。比如 21 的约数有 1、3、7、21。  
- 为了得到约数，我们可以把「从 1 到这个数」逐个尝试，能整除的就是约数。  
- 这相当于把每个数字当成一本厚厚的字典，逐页翻，看哪一页的页码（i）能被它整除。

> **为什么一定能找全**：如果 `i` 能整除 `num`，必定在 1~`num` 之间；遍历完整个区间自然不会漏掉任何约数。

**时间复杂度**  
- 对每个数组元素 `num`，我们都要遍历 `1 … num`，最坏情况是 `num = 10⁵`。  
- 若数组长度为 `n`，总的时间就是 `O(n * max(nums))`。  
- 用大白话说，就是「每个数都要检查一遍所有可能的除数」，如果 `n=10⁴`、`max=10⁵`，大约要跑 **10⁹** 次循环，明显太慢。

**空间复杂度**  
- 只用常数个变量保存计数和求和，`O(1)`。

#### 代码（Python）

```python
from typing import List

def sumFourDivisors(nums: List[int]) -> int:
    total = 0                         # 最终答案

    for num in nums:                  # 逐个处理数组里的数
        divisors = []                 # 暂存当前数的约数
        for i in range(1, num + 1):  # 暴力遍历 1~num
            if num % i == 0:         # 能整除说明 i 是约数
                divisors.append(i)

        if len(divisors) == 4:       # 正好有 4 个约数才算
            total += sum(divisors)   # 把约数之和累加到答案

    return total
```

#### 复杂度

- **时间复杂度**：`O(n * max(nums))`  
  > “O” 表示上限，意思是最坏情况下要跑这么多次循环。这里相当于每个数都要检查它的全部可能除数，数量非常大。

- **空间复杂度**：`O(1)`（不计返回值的额外空间）  
  > 只用了几个计数器和一个临时列表，大小不随输入规模增长。

### 2. 最优解

#### 思路  

从暴力解可以看出，**瓶颈在于遍历所有可能的除数**。  
实际上，约数总是成对出现：如果 `i` 是约数，那么 `num // i` 也是约数。  
因此只需要检查到 **√num**（平方根）即可把所有约数找齐。  

进一步思考：我们只关心约数个数恰好为 4 的情况。  
四个约数只能出现两种形态：

1. **两个不同的质数相乘**：`num = p * q`（`p ≠ q`，且 `p, q` 都是质数）。  
   - 约数是 `{1, p, q, p*q}`，恰好四个。  

2. **一个质数的立方**：`num = p³`（`p` 为质数）。  
   - 约数是 `{1, p, p², p³}`，也是四个。  

只要能快速判断一个数是否符合上面两种形式，就能在 **O(√max)** 的时间内得到答案。  
实现思路：

1. **预处理**：使用埃拉托斯特尼筛法（Sieve of Eratosthenes）在 `1 … 10⁵` 范围内生成所有质数，或者更进一步生成「最小质因子」数组 `spf`（smallest prime factor），这样可以在 **O(log n)** 时间内完成因子分解。  
2. 对每个 `num`：  
   - 用 `spf` 分解出它的质因子及对应的指数。  
   - 判断是否满足「两个不同质数，各出现一次」或「一个质数出现三次」的模式。  
   - 若满足，直接利用数学公式计算四个约数的和：  
     - `p * q` → `1 + p + q + p*q`  
     - `p³`    → `1 + p + p² + p³`  
   - 累加到答案中。

这样每个数的处理时间是 **O(log num)**，整体时间约为 `O(n log max)`，远快于暴力的 `O(n * max)`。  
在本题的约束下，`n ≤ 10⁴`、`max ≤ 10⁵`，该方案运行毫秒级。

> **类比**：把「最小质因子」想象成一本“数字-它的第一个质因子”字典，查一次就能知道该怎么继续拆分，省去遍历所有可能的除数。

#### 代码（Python）

```python
from typing import List
import math

def sumFourDivisors(nums: List[int]) -> int:
    MAX = 100_000                     # 题目给的上界
    # ---------- 1. 生成最小质因子表 ----------
    spf = list(range(MAX + 1))        # spf[i] = i 默认是自身（即质数）
    for i in range(2, int(math.isqrt(MAX)) + 1):
        if spf[i] == i:               # i 是质数
            for j in range(i * i, MAX + 1, i):
                if spf[j] == j:       # 只写入第一次出现的因子
                    spf[j] = i

    # ---------- 2. 辅助函数：判断并返回四个约数之和 ----------
    def four_div_sum(num: int) -> int:
        """如果 num 恰好有四个约数，返回这些约数的和；否则返回 0"""
        # 用 spf 分解因子
        factors = {}
        x = num
        while x > 1:
            p = spf[x]
            factors[p] = factors.get(p, 0) + 1
            x //= p

        # 情形 1：两个不同质数，各出现一次
        if len(factors) == 2 and all(exp == 1 for exp in factors.values()):
            p, q = factors.keys()
            return 1 + p + q + p * q

        # 情形 2：一个质数的立方
        if len(factors) == 1:
            p, exp = next(iter(factors.items()))
            if exp == 3:                # p³
                return 1 + p + p * p + p * p * p

        # 其余情况不满足恰好四个约数
        return 0

    # ---------- 3. 主循环 ----------
    ans = 0
    for num in nums:
        ans += four_div_sum(num)
    return ans
```

#### 复杂度

- **时间复杂度**：`O(n log MAX)`  
  > `log MAX` 来自因子分解的循环次数（每次除以最小质因子）。与暴力解的 `O(n * MAX)` 相比，前者只需要几千次操作，速度快得多。

- **空间复杂度**：`O(MAX)`  
  > 用来存放最小质因子表的数组大小为 `MAX + 1 ≈ 10⁵`，相当于几百 KB 的内存，完全可以接受。

## 心得

- 本题核心在于**快速判断一个整数的约数个数是否为 4**，而不是逐个枚举约数。  
- 关键技巧是**利用数的质因子结构**（两个不同质数或一个质数的立方），配合**筛法预处理最小质因子**实现近乎常数时间的判定。  
- 这种“质因子模式匹配”技巧同样适用于：  
  1. **`Number of Divisors`**（判断约数个数是否为奇数等）  
  2. **`Prime and Power Numbers`**（判断是否为质数的幂）  
  3. **`Product of Two Primes`** 类题目（如判断数是否为半素数）。

> **解题钥匙**：先把数拆成质因子，再看这些因子能否组合出恰好四个约数。

## 反思

- **第一反应**：直接遍历所有可能的除数去统计约数，想当然地认为能通过。  
- **最容易踩的坑**：  
  - 没有提前终止计数：一旦约数超过 4，就可以直接放弃后续搜索。  
  - 忽视 `1` 的特殊性：`1` 只有 1 个约数，永远不满足条件。  
  - 对大数使用 O(n) 遍历会导致超时。  
- **下次类似题目**：第一步先**思考约数的结构**（是否能用质因子描述），如果可以，就考虑 **筛法 / 预处理** 来把因子分解的成本压到 `O(log n)`，再根据结构直接计算答案。这样既能保证正确性，又能避免不必要的枚举。
