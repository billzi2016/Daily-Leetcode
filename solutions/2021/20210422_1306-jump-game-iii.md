# #1306. 跳跃游戏 III / Jump Game III

## 题目（英文原版）

**Description**

Given an array of non-negative integers arr, you are initially positioned at start index of the array. When you are at index i, you can jump to i + arr[i] or i - arr[i], check if you can reach any index with value 0.
Notice that you can not jump outside of the array at any time.

**Examples**

**Example 1:**

```
Input: arr = [4,2,3,0,3,1,2], start = 5
Output: true
Explanation: 
All possible ways to reach at index 3 with value 0 are: 
index 5 -> index 4 -> index 1 -> index 3 
index 5 -> index 6 -> index 4 -> index 1 -> index 3
```

**Example 2:**

```
Input: arr = [4,2,3,0,3,1,2], start = 0
Output: true 
Explanation: 
One possible way to reach at index 3 with value 0 is: 
index 0 -> index 4 -> index 1 -> index 3
```

**Example 3:**

```
Input: arr = [3,0,2,1,2], start = 2
Output: false
Explanation: There is no way to reach at index 1 with value 0.
```

**Constraints**

- 1 <= arr.length <= 5 * 104
- 0 <= arr[i] < arr.length
- 0 <= start < arr.length

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：从 `start` 位置出发，**每次都尝试两种可能的跳法**——向左跳 `i - arr[i]`，向右跳 `i + arr[i]`。只要跳到的下标在数组范围内，就继续往下走，直到找到值为 `0` 的位置或者所有能到达的下标都走完为止。

这相当于在一个“图”里做遍历：

- **节点**：数组的下标 `i`（0 … n‑1）。
- **边**：从 `i` 可以到达的两个下标 `i - arr[i]`、`i + arr[i]`（如果它们合法）。

遍历的过程可以用 **深度优先搜索（DFS）** 或 **递归** 来实现。  
为了防止走回头路（比如 `i -> j -> i` 形成死循环），需要记录已经访问过的下标，就像查字典时记住已经翻到的页码一样，这里用一个 `visited` 集合来记。

> **为什么正确**  
> 我们把所有可能的跳法都枚举出来，只要有一条路径能抵达值为 `0` 的下标，搜索必定会在某一步发现它。因此只要搜索结束后没有找到 `0`，说明不存在这样的一条路径，答案就是 `false`。

#### 代码（Python）

```python
from typing import List

def canReach_bruteforce(arr: List[int], start: int) -> bool:
    n = len(arr)
    visited = set()                     # 记录已经访问过的下标，防止循环

    def dfs(i: int) -> bool:
        # 越界或已经访问过，直接返回 False
        if i < 0 or i >= n or i in visited:
            return False
        # 到达值为 0 的位置，成功
        if arr[i] == 0:
            return True

        visited.add(i)                  # 标记为已访问

        # 递归尝试向左、向右两种跳法
        left = dfs(i - arr[i])
        right = dfs(i + arr[i])
        return left or right

    return dfs(start)
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  虽然看起来每个位置会被递归两次（左、右），但因为每个下标只会被访问一次（`visited` 把重复访问剪掉），最多遍历 `n` 个下标，所以时间随数组长度线性增长。  
  用大白话说，就是如果数组有 10,000 个元素，最坏也只会检查这 10,000 次。

- **空间复杂度**：`O(n)`  
  递归栈最深可能达到 `n`（比如每次都只能往同一个方向跳），再加上 `visited` 集合也会保存最多 `n` 个下标，所以使用的额外空间与数组长度成正比。

### 2. 最优解

#### 思路  

暴力 DFS 的瓶颈在 **递归深度** 和 **函数调用的额外开销**，尤其在 Python 中递归层数受限，容易导致 `RecursionError`。  
另外，DFS 会一次把一条路径走到底才回溯，若目标 `0` 位于“较浅”的层次，仍要走完深层的分支才会返回，效率不高。

**广度优先搜索（BFS）** 能一次性遍历所有**同层**的节点，层数越小就越先被检查。因为我们只关心“是否能到达”，不在乎具体的路径长度，BFS 能更早发现答案，也避免了深递归。

实现要点：

1. **队列**（`collections.deque`）保存待访问的下标，先入先出保证同层节点一起处理。  
2. 同样需要 **visited** 集合防止重复入队。  
3. 每次弹出一个下标 `i`，检查 `arr[i] == 0`，若是直接返回 `True`。  
4. 否则计算左右两个可跳到的下标 `next_idx = i ± arr[i]`，若合法且未访问就加入队列。

> **核心数据结构**  
> - **队列**：像排队买票一样，先来的先服务，保证层序遍历。  
> - **哈希表（集合）**：类似字典查词，`key` 是下标，`value` 是“是否已看过”，查找、插入时间都非常快（常数级），所以不增加额外的时间负担。

#### 代码（Python）

```python
from collections import deque
from typing import List

def canReach_bfs(arr: List[int], start: int) -> bool:
    n = len(arr)
    visited = [False] * n          # 用列表代替集合，省空间且 O(1) 访问
    q = deque([start])             # 初始化队列，只放起点
    visited[start] = True

    while q:
        i = q.popleft()            # 取出当前层的一个位置
        if arr[i] == 0:            # 找到值为 0，成功
            return True

        # 计算两种可能的下一跳
        for nxt in (i + arr[i], i - arr[i]):
            if 0 <= nxt < n and not visited[nxt]:
                visited[nxt] = True
                q.append(nxt)      # 加入队列，待后续遍历

    # 队列空了还没找到 0，说明不可达
    return False
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  每个下标最多入队一次、出队一次，检查常数次左右跳的合法性，所以整体仍是线性时间。相比递归版，省去了函数调用的额外开销，实际运行更快。

- **空间复杂度**：`O(n)`  
  `visited` 数组占 `n` 个布尔值，队列最坏情况下也可能同时保存 `n` 个下标（比如所有位置都可以到达），所以空间仍是线性。

## 心得

- **核心技巧**：把数组看成图，用 **BFS** 在图上层序遍历。  
- **适用的题型**：  
  1. “从起点能否到达目标”类问题（如 *Jump Game II*、*Reachable Nodes With Restrictions*）。  
  2. “最短路径/最少步数”类问题（如 *Open the Lock*、*Shortest Path in Binary Matrix*）。  
- **解题钥匙**：**把跳跃关系抽象成图的邻接关系，层序遍历即可快速判断可达性**。

## 反思

- **第一反应**：看到“可以向左/向右跳”，立刻想到“遍历所有可能的路径”。  
- **最容易踩的坑**：  
  - **越界检查**：`i ± arr[i]` 必须先判断是否在 `[0, n-1]`，否则会访问非法下标。  
  - **重复访问**：忘记 `visited` 会导致无限循环（例如 `i -> j -> i`）。  
  - **递归深度**：在 Python 中递归层数超过约 1000 会报错，需要改用显式栈或 BFS。  
- **下次类似题的第一步**：先把“位置之间的跳转关系”画成图，决定用 **BFS**（层序）还是 **DFS**（深度）来遍历，再记得加上“已访问”标记防止循环。
