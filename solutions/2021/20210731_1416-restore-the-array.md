# #1416. 恢复数组 / Restore The Array

> 难度：困难 · 标签：String、Dynamic Programming · [LeetCode 链接](https://leetcode.com/problems/restore-the-array/)

---

## 题目（英文原版）

**Description**

A program was supposed to print an array of integers. The program forgot to print whitespaces and the array is printed as a string of digits s and all we know is that all integers in the array were in the range [1, k] and there are no leading zeros in the array.
Given the string s and the integer k, return the number of the possible arrays that can be printed as s using the mentioned program. Since the answer may be very large, return it modulo 109 + 7.

**Examples**

**Example 1:**

```
Input: s = "1000", k = 10000
Output: 1
Explanation: The only possible array is [1000]
```

**Example 2:**

```
Input: s = "1000", k = 10
Output: 0
Explanation: There cannot be an array that was printed this way and has all integer >= 1 and <= 10.
```

**Example 3:**

```
Input: s = "1317", k = 2000
Output: 8
Explanation: Possible arrays are [1317],[131,7],[13,17],[1,317],[13,1,7],[1,31,7],[1,3,17],[1,3,1,7]
```

**Constraints**

- 1 <= s.length <= 105
- s consists of only digits and does not contain leading zeros.
- 1 <= k <= 109

**示例**  

*示例 1*  
```
Input: s = "1000", k = 10000
Output: 1

```

*示例 2*

```
Input: s = "1000", k = 10
```

```
[13,1,7],
[1,31,7],
[1,3,17],

```

**约束条件**  

- `1 <= s.length <= 10^5`
- `s` 仅由数字组成，且不包含前导零。
- `1 <= k <= 10^9`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把字符串 `s` 看成若干个 **子串**，每个子串代表数组中的一个整数。  
我们可以从左到右逐个尝试：

1. 把前 `1` 位切下来，判断它是否在 `[1, k]` 范围且没有前导零；  
2. 再把后面的部分递归地继续切分；  
3. 把所有合法的切分方式累计起来。

这和我们平时把一根绳子剪成若干段的过程一样，只是每段的长度必须满足「对应的数字 ≤ k 且没有前导零」这两个条件。

> **数据结构类比**：  
> 这里用到的只是 **递归栈**（相当于我们在纸上画的「树」），不需要哈希表、队列等高级结构。递归调用本身会把每一步的「已切好的子串」暂时保存起来，就像把已经剪好的绳段放进一个小盒子，等到整根绳子全部剪完再一起数一数。

**为什么一定正确？**  
只要我们把所有可能的切法都枚举一遍，并且每一次切分都严格检查「是否在 `[1,k]`」和「是否有前导零」，最后计数的总和必然等于所有合法数组的数量——因为没有任何合法情况会被遗漏，也没有不合法的情况会被计入。

#### 代码（Python）

```python
MOD = 10**9 + 7

def numberOfArrays_bruteforce(s: str, k: int) -> int:
    n = len(s)

    # 递归函数：从下标 i 开始，返回剩余部分的合法切分数
    def dfs(i: int) -> int:
        # 已经走到字符串末尾，说明一种合法切法完成
        if i == n:
            return 1

        # 以 0 开头的子串不合法，直接返回 0
        if s[i] == '0':
            return 0

        total = 0
        # 枚举当前数字的长度，最长不超过剩余字符数
        for j in range(i, n):
            # 把 s[i:j+1] 转成整数
            num = int(s[i:j+1])
            if num > k:               # 超出上界，后面的更长子串只会更大，直接退出循环
                break
            total = (total + dfs(j + 1)) % MOD   # 累计子问题的答案并取模
        return total

    return dfs(0)
```

> **关键行解释**  
> - `if s[i] == '0': return 0` → 防止出现前导零的非法数字。  
> - `if num > k: break` → 一旦当前子串已经超过 `k`，更长的子串必定更大，直接剪枝。  
> - `total = (total + dfs(j + 1)) % MOD` → 把子问题的结果累加，同时做模运算防止整数爆炸。

#### 复杂度

- **时间复杂度**：`O(2^n)`（指数级）。  
  想象每个字符后面都可能「切」或「不切」——类似二叉树的每层有两条分支，深度为 `n`，所以总的递归路径数大约是 `2^n`。这在 `n=10^5` 时根本不可接受。

- **空间复杂度**：`O(n)`（递归栈的最大深度）。  
  最坏情况下递归会沿着字符串一直向下走，栈深度等于字符串长度。

### 2. 最优解

#### 思路  

暴力解的主要瓶颈是**大量重复计算**：同一个子串的切分方式会被多次递归求值。  
我们可以把「从位置 i 开始的子串有多少种合法切法」记下来，下次再需要时直接取用——这就是**动态规划**（Dynamic Programming, DP）的思想。

**步骤拆解**  

1. **定义状态**  
   `dp[i]` 表示「从下标 `i` 开始，到字符串末尾的子串，有多少种合法分割方式」。答案最终是 `dp[0]`。  
   为了方便边界处理，额外设 `dp[n] = 1`（空串只有一种「不切」的方式）。

2. **状态转移**  
   从左到右看似很自然，但如果我们从右往左计算 `dp`，转移会更简洁：  
   - 固定起点 `i`，尝试把 `s[i…j]`（`j ≥ i`）当作当前的一个整数。  
   - 若 `s[i] == '0'`，说明以 `0` 开头的数字非法，直接 `dp[i] = 0`。  
   - 否则，把 `s[i…j]` 转成整数 `num`，只要 `num ≤ k`，就可以把后面的分割方式 `dp[j+1]` 加到 `dp[i]` 中。  
   - 当 `num > k` 时，进一步增大 `j` 只会让数字更大，直接停止循环（**剪枝**）。

3. **为什么是 O(n·log₁₀k)？**  
   `k ≤ 10^9`，最多只有 **10 位**。所以在每个起点 `i`，我们最多只需要检查 `10` 个长度的子串（或者更少，如果剩余字符不足 10 位）。  
   整体时间复杂度就是 `O(n * 10) = O(n)`，线性可接受。  
   空间上只需要保存 `dp` 数组，大小为 `n+1`，即 `O(n)`。

4. **取模**  
   题目要求答案对 `10^9+7` 取模。为了防止中间相加时溢出，每一步累加后立即 `% MOD`。

> **类比**：  
> 把 `dp` 想象成一本「分割手册」，第 `i` 页记录了「从第 `i` 位开始」的所有合法切法数。当我们在第 `i` 位决定「取几位做一个数」时，只需要查阅「后面几页」的手册（`dp[j+1]`），不必重新算一遍。

#### 代码（Python）

```python
MOD = 10**9 + 7

def numberOfArrays(s: str, k: int) -> int:
    n = len(s)
    dp = [0] * (n + 1)          # dp[i] 表示从 i 开始的子串的合法切分数
    dp[n] = 1                    # 空串只有一种“什么也不切”的方式

    # 为了快速判断子串是否超过 k，预先算出 k 的位数上限
    max_len = len(str(k))        # 例如 k=10000 -> max_len=5

    # 从后往前填表
    for i in range(n - 1, -1, -1):
        if s[i] == '0':          # 前导零非法
            dp[i] = 0
            continue

        num = 0
        # 只检查最多 max_len 位，且不能越界
        for j in range(i, min(n, i + max_len)):
            num = num * 10 + int(s[j])   # 手动拼接数字，避免切片再转 int 的开销
            if num > k:                  # 超出上界，后面的更长子串必定更大
                break
            dp[i] = (dp[i] + dp[j + 1]) % MOD

    return dp[0]
```

> **关键行解释**  
> - `max_len = len(str(k))` → `k` 最多有多少位，限制循环次数。  
> - `num = num * 10 + int(s[j])` → 逐位构造当前数字，避免每次 `int(s[i:j+1])` 的切片开销。  
> - `if num > k: break` → 发现已经超过 `k`，立即停止扩展子串长度（剪枝）。  
> - `dp[i] = (dp[i] + dp[j + 1]) % MOD` → 把「从 j+1 开始」的合法方式累加到「从 i 开始」的答案中，并取模。

#### 复杂度

- **时间复杂度**：`O(n * log10(k))` → 实际上 ≤ `O(10·n)`，即线性时间。  
  与暴力解相比，指数级的递归被「记忆化」成一次遍历，快了天差地别。

- **空间复杂度**：`O(n)` → 只需要保存 `dp` 数组和常数级的临时变量。

## 心得

- **核心技巧**：**从右往左的动态规划 + 长度剪枝**。  
- **适用场景**：  
  1. **数字字符串切分**（如「把数字字符串拆成不超过 K 的子数」）  
  2. **带约束的分割计数**（如「把字符串拆成字典中的单词数」）  
  3. **区间限制的子序列计数**（如「子序列和 ≤ K」的 DP）  
- **一句话总结**：**把「从当前位置开始的子问题」记下来，利用“数字长度上限”提前结束循环，整个过程就是“记忆化 + 剪枝”。**

## 反思

- **第一反应**：看到“没有空格的数字串”和“每个数在 `[1,k]`”，自然想到“把字符串随意切”，于是想到了递归枚举。  
- **最容易踩的坑**：  
  1. **前导零**：`"0"` 不能单独成数，也不能作为多位数的开头。  
  2. **大数溢出**：直接把子串转成 `int` 可能导致 Python 仍然可以处理，但在其他语言会溢出；因此建议逐位累加并随时比较 `k`。  
  3. **取模时机**：每一步累加后都要 `% MOD`，否则中间结果会爆炸。  
- **下次类似题目**：第一步先思考「是否可以把问题拆成子问题」——如果答案是“可以”，就立刻写出 **dp[i]** 的定义，然后检查**状态转移的边界**（如长度上限、前导零），最后再考虑**剪枝**和**取模**。这样可以快速从暴力到最优的转变。
