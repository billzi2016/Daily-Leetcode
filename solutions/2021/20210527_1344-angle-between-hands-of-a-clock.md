## 题目（英文原版）

**Description**

Given two numbers, hour and minutes, return the smaller angle (in degrees) formed between the hour and the minute hand.
Answers within 10-5 of the actual value will be accepted as correct.

**Examples**

**Example 1:**

```
Input: hour = 12, minutes = 30
Output: 165
```

**Example 2:**

```
Input: hour = 3, minutes = 30
Output: 75
```

**Example 3:**

```
Input: hour = 3, minutes = 15
Output: 7.5
```

**Constraints**

- 1 <= hour <= 12
- 0 <= minutes <= 59

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把时钟的每一根指针都**逐格**（每分钟一格）走一遍，记录下它们各自指向的角度，然后算两根指针之间的差值，取较小的那一个。

- **时针**：在 12 小时里转一圈（360°），所以每小时走 30°。但是时针并不是每到整点才转，它会随 **分钟** 的变化而慢慢移动：每走 1 分钟，时针前进 `30° / 60 = 0.5°`。可以把它想成「钟表里的小乌龟」——每走一分钟只爬半度。
- **分针**：每分钟走 6°（因为 60 分钟走满 360°），相当于「每分钟跳一格」的指针。

把这两个指针的角度算出来后，用绝对值求出它们的差，再和 `360° - 差值` 比较，取最小的那个，就是题目要求的「较小的夹角」。

> 这里的「暴力」并不是指时间复杂度很高，而是指**一步一步、直观地模拟指针的运动**，不去思考有没有更简洁的公式。即使这样做的时间复杂度已经是常数（因为最多只会循环 60 次），它仍然帮助我们理清「时针会受分钟影响」这件事。

#### 代码（Python）

```python
def angle_brute_force(hour: int, minutes: int) -> float:
    """
    暴力思路：逐分钟模拟时针和分针的位置，最后算出最小夹角。
    """
    # 1. 把 hour 转成 0~11 的范围，12 点视作 0 点
    hour = hour % 12

    # 2. 计算时针的角度
    #    每小时 30°，每分钟 0.5°
    hour_angle = hour * 30 + minutes * 0.5   # 关键：分钟会影响时针

    # 3. 计算分针的角度
    #    每分钟 6°
    minute_angle = minutes * 6

    # 4. 两根指针的差值（绝对值）
    diff = abs(hour_angle - minute_angle)

    # 5. 取较小的那个夹角（因为角度是环形的）
    return min(diff, 360 - diff)
```

#### 复杂度

- **时间复杂度**：`O(1)` — 只进行几次算术运算，和输入规模无关。即使我们把「逐分钟模拟」写成循环（最多 60 次），也是常数级别的。
- **空间复杂度**：`O(1)` — 只用了几个变量来保存角度，没有额外的数组或递归栈。

### 2. 最优解

#### 思路  

从暴力解可以看到，**核心难点**是「时针会随分钟移动」这一点。我们完全可以用**公式**直接算出两个指针的角度，而不必真的去「走」每一分钟。这样做的好处是：

1. **避免循环**（即使循环本身是常数），让代码更简洁、更易读；
2. **直接得到答案**，时间和空间都是最小的 `O(1)`。

下面一步步推导公式：

1. **时针的角度**  
   - 整点时（如 3:00），时针指向 `hour * 30°`（因为每小时 30°）。  
   - 每过去 1 分钟，时针再前进 `0.5°`（30° / 60）。  
   - 所以 `hour_angle = (hour % 12) * 30 + minutes * 0.5`。

2. **分针的角度**  
   - 每分钟转 6°（360° / 60），所以 `minute_angle = minutes * 6`。

3. **两指针的夹角**  
   - 先算绝对差 `diff = |hour_angle - minute_angle|`。  
   - 由于时钟是圆形的，真正的最小夹角应该是 `diff` 与 `360 - diff` 之间的较小者。  

这就是完整的**最优解**，只用了三行算式。

> 类比：如果把时钟想象成一条 **圆形跑道**，我们只需要知道两个人（时针、分针）分别站在跑道上的哪一个刻度（角度），然后直接量他们之间的最短距离，而不必让他们一步步跑过去。

#### 代码（Python）

```python
def angle_of_clock_hands(hour: int, minutes: int) -> float:
    """
    最优解：利用数学公式直接求出时针和分针的角度，随后计算最小夹角。
    """
    # 1️⃣ 把 12 点视作 0 点，防止 hour 为 12 时算出 360°
    hour = hour % 12

    # 2️⃣ 计算时针角度：每小时 30° + 每分钟 0.5°
    hour_angle = hour * 30 + minutes * 0.5   # 关键：分钟对时针有影响

    # 3️⃣ 计算分针角度：每分钟 6°
    minute_angle = minutes * 6

    # 4️⃣ 夹角的绝对差
    diff = abs(hour_angle - minute_angle)

    # 5️⃣ 取最小的那条弧（因为圆有两条路径）
    return min(diff, 360 - diff)
```

#### 复杂度

- **时间复杂度**：`O(1)` — 只做了常数次的加减乘除，和输入规模无关。相比暴力解，它省去了「思考每分钟位置」的过程，真正做到“一次算完”。
- **空间复杂度**：`O(1)` – 只用了几个局部变量。

## 心得

- **核心技巧**：**把时钟的角度转化为数学公式**，尤其要注意「时针会随分钟微调」这一细节。
- **适用的题型**  
  1. 任意**时钟角度**类题（如求两次时间之间的角度差）。  
  2. **旋转坐标系**或**角度比较**的几何题（如旋转指针、时针分针的相对位置）。  
  3. 需要把**连续运动**离散化为公式的场景（如汽车行驶里程、匀速运动的位移）。
- **一句话总结**：**先把“指针随时间微调”写成公式，再用绝对差和 360° 取最小**，就是这道题的解题钥匙。

## 反思

- **第一反应**：看到“时针”和“分针”，立刻想到它们分别每小时走 30°、每分钟走 6°，但容易忘记「时针会随分钟而动」。
- **最容易踩的坑**  
  - 忽略 `hour = 12` 时应视为 `0`（否则会得到 360° 而不是 0°）。  
  - 只计算 `|hour_angle - minute_angle|` 而不取 `360 - diff`，会在差值大于 180° 时得到错误答案。  
  - 输入的 `minutes` 可能是 `0`，此时要确保时针仍然受到 `hour` 的影响（例如 12:00 的角度是 0°）。
- **下次第一步**：先**把每根指针的角度写成公式**（考虑小时、分钟的权重），再**比较两角度的差值并取最小**。这样可以避免遗漏细节，快速得到正确解法。
