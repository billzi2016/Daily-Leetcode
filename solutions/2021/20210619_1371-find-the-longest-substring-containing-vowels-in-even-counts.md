# #1371. 寻找元音出现偶数次数的最长子字符串 / Find the Longest Substring Containing Vowels in Even Counts

> 难度：中等 · 标签：Hash Table、String、Bit Manipulation、Prefix Sum · [LeetCode 链接](https://leetcode.com/problems/find-the-longest-substring-containing-vowels-in-even-counts/)

---

## 题目（英文原版）

**Description**

Given the string s, return the size of the longest substring containing each vowel an even number of times. That is, 'a', 'e', 'i', 'o', and 'u' must appear an even number of times.

**Examples**

**Example 1:**

```
Input: s = "eleetminicoworoep"
Output: 13
Explanation: The longest substring is "leetminicowor" which contains two each of the vowels: e, i and o and zero of the vowels: a and u.
```

**Example 2:**

```
Input: s = "leetcodeisgreat"
Output: 5
Explanation: The longest substring is "leetc" which contains two e's.
```

**Example 3:**

```
Input: s = "bcbcbc"
Output: 6
Explanation: In this case, the given string "bcbcbc" is the longest because all vowels: a, e, i, o and u appear zero times.
```

**Constraints**

- 1 <= s.length <= 5 x 10^5
- s contains only lowercase English letters.

## 题目（中文翻译）

**描述**  
给定字符串 `s`，返回满足每个元音字母出现偶数次的最长子字符串（substring）的长度。即字符 `'a'、'e'、'i'、'o'、'u'` 必须各出现偶数次（包括 0 次）。

**示例 1**

> **输出**: `13`  
> **解释**: 最长的满足条件的子字符串是 `"leetminicowor"`，其中元音 `e、i、o` 各出现两次，`a、u` 出现零次。

**示例 2**  
> **输入**: `s = "leetcodeisgreat"`  
> **输出**: `5`  
> **解释**: 最长的满足条件的子字符串是 `"leetc"`，其中元音 `e` 出现两次。

> **输出**: `6`

**约束条件**  
- `1 <= s.length <= 5 × 10^5`  
- `s` 仅由小写英文字母组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**枚举所有子串**，统计子串里每个元音字母 (`a, e, i, o, u`) 出现的次数，检查它们是否都是偶数。如果是，就更新答案为当前子串的长度。  

- **用到的数据结构**：  
  - `dict`（字典）或数组来记录五个元音的出现次数。可以把它想成一本小字典，`key` 是元音字母，`value` 是它在当前子串里出现了几次。  
- **为什么正确**：  
  - 我们检查了**每一种可能的子串**，只要子串满足“所有元音出现次数为偶数”，就一定会被考虑到。最终取最长的那一个自然就是答案。  
- **复杂度分析（大白话）**：  
  - 枚举子串需要两层循环：外层选左边界 `i`，内层选右边界 `j`。左边界可以是 `0 … n-1`（共 `n` 种），右边界可以是 `i … n-1`（平均约 `n/2` 种），所以总共要检查大约 `n·n/2 ≈ n²/2` 次子串，用 **O(n²)** 表示。  
  - 对每个子串我们要遍历一次子串内部统计元音，这又是 **O(length)**，最坏情况下也是 `O(n)`，于是整体时间是 **O(n³)**，但我们可以在遍历子串的同时即时更新计数，使每个子串的检查变成 **O(1)**（只要在加入一个字符时更新计数），这样整体时间降到 **O(n²)**。  
  - 空间上只需要存放五个计数，常数级别，记作 **O(1)**。

#### 代码（Python）

```python
def findTheLongestSubstring_bruteforce(s: str) -> int:
    n = len(s)
    ans = 0                     # 当前找到的最长合法子串长度
    vowels = {'a', 'e', 'i', 'o', 'u'}

    # i 为子串左端点（包含），j 为右端点（包含）
    for i in range(n):
        cnt = {v: 0 for v in vowels}   # 统计从 i 开始的子串里每个元音出现次数
        for j in range(i, n):
            ch = s[j]
            if ch in vowels:           # 只关心元音，其他字符直接跳过
                cnt[ch] += 1           # 计数 +1

            # 检查当前子串是否满足“所有元音出现次数为偶数”
            if all(c % 2 == 0 for c in cnt.values()):
                ans = max(ans, j - i + 1)   # 更新最长长度

    return ans
```

> **注**：这段代码已经把「统计」和「检查」合在同一次循环里，避免了再次遍历子串，时间已经是 **O(n²)**。

#### 复杂度

- **时间复杂度**：`O(n²)`  
  - 想象一下，你站在一条长长的队伍前面，每次从左往右挑一个人作为起点，然后往后看每一个人，这相当于两层循环，所以是 `n` 乘 `n`，即平方级别。
- **空间复杂度**：`O(1)`  
  - 只用了一个大小固定的字典（5 个键），不随字符串长度增长。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**两层循环**，每次都要重新遍历子串或更新计数，导致 `O(n²)`。我们需要把“检查子串是否合法”的过程 **一次性** 完成，而不是在每个子串上重复工作。

下面一步步推导优化思路：

1. **把“出现次数是奇数还是偶数”抽象成 0/1**  
   - 对于每个元音，只关心它出现的次数是 **奇** 还是 **偶**。  
   - 用 **1** 表示奇数，**0** 表示偶数。这样每个元音只需要 1 位二进制来保存状态。

2. **用位掩码（bitmask）把 5 个状态压进一个整数**  
   - 把 `a, e, i, o, u` 按顺序对应二进制的第 `0~4` 位。  
   - 例如，当前出现了 3 个 `a`（奇数）和 2 个 `e`（偶数），其掩码是 `00001`（只第 0 位为 1）。

3. **前缀异或（prefix xor）**  
   - 定义 `mask[i]` 为 **从字符串开头到第 i-1 个字符**（即前 i 个字符）对应的位掩码。  
   - 当我们往后走一个字符 `c` 时，只要 `c` 是元音，就把对应的那一位 **翻转**（异或 1），非元音则保持不变。  
   - 关键点：**如果两个位置的 mask 相同，则它们之间的子串里每个元音的奇偶性都相同，即出现偶数次**。因为相同的掩码说明从左端点到右端点的累计翻转次数是偶数次，等价于“偶数”。

4. **把“相同掩码出现的最早位置”记下来**  
   - 当我们遍历字符串，计算 `mask` 的同时，如果当前 `mask` **第一次出现**，把它的下标记下来（因为更早的下标可以得到更长的子串）。  
   - 若 `mask` 已经出现过，则当前下标 `i` 与最早出现下标 `first[mask]` 之间的距离 `i - first[mask]` 就是一个合法子串的长度。取最大的即可。

5. **为什么要记录最早出现位置**  
   - 想象有两次出现相同掩码：一次在位置 2，另一次在位置 10。显然，`10 - 2 = 8` 比 `10 - 5`（若 5 是后面一次出现）更长。于是我们只需要记住 **第一次出现** 的位置。

6. **实现细节**  
   - 使用 Python 的 `dict` 把 `mask -> 最早出现的下标` 保存下来，初始化时把掩码 `0`（所有元音出现偶数）映射到下标 `0`（空前缀）。  
   - 遍历字符时，用 `ord(ch)` 快速判断是否是元音并找对应位。  
   - 整个过程只需一次遍历，时间 **O(n)**，空间最多保存 `2^5 = 32` 种不同的掩码，**O(1)**。

> **类比**：把掩码想成一把 5 位的“钥匙”。我们在走路（遍历字符）时，偶尔会把钥匙上的某一位翻转（遇到元音），如果两次路过时钥匙长得一模一样，那这段路之间的所有钥匙位都翻转了偶数次，正好满足“每个元音出现偶数次”。

#### 代码（Python）

```python
def findTheLongestSubstring(s: str) -> int:
    # 元音对应的位编号，a->0, e->1, i->2, o->3, u->4
    vowel_to_bit = {'a': 0, 'e': 1, 'i': 2, 'o': 3, 'u': 4}

    first_pos = {0: 0}        # mask -> 第一次出现的下标（前缀长度），0 表示空前缀
    mask = 0                  # 当前前缀的位掩码，初始全为偶数（0）
    ans = 0                   # 最长合法子串长度

    for idx, ch in enumerate(s, 1):          # idx 从 1 开始，方便对应前缀长度
        if ch in vowel_to_bit:               # 只在遇到元音时翻转对应位
            bit = vowel_to_bit[ch]
            mask ^= (1 << bit)               # 异或 1，翻转第 bit 位

        # 如果这个 mask 以前出现过，说明 idx 与第一次出现位置之间的子串合法
        if mask in first_pos:
            ans = max(ans, idx - first_pos[mask])
        else:
            # 第一次出现该 mask，记录下它的下标（越早越好）
            first_pos[mask] = idx

    return ans
```

> **关键注释**  
> - `mask ^= (1 << bit)`：`1 << bit` 把 1 左移 `bit` 位，得到只有第 `bit` 位为 1 的数。异或 `^=` 就是“翻转这一位”。  
> - `first_pos = {0: 0}`：把全偶数（掩码 0）映射到位置 0，表示空串也满足条件，方便后面直接计算从开头的合法子串长度。  

#### 复杂度

- **时间复杂度**：`O(n)`  
  - 只遍历一次字符串，像走直线一样，一步一步算掩码，时间随字符数线性增长。相比暴力的 `n²`，这就像把“找朋友”从“每个人都要相互问候”变成“只要记住第一次见面时间”。  
- **空间复杂度**：`O(1)`  
  - 掩码最多只有 `2^5 = 32` 种可能，字典最多存 32 条记录，和字符串长度无关，算作常数空间。

## 心得

- **核心技巧**：使用 **位掩码 + 前缀异或** 把“奇偶计数”压缩到一个整数，用哈希表记录每种掩码最早出现的位置，从而在一次遍历中得到最长合法子串。  
- **适用场景**（类似题目）  
  1. **“找最长子数组，出现次数为偶数”**（如 LeetCode 1371. 同时出现的最短子数组）  
  2. **“找最长子串，出现次数为奇数/偶数的子集”**（如 0/1 子数组和为偶数）  
  3. **“找最长子串，使得字符种类出现次数的奇偶性满足特定模式”**（如 LeetCode 1372. 最长的字母序列）  
- **一句话总结**：**把“每个元音出现偶数”转化为“前缀掩码相同”，用最早出现的掩码位置求最大距离**。

## 反思

- **第一反应**：直接暴力枚举子串，边遍历边计数——思路清晰但不够高效。  
- **最容易踩的坑**  
  - **忘记把空前缀（mask = 0）加入哈希表**，导致从字符串开头的合法子串长度无法被计算。  
  - **位运算错误**：翻转位时用了 `|=` 而不是 `^=`，会把位设为 1 而不是翻转，导致奇偶计数出错。  
  - **下标混淆**：前缀长度的下标需要比字符下标多 1（因为 `first_pos` 保存的是“前缀结束位置”），不注意会少算或多算 1。  
- **下次遇到同类题的第一步**：  
  1. 把“出现次数的奇偶性”抽象成 **位掩码**。  
  2. 计算 **前缀掩码**，并在遍历过程中查找 **相同掩码的最早出现位置**。  

这样就能把原本需要 `O(n²)` 的枚举，快速降到 `O(n)`。祝你玩得开心！
