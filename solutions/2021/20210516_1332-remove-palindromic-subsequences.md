# #1332. 删除回文子序列 / Remove Palindromic Subsequences

> 难度：简单 · 标签：Two Pointers、String · [LeetCode 链接](https://leetcode.com/problems/remove-palindromic-subsequences/)

---

## 题目（英文原版）

**Description**

You are given a string s consisting only of letters 'a' and 'b'. In a single step you can remove one palindromic subsequence from s.
Return the minimum number of steps to make the given string empty.
A string is a subsequence of a given string if it is generated by deleting some characters of a given string without changing its order. Note that a subsequence does not necessarily need to be contiguous.
A string is called palindrome if is one that reads the same backward as well as forward.

**Examples**

**Example 1:**

```
Input: s = "ababa"
Output: 1
Explanation: s is already a palindrome, so its entirety can be removed in a single step.
```

**Example 2:**

```
Input: s = "abb"
Output: 2
Explanation: "abb" -> "bb" -> "". 
Remove palindromic subsequence "a" then "bb".
```

**Example 3:**

```
Input: s = "baabb"
Output: 2
Explanation: "baabb" -> "b" -> "". 
Remove palindromic subsequence "baab" then "b".
```

**Constraints**

- 1 <= s.length <= 1000
- s[i] is either 'a' or 'b'.

## 题目（中文翻译）

给定一个仅由字符 `'a'` 和 `'b'` 构成的字符串 `s`。在一次操作中，你可以删除 `s` 中的一个回文子序列（palindromic subsequence）。返回将该字符串清空所需的最少操作次数。

子序列（subsequence）是指通过删除字符串中的若干字符而不改变剩余字符相对顺序得到的字符串。注意，子序列不要求连续。

回文（palindrome）是指正着读和倒着读完全相同的字符串。

**示例 1**

``` 
Input: s = "ababa"
Output: 1
Explanation: s 本身已经是回文，所以可以在一次操作中全部删除。
```

**示例 2**

``` 
Input: s = "abb"
Output: 2
Explanation: "abb" -> "bb" -> ""。先删除回文子序列 "a"，再删除 "bb"。
```

**示例 3**

``` 
Input: s = "baabb"
Output: 2
Explanation: "baabb" -> "b" -> ""。先删除回文子序列 "baab"，再删除 "b"。
```

**约束条件**

- `1 <= s.length <= 1000`
- `s[i]` 只能是 `'a'` 或 `'b'`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**枚举所有可能的回文子序列**，每一次把它删掉后递归求剩余字符串的最少步数。  
可以把这个过程想成：

1. 从字符串 `s` 中挑出一组字符（不要求连续），只要这组字符正读倒读都一样，就是**回文子序列**。  
2. 把挑出的字符从 `s` 中删除，得到一个更短的字符串 `s'`。  
3. 对 `s'` 重复上述步骤，直到字符串为空。

这里用到的主要数据结构是**递归调用栈**（相当于我们在纸上写下每一步的“待解决子问题”），而**回文检测**可以用两指针从两端向中间比较字符——这就像从两头同时检查一条绳子是否对称。

这种方法一定能得到答案，因为我们把**所有**可能的删除方式都尝试了一遍。唯一的缺点是——**穷举**的代价太高，随着字符串长度的增长，可能的子序列数量呈指数级增长。

#### 代码（Python）

```python
def min_steps_bruteforce(s: str) -> int:
    """
    暴力递归：尝试所有回文子序列的删除方式，返回最小步数。
    由于会枚举指数级的子序列，只适合长度很小的测试。
    """
    # 递归终止条件：空串已经不需要任何操作
    if not s:
        return 0

    n = len(s)
    best = float('inf')        # 用一个很大的数记录目前找到的最小步数

    # 枚举所有非空子序列（用二进制掩码表示是否选取第 i 位字符）
    # 这里的时间复杂度是 O(2^n * n)——每个子序列要检查是否回文
    for mask in range(1, 1 << n):
        # 取出当前掩码对应的子序列
        subseq = [s[i] for i in range(n) if mask & (1 << i)]
        # 判断是否为回文——两指针法
        l, r = 0, len(subseq) - 1
        is_pal = True
        while l < r:
            if subseq[l] != subseq[r]:
                is_pal = False
                break
            l += 1
            r -= 1
        if not is_pal:
            continue          # 不是回文子序列，直接跳过

        # 构造删除该子序列后的剩余字符串
        # 这里用列表保存未被选中的字符
        remaining = [s[i] for i in range(n) if not (mask & (1 << i))]
        # 递归求剩余部分的最少步数，加上当前这一步
        steps = 1 + min_steps_bruteforce(''.join(remaining))
        best = min(best, steps)

    return best
```

> **提示**：上述代码在 `len(s) > 12` 时就会明显变慢，仅用于说明暴力思路，实际提交时请使用下面的最优解。

#### 复杂度  

- **时间复杂度**：`O(2^n * n)`  
  - `2^n` 是所有子序列的数量（每个字符保留或删除两种可能），`n` 是检查回文需要的线性扫描。用大白话说，就是“随着字符个数每增加一个，可能的组合就会翻倍”，所以很快就会不可接受。  
- **空间复杂度**：`O(n)`  
  - 递归栈的最大深度等于字符串长度，每层需要保存一个临时的子序列和剩余字符串。

### 2. 最优解

#### 思路  

从暴力解可以看到，**真正的瓶颈在于枚举所有子序列**。  
观察题目给出的约束：

- 字符串只包含 `'a'` 和 `'b'` 两种字符。  

这让我们可以用更高层次的“整体”思考，而不是逐个子序列枚举。

**关键观察**：

1. **任意只由同一种字符组成的子序列必然是回文**。  
   想象一本只有一种字母的词典，正读倒读都是同一个字母，自然对称。

2. 因此，我们可以一次性把所有 `'a'`（或所有 `'b'`）作为一个回文子序列删除。  
   剩下的只会是另一种字符，同理再删一次即可。  
   所以**答案至多是 2**。

3. 若原字符串本身已经是回文，则一次即可全部删除，答案为 **1**。  
   判断回文只需要一次两指针遍历（从左、右同时向中间比较），时间是线性的。

4. 空字符串显然不需要任何操作，答案为 **0**（题目中最小长度为 1，这里仅作完整性说明）。

综上，答案只能是 0、1 或 2 三种情况：

- `s == ""` → 0  
- `s` 是回文 → 1  
- 否则 → 2  

**为什么不可能出现 3 或更大的答案？**  
因为我们已经证明：只要把一种字符全部删掉，剩下的必然只包含另一种字符，第二次删除即可清空。不存在需要第三次才能完成的情况。

#### 代码（Python）

```python
def removePalindromeSub(s: str) -> int:
    """
    最优解：只需要判断原串是否为回文。
    - 若是回文，直接一次删除 → 1 步
    - 若不是回文（且非空），最多两步即可删除完毕 → 2 步
    """
    # 空串的情况（本题不会出现，但写上更严谨）
    if not s:
        return 0

    # 两指针判断回文：左指针 l, 右指针 r
    l, r = 0, len(s) - 1
    is_pal = True
    while l < r:
        if s[l] != s[r]:
            is_pal = False   # 只要出现一次不相等，就不是回文
            break
        l += 1
        r -= 1

    return 1 if is_pal else 2
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 只需要一次线性扫描检查回文，`n` 是字符串长度。用大白话说，就是“看一遍就够了”，比暴力的指数级快很多。  
- **空间复杂度**：`O(1)`  
  - 只用了常数个额外变量（两个指针和一个布尔标记），不随 `n` 增长。

## 心得

- **核心技巧**：利用字符种类的限制，把问题抽象成“是否为回文”，从而将原本可能的多步操作压缩到最多两步。  
- **适用的类似题型**  
  1. *只含两种字符的删除/转换问题*（如 “把字符串变成全 a 或全 b，只需要一步或两步”。）  
  2. *判断回文并利用回文性质简化求解*（如 “最少删除回文子序列使字符串为空” 与本题本质相同）。  
  3. *使用双指针快速判断对称性*（如 “Valid Palindrome”）。  

> **解题钥匙**：先把“字符种类少”这条信息写在纸上，再问自己“这能把问题简化到几种可能？”——答案往往出奇地简单。

## 反思

- **第一反应**：看到“删除回文子序列”，立刻想到“枚举所有子序列”。这在没有进一步限制时是自然的想法，却容易陷入指数爆炸。  
- **最容易踩的坑**  
  - 忽视题目只包含 `'a'`、`'b'` 两种字符，以为需要复杂的 DP。  
  - 在实现回文检查时忘记处理空字符串或单字符的边界（虽然这里不影响结果，但代码健壮性会受影响）。  
- **下次遇到同类题**：第一步先**审题找限制**（字符种类、长度、是否只含特定字符等），再思考这些限制能否把“搜索空间”压到常数级；如果能，就直接用**数学/逻辑推导**得出答案，而不是急着写递归或 DP。
