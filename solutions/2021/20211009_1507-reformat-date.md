## 题目（中文翻译）

给定一个日期字符串（date string），其形式为 **Day Month Year**，其中  
- **Day** 为带序数后缀的日期，如 `20th`、`6th`、`26th`；  
- **Month** 为英文月份的三字母缩写，如 `Oct`、`Jun`、`May`；  
- **Year** 为四位数字的年份。  

请将该日期字符串转换为 **YYYY-MM-DD** 的格式，其中  
- `YYYY` 为四位数的年份，  
- `MM` 为两位数的月份（不足两位前面补 `0`），  
- `DD` 为两位数的日期（不足两位前面补 `0`）。

**示例 1:**  
**输入:** `date = "20th Oct 2052"`  
**输出:** `"2052-10-20"`

**示例 2:**  
**输入:** `date = "6th Jun 1933"`  
**输出:** `"1933-06-06"`

**示例 3:**  
**输入:** `date = "26th May 1960"`  
**输出:** `"1960-05-26"`

**约束条件**  
- 给定的日期均保证合法，无需进行错误处理。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

这道题的输入是一段英文日期，例如 `"20th Oct 2052"`，要求把它变成 `"2052-10-20"`。  
最直接的想法是：

1. **把整句切成三段**：`day`、`month`、`year`。这就像把一句话拆成「词语」一样，用空格做分隔符（`split()`）。
2. **处理 day**：  
   - 日期后面总会有两个英文后缀（`st`、`nd`、`rd`、`th`），比如 `20th` → `20`。  
   - 只要把最后两个字符删掉（`[:-2]`），剩下的就是数字字符串。  
   - 为了统一成两位数，如果只有一位（比如 `6`），在前面补一个 `0`（`zfill(2)`）。
3. **处理 month**：  
   - 需要把英文月份（`Jan`、`Feb` … `Dec`）映射成两位数字（`01`、`02` … `12`）。  
   - 这里可以准备一个字典（哈希表），把月份名当作 **key**（就像查字典时用单词找对应的页码），对应的 **value** 就是两位数字字符串。
4. **处理 year**：年份已经是四位，直接使用即可。  
5. **拼接**：按照 `YYYY-MM-DD` 的顺序，用连字符 `-` 把三部分连起来。

> **为什么这种做法一定能得到正确答案？**  
> - 输入保证合法，且结构固定为「日 月 年」三个用空格分开的子串。  
> - 去掉日的后缀后只剩数字，月份字典覆盖了所有可能的英文月份，年份不变。  
> - 因此每一步都对应唯一的、题目要求的输出形式。

#### 代码（Python）

```python
def reformatDate(date: str) -> str:
    # 1. 把字符串按空格拆成 three parts
    day_str, month_str, year_str = date.split(' ')   # ["20th", "Oct", "2052"]

    # 2. 处理 day：去掉后缀，转成两位数
    day_num = day_str[:-2]            # 去掉 "th"/"st"/"nd"/"rd"
    day = day_num.zfill(2)            # 若只有一位，在前面补 0，例如 "6" → "06"

    # 3. 处理 month：使用字典把英文月份映射到数字
    month_map = {
        "Jan": "01", "Feb": "02", "Mar": "03", "Apr": "04",
        "May": "05", "Jun": "06", "Jul": "07", "Aug": "08",
        "Sep": "09", "Oct": "10", "Nov": "11", "Dec": "12"
    }
    month = month_map[month_str]      # 例如 "Oct" → "10"

    # 4. year 已经是四位，直接使用
    year = year_str

    # 5. 按要求的格式拼接返回
    return f"{year}-{month}-{day}"
```

#### 复杂度

- **时间复杂度：O(1)** — 输入长度固定在几段字符（最多 15 左右），所有操作（切割、字典查找、字符串拼接）都是常数时间。  
- **空间复杂度：O(1)** — 只用了常数个额外变量和一个固定大小的字典，和输入规模无关。

### 2. 最优解

#### 思路  

从上面的暴力解可以看到，真正的「瓶颈」并不是时间——本身已经是 O(1)。  
但如果把「暴力」理解为**逐字符遍历并手动拼接**，代码会显得冗长且不易读。  
我们可以进一步**简化**思路，使代码更直观：

1. **统一使用字典**：把所有月份映射放进字典，这一步已经是最简的 O(1) 查找。  
2. **利用 Python 的字符串切片和 `zfill`**：一次性完成日的去后缀和补零。  
3. **直接返回格式化字符串**：使用 f-string 或 `format`，不需要额外的列表或拼接步骤。

实际上，上面的「直觉解」已经是最优的实现，只要保持代码简洁即可。下面给出更为精炼的版本，便于阅读和记忆。

#### 代码（Python）

```python
def reformatDate(date: str) -> str:
    # 按空格分割
    d, m, y = date.split()

    # 日期去掉后缀后补零
    day = d[:-2].zfill(2)

    # 月份映射表（一次性写在函数内部，保持 O(1) 查找）
    month = {
        "Jan": "01", "Feb": "02", "Mar": "03", "Apr": "04",
        "May": "05", "Jun": "06", "Jul": "07", "Aug": "08",
        "Sep": "09", "Oct": "10", "Nov": "11", "Dec": "12"
    }[m]          # 直接取值

    # 直接返回目标格式
    return f"{y}-{month}-{day}"
```

#### 复杂度

- **时间复杂度：O(1)** — 仍然是常数时间，唯一的工作是一次分割和一次字典查找。  
- **空间复杂度：O(1)** — 只用了常数个局部变量和一个固定大小的字典。

与「暴力」解相比，时间空间都没有改变（本题本身已经是常数级），但代码更短、更易懂，降低了出错概率。

## 心得

- **核心技巧**：把固定映射关系（英文月份 → 两位数字）用哈希表（字典）存储，利用字符串切片和 `zfill` 统一处理日期格式。  
- **适用场景**：  
  1. 需要把固定的文字映射为数字或其它形式的题目（如罗马数字转整数）。  
  2. 需要对日期、时间等固定格式字符串进行标准化处理。  
- **解题钥匙**：**拆分 + 映射 + 格式化**——先把整体拆成小块，再用映射表把每块转换成目标形式，最后统一格式输出。

## 反思

- **第一反应**：看到「Day Month Year」这种固定结构，第一步就是「先把它拆开」。  
- **最容易踩的坑**：  
  - 忘记去掉日期的后缀（`st/nd/rd/th`），导致字符串转整数时报错。  
  - 对单字符日期（如 `6th`）没有补零，输出 `6` 而不是 `06`。  
  - 月份映射表写错或漏掉某个月份。  
- **下次遇到同类题**：第一步想到「把字符串按空格切开」，第二步检查每一块是否需要 **去噪**（如后缀、前导零），再用 **字典映射** 完成转换，最后统一 **格式化输出**。
