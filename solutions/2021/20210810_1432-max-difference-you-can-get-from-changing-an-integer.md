## 题目（英文原版）

**Description**

You are given an integer num. You will apply the following steps to num two separate times:
Let a and b be the two results from applying the operation to num independently.
Return the max difference between a and b.
Note that neither a nor b may have any leading zeros, and must not be 0.

**Examples**

**Example 1:**

```
Input: num = 555
Output: 888
Explanation: The first time pick x = 5 and y = 9 and store the new integer in a.
The second time pick x = 5 and y = 1 and store the new integer in b.
We have now a = 999 and b = 111 and max difference = 888
```

**Example 2:**

```
Input: num = 9
Output: 8
Explanation: The first time pick x = 9 and y = 9 and store the new integer in a.
The second time pick x = 9 and y = 1 and store the new integer in b.
We have now a = 9 and b = 1 and max difference = 8
```

**Constraints**

- 1 <= num <= 108

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

题目要求 **对整数 `num` 做两次独立的“替换操作”，得到两个新整数 `a`、`b`，返回 `a‑b` 的最大可能值**。  
一次替换操作的规则是：

1. 任选一个 **出现过的数字 `x`**（0~9 中的某个字符）。  
2. 再任选一个 **目标数字 `y`**（0~9 中的某个字符），把 `num` 中所有出现的 `x` **全部换成 `y`**。  
3. 替换后得到的新整数 **不能有前导零**，且 **不能是 0**（即首位不能是 `'0'`）。

把这个过程想象成 **在一本字典里查词**：  
- `x` 就是我们要查的词，`y` 是对应的页码。把所有相同的词都指向同一页，就相当于把所有相同的数字都改成同一个新数字。  
- 只要页码是 `'0'` 且恰好在最前面，这本字典就会出现“空白页”，这在题目里是被禁止的。

**暴力做法**：枚举所有合法的 `(x, y)` 组合，执行一次替换，得到一个候选整数。把所有候选整数记录下来，最后取 **最大值** 与 **最小值** 的差即为答案。

为什么这样一定能得到正确答案？

- 题目只要求“任意两次独立的替换”，所以我们可以把 **所有可能的替换结果** 都列出来。  
- 在这些结果中，差值最大的必然是 **最大数** 与 **最小数** 的差，因为 `max - min` 是所有两数差中最大的。

**复杂度分析（大白话）**  

- 枚举 `x`：最多 10 种（0~9）。  
- 枚举 `y`：同样最多 10 种。  
- 对每一对 `(x, y)`，我们要遍历一遍 `num` 的每个字符，做一次字符替换，时间是 `O(L)`，其中 `L` 是数字的位数（最多 9 位，因为 `num ≤ 10⁸`）。  

于是总时间是 `10 × 10 × L ≈ 100L`，即 **线性时间**（`O(L)`）——常数因子比较大，但在本题的约束下完全够用。  
空间上我们只需要保存当前的最小/最大值，使用 **常数级别的额外空间**（`O(1)`）。

#### 代码（Python）

```python
def maxDiff(num: int) -> int:
    s = str(num)                     # 把整数转成字符串，方便逐位操作
    n = len(s)

    # 用来保存所有合法的结果
    min_val = float('inf')
    max_val = -float('inf')

    # 枚举所有出现过的数字 x（字符形式）
    for x in set(s):
        # 枚举所有可能的目标数字 y（字符形式）
        for y in map(str, range(10)):
            if x == y:               # 替换前后相同，没意义，直接跳过
                continue

            # 生成替换后的字符串
            t = s.replace(x, y)

            # 检查是否出现了前导零或整个数变成了 0
            if t[0] == '0':          # 首位是 0，非法
                continue
            if int(t) == 0:          # 结果为 0，非法（虽然前导零已排除，这里防止全部位都是 0）
                continue

            val = int(t)             # 合法结果转回整数
            min_val = min(min_val, val)
            max_val = max(max_val, val)

    # 题目保证一定有合法的替换（最坏情况把自己换成自己），所以 min_val / max_val 必定被更新
    return max_val - min_val
```

> **关键行中文注释** 已在代码中给出，直接复制运行即可。

#### 复杂度  

- **时间复杂度**：`O(L)`（实际是 `≈100·L`，常数项大但仍线性）。  
  - `L` 是 `num` 的位数，最多 9。  
  - 大白话：即使每位都要检查 100 次，也只会跑几百步，几乎瞬间完成。  
- **空间复杂度**：`O(1)`，只用了几个整数变量。

### 2. 最优解  

#### 思路  

暴力解已经是 **线性** 的，已经很快。但我们可以 **只遍历一次数字**，直接构造出 **最大可能的数** 与 **最小可能的数**，进一步降低常数因子。

**观察 1：最大数**  
- 为了让整数尽可能大，我们希望把 **最高位**（最左边的位）尽可能变成 `9`。  
- 只要把 **第一个不是 `9` 的数字 `d`** 全部换成 `9`，就能得到最大的可能结果。  
  - 为什么只换第一个？因为更左边的位权值更大，改动它的效果远大于改动后面的位。  
  - 如果所有位本来就是 `9`，则已经是最大值，保持不变。  

**观察 2：最小数**  
- 为了让整数尽可能小，目标是把 **最高位** 变成最小的合法数字。  
- 首位不能是 `0`，最小合法首位是 `1`。  
  - **情况 A**：如果首位本身不是 `1`，把 **首位所在的数字**（所有出现的那个数字）全部换成 `1`，即可得到最小值。  
  - **情况 B**：如果首位已经是 `1`，我们就不能再把它改成更小的数字，只能尝试把后面的某个数字换成 `0`（因为 `0` 是最小的），并且要确保换的不是首位（否则会出现前导零）。于是我们找 **第一个既不是 `0` 也不是 `1` 的数字**，把它全部换成 `0`。  
- 若整个数字只有 `1` 和 `0`（例如 `1010`），上述步骤仍能得到合法最小数，因为把后面的 `1` 换成 `0` 不会影响首位。

**核心算法**：只需要 **一次遍历** 找到上述两个“关键数字”，随后使用 `str.replace` 完成替换。整个过程 **O(L)**，且常数极小。

#### 代码（Python）

```python
def maxDiff(num: int) -> int:
    s = str(num)               # 原始字符串
    n = len(s)

    # ---------- 求最大数 ----------
    # 找到第一个不是 '9' 的字符
    for ch in s:
        if ch != '9':
            max_num = int(s.replace(ch, '9'))   # 把所有该字符换成 '9'
            break
    else:
        # 所有字符都是 '9'，已经是最大值
        max_num = num

    # ---------- 求最小数 ----------
    # 情况 A：首位不是 '1'，把首位对应的数字全部换成 '1'
    if s[0] != '1':
        min_num = int(s.replace(s[0], '1'))
    else:
        # 情况 B：首位已经是 '1'，找第一个既不是 '0' 也不是 '1' 的字符
        target = None
        for ch in s[1:]:               # 从第二位开始检查
            if ch != '0' and ch != '1':
                target = ch
                break
        if target is None:
            # 说明除了首位都是 '0' 或 '1'，最小数就是原数本身
            min_num = num
        else:
            min_num = int(s.replace(target, '0'))

    return max_num - min_num
```

**代码要点解释**  

- `for ch in s: ... break`：一次遍历找出 **第一个非 9 的数字**，立刻完成替换并退出循环。  
- `else:` 块是 Python 的 **for‑else** 结构，只有当循环没有 `break`（即所有字符都是 `9`）时才会执行。  
- 对最小数的处理分两段，**先看首位**，再在后面找合适的字符换成 `0`。  
- `int(...)` 把最终的字符串重新转回整数，自动去掉前导零（但我们已经保证不会出现前导零）。

#### 复杂度  

- **时间复杂度**：`O(L)`，只遍历了一遍原始字符串（两次遍历但都是线性的），常数极小。  
  - 与暴力解相比，省掉了 100 倍的枚举，只做了 **一次** 替换操作。  
- **空间复杂度**：`O(1)`，只用了几个临时变量和常数长度的字符串副本（Python 字符串是不可变的，但这不算额外的 *可扩展* 空间）。

## 心得  

- **核心技巧**：**利用位权的大小**（左侧位的影响更大）**一次遍历** 找出需要统一替换的数字，分别构造 **最大数** 与 **最小数**。  
- **该技巧适用的题型**：  
  1. “把数字中某个字符全部换成另一个字符，使结果最大/最小”——如本题、LeetCode 2565 *Maximum Score Of a Node Sequence*（思路类似的字符映射）。  
  2. “对字符串/数组进行一次统一替换，以获得字典序最大/最小”——如 “Smallest Number After Removing Digits”。  
- **一句话总结**：**只要把左侧第一位可以改得更大的换成 9，左侧第一位可以改得更小的换成 1（或后面的换成 0），差值最大即为两者之差。**

## 反思  

- **第一反应**：看到“两次独立的替换”，立刻想到“枚举所有可能”，于是写了暴力解。  
- **最容易踩的坑**  
  1. **前导零**：把首位换成 `0` 会产生非法答案，需要额外判断。  
  2. **全部相同数字**：比如 `num = 9`，最大数仍是 `9`（换成自己），最小数是 `1`（换成 `1`），一定要处理 `x == y` 的情况。  
  3. **只有 `1` 和 `0` 的情况**：如果首位是 `1`，后面只剩 `0`，最小数就是原数本身，不能再把 `1` 换成 `0`（会导致前导零）。  
- **下次遇到同类题**，第一步应该先 **思考左侧位的权重**，判断是否可以通过一次统一替换把左侧位改成最极端的合法数字（最大用 `9`，最小用 `1` 或 `0`），再再做细节检查，而不是直接暴力枚举。
