# #1470. 打乱数组 / Shuffle the Array

> 难度：简单 · 标签：Array · [LeetCode 链接](https://leetcode.com/problems/shuffle-the-array/)

---

## 题目（英文原版）

**Description**

Given the array nums consisting of 2n elements in the form [x1,x2,...,xn,y1,y2,...,yn].
Return the array in the form [x1,y1,x2,y2,...,xn,yn].

**Examples**

**Example 1:**

```
Input: nums = [2,5,1,3,4,7], n = 3
Output: [2,3,5,4,1,7] 
Explanation: Since x1=2, x2=5, x3=1, y1=3, y2=4, y3=7 then the answer is [2,3,5,4,1,7].
```

**Example 2:**

```
Input: nums = [1,2,3,4,4,3,2,1], n = 4
Output: [1,4,2,3,3,2,4,1]
```

**Example 3:**

```
Input: nums = [1,1,2,2], n = 2
Output: [1,2,1,2]
```

**Constraints**

- 1 <= n <= 500
- nums.length == 2n
- 1 <= nums[i] <= 10^3

给定一个数组 `nums`，它由 `2n` 个元素组成，形式为 `[x1,x2,...,xn,y1,y2,...,yn]`。  
返回一个数组，使其排列为 `[x1,y1,x2,y2,...,xn,yn]`。

**示例 1**

```
Input: nums = [2,5,1,3,4,7], n = 3
Output: [2,3,5,4,1,7]

```

**示例 2**

```
Input: nums = [1,2,3,4,4,3,2,1], n = 4
Output: [1,4,2,3,3,2,4,1]
```

**示例 3**

```

```

- `nums.length == 2n`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法就是**把两段数组的元素交叉取出来，重新放进一个新数组**。  
- 原数组 `nums` 前半段 `[x1, x2, …, xn]` 可以想象成左边的“水果篮”。  
- 后半段 `[y1, y2, …, yn]` 则像右边的“水果篮”。  
我们把左篮子和右篮子的水果交错挑出来，依次放进一个空的盘子（新数组）里。  

这一步只需要遍历一次原数组，用两个指针分别指向左篮子和右篮子的起始位置，然后交替取值即可。  
因为我们没有修改原数组，只是**新建**一个同样大小的数组，所以一定能得到正确的结果。

#### 代码（Python）
```python
def shuffle(nums, n):
    """
    暴力解：使用额外的数组把 x 和 y 交叉放入
    :param nums: 长度为 2n 的列表
    :param n: 前半段的长度
    :return: 交叉后的新列表
    """
    res = []                         # 用来装结果的空盘子
    i, j = 0, n                      # i 指向左篮子起点，j 指向右篮子起点
    while i < n and j < 2 * n:       # 两个指针都没走完时循环
        res.append(nums[i])          # 先放左篮子里的水果 x_i
        res.append(nums[j])          # 再放右篮子里的水果 y_i
        i += 1                       # 左篮子指针右移
        j += 1                       # 右篮子指针右移
    return res
```

#### 复杂度
- **时间复杂度：O(n)** — 只遍历了一遍原数组，`n` 表示左半段的长度（实际元素总数是 `2n`，常数 2 不计入）。
- **空间复杂度：O(n)** — 需要额外的数组 `res` 来存放 `2n` 个元素，等价于原数组大小的一半（这里我们按 `n` 来计）。

### 2. 最优解

#### 思路  
暴力解已经是 **线性时间 O(n)**，已经很快了。  
唯一可以改进的地方是 **空间**：我们可以不新建数组，直接在原数组里“把两个数装进同一个格子”，等遍历结束后再把它们拆开。  

这就像把两本薄书压在一起，用一本书的厚度 * 1000（因为题目保证 `nums[i] ≤ 1000`）来把另一本藏进去，等到全部压好后再把每本书单独取出。

实现步骤：

1. **编码**：遍历 `i = 0 … n-1`，把 `x_i`（在 `nums[i]`）和 `y_i`（在 `nums[i + n]`）压进位置 `2*i`。  
   - 设 `base = 1001`（比所有可能的数大 1），则 `encoded = x_i + y_i * base`。  
   - 把 `encoded` 暂时存回 `nums[2*i]`，`nums[2*i+1]` 先留空（稍后填）。
2. **解码**：再遍历一遍，把每个 `encoded` 拆成原来的 `x_i` 与 `y_i`，分别写回 `nums[2*i]` 与 `nums[2*i+1]`。  
   - `x_i = encoded % base`（余数），`y_i = encoded // base`（整数除法）。

这样只用了 **常数级的额外空间**（几个临时变量），时间仍是一次线性遍历（两次遍历仍是 O(n)），空间降到了 O(1)。

#### 代码（Python）
```python
def shuffle(nums, n):
    """
    最优解：原地交叉，利用编码技巧把两个数放进同一个格子
    由于 nums[i] <= 1000，取 base = 1001 足够大，保证不会产生冲突。
    """
    base = 1001                     # 大于所有可能的原始数

    # 第一次遍历：把 x_i 和 y_i 编码后写到偶数位置
    for i in range(n):
        x = nums[i]                 # 左半段的数 x_i
        y = nums[i + n]             # 右半段的数 y_i
        # 把两个数压进一个格子，低位放 x，高位放 y
        nums[2 * i] = x + y * base   # 这里暂时只写到偶数位

    # 第二次遍历：把编码的数拆出来，填满奇数位
    for i in range(n):
        encoded = nums[2 * i]        # 之前存的 x + y*base
        x = encoded % base           # 余数就是原来的 x
        y = encoded // base          # 整除得到原来的 y
        nums[2 * i] = x              # 偶数位恢复为 x
        nums[2 * i + 1] = y          # 奇数位写入 y

    return nums
```

#### 复杂度
- **时间复杂度：O(n)** — 两次线性遍历，常数因子不影响大 O 表示。相较于暴力解，速度相同，但省了额外的数组拷贝。
- **空间复杂度：O(1)** — 只使用了几个临时变量 `base、x、y、encoded`，不随输入规模增长。

## 心得

- **核心技巧**：利用“编码/解码”把两个数压在同一个位置，从而实现 **原地**（O(1) 额外空间）操作。  
- **适用场景**：  
  1. **数组原地重排**（如 “交错合并两个有序数组”）。  
  2. **在同一个容器里存放两层信息**（如 “把奇偶位信息合并到同一个整数”）。  
  3. **把两个小数合并进一个大数**（如 “把坐标压缩进一个整数”）。  
- **一句话总结**：**“把两个数装进一个格子，再拆出来”** 是解这类原地交叉题的钥匙。

---

## 反思

- **第一反应**：直接开辟新数组，把前后两段交叉写进去。虽然简单，却没有利用原地的可能。  
- **最容易踩的坑**：  
  - **编码基数**（`base`）必须大于所有可能的原始数，否则会产生“进位冲突”。  
  - **整数溢出**：在语言里若数值范围很大，需要使用更大的基数或使用 Python 的大整数特性（Python 不会溢出）。  
  - **下标错误**：记得偶数位是 `2*i`，奇数位是 `2*i+1`，不要写错导致覆盖。  
- **下次遇到同类题**：第一步先思考 **“能否在原数组里直接改写？”**，如果可以，尝试 **编码/解码** 或 **双指针** 的原地技巧。
