# #1346. 检查 N 与其两倍是否同时存在 / Check If N and Its Double Exist

## 题目（英文原版）

**Description**

Given an array arr of integers, check if there exist two indices i and j such that :

**Examples**

**Example 1:**

```
Input: arr = [10,2,5,3]
Output: true
Explanation: For i = 0 and j = 2, arr[i] == 10 == 2 * 5 == 2 * arr[j]
```

**Example 2:**

```
Input: arr = [3,1,7,11]
Output: false
Explanation: There is no i and j that satisfy the conditions.
```

**Constraints**

- 2 <= arr.length <= 500
- -103 <= arr[i] <= 103

## 题目（中文翻译）

**题目描述**  
给定一个整数数组 `arr`，请判断是否存在两个不同的下标 `i` 和 `j`，满足：

- `i != j`
- `arr[i] == 2 * arr[j]`

如果存在满足条件的下标对，返回 `true`；否则返回 `false`。

**示例**

**示例 1**  
```
Input: arr = [10,2,5,3]
Output: true
Explanation: 当 i = 0 且 j = 2 时，arr[i] == 10 == 2 * 5 == 2 * arr[j]
```

**示例 2**  
```
Input: arr = [3,1,7,11]
Output: false
Explanation: 不存在满足条件的 i 和 j。
```

**约束条件**

- `2 <= arr.length <= 500`
- `-10^3 <= arr[i] <= 10^3`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把数组里每一对下标 `(i, j)` 都枚举一遍，看看是否满足  

```
arr[i] == 2 * arr[j]   或者   arr[j] == 2 * arr[i]
```

这相当于把数组的每个元素都和它后面的每个元素比较一次。  
可以把 **哈希表** 想成一本“查词典”，不过在暴力解里我们根本不需要它，只是单纯地用两个**循环**（外层遍历 i，内层遍历 j）来“查”。  

只要找到一对满足条件的下标，就立刻返回 `True`；如果所有组合都检查完仍未找到，则返回 `False`。

#### 代码（Python）

```python
def check_if_exist_brute(arr):
    n = len(arr)
    # 外层遍历每个 i
    for i in range(n):
        # 内层遍历 i 之后的每个 j，避免重复比较
        for j in range(i + 1, n):
            # 检查两种可能：arr[i] 是 arr[j] 的两倍，或者相反
            if arr[i] == 2 * arr[j] or arr[j] == 2 * arr[i]:
                return True        # 找到答案，直接返回
    return False                 # 全部遍历完也没找到
```

#### 复杂度  

- **时间复杂度：** `O(n²)`  
  “二次方”意思是如果数组长度翻倍，比较次数会变成原来的 **4 倍**。因为我们要把每个元素和后面的所有元素配对，最坏情况下要做 `n·(n-1)/2` 次比较。  
- **空间复杂度：** `O(1)`  
  只用了几个计数变量，和数组大小无关。

---

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈** 在于每次都要遍历所有已经出现的元素去找“它的两倍”。  
如果我们能在 **O(1)** 时间内判断“某个数是否已经出现”，就可以把内层循环去掉。

这正是 **哈希表（Python 中的 `set`）** 的强项：  
- 把已经遍历过的元素存进集合，像查字典一样，给定一个数可以在常数时间判断它是否在集合里。  
- 对于当前元素 `x`，只需要检查两件事：
  1. `2 * x` 是否已经出现（意味着之前有一个数是 `x` 的两倍）。
  2. `x` 是否是偶数且 `x // 2` 已经出现（意味着之前有一个数是 `x` 的一半）。

遍历数组一次即可完成检查，整体时间降到线性 `O(n)`，空间使用 `O(n)`（存放集合）。

下面用生活化的类比来帮助理解：

> 把集合想成一张 **“出现过的数字清单”**，每读到一个新数字，就把它记在清单上。  
> 当我们看到新数字 `x` 时，先去清单里找 “`2·x`” 或 “`x/2`”（如果 `x` 能整除 2），如果找到，说明已经有配对的数字出现过，直接返回 `True`。

#### 代码（Python）

```python
def check_if_exist(arr):
    seen = set()                     # 用来存放已经遍历过的数字
    for x in arr:                    # 逐个读取数组元素
        # 1. 看之前是否出现过 2*x（即当前 x 是之前某数的一半）
        if 2 * x in seen:
            return True
        # 2. 如果 x 能被 2 整除，检查之前是否出现过 x/2
        if x % 2 == 0 and (x // 2) in seen:
            return True
        # 当前数字加入集合，供后面的元素使用
        seen.add(x)
    return False                     # 遍历完都没有配对
```

#### 复杂度  

- **时间复杂度：** `O(n)`  
  只遍历一次数组，每次查询集合都是常数时间（`O(1)`），所以整体随数组长度线性增长。相较于暴力解的 `O(n²)`，如果 `n=500`，最多只做 500 次检查，而不是 125 000 次，快得多。  
- **空间复杂度：** `O(n)`  
  最坏情况下要把所有元素都放进集合，使用的额外空间和数组长度成正比。

## 心得

- 这道题核心考察 **利用哈希表实现 O(1) 查找** 的技巧。  
- 类似思路常用于：
  1. **两数之和**（判断是否存在两数相加等于目标值）  
  2. **数组中是否存在重复元素**（直接用集合判断）  
  3. **判断是否存在相差为 k 的两个数**（集合 + 差值判断）  
- 一句话总结解题钥匙：**“遍历时把已见元素放进哈希表，利用常数时间查询配对条件”。**

## 反思

- **第一反应**：直接写双层循环枚举所有配对（暴力解）。  
- **最容易踩的坑**：  
  - 忽略了 **负数** 和 **零** 的情况。负数同样可以满足 “一半/两倍” 的关系，零更是特殊：`0 == 2 * 0`，只要数组里出现两个零就应该返回 `True`（集合实现自然覆盖）。  
  - 在判断 `x/2` 时必须先确保 `x` 能被 2 整除，否则会产生非整数的错误匹配。  
- **下次遇到同类题**，第一步应该思考：“是否可以在遍历的同时，用哈希表把已经出现的元素记下来，并用常数时间检查当前元素的**配对条件**？”这样往往能立刻把时间复杂度从平方级降到线性级。
