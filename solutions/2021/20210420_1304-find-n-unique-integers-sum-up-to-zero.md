# #1304. 找到 N 个唯一整数，使其和为 0 / Find N Unique Integers Sum up to Zero

> 难度：简单 · 标签：Array、Math · [LeetCode 链接](https://leetcode.com/problems/find-n-unique-integers-sum-up-to-zero/)

---

## 题目（英文原版）

**Description**

Given an integer n, return any array containing n unique integers such that they add up to 0.

**Examples**

**Example 1:**

```
Input: n = 5
Output: [-7,-1,1,3,4]
Explanation: These arrays also are accepted [-5,-1,1,2,3] , [-3,-1,2,-2,4].
```

**Example 2:**

```
Input: n = 3
Output: [-1,0,1]
```

**Example 3:**

```
Input: n = 1
Output: [0]
```

**Constraints**

- 1 <= n <= 1000

---

给定一个整数 `n`，返回任意一个包含 `n` 个唯一整数且它们的和为 `0` 的数组（array）。

**输出：** `[-7,-1,1,3,4]`

**输入：** `n = 3`  
**输出：** `[-1,0,1]`

**示例 3：**  
**输入：** `n = 1`  
**输出：** `[0]`

**约束条件：**  
- `1 <= n <= 1000`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**一次往答案里塞数字**，每塞一个就检查当前数组的和是否已经等于 0，若不等就继续往里加。  
- **数据结构**：我们使用 Python 的 `list` 来存放已经挑好的整数，用 `set`（类似字典的“查字典”）快速判断一个数是否已经出现过，防止出现重复。  
- **为什么正确**：只要我们最终得到 `n` 个互不相同的整数，并且它们的和恰好为 0，题目就说「any」数组都可以接受。暴力地把数一个个试进去，只要把「和」控制在 0，答案一定成立。  
- **时间/空间分析**：  
  - 每加入一个新数，都要遍历已经有的数去计算当前和（最坏会遍历 `i` 次），于是总共会进行 `1 + 2 + … + (n‑1) = O(n²)` 次加法运算。  
  - 额外使用 `set` 存放已经出现的数，需要 `O(n)` 的空间。  

> **大白话**：`O(n²)` 就像在排队买票时，你每来一个人都要把前面所有人重新叫一遍名字检查，人数多了，等的时间会呈平方增长。

#### 代码（Python）

```python
def sumZero_brute(n: int):
    """
    暴力思路：逐个尝试加入新数，保证不重复且最终和为 0
    """
    ans = []            # 用 list 保存答案
    used = set()        # 用 set 判断是否已经出现（查字典的感觉）
    cur_sum = 0         # 当前数组的总和

    # 从 1 开始尝试正整数，如果不行就尝试它的负数
    candidate = 1
    while len(ans) < n:
        # 若 candidate 已经在答案里，直接跳过
        if candidate in used:
            candidate += 1
            continue

        # 计算加入 candidate 后的和是否仍有可能调成 0
        # 这里的判断比较宽松，只要不超出 [-1000, 1000]（题目范围）即可
        if abs(cur_sum + candidate) <= 1000 * n:
            ans.append(candidate)
            used.add(candidate)
            cur_sum += candidate
        else:
            # 试试它的相反数
            neg = -candidate
            if neg not in used:
                ans.append(neg)
                used.add(neg)
                cur_sum += neg

        candidate += 1

    # 如果最后的和不为 0（极少出现），把最后一个数改成 -cur_sum
    # 这样仍然保证所有数唯一，因为 -cur_sum 之前一定没有出现过
    if cur_sum != 0:
        last = ans.pop()          # 移除最后一个数
        used.remove(last)
        need = -cur_sum           # 需要的补数
        ans.append(need)
        used.add(need)

    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n²)` — 每次往答案里加入新数都要遍历已有的数去累计和，随着 `n` 增大，工作量会呈平方增长。  
- **空间复杂度**：`O(n)` — 需要存放 `n` 个整数的列表和集合。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈在于不断累计求和**，以及**不停地检查是否已经出现**。  
实际上，这道题只要让数组**关于 0 对称**，和自然就会是 0：  
- 把 `x` 和 `-x` 同时放进数组，它们的和互相抵消。  
- 如果 `n` 为奇数，还需要一个 `0` 来凑齐长度，因为 `0` 本身不影响和。  

这样我们只需要 **线性地生成** `n//2` 对正负数（`1, -1, 2, -2, …`），再视情况加上 `0`。  

**核心技巧**：对称配对（Symmetric Pair），相当于把数轴左右两边的点成对取，天然抵消。  

**类比**：想象天平两边各放同样重量的砝码，左边放 `+x`，右边放 `-x`，天平始终保持平衡（和为 0）。

#### 代码（Python）

```python
def sumZero_optimal(n: int):
    """
    最优思路：利用正负配对，让和自动为 0
    """
    res = []                     # 最终答案列表
    # 生成 1, -1, 2, -2, ... 直到填满 n//2 对
    for i in range(1, n // 2 + 1):
        res.append(i)            # 正数
        res.append(-i)           # 对应的负数

    # 如果 n 为奇数，需要再加一个 0
    if n % 2 == 1:
        res.append(0)

    return res
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 只遍历一次 `1 … n//2`，每次做常数次操作，随 `n` 成线性增长。相比暴力的 `O(n²)`，快了很多。  
- **空间复杂度**：`O(n)` — 需要存放 `n` 个整数的列表，空间使用和输出规模相同，已经是最优。

## 心得

- **核心技巧**：**对称配对**（把 `x` 与 `-x` 同时放入） + **奇偶处理**（奇数时加 `0`）。  
- **适用题型**：  
  1. “返回和为 0 的数组” 系列（如 *Find Array of Length N With Sum Zero*）。  
  2. “构造满足特定和的集合” 类题目（如 *Construct Array With Given Sum*）。  
  3. “平衡两边的数值” 题目（如 *Two Sum with Opposite Signs*）。  
- **一句话总结解题钥匙**：**让每个正数都有对应的负数，剩下的空位填 0**。

## 反思

- **第一反应**：看到“和为 0”立刻想到“正负抵消”，但因为想写通用的搜索代码，先写了暴力版。  
- **最容易踩的坑**：  
  - **重复**：如果不使用对称配对，随机挑数很容易出现重复，需要额外的哈希表检查。  
  - **奇偶处理**：忘记在 `n` 为奇数时加入 `0`，会导致数组长度不够或总和不为 0。  
  - **范围**：题目限制 `n ≤ 1000`，但若不加限制直接使用太大的数，可能会超出题目对“整数”的常规范围。  
- **下次类似题的第一步**：先判断**是否可以通过对称结构直接满足条件**（如正负配对、递增递减配对等），若可以，就直接构造；若不行，再考虑搜索或 DP。
