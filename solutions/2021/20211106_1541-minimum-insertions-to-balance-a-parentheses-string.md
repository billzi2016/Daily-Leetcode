# #1541. 平衡括号字符串的最少插入次数 / Minimum Insertions to Balance a Parentheses String

> 难度：中等 · 标签：String、Stack、Greedy · [LeetCode 链接](https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/)

## 题目（英文原版）

**Description**

Given a parentheses string s containing only the characters '(' and ')'. A parentheses string is balanced if:
In other words, we treat '(' as an opening parenthesis and '))' as a closing parenthesis.
You can insert the characters '(' and ')' at any position of the string to balance it if needed.
Return the minimum number of insertions needed to make s balanced.

**Examples**

**Example 1:**

```
Input: s = "(()))"
Output: 1
Explanation: The second '(' has two matching '))', but the first '(' has only ')' matching. We need to add one more ')' at the end of the string to be "(())))" which is balanced.
```

**Example 2:**

```
Input: s = "())"
Output: 0
Explanation: The string is already balanced.
```

**Example 3:**

```
Input: s = "))())("
Output: 3
Explanation: Add '(' to match the first '))', Add '))' to match the last '('.
```

**Constraints**

- 1 <= s.length <= 105
- s consists of '(' and ')' only.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**从左到右遍历字符串**，一边维护一个“栈”来保存还没有配对好的左括号 `'('`，一边在遇到右括号 `')'` 时检查它能否和栈顶的左括号配对。  
因为题目要求每个左括号必须匹配 **两个** 连续的右括号 `'))'`，所以我们把右括号分两种情况来看：

| 情况 | 说明 |
|------|------|
| 单个 `')'`（后面没有紧跟另一个 `')'`）| 这只能和一个左括号配对，但配对规则要求两个 `')'`，所以我们**先插入一个 `')'`** 使它变成 `'))'`，然后再去配对。 |
| 成对的 `'))'` | 正常的闭合，尝试和栈顶的左括号配对。如果栈为空，说明没有左括号可配，此时**需要在前面插入一个 `'('`**。 |

这相当于 **“把缺少的字符直接补上”**，每补一次就记一次插入次数。  
栈在这里可以类比为“字典里查词”，`key` 是左括号的位置，`value` 只是一条占位记号，帮助我们知道还有多少左括号等待配对。

**为什么一定能得到正确答案？**  
- 每次我们都把 **当前最紧迫的配对需求** 解决掉（要么补成 `'))'`，要么补一个 `'('`），不会留下可以后面再处理的“半成品”。  
- 最后如果栈里还有左括号，说明这些左括号一直没有遇到配对的 `'))'`，只能在字符串末尾各补两个 `')'`。  

#### 代码（Python）

```python
def minInsertions_brutal(s: str) -> int:
    stack = []          # 用列表模拟栈，存放 '('
    insertions = 0      # 记录需要插入的字符数

    i = 0
    n = len(s)
    while i < n:
        ch = s[i]

        if ch == '(':
            # 左括号直接入栈，等后面找两个 ')'
            stack.append('(')
            i += 1

        else:  # ch == ')'
            # 看看后面是否还有一个 ')' 能组成 '))'
            if i + 1 < n and s[i + 1] == ')':
                # 成对的 '))'，可以直接尝试配对
                if stack:
                    stack.pop()          # 配对成功，弹出一个 '('
                else:
                    # 没有左括号可配，需要在前面插入一个 '('
                    insertions += 1
                i += 2                  # 跳过这两个 ')'
            else:
                # 单独的 ')'
                # 先补一个 ')' 使其变成 '))'，插入计数 +1
                insertions += 1
                # 现在等价于有一个 '))'，继续配对逻辑
                if stack:
                    stack.pop()
                else:
                    insertions += 1      # 仍然没有 '('，再插入一个 '('
                i += 1                  # 只消费当前的 ')'

    # 栈里剩下的每个 '(' 需要补两个 ')'
    insertions += 2 * len(stack)
    return insertions
```

> **关键行中文注释**已经写在代码里，直接运行即可看到结果。

#### 复杂度

- **时间复杂度：`O(n)`**  
  只需要一次线性遍历，每个字符最多被检查两次（例如 `')'` 需要看后面一个字符），所以时间随输入长度 `n` 成正比。  
  大白话：如果字符串有 1000 个字符，程序大约会跑 1000 次左右的循环。

- **空间复杂度：`O(n)`（最坏情况）**  
  当全部都是左括号 `'('` 时，栈会把它们全部存进去，空间随字符数线性增长。  
  大白话：最坏情况下需要额外记住和原字符串一样多的“未配对左括号”。

### 2. 最优解

#### 思路  

虽然上面的“暴力”实现已经是 **线性** 的，但它用了栈，占用了 `O(n)` 的额外空间。我们可以进一步观察：

1. **左括号只需要记住数量**，不需要保存具体位置。  
2. 每次遇到 `')'` 时，只要知道**当前还有多少未配对的左括号**，以及**上一次看到的 `')'` 是否已经配对成 `'))'`**，就可以决定是否需要插入字符。

因此我们只用 **两个整数** 来完成所有配对工作：

- `open_cnt`：当前还没有配对好的左括号的数量。相当于栈的大小，但只用一个计数器保存。
- `need`：**我们现在期待的右括号数量**（每个左括号需要两个 `')'`）。如果 `need` 为 1，说明上一次看到的 `')'` 只配对了一个，需要再来一个 `')'` 才算完整的 `'))'`。

遍历过程：

| 当前字符 | 处理方式 | 说明 |
|----------|----------|------|
| `'('` | `open_cnt += 1`，`need += 2` | 新左括号出现，需要两个右括号才能完成配对。 |
| `')'` | <ul><li>如果 `need == 0`（上一次没有待补的 `')'`），说明这是**单独的** `')'`，我们必须先插入一个 `')'` 使其变成 `'))'`，计数 `insertions += 1`，并把 `need` 设为 **1**（已经配好一个 `')'`，还差一个）。</li><li>否则 `need -= 1`（用掉一个期待的右括号）。</li></ul> | 通过 `need` 判断这是不是成对的 `'))'`。 |
| 当 `need` 变成 **负数** 时，说明我们已经得到 **两个 `')'`**，但却没有左括号与之匹配，此时需要 **插入一个 `'('`**，计数 `insertions += 1`，并把 `need` 重置为 **0**（因为这两个 `')'` 已经被新插入的 `'('` 完全配对）。 | 这一步是贪心的核心：**只在必须的时候才插入**，并且立刻把多余的右括号消化掉。 |

遍历结束后，可能还有未配对的左括号 `open_cnt`，每个左括号还缺 `need` 个右括号（实际上 `need` 已经等于 `2 * open_cnt`），直接把它们全部加到答案里即可。

**为什么是最优的？**  
- **每次插入都是迫不得已**：只有在左括号缺少右括号、或右括号没有左括号可配时才插入，且插入的字符恰好可以立刻完成一次配对，避免了后续再补的可能。  
- **只用常数空间**：不需要保存每个左括号的具体位置，只用计数器即可，空间从 `O(n)` 降到 `O(1)`。  

#### 代码（Python）

```python
def minInsertions(s: str) -> int:
    insertions = 0   # 需要插入的字符总数
    open_cnt = 0     # 未配对的 '(' 的数量
    need = 0         # 还缺多少个 ')' 使当前的配对完整（每个 '(' 需要 2 个 ')'）

    i = 0
    n = len(s)
    while i < n:
        if s[i] == '(':
            open_cnt += 1          # 新的 '(' 加入等待配对的池子
            need += 2              # 这个 '(' 需要两个 ')'
            i += 1

        else:  # s[i] == ')'
            # 处理单个 ')' 的情况：如果当前没有待配的 ')'（need 为 0），
            # 说明这是一个孤立的 ')', 必须先补一个 ')' 变成 '))'
            if need == 0:
                insertions += 1    # 插入一个 ')' 使其成为 '))'
                need = 1           # 已经用了一个 ')', 还差一个 ')'
            else:
                need -= 1           # 用掉一个期待的 ')'

            # 当 need 变成负数，说明已经出现了两个连续的 ')'
            # 但此时左括号数量不足，需要在前面补一个 '('
            if need < 0:
                insertions += 1    # 插入 '('
                # 这两个 ')' 已经被新插入的 '(' 完全配对，恢复 need 为 0
                need = 0
                # 同时把已经配对好的 '(' 从计数中扣掉
                open_cnt -= 1

            i += 1

    # 循环结束后，可能还有未配对的 '('，每个 '(' 还缺 need（其实等于 2*open_cnt）个 ')'
    insertions += need
    return insertions
```

> 代码采用 **贪心** 思路，只用 `open_cnt`、`need`、`insertions` 三个整数，时间 `O(n)`，空间 `O(1)`。

#### 复杂度

- **时间复杂度：`O(n)`**  
  只遍历一次字符串，`n` 越大，运行时间线性增长。比如 10 万字符的输入，循环也只会跑 10 万次左右。

- **空间复杂度：`O(1)`**  
  只用了常数个整数变量，不会随输入长度增长。相比暴力解省掉了栈的 `O(n)` 空间。

## 心得

- **核心技巧**：**贪心 + 计数**。在遇到不符合配对规则的字符时，立刻补足最少的字符，使得当前局部已经合法，再继续向后扫描。
- **适用的题型**  
  1. **需要把字符配对成特定模式** 的字符串题，如 “Make String Balanced” (`'{'` 与 `'}'`)、`"Minimum Add to Make Parentheses Valid"`（每个 `'('` 只匹配一个 `')'`）  
  2. **连续字符的配对要求**，比如 “Remove All Adjacent Duplicates in String II”（需要 k 个相同字符一起消除）  
  3. **栈/计数类的平衡检查**，如 “Valid Parenthesis String”  
- **一句话总结解题钥匙**：**只在配对缺口出现时立即插入最少字符，保持局部始终合法**。

## 反思

- **第一反应**：看到题目立刻想到用栈来配对括号，然后再考虑特殊的 `'))'` 规则。  
- **最容易踩的坑**  
  - 忽略 **单个 `')'`** 需要补一个 `')'` 的情况，会导致计数少 1。  
  - 处理 **连续 `'))'`** 时，如果栈空忘记插入 `'('`，答案会不完整。  
  - 结束后忘记把剩余的左括号对应的 `'))'` 加上，导致答案偏小。  
- **下次遇到同类题**：第一步先 **明确配对规则**（每个左括号需要多少右括号），然后 **用计数器代替完整栈**，在遍历时实时判断是否缺少字符并即时插入。这样既能保证正确性，又能把空间压到最小。
