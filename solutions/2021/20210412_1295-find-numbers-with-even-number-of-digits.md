# #1295. 偶数位数字的计数 / Find Numbers with Even Number of Digits

> 难度：简单 · 标签：Array、Math · [LeetCode 链接](https://leetcode.com/problems/find-numbers-with-even-number-of-digits/)

## 题目（英文原版）

**Description**

Given an array nums of integers, return how many of them contain an even number of digits.

**Examples**

**Example 1:**

```
Input: nums = [12,345,2,6,7896]
Output: 2
Explanation: 
12 contains 2 digits (even number of digits). 
345 contains 3 digits (odd number of digits). 
2 contains 1 digit (odd number of digits). 
6 contains 1 digit (odd number of digits). 
7896 contains 4 digits (even number of digits). 
Therefore only 12 and 7896 contain an even number of digits.
```

**Example 2:**

```
Input: nums = [555,901,482,1771]
Output: 1 
Explanation: 
Only 1771 contains an even number of digits.
```

**Constraints**

- 1 <= nums.length <= 500
- 1 <= nums[i] <= 105

给定一个整数数组（array）`nums`，返回其中 **位数为偶数** 的元素个数。

**示例 2**  
**约束条件**  

**示例**

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是：遍历数组里的每个整数，**逐个数它有多少位**，如果位数是偶数就计数。  
- **用到的数据结构**：只需要一个普通的列表 `nums`（相当于装有若干本书的书架），以及一个整数 `cnt` 用来记录符合条件的书的数量（像是统计符合要求的书的计数器）。
- **位数的获取**：把数字不断除以 `10`（相当于把一本厚厚的书拆成一页页往后翻），每除一次就说明去掉了一位，除到 `0` 时累计的除法次数就是该数字的位数。  
- **正确性**：因为十进制每除一次就去掉最右边一位，循环结束时恰好遍历了所有位，所以得到的计数必然等于实际位数。随后判断 `位数 % 2 == 0`（偶数）即可。

#### 代码（Python）

```python
def findNumbers(nums):
    """
    :param nums: List[int]  待检测的整数数组
    :return: int          符合“位数为偶数”的整数个数
    """
    cnt = 0                     # 计数器，记录满足条件的数字个数

    for num in nums:            # 逐个遍历数组中的每个数
        digits = 0              # 用来统计当前数字的位数

        # 通过不断除以 10 来“数位”。相当于把数字拆成一位一位地看
        while num > 0:
            digits += 1         # 去掉一位，计数器加一
            num //= 10          # 整数除法，丢掉最右边的那一位

        # 判断位数是否为偶数，若是则计数器加一
        if digits % 2 == 0:
            cnt += 1

    return cnt
```

#### 复杂度  

- **时间复杂度**：`O(n * log₁₀M)`  
  - `n` 是数组长度，`M` 是数组中最大数的大小（本题 ≤ 10⁵）。对每个数我们要除以 10 直到为 0，除法次数大约等于该数的位数，即 `log₁₀M`。可以把 `log₁₀M` 想成“把一个 5 位数拆成 5 片需要 5 次操作”。所以整体时间是 `n` 乘以每个数的位数。  
- **空间复杂度**：`O(1)`  
  - 只用了常数级别的额外变量 `cnt、digits、num`，不随输入规模增长。

### 2. 最优解

#### 思路  
从暴力解来看，主要的**瓶颈**在于对每个数字都要进行 `while` 循环除以 10。其实这一步已经是最小的可能——我们必须至少看一次每个数字的每一位才能判断位数。  
不过，有两种方式可以**省掉显式的循环**：

1. **把整数转成字符串**，直接用 `len(str(num))` 获得位数。字符串的长度本质上已经帮我们数好了位数，代码更简洁。  
2. **利用数学公式**：`int(math.log10(num)) + 1` 也能得到位数（因为 `log10` 给出的是位数的指数），但要注意 `num = 0` 的特殊情况（本题不涉及 0）。

这两种写法的时间复杂度仍是 `O(n)`，因为对每个元素我们只做 **一次** “获取位数”的操作，而不再在内部循环。空间上仍是 `O(1)`（字符串的临时存储不计入额外空间）。

下面采用**字符串法**，因为它最直观、最不容易出错，尤其适合初学者。

#### 代码（Python）

```python
def findNumbers(nums):
    """
    使用字符串直接获取位数，代码简洁且运行高效。
    """
    cnt = 0                     # 统计满足条件的数字个数

    for num in nums:
        # 把整数转换成字符串，len() 直接返回位数
        if len(str(num)) % 2 == 0:   # 位数为偶数则计数
            cnt += 1

    return cnt
```

> **小技巧**：如果你对 Python 的 `list comprehension` 熟悉，还可以写成一行  
> `return sum(1 for x in nums if len(str(x)) % 2 == 0)`

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 只遍历一次数组，每个元素的 `str` 转换和 `len` 操作都是常数时间（相当于一次“快速扫描”），所以总体随 `n` 线性增长。相比暴力解省掉了内部的 `log₁₀M` 次循环，实际跑起来更快。  
- **空间复杂度**：`O(1)`（不计临时字符串）  
  - 只用了常数级别的计数器，额外的存储不随输入规模扩大。

## 心得

- **核心技巧**：**位数判定**——可以用除法循环、字符串长度或对数公式三种方式实现。  
- **适用场景**：  
  1. 判断整数的位数奇偶（本题）。  
  2. “数字翻转”或“判断回文数”时，需要先知道位数。  
  3. “统计满足某个位数范围的数”如统计 3 位数、4 位数的出现次数。  
- **一句话总结**：把数字当成“文字”来看，用 `len(str(num))` 直接读出它的长度，省去手动除法的麻烦。

## 反思

- **第一反应**：看到“位数”，自然想到“一位一位地除 10”。这在脑海里像是把一本书拆成页的过程。  
- **最容易踩的坑**：  
  - 忘记 `num = 0` 的特殊情况（`while num > 0` 会直接跳过），导致位数算成 0。虽然本题约束 `num ≥ 1`，但在实际面试或扩展时要留意。  
  - 使用 `log10` 时要注意浮点数精度，最好加上 `int(... ) + 1` 并处理 `num = 0`。  
- **下次遇到同类题**：第一步先决定“如何快速得到位数”。如果语言提供了直接的长度/字符串转换，就优先使用；否则用除法循环是最安全的备选方案。
