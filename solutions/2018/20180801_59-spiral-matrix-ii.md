# #59. 螺旋矩阵 II / Spiral Matrix II

## 题目（英文原版）

**Description**

Given a positive integer n, generate an n x n matrix filled with elements from 1 to n2 in spiral order.

**Examples**

**Example 1:**

```
Input: n = 3
Output: [[1,2,3],[8,9,4],[7,6,5]]
```

**Example 2:**

```
Input: n = 1
Output: [[1]]
```

**Constraints**

- 1 <= n <= 20

---

## 题目（中文翻译）

给定一个正整数 `n`，生成一个 `n × n` 的矩阵，使其中的元素从 `1` 到 `n²` 按螺旋顺序（spiral order）填充。

**示例 1**  
**输入**: `n = 3`  
**输出**: `[[1,2,3],[8,9,4],[7,6,5]]`

**示例 2**  
**输入**: `n = 1`  
**输出**: `[[1]]`

**约束条件**  
- `1 <= n <= 20`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把矩阵看成一张空白的地图**，从左上角出发，按照“右→下→左→上”四个方向依次走，每走一步就在当前位置写下当前的数字。  
只要走到的格子已经写过数字，或者越界了（走到矩阵外面），就**换方向**，继续前进，直到把 `1 … n²` 都写完。

- **数据结构**：  
  - `matrix`：二维列表（list of list），相当于一张 `n × n` 的表格，初始时全部填 `0`（相当于“空格”）。  
  - `visited`（可选）：用来记录已经写过数字的格子。其实我们可以直接检查 `matrix[i][j] != 0` 来判断是否已经访问过，这就像在 **查字典**：键是坐标 `(i, j)`，值是格子里是否已经有数字。

- **为什么正确**：  
  按照顺时针螺旋的顺序遍历所有格子，**每一步都保证**：① 当前格子在矩阵范围内，② 该格子还未被填过。只要这两个条件满足，就可以安全地写入下一个数字。循环结束时，所有格子恰好被访问一次，得到的就是题目要求的螺旋矩阵。

- **时间/空间复杂度**：  
  - 我们需要遍历 `n²` 个格子，每个格子只写一次，检查方向也只做常数次操作，所以 **时间复杂度是 O(n²)**。  
    > 大白话：如果矩阵是 5×5（共 25 格），我们大约会做 25 次“写数”操作，复杂度随格子数量的平方增长。  
  - 需要额外的 `n²` 空间存放结果矩阵（这是必须的），再加上常数级的方向数组和指针，**空间复杂度是 O(n²)**。

#### 代码（Python）

```python
def generateMatrix_brute(n: int):
    # 创建 n×n 的全 0 矩阵，类似一张空白的纸
    matrix = [[0] * n for _ in range(n)]

    # 四个方向：右、下、左、上，分别对应坐标的增量
    dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]

    row, col = 0, 0          # 当前坐标，起点在左上角
    dir_idx = 0              # 当前使用的方向下标（0 表示向右）

    for num in range(1, n * n + 1):
        matrix[row][col] = num               # 把数字写进当前格子

        # 预计算下一步的坐标
        nxt_row = row + dirs[dir_idx][0]
        nxt_col = col + dirs[dir_idx][1]

        # 判断是否需要换方向：
        # 1）下一步超出矩阵边界；2）下一步已经被填过（matrix[nxt_row][nxt_col] != 0）
        if not (0 <= nxt_row < n and 0 <= nxt_col < n) or matrix[nxt_row][nxt_col] != 0:
            dir_idx = (dir_idx + 1) % 4      # 顺时针转向
            nxt_row = row + dirs[dir_idx][0]
            nxt_col = col + dirs[dir_idx][1]

        row, col = nxt_row, nxt_col          # 移动到下一格

    return matrix
```

#### 复杂度

- **时间复杂度**：`O(n²)` — 每个格子只写一次，整体操作随格子数的平方增长。  
- **空间复杂度**：`O(n²)` — 需要保存整个 `n × n` 的矩阵（题目本身就要求返回这么大的结果）。

---

### 2. 最优解

#### 思路  

暴力解已经是 **O(n²)**，这是不可再降低的下界，因为我们必须把 `n²` 个数字写进矩阵。  
所谓“最优”，指的是 **不需要额外的 visited 判断**，直接利用四条边界来控制前进方向，这样代码更简洁、常数因子更小。

**核心思想**：  
- 维护四条“活动边界”——`top`, `bottom`, `left`, `right`。  
- 每遍历完一条边后，收紧相应的边界（例如向右走完上边后，`top` 向下移动一行）。  
- 按照 **右 → 下 → 左 → 上** 的顺序循环，直至所有数字填完。

**为什么快**：  
- 只需要检查当前位置是否越过当前的边界，而不必每次都去查询矩阵里是否已经有数字。  
- 边界的收紧操作是 O(1) 的常数操作，整体仍是 O(n²) 时间，但省掉了 `if matrix[nxt_row][nxt_col] != 0` 这类额外的数组访问。

**类比**：  
把矩阵想象成一块正在被“削层”的蛋糕，先切掉最外层的四条边（右、下、左、上），再把剩下的内部视作一个更小的矩阵，继续切。每次切完一层，蛋糕的尺寸就缩小了。

#### 代码（Python）

```python
def generateMatrix_optimal(n: int):
    # 初始化全 0 矩阵
    matrix = [[0] * n for _ in range(n)]

    # 四条活动边界，初始时覆盖整个矩阵
    top, bottom = 0, n - 1
    left, right = 0, n - 1

    num = 1               # 当前要写入的数字
    max_num = n * n

    while num <= max_num:
        # 1. 从左到右填充上边
        for col in range(left, right + 1):
            matrix[top][col] = num
            num += 1
        top += 1          # 上边界下移，下一轮不再碰到已填的行

        # 2. 从上到下填充右边
        for row in range(top, bottom + 1):
            matrix[row][right] = num
            num += 1
        right -= 1        # 右边界左移

        # 3. 从右到左填充下边（要先判断是否还有未填的行）
        if top <= bottom:
            for col in range(right, left - 1, -1):
                matrix[bottom][col] = num
                num += 1
            bottom -= 1   # 下边界上移

        # 4. 从下到上填充左边（要先判断是否还有未填的列）
        if left <= right:
            for row in range(bottom, top - 1, -1):
                matrix[row][left] = num
                num += 1
            left += 1    # 左边界右移

    return matrix
```

#### 复杂度

- **时间复杂度**：`O(n²)` — 仍然需要写入 `n²` 个数字，但没有额外的“已访问”检查，常数因子更小。  
- **空间复杂度**：`O(n²)` — 仅存放返回的矩阵，额外的四个边界变量占 O(1) 空间。

## 心得

- **核心技巧**：使用**四条活动边界**（或“层层收缩”的思路）来控制螺旋遍历。  
- **适用的题型**：  
  1. **Spiral Matrix I**（从已有矩阵中按螺旋顺序读取）。  
  2. **矩阵旋转**（如 90° 旋转，常用层遍历）。  
  3. **分层遍历**（如 LeetCode 54 “螺旋矩阵”。）  
- **一句话总结**：**“把矩阵当作被削的蛋糕，每走完一圈就把对应的边界收紧”**，这样就能自然得到螺旋顺序。

## 反思

- **第一反应**：直接想象一个人走在网格上，遇到墙或已经走过的格子就右转。  
- **最容易踩的坑**：  
  - **边界收紧的顺序错误**（比如先收紧左边导致漏填），导致出现空格或重复填。  
  - **忘记在填完下边或左边前检查 `top <= bottom` / `left <= right`**，在奇数尺寸时会多走一遍中心行/列。  
- **下次遇到同类题**：第一步先 **画出矩阵的四条边界**，思考“每遍历完一条边后，如何收紧”。这样可以快速构造出不需要额外 visited 检查的高效解法。
