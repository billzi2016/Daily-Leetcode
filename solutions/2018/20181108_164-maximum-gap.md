## 题目（英文原版）

**Description**

Given an integer array nums, return the maximum difference between two successive elements in its sorted form. If the array contains less than two elements, return 0.
You must write an algorithm that runs in linear time and uses linear extra space.

**Examples**

**Example 1:**

```
Input: nums = [3,6,9,1]
Output: 3
Explanation: The sorted form of the array is [1,3,6,9], either (3,6) or (6,9) has the maximum difference 3.
```

**Example 2:**

```
Input: nums = [10]
Output: 0
Explanation: The array contains less than 2 elements, therefore return 0.
```

**Constraints**

- 1 <= nums.length <= 105
- 0 <= nums[i] <= 109

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：先把数组排好序，然后一次遍历相邻的两个数，记录它们的差值的最大值即可。

- **用到的数据结构**：Python 的列表（list）和内置的排序函数 `sorted`。可以把 `sorted` 想象成“把一堆乱七八糟的书按照编号排好”，排好以后我们只需要顺着书架走一遍，就能看到每两本相邻书之间编号的差距。
- **为什么正确**：题目要求的“相邻元素的最大差”本身就定义在排好序的数组上。只要我们得到排好序的数组，顺序遍历一次必然能找到最大的相邻差。
- **时间/空间复杂度**：  
  - 排序的时间复杂度是 `O(n log n)`（`n` 是数组长度），这相当于“把 `n` 本书按编号排好序需要的时间”。  
  - 排序后再遍历一次是 `O(n)`，两者相加仍是 `O(n log n)`。  
  - 额外空间只用了排序函数产生的临时列表，最坏情况是 `O(n)`（如果不原地排序的话）。

#### 代码（Python）

```python
def maximumGap_brute(nums):
    """
    暴力解：先排序，再一次遍历求相邻差的最大值
    """
    if len(nums) < 2:          # 少于两个元素直接返回 0
        return 0

    # 1. 对数组进行升序排序（相当于把书按编号排好）
    sorted_nums = sorted(nums)  # O(n log n)

    # 2. 初始化最大差值为 0
    max_gap = 0

    # 3. 依次比较相邻两个元素的差值
    for i in range(1, len(sorted_nums)):
        gap = sorted_nums[i] - sorted_nums[i - 1]   # 当前相邻差
        if gap > max_gap:                          # 若更大则更新
            max_gap = gap

    return max_gap
```

#### 复杂度

- **时间复杂度**：`O(n log n)` —— 排序的时间主导整个算法，就像把 `n` 本书排好序需要 `n log n` 的时间。
- **空间复杂度**：`O(n)` —— 需要额外存放排好序的数组（如果使用原地排序可以降到 `O(1)`，但这里为了代码简洁用了 `sorted`）。

### 2. 最优解

#### 思路  

暴力解的瓶颈在 **排序**，`O(n log n)` 已经超出了题目要求的线性时间。  
要做到 `O(n)`，我们可以利用 **桶排序 + 鸽巢原理**（Pigeonhole Principle）。

**关键观察**：

1. 设数组的最小值为 `min_val`，最大值为 `max_val`。如果把 `min_val` 与 `max_val` 之间的区间均匀划分成 `n‑1`（`n` 为数组长度）个小区间（桶），那么 **必然有至少一个桶是空的**（因为有 `n` 个数放进 `n‑1` 个桶）。  
2. **最大相邻差一定出现在两个非空桶之间的间隙**，而不是同一个桶内部。因为同一个桶的宽度已经被限制得很小（不超过理论上的最大相邻差）。

**步骤**：

1. **求最小值、最大值**：一次遍历得到 `min_val`、`max_val`。  
2. **确定桶的大小**  
   - 桶的最小可能宽度 = `ceil((max_val - min_val) / (n - 1))`。  
   - 为避免除以 0（当所有数相同），我们取 `max(1, ...)`，确保每个桶至少宽度为 1。  
3. **创建桶**：每个桶只需要记录 **桶内的最小值** 与 **最大值**（两者初始化为 `None`），共 `bucket_cnt = (max_val - min_val) // bucket_size + 1` 个桶。  
4. **遍历原数组，把每个数放入对应桶**：  
   - 桶索引 = `(num - min_val) // bucket_size`。  
   - 更新该桶的 `bucket_min`、`bucket_max`。  
5. **扫描桶**：从左到右找出相邻非空桶之间的差值 `curr_gap = bucket_min[i] - prev_bucket_max`，取最大值即为答案。  
   - `prev_bucket_max` 记录上一个非空桶的最大值。  

这样只用了几次线性遍历，时间 `O(n)`，额外空间 `O(n)`（存桶信息）。

#### 代码（Python）

```python
import math

def maximumGap(nums):
    """
    最优解：桶排序（线性时间）
    思路：利用鸽巢原理，最大间隙一定出现在两个非空桶之间。
    """
    n = len(nums)
    if n < 2:                     # 少于两个元素直接返回 0
        return 0

    # 1. 找到全局最小值和最大值
    min_val = min(nums)
    max_val = max(nums)
    if min_val == max_val:        # 全部相同，间隙必为 0
        return 0

    # 2. 计算桶的大小和数量
    #   桶宽度向上取整，确保最多只有 n-1 个非空桶
    bucket_size = max(1, math.ceil((max_val - min_val) / (n - 1)))
    bucket_cnt = (max_val - min_val) // bucket_size + 1

    # 3. 初始化每个桶的最小值和最大值（使用 None 表示空桶）
    bucket_min = [None] * bucket_cnt
    bucket_max = [None] * bucket_cnt

    # 4. 把每个数放进对应的桶，更新桶内最值
    for num in nums:
        idx = (num - min_val) // bucket_size   # 计算桶索引
        if bucket_min[idx] is None:            # 第一次放入该桶
            bucket_min[idx] = bucket_max[idx] = num
        else:
            bucket_min[idx] = min(bucket_min[idx], num)
            bucket_max[idx] = max(bucket_max[idx], num)

    # 5. 扫描桶，计算相邻非空桶之间的间隙
    max_gap = 0
    prev_max = None  # 上一个非空桶的最大值

    for i in range(bucket_cnt):
        if bucket_min[i] is None:   # 空桶直接跳过
            continue
        if prev_max is not None:
            # 当前桶的最小值 与 上一个非空桶的最大值 之差
            max_gap = max(max_gap, bucket_min[i] - prev_max)
        prev_max = bucket_max[i]    # 更新 prev_max 为当前桶的最大值

    return max_gap
```

#### 复杂度

- **时间复杂度**：`O(n)` —— 只做了几次对 `n` 长度数组的线性遍历，相当于“一遍遍历就能得到答案”。比暴力的 `O(n log n)` 快很多，尤其在 `n` 很大时优势明显。
- **空间复杂度**：`O(n)` —— 需要 `bucket_cnt`（最多 `n+1`）个桶来存最小值和最大值。相当于“给每本书预留一个小抽屉来记录该抽屉里最小和最大编号”。

## 心得

- 这道题核心考察 **桶排序 + 鸽巢原理**，即通过划分区间把问题的 “搜索范围” 大幅缩小，从而实现线性时间。
- 这种技巧适用于以下类似题型：
  1. **最大相邻差**（本题）  
  2. **找出数组中第 K 大/小的数**（利用桶/计数排序）  
  3. **分桶统计（如直方图最大矩形面积）**  
- **一句话总结解题钥匙**：*最大间隙一定跨越空桶 → 只需记录每个桶的极值即可*。

## 反思

- **第一反应**：直接排序然后遍历——最直观但不满足线性时间要求。  
- **最容易踩的坑**：  
  - 当所有元素相同时，`bucket_size` 会被算成 0，需要提前返回 0。  
  - 计算桶大小时要使用向上取整 `ceil`，否则会出现 “桶宽度太小导致除以 0” 或 “桶数量不足”。  
  - 处理空桶时必须跳过，否则会把 `None` 当作数参与比较导致错误。  
- **下次遇到同类题**：第一步先思考“有没有办法把搜索空间划分成若干区间”，然后检查“最大/最小值是否一定落在相邻非空区间之间”。这样可以快速定位到桶排序或计数排序的思路。
