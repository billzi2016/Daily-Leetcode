# #73. 矩阵置零 / Set Matrix Zeroes

## 题目（英文原版）

**Description**

Given an m x n integer matrix matrix, if an element is 0, set its entire row and column to 0's.
You must do it in place.
Follow up:

**Examples**

**Example 1:**

```
Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```

**Example 2:**

```
Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

**Constraints**

- m == matrix.length
- n == matrix[0].length
- 1 <= m, n <= 200
- -231 <= matrix[i][j] <= 231 - 1

## 题目（中文翻译）

给定一个 **m × n** 的整数矩阵 `matrix`，如果某个元素为 **0**，则将其所在的整行和整列全部设为 **0**。  
要求 **原地**（in place）完成修改。

## 示例

### 示例 1
**输入:** `matrix = [[1,1,1],[1,0,1],[1,1,1]]`  
**输出:** `[[1,0,1],[0,0,0],[1,0,1]]`

### 示例 2
**输入:** `matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]`  
**输出:** `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`

## 约束条件
- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

## 进阶
- 请尝试使用 **O(1)** 的额外空间（不计入返回结果的空间）来完成此任务。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**先把所有为 0 的位置记下来**，等全部遍历结束后，再把对应的行和列全部改成 0。  
- 记录位置可以用两个集合（`set`），一个集合存放需要清零的行号，另一个集合存放需要清零的列号。  
- `set` 就像一本字典，里面的“词”是行号或列号，查找是否已经存在非常快（相当于在字典里找页码），所以可以在 O(1) 时间判断一个行/列是否需要被置零。  

为什么这样一定对？  
1. 第一次遍历时，只是**观察**矩阵，记录哪些行列出现了 0，矩阵本身不动。  
2. 第二次遍历时，依据记录好的行列信息统一把对应的元素改成 0。这样不会因为“先改了再观察”而产生误判。  

#### 代码（Python）

```python
from typing import List

def setZeroes_brute(matrix: List[List[int]]) -> None:
    """
    暴力解：两次遍历 + 两个集合记录要清零的行列
    不返回值，直接在原矩阵上修改（符合题目要求）
    """
    m, n = len(matrix), len(matrix[0])
    rows_to_zero = set()   # 记录出现 0 的行号
    cols_to_zero = set()   # 记录出现 0 的列号

    # 第一次遍历：找出所有为 0 的单元格
    for i in range(m):
        for j in range(n):
            if matrix[i][j] == 0:
                rows_to_zero.add(i)   # 把第 i 行加入集合
                cols_to_zero.add(j)   # 把第 j 列加入集合

    # 第二次遍历：根据记录的行列统一置零
    for i in range(m):
        for j in range(n):
            if i in rows_to_zero or j in cols_to_zero:
                matrix[i][j] = 0
```

#### 复杂度  

- **时间复杂度**：`O(m * n)`  
  两次完整遍历矩阵，每次都看每个元素一次。  
  用大白话说，就是如果矩阵有 1000 × 1000 = 1 000 000 个格子，程序大概会跑 2 000 000 次“检查”，这就是线性随矩阵大小增长的意思。  

- **空间复杂度**：`O(m + n)`  
  需要额外存储两组行号和列号，最坏情况下每一行每一列都出现 0，集合里会有 `m` 个行号和 `n` 个列号。  
  用生活化的比喻：就像在笔记本上记下所有要擦掉的行和列，笔记本的页数和行数正好和矩阵的行列数成正比。

### 2. 最优解

#### 思路  

虽然暴力解已经是 `O(m·n)` 的时间，但它用了 `O(m+n)` 的额外空间。  
**空间瓶颈**在于我们额外用了两个集合。如果要求 **原地**（`in‑place`）且 **常数空间**（`O(1)`），就要把“记录信息”的空间压缩到矩阵本身。

关键观察：

1. **第一行 / 第一列本身可以当作标记位**。  
   - 当遍历到某个元素为 0 时，我们把它所在行的第一列设为 0，所在列的第一行也设为 0。这样，`matrix[i][0]` 表示第 `i` 行是否需要清零，`matrix[0][j]` 表示第 `j` 列是否需要清零。  
   - 这就好像在一本书的封面（第一行/列）写下“这页后面全要擦掉”，以后再翻到该页时只要看封面就知道要不要擦。

2. **但第一行和第一列本身是否也需要被清零** 需要额外记住，因为它们被用作标记位，不能直接覆盖。  
   - 用两个布尔变量 `first_row_has_zero`、`first_col_has_zero` 分别记录原始矩阵第一行/列是否出现过 0。

3. **两遍完成**  
   - **第一遍**（从左上角开始，但跳过第一行第一列）把标记写进第一行/列。  
   - **第二遍**（逆序从右下角开始），根据标记把对应的行列置零。逆序遍历是为了在修改矩阵时不破坏还未使用的标记。  
   - 最后，根据 `first_row_has_zero`、`first_col_has_zero` 再统一处理第一行和第一列。

这样就只用了常数个额外变量，实现了 `O(1)` 额外空间。

#### 代码（Python）

```python
from typing import List

def setZeroes_opt(matrix: List[List[int]]) -> None:
    """
    最优解：使用矩阵的第一行和第一列作为标记位，做到 O(1) 额外空间
    """
    m, n = len(matrix), len(matrix[0])

    # 1️⃣ 先判断第一行、第一列是否本来就有 0
    first_row_has_zero = any(matrix[0][j] == 0 for j in range(n))
    first_col_has_zero = any(matrix[i][0] == 0 for i in range(m))

    # 2️⃣ 用第一行/列记录其余位置的 zero 信息
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = 0   # 标记第 i 行需要清零
                matrix[0][j] = 0   # 标记第 j 列需要清零

    # 3️⃣ 从右下角逆序遍历，根据标记置零（避免提前覆盖标记）
    for i in range(m - 1, 0, -1):
        for j in range(n - 1, 0, -1):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0

    # 4️⃣ 最后处理第一行和第一列
    if first_row_has_zero:
        for j in range(n):
            matrix[0][j] = 0

    if first_col_has_zero:
        for i in range(m):
            matrix[i][0] = 0
```

#### 复杂度  

- **时间复杂度**：`O(m * n)`  
  仍然是两次遍历矩阵，和暴力解一样快。  
  与暴力解对比：**时间没有增加**，但我们省掉了额外的集合操作。

- **空间复杂度**：`O(1)`  
  只用了四个布尔变量（常数个）和若干循环计数器，**不随矩阵大小增长**。  
  用通俗的话说，就是“只在脑子里记了几句话”，不需要额外的笔记本来记录行列信息。

## 心得

- **核心技巧**：**原地标记**（把额外信息写回输入数组的“空余位置”）。  
- **适用的题型**  
  1. “矩阵中 0 的行列置零”（本题）。  
  2. “若矩阵中出现 1，则把所在行列全部设为 1” 类似题目。  
  3. “二维网格中使用首行/列保存状态的翻转或计数” 例如 LeetCode 73. Set Matrix Zeroes 的变体。  
- **一句话总结**：**把“要记的东西”藏在矩阵的第一行/列里，既不占额外空间，又能随时查到**。

## 反思

- **第一反应**：直接用两个集合记录行列，写完后再遍历一次把对应位置改为 0。  
- **最容易踩的坑**  
  1. **在第一次遍历时就直接把行列置零**，会导致后面的 0 被“误传”，产生错误的结果。  
  2. **忘记保存第一行、第一列原始的 zero 信息**，导致用作标记的行/列被错误覆盖。  
  3. **逆序遍历**的必要性：如果正序遍历第二遍，可能在处理某个单元格前把它所在行/列的标记改成 0，导致后面的格子被错误清零。  
- **下次遇到同类题**：第一步先**判断哪些位置需要“记”，再决定是用额外集合还是“原地标记”。如果空间要求是 O(1)，立刻想到把标记写回到输入结构的“第一行/列”或其他“冗余”位置。
