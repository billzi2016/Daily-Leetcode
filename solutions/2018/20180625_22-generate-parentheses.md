# #22. 生成括号 / Generate Parentheses

> 难度：中等 · 标签：String、Dynamic Programming、Backtracking · [LeetCode 链接](https://leetcode.com/problems/generate-parentheses/)

---

## 题目（英文原版）

**Description**

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

**Examples**

**Example 1:**

```
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```

**Example 2:**

```
Input: n = 1
Output: ["()"]
```

**Constraints**

- 1 <= n <= 8

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：先把所有可能的由 `2n` 个字符 `'('`、`')'` 组成的序列枚举出来，然后把「合法」的挑选出来。  
这里的「所有可能」相当于把每个位置都放 `'('` 或 `')'`，相当于二进制的全排列，长度为 `2n`，一共有 `2^{2n}` 种。  

- **用到的数据结构**：  
  - `list` 用来保存每一种完整的字符序列。  
  - 「哈希表」在这里不需要，但如果要快速判断是否已经出现过某个序列，哈希表就像一本字典，`key` 是序列，`value` 可以是布尔值「已出现」。
- **为什么正确**：  
  - 我们把所有可能的排列都生成了，合法的自然包含在其中。只要再加一步「合法性检测」就能得到答案。
- **合法性检测**：遍历序列，维护一个计数器 `balance`，`'('` 加一，`')'` 减一；只要 `balance` 在任何位置小于 0（说明出现了右括号先于左括号）或遍历结束后不等于 0（左右括号数量不匹配），则该序列非法。

- **时间/空间复杂度**：  
  - 枚举所有序列需要 `2^{2n}` 次循环，每次循环里要检查 `2n` 长度的合法性，整体是 **O( 2^{2n} * n )**。  
  - 空间上我们需要保存所有合法序列，最多是卡塔兰数 `C_n ≈ 4^n / (n^{3/2}√π)`，所以空间是 **O(C_n * n)**，但在最坏情况下（仅保存临时序列）也会达到 **O(2^{2n})**。

> **大白话解释**：  
> `O(2^{2n})` 就像把一把 2n 把的钥匙每把都拧两次（开/关）所有组合，数量会呈指数级爆炸，几分钟能算完的范围只能到 n≈4 左右。

#### 代码（Python）

```python
def generateParenthesis_brute(n: int):
    """暴力枚举 2n 长度的所有括号序列，然后筛选合法的"""
    res = []                     # 用来保存所有合法答案
    total_len = 2 * n            # 序列总长度

    def is_valid(s: str) -> bool:
        """检查字符串 s 是否是合法的括号序列"""
        balance = 0
        for ch in s:
            if ch == '(':
                balance += 1
            else:                # ch == ')'
                balance -= 1
            if balance < 0:      # 右括号先出现，非法
                return False
        return balance == 0      # 最终必须平衡

    # 递归枚举每一种可能的字符放置
    def dfs(pos: int, cur: list):
        """pos: 当前已经填了多少个字符；cur: 正在构造的字符列表"""
        if pos == total_len:      # 已经填满 2n 个字符
            s = ''.join(cur)
            if is_valid(s):
                res.append(s)
            return
        # 放 '('
        cur.append('(')
        dfs(pos + 1, cur)
        cur.pop()                 # 回溯，撤销

        # 放 ')'
        cur.append(')')
        dfs(pos + 1, cur)
        cur.pop()                 # 回溯，撤销

    dfs(0, [])
    return res
```

#### 复杂度

- **时间复杂度**：`O( 2^{2n} * n )`  
  - `2^{2n}` 是所有可能的序列数，`n` 是每次检查合法性时遍历的长度。  
  - 用大白话说，就是「把所有钥匙一次拧完，再每把钥匙检查一次」。
- **空间复杂度**：`O( 2^{2n} )`（递归栈 + 临时字符串）  
  - 递归深度是 `2n`，每层保存一个字符，最坏情况下需要保存所有的临时序列。

### 2. 最优解

#### 思路  

暴力解的瓶颈在 **「盲目枚举所有序列」**，尤其是大量明显非法的情况会被提前生成，却在最后才被剔除。  
我们可以在「生成」的过程中就保证合法性——**只在合法的前缀上继续扩展**，这叫「回溯（Backtracking）」或「深度优先搜索 + 剪枝」。

关键观察：

1. 在任意时刻，左括号 `'('` 的数量不能超过 `n`（因为总共只有 `n` 对）。  
2. 右括号 `')'` 的数量不能超过左括号的数量，否则会出现「右括号先出现」的非法前缀。  
3. 当左括号用了 `n` 个，右括号用了 `n` 个时，序列就完成了。

于是我们维护两个计数器：

- `left` 已经放了多少个 `'('`；
- `right` 已经放了多少个 `')'`。

递归的「选择」只有两种：

- **如果 `left < n`**，可以再放一个左括号；
- **如果 `right < left`**，可以放一个右括号（保证合法前缀）。

每次递归把当前字符加入 `path`，当 `len(path) == 2*n` 时把完整序列加入答案。这样**只会生成合法的序列**，没有任何“后期剔除”。

> **类比**：把生成括号的过程想象成「走迷宫」。暴力解是把所有可能的路都走遍（包括撞墙），而回溯则是「只在没有撞墙的地方继续前进」，大大减少了无用的步数。

#### 代码（Python）

```python
def generateParenthesis(n: int):
    """回溯法：在生成过程中始终保持序列合法，只产生合法的组合"""
    res = []                     # 最终答案列表

    def backtrack(path: list, left: int, right: int):
        """
        path  : 当前已经构造好的字符列表
        left  : 已经使用的 '(' 的个数
        right : 已经使用的 ')' 的个数
        """
        # 终止条件：已经放满 2n 个字符，得到一个合法答案
        if len(path) == 2 * n:
            res.append(''.join(path))
            return

        # 1) 还能放左括号，就放 '('
        if left < n:
            path.append('(')
            backtrack(path, left + 1, right)   # 递归继续
            path.pop()                         # 回溯，撤销

        # 2) 右括号数量不能超过左括号，才能保持合法
        if right < left:
            path.append(')')
            backtrack(path, left, right + 1)
            path.pop()                         # 回溯

    backtrack([], 0, 0)   # 从空序列开始
    return res
```

#### 复杂度

- **时间复杂度**：`O(C_n)`，其中 `C_n` 是第 `n` 个 **卡塔兰数**，`C_n = (2n)! / (n! * (n+1)!)`。  
  - 卡塔兰数恰好等于合法括号序列的个数，回溯算法只生成这些序列，每生成一个序列需要 `O(n)` 的时间拼接字符串，所以整体是 `O(C_n * n)`，但常用的记法是 `O(C_n)`。  
  - 与暴力的 `2^{2n}` 相比，`C_n` 增长要慢得多（比如 n=8 时 `C_8 = 1430`，而 `2^{16}=65536`）。
- **空间复杂度**：`O(n)`（递归栈深度）+ `O(C_n * n)`（保存答案）。  
  - 递归最多进行 `2n` 层调用，使用的额外空间是 `O(n)`；答案本身需要的空间不可避免。

## 心得

- **核心技巧**：回溯（Backtracking）——在搜索的每一步都保持「局部合法」来剪枝，避免产生无效的候选。
- **适用的题型**  
  1. **子集/组合生成**（如「组合总和」）  
  2. **排列问题**（如「全排列」）  
  3. **棋盘/路径类搜索**（如「N 皇后」）  
- **一句话总结**：**“只在合法的前缀上继续扩展，非法分支立刻剪掉”**。

## 反思

- **第一反应**：想到「把所有 2n 位的 '('、')' 组合都列出来，然后挑合法的」——这就是暴力思路。
- **最容易踩的坑**  
  1. **递归终止条件写错**：忘记 `len(path) == 2*n` 或者 `left == n and right == n`。  
  2. **剪枝条件不完整**：只检查 `right < left` 而忘记 `left < n`，会导致左括号放太多。  
  3. **忘记回溯**：`path.append` 后没有 `path.pop()`，会导致结果串被污染。  
- **下次遇到同类题**：第一步先思考「在构造过程中，哪些状态是非法的？」并把这些非法状态作为**剪枝条件**写进递归/迭代里。这样就能直接走向最优解。
