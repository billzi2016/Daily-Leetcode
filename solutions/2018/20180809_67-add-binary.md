# #67. 二进制求和 / Add Binary

> 难度：简单 · 标签：Math、String、Bit Manipulation、Simulation · [LeetCode 链接](https://leetcode.com/problems/add-binary/)

---

## 题目（英文原版）

**Description**

Given two binary strings a and b, return their sum as a binary string.

**Examples**

**Example 1:**

```
Input: a = "11", b = "1"
Output: "100"
```

**Example 2:**

```
Input: a = "1010", b = "1011"
Output: "10101"
```

**Constraints**

- 1 <= a.length, b.length <= 104
- a and b consist only of '0' or '1' characters.
- Each string does not contain leading zeros except for the zero itself.

---

## 题目（中文翻译）

给定两个二进制字符串（binary string）`a` 和 `b`，返回它们的和，结果仍为二进制字符串。

示例：

**示例 1**  
输入: `a = "11", b = "1"`  
输出: `"100"`

**示例 2**  
输入: `a = "1010", b = "1011"`  
输出: `"10101"`

约束条件：

- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成。
- 除了表示零本身的情况外，每个字符串均不含前导零。

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法就是把两串二进制数**从右往左**逐位相加，就像我们平时算十进制加法时从个位往高位进位一样。  

- **数据结构**：这里仅需要 **两个字符串**（`a`、`b`）和 **几个整型变量**（保存当前位的和、进位）。可以把字符串想象成装有字符的小盒子，`a[i]` 就是第 `i` 个盒子里的字符。  
- **为什么正确**：二进制加法的规则只有三种可能：`0+0=0`、`0+1=1`、`1+1=10`（产生进位 1）。把所有位都按照这个规则算完，最终得到的结果必然是两数的和。  
- **时间/空间复杂度**：我们需要遍历两串的每一位一次，时间随字符串长度线性增长，用 **O(max(|a|,|b|))** 表示。空间上只用了常数个额外变量（进位、结果列表），所以是 **O(1)**（不计返回值的空间）。

> 大白话解释：如果 `a` 长 1000，`b` 长 800，最多只会遍历 1000 次（最长的那个），所以时间大约是 1000 步；而不管多长，我们只用几个小盒子（变量）来记进位和当前和，所以占的内存几乎不变。

#### 代码（Python）

```python
def addBinary(a: str, b: str) -> str:
    # 1. 让 a、b 都从右侧开始遍历（用指针 i、j）
    i, j = len(a) - 1, len(b) - 1
    carry = 0               # 进位，初始为 0
    res = []                # 用列表收集每一位的结果，最后再逆序拼成字符串

    # 2. 当还有未处理的位，或者还有残留的进位时，继续循环
    while i >= 0 or j >= 0 or carry:
        # 取当前位的数值，若指针已经越界则当作 0
        digit_a = int(a[i]) if i >= 0 else 0
        digit_b = int(b[j]) if j >= 0 else 0

        # 3. 当前位相加 + 进位
        total = digit_a + digit_b + carry

        # 4. 本位的结果是 total % 2（因为二进制只能是 0/1）
        res.append(str(total % 2))

        # 5. 新的进位是 total // 2（0 或 1）
        carry = total // 2

        # 6. 指针左移，准备处理更高位
        i -= 1
        j -= 1

    # 7. 结果列表是逆序的，翻转后拼成最终字符串
    return ''.join(reversed(res))
```

#### 复杂度  

- **时间复杂度**：`O(max(|a|, |b|))`  
  - 解释：我们最多遍历最长的那个字符串一次，长度再多也只是一条直线增长。  
- **空间复杂度**：`O(max(|a|, |b|))`（返回值的空间）  
  - 解释：除了返回的结果外，只用了常数个变量 (`i, j, carry, total`)，所以额外空间是 `O(1)`，但把结果保存下来需要和输入等长的空间。

### 2. 最优解  

#### 思路  

上面的“暴力”已经是最常见、最简洁的做法，时间已经是线性最优（不可能比遍历每一位更快），但我们可以**把代码写得更简洁**，利用 Python 的特性把进位和结果一次性算出来。思路仍然是“从低位到高位逐位相加”，唯一的优化是：

1. **一次性把两个字符相加**：`int(a[i]) + int(b[i])` 可以直接写成 `int(a[i]) + int(b[i])`，不需要先分别取值。  
2. **使用 `list.append` + `''.join`** 已经是最省时的拼接方式。  
3. **不需要显式的 `while i >= 0 or j >= 0`**，可以把两串统一填充到同等长度（在左侧补 `'0'`），这样只需遍历一次统一的长度。

下面的实现把两串补齐后，用 **单个 for 循环** 完成全部加法，代码更紧凑，逻辑更清晰。

#### 代码（Python）

```python
def addBinary(a: str, b: str) -> str:
    # 1. 让两串长度相同，短的左侧补零（想象在数字前面加了“0”来占位）
    max_len = max(len(a), len(b))
    a = a.zfill(max_len)   # zfill 会在左侧填充 '0'
    b = b.zfill(max_len)

    carry = 0               # 进位
    res = []                # 结果列表（逆序存）

    # 2. 从右到左一次遍历所有位置
    for i in range(max_len - 1, -1, -1):
        total = int(a[i]) + int(b[i]) + carry   # 当前位相加 + 进位
        res.append(str(total & 1))              # total % 2 等价于 total & 1，取最低位
        carry = total >> 1                      # total // 2 等价于右移一位，得到进位

    # 3. 循环结束后如果还有进位，要补上最高位的 '1'
    if carry:
        res.append('1')

    # 4. 逆序拼接得到最终二进制字符串
    return ''.join(reversed(res))
```

> **小技巧**：`total & 1` 和 `total >> 1` 分别是取最低位和向右移动一位的位运算写法，和 `% 2`、`// 2` 的效果相同，但更贴近“位运算”这个标签的本意，帮助你以后在处理更大规模的二进制问题时更得心应手。

#### 复杂度  

- **时间复杂度**：`O(max(|a|, |b|))`  
  - 与暴力解相同，因为我们仍然必须检查每一位一次。唯一的提升是常数因子更小（少了几次条件判断）。  
- **空间复杂度**：`O(max(|a|, |b|))`（返回值的空间）  
  - 额外使用的变量仍是常数级，主要空间是存放结果的列表。

## 心得  

- **核心技巧**：模拟二进制逐位加法（带进位），并学会把字符串“左侧补零”使长度统一，方便一次遍历。  
- **适用的题型**：  
  1. **二进制/十进制字符串相加**（如 LeetCode 415 `Add Strings`）。  
  2. **大整数相乘/除**（需要逐位模拟，不能直接转成整数）。  
  3. **位运算相关的模拟题**（如“翻转二进制位”“二进制求和”等）。  
- **一句话总结解题钥匙**：**从最低位向最高位逐位相加，记住进位即可**。

## 反思  

- **第一反应**：看到“二进制字符串相加”，立刻想到手算的“从右往左逐位加并进位”。  
- **最容易踩的坑**：  
  - 忘记处理最高位仍有进位的情况（比如 `1 + 1 = 10`，结果长度会比输入长 1）。  
  - 当两串长度不等时，直接用索引会越界，需要补零或加条件判断。  
- **下次遇到同类题**：**先把所有位对齐（补零），再统一遍历一次，记住进位**，这样代码结构最清晰，错误率最低。
