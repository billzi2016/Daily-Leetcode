## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  
最直接的想法是：把数组里每个元素往右搬 `k` 步。  
- **用到的数据结构**：额外开辟一个同样长度的数组 `tmp`，把搬好的元素放进去，再把 `tmp` 整体拷贝回原数组。  
  - 这跟我们查字典的过程类似：字典（`tmp`）里已经把「原来的位置」映射成「搬完后的新位置」，查完后再把所有内容写回原书（`nums`）。  
- **为什么正确**：对每个下标 `i`，右移 `k` 步后它的新下标应该是 `(i + k) % n`（`% n` 用来环绕回到数组开头），把原始值写到这个位置即可。  
- **复杂度分析**：  
  - **时间**：我们遍历一次数组，做 `O(1)` 的计算和写入，总共 `n` 次操作，用大白话说就是「跟数组长度成正比」，记作 `O(n)`。  
  - **空间**：多用了一个长度为 `n` 的临时数组，额外占用了 `n` 个位置，用大白话说就是「需要和原数组一样多的额外空间」，记作 `O(n)`。  

#### 代码（Python）  

```python
def rotate(nums, k):
    """
    暴力解：使用额外数组把元素搬到正确位置
    :param nums: List[int] 原始数组，原地修改
    :param k: int 右移步数
    """
    n = len(nums)                     # 数组长度
    k %= n                            # 防止 k > n，取模后等价于只右移 k 步
    tmp = [0] * n                     # 新建一个同等大小的临时数组

    # 把每个元素搬到它应该去的位置
    for i, val in enumerate(nums):
        new_idx = (i + k) % n          # 计算新下标，环绕回到开头
        tmp[new_idx] = val            # 把值写进临时数组

    # 把搬好的结果拷贝回原数组（原地修改）
    for i in range(n):
        nums[i] = tmp[i]               # 覆盖原数组
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 随着数组长度 `n` 增大，运行时间线性增长。  
- **空间复杂度**：`O(n)` — 需要额外开辟一个同样大小的数组来存放搬好的元素。

### 2. 最优解  

#### 思路  
从暴力解出发，最大的「瓶颈」在于我们用了额外的 `O(n)` 空间。  
我们希望**在原数组上就完成搬移**，也就是「原地」算法。  

**核心技巧：三次翻转**（Reverse）。  
- 先把整个数组翻转一次，得到 `[7,6,5,4,3,2,1]`（以示例 1 为例）。  
- 再把前 `k` 个元素翻转，得到 `[5,6,7,4,3,2,1]`。  
- 最后把剩下的 `n‑k` 个元素翻转，得到 `[5,6,7,1,2,3,4]`，这正是右移 `k` 步的结果。  

**为什么翻转能实现右移？**  
想象把数组切成两段：  
```
原数组: [A | B]   （A 为前 n-k 部分，B 为后 k 部分）
目标:   [B | A]
```
如果把整个数组翻转，顺序变成 `[B_rev | A_rev]`。  
再把每段各自翻转回来，就得到 `[B | A]`，正好是右移 `k` 步。  

**需要的工具**：**双指针**（Two Pointers）——用 `left`、`right` 两个指针从两端向中间交换元素，实现原地翻转。  

**步骤概览**  
1. `k = k % n`（防止 k 超过数组长度）。  
2. 调用 `reverse(0, n-1)` 把全数组翻转。  
3. 调用 `reverse(0, k-1)` 翻转前 `k` 个元素。  
4. 调用 `reverse(k, n-1)` 翻转后 `n-k` 个元素。  

#### 代码（Python）  

```python
def rotate(nums, k):
    """
    最优解：原地三次翻转实现右移 k 步
    :param nums: List[int] 原始数组，原地修改
    :param k: int 右移步数
    """
    n = len(nums)
    k %= n                     # 只需要右移 k% n 步

    # 辅助函数：原地翻转 nums[l..r]（闭区间）
    def reverse(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]   # 交换两端元素
            l += 1
            r -= 1

    # 1️⃣ 全部翻转
    reverse(0, n - 1)
    # 2️⃣ 前 k 个翻转（现在是原来的后 k 个）
    reverse(0, k - 1)
    # 3️⃣ 剩下的翻转
    reverse(k, n - 1)
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 每次翻转都遍历一段元素，总共恰好遍历 `n` 次（两两交换），所以仍是线性时间。相比暴力解，**不再需要额外的拷贝**，但时间上并没有下降。  
- **空间复杂度**：`O(1)` — 只用了常数个额外变量（`l`, `r`, `k`），没有额外的数组，真正实现了「原地」操作。

## 心得  

- **核心技巧**：**数组翻转 + 双指针**。通过把「整体」翻转再「局部」翻转，巧妙地实现了右移。  
- **适用的题型**  
  1. **循环移位**（如左移、右移的数组题）。  
  2. **环形数组**（如环形队列的实现，需要把头尾相连的逻辑转化为翻转）。  
  3. **数组的旋转**（如把数组分成两段调换顺序的题目）。  
- **一句话总结解题钥匙**：**把「搬」的过程转化为「翻」的过程，翻转本身只需要常数空间。**  

## 反思  

- **第一反应**：直接开一个新数组把每个元素搬到 `(i + k) % n` 的位置，代码最容易写。  
- **最容易踩的坑**  
  - `k` 可能大于数组长度，需要先取模 `k %= n`，否则会越界。  
  - 当 `k == 0` 或 `k == n` 时，翻转会把数组恢复原样，需保证代码仍然正确（翻转空区间是安全的）。  
  - 在实现 `reverse` 时，记得使用 `while l < r`，否则会出现无限循环。  
- **下次类似题的第一步**：先思考「是否可以把移动转化为翻转」或「是否可以用双指针一次遍历完成」，这样就能快速锁定原地 `O(1)` 的思路。
