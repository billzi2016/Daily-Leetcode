# #100. 相同的树 / Same Tree

## 题目（英文原版）

**Description**

Given the roots of two binary trees p and q, write a function to check if they are the same or not.
Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Examples**

**Example 1:**

```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**

```
Input: p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**

```
Input: p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints**

- The number of nodes in both trees is in the range [0, 100].
- -104 <= Node.val <= 104

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是**同步遍历**两棵树的每一个节点，看看对应位置的值是否相同，结构是否一致。  
可以把这一步想象成**两本相同章节的教材**，我们把两本书的每一页对应翻开，检查页码上的文字是否完全一样。  

- **递归**是一种天然的“同步遍历”方式：先比较根节点 `p.val` 与 `q.val`，若相等再分别递归比较左子树和右子树。  
- 若其中有一棵树已经到达叶子（`None`），而另一棵仍有节点，则结构不相同，直接返回 `False`。  

> **为什么正确？**  
> 二叉树的定义是“根节点 + 左子树 + 右子树”。只要我们每一步都严格对齐比较根、左、右，所有子树都满足相同，整棵树必然相同；只要有一步不相同，整体就不相同。

#### 代码（Python）  

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val          # 节点的数值
        self.left = left        # 左子树（可能是 None）
        self.right = right      # 右子树（可能是 None）

def isSameTree(p: TreeNode, q: TreeNode) -> bool:
    """
    递归版的“同步遍历”
    """
    # 两棵树都已经遍历完，说明到达相同的空节点
    if not p and not q:
        return True

    # 只要有一棵为空，另一棵不为空，结构必不相同
    if not p or not q:
        return False

    # 当前节点的值不同，直接返回 False
    if p.val != q.val:
        return False

    # 递归比较左子树和右子树
    left_same = isSameTree(p.left, q.left)   # 检查左子树是否相同
    right_same = isSameTree(p.right, q.right) # 检查右子树是否相同
    return left_same and right_same
```

#### 复杂度  

- **时间复杂度：** `O(n)`  
  - 这里的 `n` 是两棵树中较大的节点数。我们最多会访问每个节点一次，就像一次遍历所有章节。  
- **空间复杂度：** `O(h)`  
  - 递归调用会占用栈空间，`h` 是树的高度。最坏情况（树退化成链表）时 `h = n`，最好的平衡树时 `h ≈ log n`。  

---

### 2. 最优解  

#### 思路  

从暴力递归可以看到**瓶颈**在于递归调用本身带来的栈空间开销，尤其在极端不平衡的树上会导致 `O(n)` 的额外空间。  
如果我们用 **显式的栈（或队列）** 来模拟遍历，就可以把递归改写成 **迭代**，从而把空间控制在 `O(n)`（最坏情况仍是 `n`，但实现上更直观），并且可以在遍历过程中 **提前终止**，不必等所有递归返回。

这里展示两种等价的迭代写法：

1. **深度优先搜索（DFS）** 用栈模拟递归的过程。  
2. **广度优先搜索（BFS）** 用队列一次比较同层节点。  

我们选用 **DFS + 栈** 作为“最优解”，因为它的代码最简洁，同时仍然体现了“同步遍历”的核心思想。

> **关键概念解释**  
> - **栈**：就像一叠盘子，后放进去的先拿出来（后进先出）。我们把待比较的节点对压进去，随后弹出比较，保证左子树、右子树的比较顺序和递归一致。  
> - **队列**（若使用 BFS）：像排队买票，先进去的先出来（先进先出），适合层序遍历。  

#### 代码（Python）  

```python
from collections import deque  # 为了演示 BFS 也顺便导入

def isSameTree_iter(p: TreeNode, q: TreeNode) -> bool:
    """
    迭代版的同步遍历（使用栈实现 DFS）
    """
    stack = [(p, q)]                     # 初始把根节点对放入栈中

    while stack:
        node1, node2 = stack.pop()       # 取出一对待比较的节点

        # 两个节点都为空，说明这一对是相同的空位，继续处理下一对
        if not node1 and not node2:
            continue

        # 只要有一个为空，另一方不为空，结构不同
        if not node1 or not node2:
            return False

        # 值不相等直接返回 False
        if node1.val != node2.val:
            return False

        # 将左子树、右子树对应位置的节点对压入栈中
        # 先压右子树再压左子树，这样弹出时左子树先比较（保持和递归相同的顺序）
        stack.append((node1.right, node2.right))
        stack.append((node1.left,  node2.left))

    # 栈空了，说明所有对应位置都相同
    return True
```

> **如果你更喜欢 BFS**（层序遍历），只需要把 `stack` 换成 `deque`，使用 `popleft()` 代替 `pop()`，其余逻辑完全相同。

#### 复杂度  

- **时间复杂度：** `O(n)`  
  - 仍然需要检查每个节点一次，和递归版一样。  
- **空间复杂度：** `O(n)`（最坏情况）  
  - 栈中最多会同时保存树的某一层的所有节点对。对于完全平衡的树，这一层的节点数约为 `n/2`，即 `O(n)`。相比递归的 `O(h)`，在最坏的深链情况下略高，但在实际面试中更容易控制栈溢出。

## 心得  

- **核心技巧**：同步遍历两棵树（递归或显式栈/队列），每一步都检查“值相等 + 结构相同”。  
- **适用的题型**  
  1. 判断两棵二叉树是否互为镜像（`isMirror`）  
  2. 判断一棵二叉树是否为另一棵的子树（`isSubtree`）  
  3. 合并两棵二叉树（`mergeTrees`）——同样需要同步遍历两棵树的对应节点。  
- **一句话总结解题钥匙**：**“把两棵树的对应节点配对，逐对比较，出现不匹配立刻返回”。**

## 反思  

- **第一反应**：看到“相同的树”，立刻想到递归，因为二叉树的自然递归结构最贴合“根、左、右”。  
- **最容易踩的坑**  
  - 忘记处理 `None` 与实际节点的对应关系，导致 `AttributeError`。  
  - 只比较了节点值，却忘了检查两边是否同时为空或同时非空。  
  - 在迭代实现时，压栈的顺序写反了，导致遍历顺序不一致（虽然对最终结果影响不大，但会让调试更困难）。  
- **下次遇到同类题的第一步**：先在纸上画出两棵树的对应节点配对，明确“同步比较”这个思路，再决定是递归实现还是显式栈/队列实现。
