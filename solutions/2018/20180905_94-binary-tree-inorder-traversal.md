## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的办法就是**递归**地按照「左子树 → 根节点 → 右子树」的顺序访问二叉树，这正好对应中序遍历的定义。  
- **数据结构**：这里我们只用到递归调用栈（系统自动维护的一个「堆叠」），可以把它想象成一本《查找手册》里的「翻页记录」，每次进入左子树就往里翻一页，回到根节点再翻回去，最后进入右子树。
- **正确性**：因为递归保证了先把左子树全部遍历完，再把根节点的值加入结果，最后遍历右子树，正好满足中序遍历的顺序要求。
- **复杂度大白话**：  
  - **时间**：每个节点恰好被访问一次，若树有 `n` 个节点，则需要 `n` 次操作，用 `O(n)` 表示。想象成「数完所有树上的水果需要走 `n` 步」。
  - **空间**：递归会占用调用栈的空间，最坏情况下（树像链条一样单边伸展）栈深度会等于节点数 `n`，即 `O(n)`；平均或最平衡的情况下栈深度是树的高度 `h`，约 `O(log n)`。

#### 代码（Python）

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val          # 节点的数值
        self.left = left        # 左子树
        self.right = right      # 右子树

def inorder_traversal(root: TreeNode) -> list[int]:
    """
    递归版中序遍历
    """
    res = []                     # 用来存放遍历结果

    def dfs(node: TreeNode):
        if not node:             # 空节点直接返回
            return
        dfs(node.left)           # 先遍历左子树
        res.append(node.val)     # 再访问根节点
        dfs(node.right)          # 最后遍历右子树

    dfs(root)                    # 从根节点开始递归
    return res
```

#### 复杂度

- **时间复杂度**：`O(n)` — 树中每个节点恰好被访问一次，就像数一次所有苹果。
- **空间复杂度**：`O(h)` — 递归栈的深度等于树的高度 `h`，最坏 `O(n)`，最好的平衡树 `O(log n)`。

### 2. 最优解

#### 思路  
递归虽然简洁，但它依赖系统的调用栈，某些语言（或极端的深度）会导致 **栈溢出**。我们可以手动使用 **显式栈**（Python 的 `list`）来模拟递归过程，这样可以更清晰地控制空间，也更符合面试中常见的「迭代」写法。  
从暴力解出发，慢的地方其实是 **递归调用的开销**（每次函数进出都有额外的时间和空间），而 **遍历本身已经是线性的**，没有进一步加速的余地。于是我们把递归改成 **循环 + 栈**：

1. **一直向左走**，把沿途的节点压入栈中（相当于把「左子树」的所有「未完成」的根节点记下来）。
2. 当左子树走到尽头（`node` 为 `None`）时，从栈顶弹出最近的根节点，访问它（加入结果）。
3. 转向它的右子树，重复上述过程，直到栈空且当前节点为空，遍历结束。

核心概念 **栈** 可以类比为「装盒子」：先把左边的盒子一个个放进去，最先放进去的（最左边的叶子）会最后拿出来，这正好满足中序遍历「左 → 根 → 右」的顺序。

#### 代码（Python）

```python
def inorder_traversal_iter(root: TreeNode) -> list[int]:
    """
    迭代版中序遍历（使用显式栈）
    """
    res = []          # 结果列表
    stack = []        # 手动维护的栈
    node = root       # 从根节点开始

    while stack or node:          # 栈不空或还有未遍历的节点
        # 把左子树全部压栈
        while node:
            stack.append(node)    # 记住当前节点，等会儿回来访问
            node = node.left      # 一直向左

        # 左子树已经到底，弹出最近的根节点
        node = stack.pop()        # 取出栈顶
        res.append(node.val)      # 访问根节点

        # 开始遍历右子树
        node = node.right         # 下一轮循环会继续向左压栈

    return res
```

#### 复杂度

- **时间复杂度**：`O(n)` — 每个节点恰好被压栈一次、弹栈一次，仍然是线性遍历。相比递归，没有额外的函数调用开销。
- **空间复杂度**：`O(h)` — 栈里最多同时存放树的高度 `h` 个节点，最坏 `O(n)`，平衡树 `O(log n)`。这和递归的空间使用是一样的，只是我们自己管理而已。

## 心得

- **核心技巧**：利用**栈**模拟递归的深度优先搜索（DFS），实现二叉树的中序遍历。  
- **适用题型**：  
  1. 前序遍历（根 → 左 → 右）  
  2. 后序遍历（左 → 右 → 根）— 需要稍微改动栈的出栈顺序或使用两个栈  
  3. 任何需要**深度优先**且需要“回溯”信息的树/图遍历  
- **一句话总结解题钥匙**：**把「左子树 → 根 → 右子树」的访问顺序用栈记录下来，循环弹栈即可**。

## 反思

- **第一反应**：看到「中序遍历」立刻想到递归实现，因为它最贴合「左‑根‑右」的定义。  
- **最容易踩的坑**：  
  - 忘记在循环结束条件上同时检查 `stack` 和 `node`，导致无限循环或漏掉右子树。  
  - 对空树（`root = None`）没有特殊处理，直接返回空列表。  
  - 栈的压入顺序写反了（比如先压右子树再压左子树），会得到错误的遍历顺序。  
- **下次遇到同类题**：第一步先明确遍历顺序，然后决定是用**递归**（思路快）还是**显式栈**（防止栈溢出），再按「压左、弹根、转右」的模板写循环。
