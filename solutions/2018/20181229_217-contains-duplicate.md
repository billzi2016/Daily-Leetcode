# #217. 包含重复元素 / Contains Duplicate

> 难度：简单 · 标签：Array、Hash Table、Sorting · [LeetCode 链接](https://leetcode.com/problems/contains-duplicate/)

---

## 题目（英文原版）

**Description**

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

**Examples**

**Example 1:**

```
Input: nums = [1,2,3,1]
Output: true
Explanation:
The element 1 occurs at the indices 0 and 3.
```

**Example 2:**

```
Input: nums = [1,2,3,4]
Output: false
Explanation:
All elements are distinct.
```

**Example 3:**

```
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

**Constraints**

- 1 <= nums.length <= 105
- -109 <= nums[i] <= 109

---

## 题目（中文翻译）

给定一个整数数组（integer array）`nums`，如果数组中存在任意值出现至少两次则返回 `true`，若所有元素均互不相同则返回 `false`。

### 示例

**示例 1**  
输入：`nums = [1,2,3,1]`  
输出：`true`  
解释：元素 `1` 分别出现在索引 `0` 和 `3` 处。

**示例 2**  
输入：`nums = [1,2,3,4]`  
输出：`false`  
解释：所有元素均互不相同。

**示例 3**  
输入：`nums = [1,1,1,3,3,4,3,2,4,2]`  
输出：`true`

### 约束条件

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把数组里每一个元素都和后面的所有元素两两比较一次，只要发现两个相同的值，就返回 `True`；如果遍历完都没有相同的，就返回 `False`。  

- **用到的数据结构**：仅仅是原始的 `list`（数组），不需要额外的容器。可以把它想象成一排排编号的盒子，我们逐个打开盒子并和后面的每个盒子里的东西比对。  
- **为什么正确**：因为我们检查了所有可能的配对，若有任意一对相等，就一定会被发现。  
- **时间/空间复杂度**：  
  - 时间上需要两层循环，外层 `n` 次，内层至多 `n‑1` 次，整体大约是 `n × n`，记作 **O(n²)**。这里的 “O” 表示“数量级”，也就是当数组很大时，运行时间会随 **n²** 的速度增长。  
  - 空间上只用了常数级的临时变量，记作 **O(1)**（不随输入规模增长）。

#### 代码（Python）

```python
def containsDuplicate(nums):
    """
    暴力两层遍历检查是否有重复元素
    :param nums: List[int] 输入数组
    :return: bool 是否存在重复
    """
    n = len(nums)
    for i in range(n):
        # i 位置的元素与后面的每个元素比较
        for j in range(i + 1, n):
            if nums[i] == nums[j]:      # 找到相同的就直接返回 True
                return True
    return False                       # 没有任何相等的配对
```

#### 复杂度  

- **时间复杂度**：O(n²) — 当数组长度翻倍时，比较次数会变成原来的四倍。  
- **空间复杂度**：O(1) — 只用了几个计数变量，不会随 `n` 增长。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈在于大量的重复比较**。我们其实只需要判断“某个数是否已经出现过”，不必把它和每一个后面的数逐个比。  

这时可以使用 **哈希表**（在 Python 中就是 `set`），它的查找/插入操作平均只需要 **O(1)** 的时间。把 `set` 想象成一本“查字典”，每次看到一个新数字，就把它记在字典里；如果下次再看到同样的数字，直接在字典里找得到，说明出现重复，立刻返回 `True`。  

实现步骤：

1. 创建一个空的 `set` 用来保存已经遍历过的元素。  
2. 从左到右遍历数组：  
   - 若当前元素已经在 `set` 中，说明之前出现过，返回 `True`。  
   - 否则把当前元素加入 `set`，继续往后走。  
3. 循环结束仍未发现重复，返回 `False`。

这就是 **一次遍历 + 哈希表** 的典型做法，时间只需要 **O(n)**，空间需要额外的 `set`，最坏情况下要保存所有不重复的元素，空间是 **O(n)**。

#### 代码（Python）

```python
def containsDuplicate(nums):
    """
    使用集合（哈希表）在一次遍历中检测重复
    :param nums: List[int] 输入数组
    :return: bool 是否存在重复
    """
    seen = set()                # 用集合保存已经出现过的数
    for num in nums:
        if num in seen:         # 如果集合里已经有这个数，说明重复
            return True
        seen.add(num)           # 否则把它加入集合，继续检查后面的数
    return False                # 所有数都不重复
```

#### 复杂度  

- **时间复杂度**：O(n) — 只遍历一次数组，每次查找/插入集合的代价是常数级。相比暴力的 O(n²) 快了很多。  
- **空间复杂度**：O(n) — 最坏情况下所有元素都不重复，需要把 `n` 个数全部存进集合。

## 心得

- 这道题考察的核心技巧是 **利用哈希表（集合）实现快速去重 / 重复检测**。  
- 该技巧适用的题型还有：  
  1. **两数之和**（判断是否存在两数之和等于目标值）  
  2. **无重复字符的最长子串**（使用滑动窗口 + 集合）  
  3. **数组交集**（使用集合求交）  
- **一句话总结解题钥匙**：*把“是否出现过”抽象成“是否在集合里”，用 O(1) 的查询代替 O(n) 的遍历比较*。

## 反思

- **第一反应**：直接想到两层循环逐个比较，因为这是最自然的“暴力”思路。  
- **最容易踩的坑**：  
  - 忘记在遍历过程中及时把当前元素加入集合，导致错误地认为不存在重复。  
  - 对输入规模不敏感，使用 O(n²) 方法在 `n=10⁵` 时会超时。  
- **下次遇到同类题**：第一步先问自己“我只需要判断是否出现过吗？”，如果答案是肯定的，就立刻考虑使用集合/哈希表来做 **“出现过？”** 的 O(1) 查询。
