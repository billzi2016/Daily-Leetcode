## 题目（中文翻译）

判断一个 **9 × 9** 的数独棋盘（board）是否有效。只需要对已经填入的格子进行校验，遵循以下规则：

- 每一行（row）必须包含数字 **1-9**，且不能出现重复。
- 每一列（column）必须包含数字 **1-9**，且不能出现重复。
- 每一个 3×3 子盒（sub-box）必须包含数字 **1-9**，且不能出现重复。

空格用字符 `'.'` 表示，忽略空格的检查。

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  
最直接的想法是：**把每一行、每一列、每一个 3×3 小宫格都检查一遍**。  
- 对于一行，只要把出现的数字记下来（可以用 `set`，类似查字典——键是数字，值只要记“出现过”），再出现相同数字就说明冲突。  
- 对于一列、一个小宫格，同理。  
- 只要遍历完所有格子，且没有发现冲突，就说明这个数独是合法的。  

为什么这样一定对？  
数独的合法性只由三条规则决定：  
1) 同一行不能出现重复数字。  
2) 同一列不能出现重复数字。  
3) 同一 3×3 小宫格不能出现重复数字。  
如果我们把这三条规则分别检查完，且每条规则都没有违背，那么整体就一定合法。  

#### 代码（Python）  

```python
from typing import List

def isValidSudoku(board: List[List[str]]) -> bool:
    # ---------- 检查行 ----------
    for i in range(9):                     # 逐行遍历
        seen = set()                       # 记录本行出现的数字，像字典一样查重
        for j in range(9):
            val = board[i][j]
            if val == '.':                 # 空格不参与判断
                continue
            if val in seen:                # 已经出现过，冲突
                return False
            seen.add(val)                  # 加入已出现集合

    # ---------- 检查列 ----------
    for j in range(9):                     # 逐列遍历
        seen = set()
        for i in range(9):
            val = board[i][j]
            if val == '.':
                continue
            if val in seen:
                return False
            seen.add(val)

    # ---------- 检查 3×3 小宫格 ----------
    for box_row in range(3):               # 小宫格行坐标 0/1/2
        for box_col in range(3):           # 小宫格列坐标 0/1/2
            seen = set()
            # 遍历当前宫格内部的 9 个格子
            for i in range(box_row * 3, box_row * 3 + 3):
                for j in range(box_col * 3, box_col * 3 + 3):
                    val = board[i][j]
                    if val == '.':
                        continue
                    if val in seen:
                        return False
                    seen.add(val)

    # 三类检查都没有返回 False，说明合法
    return True
```

#### 复杂度  
- **时间复杂度：** `O(9·9) = O(1)`，因为棋盘大小固定为 9×9，实际运行时间是常数级。但如果把 9 换成 N，遍历三次（行、列、小宫格）每次都要遍历 N²，故可以写成 `O(N²)`。  
- **空间复杂度：** `O(9) = O(1)`，每次只用到一个 `set`，最多装 9 个数字，空间同样是常数级。

### 2. 最优解  

#### 思路  
暴力解的**瓶颈**在于我们分别遍历了三遍（行、列、小宫格），虽然每遍都是 O(N²)，但常数系数较大。  
我们可以**一次遍历**同时完成三类检查：  

- 用三个长度为 9 的数组分别记录每一行、每一列、每一个小宫格已经出现的数字。  
- 数组的每个元素都是一个 `set`（或者 9 位的二进制整数），用来快速判断当前数字是否已经出现。  
- 对于坐标 `(i, j)`，它所在的小宫格编号可以用 `box_index = (i // 3) * 3 + (j // 3)` 计算得到。  

这样，在遍历每个格子时，只要检查对应行、列、宫格的 `set` 中是否已有该数字，即可立刻判断是否合法，若没有则把数字加入三套 `set` 中继续往后走。  

**核心概念解释**  
- **哈希表（set）**：像查字典一样，键是数字字符，查询/插入的时间几乎是瞬间（常数时间），所以判断“是否出现过”非常快。  
- **小宫格编号**：把 9×9 的棋盘划分成 3 行 3 列的宫格，每个宫格可以用 0~8 的编号唯一表示。公式 `(i // 3) * 3 + (j // 3)` 就是把行号和列号分别除以 3（取整）后组合成唯一编号。  

#### 代码（Python）  

```python
from typing import List

def isValidSudoku(board: List[List[str]]) -> bool:
    # 分别为行、列、小宫格准备 9 个 set，类似 9 本小字典
    rows   = [set() for _ in range(9)]   # rows[i] 记录第 i 行出现的数字
    cols   = [set() for _ in range(9)]   # cols[j] 记录第 j 列出现的数字
    boxes  = [set() for _ in range(9)]   # boxes[k] 记录第 k 个 3×3 小宫格出现的数字

    for i in range(9):                # 遍历每一行
        for j in range(9):            # 遍历每一列
            val = board[i][j]
            if val == '.':            # 空格直接跳过
                continue

            # 计算当前格子所属的小宫格编号
            box_index = (i // 3) * 3 + (j // 3)

            # 同时检查行、列、宫格是否已经出现过该数字
            if (val in rows[i]) or (val in cols[j]) or (val in boxes[box_index]):
                return False          # 任意一次冲突立即返回 False

            # 没冲突就把数字记入对应的三个集合
            rows[i].add(val)
            cols[j].add(val)
            boxes[box_index].add(val)

    # 所有格子检查完毕，没有冲突
    return True
```

#### 复杂度  
- **时间复杂度：** `O(N²)`（这里 N=9），因为只遍历一次棋盘，每个格子做的操作都是常数时间（集合的插入/查询）。相较于暴力解省去了两次额外的遍历，常数系数更小。  
- **空间复杂度：** `O(N)`，我们维护了 27 个 `set`（9 行 + 9 列 + 9 宫格），每个最多装 9 个数字，整体空间随棋盘大小线性增长。

## 心得  

- **核心技巧**：使用哈希表（`set`）一次遍历同时记录行、列、子盒子的信息，实现 **“同步检查”**。  
- **适用的题型**：  
  1. **Valid Sudoku**（本题）  
  2. **Word Search II**（利用前缀树+哈希记录已访问）  
  3. **Find Duplicate Subtrees**（一次遍历记录子树结构）  
- **一句话总结**：**把“是否出现过”抽象成集合的“是否在里”，一次遍历即可完成所有约束的检查**。

## 反思  

- **第一反应**：先把每条规则单独实现，想到要检查行、列、小宫格。  
- **最容易踩的坑**：  
  - 小宫格编号算错（行列除以 3 再组合）。  
  - 忽略了 `'.'`（空格）不参与冲突判断。  
  - 把 `set` 当作全局变量忘记在每次检查前清空。  
- **下次类似题的第一步**：先明确“约束有几类”，把每类约束用哈希表/数组记录，然后在一次遍历中同步更新与校验。
