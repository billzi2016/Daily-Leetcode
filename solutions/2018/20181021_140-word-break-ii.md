## 题目（英文原版）

**Description**

Given a string s and a dictionary of strings wordDict, add spaces in s to construct a sentence where each word is a valid dictionary word. Return all such possible sentences in any order.
Note that the same word in the dictionary may be reused multiple times in the segmentation.

**Examples**

**Example 1:**

```
Input: s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
Output: ["cats and dog","cat sand dog"]
```

**Example 2:**

```
Input: s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
Output: ["pine apple pen apple","pineapple pen apple","pine applepen apple"]
Explanation: Note that you are allowed to reuse a dictionary word.
```

**Example 3:**

```
Input: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Output: []
```

**Constraints**

- 1 <= s.length <= 20
- 1 <= wordDict.length <= 1000
- 1 <= wordDict[i].length <= 10
- s and wordDict[i] consist of only lowercase English letters.
- All the strings of wordDict are unique.
- Input is generated in a way that the length of the answer doesn't exceed 105.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把字符串 `s` 的每一个可能的切分点都枚举出来，然后把切出的每段都去字典里查找是否是合法单词。  
可以把这个过程想象成 **“把一根绳子不停剪成若干段，看每段是否能对应字典里的词”**：

1. 从左到右遍历所有切分位置 `i`（`i` 表示前 `i` 个字符形成的子串），把 `s[:i]` 当成第一段。  
2. 判断 `s[:i]` 是否在字典里（字典就像一本 **查字典**，key 是单词，value 只要知道它存在即可）。  
3. 如果是合法单词，就把剩下的 `s[i:]` 递归地继续切分。  
4. 当递归走到字符串空了，说明找到了一个完整的切分方案，把它加入答案。

这就是“穷举所有切法、把合法的留下”。因为我们会对每一种切法都尝试一次，所以一定能得到所有答案——**正确**。

**为什么会超时？**  
每个字符后面都有两种选择：**切** 或 **不切**。长度为 `n` 的字符串大约会产生 `2^{n-1}` 种切法（类似二进制的全排列），指数级的增长在 `n=20` 时已经有 **约 500,000** 条路径，且每条路径都要进行字典查找，时间会爆炸。

#### 代码（Python）

```python
from typing import List

def wordBreak_brute(s: str, wordDict: List[str]) -> List[str]:
    word_set = set(wordDict)               # 把字典装进哈希表，查单词像查字典一样 O(1)

    def backtrack(start: int) -> List[List[str]]:
        """
        返回从位置 start 开始，所有合法的单词序列（每个序列是一个列表）。
        """
        if start == len(s):                # 已经划到字符串末尾，构成一种空序列
            return [[]]

        res = []
        # 枚举所有可能的切分点 i（左闭右开区间 [start, i)）
        for i in range(start + 1, len(s) + 1):
            prefix = s[start:i]            # 当前切出来的子串
            if prefix in word_set:         # 看看它是不是字典里的合法单词
                # 递归求解后缀部分的所有组合
                for suffix in backtrack(i):
                    res.append([prefix] + suffix)   # 把当前单词拼到后面的组合前面
        return res

    # 把每个单词列表用空格连接成句子
    return [' '.join(words) for words in backtrack(0)]
```

#### 复杂度  

- **时间复杂度**：`O(2^n * n)`  
  - `2^{n-1}` 是所有切分方式的数量，`n` 是每次切分时需要拼接子串和复制列表的开销。  
  - 用大白话说，就是“每次都要把所有可能的切法都尝试一次，时间会随字符数呈指数增长”。

- **空间复杂度**：`O(2^n * n)`（递归栈 + 保存所有答案）  
  - 递归深度最多 `n`，而返回的答案本身就可能有指数级条目，需要把它们全部存下来。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**大量无效的切法**：很多前缀根本不可能构成合法句子，却仍然被递归深度遍历。我们要做的，就是**提前把这些“死路”剪掉**。

思路分两步：

1. **预处理：** 用动态规划（DP）先算出每个位置 `i`（从 `0` 到 `len(s)`）是否**能够**被合法切分到结尾。  
   - 这一步相当于先做一次 “能否拆分” 的判断（LeetCode 139 Word Break），只要知道 `dp[i] = True`，就说明从 `i` 开始后面有合法切法。  
   - 这样在后面的递归里，如果发现 `dp[i]` 为 `False`，就直接返回空，避免继续深挖。

2. **记忆化回溯（Memoization + Backtracking）：**  
   - 对每个起始位置 `i`，我们只计算一次所有合法的句子列表，并把结果缓存到 `memo[i]`。  
   - 当后面再次需要从同一位置 `i` 开始的答案时，直接复用缓存，省去重复计算。  
   - 这一步仍然是 **回溯**（把所有合法路径都收集），但因为 **剪枝 + 记忆**，实际遍历的状态数从指数级降到了 **线性**（每个位置最多遍历一次）。

> **类比**：把 `dp` 想成一本 “是否能通关的地图”，只有标记为 “可通关” 的格子我们才会进去探险；而 `memo` 则像是 **“探险日志”**，记录了每个格子已经找到的所有路线，后面再来时直接翻日志。

**核心数据结构**  

| 数据结构 | 生活化类比 | 作用 |
|----------|-----------|------|
| `set`（哈希表） | 查字典 | `O(1)` 判断一个子串是否是合法单词 |
| `list dp`（布尔数组） | 通关图 | `dp[i] = True` 表示从位置 `i` 开始还有办法通关 |
| `dict memo`（哈希表） | 探险日志 | 缓存每个起点对应的所有句子列表，防止重复递归 |

#### 代码（Python）

```python
from typing import List

def wordBreak(s: str, wordDict: List[str]) -> List[str]:
    word_set = set(wordDict)                 # 哈希表，查单词像查字典 O(1)
    n = len(s)

    # ---------- 第一步：DP 预处理 ----------
    # dp[i] 表示 s[i:] 能否被拆分成字典里的单词
    dp = [False] * (n + 1)
    dp[n] = True                             # 空串总是可以拆分

    # 逆序遍历，判断每个位置是否可以到达结尾
    for i in range(n - 1, -1, -1):
        for j in range(i + 1, n + 1):
            if s[i:j] in word_set and dp[j]:
                dp[i] = True
                break                        # 一旦找到一种合法切法即可

    # ---------- 第二步：记忆化回溯 ----------
    memo = {}                                 # memo[i] -> 从 i 开始的所有句子列表

    def backtrack(start: int) -> List[str]:
        """
        返回从位置 start 开始，所有合法的完整句子（每个句子是一个字符串）。
        """
        if start == n:                        # 已经到达字符串末尾
            return [""]                       # 空串表示已经完成一个句子

        if start in memo:                     # 已经算过，直接返回缓存
            return memo[start]

        sentences = []
        # 只枚举能够到达结尾的切分点（利用 dp 剪枝）
        for end in range(start + 1, n + 1):
            word = s[start:end]
            if word in word_set and dp[end]:  # dp[end] 为 True，说明后面还能继续
                for suffix in backtrack(end):
                    # suffix 可能是空串，需要特殊处理避免多余的空格
                    sentence = word + ("" if suffix == "" else " " + suffix)
                    sentences.append(sentence)

        memo[start] = sentences                # 记忆化
        return sentences

    return backtrack(0)
```

#### 复杂度  

- **时间复杂度**：`O(n^2 + m)`  
  - DP 预处理遍历所有区间，`O(n^2)`（`n ≤ 20`，非常小）。  
  - 回溯阶段每个起点只计算一次，且每次只遍历它后面能形成合法单词的区间，整体也是 `O(n^2)`。  
  - `m` 是答案的总字符数（返回所有句子本身需要花费的时间），这在题目中已经被限制在 `10^5` 以内。  
  - 相比暴力的 `O(2^n)`，这里是 **多项式** 级别，实际运行非常快。

- **空间复杂度**：`O(n^2 + m)`  
  - `dp`、`memo`、递归栈共占 `O(n)`~`O(n^2)`（每个位置可能保存多个子句）。  
  - 再加上返回的所有答案 `m`（不可避免的），整体空间与答案大小同阶。

## 心得

- **核心技巧**：**先用 DP 剪枝，再用记忆化回溯**。  
  - DP 负责快速判断“这条路是否可能通向终点”。  
  - 记忆化回溯负责把所有合法路径**完整收集**，并且避免重复计算。

- **适用场景**  
  1. **Word Break 系列**（139、140、151）——先判断可行性，再枚举所有方案。  
  2. **组合总和 II**（组合问题，需要先剪枝再回溯）。  
  3. **所有路径求和**（树/图的所有合法路径，需要 DP 预判可达性）。

- **一句话总结解题钥匙**：**“先把不通的路堵死，再把通的路记下来”**。

## 反思

- **第一反应**：直接写递归穷举，忽视了大量无效前缀会导致指数爆炸。  
- **最容易踩的坑**  
  - 忘记对 `dp` 做逆向遍历，导致仍然遍历大量无效子串。  
  - 递归返回的空串处理不当，会在拼接时出现多余的空格。  
  - `memo` 必须以起始下标为键，而不是整条子串（子串复制代价大）。  

- **下次遇到同类题**：  
  1. 先思考 **“能否提前判断是否有解”**（DP 可行性检查）。  
  2. 再决定 **“如何在回溯中复用已经算好的子结果”**（记忆化或构造树）。  
  3. 最后实现并注意边界（空串、末尾空格）处理。
