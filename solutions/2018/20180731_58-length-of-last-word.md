# #58. 最后一个单词的长度 / Length of Last Word

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/length-of-last-word/)

---

## 题目（英文原版）

**Description**

Given a string s consisting of words and spaces, return the length of the last word in the string.
A word is a maximal substring consisting of non-space characters only.

**Examples**

**Example 1:**

```
Input: s = "Hello World"
Output: 5
Explanation: The last word is "World" with length 5.
```

**Example 2:**

```
Input: s = "   fly me   to   the moon  "
Output: 4
Explanation: The last word is "moon" with length 4.
```

**Example 3:**

```
Input: s = "luffy is still joyboy"
Output: 6
Explanation: The last word is "joyboy" with length 6.
```

**Constraints**

- 1 <= s.length <= 104
- s consists of only English letters and spaces ' '.
- There will be at least one word in s.

---

## 题目（中文翻译）

给定一个仅由单词和空格组成的字符串 `s`，返回字符串中最后一个单词的长度。  
单词（word）是指仅由非空格字符构成的最大子串（maximal substring）。

## 示例

### 示例 1
**输入:** `s = "Hello World"`  
**输出:** `5`  
**解释:** 最后一个单词是 `"World"`，长度为 5。

### 示例 2
**输入:** `s = "   fly me   to   the moon  "`  
**输出:** `4`  
**解释:** 最后一个单词是 `"moon"`，长度为 4。

### 示例 3
**输入:** `s = "luffy is still joyboy"`  
**输出:** `6`  
**解释:** 最后一个单词是 `"joyboy"`，长度为 6。

## 约束条件
- `1 <= s.length <= 10^4`
- `s` 仅由英文字母和空格字符 `' '` 组成。
- `s` 中至少存在一个单词。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把整句话 **按照空格切成若干段**，然后把最后一个非空的段取出来，算它的字符数。

- **用到的数据结构**：`list`（列表），相当于把句子拆成一串“单词”。可以把列表想象成一本词典的目录，目录里每一项都是一个单词（这里的“单词”其实是子串）。
- **为什么正确**：题目要求“最后一个单词的长度”，而 `str.split()` 正好会把所有由空格分隔的子串都取出来（空的子串会被自动丢掉），于是列表的最后一个元素就是我们要的“最后一个单词”。
- **时间/空间复杂度**：  
  - **时间**：遍历一次字符串把它切成子串，需要 **O(n)** 的时间（`n` 为字符串长度），这在大多数情况下已经足够快。  
  - **空间**：`split` 会把每个单词都保存到列表里，最坏情况下（没有空格）会保存 `n` 个字符，也就是 **O(n)** 的额外空间。

> 大白话解释：  
> - `O(n)` 就是“随字符串长度线性增长”，如果把字符串看成一条路，走完这条路需要的时间和路的长度成正比。  
> - `O(n)` 的空间就是“需要和路的长度一样多的背包容量”。  

#### 代码（Python）

```python
def length_of_last_word(s: str) -> int:
    """
    暴力解：先把字符串按空格切成若干单词，再返回最后一个单词的长度。
    """
    # 使用 str.split() 会自动把连续的空格视为分隔符，并且把空的子串过滤掉
    words = s.split()               # 例如 "  a  b " -> ["a", "b"]
    # 列表的最后一个元素就是题目要求的最后一个单词
    last_word = words[-1]           # 直接取倒数第一个
    return len(last_word)           # 返回该单词的字符数
```

#### 复杂度

- **时间复杂度**：`O(n)` — 需要遍历完整个字符串一次来切割。
- **空间复杂度**：`O(n)` — 需要额外的列表来保存所有切出来的单词。

---

### 2. 最优解

#### 思路  

虽然上面的暴力解已经是 **线性时间**，但它用了额外的列表来保存所有单词。我们可以 **只用一次遍历**，**不申请额外的存储**，直接从字符串右侧往左找第一个非空字符，然后继续往左数，直到遇到空格或遍历到开头为止，这样得到的计数就是最后一个单词的长度。

- **慢在哪里**：暴力解在 `split` 的过程中会创建很多子串（每个单词都要复制一次），这在空间上是多余的。
- **优化思路**：从右往左扫描，遇到第一个非空字符就开始计数，遇到空格后停止。因为我们只关心“最后一个单词”，所以不需要记住其它单词的信息。
- **核心技巧**：**双指针**（其实这里用的是一个指针 + 计数器），从右侧向左移动。可以把指针想象成一只手，从句子的最右边往左抓字母，遇到空格就停下来。

> 类比：想象你在一行文字的最右边，先把手伸过去找第一个字母（跳过所有尾部的空格），随后继续往左数，直到手碰到空格或左边的墙壁——这段手指经过的字符数，就是最后一个单词的长度。

#### 代码（Python）

```python
def length_of_last_word(s: str) -> int:
    """
    最优解：一次遍历，直接从右侧统计最后一个单词的长度，空间复杂度 O(1)。
    """
    length = 0          # 用来记录最后一个单词的长度
    i = len(s) - 1      # 从字符串最右侧的下标开始

    # 1）先跳过所有结尾的空格
    while i >= 0 and s[i] == ' ':
        i -= 1

    # 2）遍历剩下的字符，只要不是空格就累加长度
    while i >= 0 and s[i] != ' ':
        length += 1
        i -= 1

    return length
```

#### 复杂度

- **时间复杂度**：`O(n)` — 最多遍历字符串一次，和暴力解的时间相同，只是常数因子更小（没有创建子串）。
- **空间复杂度**：`O(1)` — 只使用了几个整数变量，不会随输入规模增长而增加额外内存。

## 心得

- **核心技巧**：**从后往前扫描**（或双指针）可以在只关心“最后一个”或“最长/最短”等局部信息时，省掉不必要的额外存储。
- **适用的题型**：  
  1. “找出字符串中最后一个单词/数字的长度”  
  2. “去除字符串首尾空格” (`trim`)  
  3. “反向遍历数组找满足条件的第一个元素”
- **一句话总结解题钥匙**：**只从右侧向左找，遇空即停**。

## 反思

- **第一反应**：直接想到 `split()`，因为它能一次性把所有单词拆出来，写起来最省事。
- **最容易踩的坑**：  
  - 输入可能在结尾有多个空格，需要先把这些空格跳过，否则会把长度算成 0。  
  - 字符串全是空格的情况在本题不会出现（题目保证至少有一个单词），但如果没有这条保证，代码需要额外判断返回 0。
- **下次遇到同类题**：第一步先思考“我只需要最后一个/第一个满足条件的元素”，于是就尝试 **从对应方向逆向遍历**，把不需要的部分直接跳过。这样既省时又省空间。
