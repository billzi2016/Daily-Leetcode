# #32. 最长有效括号 / Longest Valid Parentheses

> 难度：困难 · 标签：String、Dynamic Programming、Stack · [LeetCode 链接](https://leetcode.com/problems/longest-valid-parentheses/)

---

## 题目（英文原版）

**Description**

Given a string containing just the characters '(' and ')', return the length of the longest valid (well-formed) parentheses substring.

**Examples**

**Example 1:**

```
Input: s = "(()"
Output: 2
Explanation: The longest valid parentheses substring is "()".
```

**Example 2:**

```
Input: s = ")()())"
Output: 4
Explanation: The longest valid parentheses substring is "()()".
```

**Example 3:**

```
Input: s = ""
Output: 0
```

**Constraints**

- 0 <= s.length <= 3 * 104
- s[i] is '(', or ')'.

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有可能的子串都枚举出来，逐个判断它们是不是「合法」的括号序列。  
- **枚举子串**：把字符串的左边界 `i`（从 0 到 n‑1）和右边界 `j`（从 `i+1` 到 n）全部遍历一遍，这相当于把一块巧克力切成所有可能的连续小块。  
- **判断合法性**：对每个子串，用一个 **栈**（可以把栈想象成“查字典”，每遇到左括号 `'('` 就在字典里记一个“待匹配”，每遇到右括号 `')'` 就把最近的左括号弹出来）来检查是否配对完整。  
  - 遇到 `'('` → 把它压入栈。  
  - 遇到 `')'` → 若栈不为空则弹出一个 `'('`（配对成功），否则说明多了一个右括号，这个子串一定非法。  
  - 最后栈为空且遍历完整个子串，说明这个子串是合法的。  

只要找到了合法子串，就记录它的长度，取所有合法子串长度的最大值即可。  

**为什么正确？**  
合法的括号序列恰好满足“每遇到一个右括号，都能在它左边找到一个未匹配的左括号”。栈正好模拟了这个过程，只有栈最终为空时才说明所有左括号都被匹配，子串合法。

#### 代码（Python）

```python
def longestValidParentheses_bruteforce(s: str) -> int:
    n = len(s)
    max_len = 0

    # 枚举所有子串的左端点 i
    for i in range(n):
        # 枚举所有子串的右端点 j（不含 j 本身），长度至少为 2
        for j in range(i + 2, n + 1, 2):   # 合法子串长度一定是偶数，步长设为 2 可以少算一半
            if is_valid(s[i:j]):          # 判断子串 s[i:j] 是否合法
                max_len = max(max_len, j - i)

    return max_len


def is_valid(sub: str) -> bool:
    """使用栈检查子串是否为合法的括号序列"""
    stack = []
    for ch in sub:
        if ch == '(':
            stack.append(ch)          # 左括号入栈
        else:  # ch == ')'
            if not stack:             # 栈空说明右括号找不到匹配的左括号
                return False
            stack.pop()               # 配对成功，弹出左括号
    return not stack                 # 栈空则全部匹配，合法
```

> 关键行中文注释已写在代码里，直接复制运行即可。

#### 复杂度  

- **时间复杂度**：`O(n³)`  
  - 外层两层循环枚举所有子串，组合数约为 `n²/2`。  
  - 每次判断合法性要遍历子串，最坏情况长度是 `O(n)`。  
  - 所以总体是 `n² * n = n³`，大约相当于“立方级别的工作量”，即使 n=10⁴ 也会超时。  

- **空间复杂度**：`O(n)`  
  - `is_valid` 函数里用了一个栈，最坏情况下栈会存 `n` 个左括号。

### 2. 最优解  

#### 思路  

暴力解的瓶颈在于 **重复遍历子串**：相同的字符会被检查很多次。我们需要一次扫描就能把所有合法子串的信息“累计”起来。  

常见的线性解法有三种：  

1. **双栈（或单栈）**：用栈记录左括号的下标，遇到匹配时直接算出当前合法子串的长度。  
2. **双指针计数**：从左到右、从右到左各扫一遍，用计数器记录左/右括号的数量，遇到平衡时更新答案。  
3. **动态规划（DP）**：`dp[i]` 表示以位置 `i`（字符 `s[i]`）结尾的最长合法子串的长度。  

这里选用 **动态规划**，因为它能清晰展示“状态转移”的思想，且容易推广到类似的区间问题。  

**状态定义**  
- `dp[i]`（`i` 为下标，0‑based）= 以 `s[i]` 为结尾的最长合法括号子串的长度。如果 `s[i]` 是 `'('`，显然不可能以它结尾合法，`dp[i] = 0`。  

**状态转移**（只讨论 `s[i] == ')'` 的情况）  

1. **直接配对**：如果 `s[i-1]` 是 `'('`，则 `s[i-1]` 与 `s[i]` 形成一对 `"()"`。此时合法子串长度为 `dp[i-2] + 2`（`i-2` 位置之前的合法子串可以直接拼接）。  
2. **间接配对**：如果 `s[i-1]` 也是 `')'`，说明 `s[i]` 可能和它左边更远的一个 `'('` 配对。我们先看 `i - dp[i-1] - 1` 这个位置——它正好是 `s[i]` 左边最近的“可能配对的左括号”。  
   - 若该位置存在且是 `'('`，则 `s[i]` 与它匹配，长度 = `dp[i-1]`（中间已经是合法子串） + 2（这对新配对） + `dp[i - dp[i-1] - 2]`（再把它左边更早的合法子串拼上，若不存在则为 0）。  

**类比**：可以把 `dp` 看成“积木”，每块积木记录以某个位置结尾的合法长度。遇到右括号时，我们尝试把左边的积木“拼接”起来，形成更大的积木。

**遍历顺序**：从左到右一次遍历即可，期间维护全局最大值 `ans`。

#### 代码（Python）

```python
def longestValidParentheses(s: str) -> int:
    n = len(s)
    dp = [0] * n          # dp[i] 表示以 i 结尾的最长合法长度
    ans = 0               # 全局最大长度

    for i in range(1, n):               # i 从 1 开始，因为要看 i-1
        if s[i] == ')':                 # 只讨论右括号
            # 情况 1：直接配对 "...()"，检查 i-1 是否是 '('
            if s[i - 1] == '(':
                dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
            # 情况 2：间接配对 "...))"，看 i - dp[i-1] - 1 是否是 '('
            else:
                # i - dp[i-1] - 1 是左括号可能出现的位置
                left_idx = i - dp[i - 1] - 1
                if left_idx >= 0 and s[left_idx] == '(':
                    # dp[i-1] 是中间合法子串长度，+2 为新配对
                    # 再加上 left_idx 左边的合法子串长度（若有）
                    dp[i] = dp[i - 1] + 2 + (dp[left_idx - 1] if left_idx >= 1 else 0)

            # 更新全局最大值
            ans = max(ans, dp[i])

    return ans
```

> 代码中每一行都有中文解释，直接运行即可得到答案。

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 只遍历一次字符串，每个字符做常数次操作。相当于“线性时间”，即使 `n=3·10⁴` 也能毫秒级完成。  

- **空间复杂度**：`O(n)`  
  - 需要一个长度为 `n` 的 `dp` 数组来保存状态。如果进一步优化（使用栈或双指针）可以把空间降到 `O(1)`，但 `O(n)` 已经足够好，且代码更易懂。

## 心得  

- **核心技巧**：**动态规划**（把子问题的答案存下来，利用它们快速推导更大的子问题）。  
- **适用题型**：  
  1. “最长有效括号”（本题）  
  2. “最长连续 1 的子数组” – 也可以用 DP 记录以当前位置结尾的长度。  
  3. “最长递增子序列” – DP 记录以每个元素结尾的最长递增长度。  
- **解题钥匙**：**先找出“局部合法”再拼接成“全局合法”。**  

---

## 反思  

- **第一反应**：把所有子串都枚举检查，想到栈来验证合法性。  
- **最容易踩的坑**：  
  - 忘记处理 `i - dp[i-1] - 1` 越界的情况。  
  - 只考虑了直接配对 `"()"`，而遗漏了 `"...))"` 这种需要跳过中间合法子串的配对。  
  - 在 DP 转移式里忘记把左边更早的合法子串 `dp[left_idx-1]` 加进来，导致答案偏小。  
- **下次思路**：遇到“最长子串”这类问题，第一步先**思考是否可以把答案拆成“以当前位置结尾的子问题”**，如果可以，马上尝试 DP 或者栈的线性扫描方案。
