## 题目（英文原版）

**Description**

Given an integer array nums of unique elements, return all possible subsets (the power set).
The solution set must not contain duplicate subsets. Return the solution in any order.

**Examples**

**Example 1:**

```
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Example 2:**

```
Input: nums = [0]
Output: [[],[0]]
```

**Constraints**

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- All the numbers of nums are unique.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是「把每个元素都拿或不拿」遍历所有可能的组合。  
- **数据结构**：我们只需要一个普通的 Python 列表 `subset` 来暂存当前正在构造的子集，最终的答案用 `result`（也是列表）保存所有子集。  
- **生活化类比**：想象你在超市购物，每件商品你可以选择**放进购物车**（拿）或**不放**（不拿），所有的购物车组合就是所有子集。  
- **为什么正确**：因为题目要求返回「所有」可能的子集，而「每件商品都有两种状态」恰好覆盖了所有情况。只要我们把「拿」和「不拿」的所有组合都枚举出来，就一定能得到完整的答案。  
- **时间/空间复杂度**：  
  - 对于长度为 `n` 的数组，**每个元素都有 2 种选择**，所以总共会产生 `2^n` 种子集。遍历这些子集的时间是 `O(2^n)`，而在每次生成子集时我们会复制一次列表（长度最多 `n`），所以总体时间可以认为是 `O(n·2^n)`。  
  - 空间上，递归深度最多 `n`（因为我们要把每个元素都决定一次），再加上存放所有子集的结果，需要 `O(2^n)` 的空间（因为答案本身就这么大）。

> **大白话**：`O(2^n)` 就像把所有灯的开关（每个灯有开/关两种状态）全打开一次，组合的数量会指数级增长，`n` 越大，数量会“翻倍翻倍”。  

#### 代码（Python）

```python
from typing import List

def subsets(nums: List[int]) -> List[List[int]]:
    """
    暴力枚举：对每个元素，都决定“选”或“不选”，递归遍历所有可能。
    """
    result = []                     # 用来保存所有子集
    n = len(nums)

    def backtrack(index: int, path: List[int]) -> None:
        """
        index   : 当前正在考虑的元素下标
        path    : 已经选好的元素集合（一个子集）
        """
        # 每进入一次递归，就把当前的 path 复制一份加入结果
        result.append(path.copy())  # copy 防止后面修改影响已经保存的子集

        # 从 index 开始尝试把后面的每个元素加入子集
        for i in range(index, n):
            path.append(nums[i])    # 选 nums[i]
            backtrack(i + 1, path)  # 递归处理下一个位置
            path.pop()              # 撤销选择，回溯到上一步

    # 从第 0 个元素开始，当前子集为空 []
    backtrack(0, [])
    return result
```

#### 复杂度

- **时间复杂度**：`O(n·2^n)`  
  - `2^n` 是子集的总数，`n` 是每次复制子集时最坏需要遍历的元素个数。可以把它想象成「每生成一个子集，都要把最多 `n` 本书的目录抄一遍」。
- **空间复杂度**：`O(2^n)`（答案本身）+ `O(n)`（递归栈）  
  - 递归栈深度最多 `n`，答案列表需要存 `2^n` 个子集。

### 2. 最优解

#### 思路  

暴力解已经是「遍历所有子集」的必然做法，真正的优化点在于 **如何更简洁、直观地生成这些子集**，并且 **把代码的结构写得更易懂**。常见的两种思路：

1. **回溯（Backtracking）**——和上面的暴力解本质相同，只是把「把每个元素都决定一次」的过程写成递归框架，使代码更简洁。  
2. **位运算（Bit Manipulation）**——把子集的「选或不选」看成二进制位。`0` 表示不选，`1` 表示选。遍历 `0 … 2^n-1` 的所有整数，每个整数的二进制位自然对应一种子集。

这里重点讲 **位运算**，因为它在时间复杂度上和回溯一样（`O(n·2^n)`），但实现上只用两层循环，思路更“数学化”，有时写起来更快。

- **核心概念：二进制位**  
  把数组长度 `n` 看成 `n` 位二进制数。比如 `n=3`，整数 `5` 的二进制是 `101`，从右往左第 0 位对应 `nums[0]`，第 1 位对应 `nums[1]`，第 2 位对应 `nums[2]`。`1` 表示把对应的元素放进子集，`0` 表示不放。  

- **步骤**  
  1. 计算子集总数 `total = 1 << n`（左移相当于 `2^n`）。  
  2. 用 `mask` 从 `0` 遍历到 `total-1`。每个 `mask` 表示一种子集。  
  3. 对每个 `mask`，检查它的每一位 `j`（`0 … n-1`），如果第 `j` 位是 `1`，就把 `nums[j]` 加入当前子集。  

- **为什么更好**：  
  - 只用了两层普通循环，没有递归调用，省去了函数调用的开销（在 Python 中递归稍慢）。  
  - 代码结构一目了然：外层遍历「所有子集」，内层遍历「子集中每个位置是否被选」。  

#### 代码（Python）

```python
from typing import List

def subsets(nums: List[int]) -> List[List[int]]:
    """
    位运算实现：用整数的二进制位表示子集的选取状态。
    """
    n = len(nums)
    total = 1 << n                 # 2^n，所有子集的数量
    result = []

    for mask in range(total):      # mask 从 0 到 2^n-1，遍历每一种选取方式
        subset = []
        for j in range(n):         # 检查 mask 的第 j 位是否为 1
            if mask & (1 << j):    # & 运算保留第 j 位，若不为 0 则说明选了 nums[j]
                subset.append(nums[j])
        result.append(subset)      # 收集当前子集

    return result
```

#### 复杂度

- **时间复杂度**：`O(n·2^n)`  
  - `2^n` 是子集总数，外层循环遍历每个子集，内层最多检查 `n` 位（即 `n` 次位运算），相当于「把每个子集的所有可能元素都看一遍」。
- **空间复杂度**：`O(2^n)`（存放答案）+ `O(n)`（临时子集列表）  
  - 与暴力回溯相同，因为答案本身就是指数级的。

> **对比**：相较于递归版的「函数调用栈」开销，位运算版的循环更省内存、更快一些，但核心复杂度没有改变——因为无论怎么写，输出所有子集本身就需要 `2^n` 的空间和时间。

## 心得

- **核心技巧**：**用二进制位枚举子集**（位运算）或 **回溯**（深度优先搜索）都是遍历幂集的标准方法。  
- **适用的题型**：  
  1. **子集类**：`Subsets II`（含重复元素，需要去重）、`Combination Sum`（求和组合）  
  2. **子序列/子数组枚举**：`Permutations`（全排列）、`Letter Case Permutation`（大小写全排列）  
  3. **状态压缩 DP**：`Maximum Profit in Job Scheduling`（用位表示状态）  
- **一句话总结解题钥匙**：**把“选或不选”转化为“二进制位是 1 还是 0”，遍历所有二进制数即可得到所有子集**。

## 反思

- **第一反应**：看到“所有子集”，立刻想到“每个元素都有选或不选两种状态”，于是想到递归或位运算。  
- **最容易踩的坑**：  
  - **遗漏空集**：`mask = 0` 对应的子集是空集，别忘了把它加入答案。  
  - **位数对应错误**：检查第 `j` 位时要用 `mask & (1 << j)`，不要写成 `mask >> j & 1`（虽然也可，但要注意运算顺序）。  
  - **答案顺序**：题目不要求特定顺序，但如果你在面试中手写代码，保持输出顺序一致（比如从 `0` 到 `2^n-1`）更容易让面试官检查。  
- **下次第一步**：先判断「是否需要去重」或「是否有额外约束」（如子集大小、和等），如果没有，直接考虑「二进制位枚举」或「回溯」两条主线之一。
