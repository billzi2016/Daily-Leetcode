## 题目（英文原版）

**Description**

Implement pow(x, n), which calculates x raised to the power n (i.e., xn).

**Examples**

**Example 1:**

```
Input: x = 2.00000, n = 10
Output: 1024.00000
```

**Example 2:**

```
Input: x = 2.10000, n = 3
Output: 9.26100
```

**Example 3:**

```
Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2-2 = 1/22 = 1/4 = 0.25
```

**Constraints**

- -100.0 < x < 100.0
- -231 <= n <= 231-1
- n is an integer.
- Either x is not zero or n > 0.
- -104 <= xn <= 104

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把 `x` 连乘 `n` 次：  

```
result = 1
for i in range(n):
    result *= x
```

- **用到的数据结构**：这里只需要一个普通的变量 `result`，相当于我们手里的一只杯子，先装 1，然后每次往里倒 `x`，倒 `n` 次就得到答案。  
- **为什么正确**：数学上 `xⁿ` 就是 `x` 与自身相乘 `n` 次，循环每次都把 `result` 乘以 `x`，正好实现了这个定义。  
- **时间/空间复杂度**：  
  - 时间复杂度是 **O(|n|)**。如果 `n` 为正，需要循环 `n` 次；如果 `n` 为负，我们可以先把 `x` 换成 `1/x` 再循环 `|n|` 次。这里的 “O(|n|)” 可以理解为“随 `n` 的绝对值线性增长”。  
  - 空间复杂度是 **O(1)**，因为只用了常数个变量，和 `n` 大小无关。

> **注意**：在 Python 中直接 `for i in range(n)` 当 `n` 为负数会报错，所以我们需要先把负指数转成正数再处理。

#### 代码（Python）

```python
def myPow_brute(x: float, n: int) -> float:
    """
    暴力实现：把 x 连乘 n 次
    """
    # 负指数转正，并把 x 取倒数
    if n < 0:
        x = 1 / x          # 把 x 变成 1/x
        n = -n             # 把 n 变成正数

    result = 1.0           # 初始值相当于乘法的“1”
    for _ in range(n):     # 循环 n 次
        result *= x        # 每次把 result 乘以 x
    return result
```

#### 复杂度

- **时间复杂度**：`O(|n|)` — 需要执行 `|n|` 次乘法，`|n|` 越大耗时越久。  
- **空间复杂度**：`O(1)` — 只用了常数个变量，和 `n` 的大小无关。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**每次只乘一次**，当 `|n|` 很大（比如 `10⁹`）时，循环次数会爆炸，根本不可接受。  
我们可以利用 **“指数的二分”**（又叫 **快速幂**、**二进制指数**）来把乘法次数压缩到 **对数级**。

**关键观察**：

- `xⁿ` 可以拆成 `xⁿ = (x²)ⁿ⁄²`（当 `n` 为偶数）  
  - 例子：`x⁸ = (x⁴)² = ((x²)²)²`，只需要算 `x²`、`x⁴`、`x⁸` 三次乘法，而不是八次。  
- 当 `n` 为奇数时，`xⁿ = x * xⁿ⁻¹`，此时把 `n-1` 变成偶数再使用上面的拆分。  

这正好对应 **二进制** 的思想：  
把 `n` 写成二进制，例如 `13 = 1101₂ = 8 + 4 + 1`，则  

```
x¹³ = x⁸ * x⁴ * x¹
```

只要我们在遍历二进制位的过程中，**每次把当前的底数平方**，并在对应位为 `1` 时把结果乘进去，就能在 **log₂|n|** 次乘法内完成计算。

实现方式有两种：

1. **递归**：把问题不断「除以 2」直到基准情形 `n == 0`。  
2. **迭代（循环）**：用 `while n != 0`，每次右移 `n`（相当于除以 2），并把当前 `x` 平方。

下面给出递归版和迭代版，两者时间复杂度相同，迭代版更省栈空间。

**数据结构类比**：

- **位运算** 像是把数字拆成「灯泡」的开关（0/1），我们只在灯泡亮（位为 1）的时候才把对应的「电流」乘进去。  
- **变量 `current`**（当前底数）像是「不断翻倍的水桶」，每次翻倍后如果灯泡亮，就往答案里倒一点水。

#### 代码（Python）

```python
def myPow(x: float, n: int) -> float:
    """
    快速幂（二进制指数）实现，时间 O(log|n|)，空间 O(1)
    """
    # 处理负指数：把 x 换成 1/x，n 取正
    if n < 0:
        x = 1 / x
        n = -n

    result = 1.0          # 最终答案
    current = x           # 当前的 x^(2^i)，初始 i=0 时是 x^1

    while n > 0:
        # n 的最低位是 1 时，需要把当前的 current 乘到结果里
        if n & 1:         # n & 1 等价于 n % 2，只判断最低位是否为 1
            result *= current   # 把对应的幂乘进去

        # 把 current 平方，准备进入下一位（相当于 x^(2^(i+1))）
        current *= current

        # 右移一位，等价于 n //= 2，进入下一位检查
        n >>= 1            # n >>= 1 是 n = n // 2 的快捷写法

    return result
```

> **递归版（供参考）**  
> ```python
> def myPow_recursive(x: float, n: int) -> float:
>     if n == 0:
>         return 1.0
>     if n < 0:
>         x = 1 / x
>         n = -n
>     half = myPow_recursive(x, n // 2)   # 先算出 x^(n//2)
>     if n % 2 == 0:                     # 偶数
>         return half * half
>     else:                              # 奇数
>         return half * half * x
> ```

#### 复杂度

- **时间复杂度**：`O(log|n|)` — 只需要遍历 `n` 的二进制位数，位数大约是 `log₂|n|`，比暴力的 `|n|` 快很多。  
- **空间复杂度**：`O(1)` — 只用了固定数量的变量（`result、current、n`），不随 `n` 增长。  
  - 若使用递归实现，则额外的调用栈深度为 `O(log|n|)`，但迭代版可以保持 `O(1)`。

## 心得

- **核心技巧**：**二进制分解 + 快速幂**（把指数的乘法次数压到对数级）。  
- **适用的题型**：  
  1. 计算大整数幂（如 LeetCode 50. Pow(x, n)）  
  2. 矩阵快速幂（求第 `n` 项斐波那契等）  
  3. 模幂运算（如 `pow(a, b, mod)`，常见于密码学）  
- **一句话总结**：**“把指数写成二进制，只在 1 位上乘”，就是快速幂的钥匙。**

## 反思

- **第一反应**：直接循环乘 `n` 次——这就是暴力解。  
- **最容易踩的坑**：  
  - 负指数需要先取倒数并把指数取正，否则循环会出错。  
  - `n` 为最小的 32 位整数 `-2³¹` 时，`-n` 会溢出（在 Python 不会，但在某些语言会），所以先把 `x` 取倒数再把 `n` 变正是更安全的做法。  
  - 浮点数精度：`x`、`n` 范围很大时，返回值会有微小误差，题目只要求 1e-5 以内的误差即可。  
- **下次第一步**：**先判断指数的符号，再考虑二进制拆分**，即“负号处理 → 二进制位遍历”。这样可以迅速把思路锁定在快速幂上，避免再走回暴力循环。
