# #136. 只出现一次的数字 / Single Number

## 题目（英文原版）

**Description**

Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.
You must implement a solution with a linear runtime complexity and use only constant extra space.

**Examples**

**Example 1:**

```
Input: nums = [2,2,1]
Output: 1
```

**Example 2:**

```
Input: nums = [4,1,2,1,2]
Output: 4
```

**Example 3:**

```
Input: nums = [1]
Output: 1
```

**Constraints**

- 1 <= nums.length <= 3 * 104
- -3 * 104 <= nums[i] <= 3 * 104
- Each element in the array appears twice except for one element which appears only once.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把每个数字都和别的数字两两比较**，看有没有相同的。如果找不到相同的，那它就是只出现一次的那个数。

- **使用的数据结构**：我们只需要遍历数组本身，不需要额外的数据结构。  
- **生活化类比**：想象你在检查一堆钥匙，每把钥匙都可能有一把相同的备份。最笨的办法就是把每把钥匙都拿出来，和剩下的每一把钥匙逐个对比，看看有没有相同的。如果找不到配对的钥匙，那这把钥匙就是唯一的。  

这个方法**一定正确**，因为题目保证只有一个数出现一次，其他数都恰好出现两次。只要我们把每个数都和所有其它数比较一次，就一定能发现它是否有配对。

#### 代码（Python）

```python
def singleNumber_brute(nums):
    n = len(nums)
    # 外层循环：依次取出每个元素 i
    for i in range(n):
        found = False                 # 标记 i 是否找到了配对
        # 内层循环：把 i 和后面的每个元素 j 作比较
        for j in range(n):
            if i != j and nums[i] == nums[j]:
                found = True          # 找到相同的元素，说明 i 有配对
                break
        if not found:                 # 没有配对的 i 就是唯一的元素
            return nums[i]
    # 根据题目条件，这行代码永远不会被执行
    return None
```

#### 复杂度  

- **时间复杂度**：`O(n²)`  
  - “n²” 可以想象成把 `n`（比如 10）个元素排成 10 行 10 列的格子，每个格子都要检查一次。也就是说，随着数组长度的增加，比较次数会以 **平方** 的速度增长，数组 1000 长时要检查 1,000,000 次，明显太慢了。  
- **空间复杂度**：`O(1)`  
  - 只用了常数个额外变量（`found`, `i`, `j`），和数组长度无关。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈在于大量的两两比较**。我们需要一种方式，**一次遍历就能把配对的数字“抵消掉”，只留下唯一的数字**。这里就可以利用 **异或 (XOR) 运算** 的两个重要特性：

1. **相同的数异或结果为 0**  
   `a ^ a = 0`  
   把两个相同的数异或，就相当于把它们“抵消”。  
2. **0 与任意数异或仍是该数**  
   `a ^ 0 = a`  

另外，异或运算满足**交换律**和**结合律**，所以我们可以把所有数字的异或顺序随意打乱，最终的结果不变。

**核心想法**：把数组里的所有数依次做 `result = result ^ num`。成对出现的数会两两抵消成 0，最后只剩下唯一出现一次的那个数。

- **使用的数据结构**：只需要一个整数变量 `result`，它相当于“记事本”，不断把当前看到的数“写进去”。  
- **生活化类比**：想象你有一个只能记“奇数次出现”的魔法盒子，每放进一个相同的物品两次，盒子就会把它“清空”。最后盒子里剩下的，就是只出现一次的那件物品。

#### 代码（Python）

```python
def singleNumber(nums):
    """
    使用异或运算一次遍历找出只出现一次的数字
    :param nums: List[int] - 输入数组，保证除一个数外，其他数均出现两次
    :return: int - 唯一出现一次的数
    """
    result = 0               # 先把 result 初始化为 0（因为 0 与任何数异或不改变该数）
    for num in nums:
        result ^= num        # result = result ^ num，逐个把数组元素异或进来
    return result            # 循环结束后，result 就是唯一的数字
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 只需要遍历一次数组，随着数组长度线性增长，1000 长只检查 1000 次，远快于 `O(n²)`。  
- **空间复杂度**：`O(1)`  
  - 只用了一个整数 `result`，不随输入规模变化。

## 心得

- **核心技巧**：利用异或的“相同抵消、不同保留”特性，实现 **线性时间、常数空间** 的解法。  
- **适用的题型**：  
  1. **所有数出现两次，只有一个数出现一次**（本题）。  
  2. **所有数出现三次，只有一个数出现一次**（可以使用位计数的思路）。  
  3. **数组中出现奇数次的数**（同样可用异或）。  
- **一句话总结解题钥匙**：**把“配对”用异或消掉，剩下的就是唯一的数**。

## 反思

- **第一反应**：看到“每个元素出现两次，只有一个出现一次”，立刻想到要把配对的数“配对消除”。  
- **最容易踩的坑**：  
  - 忘记把 `result` 初始化为 `0`（如果直接用第一个数初始化，仍然可以，但需要额外判断空数组）。  
  - 对负数的异或仍然有效，但有些初学者可能担心符号位，实际 Python 的整数是无限位的，直接使用即可。  
- **下次遇到同类题，第一步该想到**：**是否可以用位运算（尤其是 XOR）把配对的元素“抵消”，从而只保留出现奇数次的元素**。
