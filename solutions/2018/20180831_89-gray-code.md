# #89. 灰码 / Gray Code

## 题目（英文原版）

**Description**

An n-bit gray code sequence is a sequence of 2n integers where:
Given an integer n, return any valid n-bit gray code sequence.

**Examples**

**Example 1:**

```
Input: n = 2
Output: [0,1,3,2]
Explanation:
The binary representation of [0,1,3,2] is [00,01,11,10].
- 00 and 01 differ by one bit
- 01 and 11 differ by one bit
- 11 and 10 differ by one bit
- 10 and 00 differ by one bit
[0,2,3,1] is also a valid gray code sequence, whose binary representation is [00,10,11,01].
- 00 and 10 differ by one bit
- 10 and 11 differ by one bit
- 11 and 01 differ by one bit
- 01 and 00 differ by one bit
```

**Example 2:**

```
Input: n = 1
Output: [0,1]
```

**Constraints**

- 1 <= n <= 16

## 题目（中文翻译）

给定一个整数 `n`，返回任意有效的 **n 位格雷码 (gray code) 序列**。

**示例 1**  
**输入**: `n = 2`  
**输出**: `[0,1,3,2]`  
**解释**:  
`[0,1,3,2]` 的二进制表示为 `[00,01,11,10]`。  
- `00` 与 `01` 只相差一位  
- `01` 与 `11` 只相差一位  
- `11` 与 `10` 只相差一位  
- `10` 与 `00` 只相差一位  

`[0,2,3,1]` 也是一个合法的格雷码序列，其二进制表示为 `[00,10,11,01]`。  
- `00` 与 `10` 只相差一位  
- `10` 与 `11` 只相差一位  
- `11` 与 `01` 只相差一位  
- `01` 与 `00` 只相差一位  

**示例 2**  
**输入**: `n = 1`  
**输出**: `[0,1]`  

**约束条件**  
- `1 <= n <= 16`   (即序列长度为 `2^n` 个整数)

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把所有 2ⁿ 个整数都列出来**，然后尝试把它们排成一条链，使得相邻的两个数在二进制表示下只差 **一位**（即汉明距离为 1）。  

- **数据结构**：我们可以把每个整数看成一张“卡片”。要找相邻的卡片，就像在字典里查单词一样，需要比较它们的二进制“字形”。这里的“比较”其实是 **按位异或**（`a ^ b`），如果结果恰好只有一个 1，就说明它们只差一位。  
- **为什么正确**：只要我们能找到一条遍历所有卡片的路径，并且每一步都满足“一位不同”，这条路径本身就是合法的 Gray 码序列。  
- **时间/空间分析**：  
  - 暴力搜索相当于在 **2ⁿ** 张卡片中做深度优先搜索，每一步都要尝试所有未访问的卡片。最坏情况下会遍历所有可能的排列，复杂度是 **O((2ⁿ)!)**（阶乘），这在 n=4 以后已经天文数字。  
  - 需要保存已经访问过的卡片集合（哈希表），空间是 **O(2ⁿ)**。

> **大白话**：`O((2ⁿ)!)` 就像你要把 16 张牌全排成一列，尝试每一种可能的顺序，根本不可能在电脑里跑完。

#### 代码（Python）

```python
from typing import List

def grayCode_bruteforce(n: int) -> List[int]:
    """暴力回溯求 n 位 Gray 码（仅作演示，实际不可用）"""
    total = 1 << n                     # 2ⁿ 个数
    used = set()                       # 已经放进序列的数，类似“字典”
    path = []                          # 当前构造的序列

    # 判断 a 与 b 是否只差一位
    def differ_one_bit(a: int, b: int) -> bool:
        return (a ^ b).bit_count() == 1   # XOR 结果里 1 的个数恰好是 1

    # 深度优先搜索
    def dfs() -> bool:
        if len(path) == total:          # 全部放完，找到合法序列
            return True
        for nxt in range(total):
            if nxt not in used and (not path or differ_one_bit(path[-1], nxt)):
                used.add(nxt)
                path.append(nxt)
                if dfs():
                    return True
                # 回溯
                used.remove(nxt)
                path.pop()
        return False

    dfs()
    return path
```

> 代码里每一行都有中文注释，帮助你对照思路。

#### 复杂度

- **时间复杂度**：`O((2ⁿ)!)` —— 必须尝试所有排列，几乎不可能在合理时间内完成。  
- **空间复杂度**：`O(2ⁿ)` —— 记录已经使用的数字以及当前路径，最多存 2ⁿ 个整数。

### 2. 最优解

#### 思路  

从暴力解可以看到 **瓶颈** 在于 **“每一步都要遍历所有未使用的数”**。其实 Gray 码有非常好的结构特性，根本不需要搜索：

1. **反射法（递归构造）**  
   - 先写出 n‑1 位的 Gray 码序列 `G`。  
   - 把 `G` 正序放在前半段，**在每个数前面加 0**（实际上不需要显式加，因为最高位是 0）。  
   - 把 `G` 逆序放在后半段，**在每个数前面加 1**（相当于在数值上加 `1 << (n-1)`）。  
   - 这样得到的序列天然满足相邻只差一位，因为前半段内部、后半段内部都是递归保证的，且中间的过渡点是 `0…0` 与 `1…0`，只差最高位 1 位。

2. **公式法（位运算）**  
   - 对于任意 `i`（0 ≤ i < 2ⁿ），Gray 码可以直接用公式 **`g = i ^ (i >> 1)`** 计算。  
   - 解释一下：`i` 的二进制是自然顺序，`i >> 1` 把它右移一位，相当于把高位的变化“带到”低位。异或（XOR）正好把两者不同的位标记为 1，结果就是相邻只差一位的 Gray 码。  

> **类比**：把 `i` 看成一本普通的数字书，`i>>1` 就像把这本书往左平移一页。把两本书对应页码做“不同标记”（异或），得到的就是一本“只改动一格”的特殊书——Gray 码。

我们这里使用 **公式法**，因为它最简洁、只需要一次遍历。

#### 代码（Python）

```python
from typing import List

def grayCode(n: int) -> List[int]:
    """利用位运算公式直接生成 n 位 Gray 码序列"""
    total = 1 << n                 # 2ⁿ
    res = []
    for i in range(total):
        gray = i ^ (i >> 1)        # i 与 i 右移一位的异或，得到 Gray 码
        res.append(gray)          # 把结果放进列表
    return res
```

- `i ^ (i >> 1)`：`^` 是异或，`>>` 是右移。右移一位相当于把高位的变化“提前”，异或后恰好只保留相邻位的差异。

#### 复杂度

- **时间复杂度**：`O(2ⁿ)` —— 只需要遍历 `0 … 2ⁿ-1` 一遍，线性时间。相比暴力的阶乘级别，快得多。  
- **空间复杂度**：`O(2ⁿ)` —— 结果列表本身需要存放 `2ⁿ` 个整数，属于必要空间。

## 心得

- **核心技巧**：**位运算（异或 & 右移）** 可以把看似需要搜索的问题转化为直接公式计算。  
- **适用的题型**：  
  1. **Gray Code 变体**（如求两个 Gray 编码的最小翻转次数）。  
  2. **求整数的二进制翻转或反转**（如 LeetCode 190. Reverse Bits）。  
  3. **利用异或判断奇偶性或唯一元素**（如 LeetCode 136. Single Number）。  
- **一句话总结**：*“相邻只变一位的序列，直接用 `i ^ (i>>1)` 生成，别再用暴力回溯了。”*

## 反思

- **第一反应**：看到“相邻只差一位”，立刻想到“哈希表 + 深度搜索”，于是写出了暴力回溯。  
- **最容易踩的坑**：  
  - 忘记 `i >> 1` 的右移会把最高位填 0，导致公式在最高位失效（其实这正是我们想要的）。  
  - 对 `n=0` 的边界没有考虑，答案应该是 `[0]`（本题限制 n≥1，暂不涉及）。  
  - 在某些语言里 `^` 是乘方，需要确认是位异或。  
- **下次第一步**：先 **思考是否有已知的数学/位运算公式**，再决定是否需要搜索或 DP。对“相邻只差一位”这类问题，**Gray 码公式** 常常是最直接的钥匙。
