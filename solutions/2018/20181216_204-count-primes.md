## 题目（英文原版）

**Description**

Given an integer n, return the number of prime numbers that are strictly less than n.

**Examples**

**Example 1:**

```
Input: n = 10
Output: 4
Explanation: There are 4 prime numbers less than 10, they are 2, 3, 5, 7.
```

**Example 2:**

```
Input: n = 0
Output: 0
```

**Example 3:**

```
Input: n = 1
Output: 0
```

**Constraints**

- 0 <= n <= 5 * 106

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是把 **每个小于 n 的整数** 都检查一遍，判断它是不是质数（只能被 1 和它本身整除的数）。  
- **判断质数**：对一个数 `x`，我们可以从 `2` 开始一直除到 `sqrt(x)`（因为如果 `x = a * b`，必有 `a ≤ sqrt(x)`），只要找不到可以整除的数，就说明 `x` 是质数。  
- **使用的数据结构**：这里几乎不需要额外的数据结构，只用几个整数变量来循环。可以把它想象成我们在超市里一次挑选每件商品，然后逐个检查它们的“标签”，看是否符合“质数”这一条件。

这个方法之所以 **正确**，是因为质数的定义本身就是“没有除 1 和自身之外的因子”，我们把所有可能的因子都穷举检查了一遍，自然不会漏掉任何一个质数。

#### 代码（Python）

```python
import math

def count_primes_brute(n: int) -> int:
    """暴力枚举，时间复杂度高"""
    def is_prime(x: int) -> bool:
        """判断 x 是否为质数"""
        if x < 2:                     # 0、1 不是质数
            return False
        # 只需要检查到 sqrt(x) 就够了
        limit = int(math.isqrt(x))    # math.isqrt(x) == int(sqrt(x))
        for d in range(2, limit + 1):
            if x % d == 0:            # 能整除，说明不是质数
                return False
        return True

    count = 0
    for num in range(2, n):           # 只需要从 2 开始，因为 0、1 已经排除
        if is_prime(num):
            count += 1
    return count
```

#### 复杂度  

- **时间复杂度**：`O(n * sqrt(n))`  
  - 大白话：我们对每个小于 `n` 的数都要检查一次，而检查一个数最坏要尝试 `sqrt(该数)` 次除法。比如 `n = 10^6`，大约要做 `10^6 * 1000` 次运算，明显太慢。  
- **空间复杂度**：`O(1)`  
  - 只用了常数个变量，不随 `n` 增长。

---

### 2. 最优解

#### 思路  

从暴力解可以看出，**瓶颈** 在于我们对同一个数的因子做了大量重复的检查。实际上，**大多数整数都不是质数**，我们完全可以一次性把所有“合数”剔除掉，只留下质数。

这正是 **埃拉托斯特尼筛法（Sieve of Eratosthenes）** 的核心思想：

1. 创建一个长度为 `n` 的布尔数组 `is_prime`，默认全部标记为 `True`（表示“可能是质数”）。下标 i 代表整数 i。  
2. 从最小的质数 `2` 开始，遍历到 `sqrt(n)`（因为更大的数的倍数已经在前面被标记）。  
3. 每当发现 `is_prime[p]` 为 `True`，说明 `p` 是质数。接下来把 `p` 的所有 **严格大于 p 的倍数**（`p*p, p*p+p, p*p+2p, ...`）全部标记为 `False`，因为这些数一定不是质数。  
4. 最后，数组中仍为 `True` 的下标即为小于 `n` 的质数，统计它们的个数即可。

**类比**：想象我们有一排编号从 2 开始的灯，每盏灯初始都是亮的（可能是质数）。当我们确定 2 是质数后，就把所有能被 2 整除的灯关掉（因为它们一定不是质数）。然后继续找下一个仍亮着的灯（下一个质数 3），把它的倍数关掉……如此往复，最后留下的亮灯就是所有质数。

#### 代码（Python）

```python
import math

def count_primes_sieve(n: int) -> int:
    """埃拉托斯特尼筛法，时间复杂度 O(n log log n)"""
    if n <= 2:
        return 0                     # 小于 2 的范围里没有质数

    # 步骤 1：初始化布尔数组，True 表示“可能是质数”
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False   # 0、1 肯定不是质数

    # 步骤 2：只需要遍历到 sqrt(n)
    limit = int(math.isqrt(n - 1))
    for p in range(2, limit + 1):
        if is_prime[p]:                # p 仍为 True，说明是质数
            # 步骤 3：把 p 的所有倍数标记为 False
            # 从 p*p 开始，因为 p 以下的倍数已经在更小的质数循环里被标记过了
            start = p * p
            for multiple in range(start, n, p):
                is_prime[multiple] = False

    # 步骤 4：统计 True 的个数，即为质数的数量
    return sum(is_prime)
```

#### 复杂度  

- **时间复杂度**：`O(n log log n)`  
  - 大白话：筛法的每个数只会被它的**最小**质因子标记一次。整体上看，标记的次数大约是 `n * (1/2 + 1/3 + 1/5 + …)`，这个和的增长速度非常慢，约等于 `log log n`。因此即使 `n` 达到 `5·10⁶`，运行也非常快。  
- **空间复杂度**：`O(n)`  
  - 需要一个长度为 `n` 的布尔数组来记录每个整数是否仍可能是质数。对于 `5·10⁶` 大约占用 5 MB 左右的内存，完全在普通机器的承受范围内。

## 心得

- **核心技巧**：埃拉托斯特尼筛法（Sieve of Eratosthenes），一次性剔除所有合数，利用“标记”把重复工作降到最低。  
- **适用的题型**  
  1. **统计区间内的质数**（如本题、LeetCode 204计数质数的扩展版）。  
  2. **求区间内所有质数**（如“输出小于 N 的所有质数”）。  
  3. **与质数相关的其他数论问题**（如“求每个数的最小质因子”“欧拉函数”等）。  
- **一句话总结解题钥匙**：**用筛子一次性把所有“不是质数”的数字挑出来，剩下的自然就是质数。**

## 反思

- **第一反应**：直接遍历每个数，逐个检查是否有因子——也就是暴力解。  
- **最容易踩的坑**  
  - **边界条件**：`n <= 2` 时直接返回 0，防止访问 `is_prime[0]`、`is_prime[1]` 时出错。  
  - **起始倍数**：在筛除时必须从 `p * p` 开始，否则会重复标记已经被更小质数处理过的数，导致不必要的循环。  
  - **整数溢出**：在 Python 中不必担心，但在某些语言里 `p * p` 可能会超过整数范围，需要使用更大的数据类型。  
- **下次遇到同类题**：第一步先问自己“有没有可以一次性剔除大量无效候选的办法”，如果答案是“是”，就立刻想到筛法或类似的**预处理**技巧。这样可以把原本 `O(n√n)` 的暴力搜索降到 `O(n log log n)`，效率提升数十倍甚至上百倍。
