# #198. 打家劫舍 / House Robber

> 难度：中等 · 标签：Array、Dynamic Programming · [LeetCode 链接](https://leetcode.com/problems/house-robber/)

---

## 题目（英文原版）

**Description**

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed, the only constraint stopping you from robbing each of them is that adjacent houses have security systems connected and it will automatically contact the police if two adjacent houses were broken into on the same night.
Given an integer array nums representing the amount of money of each house, return the maximum amount of money you can rob tonight without alerting the police.

**Examples**

**Example 1:**

```
Input: nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3).
Total amount you can rob = 1 + 3 = 4.
```

**Example 2:**

```
Input: nums = [2,7,9,3,1]
Output: 12
Explanation: Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
Total amount you can rob = 2 + 9 + 1 = 12.
```

**Constraints**

- 1 <= nums.length <= 100
- 0 <= nums[i] <= 400

## 题目（中文翻译）

你是一名专业的盗贼，计划在一条街道上对房子进行抢劫。每栋房子里都存放着一定数量的钱，唯一的限制是相邻的房子（adjacent houses）之间的安全系统相连，如果同一夜里抢劫了两栋相邻的房子，系统会自动报警并联系警察。

给定一个整数数组 `nums`，其中 `nums[i]` 表示第 `i` 栋房子中的现金数额，返回在不触发警报的前提下，你今晚能够抢劫到的最大现金总额。

示例 1:
```
Input: nums = [1,2,3,1]
Output: 4
Explanation: 抢劫第 1 栋房子（money = 1），然后抢劫第 3 栋房子（money = 3）。
总金额 = 1 + 3 = 4。
```

示例 2:
```
Input: nums = [2,7,9,3,1]
Output: 12
Explanation: 抢劫第 1 栋房子（money = 2），抢劫第 3 栋房子（money = 9），再抢劫第 5 栋房子（money = 1）。
总金额 = 2 + 9 + 1 = 12。
```

约束条件：
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**枚举所有可能的抢劫方案**，挑出合法且总金额最大的那一种。  
- 我们可以把每栋房子看成一张“是否抢劫”的卡片，拿或不拿都是一种选择。  
- 对于 `n` 栋房子，一共有 `2ⁿ` 种组合（因为每栋房子有两种状态）。  
- 只要遍历每一种组合，检查是否出现相邻两栋都被抢（相当于把字典里两个相邻的 key 都勾选了），如果没有冲突，就把该组合的金额相加，记录最大值。

> **类比**：把每栋房子想成一本词典的词条，想要查找所有不相邻的词条组合，就像在词典里挑选不相邻的页码一起阅读。

该方法一定能得到正确答案，因为我们穷举了**所有**合法的抢劫方式。

#### 代码（Python）

```python
from itertools import product

def rob_bruteforce(nums):
    n = len(nums)
    max_money = 0

    # product 会产生 0/1 的所有长度为 n 的二进制序列，0 表示不抢，1 表示抢
    for mask in product([0, 1], repeat=n):
        # 检查是否出现相邻两位都是 1（即相邻两家都被抢）
        illegal = any(mask[i] == 1 and mask[i + 1] == 1 for i in range(n - 1))
        if illegal:
            continue                     # 不合法的方案直接跳过

        # 计算合法方案的总金额
        cur_money = sum(nums[i] for i in range(n) if mask[i] == 1)
        max_money = max(max_money, cur_money)

    return max_money
```

#### 复杂度  

- **时间复杂度**：`O(2ⁿ * n)`  
  - `2ⁿ` 是所有可能的组合数，遍历每个组合时要检查相邻冲突（`O(n)`）并求和（`O(n)`），所以整体是指数级的。  
  - 用大白话说，就是**“随着房子数量每增加 1，工作量会翻一番”**，对稍大的输入会很慢。

- **空间复杂度**：`O(n)`  
  - 只用了一个长度为 `n` 的临时数组 `mask`（实际上是元组），其余空间常数级。

### 2. 最优解

#### 思路  

从暴力解可以看到，**“相邻两家不能一起抢”**是唯一的约束。  
如果我们从左到右依次考虑每一栋房子，当前决定是否抢，只和**前面两栋的选择有关**：

- 抢第 `i` 栋房子 → 只能加上抢到第 `i-2` 栋的最大金额（因为 `i-1` 不能抢）。
- 不抢第 `i` 栋房子 → 直接沿用抢到第 `i-1` 栋的最大金额。

这正是**动态规划**的典型形式：  
`dp[i]` 表示抢到第 `i` 栋（下标从 0 开始）时，能够得到的最大金额。  

递推公式：

```
dp[i] = max(dp[i-1],          # 不抢第 i 栋
            dp[i-2] + nums[i])   # 抢第 i 栋
```

边界条件：

- `dp[0] = nums[0]`（只有一栋房子只能抢它）
- `dp[1] = max(nums[0], nums[1])`（两栋只能抢较大的那一栋）

因为每一步只依赖前两步的结果，**我们可以用两个变量滚动保存**，把空间从 `O(n)` 降到 `O(1)`。

> **类比**：想象你在走楼梯，每走一步可以选择跨一步或跨两步，目标是让走过的台阶价值最大。`dp[i]` 就是到达第 `i` 步时的最优价值。

#### 代码（Python）

```python
def rob(nums):
    """
    动态规划：只保留最近两个状态，空间 O(1)
    """
    n = len(nums)
    if n == 0:
        return 0
    if n == 1:
        return nums[0]

    # prev2 对应 dp[i-2]，prev1 对应 dp[i-1]
    prev2 = nums[0]                               # dp[0]
    prev1 = max(nums[0], nums[1])                 # dp[1]

    # 从第 2 栋开始遍历（下标 i = 2）
    for i in range(2, n):
        cur = max(prev1, prev2 + nums[i])         # dp[i] 的递推公式
        # 滚动更新状态
        prev2, prev1 = prev1, cur

    return prev1                                   # 最后得到 dp[n-1]
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 只需要一次线性遍历，每栋房子做常数次计算。用大白话说，就是**“房子有多少，就做多少步”**，非常快。

- **空间复杂度**：`O(1)`  
  - 只用了两个整数变量来记录前两步的结果，和房子数量无关。相较于暴力解的指数空间，这几乎可以忽略不计。

## 心得

- **核心技巧**：**动态规划**——把“大问题”拆解成“子问题”，用 `dp[i] = max(不选, 选)` 的形式递推。
- **适用的题型**  
  1. **最长不相邻子序列**（如“打家劫舍 II”在环形街道的变形）。  
  2. **最大子集和且元素不相邻**（如“最大不相交子集和”）。  
  3. **步数或费用类 DP**（如“爬楼梯”）。
- **一句话总结解题钥匙**：**“每一步只关心前两步的最优值”**。

## 反思

- **第一反应**：看到“相邻不能一起”，马上想到“选或不选”两种状态，想到可以用递归或 DP 来记录选择的收益。
- **最容易踩的坑**  
  - 边界条件处理不全：`n=1`、`n=2` 时递推公式会越界。  
  - 忘记把 `dp[i-2]` 的值在 `i=2` 时初始化好，导致错误的加法。  
  - 题目要求返回 **最大** 金额，而不是所有合法方案的集合，需要记得取 `max`。
- **下次遇到同类题**：**第一步先写出递推关系**，确认只依赖前几步，然后决定是否需要压缩空间。这样可以快速从“枚举”跳到“DP”。
