# #1758. **使二进制字符串交替的最少更改次数** / Minimum Changes To Make Alternating Binary String

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/minimum-changes-to-make-alternating-binary-string/)

---

## 题目（英文原版）

**Description**

You are given a string s consisting only of the characters '0' and '1'. In one operation, you can change any '0' to '1' or vice versa.
The string is called alternating if no two adjacent characters are equal. For example, the string "010" is alternating, while the string "0100" is not.
Return the minimum number of operations needed to make s alternating.

**Examples**

**Example 1:**

```
Input: s = "0100"
Output: 1
Explanation: If you change the last character to '1', s will be "0101", which is alternating.
```

**Example 2:**

```
Input: s = "10"
Output: 0
Explanation: s is already alternating.
```

**Example 3:**

```
Input: s = "1111"
Output: 2
Explanation: You need two operations to reach "0101" or "1010".
```

**Constraints**

- 1 <= s.length <= 104
- s[i] is either '0' or '1'.

---

## 题目（中文翻译）

给定仅由字符 `'0'` 和 `'1'` 组成的字符串 `s`。一次操作（operation）可以将任意 `'0'` 改为 `'1'`，或将 `'1'` 改为 `'0'`。  

如果相邻的两个字符不相等，则称该字符串为交替的（alternating）。例如字符串 `"010"` 是交替的，而 `"0100"` 则不是。  

返回使 `s` 变为交替的最少操作次数。

---

### 示例

**示例 1**  
**输入**: `s = "0100"`  
**输出**: `1`  
**解释**: 将最后一个字符改为 `'1'`，得到 `"0101"`，此时字符串交替。

**示例 2**  
**输入**: `s = "10"`  
**输出**: `0`  
**解释**: `s` 已经是交替的。

**示例 3**  
**输入**: `s = "1111"`  
**输出**: `2`  
**解释**: 需要两次操作才能得到 `"0101"` 或 `"1010"`。

---

### 约束条件

- `1 <= s.length <= 10^4`
- `s[i]` 只能是 `'0'` 或 `'1'`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**先把目标字符串的两种可能写出来**，然后把原字符串和这两个目标一位一位比较，看看需要改几次。  

- **目标一**：以 `'0'` 开头的交替串 → `"010101…"`.  
- **目标二**：以 `'1'` 开头的交替串 → `"101010…"`.  

把这两条“模板”想象成 **字典**：键是下标，值是该位置应该出现的字符。我们只需要遍历一次原字符串，统计与模板不相等的次数即可。  

为什么这样一定能得到最少操作数？  
因为交替字符串的定义只有两种可能（长度固定时），不管怎么改，都必须最终变成这两种之一。我们分别计算把原串改成这两种的代价，取最小的那个，就是答案。

#### 代码（Python）

```python
def minChanges(s: str) -> int:
    """
    暴力（直觉）解法：分别和两种交替模式比较，统计不同的字符数。
    """
    n = len(s)
    # 目标模式 1: 0,1,0,1,...
    # 目标模式 2: 1,0,1,0,...
    diff_start_with_0 = 0   # 与 "0101..." 的不相等计数
    diff_start_with_1 = 0   # 与 "1010..." 的不相等计数

    for i, ch in enumerate(s):
        # i 为偶数时，模式 1 需要 '0'，模式 2 需要 '1'
        # i 为奇数时，模式 1 需要 '1'，模式 2 需要 '0'
        expected0 = '0' if i % 2 == 0 else '1'   # 模式 1 的期望字符
        expected1 = '1' if i % 2 == 0 else '0'   # 模式 2 的期望字符

        if ch != expected0:
            diff_start_with_0 += 1   # 需要改动一次
        if ch != expected1:
            diff_start_with_1 += 1   # 需要改动一次

    # 两种方案取最小值即为答案
    return min(diff_start_with_0, diff_start_with_1)
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  只遍历一次字符串，`n` 是字符串长度。这里的 `O(n)` 可以理解为“随字符串长度线性增长”，比如长度是 10 时会检查 10 次，长度是 1000 时会检查 1000 次。

- **空间复杂度**：`O(1)`  
  只用常数个整数变量来计数，和输入大小无关。

---

### 2. 最优解

#### 思路  

从上面的“暴力”解法可以看到，真正的瓶颈并不是时间——我们已经是 `O(n)` 了。  
但如果把 “生成两个完整的目标字符串” 这一步也算进去，会产生额外的 **O(n)** 空间开销（保存两个模板）。我们可以进一步 **省掉这两个模板**，直接在遍历时根据下标判断期望字符，这样只用常数空间。

优化步骤：

1. **不显式构造目标串**：下标 `i` 为偶数时，模式 1 期望 `'0'`、模式 2 期望 `'1'`；下标为奇数时相反。利用 `i % 2` 的奇偶性即可得到期望字符。
2. **一次遍历同步统计**：在同一次循环里，同时统计两种模式的不同字符数。
3. **返回最小值**：遍历结束后，直接取两种计数的最小值。

这一步的核心是 **“利用下标奇偶性直接得到期望字符”**，不需要额外的数据结构，就像在字典里查找时，键（下标）已经告诉我们该找哪个页码。

#### 代码（Python）

```python
def minChanges(s: str) -> int:
    """
    最优解：在一次遍历中直接根据下标奇偶性判断期望字符，省掉额外空间。
    """
    diff0, diff1 = 0, 0          # 分别记录两种模式的修改次数

    for i, ch in enumerate(s):
        # i % 2 == 0 -> 偶数位, i % 2 == 1 -> 奇数位
        # 模式 A (以 0 开头) 的期望字符
        expect_a = '0' if i % 2 == 0 else '1'
        # 模式 B (以 1 开头) 的期望字符
        expect_b = '1' if i % 2 == 0 else '0'

        if ch != expect_a:
            diff0 += 1          # 需要把当前字符改成模式 A 的字符
        if ch != expect_b:
            diff1 += 1          # 需要把当前字符改成模式 B 的字符

    return min(diff0, diff1)
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  与暴力解相同，只是常数因子更小，因为没有额外的字符串拼接或复制。

- **空间复杂度**：`O(1)`  
  只使用了四个整数变量，真正做到了**常数空间**。相较于暴力解省掉了保存两条完整模板所需的 `O(n)` 空间。

## 心得

- **核心技巧**：交替二进制串只有两种可能，用下标奇偶性直接判断期望字符并一次遍历统计差异。
- **适用场景**：  
  1. “把字符串变成某种固定模式” 的最小修改次数（如 `0101…`、`111…000…` 等）。  
  2. “判断两个字符串相似度” 时，只需要逐位比较并统计不匹配次数（如汉明距离）。  
  3. “判断数组是否满足交替或周期性模式” 的问题（如交替升降序列）。
- **一句话总结**：**只要列出所有合法目标，逐位比较并取最小即可**。

---

## 反思

- **第一反应**：先把目标交替串写出来，想到“枚举两种起始方式”。
- **最容易踩的坑**：  
  - 忘记两种起始方式都要考虑，单独只检查 `0101…` 会漏掉 `1010…`。  
  - 边界条件：长度为 1 时，两种模式其实是同一个字符，仍然要返回 `0`。  
- **下次思路**：遇到“把序列改成某种固定模式”的题，第一步立刻写出**所有合法目标**（通常很少），再**逐位比较**，这几乎总是最直接且最优的做法。
