# #1784. 检查二进制字符串是否最多只有一个连续的 1 段 / Check if Binary String Has at Most One Segment of Ones

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/check-if-binary-string-has-at-most-one-segment-of-ones/)

---

## 题目（英文原版）

**Description**

Given a binary string s ​​​​​without leading zeros, return true​​​ if s contains at most one contiguous segment of ones. Otherwise, return false.

**Examples**

**Example 1:**

```
Input: s = "1001"
Output: false
Explanation: The ones do not form a contiguous segment.
```

**Example 2:**

```
Input: s = "110"
Output: true
```

**Constraints**

- 1 <= s.length <= 100
- s[i]​​​​ is either '0' or '1'.
- s[0] is '1'.

---

## 题目（中文翻译）

给定一个不含前导零的二进制字符串（binary string）`s`，如果 `s` 至多包含一个连续段（contiguous segment）的 `1`，则返回 `true`；否则返回 `false`。

**示例 1**  
输入: `s = "1001"`  
输出: `false`  
解释: `1` 不构成连续段。

**示例 2**  
输入: `s = "110"`  
输出: `true`

**约束条件**  
- `1 <= s.length <= 100`  
- `s[i]` 为 `'0'` 或 `'1'`。  
- `s[0]` 为 `'1'`。

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是：**把字符串里每一个 `'1'` 当成小石子，看看这些石子能否全部放进同一个连续的盒子里**。  
如果石子被 `0` 隔开了两次以上，就说明有不止一个连续的 `1` 段，答案为 `False`。  

实现上可以把每个字符都和它左边的字符比较：

1. 先准备一个计数器 `segments`，记录出现了多少个 “`1` 段”。  
2. 从左到右遍历字符串 `s`，当遇到 `s[i] == '1'` 且 `i == 0` 或者 `s[i-1] == '0'` 时，说明我们刚进入了一个新的 `1` 段，`segments += 1`。  
3. 遍历结束后，只要 `segments <= 1` 就返回 `True`，否则返回 `False`。  

> **数据结构类比**：这里的计数器就像在记录“章节数”。每当我们看到新章节的标题（即 `'1'` 前面是 `'0'` 或是字符串开头），就把章节数加一。  

这个方法一定能得到正确答案，因为我们把所有可能的 `1` 段都枚举了一遍，没漏也没多算。

> **为什么是“暴力”**：我们没有任何提前退出的技巧，整条字符串都要走一遍，哪怕已经发现已经有两个 `1` 段了才继续遍历。  

#### 代码（Python）

```python
def check_one_segment_bruteforce(s: str) -> bool:
    """
    暴力实现：完整遍历字符串，统计出现了多少个连续的 1 段。
    """
    segments = 0                     # 记录 1 段的个数
    n = len(s)

    for i in range(n):
        # 当当前位置是 '1' 且（是开头或左边是 '0'）时，说明进入了一个新段
        if s[i] == '1' and (i == 0 or s[i - 1] == '0'):
            segments += 1            # 段数加一
        # 没有提前退出，整条字符串都会遍历完

    # 最多只有一段 1，返回 True；否则返回 False
    return segments <= 1
```

#### 复杂度  

- **时间复杂度：** `O(n)`  
  - 这里的 `n` 是字符串长度。我们需要检查每个字符一次，实际运行时间会随 `n` 线性增长。  
  - 用大白话说：如果字符串长 10，就要看 10 次；长 100，就要看 100 次。  

- **空间复杂度：** `O(1)`  
  - 只用了几个整数变量（计数器和下标），不随输入大小增加额外的内存。

### 2. 最优解  

#### 思路  

从暴力解可以看到，**瓶颈在于我们始终遍历完整个字符串**，即使已经发现了两个 `1` 段，后面的字符已经不再影响答案。  
优化思路如下：

1. **提前退出**：只要 `segments` 已经等于 2，就可以立即返回 `False`，不必继续检查后面的字符。  
2. **一次遍历即可**：仍然用同样的“看左邻是否为 `0`”的规则，只是加上了 “如果已经出现两个段就直接结束”。  

这样我们仍然只需要 `O(n)` 的时间，但在最坏情况下仍然是线性；在多数实际输入（比如很早就出现两个段）时会更快。  

> **核心技巧**：**“一次遍历 + 计数 + 及时返回”**。  
> 类比：在阅读一本书时，如果已经发现两次章节标题出现错误，就可以立刻认定这本书有问题，不必把整本书读完。  

#### 代码（Python）

```python
def check_one_segment_optimal(s: str) -> bool:
    """
    最优实现：在遍历过程中，一旦发现第二段 1，就立即返回 False。
    """
    segments = 0                     # 记录已经看到的 1 段数
    n = len(s)

    for i in range(n):
        if s[i] == '1' and (i == 0 or s[i - 1] == '0'):
            segments += 1            # 进入新段
            if segments > 1:         # 已经超过一段，答案必定是 False
                return False

    # 循环结束后，segments 只可能是 0 或 1，满足题意
    return True
```

#### 复杂度  

- **时间复杂度：** `O(n)`（最坏情况）  
  - 与暴力解相同的量级，但因为**提前返回**，在出现两个段的早期就可以结束，实际运行时间通常更短。  

- **空间复杂度：** `O(1)`  
  - 仍然只使用常数级别的额外变量。

## 心得  

- **核心技巧**：一次遍历统计连续段数并在必要时提前返回。  
- **适用的题型**：  
  1. 判断字符串/数组中是否只有一种模式出现（如“仅出现一次的 0/1 段”）。  
  2. 检查数组是否已经排序好，出现第一个逆序即返回 `False`。  
  3. 判断数字序列是否只出现一次峰值（单调递增后递减）。  
- **一句话总结**：**“只要能在遍历中实时判断出答案，就不要等遍历结束”**。  

## 反思  

- **第一反应**：看到“最多一个连续的 1 段”，自然想到“数数有多少段”。  
- **最容易踩的坑**：  
  - 忘记把字符串开头也算作一个段（`i == 0` 的特殊处理）。  
  - 忽略了题目保证首字符是 `'1'`，但如果忘记这点，代码仍需兼容 `s[0] == '0'` 的情况。  
- **下次第一步**：先**明确什么是“段”**（即相邻字符相同的连续子串），再决定**用计数器遍历一次**来统计段的数量。
