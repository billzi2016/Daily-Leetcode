# #1922. 计数好数字 / Count Good Numbers

> 难度：中等 · 标签：Math、Recursion · [LeetCode 链接](https://leetcode.com/problems/count-good-numbers/)

---

## 题目（英文原版）

**Description**

A digit string is good if the digits (0-indexed) at even indices are even and the digits at odd indices are prime (2, 3, 5, or 7).
Given an integer n, return the total number of good digit strings of length n. Since the answer may be large, return it modulo 109 + 7.
A digit string is a string consisting of digits 0 through 9 that may contain leading zeros.

**Examples**

**Example 1:**

```
Input: n = 1
Output: 5
Explanation: The good numbers of length 1 are "0", "2", "4", "6", "8".
```

**Example 2:**

```
Input: n = 4
Output: 400
```

**Example 3:**

```
Input: n = 50
Output: 564908303
```

**Constraints**

- 1 <= n <= 1015

## 题目（中文翻译）

一个数字字符串如果满足以下条件则称为「好」：在偶数索引（0 起始）的位上的数字是偶数，在奇数索引的位上的数字是质数（2、3、5、7）。  
给定整数 `n`，返回长度为 `n` 的好数字字符串的总数。由于答案可能很大，请返回其对 `10^9 + 7` 取模后的结果。  
数字字符串是由字符 `'0'` 到 `'9'` 组成的字符串，允许出现前导零。

**示例 1**  
**输入**: `n = 1`  
**输出**: `5`  
**解释**: 长度为 1 的好数字有 `"0"`, `"2"`, `"4"`, `"6"`, `"8"`。

**示例 2**  
**输入**: `n = 4`  
**输出**: `400`

**示例 3**  
**输入**: `n = 50`  
**输出**: `564908303`

**约束条件**  
- `1 <= n <= 1015`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：把所有可能的长度为 `n` 的数字串全部枚举出来，逐个检查它们是否满足“偶数下标位是偶数，奇数下标位是质数 (2、3、5、7)”的规则，然后把符合条件的计数累加。

- **使用的数据结构**  
  - **列表/字符串**：把每一次枚举得到的数字串保存为字符串，方便逐字符检查。可以把它想象成我们把所有可能的密码本（每本 10ⁿ 页）都翻一遍，看看哪几页符合要求。  
  - **计数器**：用一个整数 `ans` 来累计符合条件的数量，就像我们在纸上记“符合的有多少页”。

- **为什么正确**  
  枚举了 **所有** 长度为 `n` 的数字串（包括前导零），没有漏掉任何一种可能；检查过程严格按照题目要求判断每一位是否符合条件，所以最后得到的计数必然是正确的。

- **复杂度分析（大白话）**  
  - **时间**：每一条数字串有 `n` 位，需要检查 `n` 次；而数字串的总数是 `10ⁿ`（因为每一位可以是 0~9 中的任意一个）。于是总体时间是 `10ⁿ × n`，用大 O 表示就是 **O(10ⁿ·n)**。  
    这里的 `O(10ⁿ·n)` 可以理解为“随着 `n` 增大，运算次数会像 10 的 n 次方一样疯狂增长”，即使 `n=10`，也已经是 10 000 000 000 次检查，根本跑不完。
  - **空间**：只需要保存一个计数器和当前枚举的字符串，空间是 **O(n)**（保存一条长度为 n 的字符串），几乎可以忽略不计。

> **结论**：暴力法思路很清晰，但因为搜索空间是指数级的，根本不适合 `n` 甚至达到 10⁵、10¹⁵ 的情况。

#### 代码（Python）

```python
def countGoodNumbers_bruteforce(n: int) -> int:
    # 0~9 共 10 个数字，使用递归枚举所有长度为 n 的字符串
    digits = [str(i) for i in range(10)]
    ans = 0                         # 计数器

    def dfs(pos: int, cur: list):
        """深度优先搜索，pos 表示当前已经填到第几位（0-indexed）"""
        nonlocal ans
        if pos == n:                # 已经填满 n 位，检查合法性
            # 检查每一位是否满足要求
            for i, ch in enumerate(cur):
                d = int(ch)
                if i % 2 == 0:      # 偶数下标，需要是偶数
                    if d % 2 != 0:
                        return
                else:               # 奇数下标，需要是质数 2,3,5,7
                    if d not in (2, 3, 5, 7):
                        return
            ans += 1                 # 全部检查通过，计数加一
            return

        # 继续枚举下一位
        for d in digits:
            cur.append(d)           # 把一个数字放到当前位置
            dfs(pos + 1, cur)       # 递归进入下一层
            cur.pop()               # 恢复现场，尝试下一个数字

    dfs(0, [])
    return ans
```

> 这段代码只适合 **非常小** 的 `n`（比如 `n ≤ 4`），否则会因为 `10ⁿ` 的枚举而卡死。

#### 复杂度

- **时间复杂度**：`O(10ⁿ·n)` —— 随着 `n` 增大，运行时间会呈指数级爆炸，实际上不可用。
- **空间复杂度**：`O(n)` —— 递归栈深度和当前构造的字符串长度。

### 2. 最优解

#### 思路  

从暴力解可以看到，**每一位的合法取值是相互独立的**，也就是说第 `i` 位的选择并不影响第 `j` 位（`i ≠ j`）的合法性。只要我们知道每种下标对应的合法数字有多少种，就可以直接用乘法原理算出总数。

1. **统计每种下标的合法数字个数**  
   - 偶数下标（0、2、4、…）：必须是偶数 → `{0,2,4,6,8}`，**5 种**。  
   - 奇数下标（1、3、5、…）：必须是质数 2、3、5、7 → **4 种**。

2. **把 `n` 分成两部分**  
   - 偶数下标的个数 = `ceil(n / 2)`（因为第 0 位一定是偶数下标）。  
   - 奇数下标的个数 = `floor(n / 2)`。

3. **直接乘**  
   总的好数字串数目 = `5^{ceil(n/2)} * 4^{floor(n/2)}`。  
   这一步就像我们有 5 种颜色的红球要放到偶数格子，有 4 种颜色的蓝球要放到奇数格子，所有格子互不干扰，整体组合数就是两者的乘积。

4. **模运算 & 快速幂**  
   题目要求对 `10⁹+7` 取模。直接用 Python 的 `pow(base, exp, mod)` 就可以做到 **二进制快速幂**，时间是 `O(log exp)`。  
   - **二进制快速幂的直观类比**：把大数字的指数拆成二进制位（比如 13 = 1101₂），只需要把底数平方若干次并在对应的“1 位”时相乘，就能在对数时间内算出结果。

5. **边界**  
   - `n` 最大可达 `10¹⁵`，远远超过普通循环的可接受范围，唯一可行的办法就是 **对指数做对数级别的运算**（即快速幂）。

#### 代码（Python）

```python
MOD = 10 ** 9 + 7          # 题目要求的模数

def countGoodNumbers(n: int) -> int:
    """
    计算长度为 n 的好数字串个数，返回值对 1e9+7 取模。
    思路：每个偶数下标有 5 种可能，每个奇数下标有 4 种可能，
          结果 = 5^{ceil(n/2)} * 4^{floor(n/2)} (mod MOD)。
    """
    # 计算偶数下标的个数和奇数下标的个数
    even_cnt = (n + 1) // 2   # ceil(n/2)  // Python 整除向下取整，先加 1 再除 2
    odd_cnt  = n // 2         # floor(n/2)

    # 快速幂：pow(base, exp, mod) 在 Python 中已经实现了二进制指数算法
    part_even = pow(5, even_cnt, MOD)   # 5^{even_cnt} % MOD
    part_odd  = pow(4, odd_cnt, MOD)    # 4^{odd_cnt} % MOD

    # 乘法仍然要取模，防止中间结果溢出
    ans = (part_even * part_odd) % MOD
    return ans
```

**关键行解释**  

- `even_cnt = (n + 1) // 2`：把 `n` 向上取整除以 2，得到偶数下标的个数。比如 `n=5` → `(5+1)//2 = 3`（下标 0、2、4）。  
- `pow(5, even_cnt, MOD)`：Python 内置的 **模幂** 函数，底数 5、指数 `even_cnt`，结果自动对 `MOD` 取模，内部实现了二进制快速幂，时间复杂度是 `O(log even_cnt)`。  
- `ans = (part_even * part_odd) % MOD`：先把两部分分别取模，再乘起来后再取模，确保结果始终在整数范围内。

#### 复杂度

- **时间复杂度**：`O(log n)` —— 只做了两次模幂运算，每次的循环次数与指数的二进制位数成正比（约 `log₂ n`），即使 `n=10¹⁵` 也只需要不到 50 次乘法。相比暴力的指数级时间，快了 **天壤之别**。  
- **空间复杂度**：`O(1)` —— 只用了常数个整数变量，和 `n` 的大小无关。

## 心得

- **核心技巧**：**把每一位的选择独立出来，用乘法原理计数 + 快速幂（模幂）**。  
- **适用的题型**  
  1. “统计满足某种每位独立限制的数字串”——如 **“Count Binary Substrings with No Consecutive 1s”**（每位只能是 0 或 1，但不能相邻为 1）。  
  2. “计数满足位置约束的排列”——如 **“Number of Ways to Paint the Fence”**（每根栅栏颜色受前一根影响，但可以转化为指数形式）。  
  3. “大指数取模”——如 **“Super Pow”**（快速幂 + 余数循环）。  
- **一句话总结**：**“先把问题拆成每位独立的计数，再用快速幂把指数压到对数级”**。

## 反思

- **第一反应**：看到“偶数下标必须是偶数，奇数下标必须是质数”，本能想把所有可能枚举出来检验。  
- **最容易踩的坑**  
  1. **忘记取模**：直接算 `5^{...} * 4^{...}` 会导致整数爆炸，必须在每一步都取 `% MOD`。  
  2. **下标计数错误**：`ceil` 与 `floor` 容易写反，导致偶数位和奇数位的次数对调。  
  3. **指数过大**：`n` 可达 `10¹⁵`，如果用普通循环乘幂会超时，必须使用二进制快速幂。  
- **下次遇到同类题**：**第一步先判断每一位是否相互独立**；**若独立，则直接用乘法原理算出“基数的幂”**，随后**用快速幂** 处理大指数并做好模运算。
