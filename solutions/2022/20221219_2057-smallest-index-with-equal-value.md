# #2057. 等值最小索引 / Smallest Index With Equal Value

> 难度：简单 · 标签：Array · [LeetCode 链接](https://leetcode.com/problems/smallest-index-with-equal-value/)

---

## 题目（英文原版）

**Description**

Given a 0-indexed integer array nums, return the smallest index i of nums such that i mod 10 == nums[i], or -1 if such index does not exist.
x mod y denotes the remainder when x is divided by y.

**Examples**

**Example 1:**

```
Input: nums = [0,1,2]
Output: 0
Explanation: 
i=0: 0 mod 10 = 0 == nums[0].
i=1: 1 mod 10 = 1 == nums[1].
i=2: 2 mod 10 = 2 == nums[2].
All indices have i mod 10 == nums[i], so we return the smallest index 0.
```

**Example 2:**

```
Input: nums = [4,3,2,1]
Output: 2
Explanation: 
i=0: 0 mod 10 = 0 != nums[0].
i=1: 1 mod 10 = 1 != nums[1].
i=2: 2 mod 10 = 2 == nums[2].
i=3: 3 mod 10 = 3 != nums[3].
2 is the only index which has i mod 10 == nums[i].
```

**Example 3:**

```
Input: nums = [1,2,3,4,5,6,7,8,9,0]
Output: -1
Explanation: No index satisfies i mod 10 == nums[i].
```

**Constraints**

- 1 <= nums.length <= 100
- 0 <= nums[i] <= 9

## 题目（中文翻译）

**题目描述**  
给定一个下标从 0 开始的整数数组 `nums`，返回满足 `i mod 10 == nums[i]` 的最小下标 `i`，如果不存在这样的下标则返回 `-1`。  
`x mod y` 表示 `x` 除以 `y` 的余数。

**示例**  

**示例 1**  
输入: `nums = [0,1,2]`  
输出: `0`  
解释:  
- `i=0: 0 mod 10 = 0 == nums[0]`。  
- `i=1: 1 mod 10 = 1 == nums[1]`。  
- `i=2: 2 mod 10 = 2 == nums[2]`。  
所有下标均满足 `i mod 10 == nums[i]`，因此返回最小的下标 `0`。

**示例 2**  
输入: `nums = [4,3,2,1]`  
输出: `2`  
解释:  
- `i=0: 0 mod 10 = 0 != nums[0]`。  
- `i=1: 1 mod 10 = 1 != nums[1]`。  
- `i=2: 2 mod 10 = 2 == nums[2]`。  
- `i=3: 3 mod 10 = 3 != nums[3]`。  
下标 `2` 是唯一满足 `i mod 10 == nums[i]` 的位置。

**示例 3**  
输入: `nums = [1,2,3,4,5,6,7,8,9,0]`  
输出: `-1`  
解释: 没有任何下标满足 `i mod 10 == nums[i]`。

**约束条件**  
- `1 <= nums.length <= 100`  
- `0 <= nums[i] <= 9`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是 **从左到右逐个检查** 每个下标 `i` 是否满足  

```
i mod 10 == nums[i]
```

- **使用的结构**：普通的 Python 列表 `nums`，只需要顺序遍历它。可以把遍历想象成 **排队检查**，每个人（下标）依次上来让老师（我们）检查是否符合要求，第一位合格的就是答案。
- **正确性**：因为我们是从最小的下标开始检查的，一旦找到满足条件的 `i`，必然是所有符合条件的下标中最小的。若遍历完都没有找到，则说明不存在这样的位置，返回 `-1`。
- **时间/空间复杂度**：  
  - **时间**：我们最多要看一遍数组，最多检查 `n` 次（`n = len(nums)`），所以是 **O(n)**。这里的 `O(n)` 可以理解为“随数组长度线性增长”，比如数组长度是 10，检查 10 次；长度是 100，检查 100 次，耗时大概是长度的常数倍。  
  - **空间**：只用了常数个额外变量（下标 `i`、返回值），不随 `n` 增长，故是 **O(1)**。

#### 代码（Python）

```python
def smallestEqual(nums):
    """
    暴力线性扫描
    :param nums: List[int]，长度 1~100，元素值 0~9
    :return: int，满足 i % 10 == nums[i] 的最小下标，若不存在返回 -1
    """
    for i in range(len(nums)):               # 从下标 0 开始逐个检查
        if i % 10 == nums[i]:                # i % 10 等价于 i 除以 10 的余数
            return i                         # 第一个符合条件的下标直接返回
    return -1                                # 循环结束仍未找到，返回 -1
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 随着数组长度线性增加检查次数。  
- **空间复杂度**：`O(1)` — 只使用了几个额外的整数变量。

---

### 2. 最优解

#### 思路  

对于本题，**暴力解已经是最优** 的了，因为我们只需要一次遍历就能得到答案，无法再把时间降到 `O(log n)` 或 `O(1)`（除非提前知道答案）。这里的“最优”指的就是 **一次线性扫描**，但我们可以把思路写得更“结构化”，帮助以后遇到类似“找满足某个条件的最小下标” 的题目时快速定位：

1. **明确搜索方向**：因为要求最小的下标，搜索只能从左向右进行，不能跳过前面的元素。  
2. **一次遍历即可**：只要遍历到当前下标 `i`，立刻判断 `i % 10` 与 `nums[i]` 是否相等，满足即返回。  
3. **提前结束**：一旦找到答案就立刻返回，避免不必要的后续检查。

**核心概念**：**线性扫描**（Linear Scan）——一种最基本、最直观的遍历技巧，适用于“找第一个满足条件的元素”。可以把它类比为在一本书的目录里 **从第一页往后翻**，一旦看到符合要求的章节，就停下来。

#### 代码（Python）

```python
def smallestEqual(nums):
    """
    最优解：一次线性扫描即可得到答案
    """
    n = len(nums)
    i = 0
    while i < n:                 # 用 while 写法，逻辑完全等价于 for
        if i % 10 == nums[i]:    # 检查当前下标是否满足条件
            return i
        i += 1                   # 不满足则继续检查下一个下标
    return -1                    # 全部检查完仍未找到，返回 -1
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 与暴力解相同，最坏情况下仍需检查每个元素一次。  
- **空间复杂度**：`O(1)` — 只使用了几个整数变量。

## 心得

- **核心技巧**：一次线性扫描找第一个满足条件的下标。  
- **适用题型**：  
  1. “找数组中第一个大于/小于某值的下标”。  
  2. “在字符串中找第一个出现指定字符的位置”。  
  3. “寻找满足特定余数关系的最小下标”（本题）。  
- **一句话总结**：**从左到右逐个检查，一旦符合立刻返回，即是最小下标**。

## 反思

- **第一反应**：看到 “i mod 10 == nums[i]”，立刻想到逐个验证，因为数组长度只有 100，暴力遍历毫无压力。  
- **最容易踩的坑**：  
  - 忘记 `i % 10` 而误写成 `i / 10`（整数除法），导致结果错误。  
  - 没有在找到答案后立即 `return`，继续遍历导致返回的不是最小下标。  
  - 忽视题目要求的 “-1” 返回值，直接返回 `None` 会导致答案不匹配。  
- **下次思路**：遇到“找满足某种关系的最小下标”时，第一步就想 **线性扫描 + 立即返回**，确认是否还有可以利用的单调性或二分搜索的可能（如果数组已排序或关系单调）。如果没有，线性扫描就是最安全、最简洁的方案。
