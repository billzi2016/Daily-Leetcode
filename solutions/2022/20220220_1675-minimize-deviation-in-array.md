## 题目（英文原版）

**Description**

You are given an array nums of n positive integers.
You can perform two types of operations on any element of the array any number of times:
The deviation of the array is the maximum difference between any two elements in the array.
Return the minimum deviation the array can have after performing some number of operations.

**Examples**

**Example 1:**

```
Input: nums = [1,2,3,4]
Output: 1
Explanation: You can transform the array to [1,2,3,2], then to [2,2,3,2], then the deviation will be 3 - 2 = 1.
```

**Example 2:**

```
Input: nums = [4,1,5,20,3]
Output: 3
Explanation: You can transform the array after two operations to [4,2,5,5,3], then the deviation will be 5 - 2 = 3.
```

**Example 3:**

```
Input: nums = [2,10,8]
Output: 3
```

**Constraints**

- n == nums.length
- 2 <= n <= 5 * 104
- 1 <= nums[i] <= 109

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把每个数都枚举所有可能的变化**，然后在每一种组合下计算数组的偏差（最大值‑最小值），最后取最小的那个。  

- **每个数的变化**：题目只允许两种操作  
  1. **如果是偶数**，可以除以 2（一直除到变成奇数）。  
  2. **如果是奇数**，可以乘以 2（可以无限次乘，只要不超过题目设定的上限）。  
  为了穷举，我们可以先把每个数 **预处理** 成所有可能出现的值的集合，例如 `4 → {4,2,1}`，`5 → {5,10,20,…}`（只要不超过题目给出的最大数 10⁹）。  

- **枚举所有组合**：把每个位置的取值看成一个维度，所有维度的笛卡尔积就是所有可能的数组状态。遍历这些状态，计算偏差，取最小值。

**为什么这个方法正确？**  
因为我们把每个数的所有合法取值都列举出来了，遍历所有组合就一定会包含最终最优的那个数组。因此最小的偏差一定会被找到。

**时间/空间复杂度**  
- 假设第 `i` 个数有 `k_i` 种取值，那么总的组合数是 `k_1 * k_2 * … * k_n`，呈指数级增长。即使每个数只有 10 种取值，`n` 为 10⁴ 时也根本不可能遍历完。  
- 空间上我们需要保存每个数的取值集合，同样是 `O(∑k_i)`，在最坏情况下也很大。

用大白话说，**暴力法相当于把所有可能的水果拼盘全部做一遍再挑最好的，水果种类多、拼盘数目多时根本做不完**。

#### 代码（Python）

```python
from itertools import product
from typing import List

def min_deviation_bruteforce(nums: List[int]) -> int:
    # 1. 为每个数生成所有可能的取值（这里只是演示，实际会爆炸）
    all_vals = []
    for x in nums:
        cur = set()
        # 先把所有能除到奇数的值加入
        while x % 2 == 0:
            cur.add(x)
            x //= 2
        cur.add(x)                     # 最终的奇数
        # 再把奇数不断 *2，直到超过原始最大值的上界（这里随便设个 2*10^9）
        y = x
        while y <= 2_000_000_000:
            cur.add(y)
            y *= 2
        all_vals.append(sorted(cur))

    # 2. 枚举所有组合（仅用于极小规模演示）
    best = float('inf')
    for combo in product(*all_vals):
        deviation = max(combo) - min(combo)
        best = min(best, deviation)
    return best
```

> 这段代码只能在 `len(nums) ≤ 5`、每个数的取值很少时跑得通，真正的测试数据会直接卡死。

#### 复杂度

- **时间复杂度**：`O(k_1 * k_2 * … * k_n)`（指数级），实际会因为组合数爆炸而不可接受。  
- **空间复杂度**：`O(∑k_i)`，用于保存每个数的所有可能取值。

### 2. 最优解

#### 思路  

暴力法的瓶颈在于**“同时枚举所有数的取值”**，导致组合爆炸。观察题目可以发现：

1. **所有数的取值范围是单调的**  
   - 偶数只能 **除以 2**（向下），直到变成奇数。  
   - 奇数只能 **乘以 2**（向上），可以一直乘，只要不超过某个上限。  
   于是每个数的取值序列是 **单调递增**（奇数）或 **单调递减**（偶数），而且**每个数的最小值一定是奇数**（因为偶数可以一直除到奇数）。

2. **把每个数先变成最小可能的值**（即全部除尽得到奇数），此时我们只能 **把某些数乘以 2**（把最小的数往上提升），**不能把已经是最大值的数再往上**，因为那样只会让偏差更大。

3. **当前偏差 = 最大值 - 最小值**。  
   若要继续降低偏差，唯一的操作是 **把当前最小的数乘以 2**（让最小值上升），因为最大值只能通过把最小值提升来间接降低差距。

基于上述观察，我们可以用**最大堆（或相反的最小堆）**来动态维护当前数组的 **最大值**，并用 **有序集合**（或直接把最小值放进堆的另一端）来快速取得 **最小值**。下面的实现采用 **最大堆 + 记录当前最小值** 的技巧：

- **步骤 1**：把所有数先除尽得到奇数，同时把对应的 **可能的最大值**（即把这个奇数不断 *2* 直到不超过原始数的上限）记录下来。  
  为了方便，我们把每个数 **先乘以 2**（如果原来是偶数则已经是最大可能值），这样所有数都变成 **偶数**，随后把它们放入 **最大堆**（Python `heapq` 默认是最小堆，用负数实现最大堆）。

- **步骤 2**：维护一个变量 `cur_min` 保存当前堆中所有数的最小值。初始时 `cur_min` 就是所有奇数中的最小值。

- **步骤 3**：循环：
  1. 取出堆顶（最大值）`max_val`。当前偏差 = `max_val - cur_min`，更新答案 `ans`。
  2. 如果 `max_val` 是 **奇数**，说明已经不能再乘以 2（因为我们只能把偶数除 2），此时退出循环。
  3. 否则，把 `max_val` **除以 2**（相当于把当前最大的数往下调），得到 `new_val`。把 `new_val` 再压回堆，同时更新 `cur_min = min(cur_min, new_val)`。
  4. 重复上述过程，直到堆顶是奇数为止。

为什么这样可以得到最小偏差？  
- 每一次我们**只能把当前最大值往下调**（除 2），这会让最大值下降，可能会使偏差变小。  
- 同时，**最小值只会在除 2 的过程中变小**，因为我们把最大的数除 2 后，新的数可能比原来的最小值更小。于是 `cur_min` 只会变得更小或保持不变。  
- 当堆顶成为奇数时，所有数已经都是 **不可再除 2** 的最小形态（即所有数都是奇数），此时已经没有进一步降低偏差的空间，循环结束。

整个过程只会对每个数进行 **O(log(max_num))** 次除 2 操作，整体复杂度满足题目要求。

> **类比**：把数组看成一堆 **天平砝码**，我们想让最重的砝码和最轻的砝码差距最小。只能把最重的砝码砍半（除 2），每砍一次就重新称量，直到所有砝码都是最轻的那种形态（奇数）为止。

#### 代码（Python）

```python
import heapq
from typing import List

def minimum_deviation(nums: List[int]) -> int:
    """
    最小化数组偏差的最优实现
    思路：
    1. 把所有数先除尽得到奇数，同时把对应的「最大可能值」放入最大堆
    2. 维护当前最小值 cur_min
    3. 循环弹出堆顶（最大值），尝试把它除以 2，更新答案
    """
    max_heap = []          # 用负数实现最大堆
    cur_min = float('inf') # 当前所有数的最小值

    # 步骤 1：标准化每个数，使其成为「偶数」并记录最小值
    for x in nums:
        # ① 把偶数除尽得到奇数
        while x % 2 == 0:
            x //= 2
        # ② 现在 x 是奇数，乘以 2 让它成为「可被除的最大偶数」
        #    这样后面我们只会对它执行「除以 2」的操作
        max_val = x * 2
        heapq.heappush(max_heap, -max_val)   # 放入负数，形成最大堆
        cur_min = min(cur_min, x)            # 记录所有奇数中的最小值

    ans = float('inf')

    # 步骤 2：不断把堆顶（最大值）除以 2，尝试缩小偏差
    while True:
        max_val = -heapq.heappop(max_heap)   # 取出当前最大值
        ans = min(ans, max_val - cur_min)    # 更新最小偏差

        # 如果最大值已经是奇数，说明再也无法除以 2，结束循环
        if max_val % 2 == 1:
            break

        # 否则把最大值除以 2，重新放回堆中
        new_val = max_val // 2
        heapq.heappush(max_heap, -new_val)
        # 更新当前最小值（因为 new_val 可能更小）
        cur_min = min(cur_min, new_val)

    return ans
```

#### 复杂度

- **时间复杂度**：`O(N log M)`  
  - `N` 为数组长度（最多 5×10⁴）。  
  - 每个数最多被除以 2 的次数等于其二进制表示中最高位的下标，即 `log₂(max(nums))`（不超过 30 次，因为 `nums[i] ≤ 10⁹`）。  
  - 每次除 2 都伴随一次堆的 `push/pop`，每次操作是 `O(log N)`，所以整体是 `O(N log M)`，这里的 `M` 代表最大值的二进制位数，实际约为 `O(N log N)`。

- **空间复杂度**：`O(N)`  
  - 需要一个大小为 `N` 的堆来存放当前的数值，以及若干常数级的额外变量。

## 心得

- **核心技巧**：把所有数先统一到「只能向下调」的状态（即偶数），然后利用**最大堆**不断把当前最大值除以 2，配合维护最小值，贪心地压缩偏差。
- **适用的题型**  
  1. 需要在**单调可变**的数列上寻找最小/最大差值的题目（如 “Maximum Frequency Stack”）。  
  2. 需要**动态维护最大值或最小值**并进行单向调整的题目（如 “Find Minimum Possible Sum of Squares”）。  
  3. 结合**堆**与**单调操作**的优化思路（如 “Super Washing Machines”）。
- **一句话总结**：把所有数先“降到最低”，然后只对**当前最大值**向下逼近，利用堆实现贪心压缩即可得到最小偏差。

## 反思

- **第一反应**：看到“可以把偶数除 2、奇数乘 2”，立刻想到把所有数都“标准化”成只能单方向变化的形式。
- **最容易踩的坑**  
  1. **忘记把偶数除尽**：如果直接把原始偶数放进堆，后续会出现“除 2”后仍是偶数，导致无限循环。  
  2. **最小值更新遗漏**：每次把最大值除 2 后，新的值可能比当前最小值更小，必须及时更新 `cur_min`。  
  3. **堆的实现细节**：Python 的 `heapq` 是最小堆，需要取负数来模拟最大堆，容易写错符号。
- **下次类似题的第一步**：先**把所有元素统一到只能单向变化的状态**（比如只能增或只能减），再**用合适的数据结构（堆、单调队列、平衡树）维护当前极值**，通过贪心或二分搜索逐步逼近最优解。
