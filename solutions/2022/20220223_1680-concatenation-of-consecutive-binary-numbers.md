# #1680. 连续二进制数的拼接 / Concatenation of Consecutive Binary Numbers

## 题目（英文原版）

**Description**

Given an integer n, return the decimal value of the binary string formed by concatenating the binary representations of 1 to n in order, modulo 109 + 7.

**Examples**

**Example 1:**

```
Input: n = 1
Output: 1
Explanation: "1" in binary corresponds to the decimal value 1.
```

**Example 2:**

```
Input: n = 3
Output: 27
Explanation: In binary, 1, 2, and 3 corresponds to "1", "10", and "11".
After concatenating them, we have "11011", which corresponds to the decimal value 27.
```

**Example 3:**

```
Input: n = 12
Output: 505379714
Explanation: The concatenation results in "1101110010111011110001001101010111100".
The decimal value of that is 118505380540.
After modulo 109 + 7, the result is 505379714.
```

**Constraints**

- 1 <= n <= 105

## 题目（中文翻译）

给定一个整数 `n`，返回由 `1` 到 `n` 的二进制表示（binary representation）按顺序拼接得到的二进制字符串（binary string）的十进制值，取模 `10^9 + 7`。

**示例 1**  
**输入:** `n = 1`  
**输出:** `1`  
**解释:** 二进制的 `"1"` 对应的十进制值为 1。

**示例 2**  
**输入:** `n = 3`  
**输出:** `27`  
**解释:** 在二进制中，1、2、3 分别对应 `"1"`、`"10"`、`"11"`。  
将它们拼接后得到 `"11011"`，对应的十进制值为 27。

**示例 3**  
**输入:** `n = 12`  
**输出:** `505379714`  
**解释:** 拼接结果为 `"1101110010111011110001001101010111100"`。  
该二进制数的十进制值为 `118505380540`。  
对 `10^9 + 7` 取模后，结果为 `505379714`。

**约束条件**  
- `1 <= n <= 10^5`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：

1. 把 `1 … n` 的每个整数都转成二进制字符串（`bin(i)[2:]`），比如 `5 → "101"`。  
2. 把这些字符串一个接一个拼在一起，得到一个超长的二进制串。  
3. 把这个二进制串再一次性转成十进制整数，最后对 `10^9+7` 取模。

> **类比**：把每个二进制表示想象成一本小册子，把所有小册子按顺序粘在一起，就得到一本“大册子”。我们只需要把“大册子”翻成十进制即可。

这种做法**一定能得到正确答案**，因为我们没有遗漏任何位，也没有改变位的顺序。

但这里有两个隐蔽的坑：

- Python 的字符串是不可变的，`s = s + t` 每一次都会创建一个新字符串，时间会随 `s` 长度线性增长，导致整体 **O(L²)**（`L` 为最终二进制串的长度）。  
- 把超长二进制串一次性转成十进制会占用巨大的内存，甚至会超出 Python 整数的可接受范围（虽然 Python 的大整数可以自动扩展，但会非常慢）。

#### 代码（Python）

```python
def concatenatedBinary_bruteforce(n: int) -> int:
    MOD = 10 ** 9 + 7

    # 1. 把所有二进制字符串拼在一起（会产生大量中间字符串）
    binary_str = ""
    for i in range(1, n + 1):
        binary_str += bin(i)[2:]          # bin(i) 形如 '0b101'，去掉前缀 '0b'

    # 2. 把超长二进制串一次性转成十进制
    result = int(binary_str, 2) % MOD
    return result
```

> 关键行解释  
> - `bin(i)[2:]`：把整数 `i` 转成二进制并去掉前面的 `'0b'` 前缀。  
> - `int(binary_str, 2)`：把二进制字符串一次性解释为十进制整数。  

#### 复杂度

- **时间复杂度**：`O(L²)`，其中 `L` 是所有二进制位的总数（约 `n·log₂n`）。因为每次 `binary_str += …` 都要拷贝已有的字符，导致二次方增长。  
- **空间复杂度**：`O(L)`，需要存放完整的二进制串。  

> **大白话**：如果 `n = 10⁵`，二进制位大约有 1.7 百万，`L²` 级别的操作会让程序跑几分钟甚至更久，明显不可接受。

### 2. 最优解

#### 思路  

从暴力解可以看到，真正的耗时并不是“拼接”二进制本身，而是**不断创建新字符串**和**一次性把巨串转整数**。我们可以把“拼接二进制”改写成**数学运算**：

- 把已经得到的结果记为 `ans`（对应已经拼好的二进制串的十进制值）。  
- 再加入下一个数 `i` 时，只需要把 `ans` 向左移动 `len(i)` 位（相当于在二进制末尾补 `len(i)` 个 0），再把 `i` 加进去。  
- 公式：`ans = ans * 2^{len(i)} + i`，其中 `len(i)` 是 `i` 的二进制位数。

> **类比**：想象 `ans` 是一根已经写好的纸条，左移相当于在纸条右端空出足够的格子，随后把 `i` 的二进制直接写进去。

这一步可以 **一步一步** 进行，而且每一步只涉及常数时间的整数运算（乘法、加法、取模），不需要创建任何大字符串。

关键点：

1. **快速获得二进制位数**：`i.bit_length()` 在 O(1) 时间内返回 `i` 的二进制位数。  
2. **取模**：因为数会非常大，需要在每一步都对 `10⁹+7` 取模，防止溢出。  
3. **预计算 2 的幂**（可选）：`pow(2, k, MOD)` 能在 O(log k) 时间内算出 `2^k mod MOD`，但这里 `k ≤ 17`（因为 `n ≤ 10⁵`），直接使用 `pow` 即可。

这样整体时间是 **O(n)**，空间只需要几个整数 **O(1)**。

#### 代码（Python）

```python
def concatenatedBinary(n: int) -> int:
    MOD = 10 ** 9 + 7          # 题目要求的取模数
    ans = 0                    # 当前已经拼好的二进制对应的十进制值

    for i in range(1, n + 1):
        # 1. 计算 i 的二进制位数，例如 5 -> 3 位 ("101")
        bits = i.bit_length()          # O(1) 操作

        # 2. 把 ans 左移 bits 位，相当于乘以 2**bits
        ans = (ans << bits) % MOD      # 左移相当于 * 2**bits，取模防止溢出

        # 3. 把 i 加到末尾
        ans = (ans + i) % MOD

    return ans
```

> 关键行解释  
> - `i.bit_length()`：直接返回整数 `i` 需要多少位二进制来表示。  
> - `ans << bits`：左移 `bits` 位，相当于 `ans * (2 ** bits)`，在二进制层面实现“拼接”。  
> - 每一步都 `% MOD`，保证数值始终在 64 位整数范围内，避免 Python 大整数带来的额外开销。

#### 复杂度

- **时间复杂度**：`O(n)`，因为循环遍历 `1 … n`，每一步只做常数次整数运算。  
- **空间复杂度**：`O(1)`，只使用了 `ans`、`bits`、`i` 三个变量。

> 与暴力解对比：我们把原本的 `O(L²)`（几乎是 `O(n²·log²n)`）降低到了线性 `O(n)`，运行速度提升几个数量级，轻松通过所有测试。

## 心得

- **核心技巧**：利用左移（乘以 2 的幂）实现“二进制串拼接”，并在每一步取模防止溢出。  
- **适用场景**：  
  1. **把多个数的二进制依次拼接**（本题）。  
  2. **在位运算中累计构造数**（如 LeetCode 1680 “Concatenation of Binary Numbers” 的变体）。  
  3. **把数组视作二进制位流进行哈希**（如滚动哈希、KMP 的位版实现）。  
- **一句话总结**：**左移等价于在二进制末尾“开辟空位”，再把新数写进去，即可在 O(1) 时间完成拼接。**

## 反思

- **第一反应**：直接把所有二进制字符串拼起来再一次性转整数——思路直观但忽略了字符串拼接的成本。  
- **最容易踩的坑**：  
  - 使用 `+` 拼接字符串导致时间爆炸。  
  - 直接 `int(huge_binary, 2)` 会产生巨大的中间整数，内存和时间都不友好。  
  - 忘记在每一步取模，会导致 Python 大整数慢到超时。  
- **下次类似题的第一步**：**先把“拼接”转化为数学公式**（乘以 2 的位数再加），然后检查是否可以在循环中逐步完成并取模。这样既避免大字符串，也保持 O(n) 复杂度。
