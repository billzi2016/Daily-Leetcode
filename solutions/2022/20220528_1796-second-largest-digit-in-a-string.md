# #1796. 字符串中的第二大数字 / Second Largest Digit in a String

> 难度：简单 · 标签：Hash Table、String · [LeetCode 链接](https://leetcode.com/problems/second-largest-digit-in-a-string/)

---

## 题目（英文原版）

**Description**

Given an alphanumeric string s, return the second largest numerical digit that appears in s, or -1 if it does not exist.
An alphanumeric string is a string consisting of lowercase English letters and digits.

**Examples**

**Example 1:**

```
Input: s = "dfa12321afd"
Output: 2
Explanation: The digits that appear in s are [1, 2, 3]. The second largest digit is 2.
```

**Example 2:**

```
Input: s = "abc1111"
Output: -1
Explanation: The digits that appear in s are [1]. There is no second largest digit.
```

**Constraints**

- 1 <= s.length <= 500
- s consists of only lowercase English letters and digits.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法就是把字符串里出现的所有数字全部挑出来，去掉重复的（因为只关心**不同**的数字），然后把它们从大到小排个序，排好序后取第二个元素。如果排好序后只有一个数字或者根本没有数字，就返回 `-1`。

- **用到的数据结构**  
  - **集合（Set）**：可以把它想象成一本“字典”，往里放一个东西，如果已经有了就不会再出现重复，就像查字典时同一个词只能出现一次。这里我们用集合来存放所有出现过的数字字符。  
  - **列表（List）**：把集合里的数字转成列表后可以排序，就像把字典里的词按字母顺序排好，方便取第几名。

- **为什么正确**  
  1. 把所有数字都找出来，确保不漏。  
  2. 用集合去重，保证每个数字只算一次（题目只要不同的数字）。  
  3. 排序后，最大的在最前面，第二大的自然就在第二位。  

- **复杂度分析（大白话）**  
  - **时间复杂度**：`O(n log n)`  
    - 先遍历一次字符串，`n` 是字符串长度，这一步是 `O(n)`。  
    - 把集合转成列表并排序，排序的时间大概是 `n log n`（因为排序本身需要比较很多次），所以总体是 `O(n log n)`。  
    - 用大白话说，就是如果字符串有 1000 个字符，排序大概要花 1000 × log₂1000 ≈ 1000 × 10 = 1 万次比较。  
  - **空间复杂度**：`O(1)`（实际是 `O(10)`）  
    - 最多只会出现 0~9 共十个不同的数字，集合最多存 10 个元素，和字符串长度无关，算作常数空间。

#### 代码（Python）

```python
def secondHighest(s: str) -> int:
    # 1️⃣ 用集合把所有出现过的数字字符收集起来
    digit_set = set()
    for ch in s:
        if ch.isdigit():          # 判断字符是否是数字，类似“检查这个词是否在字典里”
            digit_set.add(ch)    # 加入集合，重复的会自动被过滤掉

    # 2️⃣ 把集合转成列表并按数值大小降序排列
    digits = sorted([int(d) for d in digit_set], reverse=True)

    # 3️⃣ 根据列表长度返回答案
    if len(digits) >= 2:          # 至少有两个不同的数字
        return digits[1]          # 第二大的就在下标 1 位置
    return -1                     # 不满足条件，返回 -1
```

#### 复杂度

- **时间复杂度**：`O(n log n)` — 遍历 + 排序，`log n` 表示“对数”，相当于把事情一次次“二分”处理，规模会大幅降低。  
- **空间复杂度**：`O(1)` — 最多只存 10 个数字，算作常数空间。

### 2. 最优解

#### 思路  
暴力解的瓶颈在于**排序**，排序本身会带来 `log n` 的额外开销。其实我们只需要找出最大的和第二大的两个数字，完全可以在一次遍历中直接维护这两个值，而不必把所有数字都排好序。

从暴力解出发：

1. **慢在哪里**  
   - 排序需要比较很多次，而我们只关心前两名。  
   - 另外，集合的创建和列表的拷贝也占用一点时间和空间（虽然很小），但可以省掉。

2. **一步步推导优化**  
   - 设两个变量 `first`（最大）和 `second`（第二大），初始都设为 `-1`（表示还没找到）。  
   - 再遍历字符串，遇到数字 `d` 时：  
     - 如果 `d` 大于 `first`，说明我们找到了更大的数字，`second` 变成旧的 `first`，`first` 更新为 `d`。  
     - 否则如果 `d` 小于 `first` 但大于 `second`，说明它可以成为第二大，直接更新 `second`。  
   - 注意要**去重**：如果已经看到的 `d` 和 `first`、`second` 相等，就不需要再更新（因为题目只要不同的数字）。

3. **核心算法/数据结构**  
   - **双指针（Two variables）**：这里的“指针”其实就是两个整数变量，分别记录当前最大的和第二大的数字。  
   - **字符判断**：使用 `str.isdigit()` 判断字符是否为数字，类似“检查这个词是不是在字典里”。  

4. **类比**  
   - 想象你在一次跑步比赛里，只记录第一名和第二名的成绩。每当有新选手跑完，你只需要把他的成绩和已有的第一、第二名比较，决定是否上榜，而不必把所有成绩都排成表。

#### 代码（Python）

```python
def secondHighest(s: str) -> int:
    first = second = -1          # 初始时，最大和次大都设为 -1（表示“还没有”）

    for ch in s:
        if not ch.isdigit():    # 只关心数字，字母直接跳过
            continue

        d = int(ch)             # 把字符转成整数，方便比较

        # 已经出现过的数字不需要再次处理（去重）
        if d == first or d == second:
            continue

        if d > first:           # d 成为新的最大值
            second = first      # 旧的最大值变成次大
            first = d
        elif d > second:        # d 介于 first 和 second 之间，更新次大
            second = d

    return second               # 如果没有次大，second 仍然是 -1
```

#### 复杂度

- **时间复杂度**：`O(n)` — 只遍历一次字符串，`n` 是字符个数。和排排序的 `log n` 比，省去了额外的比较。  
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和字符串长度无关，真正的常数空间。

## 心得

- **核心技巧**：一次遍历维护**最大值和次大值**，并且在遍历过程中进行**去重**。  
- **适用的题型**：  
  1. “在数组/字符串中找第 K 大/小的元素（K 固定且很小）”。  
  2. “统计出现次数最多的前两名字符”。  
  3. “找出字符串中出现的最高/第二高的字母”。  
- **一句话总结解题钥匙**：只要把“找最大”这件事拆成“最大 + 次大”，在遍历时同时更新，就能在 O(n) 时间内搞定。

## 反思

- **第一反应**：看到“第二大数字”，第一时间想到“把所有数字收集后排序”。这是一种自然的直觉，但不一定是最优的。  
- **最容易踩的坑**  
  - **去重**：如果不判断 `d == first or d == second`，相同的数字会被错误地当成第二大。  
  - **没有数字或只有一个数字**：需要在最终返回时确保如果次大仍是 `-1`，就直接返回 `-1`。  
  - **字符转整数**：直接比较字符 `'9'` 和 `'10'` 会出错，必须先 `int()` 转换。  
- **下次遇到同类题**：第一步先思考“我真的需要完整排序吗？还是只要前几名？”如果只要前几名，立刻考虑**维护几个极值变量**的思路。
