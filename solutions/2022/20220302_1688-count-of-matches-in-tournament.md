# #1688. 赛事中的比赛场数 / Count of Matches in Tournament

## 题目（英文原版）

**Description**

You are given an integer n, the number of teams in a tournament that has strange rules:
Return the number of matches played in the tournament until a winner is decided.

**Examples**

**Example 1:**

```
Input: n = 7
Output: 6
Explanation: Details of the tournament: 
- 1st Round: Teams = 7, Matches = 3, and 4 teams advance.
- 2nd Round: Teams = 4, Matches = 2, and 2 teams advance.
- 3rd Round: Teams = 2, Matches = 1, and 1 team is declared the winner.
Total number of matches = 3 + 2 + 1 = 6.
```

**Example 2:**

```
Input: n = 14
Output: 13
Explanation: Details of the tournament:
- 1st Round: Teams = 14, Matches = 7, and 7 teams advance.
- 2nd Round: Teams = 7, Matches = 3, and 4 teams advance.
- 3rd Round: Teams = 4, Matches = 2, and 2 teams advance.
- 4th Round: Teams = 2, Matches = 1, and 1 team is declared the winner.
Total number of matches = 7 + 3 + 2 + 1 = 13.
```

**Constraints**

- 1 <= n <= 200

## 题目（中文翻译）

给定一个整数 `n`，表示参加一场规则特殊的锦标赛的球队数量。  
返回在锦标赛中进行的比赛总场数，直到决出冠军为止。

**示例 1**  
**输入**: `n = 7`  
**输出**: `6`  
**解释**: 锦标赛的详细过程如下:  
- 第 1 轮: 球队数 = 7，比赛场数 = 3，晋级球队数 = 4。  
- 第 2 轮: 球队数 = 4，比赛场数 = 2，晋级球队数 = 2。  
- 第 3 轮: 球队数 = 2，比赛场数 = 1，产生冠军。  
总比赛场数 = 3 + 2 + 1 = 6。

**示例 2**  
**输入**: `n = 14`  
**输出**: `13`  
**解释**: 锦标赛的详细过程如下:  
- 第 1 轮: 球队数 = 14，比赛场数 = 7，晋级球队数 = 7。  
- 第 2 轮: 球队数 = 7，比赛场数 = 3，晋级球队数 = 4。  
- 第 3 轮: 球队数 = 4，比赛场数 = 2，晋级球队数 = 2。  
- 第 4 轮: 球队数 = 2，比赛场数 = 1，产生冠军。  
总比赛场数 = 7 + 3 + 2 + 1 = 13。

**约束条件**  
- $1 \le n \le 200$

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法就是 **按题目描述一步步模拟** 整个锦标赛的进行过程：

1. **当前还有多少支球队** `teams`（一开始等于 `n`）。  
2. 每一轮，**两支球队打一场**，所以本轮的比赛场数是 `teams // 2`（整数除法，去掉余数）。  
3. 胜者晋级，**晋级的球队数**是 `teams // 2`（胜者）+ `teams % 2`（如果是奇数，会多出一支直接晋级的球队）。  
4. 把本轮的比赛场数累加到答案里，`teams` 更新为下一轮的球队数，继续循环，直到只剩一支球队为止。

> 类比：想象一副扑克牌，每两张牌比一次大小，输的牌被“扔掉”。每轮把剩下的牌重新两两比较，直到只剩一张牌——这张牌就是冠军。我们只需要统计一共扔掉了多少张牌，也就是比赛场数。

**为什么这个方法一定能得到正确答案**  
- 每场比赛必然淘汰一支球队（胜者晋级，败者出局），所以 **每进行一场比赛，球队总数就会减 1**。  
- 循环结束的条件是只剩一支球队，即已经淘汰了 `n‑1` 支球队。把每轮的比赛数累加，就是总的淘汰次数，也就是答案。

#### 代码（Python）

```python
def number_of_matches_bruteforce(n: int) -> int:
    """
    暴力模拟锦标赛的每一轮
    :param n: 初始球队数量
    :return: 总比赛场数
    """
    matches = 0          # 用来累计总场次
    teams = n            # 当前剩余的球队数

    # 当剩余球队大于 1 时继续进行下一轮
    while teams > 1:
        # 本轮可以进行的比赛场数 = 两两配对的数量
        cur = teams // 2
        matches += cur    # 累加本轮的比赛数

        # 计算晋级的球队数：
        #   - 每场比赛产生 1 支胜者
        #   - 如果球队数是奇数，还会多出一支直接晋级的球队（teams % 2）
        teams = cur + (teams % 2)

    return matches
```

#### 复杂度

- **时间复杂度：** `O(log n)`  
  每轮球队数量大约会减半（偶数时正好减半，奇数时也接近），所以循环的次数大约是 `log₂ n`，这在实际中非常快。  
- **空间复杂度：** `O(1)`  
  只用了几个整数变量，和 `n` 的大小无关。

### 2. 最优解

#### 思路  
从暴力解可以看到：**每进行一场比赛，就会淘汰一支球队**。  
整个锦标赛的目标是 **把 `n` 支球队削减到 1 支**，也就是说 **必须淘汰 `n‑1` 支球队**。  
而每场比赛只能淘汰 **恰好一支**，所以 **比赛总场数一定等于 `n‑1`**。

这是一条非常直接的数学结论，不需要模拟每一轮，只要返回 `n-1` 即可。

> 类比：把 `n` 支球队看成 `n` 块积木，每次比赛把一块积木“砸掉”。要只剩下一块，就得砸掉 `n-1` 块。砸掉多少次，就是比赛多少场。

#### 代码（Python）

```python
def number_of_matches_optimal(n: int) -> int:
    """
    直接返回 n-1，利用每场比赛淘汰一支球队的性质
    :param n: 初始球队数量
    :return: 总比赛场数
    """
    # 当只剩一支球队时，已经没有比赛可进行
    # 因此总比赛场数 = 初始球队数 - 1
    return n - 1
```

#### 复杂度

- **时间复杂度：** `O(1)`  
  只做一次减法运算，时间不随 `n` 增长而变化。  
- **空间复杂度：** `O(1)`  
  只用了一个局部变量（返回值），不占额外空间。

## 心得

- **核心技巧**：**“每场比赛淘汰一支球队”** 的计数思路。把问题转化为“要把多少东西删掉”，往往能得到 O(1) 的答案。  
- **适用的类似题目**  
  1. **把 `n` 个人配对成 `n/2` 对，求配对次数**（每配对一次，两人合并为一组）。  
  2. **合并石子游戏**：每次把两堆石子合并成一堆，求最少合并次数。  
  3. **树的边数**：一棵有 `n` 个节点的无向连通树恰好有 `n-1` 条边。  
- **一句话总结解题钥匙**：**“每次操作削减一个单位，最终要削减多少单位，就等于操作次数”。**

## 反思

- **第一反应**：看到“奇数队伍会多出一支直接晋级”，立刻想到要写循环模拟每一轮。  
- **最容易踩的坑**  
  - 忽略 **奇数** 情况导致的“直接晋级”球队，需要用 `teams % 2` 处理。  
  - 在模拟时误把 `teams // 2` 当成下一轮的球队数，而不是比赛场数。  
- **下次遇到同类题**：第一步先思考 **每一步的本质变化**（比如“淘汰一支球队”），看能否直接用 **数学公式** 代替显式模拟。这样往往能直接得到 O(1) 的最优解。
