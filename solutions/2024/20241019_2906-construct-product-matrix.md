# #2906. 构造乘积矩阵 / Construct Product Matrix

## 题目（英文原版）

**Description**

Given a 0-indexed 2D integer matrix grid of size n * m, we define a 0-indexed 2D matrix p of size n * m as the product matrix of grid if the following condition is met:
Return the product matrix of grid.

**Examples**

**Example 1:**

```
Input: grid = [[1,2],[3,4]]
Output: [[24,12],[8,6]]
Explanation: p[0][0] = grid[0][1] * grid[1][0] * grid[1][1] = 2 * 3 * 4 = 24
p[0][1] = grid[0][0] * grid[1][0] * grid[1][1] = 1 * 3 * 4 = 12
p[1][0] = grid[0][0] * grid[0][1] * grid[1][1] = 1 * 2 * 4 = 8
p[1][1] = grid[0][0] * grid[0][1] * grid[1][0] = 1 * 2 * 3 = 6
So the answer is [[24,12],[8,6]].
```

**Example 2:**

```
Input: grid = [[12345],[2],[1]]
Output: [[2],[0],[0]]
Explanation: p[0][0] = grid[0][1] * grid[0][2] = 2 * 1 = 2.
p[0][1] = grid[0][0] * grid[0][2] = 12345 * 1 = 12345. 12345 % 12345 = 0. So p[0][1] = 0.
p[0][2] = grid[0][0] * grid[0][1] = 12345 * 2 = 24690. 24690 % 12345 = 0. So p[0][2] = 0.
So the answer is [[2],[0],[0]].
```

**Constraints**

- 1 <= n == grid.length <= 105
- 1 <= m == grid[i].length <= 105
- 2 <= n * m <= 105
- 1 <= grid[i][j] <= 109

## 题目（中文翻译）

给定一个下标从 **0** 开始的二维整数矩阵 `grid`，其尺寸为 `n * m`。如果满足下列条件，则我们将下标从 **0** 开始的同尺寸二维矩阵 `p` 称为 `grid` 的 **乘积矩阵（product matrix）**：

- 对于每个位置 `(i, j)`，`p[i][j]` 等于 `grid` 中除 `(i, j)` 本身之外的所有元素的乘积。

返回 `grid` 的乘积矩阵 `p`。

---

#### 示例 1
**输入**  
`grid = [[1,2],[3,4]]`

**输出**  
`[[24,12],[8,6]]`

**解释**

- `p[0][1] = grid[0][0] * grid[1][0] * grid[1][1] = 1 * 3 * 4 = 12`  
- `p[1][0] = grid[0][0] * grid[0][1] * grid[1][1] = 1 * 2 * 4 = 8`  
- `p[1][1] = grid[0][0] * grid[0][1] * grid[1][0] = 1 * 2 * 3 = 6`  

因此答案为 `[[24,12],[8,6]]`。

#### 示例 2
**输入**  
`grid = [[12345],[2],[1]]`

**输出**  
`[[2],[0],[0]]`

**解释**  
- `p[0][0] = grid[0][1] * grid[0][2] = 2 * 1 = 2`

因此答案为 `[[2],[0],[0]]`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是**对每一个格子**，把矩阵里除它自己以外的所有数全部乘起来，得到的结果就是 `p[i][j]`。  
可以把矩阵想象成一本**词典**，每个格子是一个词，求 “除自己外的所有词的乘积”。  
实现上只需要两层循环：

1. 外层遍历所有格子 `(i, j)`，把它当作“被排除的格子”。  
2. 内层再次遍历所有格子 `(x, y)`，如果 `(x, y) != (i, j)` 就把 `grid[x][y]` 累乘到答案里。  

只要把所有乘积算出来，这个方法一定是对的，因为我们没有遗漏也没有多乘。

**为什么会对**  
每个格子都恰好乘进了 **所有** 其他格子的值一次，正好满足题目“除自身外的所有元素的乘积”。

**时间/空间复杂度**  
- 时间复杂度：外层 `n·m` 次，内层同样 `n·m` 次，总共是 `O((n·m)²)`。  
  用大白话说，就是如果矩阵有 10,000 个格子，暴力解大概要做 100,000,000 次乘法，明显太慢。  
- 空间复杂度：只需要一个和原矩阵同大小的答案矩阵，额外的辅助空间是 `O(1)`（不计答案本身）。

#### 代码（Python）

```python
def productMatrix_bruteforce(grid):
    n, m = len(grid), len(grid[0])
    ans = [[0] * m for _ in range(n)]          # 用来存放结果的矩阵

    for i in range(n):
        for j in range(m):
            prod = 1                           # 当前格子的乘积，先设为 1
            for x in range(n):
                for y in range(m):
                    if x == i and y == j:      # 跳过自己
                        continue
                    prod *= grid[x][y]          # 累乘其他格子的值
            ans[i][j] = prod                    # 写入答案矩阵

    return ans
```

#### 复杂度

- **时间复杂度**：`O((n·m)²)` —— 两层循环嵌套，格子数的平方级别。  
- **空间复杂度**：`O(1)`（不计答案矩阵）—— 只用了常数个临时变量。

### 2. 最优解

#### 思路  

从暴力解可以看到 **瓶颈** 在于每个格子都要遍历整个矩阵去乘，这导致了二次方的时间。  
我们需要把“所有格子除自己外的乘积” **一次遍历** 就算出来。  
这正好和“一维数组求除自身外的乘积”问题类似，只是这里矩阵是二维的。  

**关键点 1：把二维矩阵展平成一维**  
把 `grid` 按行展开成一个长度为 `N = n·m` 的数组 `flat`，下标 `k = i·m + j` 对应原矩阵的 `(i, j)`。  
这样问题就转化为：给定长度为 `N` 的数组，求每个位置除自身外的所有元素的乘积。

**关键点 2：前缀积 + 后缀积**  
- **前缀积** `pre[i]` 表示 `flat[0] … flat[i‑1]` 的乘积（不包括 `i` 本身）。  
- **后缀积** `suf[i]` 表示 `flat[i+1] … flat[N‑1]` 的乘积（不包括 `i` 本身）。  

则答案 `res[i] = pre[i] * suf[i]`。  
这只需要 **两次线性遍历**：

1. 从左到右累计前缀积，存入 `pre`。  
2. 从右到左累计后缀积，存入 `suf`。  

**关键点 3：把一维答案映射回二维**  
`res[i]` 对应原矩阵的 `(i // m, i % m)`。

**为什么不需要除法**  
如果我们直接算出所有元素的总乘积 `total`，再对每个格子做 `total // grid[i][j]`，会涉及除法且在出现 `0` 时会出错。  
前缀/后缀积天然把“除自身”拆成了两段乘积，完全不需要除法。

**类比**：想象一条链子，每个环上挂着一个数字。前缀积相当于从左边数到当前环前的所有环的力量，后缀积相当于从右边数到当前环后的所有环的力量。把左边的力量和右边的力量相乘，就是除掉当前环本身的总力量。

#### 代码（Python）

```python
def productMatrix(grid):
    """
    返回矩阵 grid 的 product matrix（除自身外的所有元素的乘积）。
    复杂度：O(n*m) 时间，O(n*m) 额外空间。
    """
    n, m = len(grid), len(grid[0])
    N = n * m                       # 矩阵总格子数

    # 1️⃣ 把二维矩阵展平成一维
    flat = [grid[i][j] for i in range(n) for j in range(m)]

    # 2️⃣ 前缀积
    pre = [1] * N                   # pre[i] = flat[0] * ... * flat[i-1]
    cur = 1
    for i in range(N):
        pre[i] = cur                # 记录当前位置左侧的乘积
        cur *= flat[i]              # 更新 cur 为包含当前元素的乘积

    # 3️⃣ 后缀积（直接在答案数组里算，省去单独的 suf 数组）
    ans_flat = [0] * N
    cur = 1
    for i in range(N - 1, -1, -1):
        ans_flat[i] = pre[i] * cur   # 前缀 * 后缀 = 除自身外的乘积
        cur *= flat[i]               # 累计后缀积（包括当前元素）

    # 4️⃣ 把一维答案映射回二维
    ans = [[0] * m for _ in range(n)]
    for idx, val in enumerate(ans_flat):
        i, j = divmod(idx, m)        # 逆向映射：行号 = idx // m, 列号 = idx % m
        ans[i][j] = val

    return ans
```

#### 复杂度

- **时间复杂度**：`O(n·m)` —— 只遍历了矩阵常数次（一次展平、一次前缀、一次后缀、一次写回），和格子数成线性关系。  
  与暴力解的二次方相比，快了好几个数量级。  

- **空间复杂度**：`O(n·m)` —— 需要额外的 `pre`（或 `suf`）以及展平后的 `flat`，都是线性大小。  
  如果希望进一步压缩空间，可以在遍历时直接在原矩阵上写前缀积，或者只保留一个后缀变量，空间可降到 `O(1)`（不计答案本身）。

## 心得

- **核心技巧**：前缀积 + 后缀积（Prefix‑Product & Suffix‑Product）  
  这是一种“除自身”类问题的通用套路，既能避免除法，又能在 **O(N)** 时间内完成。  

- **适用题型**  
  1. “除自身外的数组乘积”（LeetCode 238）  
  2. “除自身外的数组和”（前缀和 + 后缀和）  
  3. “二维数组除自身外的乘积”或“二维数组除自身外的和”

- **一句话总结**：  
  *把全局乘积拆成左边的前缀乘积和右边的后缀乘积，乘在一起就是除掉当前元素的答案。*

## 反思

- **第一反应**：直接写两层循环把每个格子之外的所有数相乘，忽视了时间会爆炸。  
- **最容易踩的坑**  
  - **溢出**：在语言限制（如 C/C++）下需要使用 64 位或取模，Python 自动大整数，稍微放心。  
  - **零元素**：如果矩阵里出现 `0`，前缀/后缀积仍然有效，只是答案会出现 `0`，不需要额外处理。  
  - **映射错误**：展平后一定要记得把下标 `k` 正确转回 `(i, j)`，`i = k // m, j = k % m`。  

- **下次遇到同类题**：  
  第一步先**把问题抽象成“一维除自身”**，思考是否可以用前缀/后缀累计；如果可以，就立刻转向 O(N) 的前缀‑后缀方案，而不是先写暴力循环。
