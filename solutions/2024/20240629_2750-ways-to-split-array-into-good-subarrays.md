# #2750. 将数组划分为良好子数组的方法 / Ways to Split Array Into Good Subarrays

## 题目（英文原版）

**Description**

You are given a binary array nums.
A subarray of an array is good if it contains exactly one element with the value 1.
Return an integer denoting the number of ways to split the array nums into good subarrays. As the number may be too large, return it modulo 109 + 7.
A subarray is a contiguous non-empty sequence of elements within an array.

**Examples**

**Example 1:**

```
Input: nums = [0,1,0,0,1]
Output: 3
Explanation: There are 3 ways to split nums into good subarrays:
- [0,1] [0,0,1]
- [0,1,0] [0,1]
- [0,1,0,0] [1]
```

**Example 2:**

```
Input: nums = [0,1,0]
Output: 1
Explanation: There is 1 way to split nums into good subarrays:
- [0,1,0]
```

**Constraints**

- 1 <= nums.length <= 105
- 0 <= nums[i] <= 1

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是：**把所有可能的切分方式全部枚举出来**，然后逐个检查每个子数组里是否恰好只有一个 `1`。  

- **数据结构**：我们可以把切分点看成 “在相邻两个元素之间是否放一把剪刀”。  
  - 用一个长度为 `n‑1` 的布尔数组 `cut[i]` 表示第 `i` 与 `i+1` 之间是否切开。  
  - 类比查字典：`cut[i]` 就像字典的 “键”，`True/False` 就是对应的 “页码”。  

- **正确性**：  
  - 任意一种合法的切分必然对应唯一的一组 `cut`，反之只要我们遍历所有 `cut` 的取值（`2^(n‑1)` 种），就不会漏掉任何可能。  
  - 对每种 `cut`，我们只要把数组划分成若干连续片段，然后统计每片段里 `1` 的个数，若全部恰为 `1`，这就是一种合法的划分。  

- **复杂度**：  
  - **时间**：我们要遍历 `2^(n‑1)` 种切分方式，每种方式最坏要遍历整个数组一次统计 `1` 的个数，时间复杂度是 **指数级**，记作 `O(2^n)`。这里的 `2^n` 可以想象成“把 n 张纸每张都翻面或不翻面”的所有组合数，随 n 增长非常快。  
  - **空间**：递归/回溯需要保存当前的 `cut` 状态，最多 `n‑1` 个布尔值，空间复杂度是 `O(n)`。  

#### 代码（Python）

```python
from typing import List

MOD = 10**9 + 7

def ways_bruteforce(nums: List[int]) -> int:
    n = len(nums)
    # 递归遍历第 i 位是否在 i 与 i+1 之间切开
    def backtrack(i: int, cuts: List[bool]) -> int:
        if i == n - 1:                     # 已经决定完所有切分点
            return 1 if check(cuts) else 0
        # 不切
        cuts.append(False)
        ans = backtrack(i + 1, cuts)
        cuts.pop()
        # 切
        cuts.append(True)
        ans += backtrack(i + 1, cuts)
        cuts.pop()
        return ans

    # 根据 cuts 把 nums 划分成子数组并检查每段是否恰好有一个 1
    def check(cuts: List[bool]) -> bool:
        cnt_one = 0          # 当前子数组里 1 的个数
        for idx, val in enumerate(nums):
            cnt_one += val
            # 如果到了切分点或者数组结束，判断当前子数组是否合法
            if idx == n - 1 or (idx < n - 1 and cuts[idx]):
                if cnt_one != 1:   # 必须恰好只有一个 1
                    return False
                cnt_one = 0        # 开始统计下一段
        return True

    return backtrack(0, []) % MOD
```

#### 复杂度  

- **时间复杂度**：`O(2^n)` —— 需要尝试所有 `2^(n-1)` 种切分方式，随着 `n` 增大会指数级爆炸。  
- **空间复杂度**：`O(n)` —— 递归栈和 `cuts` 列表最多保存 `n‑1` 个布尔值。

### 2. 最优解  

#### 思路  

从暴力解可以看到 **瓶颈** 在于枚举所有切分点。实际上，**合法切分只和 1 与 1 之间有多少个 0 有关**，不需要关心每一个具体的切割组合。  

观察一下示例 `[0,1,0,0,1]`：  

| 位置 | 0 | 1 | 0 | 0 | 1 |
|------|---|---|---|---|---|
| 索引 | 0 | 1 | 2 | 3 | 4 |

- 第一个 `1` 在下标 `1`，第二个 `1` 在下标 `4`。  
- 两个 `1` 之间有 **2 个 0**（下标 `2`、`3`）。  

要让每个子数组恰好只有一个 `1`，**唯一的切分点** 必须落在这两个 `1` 之间的某个位置。  
如果这段中有 `k` 个 `0`，则可以在 `k+1` 个位置切开：

```
0 1 0 0 1
|   |   |   |   <-- 可能的切点（包括最左、最右）
```

- **左侧**（在第一个 `1` 左边）和 **右侧**（在第二个 `1` 右边）不需要切，因为它们已经被前后相邻的 `1` 包围。  
- 对于 **每一对相邻的 1**，我们都有 `gap+1` 种切法，其中 `gap` 是它们之间的 `0` 的数量。  

所有相邻 `1` 对的切法互相独立，**总的合法切法** 就是这些选择的乘积。  

因此算法步骤如下：

1. **遍历数组，记录所有 `1` 的下标**。  
2. 如果 `1` 的数量为 `0` → 没有任何合法子数组，答案 `0`。  
   如果只有 **一个** `1` → 整个数组本身已经是唯一的好子数组，答案 `1`。  
3. 对每两个相邻 `1` 的下标 `prev`、`cur`，计算 `gap = cur - prev - 1`（中间有多少个 `0`），把 `gap + 1` 累乘到答案中。  
4. 每一步都对 `10^9+7` 取模，防止整数溢出。  

**为什么只和 0 的个数有关？**  
- 子数组内部的 `0` 不影响 “恰好只有一个 `1`” 的判定，它们可以随意留在左侧或右侧，只要切点不跨过另一个 `1`。  
- 所以每段 `0` 的分配方式就是在 `gap+1` 条“缝”里挑一个切点。

**类比**：  
把每个 `1` 想象成 **灯泡**，灯泡之间的 `0` 是 **暗区**。我们要在每段暗区的 **任意一格** 安装 **开关**，把左边的灯泡与右边的灯泡分开。每段暗区有 `gap+1` 种装开关的位置，所有段的选择相乘，就是所有可能的灯光布局。  

#### 代码（Python）

```python
from typing import List

MOD = 10**9 + 7

def ways_optimal(nums: List[int]) -> int:
    """
    O(n) 时间、O(1) 额外空间的最优解
    """
    n = len(nums)
    ones = []                     # 保存所有 1 的下标
    for i, v in enumerate(nums):
        if v == 1:
            ones.append(i)

    # 特殊情况处理
    if len(ones) == 0:           # 全是 0，根本不存在好子数组
        return 0
    if len(ones) == 1:           # 只有一个 1，整个数组只能算作唯一的划分
        return 1

    ans = 1
    # 遍历相邻的 1，计算它们之间的 0 的数量
    for i in range(1, len(ones)):
        gap = ones[i] - ones[i-1] - 1   # 中间有多少个 0
        ans = (ans * (gap + 1)) % MOD   # 累乘并取模
    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n)` —— 只需要一次线性扫描来收集 `1` 的位置并累计乘积。相比暴力的 `O(2^n)`，速度提升了指数级。  
- **空间复杂度**：`O(1)`（不计输出）—— 除了保存 `1` 的下标列表（最坏 `O(k)`，其中 `k` ≤ `n`，但只用整数计数），额外只用了常数级变量。若不想额外列表，也可以在遍历时直接记录上一次出现的 `1` 的位置，同样是 `O(1)`。

## 心得  

- **核心技巧**：把“每个子数组恰好有一个 `1`”转化为 **相邻 `1` 之间的切点选择**，进而得到乘积公式。  
- **适用题型**：  
  1. **计数分割**（如 “将数组划分成每段和相等” 类似思路）  
  2. **只关心特殊元素之间距离的题目**（例如 “统计两次出现相同字符之间的子串数”）  
  3. **乘积/组合计数**（如 “不同颜色的球按顺序排列的方式数”）  
- **一句话总结**：  
  > “只要把关注点放在关键元素（这里是 `1`）之间的间隔上，整体计数往往能化简为若干独立的乘法”。

## 反思  

- **第一反应**：看到 “把数组划分成好子数组”，立刻想到 “枚举所有切点”。这导致想到的暴力解是 `2^(n-1)`，虽然正确却不实际。  
- **最容易踩的坑**：  
  - 忽略 **全 0** 的情况，导致返回 `1`（错误）。  
  - 只在相邻 `1` 之间乘 `gap` 而不是 `gap+1`，少算了一种切法（把切点放在最左或最右的那条缝）。  
  - 忘记对乘积取模，导致大数溢出。  
- **下次遇到同类题**：  
  - 第一步先 **定位关键元素**（本题是 `1`），看看它们之间的 **间隔** 能否直接决定答案。  
  - 再判断是否可以把整体计数拆成 **独立子问题的乘积**，从而得到线性或对数级的解法。
