## 解题过程

### 1. 直觉解（暴力）

#### 思路  

这道题的要求非常直白：**把一个整数 `init` 包装成一个“计数器”，并返回可以操作它的三个函数**（`increment`、`decrement`、`reset`）。  
我们只需要：

1. **保存当前计数**。用一个普通的变量 `cur` 来存放“现在的值”。可以把它想象成一个 **记事本**，上面写着当前的数字。
2. **返回一个对象**，对象里放三个函数。每个函数内部都可以直接读写 `cur`。这和 **查字典** 很像，字典的键是函数名，值是对应的实现代码。
3. 三个函数的行为如下  
   - `increment()`：`cur += 1`，并返回新的 `cur`。  
   - `decrement()`：`cur -= 1`，并返回新的 `cur`。  
   - `reset()`：`cur = init`（把记事本恢复到最开始的数），并返回 `cur`。  

只要把这三步写出来，就能得到正确答案。**为什么对？** 因为题目只要求**保持一个整数的最新值**，没有其他约束，直接修改这个唯一的变量即可。

**复杂度分析（大白话）**  
- **时间复杂度**：每次调用函数只做一次加/减/赋值操作，**O(1)**（常数时间），意思是“无论调用多少次，花的时间都差不多，只和一次操作有关”。  
- **空间复杂度**：我们只需要保存一个整数 `cur`（外加 `init`），所以 **O(1)**，即“占用的内存是固定的，和输入规模无关”。

#### 代码（Python）

```python
def createCounter(init: int):
    """
    返回一个包含三个计数器方法的对象。
    """
    cur = init                     # 记事本：当前计数，初始值为 init

    # 用字典模拟返回的对象，键是方法名，值是对应的函数
    def increment():
        nonlocal cur               # 告诉 Python 这里使用的是外层的 cur
        cur += 1                   # 加 1
        return cur                 # 返回最新值

    def decrement():
        nonlocal cur
        cur -= 1                   # 减 1
        return cur

    def reset():
        nonlocal cur
        cur = init                 # 恢复到最初的 init
        return cur

    return {
        "increment": increment,
        "decrement": decrement,
        "reset": reset,
    }
```

> **使用示例**（对应题目示例 1）  
> ```python
> counter = createCounter(5)
> print(counter["increment"]())  # 6
> print(counter["reset"]())      # 5
> print(counter["decrement"]())  # 4
> ```

#### 复杂度

- **时间复杂度**：`O(1)` — 每个方法只做一次基本运算，时间不随调用次数增长而增长。
- **空间复杂度**：`O(1)` — 只保存两个整数 (`init` 与 `cur`)，占用的内存是常数。

### 2. 最优解

#### 思路  

对于这类“只需要维护一个状态并提供几种操作”的题目，**暴力解已经是最优的**。  
唯一可以改进的地方是 **代码的组织形式**，比如：

- 使用 **类（class）** 而不是返回字典，使调用更自然（`counter.increment()`）。
- 使用 **闭包**（上面已经演示）保持 `cur` 的私有性。

这里我们给出 **类实现**，它在时间、空间上仍然是 `O(1)`，但更符合面向对象的习惯，阅读起来更直观。

核心概念解释：

- **类**：把数据（属性）和操作（方法）封装在一起，就像把记事本和几支笔装进同一个盒子。外部只能通过盒子提供的“按钮”来改变记事本的内容。
- **实例属性**：每创建一个 `Counter`，都会得到一份独立的记事本（`self.cur`），互不干扰。

#### 代码（Python）

```python
class Counter:
    """
    Counter 类实现同样的功能。
    使用方法：
        c = Counter(init)
        c.increment()
        c.decrement()
        c.reset()
    """
    def __init__(self, init: int):
        self.init = init   # 保存初始值，后面 reset 用到
        self.cur = init    # 当前计数，初始时等于 init

    def increment(self) -> int:
        """计数加 1，并返回新值"""
        self.cur += 1
        return self.cur

    def decrement(self) -> int:
        """计数减 1，并返回新值"""
        self.cur -= 1
        return self.cur

    def reset(self) -> int:
        """把计数恢复到最初的 init，并返回该值"""
        self.cur = self.init
        return self.cur


def createCounter(init: int):
    """
    题目要求返回一个“对象”，这里直接返回 Counter 实例。
    """
    return Counter(init)
```

> **使用示例**（对应题目示例 2）  
> ```python
> counter = createCounter(0)
> print(counter.increment())  # 1
> print(counter.increment())  # 2
> print(counter.decrement())  # 1
> print(counter.reset())      # 0
> print(counter.reset())      # 0
> ```

#### 复杂度

- **时间复杂度**：`O(1)` — 每个方法仍然只做一次加/减/赋值。
- **空间复杂度**：`O(1)` — 只保存两个整数 (`init` 与 `cur`)。

与暴力解的对比：**本质上没有区别**，因为原始思路已经是最简的常数时间/空间实现。这里的“最优”体现在代码结构更清晰、可读性更好。

## 心得

- **核心技巧**：**闭包或类的封装**——把状态（计数）和操作（增、减、重置）绑定在一起，使外部只能通过提供的接口修改状态。
- **适用场景**：  
  1. 需要维护**全局/共享状态**但又希望对外隐藏实现细节的题目（如 LeetCode “Design Browser History”）。  
  2. 需要**多次调用同一组操作**且每次调用都要记住上一次结果的题目（如 “Design Tic‑Tac‑Toe”）。  
- **一句话总结**：**把变量放进闭包或类里，让方法去读写它，所有操作都是 O(1)。**

## 反思

- **第一反应**：看到“返回一个对象并包含三个函数”，立刻想到“用字典或类包装函数”。  
- **最容易踩的坑**：  
  - 忘记在内部函数里使用 `nonlocal`（闭包写法），导致修改的是局部变量而不是外层的计数。  
  - `reset` 时没有把计数恢复到最初的 `init`，而是恢复到当前值的副本。  
  - 边界值：`init` 可以是负数，确保加减操作仍然正确。  
- **下次遇到同类题**，第一步应该想到：**“我需要一个可以保存内部状态的容器（闭包或类），然后把所有操作写成该容器的方法”。**这样可以快速搭建出满足题意的代码框架。
