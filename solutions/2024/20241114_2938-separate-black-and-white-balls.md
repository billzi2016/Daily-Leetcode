# #2938. **分离黑白球** / Separate Black and White Balls

> 难度：中等 · 标签：Two Pointers、String、Greedy · [LeetCode 链接](https://leetcode.com/problems/separate-black-and-white-balls/)

---

## 题目（英文原版）

**Description**

There are n balls on a table, each ball has a color black or white.
You are given a 0-indexed binary string s of length n, where 1 and 0 represent black and white balls, respectively.
In each step, you can choose two adjacent balls and swap them.
Return the minimum number of steps to group all the black balls to the right and all the white balls to the left.

**Examples**

**Example 1:**

```
Input: s = "101"
Output: 1
Explanation: We can group all the black balls to the right in the following way:
- Swap s[0] and s[1], s = "011".
Initially, 1s are not grouped together, requiring at least 1 step to group them to the right.
```

**Example 2:**

```
Input: s = "100"
Output: 2
Explanation: We can group all the black balls to the right in the following way:
- Swap s[0] and s[1], s = "010".
- Swap s[1] and s[2], s = "001".
It can be proven that the minimum number of steps needed is 2.
```

**Example 3:**

```
Input: s = "0111"
Output: 0
Explanation: All the black balls are already grouped to the right.
```

**Constraints**

- 1 <= n == s.length <= 105
- s[i] is either '0' or '1'.

## 题目（中文翻译）

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把每一对“黑球在左、白球在右”的情况都数一遍**，因为每一次相邻交换只能把相邻的 `1` 与 `0` 互换一次，而要把所有的 `1` 移到最右边，就必须把每一个“左边的 `1` 与右边的 `0`”都换位一次。  

这就和 **统计逆序对** 完全一样——把字符串看成只包含 `0`、`1` 的数组，逆序对的定义是：下标 `i < j` 且 `s[i] = 1`、`s[j] = 0`。每出现这样的一对，就说明这两个球必须经过一次相邻交换才能把 `1` 挪到 `0` 的右边。把所有这样的对数起来，就是最少需要的交换步数。

> **类比**：想象一本字典，单词排好序后，若有两个词顺序颠倒了（比如 “apple” 在 “banana” 前面），我们需要把它们调换位置才能恢复字典的顺序。这里的 “调换一次” 对应一次相邻交换。

**为什么这个方法一定正确？**  
- 每一次相邻交换只能把相邻的 `1` 与 `0` 的相对顺序颠倒一次。  
- 若 `1` 在 `0` 的左边，它们之间的相对顺序必须被颠倒，否则最终 `1` 永远不可能在 `0` 的右边。  
- 因此每一对逆序都 **必须** 被交换一次，且一次交换只能解决 **恰好** 一个逆序对（因为只影响相邻两个元素）。  
- 所以逆序对的总数恰好等于最少的交换次数。

**复杂度分析（大白话）**  
- 我们要把每个位置的字符都和它右边的所有字符比较一次，这相当于 **两层循环**：外层遍历 `n` 次，内层最坏也要遍历 `n` 次。  
- 这就像排队买票，如果每个人都要检查后面所有人是否比自己晚到，就会花 **`n²` 次检查**。  
- 所以时间复杂度是 **O(n²)**，空间上只需要存放原字符串和一个计数器，**O(1)**。

#### 代码（Python）

```python
def min_swaps_bruteforce(s: str) -> int:
    """
    暴力统计逆序对的数量
    时间复杂度 O(n^2)，空间复杂度 O(1)
    """
    n = len(s)
    ans = 0
    # 双重循环：i 左边，j 右边
    for i in range(n):
        if s[i] == '1':                     # 只关心左边是黑球的情况
            for j in range(i + 1, n):
                if s[j] == '0':             # 右边出现白球，形成逆序
                    ans += 1
    return ans
```

#### 复杂度

- **时间复杂度：** `O(n²)` —— 想象每个球都要和后面的所有球比较一次，次数会随 `n` 的平方增长。
- **空间复杂度：** `O(1)` —— 只用了几个整数变量，和输入长度无关。

### 2. 最优解

#### 思路  

从暴力解我们知道：**答案等于逆序对的数量**。  
暴力的瓶颈在于每次都要遍历右侧的所有字符，导致 `n²` 次比较。  

**关键观察**：  
- 当我们从 **右向左** 扫描字符串时，已经看到的字符全部在当前字符的右边。  
- 如果我们记录 **已经出现的 `0`（白球） 的数量**，那么：
  - 遇到一个 `1`（黑球） 时，这个 `1` 必须和右边的每一个 `0` 交换一次，贡献的交换次数正好等于「右侧已出现的 `0` 的个数」。
  - 遇到一个 `0` 时，只是把计数器 `zero_cnt` 加一，表示以后遇到的 `1` 需要多交换一次。

这样只需一次线性遍历，就能把所有逆序对的贡献累加完。

> **类比**：想象在街道的右侧已经停好了若干辆白色自行车（`0`），当一辆黑色自行车（`1`）从左边驶来，它需要穿过所有已经停好的白车才能到达最右边。我们只要记住已经停了几辆白车，就知道这辆黑车要穿多少次。

**算法步骤**：

1. 初始化 `zero_cnt = 0`（右侧出现的白球数）和 `ans = 0`（累计交换步数）。  
2. 从字符串的最右侧向左遍历（`for i in range(n-1, -1, -1)`）。  
   - 如果 `s[i] == '0'`：`zero_cnt += 1`（以后左边的 `1` 都要多一次交换）。  
   - 否则（`s[i] == '1'`）：`ans += zero_cnt`（当前 `1` 需要和右侧所有 `0` 交换）。  
3. 循环结束后 `ans` 即为最小交换次数。

**复杂度**：只遍历一次，时间 `O(n)`，额外使用两个整数，空间 `O(1)`。

#### 代码（Python）

```python
def min_swaps_optimal(s: str) -> int:
    """
    一次遍历统计逆序对（右侧已出现的 0 的数量）
    时间复杂度 O(n)，空间复杂度 O(1)
    """
    zero_cnt = 0          # 右侧已经看到的白球数量
    ans = 0               # 累计需要的交换次数

    # 从右往左扫描
    for ch in reversed(s):
        if ch == '0':
            zero_cnt += 1          # 记录一个新的白球
        else:  # ch == '1'
            ans += zero_cnt        # 这个黑球要和右边的每个白球交换一次
    return ans
```

#### 复杂度

- **时间复杂度：** `O(n)` — 只需一次线性扫描，`n` 增大时，耗时几乎与 `n` 成正比。  
- **空间复杂度：** `O(1)` — 只用常数个变量，不随输入规模变化。

## 心得

- **核心技巧**：把 “把所有 1 移到右边” 转化为 “统计逆序对”，再利用单次遍历累计右侧 `0` 的数量，实现线性时间求解。  
- **适用的题型**：  
  1. **最小相邻交换使字符串有序**（如把所有 `a` 移到左边，`b` 移到右边）。  
  2. **统计数组中的逆序对**（如求数组排序需要的交换次数）。  
  3. **最少移动使所有 1 连在一起**（类似 LeetCode 1151）。  
- **一句话总结**：**逆序对即所需最小相邻交换次数，右向左累加右侧 `0` 即可得到答案**。

## 反思

- **第一反应**：看到 “相邻交换”，立刻想到 **逆序对**，因为每一次相邻交换只能消除一个逆序。  
- **最容易踩的坑**：  
  - 忽略了 `0` 与 `1` 的方向要求（本题要求所有 `1` 在右边），如果写成统计 `0` 在右侧的逆序会得到错误答案。  
  - 忽视了字符串长度可达 `10⁵`，直接使用双层循环会超时。  
  - 没有考虑空字符串或全部相同字符的情况（答案应为 `0`）。  
- **下次遇到同类题**：第一步先 **把问题抽象为逆序对或“左侧元素需要右侧多少特定元素”**，然后决定是否可以用一次遍历累计计数来完成。这样常能把时间从 `O(n²)` 降到 `O(n)`。
