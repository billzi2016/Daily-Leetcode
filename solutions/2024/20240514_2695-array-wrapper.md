## 题目（英文原版）

**Description**

Create a class ArrayWrapper that accepts an array of integers in its constructor. This class should have two features:

**Examples**

**Example 1:**

```
Input: nums = [[1,2],[3,4]], operation = "Add"
Output: 10
Explanation:
const obj1 = new ArrayWrapper([1,2]);
const obj2 = new ArrayWrapper([3,4]);
obj1 + obj2; // 10
```

**Example 2:**

```
Input: nums = [[23,98,42,70]], operation = "String"
Output: "[23,98,42,70]"
Explanation:
const obj = new ArrayWrapper([23,98,42,70]);
String(obj); // "[23,98,42,70]"
```

**Example 3:**

```
Input: nums = [[],[]], operation = "Add"
Output: 0
Explanation:
const obj1 = new ArrayWrapper([]);
const obj2 = new ArrayWrapper([]);
obj1 + obj2; // 0
```

**Constraints**

- 0 <= nums.length <= 1000
- 0 <= nums[i] <= 1000
- Note: nums is the array passed to the constructor

## 题目（中文翻译）

创建一个类 `ArrayWrapper`，其构造函数（constructor）接受一个整数数组（array of integers）。该类应实现以下两个特性：

- 当两个 `ArrayWrapper` 实例使用加法运算符（`+`）相加时，返回两个数组中所有元素的和。

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

我们要实现一个 `ArrayWrapper` 类，使得：

* `obj1 + obj2` 能返回 **两个数组中所有整数的和**  
* `String(obj)`（在 Python 中相当于 `str(obj)`）能返回 **数组的字符串形式**，比如 `[1,2,3]`

最直接的想法就是 **逐个遍历数组**，把每个元素累加起来；把数组 **一个一个字符拼接** 成目标字符串。  
这里涉及到的两个数据结构：

| 数据结构 | 类比 | 作用 |
|----------|------|------|
| **列表（list）** | 像装东西的盒子，里面可以放很多数字 | 保存传进来的整数序列 |
| **字符串（str）** | 像一本笔记本，记下“[1,2,3]”这样的文字 | 用来返回数组的可读形式 |

只要把每个数字都加一次，就一定能得到正确的总和；只要把每个数字都写进字符序列里（并加上逗号和方括号），就一定能得到正确的字符串。  

**为什么正确？**  
* 加法满足交换律和结合律，遍历一次把所有数相加等价于一次性把它们相加。  
* 字符串的拼接顺序与数组中元素的顺序一致，最终得到的字符序列正好是题目要求的形式。

**时间/空间复杂度**（大白话版）  
* **时间复杂度** `O(m + n)`：如果第一个数组有 `m` 个元素，第二个有 `n` 个，我们要 **逐个访问** 这 `m+n` 个数字，访问一次算一次工作，工作量正比于元素个数。  
* **空间复杂度** `O(1)`（不计返回值）：我们只用几个临时变量（累计和、拼接的字符串），不随输入规模增长而增长。  

#### 代码（Python）

```python
class ArrayWrapper:
    """
    暴力实现：
    - __add__   : 手动遍历两个列表，逐个相加
    - __str__   : 手动遍历列表，拼接成 "[a,b,c]" 的形式
    """

    def __init__(self, nums):
        # 把传进来的数组保存下来
        self.nums = nums

    # ------------------- 加法 -------------------
    def __add__(self, other):
        """返回 self.nums 与 other.nums 所有元素的和"""
        total = 0

        # 遍历自己的数组
        for x in self.nums:
            total += x          # 把每个元素加到 total 上

        # 再遍历对方的数组
        for x in other.nums:
            total += x

        return total          # 最后返回累计的结果

    # ------------------- 字符串 -------------------
    def __str__(self):
        """把数组转成形如 \"[1,2,3]\" 的字符串"""
        # 特殊情况：空数组直接返回 "[]"
        if not self.nums:
            return "[]"

        # 手动拼接每个元素以及逗号
        res = "["               # 开头的左方括号
        for i, x in enumerate(self.nums):
            res += str(x)       # 把数字转成字符串加入
            if i != len(self.nums) - 1:   # 不是最后一个元素就加逗号
                res += ","
        res += "]"               # 结尾的右方括号
        return res
```

#### 复杂度  

- **时间复杂度** `O(m + n)`：遍历两个数组各一次（加法），遍历一次自身数组（字符串）。  
- **空间复杂度** `O(1)`：只用常数个临时变量（`total`、`res`），不随数组长度增长。

### 2. 最优解  

#### 思路  

从暴力解来看，**瓶颈** 并不在时间上——我们已经是线性遍历了，无法再快；而是 **代码的简洁性和可读性**。  
Python 本身提供了非常高效且易用的工具：

* `sum(iterable)`：直接把可迭代对象里的所有数字加起来，内部已经是 C 实现，快且省代码。  
* `str(list)` 或 `json.dumps(list)`：把列表直接转换为字符串，内部已经处理了方括号、逗号、空列表等细节。  

所以“最优解”其实是 **利用语言内置的函数**，既保持 `O(m+n)` 的时间，又让实现更短、更不易出错。

**核心技巧**  

| 技巧 | 类比 | 作用 |
|------|------|------|
| `sum` 函数 | 像一个会算账的会计，直接把所有数字算完 | 把数组里所有数字一次性求和 |
| `str`/`json.dumps` | 像一本自动排版的印刷机，把列表直接印成 “[1,2,3]” | 把列表直接转成符合题目要求的字符串形式 |

#### 代码（Python）

```python
import json   # 用于把列表转成标准的 JSON 字符串（即题目要求的格式）

class ArrayWrapper:
    """
    最优实现：利用 Python 的内置函数 sum 和 json.dumps
    - __add__   : 直接使用 sum() 求和
    - __str__   : 使用 json.dumps() 生成 "[a,b,c]" 形式的字符串
    """

    def __init__(self, nums):
        self.nums = nums

    # ------------------- 加法 -------------------
    def __add__(self, other):
        """返回两个 ArrayWrapper 所有元素的和"""
        # sum(self.nums) 求出自己的和，sum(other.nums) 求出对方的和
        return sum(self.nums) + sum(other.nums)

    # ------------------- 字符串 -------------------
    def __str__(self):
        """把数组转成 JSON 风格的字符串，例如 \"[1,2,3]\""""
        # json.dumps 会自动处理空列表、负数、逗号、方括号等细节
        return json.dumps(self.nums)
```

> **为什么选 `json.dumps` 而不是直接 `str(self.nums)`？**  
> 在 Python 中 `str([1, 2])` 会得到 `"[1, 2]"`（注意有空格），而题目要求的字符串是 **没有空格** 的 `"[1,2]"`。`json.dumps` 正好满足这一点。

#### 复杂度  

- **时间复杂度** `O(m + n)`：`sum` 仍然需要遍历所有元素一次，`json.dumps` 也需要遍历一次生成字符序列。  
- **空间复杂度** `O(1)`（不计返回值）：仅使用常数级别的临时变量；返回的字符串或整数本身不算在额外空间里。

与暴力解相比，时间上没有提升（因为已经是线性最优），但**代码更简洁、可读性更好、出错概率更低**。

## 心得  

- **核心技巧**：利用语言提供的 **内置函数**（如 `sum`、`json.dumps`）实现常见的聚合与格式化操作。  
- **适用的题型**  
  1. **数组求和**：如 “Two Sum”，但只需要总和时直接 `sum`。  
  2. **数组转字符串**：如 “Print the Array”，可以使用 `json.dumps` 或 `','.join(map(str, arr))`。  
  3. **自定义运算符**：实现 `__add__`、`__str__`、`__repr__` 等魔法方法的题目。  
- **一句话总结**：**“先想 Python 已经帮我们实现了哪些功能，再把它们直接调用，就能写出既快又简洁的代码。”**

## 反思  

- **第一反应**：看到 “+” 和 “String” 两个操作，就想到要实现 `__add__`（加法运算符）和 `__str__`（字符串表示）这两个魔法方法。  
- **最容易踩的坑**  
  1. **字符串格式**：直接 `str(list)` 会产生空格，导致输出不匹配；需要去掉空格或使用 `json.dumps`。  
  2. **空数组**：在手动拼接字符串时要特别处理 `[]`，否则会得到 `"[ ]"` 或缺失方括号。  
  3. **类型检查**：`other` 可能不是 `ArrayWrapper`，在真实面试中应加上 `isinstance` 检查，这里题目默认合法。  
- **下次类似题目第一步**：**先确认语言已有的便利函数**（求和、转字符串、排序等），再决定是手动实现还是直接调用。这样既能保证正确性，又能节约实现时间。
