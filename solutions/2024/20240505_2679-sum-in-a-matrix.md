# #2679. 矩阵中的和 / Sum in a Matrix

> 难度：中等 · 标签：Array、Sorting、Heap (Priority Queue)、Matrix、Simulation · [LeetCode 链接](https://leetcode.com/problems/sum-in-a-matrix/)

## 题目（英文原版）

**Description**

You are given a 0-indexed 2D integer array nums. Initially, your score is 0. Perform the following operations until the matrix becomes empty:
Return the final score.

**Examples**

**Example 1:**

```
Input: nums = [[7,2,1],[6,4,2],[6,5,3],[3,2,1]]
Output: 15
Explanation: In the first operation, we remove 7, 6, 6, and 3. We then add 7 to our score. Next, we remove 2, 4, 5, and 2. We add 5 to our score. Lastly, we remove 1, 2, 3, and 1. We add 3 to our score. Thus, our final score is 7 + 5 + 3 = 15.
```

**Example 2:**

```
Input: nums = [[1]]
Output: 1
Explanation: We remove 1 and add it to the answer. We return 1.
```

**Constraints**

- 1 <= nums.length <= 300
- 1 <= nums[i].length <= 500
- 0 <= nums[i][j] <= 103

## 题目（中文翻译）

你得到一个 **0 索引的**（0-indexed）二维整数数组 `nums`。初始时，你的分数为 0。重复以下操作，直至矩阵为空：

1. 对矩阵的每一行，取当前最左侧的元素，将这些元素组成的一列从矩阵中删除；
2. 将上述被删除元素中的最大值加到分数上。

返回最终的分数。

**示例 1**  
**输入**: `nums = [[7,2,1],[6,4,2],[6,5,3],[3,2,1]]`  
**输出**: `15`  
**解释**: 第一次操作时，删除列 `[7,6,6,3]`，把最大值 `7` 加入分数。  
第二次操作时，删除列 `[2,4,5,2]`，把最大值 `5` 加入分数。  
第三次操作时，删除列 `[1,2,3,1]`，把最大值 `3` 加入分数。  
最终分数为 `7 + 5 + 3 = 15`。

**示例 2**  
**输入**: `nums = [[1]]`  
**输出**: `1`  
**解释**: 删除唯一的元素 `1` 并将其加入分数，返回 `1`。

**约束条件**  
- `1 <= nums.length <= 300`  
- `1 <= nums[i].length <= 500`  
- `0 <= nums[i][j] <= 10^3`

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

题目说要 **不停地对每一列取最大值并把它加入分数**，随后把 **每一行的最左边（或最上面的）元素全部删掉**，直到矩阵为空。  
最直接的想法就是把矩阵原样保存，循环下面的步骤：

1. 对每一列遍历所有剩余的行，找到该列的最大数 `col_max`。  
2. 把 `col_max` 加到总分 `score`。  
3. 把每一行的第一个元素（因为每行都会被“删掉”一次）弹出或标记为已删除。  

这跟生活中的 **“每轮挑出每列的最高分，然后把每位选手的第一张卡片丢掉”** 十分相似。  
只要每一步都正确地找到了列最大值，并且真的把对应的元素删掉，最终累计的分数一定就是题目要求的答案。

**为什么正确**  
- 每一次操作都完全遵循题目规定：列最大 → 加分 → 删除每行的最左元素。  
- 循环一直进行到矩阵没有元素为止，正好对应题目“直到矩阵为空”。  

**复杂度分析（大白话版）**  

- **时间**：  
  - 假设矩阵有 `R` 行、`C` 列。  
  - 每轮我们要遍历所有剩余的行来找每列的最大值，最坏情况要看 `R × C` 次。  
  - 这种遍历会进行 `R` 轮（因为每轮删掉每行的一个元素），于是总操作次数约为 `R × R × C = O(R²·C)`。  
  - 用大写的 `O` 表示的是“数量级”，也就是说当行数增大时，时间会以 **行数的平方** 乘以列数的速度增长。  

- **空间**：  
  - 只需要原矩阵本身和几个临时变量，额外空间是常数级的 `O(1)`（不算输入本身）。  

#### 代码（Python）

```python
from typing import List

def sum_in_matrix_bruteforce(nums: List[List[int]]) -> int:
    # 复制一份，防止修改原始输入
    rows = [list(row) for row in nums]          # 每行都是一个列表
    R, C = len(rows), len(rows[0])               # 行数、列数（题目保证是矩形）
    score = 0

    # 循环 R 次，每次把每行的最左边元素删掉
    for _ in range(R):
        # 1) 找每列的最大值
        col_max = -1
        for c in range(C):
            # 在第 c 列中遍历所有行，找最大值
            for r in range(R):
                if rows[r][c] > col_max:
                    col_max = rows[r][c]
        # 2) 加到答案
        score += col_max

        # 3) 删除每行的第一个元素（左侧已“使用”）
        for r in range(R):
            rows[r].pop(0)        # 删除最左边的元素

    return score
```

> **注释**  
> - `rows[r].pop(0)` 相当于把每行最左边的卡片丢掉。  
> - 这里的两层循环 `for c in range(C)` + `for r in range(R)` 就是“在每列里找最大”。  

#### 复杂度  

- **时间复杂度**：`O(R²·C)` —— 行数平方乘列数。  
  - 直观理解：如果矩阵有 100 行、10 列，时间大约是 `100*100*10 = 100,000` 次基本操作。  
- **空间复杂度**：`O(1)`（不计输入本身），因为只用了常数个额外变量。

### 2. 最优解  

#### 思路  

从暴力解可以看到 **瓶颈** 在于每轮都要遍历整列去找最大值，导致 `R` 次的 `R·C` 扫描，时间呈二次方增长。  
我们思考：**有没有办法一次就把每列的最大值提前算好？**  

观察题目给出的提示：

> - 把每一行的数字 **降序** 排序。  
> - “答案是每列中最大数的求和”。  

把每行降序后，**第 0 列** 会保存每行的最大值，**第 1 列** 会保存每行的第二大值，依此类推。  
于是第 `k` 列的所有元素正好是所有行的第 `k` 大数的集合。  
我们只需要 **遍历每一列，取该列的最大值**（这就是第 `k` 列所有行中第 `k` 大数的最大者），把它们相加即可。

实现步骤：

1. **对每一行进行降序排序**。  
   - 类比：把每个人手里的卡片从大到小排好，方便以后直接看第几张。  
   - 排序的时间是 `O(C log C)`（每行长度是 `C`），所有行一起是 `O(R·C log C)`。  

2. **遍历列索引 `c = 0 … C-1`**，在每列里找最大的元素。  
   - 因为每行已经排好序，这一步只需要一次线性扫描 `O(R·C)`。  

3. **累计这些最大值**，得到最终分数。  

这样我们把 **每轮的 O(R·C) 扫描** 合并成 **一次 O(R·C) 的整体扫描**，而且只用了排序这一步的额外时间。  

#### 代码（Python）

```python
from typing import List

def sum_in_matrix(nums: List[List[int]]) -> int:
    """
    最优解：先把每行降序排序，然后逐列取最大值求和。
    """
    # 1) 对每行进行降序排序
    for row in nums:
        row.sort(reverse=True)          # 降序，最大值在最左侧

    R, C = len(nums), len(nums[0])
    total = 0

    # 2) 对每一列，找该列的最大值
    for c in range(C):
        col_max = 0                     # 题目保证元素非负，0 够用了
        for r in range(R):
            # nums[r][c] 已经是第 r 行第 c 大的数
            if nums[r][c] > col_max:
                col_max = nums[r][c]
        total += col_max                # 把该列的最大值加到答案

    return total
```

> **关键点注释**  
> - `row.sort(reverse=True)` 相当于把每个人的卡片从大到小排好。  
> - 在第 `c` 列遍历时，`nums[r][c]` 正好是第 `r` 行第 `c` 大的数。  
> - 只要取每列的最大值并相加，就等价于题目描述的“每轮取列最大 → 删除每行最左元素”。  

#### 复杂度  

- **时间复杂度**：`O(R·C log C)`  
  - 解释：对每行排序需要 `C log C`，共 `R` 行 → `R·C log C`。  
  - 再遍历一次矩阵 `R·C`，在数量级上仍然被 `R·C log C` 主导。  
  - 与暴力解的 `R²·C` 相比，行数不再出现平方，速度提升明显。  

- **空间复杂度**：`O(1)`（原地排序，不需要额外数组）。

## 心得  

- **核心技巧**：**先对每行降序排序，再逐列取最大值**。这把“每轮取最大”转化为“一次性取每列最大”。  
- **适用的题型**  
  1. **矩阵每列求最大/最小后求和**（如 “Maximum Sum of Columns”）。  
  2. **每行或每列的 Kth 最大/最小值**（常用排序或堆）。  
  3. **先排序后按列/行处理的模拟题**（例如 “Delete Columns to Make Sorted” 的变形）。  
- **一句话总结解题钥匙**：  
  > “把行内部的顺序固定（降序），列上的比较就能一次完成”。

## 反思  

- **第一反应**：看到“每轮都要取每列最大并删掉每行最左元素”，立刻想到**循环模拟**，于是写出了暴力解。  
- **最容易踩的坑**  
  - **矩阵非方阵**：行数和列数可能不同，循环次数一定要以行数（每行被删掉的次数）为准。  
  - **元素全为 0**：若把 `col_max` 初始值设为 `-inf` 更安全，这里利用了非负约束。  
  - **原地排序**：如果不想修改原输入，需要先拷贝一份矩阵。  
- **下次遇到类似题**，第一步应该先**思考是否可以把局部的重复操作（如每轮遍历）合并为一次性处理**，比如通过**排序、前缀和或单调结构**来一次完成。
