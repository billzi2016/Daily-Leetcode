# #2620. 计数器 / Counter

## 题目（英文原版）

**Description**

Given an integer n, return a counter function. This counter function initially returns n and then returns 1 more than the previous value every subsequent time it is called (n, n + 1, n + 2, etc).

**Examples**

**Example 1:**

```
Input: 
n = 10 
["call","call","call"]
Output: [10,11,12]
Explanation: 
counter() = 10 // The first time counter() is called, it returns n.
counter() = 11 // Returns 1 more than the previous time.
counter() = 12 // Returns 1 more than the previous time.
```

**Example 2:**

```
Input: 
n = -2
["call","call","call","call","call"]
Output: [-2,-1,0,1,2]
Explanation: counter() initially returns -2. Then increases after each sebsequent call.
```

**Constraints**

- -1000 <= n <= 1000
- 0 <= calls.length <= 1000
- calls[i] === "call"

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把当前的计数值保存到一个可以被多次访问的地方**，每次调用 `counter()` 时：

1. 把保存的值返回  
2. 再把它加 1，准备给下次调用使用  

在 Python 里，有两种常见的“保存地方”：

* **全局变量**：像在教室里张贴一块黑板，所有人都能看到并修改它。  
* **类的实例属性**：把黑板放进一个盒子（对象）里，只有打开这个盒子的人（对象的成员函数）能读写。

这里我们用 **类** 来实现，因为它的结构清晰，且不需要额外的 `nonlocal` 关键字，适合作为“暴力解”。  

#### 代码（Python）

```python
class Counter:
    """
    暴力实现：把计数值放在对象的属性 self.val 中。
    每次调用 __call__() 时返回当前值，然后自增 1。
    """
    def __init__(self, n: int):
        self.val = n                 # 初始值相当于黑板上写的数字

    def __call__(self) -> int:
        """让对象本身可以像函数一样被调用"""
        cur = self.val               # 先把当前值记下来
        self.val += 1                # 再把它加 1，准备下次返回
        return cur                   # 返回之前记下的值
```

使用示例（对应题目示例 1）：

```python
counter = Counter(10)   # 创建一个计数器，初始值 10
print(counter())        # 10
print(counter())        # 11
print(counter())        # 12
```

#### 复杂度

- **时间复杂度**：`O(1)` —— 每次调用只做常数次的读取和加法，和输入规模无关。  
- **空间复杂度**：`O(1)` —— 只需要保存一个整数 `self.val`，不随调用次数增长。

### 2. 最优解

#### 思路  

虽然上面的类实现已经是 `O(1)`，但在 Python 中还有更简洁、更“Pythonic” 的写法——**闭包（closure）**。

**闭包**可以把外层函数的局部变量“带进”内部函数，使得内部函数每次被调用时仍然可以访问并修改这些变量。可以把它想象成：

> 把计数器的黑板直接粘在函数的背后，只有这个函数自己能看到和改动它。

实现步骤：

1. 在外层函数 `counterFactory(n)` 中定义一个局部变量 `cur = n`。  
2. 在同一作用域内再定义一个内部函数 `inner()`，它会读取 `cur`、返回它，然后把 `cur` 加 1。  
3. 为了让内部函数能够修改外层的 `cur`，需要使用 `nonlocal` 关键字声明 `cur` 为“非局部变量”。  
4. 最后返回内部函数 `inner` 本身。调用者拿到的就是一个 **计数函数**，每次调用都会产生递增的结果。

这样我们只用了 **两行核心代码**，而且不需要额外的类或全局变量，代码更简洁，阅读时也更容易把“计数器”这件事和“函数本身”联系起来。

#### 代码（Python）

```python
def counterFactory(n: int):
    """
    最优实现：使用闭包把计数变量封装在函数内部。
    返回的 inner() 每次被调用都会返回当前值并自增 1。
    """
    cur = n                     # 初始计数值，类似黑板上的数字

    def inner() -> int:
        nonlocal cur            # 声明我们要使用外层的 cur，而不是新建局部变量
        result = cur           # 先把当前值保存下来准备返回
        cur += 1               # 再把它加 1，供下次调用使用
        return result          # 返回保存的旧值

    return inner                # 把内部函数本身返回给调用者
```

使用示例（对应题目示例 2）：

```python
counter = counterFactory(-2)   # 创建计数器，初始值 -2
print(counter())               # -2
print(counter())               # -1
print(counter())               # 0
print(counter())               # 1
print(counter())               # 2
```

#### 复杂度

- **时间复杂度**：`O(1)` —— 与暴力解相同，每次调用只做常数次操作。  
- **空间复杂度**：`O(1)` —— 只保存一个整数 `cur`，闭包本身占用的空间也与调用次数无关。

相比类实现，闭包的 **代码行数更少**，且不需要额外的 `self`、`__call__` 等“包装”，更符合 Python 的简洁风格。

## 心得

- **核心技巧**：闭包（closure）与 `nonlocal` 关键字的使用。  
- **适用的题型**：  
  1. 需要在多次调用之间保持状态的函数（如计数器、累加器）。  
  2. 实现惰性求值或记忆化（memoization）时的内部缓存。  
- **一句话总结解题钥匙**：把“状态”封装进函数的“背后”，用闭包让每次调用都能记住并更新它。

## 反思

- **第一反应**：直接写一个类或全局变量来保存计数，想到“每次调用都要更新”。  
- **最容易踩的坑**：  
  - 在闭包里忘记加 `nonlocal`，导致内部函数只能读取不到外层变量的最新值（会报 `UnboundLocalError`）。  
  - 没有返回内部函数本身，而是返回函数的调用结果（`return inner()`），这样就失去了计数功能。  
- **下次类似题的第一步**：先判断是否需要跨调用保持状态，若是，就考虑用 **闭包**（或类）来把状态“藏”在函数内部。这样代码会更简洁且易于维护。
