# #2710. 去除字符串末尾的零 / Remove Trailing Zeros From a String

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/remove-trailing-zeros-from-a-string/)

---

## 题目（英文原版）

**Description**

Given a positive integer num represented as a string, return the integer num without trailing zeros as a string.

**Examples**

**Example 1:**

```
Input: num = "51230100"
Output: "512301"
Explanation: Integer "51230100" has 2 trailing zeros, we remove them and return integer "512301".
```

**Example 2:**

```
Input: num = "123"
Output: "123"
Explanation: Integer "123" has no trailing zeros, we return integer "123".
```

**Constraints**

- 1 <= num.length <= 1000
- num consists of only digits.
- num doesn't have any leading zeros.

---

## 题目（中文翻译）

**题目描述**  
给定一个正整数 `num`，其以字符串形式表示，返回去掉末尾零（trailing zeros）后的整数，同样以字符串形式返回。

**示例 1**  
**输入**: `num = "51230100"`  
**输出**: `"512301"`  
**解释**: 整数 `"51230100"` 末尾有 2 个零，移除后得到整数 `"512301"`。

**示例 2**  
**输入**: `num = "123"`  
**输出**: `"123"`  
**解释**: 整数 `"123"` 没有末尾零，直接返回整数 `"123"`。

**约束条件**  
- `1 <= num.length <= 1000`  
- `num` 仅由数字字符组成。  
- `num` 不含前导零（leading zeros）。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是从字符串的最右边往左找，直到遇到第一个不是 `'0'` 的字符为止。  
- **使用的数据结构**：只需要原始的 **字符串**（就像一排写好的数字卡片），我们用一个指针（下标）从右往左“走”。  
- **为什么正确**：题目要求去掉所有**尾随的**零，也就是在最后一个非零数字之后的所有零。把指针停在最后一个非零数字上，然后把它左边（包括它）全部保留下来，就是答案。  
- **时间/空间复杂度**：我们最多会检查每个字符一次，时间是 `O(n)`（`n` 为字符串长度），空间只用了常数个变量，`O(1)`。  
  - 大白话解释：如果字符串长 1000，最多检查 1000 次；不管多大，额外占用的内存几乎不变（只需要几个整数下标）。

#### 代码（Python）

```python
def removeTrailingZeros_brute(num: str) -> str:
    """
    暴力思路：从右往左找到第一个非 '0' 的位置，
    然后返回该位置左侧（含该位置）的子串。
    """
    i = len(num) - 1               # i 是指向字符串最右边的指针
    # 当指针还在范围内且当前字符是 '0' 时，继续左移
    while i >= 0 and num[i] == '0':
        i -= 1                      # 向左走一步，跳过一个零
    # i < 0 说明全是零（但根据约束不会出现），否则返回前 i+1 个字符
    return num[:i + 1] if i >= 0 else ""   # 这里返回空串仅作安全防护
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 需要检查最多 `n` 次字符，`n` 是字符串长度。  
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和输入大小无关。

---

### 2. 最优解

#### 思路  

暴力解已经是 `O(n)`，已经是线性时间的下界，无法再快到 `O(log n)` 或 `O(1)`。  
但是我们可以利用 Python 标准库提供的 **字符串方法** `rstrip`，它一次性把指定字符（这里是 `'0'`）从右端全部去掉，内部实现同样是线性扫描，只是写法更简洁、可读性更好。  

- **慢在哪里**：暴力解用 `while` 循环手动移动指针，逻辑稍显繁琐。  
- **优化**：直接使用 `num.rstrip('0')`，让底层实现帮我们完成同样的工作。  
- **核心技巧**：**字符串的右裁剪**（right strip），相当于把字符串当作一本书，把书的“尾页”上全是空白页（零）时，把这些空白页全部撕掉。

#### 代码（Python）

```python
def removeTrailingZeros_opt(num: str) -> str:
    """
    使用字符串的 rstrip 方法一次性删除右侧所有 '0'。
    rstrip 会从右向左遍历，遇到不是指定字符就停下。
    """
    # rstrip('0') → 把右端连续的 '0' 全部去掉，返回新的字符串
    return num.rstrip('0')
```

#### 复杂度  

- **时间复杂度**：`O(n)` — `rstrip` 仍然需要遍历一次字符，但代码更简洁。  
  - 与暴力解相比，常数因子更小（底层实现是 C 语言，速度更快）。  
- **空间复杂度**：`O(1)` — 只创建了一个返回的新字符串（不计入额外空间），不需要额外的列表或字典。

## 心得

- **核心技巧**：从右侧剔除指定字符（右裁剪），对应的工具是 `rstrip`。  
- **适用的题型**：  
  1. 删除字符串末尾的特定字符（如去掉 URL 末尾的 `/`）。  
  2. 处理数字字符串的前导/尾随零（如 `"0012300"` → 去掉前导零或尾随零）。  
  3. 需要对字符串做“清洗”操作的题目（如去掉多余的空格、标点等）。  
- **一句话总结**：**找出最后一个非零位置或直接使用 `rstrip`，即可一次性去除所有尾随零。**

## 反思

- **第一反应**：看到“去掉尾随零”，立刻想到从右往左扫描，找到第一个非零数字。  
- **最容易踩的坑**：  
  - 忘记字符串可能全部是零（虽然本题约束不出现，但实际面试中要防御）。  
  - 直接 `int(num)` 再 `str()`，会把前导零也去掉，违背“只能去掉尾随零”。  
- **下次遇到同类题**：第一步先想 **“从哪端裁剪？”**，如果是尾部就考虑 `rstrip`，如果是头部就考虑 `lstrip`，再决定是否需要手动遍历。
