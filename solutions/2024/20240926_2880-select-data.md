## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  
最直接的办法就是把 `students` 表（在 Python 中用 `pandas.DataFrame` 表示）一行一行地遍历，手动判断每一行的 `student_id` 是否等于 `101`，如果相等就把该行的 `name`、`age` 取出来放进结果。  

- **用到的数据结构**：`DataFrame` 类似一张电子表格，`iterrows()` 就像我们把表格的每一行拆下来，一张张“纸”检查。  
- **为什么正确**：只要把所有行都检查一遍，必定不会漏掉 `student_id = 101` 的那一行，找到后把需要的两列返回即可。  

#### 代码（Python）  
```python
import pandas as pd

def select_brute_force(students: pd.DataFrame) -> pd.DataFrame:
    """
    暴力遍历每一行，手动筛选 student_id == 101
    返回只包含 name、age 两列的 DataFrame
    """
    # 用一个空列表暂存符合条件的记录
    rows = []

    # iterrows() 会把每一行拆成 (index, Series) 的形式
    for _, row in students.iterrows():          # <-- 遍历每一行
        if row['student_id'] == 101:            # <-- 判断是否是目标学生
            # 只取 name 和 age 两列，存进列表
            rows.append({'name': row['name'], 'age': row['age']})

    # 把收集好的字典列表转换成 DataFrame 并返回
    return pd.DataFrame(rows)
```

#### 复杂度  
- **时间复杂度**：`O(n)`，其中 `n` 是表格的行数。我们必须检查每一行一次，像逐个翻书找目标页。  
- **空间复杂度**：`O(1)`（不计输出空间）。除了存放答案的极小列表外，额外使用的内存基本不随 `n` 增长。

---

### 2. 最优解  

#### 思路  
从暴力解可以看到，遍历每一行是“慢点”。`pandas` 本身提供了 **向量化过滤**（类似一次性在整张表上做筛选），它在底层使用 C 实现，速度远快于 Python 循环。  

优化的关键一步是：  

1. **行过滤**：`students[students['student_id'] == 101]`  
   - 这里把整列 `student_id` 与 101 做比较，得到一个布尔 Series（True 表示该行满足条件）。  
2. **列过滤**：在得到的子 DataFrame 上再只保留 `name`、`age` 两列：`[['name', 'age']]`  

这两步可以合在一行写完，既简洁又高效。  

> **类比**：把表格想象成一张大网，行过滤相当于把网的某些格子挑出来（只保留满足条件的格子），列过滤相当于把网的宽度缩窄，只留下我们关心的两根线。

#### 代码（Python）  
```python
import pandas as pd

def select_optimal(students: pd.DataFrame) -> pd.DataFrame:
    """
    使用 pandas 的向量化操作一次性完成行、列过滤。
    返回仅包含 name、age 两列且 student_id == 101 的记录。
    """
    # 第一步：行过滤 → 只保留 student_id 为 101 的行
    # 第二步：列过滤 → 只取 name、age 两列
    result = students[students['student_id'] == 101][['name', 'age']]
    return result.reset_index(drop=True)   # 重置索引，使输出更整洁
```

#### 复杂度  
- **时间复杂度**：`O(n)`，但由于底层是 C 实现，实际运行速度常数因子比手写循环小很多。可以把它想成“一次性在所有行上做批处理”，而不是“一行行手动检查”。  
- **空间复杂度**：`O(k)`，其中 `k` 是满足条件的行数（本题最多为 1），因为只会复制这些行到新 DataFrame；不随总行数 `n` 线性增长。

## 心得  

- **核心技巧**：利用 `pandas` 的布尔索引（行过滤） + 列切片（列过滤）实现“一次性选取”。  
- **适用的题型**：  
  1. “筛选符合条件的记录并只返回部分列”——如 `SELECT name FROM table WHERE age > 20`。  
  2. “多条件组合筛选”——`df[(df['col1'] > 0) & (df['col2'] == 'X')]`。  
  3. “基于某列的唯一值抽取对应行”——`df[df['id'].isin([101, 202])]`。  
- **一句话总结解题钥匙**：**行过滤 + 列过滤 = 直接拿到目标子表**。

## 反思  

- **第一反应**：看到 “select name and age where student_id = 101”，自然想到先找行再取列。  
- **最容易踩的坑**：  
  - 忘记在列过滤前先完成行过滤，导致返回整张表。  
  - 输出的 DataFrame 索引仍然是原表的索引，展示时会出现“空洞”，需要 `reset_index(drop=True)` 整理。  
- **下次类似题的第一步**：**先写布尔条件过滤行**，确认得到的子表后，再用 `[['col1', 'col2']]` 取所需列。这样思路清晰、代码也最短。
