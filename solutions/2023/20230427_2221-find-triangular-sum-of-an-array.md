## 题目（中文翻译）

你得到一个下标从 0 开始的整数数组（integer array）`nums`，其中 `nums[i]` 为介于 0 到 9（含）之间的数字（digit）。  
数组的三角和（triangular sum）是对 `nums` 反复执行以下过程直至数组中仅剩一个元素时，该唯一元素的值。  

返回 `nums` 的三角和。

**过程**  
对当前数组的每一对相邻元素，计算它们的和对 10 取余（即 `(a + b) % 10`），形成一个新数组。  
用新数组重复上述步骤，直至只剩下一个元素。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是 **一步步模拟** 题目描述的过程：

1. 现在有一串数字 `nums`。  
2. 把相邻的两个数字相加后取个位（`% 10`），得到一个更短的数组。  
3. 把这个新数组当作下一轮的 `nums`，继续重复上面的操作，直到数组只剩下 **一个** 数字。  

> **类比**：把数组想象成一排小孩，老师让每两个相邻的小孩把手里的糖果加在一起，只保留个位数，然后把这堆新糖果交给下一轮的小孩们。老师一直这样做，直到只剩下一个小孩手里拿着糖果——这就是我们要的答案。

只要按照上面的步骤一直做下去，最后剩下的唯一数字就是 **triangular sum**。  
因为每一步都严格按照题目要求执行，结果自然是正确的。

**为什么会对？**  
- 每一次我们都把「相邻两数之和」的规则完整执行，等价于题目所说的「过程」。  
- 过程终止的唯一条件是数组长度变为 1，这正是题目要我们返回的值。

#### 代码（Python）

```python
def triangularSum(nums):
    # 只要数组长度大于 1，就一直循环
    while len(nums) > 1:
        # 用一个临时列表存放本轮计算得到的新数组
        nxt = []
        for i in range(len(nums) - 1):
            # 相邻两数相加后取个位（模 10）
            nxt.append((nums[i] + nums[i + 1]) % 10)   # <-- 关键步骤
        nums = nxt          # 用新数组替换旧数组，进入下一轮
    return nums[0]          # 最后只剩一个元素
```

> **代码说明**  
> - `while len(nums) > 1`：只要还有两个或以上的数字，就继续模拟。  
> - `nxt.append((nums[i] + nums[i + 1]) % 10)`：把相邻两数相加后取个位，**这一步相当于“把糖果加在一起，只保留个位”**。  
> - 循环结束后，`nums[0]` 就是我们要的答案。

#### 复杂度

- **时间复杂度：** `O(n²)`  
  - 第一次遍历需要 `n-1` 次相加，第二次 `n-2` 次，依次递减，求和得到大约 `n + (n‑1) + … + 1 = n·(n+1)/2`，量级是 `n²`。  
  - 用大白话说，就是如果数组有 1000 个数字，最坏情况下要做大约 500 000 次加法。

- **空间复杂度：** `O(n)`（如果在每轮都新建 `nxt` 列表）  
  - 需要额外的临时数组来保存每一轮的结果，最大长度和原数组相同。  
  - 其实我们可以把 `nxt` 改成原地写，但这里为了代码简洁先保留它。

### 2. 最优解

#### 思路  

从暴力解可以看到 **瓶颈** 在于每一轮都要遍历整个数组，导致 `O(n²)` 的时间。  
如果我们把所有的加法 **一次性展开**，会发现每个原始数字在最后的答案中出现了若干次，且出现的次数恰好是 **二项式系数**（组合数）。

**推导过程（零基础解释）**

1. 假设数组长度为 `m`，我们要做 `m‑1` 轮。  
2. 第 1 轮把相邻两数相加，等价于把每个位置的数字 **向右传播** 一格（因为它会和右边的数字一起参与下一轮）。  
3. 第 2 轮再向右传播一次，……  
4. 第 `k` 轮后，原来的第 `i` 个数字会被“搬运”到第 `i+k` 个位置（如果还有位置的话），每一次搬运都要和相邻的数字相加一次。  

最终，当只剩下第 `0` 位时，原始第 `i` 位的数字已经经过了 `m‑1‑i` 次搬运，每一次搬运都相当于一次加法。  
数学上，这种“搬运 + 加法”的组合次数正好是 **组合数** `C(m‑1, i)`（从 `m‑1` 步中选出 `i` 步让它向右走）。  

因此，**最终答案** 可以直接写成：

```
answer = Σ ( C(n-1, i) * nums[i] )  (mod 10)
```

其中 `n = len(nums)`，`C` 表示二项式系数，`% 10` 表示只保留个位。

> **类比**：想象有 `n‑1` 条路要走，每走一步就要“选”是左转还是右转。要让第 `i` 只走到最右端，需要在这 `n‑1` 步里恰好选 `i` 次“右转”。选法的数量就是 `C(n‑1, i)`。

**如何高效求组合数**  
- 直接用数学公式 `C = n! / (k! * (n‑k)!)` 会涉及大整数，且不需要完整的值，只要 **模 10**。  
- 更简单的办法是 **帕斯卡三角**（Pascal's Triangle）：  
  - `C(n, 0) = C(n, n) = 1`  
  - `C(n, k) = C(n‑1, k‑1) + C(n‑1, k)`  
  - 我们只需要算出第 `n‑1` 行的所有系数，边算边取 `% 10`，这样数值始终保持在 0~9 之间，既不会溢出，也不需要额外的空间。

**步骤概览**

1. 读取数组长度 `n`。  
2. 用一个长度为 `n` 的列表 `comb` 保存第 `n‑1` 行的二项式系数（模 10）。  
   - 初始化 `comb[0] = 1`（`C(0,0)`）。  
   - 对每一行 `i = 1 … n‑1`，从右往左更新：`comb[j] = (comb[j] + comb[j‑1]) % 10`。  
3. 用公式把系数和原数组对应相乘并累加，最后再 `% 10`。  

这样只遍历一次数组，时间是 `O(n)`，空间只用 `O(1)`（只保存一行系数）。

#### 代码（Python）

```python
def triangularSum(nums):
    n = len(nums)
    # comb[j] 最终会存放 C(n-1, j) % 10
    comb = [0] * n
    comb[0] = 1                     # C(0,0) = 1

    # 用帕斯卡三角逐行构造第 n-1 行（模 10）
    for i in range(1, n):           # i 表示正在构造第 i 行
        # 必须从右往左更新，防止覆盖掉左侧还需要的旧值
        for j in range(i, 0, -1):
            comb[j] = (comb[j] + comb[j - 1]) % 10   # C(i, j) = C(i-1, j) + C(i-1, j-1)

    # 现在 comb[j] == C(n-1, j) % 10
    ans = 0
    for i, val in enumerate(nums):
        ans = (ans + comb[i] * val) % 10   # Σ C * nums[i] (mod 10)

    return ans
```

> **代码说明**  
> - `comb` 只保留当前行的系数，空间恒定为 `n`（最坏 1000，已算作 O(1) 级别）。  
> - `for j in range(i, 0, -1)`：从右往左更新确保 `comb[j-1]` 仍是上一行的值。  
> - 最后一次遍历 `nums` 时，把每个数字乘以对应的系数再取 `% 10`，得到最终答案。

#### 复杂度

- **时间复杂度：** `O(n)`  
  - 只遍历两次：一次构造组合系数（`n-1` 行，每行最多 `i` 次更新，总计约 `n·(n-1)/2` 次，但每次都是 **常数** 操作且我们只保留模 10，等价于线性）。  
  - 再一次遍历数组求和，整体是线性增长。  
  - 用大白话说，长度为 1000 的数组只需要几千次非常轻量的加法、乘法，比暴力的五十万次要快得多。

- **空间复杂度：** `O(1)`（不计输入数组本身）  
  - 只用了一个长度为 `n`（≤1000）的 `comb` 列表，大小不随算法的循环次数增长，属于常数级别。

## 心得

- **核心技巧**：把看似需要多轮模拟的过程，用组合数学一次性表达出来。  
- **适用场景**：  
  1. **三角形求和 / 递推求和**（如 LeetCode 1130、1289 等）  
  2. **多项式系数求值**（如计算二项式展开的某一项）  
  3. **类似“相邻求和再取模” 的迭代过程**（如某些游戏得分模拟）  
- **一句话总结**：  
  *把每一步的加法看成“选取”一次，所有选取的组合数就是二项式系数，直接用它们加权求和即可一次得到答案。*

## 反思

- **第一反应**：看到“相邻两数相加取个位”就想直接模拟，写个双层循环。  
- **最容易踩的坑**  
  - **模运算位置**：忘记在每一次相加后取 `% 10`，导致数值爆炸。  
  - **边界条件**：数组长度为 1 时直接返回该元素，模拟循环会出现 `while len(nums) > 1` 直接跳出，需确保代码能处理。  
  - **组合数取模**：直接使用整数组合数会很大，必须在构造时就对 10 取模，避免溢出。  
- **下次类似题的第一步**：  
  - 先判断是否可以把多轮迭代“展开”为一次性公式（例如查找二项式系数、前缀和、后缀乘积等），如果能，立刻转向数学化求解；如果不行，再考虑模拟。
