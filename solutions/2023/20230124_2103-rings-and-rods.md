# #2103. **环与杆** / Rings and Rods

## 题目（英文原版）

**Description**

There are n rings and each ring is either red, green, or blue. The rings are distributed across ten rods labeled from 0 to 9.
You are given a string rings of length 2n that describes the n rings that are placed onto the rods. Every two characters in rings forms a color-position pair that is used to describe each ring where:
For example, "R3G2B1" describes n == 3 rings: a red ring placed onto the rod labeled 3, a green ring placed onto the rod labeled 2, and a blue ring placed onto the rod labeled 1.
Return the number of rods that have all three colors of rings on them.

**Examples**

**Example 1:**

```
Input: rings = "B0B6G0R6R0R6G9"
Output: 1
Explanation: 
- The rod labeled 0 holds 3 rings with all colors: red, green, and blue.
- The rod labeled 6 holds 3 rings, but it only has red and blue.
- The rod labeled 9 holds only a green ring.
Thus, the number of rods with all three colors is 1.
```

**Example 2:**

```
Input: rings = "B0R0G0R9R0B0G0"
Output: 1
Explanation: 
- The rod labeled 0 holds 6 rings with all colors: red, green, and blue.
- The rod labeled 9 holds only a red ring.
Thus, the number of rods with all three colors is 1.
```

**Example 3:**

```
Input: rings = "G4"
Output: 0
Explanation: 
Only one ring is given. Thus, no rods have all three colors.
```

**Constraints**

- rings.length == 2 * n
- 1 <= n <= 100
- rings[i] where i is even is either 'R', 'G', or 'B' (0-indexed).
- rings[i] where i is odd is a digit from '0' to '9' (0-indexed).

## 题目（中文翻译）

有 `n` 个环（ring），每个环的颜色只能是红色、绿色或蓝色。这些环分布在编号为 `0` 到 `9` 的十根杆（rod）上。  

给定一个长度为 `2n` 的字符串 `rings`，用于描述放置在杆上的环。`rings` 中的每两个字符构成一个 **颜色‑位置 对 (color-position pair)**，表示一个环的颜色及其所在的杆，例如 `"R3G2B1"` 描述了 `n == 3` 个环：一个红色环放在编号为 `3` 的杆上，一个绿色环放在编号为 `2` 的杆上，一个蓝色环放在编号为 `1` 的杆上。  

返回拥有全部三种颜色环的杆的数量。

---

**示例 1**  
**输入**: `rings = "B0B6G0R6R0R6G9"`  
**输出**: `1`  
**解释**:  
- 编号为 `0` 的杆上有三环，颜色齐全：红、绿、蓝。  
- 编号为 `6` 的杆上也有三环，但仅有红色和蓝色。  
- 编号为 `9` 的杆上只有一枚绿色环。  
因此，仅有 `1` 根杆同时拥有三种颜色的环。

**示例 2**  
**输入**: `rings = "B0R0G0R9R0B0G0"`  
**输出**: `1`  
**解释**:  
- 编号为 `0` 的杆上共有 `6` 枚环，颜色齐全：红、绿、蓝。  
- 编号为 `9` 的杆上只有一枚红色环。  
所以满足条件的杆数量为 `1`。

**示例 3**  
**输入**: `rings = "G4"`  
**输出**: `0`  
**解释**: 只给出一枚环，因而没有任何杆同时拥有三种颜色。

---

**约束条件**

- `rings.length == 2 * n`
- `1 <= n <= 100`
- 索引为偶数的 `rings[i]` 为字符 `'R'`、`'G'` 或 `'B'`（表示颜色）。
- 索引为奇数的 `rings[i]` 为字符 `'0'` 到 `'9'` 之间的数字（表示杆的编号）。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**逐根棒子检查**：  
- 棒子编号只有 0~9，十根棒子是固定且很少的。  
- 对于每根棒子 `i`，我们把整个 `rings` 串从头到尾遍历一遍，找出所有落在这根棒子上的环，并记录它们的颜色。  
- 颜色可以用三个布尔变量 `hasR`、`hasG`、`hasB` 来保存，类似“查字典”，字典的 **key** 是颜色，**value** 是“这根棒子上有没有这种颜色”。  
- 当遍历完后，如果 `hasR && hasG && hasB` 同时为真，说明这根棒子上已经出现了红、绿、蓝三种颜色，就把答案加一。

这种方法之所以一定能得到正确答案，是因为我们 **对每根棒子都完整检查了一遍**，不管环的顺序如何，都能发现所有颜色。

#### 代码（Python）

```python
def countPoints(rings: str) -> int:
    ans = 0                       # 记录满足条件的棒子数量
    # 共有 10 根棒子，编号 0~9
    for rod in map(str, range(10)):          # 把数字 0~9 转成字符，方便和 rings 中的数字比较
        hasR = hasG = hasB = False           # 三种颜色的标记，初始都为 False
        # 逐个环检查，这里步长是 2，因为每两个字符描述一个环
        for i in range(0, len(rings), 2):
            color = rings[i]                 # 环的颜色，'R' / 'G' / 'B'
            pos   = rings[i + 1]              # 环所在的棒子编号，字符形式
            if pos == rod:                    # 只关心当前遍历的这根棒子
                if color == 'R':
                    hasR = True
                elif color == 'G':
                    hasG = True
                else:                         # color == 'B'
                    hasB = True
        # 如果三种颜色都出现过，就计数
        if hasR and hasG and hasB:
            ans += 1
    return ans
```

#### 复杂度

- **时间复杂度**：`O(10 * n)` → 实际上是 `O(n)`，因为 10 是常数。  
  用大白话说，就是我们要遍历 **10 次** 整个字符串，每次最多看 `2n` 个字符，`n` 最多 100，完全可以接受。
- **空间复杂度**：`O(1)` → 只用了几个布尔变量和常数级的计数器，和输入规模无关。

### 2. 最优解

#### 思路  

暴力解的“慢点”在于**每根棒子都要把整个字符串扫一遍**，虽然在本题里 10 次循环已经很快，但我们可以把这十次扫描**合并成一次**，做到“一遍遍历，顺手记”。思路如下：

1. **一次遍历** `rings`（步长 2），每读到一对 `(color, rod)`，就在一个哈希表（字典）里记录这根棒子已经出现了哪些颜色。  
   - 哈希表的 **key**：棒子编号（字符 `'0'`~`'9'`），相当于“字典的词”。  
   - **value**：一个集合 `set`，里面放出现过的颜色（`'R'`、`'G'`、`'B'`），相当于“词典的页码”。  
2. 遍历结束后，只需要统计字典中 **value 集合大小为 3**（即包含 R、G、B 三种颜色）的键的个数，即为答案。

这样我们只扫一次字符串，时间更优；同时使用集合可以天然去重，代码也更简洁。

#### 代码（Python）

```python
def countPoints(rings: str) -> int:
    # 用字典记录每根棒子出现过的颜色集合
    rod_colors = {}                     # key: rod (字符), value: set of colors
    for i in range(0, len(rings), 2):
        color = rings[i]                # 'R' / 'G' / 'B'
        rod   = rings[i + 1]            # '0' ~ '9'
        # 如果这根棒子还没出现过，先创建一个空集合
        if rod not in rod_colors:
            rod_colors[rod] = set()
        rod_colors[rod].add(color)      # 把颜色加入集合，自动去重

    # 统计集合里恰好有 3 种颜色的棒子数量
    ans = sum(1 for colors in rod_colors.values() if len(colors) == 3)
    return ans
```

#### 复杂度

- **时间复杂度**：`O(n)` → 只遍历一次 `rings`，每次 O(1) 的字典/集合操作。比暴力的 “10 次遍历” 少了一个常数因子。  
- **空间复杂度**：`O(10)` → 最多记录 10 根棒子的颜色集合，每根最多存 3 条记录，整体空间是常数级的。

## 心得

- **核心技巧**：使用哈希表（字典）+ 集合一次遍历统计。  
- **适用题型**：  
  1. “统计每个分组出现的不同元素”类（如 LeetCode 1022 — **Sum of Root To Leaf Binary Numbers** 的分组统计思路）。  
  2. “检查是否同时出现多种属性”类（如 LeetCode 1124 — **Longest Well‑Performing Interval** 中的前缀和 + 哈希表）。  
- **解题钥匙**：**把“多次扫描同一数据”合并成“一次扫描”，并用合适的数据结构（字典、集合）在遍历时“顺手记录”。

## 反思

- **第一反应**：看到“10 根棒子、颜色三种”，立刻想到对每根棒子单独检查——也就是暴力思路。  
- **最容易踩的坑**：  
  - 忘记把棒子编号当作字符处理，导致 `'0'` 与整数 `0` 比较出错。  
  - 只检查出现的棒子，而没有考虑可能根本没有出现的棒子（它们自然不满足条件）。  
- **下次遇到同类题**：第一步先思考**“能否一次遍历把所有信息都收集起来？”**，如果可以，就立刻构造哈希表或数组来累计信息。这样往往能直接得到最优解。
