## 题目（英文原版）

**Description**

A Bitset is a data structure that compactly stores bits.
Implement the Bitset class:

**Examples**

**Example 1:**

```
Input
["Bitset", "fix", "fix", "flip", "all", "unfix", "flip", "one", "unfix", "count", "toString"]
[[5], [3], [1], [], [], [0], [], [], [0], [], []]
Output
[null, null, null, null, false, null, null, true, null, 2, "01010"]

Explanation
Bitset bs = new Bitset(5); // bitset = "00000".
bs.fix(3);     // the value at idx = 3 is updated to 1, so bitset = "00010".
bs.fix(1);     // the value at idx = 1 is updated to 1, so bitset = "01010". 
bs.flip();     // the value of each bit is flipped, so bitset = "10101". 
bs.all();      // return False, as not all values of the bitset are 1.
bs.unfix(0);   // the value at idx = 0 is updated to 0, so bitset = "00101".
bs.flip();     // the value of each bit is flipped, so bitset = "11010". 
bs.one();      // return True, as there is at least 1 index with value 1.
bs.unfix(0);   // the value at idx = 0 is updated to 0, so bitset = "01010".
bs.count();    // return 2, as there are 2 bits with value 1.
bs.toString(); // return "01010", which is the composition of bitset.
```

**Constraints**

- 1 <= size <= 105
- 0 <= idx <= size - 1
- At most 105 calls will be made in total to fix, unfix, flip, all, one, count, and toString.
- At least one call will be made to all, one, count, or toString.
- At most 5 calls will be made to toString.

## 题目（中文翻译）

位集合（Bitset）是一种紧凑存储二进制位的数据结构。请实现 `Bitset` 类，使其能够高效地完成以下操作。

### 设计要求
实现 `Bitset` 类，使其支持以下方法（构造函数除外）：

- `Bitset(int size)`：创建一个长度为 `size` 的位集合，初始所有位均为 `0`（即 `"000…0"`）。
- `void fix(int idx)`：将下标 `idx` 处的位设置为 `1`。
- `void unfix(int idx)`：将下标 `idx` 处的位设置为 `0`。
- `void flip()`：将位集合中的所有位取反，即 `0` 变 `1`，`1` 变 `0`。
- `boolean all()`：若所有位均为 `1`，返回 `true`；否则返回 `false`。
- `boolean one()`：若至少有一位为 `1`，返回 `true`；否则返回 `false`。
- `int count()`：返回位集合中值为 `1` 的位的个数。
- `String toString()`：返回位集合的二进制字符串表示（从下标 `0` 到 `size‑1` 的顺序），例如 `size = 5` 时返回 `"01010"`。

### 示例

```text
示例 1:
输入
["Bitset", "fix", "fix", "flip", "all", "unfix", "flip", "one", "unfix", "count", "toString"]
[[5], [3], [1], [], [], [0], [], [], [0], [], []]
输出
[null, null, null, null, false, null, null, true, null, 2, "01010"]
```

**解释**
```java
Bitset bs = new Bitset(5); // 位集合 = "00000"
bs.fix(3);     // 将下标 3 处的位设为 1，位集合变为 "00010"
bs.fix(1);     // 将下标 1 处的位设为 1，位集合变为 "01010"
bs.flip();    // 所有位取反，位集合变为 "10101"
bs.all();     // 不是所有位都是 1，返回 false
bs.unfix(0);  // 将下标 0 处的位设为 0，位集合变为 "00101"
bs.flip();    // 再次取反，位集合变为 "11010"
bs.one();     // 至少有一位是 1，返回 true
bs.unfix(0);  // 将下标 0 处的位设为 0，位集合变为 "01010"
bs.count();   // 位集合中有 2 个 1，返回 2
bs.toString(); // 返回字符串 "01010"
```

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把整个 `Bitset` 当成一个长度为 `size` 的 **数组**（或列表），每个位置上存 `0` 或 `1`。  
- **fix(idx)**：把 `bits[idx]` 设为 `1`。  
- **unfix(idx)**：把 `bits[idx]` 设为 `0`。  
- **flip()**：把数组里所有的 `0` 变成 `1`、`1` 变成 `0`（相当于遍历一遍数组并取反）。  
- **all()**：检查数组里是否全部都是 `1`（遍历一次，只要有一个 `0` 就返回 `False`）。  
- **one()**：检查数组里是否至少有一个 `1`（遍历一次，只要出现 `1` 就返回 `True`）。  
- **count()**：把数组里所有的 `1` 加起来（遍历一次累加）。  
- **toString()**：把数组转成字符串 `"01001"`（遍历一次拼接）。  

> 类比：把 `Bitset` 想成一本小册子，每一页只能写 `0` 或 `1`。我们直接打开册子，把对应页码的内容改掉或读出来，最直观但不够高效。

这种做法 **一定能得到正确答案**，因为我们把题目要求的每一个操作都完整地模拟了一遍。

#### 代码（Python）

```python
class Bitset:
    def __init__(self, size: int):
        # 用列表保存每个位，初始全部为 0
        self.bits = [0] * size
        self.size = size

    def fix(self, idx: int) -> None:
        # 把第 idx 位设为 1
        self.bits[idx] = 1

    def unfix(self, idx: int) -> None:
        # 把第 idx 位设为 0
        self.bits[idx] = 0

    def flip(self) -> None:
        # 把所有位取反，需要遍历整个列表
        for i in range(self.size):
            self.bits[i] ^= 1   # 0->1, 1->0

    def all(self) -> bool:
        # 是否全部为 1，只要出现 0 就返回 False
        for b in self.bits:
            if b == 0:
                return False
        return True

    def one(self) -> bool:
        # 是否至少有一个 1，只要出现 1 就返回 True
        for b in self.bits:
            if b == 1:
                return True
        return False

    def count(self) -> int:
        # 统计 1 的个数
        total = 0
        for b in self.bits:
            total += b
        return total

    def toString(self) -> str:
        # 把列表转成字符串
        return ''.join(str(b) for b in self.bits)
```

#### 复杂度

- **时间复杂度**  
  - `fix` / `unfix`：`O(1)`（只改动一个位置）  
  - `flip` / `all` / `one` / `count` / `toString`：`O(n)`，其中 `n = size`。  
    大白话：如果 `size` 是 10 万，`flip` 要走 10 万步才能把所有位都翻过去。

- **空间复杂度**  
  - `O(n)`，因为我们用了一个长度为 `size` 的数组来存每一位的值。

> 这套实现虽然直观，但在最坏情况下（比如大量 `flip`、`count`、`toString` 调用）会让程序跑得很慢，尤其当 `size` 达到 `10⁵` 时，`O(n)` 的操作会接近时间限制。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈** 出在 `flip`、`all`、`one`、`count`、`toString` 这些需要遍历整个数组的操作。  
我们要把这些遍历次数 **降到常数级**（`O(1)`），只在必须输出全部位时（`toString`）才遍历一次。

关键观察：

1. **翻转操作本质上是“整体取反”**，它对每一位的影响是相同的。  
   - 我们可以用一个布尔变量 `rev`（或 `flipped`）记录当前是否被整体翻转过。  
   - 当 `rev = False` 时，数组里真实的值就是我们保存的 `bits[i]`；  
   - 当 `rev = True` 时，真实值应当是 `bits[i]` 的相反数（`1 - bits[i]`）。

2. **fix / unfix 需要先把“真实值”写成我们想要的**。  
   - 例如在 `rev = True` 的情况下，要把第 `i` 位设为 `1`（真实值），我们实际上需要把 `bits[i]` 设为 `0`（因为最终会整体再取反一次）。

3. **统计 1 的个数**：  
   - 维护一个变量 `cnt`，始终记录 **当前真实的 1 的数量**。  
   - `fix`、`unfix`、`flip` 时相应增减 `cnt`，这样 `count()`、`all()`、`one()` 都能在 `O(1)` 内直接返回结果。

实现细节：

| 操作 | 需要做的事 | 代码要点 |
|------|-----------|----------|
| `fix(idx)` | 如果真实值已经是 1，什么也不做；否则把对应存储位改成让真实值为 1，同时 `cnt += 1`。 | `if self._real(idx) == 0: self.bits[idx] = 1 if not self.rev else 0; self.cnt += 1` |
| `unfix(idx)` | 同理，如果真实值已经是 0，跳过；否则改成让真实值为 0，`cnt -= 1`。 | `if self._real(idx) == 1: self.bits[idx] = 0 if not self.rev else 1; self.cnt -= 1` |
| `flip()` | 整体翻转只需要把 `rev` 取反，同时 `cnt = size - cnt`（因为 1 变成 0，0 变成 1）。 | `self.rev = not self.rev; self.cnt = self.size - self.cnt` |
| `all()` | 只要 `cnt == size` 即可。 | `return self.cnt == self.size` |
| `one()` | 只要 `cnt > 0` 即可。 | `return self.cnt > 0` |
| `count()` | 直接返回 `cnt`。 | `return self.cnt` |
| `toString()` | 必须遍历一次，但此时只需根据 `rev` 把每个存储位转换成真实位即可。 | `return ''.join(str(self._real(i)) for i in range(self.size))` |

其中 `_real(i)` 是一个小辅助函数，用来返回第 `i` 位的 **真实值**（考虑了 `rev`）：

```python
def _real(self, i):
    return self.bits[i] ^ self.rev   # 当 rev 为 True 时会自动取反
```

> 类比：把 `rev` 想成“灯光开关”。灯光本身的开关状态保存在 `bits`，而 `rev` 表示我们把整个房间的灯都反向了。要判断某盏灯现在亮不亮，只需要看它的原始开关 (`bits[i]`) 再加上房间整体的灯光状态 (`rev`)。

#### 代码（Python）

```python
class Bitset:
    def __init__(self, size: int):
        # 保存每个位的原始状态（未考虑整体翻转），全部初始化为 0
        self.bits = [0] * size
        self.size = size
        self.cnt = 0          # 真实的 1 的个数
        self.rev = False      # 是否整体翻转过一次（相当于全局取反）

    def _real(self, i: int) -> int:
        """
        返回第 i 位的真实值。
        bits[i] 保存的是“未翻转时的值”，
        如果 rev 为 True，则真实值需要再取反一次。
        """
        return self.bits[i] ^ self.rev   # 异或实现取反

    def fix(self, idx: int) -> None:
        # 若真实值已经是 1，直接返回
        if self._real(idx) == 1:
            return
        # 需要把存储位改成让真实值为 1
        # 当 rev 为 False 时，bits[idx] 设为 1；当 rev 为 True 时，bits[idx] 设为 0
        self.bits[idx] = 1 if not self.rev else 0
        self.cnt += 1                     # 1 的数量加一

    def unfix(self, idx: int) -> None:
        # 若真实值已经是 0，直接返回
        if self._real(idx) == 0:
            return
        # 把存储位改成让真实值为 0
        self.bits[idx] = 0 if not self.rev else 1
        self.cnt -= 1                     # 1 的数量减一

    def flip(self) -> None:
        # 整体翻转，只需要翻转标记，并把 1 的计数变成 size - cnt
        self.rev = not self.rev
        self.cnt = self.size - self.cnt

    def all(self) -> bool:
        # 全部为 1 当且仅当 cnt 等于 size
        return self.cnt == self.size

    def one(self) -> bool:
        # 至少有一个 1 当且仅当 cnt > 0
        return self.cnt > 0

    def count(self) -> int:
        # 直接返回已维护好的计数
        return self.cnt

    def toString(self) -> str:
        # 只能在这里遍历一次，返回每个位的真实值组成的字符串
        return ''.join(str(self._real(i)) for i in range(self.size))
```

#### 复杂度

- **时间复杂度**  
  - `fix` / `unfix` / `flip` / `all` / `one` / `count`：`O(1)`（只做常数步操作）。  
    > 与暴力解相比，这里不再需要遍历整个数组，速度提升了数倍甚至数百倍。  
  - `toString`：仍然是 `O(n)`，因为必须把所有位拼成字符串。  
    但题目限制 `toString` 调用次数 ≤ 5，整体影响可接受。

- **空间复杂度**  
  - `O(n)` 用来存储 `bits`（与暴力解相同），额外只多了几个标量变量 `cnt`、`rev`，空间几乎不增。

> 综上，最优解在 **绝大多数操作** 上都达到了常数时间，完美满足 `size ≤ 10⁵`、调用次数 `≤ 10⁵` 的高频场景。

## 心得

- **核心技巧**：利用“全局翻转标记 + 实时计数”把原本需要遍历的操作降到 `O(1)`。  
- **适用的题型**  
  1. **需要频繁整体取反的位数组**（如本题、LeetCode 1017. **"Bitset"**）。  
  2. **需要在集合/数组上执行全局取反或全局加/减的题目**（如 “All One” 计数器的全局翻转、某些 “翻转字符串” 类题）。  
  3. **在不改变原始存储结构的前提下，实现“懒更新”**（如线段树的懒标记、布隆过滤器的全局翻转）。  

- **一句话总结解题钥匙**：  
  **“把整体操作抽象成一个标记，而不是真的遍历全部元素。”**

---

## 反思

- **第一反应**：看到 `flip`、`all`、`one`、`count` 这些需要遍历的操作，直接想到把所有位都存到数组里，按字面意思实现。  
- **最容易踩的坑**  
  1. **忘记在 `flip` 时同步更新 `cnt`**，导致 `count`、`all`、`one` 给出错误答案。  
  2. **在 `fix`/`unfix` 时没有考虑全局翻转的影响**，把 `bits[idx]` 直接设为 `1/0`，会在 `rev=True` 时产生相反的真实值。  
  3. **边界条件**：`size = 1`、连续多次 `flip`（两次翻转应该恢复原状）都要验证。  
- **下次遇到同类题的第一步**：  
  **先判断是否有“整体一次性影响所有元素的操作”，如果有，就尝试用一个全局标记（懒更新）来记录，而不是立刻遍历全部元素。**  

这样就能把时间复杂度从 `O(n)` 降到 `O(1)`，大幅提升效率。
