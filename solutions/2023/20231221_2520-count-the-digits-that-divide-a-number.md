# #2520. 统计能整除数字的位数 / Count the Digits That Divide a Number

> 难度：简单 · 标签：Math · [LeetCode 链接](https://leetcode.com/problems/count-the-digits-that-divide-a-number/)

---

## 题目（英文原版）

**Description**

Given an integer num, return the number of digits in num that divide num.
An integer val divides nums if nums % val == 0.

**Examples**

**Example 1:**

```
Input: num = 7
Output: 1
Explanation: 7 divides itself, hence the answer is 1.
```

**Example 2:**

```
Input: num = 121
Output: 2
Explanation: 121 is divisible by 1, but not 2. Since 1 occurs twice as a digit, we return 2.
```

**Example 3:**

```
Input: num = 1248
Output: 4
Explanation: 1248 is divisible by all of its digits, hence the answer is 4.
```

**Constraints**

- 1 <= num <= 109
- num does not contain 0 as one of its digits.

---

## 题目（中文翻译）

给定一个整数（integer）`num`，返回 `num` 中能够整除 `num` 本身的数字（digit）的数量。  
如果整数（integer）`val` 能整除 `num`，则满足 `num % val == 0`。

### 示例

#### 示例 1
**输入:** `num = 7`  
**输出:** `1`  
**解释:** 7 能整除自身，因此答案为 1。

#### 示例 2
**输入:** `num = 121`  
**输出:** `2`  
**解释:** 121 能被数字 1 整除，但不能被数字 2 整除。由于数字 1 在 `num` 中出现了两次，返回 2。

#### 示例 3
**输入:** `num = 1248`  
**输出:** `4`  
**解释:** 1248 能被其所有数字整除，因此答案为 4。

### 约束条件
- `1 <= num <= 10^9`
- `num` 的各位数字中不包含 `0`。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：把整数的每一位数字都拿出来，逐个判断它能不能整除原数。  
- **怎么把数字拆开**：可以把整数不断除以 `10`（相当于把右边的数字“抹掉”），用取余 `% 10` 拿到最右边的那一位。就像我们把一串珠子从右往左一颗颗摘下来。  
- **检查能否整除**：把摘下来的数字 `d` 用 `num % d == 0` 判断是否为 `num` 的约数。  
- **计数**：只要满足条件，就把计数器加一。

> **为什么正确**  
> 每一次取余 `% 10` 都恰好得到当前最右边的数字，循环直到整数被除到 `0` 为止，保证所有位都被检查到。只要满足 `num % d == 0`，说明该位数字是 `num` 的因子，计数自然成立。

> **时间/空间复杂度**  
> - 时间复杂度：`O(k)`，其中 `k` 是数字的位数（`k ≤ 10`，因为 `num ≤ 10⁹`），相当于我们每位检查一次。用大白话说，就是“检查一次就够了”，不会出现 `O(n²)` 那种“每次都要遍历全部”。  
> - 空间复杂度：`O(1)`，只用了几个整数变量，和输入规模无关。

#### 代码（Python）

```python
def countDigits(num: int) -> int:
    """
    暴力版：逐位检查是否能整除
    """
    cnt = 0               # 记录符合条件的位数
    original = num        # 保存原始数值，后面要用它来做除法检查

    while num > 0:        # 当数字还有位时循环
        digit = num % 10  # 取出最右边的数字，像把最右边的珠子拽下来
        # 题目保证 digit != 0，直接判断是否整除
        if original % digit == 0:   # 能整除就计数
            cnt += 1
        num //= 10        # 把最右边的数字抹掉，准备检查下一位
    return cnt
```

#### 复杂度

- **时间复杂度**：`O(k)` —— 只遍历了 `k` 次（每位一次），对 `10⁹` 以内的数字最多 10 次，几乎是瞬间完成。  
- **空间复杂度**：`O(1)` —— 只用了常数个变量，和数字大小没有关系。

### 2. 最优解

#### 思路  

其实上面的“暴力”已经是最优的了，因为我们只能检查每一位数字一次，无法再省掉这一步。  
不过可以从 **“把整数转成字符串”** 的角度再写一遍，让代码更直观：

1. 把整数 `num` 转成字符串 `s`，相当于把数字的每一位拆成了字符。  
2. 遍历字符串中的每个字符 `c`，把它转回整数 `d = int(c)`。  
3. 用同样的 `num % d == 0` 判断是否为约数，满足则计数。

> **为什么同样最优**  
> - 字符串长度恰好等于数字的位数 `k`，遍历一次即完成检查。  
> - 只多了把字符转成整数的常数时间开销，整体仍是 `O(k)`。  
> - 代码更易读，尤其对初学者更友好。

> **核心技巧**：**逐位检查**（Digit‑by‑Digit Check）。把大问题拆成最小的“每位数字”子问题，然后逐个解决。

#### 代码（Python）

```python
def countDigits(num: int) -> int:
    """
    最优写法：利用字符串遍历每一位
    """
    cnt = 0
    s = str(num)               # 把整数变成字符串，像把珠子排成一串文字
    for ch in s:               # 逐个字符（即每一位数字）遍历
        d = int(ch)            # 把字符再变回整数，准备做除法
        if num % d == 0:       # 检查是否整除
            cnt += 1
    return cnt
```

#### 复杂度

- **时间复杂度**：`O(k)` —— 只遍历一次字符串，`k` 为位数。和暴力解的 `while` 循环是同一个量级，只是实现方式不同。  
- **空间复杂度**：`O(k)` —— 需要额外的字符串存储 `k` 个字符（因为把整数复制成了字符串），这在本题的约束下仍然非常小（最多 10 个字符）。如果严格要求 `O(1)`，可以回到第一种 `while` 写法。

## 心得

- **核心技巧**：逐位检查每个数字是否为原数的约数（Digit‑by‑Digit Divisibility）。  
- **适用的题型**  
  1. “找出数字中满足某种数论条件的位数”——如 **LeetCode 1281. Subtract the Product and Sum of Digits of an Integer**。  
  2. “统计符合某种属性的数字位”——如 **LeetCode 1840. Maximum Building Height**（需要遍历高度数组的每一位）。  
  3. “数位 DP” 的最简形态——先检查每位，再累计结果。  
- **一句话总结解题钥匙**：把大整数拆成“一位一位”，对每位独立判断，最后把满足条件的计数相加。

## 反思

- **第一反应**：把数字转成字符串，逐位遍历最直观。  
- **最容易踩的坑**  
  - **除零错误**：若题目不保证数字里没有 `0`，在除法前必须先判断 `digit != 0`。本题已说明不含 `0`，但写代码时最好加个防御性检查。  
  - **重复计数**：题目要求“每出现一次就计一次”，所以即使同一个数字出现多次，也要逐位计数，不能去重。  
- **下次遇到同类题的第一步**：先把整数拆成每一位（`% 10` 或 `str()`），再思考每位需要满足的条件是什么。这样就能快速搭建起解题的框架。
