## 题目（中文翻译）

**描述**  
给定一个整数 `n`，返回同时是 `n` 和 `2` 的最小倍数（即最小的偶数倍数）。换句话说，求 `n` 的最小偶数倍。

**约束条件**  
- `1 <= n <= 150`

**示例**

**示例 1**  
输入: `n = 5`  
输出: `10`  
解释: 同时是 `5` 与 `2` 的最小倍数是 `10`。

**示例 2**  
输入: `n = 6`  
输出: `6`  
解释: 同时是 `6` 与 `2` 的最小倍数是 `6`。注意，一个数本身就是它自己的倍数。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

我们要找「既是 `n` 的倍数，又是 `2` 的倍数」的最小正整数。  
最直接的想法是：从 `1` 开始逐个检查每个正整数 `x`，只要 `x` 同时能被 `n` 整除 (`x % n == 0`) 且能被 `2` 整除 (`x % 2 == 0`)，就把它当作答案返回。

- **使用的数据结构**：这里只需要几个普通的整数变量。  
  - 可以把「查字典」的过程想象成：我们手里有一本「倍数表」(其实是隐式的)，要在表里找第一个同时满足两条规则的数字。

- **为什么正确**：我们从最小的正整数 `1` 起步，严格按照「从小到大」的顺序检查，每遇到一个满足条件的数，就一定是所有满足条件的数中最小的那个，所以返回的就是题目要求的最小公倍数。

- **复杂度分析**：  
  - 最坏情况下（比如 `n = 149`，是奇数），答案是 `2 * n = 298`，我们需要检查 `1 … 298` 共 `298` 次。  
  - 时间复杂度用大写的 **O** 来表示：`O(answer)`，这里的 `answer` 大约是 `2n`，所以可以写成 **O(n)**。  
    - **大白话**：算法的运行时间会随 `n` 的大小线性增长，`n` 翻倍，检查的次数也大概翻倍。  
  - 空间上只用了常数个变量，**O(1)**，意思是占用的内存几乎不随 `n` 变化。

#### 代码（Python）

```python
def smallestEvenMultiple_brute(n: int) -> int:
    """暴力枚举，从 1 开始逐个判断是否同时是 n 和 2 的倍数"""
    x = 1                      # 从最小的正整数开始
    while True:
        # 同时能被 n 整除且能被 2 整除，即满足题目要求
        if x % n == 0 and x % 2 == 0:
            return x           # 找到最小的满足条件的数，直接返回
        x += 1                  # 继续检查下一个正整数
```

#### 复杂度

- **时间复杂度**：`O(n)` — 需要检查大约 `2n` 次（因为答案最多是 `2n`），所以运行时间随 `n` 成线性关系增长。
- **空间复杂度**：`O(1)` — 只用了几个整数变量，内存占用固定不变。

### 2. 最优解

#### 思路  

从暴力解我们可以看到，**瓶颈**在于逐个尝试所有数字，实际上我们根本不需要「枚举」——可以直接用数学的性质一次算出答案。

**关键观察**：

1. “最小同时是 `n` 与 `2` 的倍数” 就是 `n` 与 `2` 的 **最小公倍数（LCM）**。  
2. `2` 只有两种因子：`1` 和 `2`。  
3. 当 `n` 本身已经是偶数（能被 `2` 整除）时，`n` 已经满足“是 `2` 的倍数”，所以答案就是 `n`。  
4. 当 `n` 是奇数时，`n` **不能** 被 `2` 整除，我们只能把 `2` 再乘一次进来，最小的公共倍数就是 `n * 2`。

于是答案可以用一句话写出来：

```
if n 是偶数 → answer = n
else          → answer = 2 * n
```

**为什么这样一定对？**  

- 偶数 `n = 2 * k`（`k` 为整数），它本身已经包含因子 `2`，所以 `LCM(2, n) = n`。  
- 奇数 `n` 没有因子 `2`，要让它同时包含 `2`，只能把 `2` 加进去一次，得到 `2 * n`，这已经是最小可能的数，因为任何更小的数要么缺少 `n` 的因子，要么缺少 `2` 的因子。

**核心概念解释**：

- **最小公倍数（LCM）**：两个数的所有公共倍数中最小的那个。可以用 `LCM(a, b) = a * b / GCD(a, b)`（`GCD` 是最大公约数）来计算。但这里因为一个数是 `2`，我们直接用上面的奇偶判断更简洁。

#### 代码（Python）

```python
def smallestEvenMultiple(n: int) -> int:
    """
    直接根据 n 的奇偶性返回最小的同时是 n 与 2 的倍数的数。
    """
    # n % 2 == 0 表示 n 能被 2 整除，即 n 是偶数
    if n % 2 == 0:
        return n          # 偶数情况下 n 本身就是答案
    else:
        return n * 2      # 奇数情况下需要再乘以 2
```

#### 复杂度

- **时间复杂度**：`O(1)` — 只做一次取模和一次乘法，运行时间与 `n` 大小无关。  
  - **对比**：相比暴力的 `O(n)`，这里的运行时间是常数级，几乎瞬间完成。
- **空间复杂度**：`O(1)` — 同样只用了固定的几个变量，内存占用不随 `n` 变化。

## 心得

- **核心技巧**：利用数的奇偶性直接判断最小公倍数，省去遍历或求最大公约数的过程。  
- **适用的题型**：  
  1. “两个数的最小公倍数” 类问题（如 `LCM(a, b)`），当其中一个数很小或有特殊性质时可以直接推导。  
  2. “把数变成偶数” 或 “使数满足特定因子” 的题目（如把奇数变成能被 3 整除的最小数）。  
- **一句话总结解题钥匙**：**先判断能否直接满足条件，若不能就把缺失的因子乘进去**。

## 反思

- **第一反应**：看到“最小的同时是 n 与 2 的倍数”，本能想到枚举检查每个数是否满足条件。  
- **最容易踩的坑**：忘记考虑 `n` 本身已经是偶数的情况，直接返回 `2 * n` 会在偶数输入时得到错误的更大答案。  
- **下次遇到同类题的第一步**：先判断两个数之间是否已经有包含关系（一个是另一个的倍数），如果有，答案就是较大的那个；如果没有，再考虑把缺失的最小因子乘进去。
