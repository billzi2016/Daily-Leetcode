## 题目（英文原版）

**Description**

The k-beauty of an integer num is defined as the number of substrings of num when it is read as a string that meet the following conditions:
Given integers num and k, return the k-beauty of num.
Note:
A substring is a contiguous sequence of characters in a string.

**Examples**

**Example 1:**

```
Input: num = 240, k = 2
Output: 2
Explanation: The following are the substrings of num of length k:
- "24" from "240": 24 is a divisor of 240.
- "40" from "240": 40 is a divisor of 240.
Therefore, the k-beauty is 2.
```

**Example 2:**

```
Input: num = 430043, k = 2
Output: 2
Explanation: The following are the substrings of num of length k:
- "43" from "430043": 43 is a divisor of 430043.
- "30" from "430043": 30 is not a divisor of 430043.
- "00" from "430043": 0 is not a divisor of 430043.
- "04" from "430043": 4 is not a divisor of 430043.
- "43" from "430043": 43 is a divisor of 430043.
Therefore, the k-beauty is 2.
```

**Constraints**

- 1 <= num <= 109
- 1 <= k <= num.length (taking num as a string)

## 题目（中文翻译）

**题目描述**  
整数 `num` 的 *k-美度*（k-beauty）定义为：将 `num` 当作字符串读取时，所有满足以下条件的子字符串（substring）个数。  
给定整数 `num` 和 `k`，返回 `num` 的 *k-美度*。

**说明**  
- 子字符串是字符串中连续的字符序列。  
- 对于每个长度恰为 `k` 的子字符串，将其转换为整数 `val`，若 `val ≠ 0` 且 `num` 能被 `val` 整除（即 `num % val == 0`），则该子字符串计入 *k-美度*。

**示例**

*示例 1*  
```
输入: num = 240, k = 2
输出: 2
解释: 长度为 k 的子字符串如下:
- "24"（来自 "240"）: 24 能整除 240.
- "40"（来自 "240"）: 40 能整除 240.
因此，k-美度为 2.
```

*示例 2*  
```
输入: num = 430043, k = 2
输出: 2
解释: 长度为 k 的子字符串如下:
- "43"（来自 "430043"）: 43 能整除 430043.
- "30"（来自 "430043"）: 30 不能整除 430043.
- "00"（来自 "430043"）: 0 不是合法除数.
- "04"（来自 "430043"）: 4 不能整除 430043.
- "43"（来自 "430043"）: 43 能整除 430043.
因此，k-美度为 2.
```

**约束条件**  
- `1 ≤ num ≤ 10^9`  
- `1 ≤ k ≤ num` 的十进制表示长度（即将 `num` 视为字符串后的长度）

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：把整数 `num` 当成字符串，看所有长度恰好为 `k` 的连续子串，然后把每个子串再转回整数，判断它是否能整除 `num`。  

- **使用的结构**：  
  - **字符串**：把数字变成字符序列，方便切片（就像把一本书的文字抽出来读）。  
  - **整数除法**：判断“能否整除”就像检查一本书的章节数能否被整本书的页数整除。  

- **为什么正确**：  
  - 题目要求统计**所有**长度为 `k` 的子串，只要我们遍历完整个字符串并且不漏掉任何起始位置，就一定会检查到每一个合法子串。  
  - 对每个子串，转成整数后直接使用 `%`（求余）判断 `num % sub == 0`，这正是“是否是除数”的定义。  

- **复杂度大白话**：  
  - 假设 `num` 有 `n` 位（`n = len(str(num))`）。我们需要从左到右检查每一个起始位置，起始位置一共 `n‑k+1` 个。  
  - 对每个位置我们都要 **切片**（取 `k` 个字符）并 **转成整数**，这一步的工作量与 `k` 成正比。于是总工作量大约是 `(n‑k+1) * k`，在最坏情况下（`k≈n/2`）约等于 `n²/2`，用大 O 表示就是 **O(n·k)**，在最坏情况下可以写成 **O(n²)**。  
  - 额外的空间只用来保存字符串本身和一个计数器，都是常数级的，记作 **O(1)**。

#### 代码（Python）

```python
def divisor_substrings_brute(num: int, k: int) -> int:
    """
    暴力解：遍历所有长度为 k 的子串，逐个检查是否能整除 num。
    """
    s = str(num)                # 把整数变成字符串，方便切片
    n = len(s)
    cnt = 0                     # 记录满足条件的子串个数

    # 起始位置 i 从 0 到 n-k（左闭右开区间）
    for i in range(n - k + 1):
        sub_str = s[i:i + k]    # 取出长度为 k 的子串，例如 "24"
        sub_num = int(sub_str)  # 把子串转成整数

        # 0 不能作为除数，直接跳过
        if sub_num != 0 and num % sub_num == 0:
            cnt += 1

    return cnt
```

#### 复杂度

- **时间复杂度**：`O(n·k)`（最坏情况约 `O(n²)`）——每个子串都要花 `k` 的时间去切片并转成整数。  
- **空间复杂度**：`O(1)` ——只用了常数级的额外变量（计数器和几个临时变量）。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈**在于每次都要把子串重新转成整数，这一步的代价与 `k` 成正比。我们可以把这个过程 **滚动**起来：  
- 当我们已经知道位置 `i` 开始的子串对应的整数值 `val` 时，位置 `i+1` 开始的子串只需要把最高位（左边）去掉，再把下一位（右边）加入。  
- 这就像在玩 **滑动窗口**：窗口宽度固定为 `k`，每次往右滑动一步，只需要 O(1) 的时间更新窗口内的数值。  

具体做法如下：

1. 把 `num` 转成字符串 `s`，长度记为 `n`。  
2. 先算出 **第一个窗口**（`i = 0`）对应的整数 `val`。可以用普通的 `int(s[:k])`。  
3. 对于后续窗口 `i → i+1`：  
   - 把最高位 `s[i]` 去掉相当于 `val - int(s[i]) * 10^{k-1}`（把左边的那位乘上 `10^{k-1}` 再减掉）。  
   - 再把新加入的右边位 `s[i+k]` 加进去：`val = (val % 10^{k-1}) * 10 + int(s[i+k])`。  
   - 这里用到 **模运算** 和 **乘10**，正好对应十进制的进位规则。  
4. 每得到一个新的 `val`，直接判断 `val != 0` 且 `num % val == 0`，如果满足则计数加一。  

这样，**每个窗口只做常数次算术运算**，整体时间降到 `O(n)`，空间仍然是 `O(1)`。

> **小贴士**：`10^{k-1}` 可以在一开始算好，记作 `pow10 = 10 ** (k - 1)`，后面直接使用。

#### 代码（Python）

```python
def divisor_substrings_opt(num: int, k: int) -> int:
    """
    最优解：使用滑动窗口（滚动哈希）在 O(n) 时间内完成。
    """
    s = str(num)
    n = len(s)
    pow10 = 10 ** (k - 1)          # 用于把最高位“抹掉”
    cnt = 0

    # 计算第一个长度为 k 的子串对应的整数值
    cur = int(s[:k])

    # 检查第一个窗口
    if cur != 0 and num % cur == 0:
        cnt += 1

    # 从第二个窗口开始向右滑动
    for i in range(1, n - k + 1):
        # 把左边即将离开的那位数字去掉
        left_digit = int(s[i - 1])
        cur -= left_digit * pow10          # 例：240 -> 40，去掉左边的 2

        # 把右边新进来的那位数字加入
        right_digit = int(s[i + k - 1])
        cur = cur * 10 + right_digit        # 例：40 -> 400，再加上新的 0

        # 判断当前窗口的数值是否为 num 的约数
        if cur != 0 and num % cur == 0:
            cnt += 1

    return cnt
```

#### 复杂度

- **时间复杂度**：`O(n)` ——只遍历一次字符串，每次滑动窗口只做 O(1) 的算术操作。相比暴力解的 `O(n·k)`，大大加速。  
- **空间复杂度**：`O(1)` ——只用了几个整数变量（`cur、pow10、cnt`），与输入规模无关。

## 心得

- **核心技巧**：**滑动窗口 + 滚动数值**（也叫“滚动哈希”）。在需要统计所有固定长度子串的属性时，往往可以把子串转成整数的过程“滚动”起来，避免重复的 O(k) 计算。  
- **适用的题型**：  
  1. **子串转整数求和/乘积**（如 LeetCode 1658 “将 x 除以 2 的次数”变形）。  
  2. **固定长度子串的统计**（如 LeetCode 930 “和相等的子数组”中使用前缀和的思路）。  
  3. **滑动窗口求最大/最小**（如 LeetCode 3 “无重复字符的最长子串”）。  
- **一句话总结解题钥匙**：*把“每次都重新计算”换成“只更新变化的那一点”。*

## 反思

- **第一反应**：看到“所有长度为 k 的子串”，立刻想到把数字转成字符串、直接切片，这就是暴力思路。  
- **最容易踩的坑**：  
  - **子串为 0**：0 不能作为除数，忘记过滤会导致除以 0 的运行错误。  
  - **前导零**：子串可以是 `"00"`、`"04"`，转成整数后会变成 `0`、`4`，要注意仍然要做除法检查。  
  - **指数 `10^{k-1}`** 的计算，如果 `k` 很大（但本题 `k ≤ 9`），直接使用 `10**(k-1)` 仍然安全。  
- **下次类似题的第一步**：先确定**窗口大小**（这里是 `k`），然后思考是否可以**滚动**更新窗口内部的状态，而不是每次都重新遍历窗口。这样往往能把 O(n·k) 降到 O(n)。
