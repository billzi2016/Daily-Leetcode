# #2264. **字符串中最大的三位相同数字** / Largest 3-Same-Digit Number in String

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/largest-3-same-digit-number-in-string/)

---

## 题目（英文原版）

**Description**

You are given a string num representing a large integer. An integer is good if it meets the following conditions:
Return the maximum good integer as a string or an empty string "" if no such integer exists.
Note:

**Examples**

**Example 1:**

```
Input: num = "6777133339"
Output: "777"
Explanation: There are two distinct good integers: "777" and "333".
"777" is the largest, so we return "777".
```

**Example 2:**

```
Input: num = "2300019"
Output: "000"
Explanation: "000" is the only good integer.
```

**Example 3:**

```
Input: num = "42352338"
Output: ""
Explanation: No substring of length 3 consists of only one unique digit. Therefore, there are no good integers.
```

**Constraints**

- 3 <= num.length <= 1000
- num only consists of digits.

## 题目（中文翻译）

给定一个字符串 `num`，它表示一个很大的整数。若一个整数满足以下条件，则称其为**好整数（good integer）**：

- 该整数是 `num` 的一个长度为 3 的子串（substring）；
- 子串中的三个字符全部相同。

返回最大的好整数（以字符串形式），如果不存在则返回空字符串 `""`。

**示例 1**  
**输入**: `num = "6777133339"`  
**输出**: `"777"`  
**解释**: 存在两个不同的好整数: `"777"` 和 `"333"`。其中 `"777"` 最大，故返回 `"777"`。

**示例 2**  
**输入**: `num = "2300019"`  
**输出**: `"000"`  
**解释**: `"000"` 是唯一的好整数。

**示例 3**  
**输入**: `num = "42352338"`  
**输出**: `""`  
**解释**: 没有长度为 3 且仅由同一数字组成的子串。因此不存在好整数。

**约束条件**  

- `3 <= num.length <= 1000`  
- `num` 仅由数字字符组成。

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把字符串 `num` 中所有长度为 **3** 的子串都枚举出来，逐个判断它们是否满足「三个字符完全相同」的条件。  

- **枚举子串**：可以把 `num` 看成一排连续的数字，用指针 `i` 从左到右滑动，每次取 `i,i+1,i+2` 这三个位置的字符形成一个子串。  
- **判断相同**：把这三个字符依次比较，只要有任意一个不同，就说明不是「好整数」；全部相同则是。  
- **记录最大**：把所有满足条件的子串放进一个列表，最后把它们按字典序（因为都是同样长度的数字，字典序就是数值大小的顺序）取最大的即可。  

> **类比**：把字符串想象成一条火车轨道，窗口大小是 3，窗口每向前移动一步，就相当于把「观景窗口」从前一段移动到后一段，看看这段景色里是否全是同一种颜色的车厢。

这个方法必然能得到正确答案，因为我们把 **所有** 可能的长度‑3 子串都检查了一遍，漏掉的情况不存在。

#### 代码（Python）

```python
def largestGoodInteger(num: str) -> str:
    good_numbers = []                     # 用来保存所有满足条件的子串
    n = len(num)

    # 用 i 作为窗口左端点，窗口长度固定为 3
    for i in range(n - 2):                # n-2 是因为最后两个字符后面已经没有足够的长度组成子串
        sub = num[i:i+3]                   # 直接切片得到长度为 3 的子串
        # 判断子串的三个字符是否相同
        if sub[0] == sub[1] == sub[2]:     # 全相同才算“好整数”
            good_numbers.append(sub)      # 记录下来

    # 如果列表为空，说明没有任何满足条件的子串
    if not good_numbers:
        return ""

    # 同样长度的数字，直接取字典序最大的就是数值最大的
    return max(good_numbers)
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  解释：我们只遍历了一遍字符串，`n` 是字符串的长度（最多 1000），每一步的比较和切片都是常数时间，所以总体是线性时间。  
- **空间复杂度**：`O(k)`，`k` 为满足条件的子串个数（最坏情况 `k ≈ n`），因为我们把所有「好整数」都存进了列表。

### 2. 最优解  

#### 思路  

暴力解已经是 **线性** 的了，但我们仍可以把「空间」进一步压到 **O(1)**，并且代码更简洁。观察题目要求的「最大」好整数，有以下两个关键点：

1. **好整数的形式固定**：只能是 `"111"`、`"222"` … `"999"`、`"000"` 这十种可能（每个数字重复三次）。  
2. **从大到小找**：只要我们按照从 `9` 到 `0` 的顺序检查这十个候选子串，**第一个出现的** 就一定是答案，因为更大的数字已经先被检查过了。  

于是我们可以：

- 依次遍历字符 `'9'、'8' … '0'`。  
- 对每个字符 `d`，构造字符串 `candidate = d*3`（比如 `'7'*3 = "777"`）。  
- 用 Python 的 `in` 运算符直接判断 `candidate` 是否是 `num` 的子串。`in` 底层是一次线性扫描，时间是 `O(n)`。  
- 第一次 `True` 的 `candidate` 就是答案，立即返回。  

如果所有十个候选子串都没有出现，返回空串 `""`。  

> **类比**：把十个候选数字想象成十把钥匙，钥匙从最大的（9）开始尝试打开锁（在字符串中寻找），第一把能打开的钥匙就是答案，后面的钥匙根本不需要再尝试。

#### 代码（Python）

```python
def largestGoodInteger(num: str) -> str:
    # 从大到小依次尝试 "999", "888", ..., "000"
    for digit in map(str, range(9, -1, -1)):   # 生成字符 '9' 到 '0'
        candidate = digit * 3                 # 构造比如 "777"
        if candidate in num:                  # 判断 candidate 是否是 num 的子串
            return candidate                  # 第一个匹配到的就是最大值
    return ""                                 # 没有任何匹配，返回空串
```

#### 复杂度  

- **时间复杂度**：`O(10·n) = O(n)`  
  解释：我们最多检查 10 次，每次 `candidate in num` 都是一次线性扫描，长度为 `n`。常数因子 10 很小，整体仍是线性时间。相较于暴力解，它省去了额外的列表收集和 `max` 操作。  
- **空间复杂度**：`O(1)`  
  解释：只用了常数个变量 (`digit`, `candidate`)；不依赖于输入规模 `n`，因此是常数空间。

## 心得  

- **核心技巧**：**从候选集合中逆序枚举 + 子串查找**。当候选集合非常小且有天然的大小顺序时，逆序遍历可以直接得到最大（或最小）解。  
- **适用题型**：  
  1. “在字符串中寻找出现次数最多/最大/最小的固定模式” （如 “Find Largest 2-Equal-Digit Number”。）  
  2. “在数组/字符串中寻找满足特定模式的子序列，且候选模式数量有限” （如 “Check if 'abc' appears”，或 “Largest 3‑Consecutive Same Letter”。）  
- **一句话总结**：**把所有可能的答案列出来，按目标的大小顺序一次尝试，最先命中的就是答案。**

## 反思  

- **第一反应**：看到「长度为 3、三个字符相同」立刻想到「滑动窗口」枚举所有子串，这是最自然的做法。  
- **最容易踩的坑**：  
  - 忘记返回空串 `""` 而不是 `None` 或 `0`（题目要求返回字符串）。  
  - 忽视字符串开头/结尾的边界：循环上界应是 `len(num)-2`，否则会出现越界切片。  
  - 对于最优解，误以为 `in` 是 O(1) 查找，实际上它仍是 O(n) 的线性扫描，但因为候选只有十个，整体仍是线性时间。  
- **下次思路**：遇到「固定长度、固定形式」的子串查找时，先问自己「候选数量是否小且有序」，如果是，就考虑 **逆序枚举 + 子串检测**，这样可以在 O(n) 时间、O(1) 空间内直接得到最优解。
