## 题目（英文原版）

**Description**

You are given a positive integer n. Determine whether n is divisible by the sum of the following two values:
Return true if n is divisible by this sum; otherwise, return false.

**Examples**

**Example 1:**

```
Input: n = 99
Output: true
Explanation:
Since 99 is divisible by the sum (9 + 9 = 18) plus product (9 * 9 = 81) of its digits (total 99), the output is true.
```

**Example 2:**

```
Input: n = 23
Output: false
Explanation:
Since 23 is not divisible by the sum (2 + 3 = 5) plus product (2 * 3 = 6) of its digits (total 11), the output is false.
```

**Constraints**

- 1 <= n <= 106

## 题目（中文翻译）

给定一个正整数 (positive integer) n。判断 n 是否能被其各位数字的和与积之和整除。若 n 能被该和整除，返回 `true`；否则返回 `false`。

**示例 1**  
**输入**: `n = 99`  
**输出**: `true`  
**解释**:  
数字 9 和 9 的和为 `9 + 9 = 18`，积为 `9 * 9 = 81`。它们的和为 `18 + 81 = 99`，恰好能被 n 整除，因此返回 `true`。

**示例 2**  
**输入**: `n = 23`  
**输出**: `false`  
**解释**:  
数字 2 和 3 的和为 `2 + 3 = 5`，积为 `2 * 3 = 6`。它们的和为 `5 + 6 = 11`，23 不能被 11 整除，所以返回 `false`。

**约束条件**  
- `1 <= n <= 10^6`

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  
最直接的想法是：**把整数 `n` 的每一位数字都取出来**，分别求它们的**和**与**积**，再把这两个结果相加，最后检查 `n` 能否被这个和整除。  

- **取数字**：把 `n` 看成一串字符（或者不断对 `10` 取余），每次取出最低位 `digit = n % 10`，然后把 `n` 整除 `10` 去掉这一位。这个过程就像把一串珠子一个一个拽下来。  
- **哈希表类比**：这里不需要哈希表，只需要两个普通变量 `s`（存和）和 `p`（存积）。  
- **正确性**：题目只要求我们 **计算** “数字之和 + 数字之积”，并判断 `n` 是否能被它整除。只要我们把每一位数字都完整地算进来，结果必然是正确的。  

**为什么叫暴力？**  
如果我们不把注意力放在“怎么快速取出每一位”，而是用最笨的办法——**从 1 遍历到 `n`，每次都把当前数字拆成各位再算一次**，那时间复杂度会是 `O(n·log10 n)`，显然非常慢。这里把“遍历所有数”当作暴力层次，而真正实现时我们只遍历 **`n` 本身的位数**，所以已经是对暴力的“优化”。下面先给出最笨的实现，再在最优解里说明如何进一步简化。  

#### 代码（Python）  

```python
def checkDivisibility_bruteforce(n: int) -> bool:
    """
    暴力实现：逐位拆分 n，求和、求积，再判断 n 是否能被 (sum + product) 整除。
    """
    # 1. 把 n 拆成每一位数字，存到列表里（这里用了字符串，最直观）
    digits = [int(ch) for ch in str(n)]   # 例如 n=99 -> [9, 9]

    # 2. 计算各位数字的和 sum 和积 product
    s = sum(digits)          # 和：9 + 9 = 18
    p = 1
    for d in digits:        # 积：9 * 9 = 81
        p *= d

    # 3. 检查 n 是否能被 (s + p) 整除
    total = s + p            # total = 18 + 81 = 99
    return n % total == 0   # 99 % 99 == 0 -> True
```

#### 复杂度  

- **时间复杂度**：`O(k)`，其中 `k` 是 `n` 的位数（`log10 n`）。遍历每一位一次即可。  
  - 大白话：如果 `n` 最大是 1,000,000，它只有 7 位，所以最多只循环 7 次，几乎可以忽略不计。  
- **空间复杂度**：`O(k)` 用来存放 `digits` 列表。如果改用数学取余的方式（不建列表），可以做到 `O(1)`，即只用常数级别的额外空间。  

---  

### 2. 最优解  

#### 思路  
从暴力解可以看到，**真正的瓶颈并不在位数遍历**（最多只有 7 次），而是在 **额外创建列表** 与 **使用字符串转换**。我们可以直接用整数运算一次性把每一位取出来，既省空间又更快。  

优化步骤：

1. **不使用字符串**：用 `n % 10` 取最低位，用 `n //= 10` 删除最低位。这样只需要两个整数变量 `s`（和）和 `p`（积）。  
2. **一次遍历完成**：在同一次循环里同时累计 `s` 与 `p`，不必再遍历两遍。  
3. **边界处理**：当 `n` 为 0 时（题目保证 `n ≥ 1`），但如果要写通用函数，需要把积的初始值设为 1，防止乘到 0。  

核心概念——**位运算**（其实是十进制的取余除法），可以类比为“从右往左数珠子”。每取出一颗珠子，就把它的价值加到总和、乘到总积中。  

#### 代码（Python）  

```python
def checkDivisibility(n: int) -> bool:
    """
    最优实现：不使用额外列表，直接用整数运算逐位取出数字。
    时间 O(k)，空间 O(1)。
    """
    s = 0          # 用来累计各位数字的和
    p = 1          # 用来累计各位数字的积（乘法的中性元是 1）

    temp = n       # 复制一份，因为后面要把它除到 0
    while temp > 0:
        digit = temp % 10   # 取出最低位数字
        s += digit          # 累加到和
        p *= digit          # 累乘到积
        temp //= 10         # 删除最低位，向左移动一位

    total = s + p            # 和 + 积
    return n % total == 0    # 判断能否整除
```

#### 复杂度  

- **时间复杂度**：`O(k)`，`k` 为数字位数。和暴力解一样，但常数更小（没有列表创建、字符串转换）。  
  - 与暴力解对比：原来用了 `O(k)` 的时间外加 `O(k)` 的空间，改进后只用 `O(k)` 时间和 `O(1)` 空间。  
- **空间复杂度**：`O(1)`，只用了几个整数变量，和输入大小无关。

## 心得  

- **核心技巧**：**位拆分（取余/除法）** + **一次遍历累计**。  
- **适用题型**：  
  1. “判断整数是否满足某种位数属性” 如 **判断回文数**、**判断整数是否是回文数**。  
  2. “根据各位数字求和/积” 如 **判断是否为自除数**（self‑dividing number）。  
  3. “数位 DP” 的最简形式，如 **统计满足特定数位条件的数**。  
- **一句话总结**：**只要能把每一位数字一次性取出来并在同一次循环里完成所有需要的累计操作，就能做到时间最优、空间最省。**

## 反思  

- **第一反应**：看到“数字之和 + 数字之积”，立刻想到把每位拆出来，用 `sum`、`product` 再判断。  
- **最容易踩的坑**：  
  - **积的初始值**：如果把 `p` 初始化为 `0`，乘完后永远是 `0`，导致错误。应初始化为 `1`（乘法的单位元）。  
  - **单独的 0 位**：若数字里出现 `0`，积会变为 `0`，此时 `total = sum + 0`，仍然合法，只要除法不除以 `0`（`total` 永不为 `0` 因为 `sum ≥ 1`）。  
  - **大数溢出**：在 Python 中整数自动扩容，不会溢出；但在某些语言要注意乘积可能超出 32 位范围。  
- **下次遇到同类题**：**第一步**先思考“怎么快速遍历每一位数字”，决定是用字符串还是数学取余；随后在一次遍历中完成所有需要的统计（和、积、计数等），避免不必要的额外空间。
