# #3504. 子串拼接后最长回文 II / Longest Palindrome After Substring Concatenation II

> 难度：困难 · 标签：Two Pointers、String、Dynamic Programming · [LeetCode 链接](https://leetcode.com/problems/longest-palindrome-after-substring-concatenation-ii/)

---

## 题目（英文原版）

**Description**

You are given two strings, s and t.
You can create a new string by selecting a substring from s (possibly empty) and a substring from t (possibly empty), then concatenating them in order.
Return the length of the longest palindrome that can be formed this way.

**Examples**

**Example 1:**

```
Input: s = "a", t = "a"
Output: 2
Explanation:
Concatenating "a" from s and "a" from t results in "aa" , which is a palindrome of length 2.
```

**Example 2:**

```
Input: s = "abc", t = "def"
Output: 1
Explanation:
Since all characters are different, the longest palindrome is any single character, so the answer is 1.
```

**Example 3:**

```
Input: s = "b", t = "aaaa"
Output: 4
Explanation:
Selecting " aaaa " from t is the longest palindrome, so the answer is 4.
```

**Example 4:**

```
Input: s = "abcde", t = "ecdba"
Output: 5
Explanation:
Concatenating "abc" from s and "ba" from t results in "abcba" , which is a palindrome of length 5.
```

**Constraints**

- 1 <= s.length, t.length <= 1000
- s and t consist of lowercase English letters.

## 题目（中文翻译）

给定两个字符串 `s` 和 `t`。  
你可以先从 `s` 中选择一个子串（substring）（可以为空），再从 `t` 中选择一个子串（可以为空），然后按顺序将它们拼接（concatenating）起来，得到一个新字符串。  
返回能够通过上述方式构造的最长回文（palindrome）的长度。

**示例 1**  
**输入**: `s = "a", t = "a"`  
**输出**: `2`  
**解释**:  
从 `s` 中取 `"a"`，从 `t` 中取 `"a"`，拼接得到 `"aa"`，它是长度为 2 的回文。

**示例 2**  
**输入**: `s = "abc", t = "def"`  
**输出**: `1`  
**解释**:  
所有字符都不同，最长的回文只能是任意单个字符，因此答案为 1。

**示例 3**  
**输入**: `s = "b", t = "aaaa"`  
**输出**: `4`  
**解释**:  
从 `t` 中选择 `"aaaa"`，它本身就是最长的回文，长度为 4。

**示例 4**  
**输入**: `s = "abcde", t = "ecdba"`  
**输出**: `5`  
**解释**:  
从 `s` 中取 `"abc"`，从 `t` 中取 `"ba"`，拼接得到 `"abcba"`，这是长度为 5 的回文。

**约束条件**  
- `1 <= s.length, t.length <= 1000`  
- `s` 和 `t` 只包含小写英文字母。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有可能的 **子串** 都枚举出来，分别取

* `s` 的一个子串 `s[l1:r1]`（可以为空）  
* `t` 的一个子串 `t[l2:r2]`（可以为空）

把它们按顺序拼接得到 `cand = s[l1:r1] + t[l2:r2]`，检查 `cand` 是否是回文串，记录最长的长度。

> **类比**：把 `s` 看成一本书的若干章节，把 `t` 看成另一本书的若干章节。我们可以随意挑选一本书的若干连续章节（甚至不选），再接着挑选另一本书的若干连续章节，拼在一起。只要拼出的文字正读正写都一样，就是回文。

**为什么正确**：我们把**所有**合法的拼接都遍历一遍，必然会碰到最长的那一种，所以答案一定在遍历过程中被找到。

#### 代码（Python）

```python
def longestPalindrome_bruteforce(s: str, t: str) -> int:
    n, m = len(s), len(t)
    best = 1                         # 至少有一个字符可以构成长度 1 的回文

    # 枚举 s 的子串（左闭右闭区间），i 为左端点，j 为右端点
    for i in range(n + 1):           # +1 让 i == n 表示“空子串”
        for j in range(i - 1, n):    # j < i 表示空子串
            sub_s = s[i:j + 1] if i <= j else ""

            # 枚举 t 的子串
            for p in range(m + 1):
                for q in range(p - 1, m):
                    sub_t = t[p:q + 1] if p <= q else ""

                    cand = sub_s + sub_t          # 拼接
                    # 检查回文（正读和反读相同）
                    if cand == cand[::-1]:
                        best = max(best, len(cand))

    return best
```

> 关键行解释  
> - `for i in range(n + 1)`: `i == n` 时表示取空子串。  
> - `cand == cand[::-1]`: Python 中 `[::-1]` 能快速得到字符串的逆序，用来判断回文。  

#### 复杂度

- **时间复杂度**：`O(n² * m² * L)`  
  - `n`、`m` 分别是两个字符串的长度。  
  - 枚举所有子串需要 `O(n²)`（`s`）和 `O(m²)`（`t`）次。  
  - 每次拼接后检查回文，需要遍历拼接后字符串的长度 `L`（最坏是 `n+m`），所以总体是四层循环乘以 `L`。  
  - 用大白话说，就是**几千甚至上万次**的嵌套循环，跑不过 1000 长度的限制。

- **空间复杂度**：`O(1)`（不计返回值和常数级别的临时变量）  

> 暴力解只能用来验证思路或在非常小的数据上实验，实际提交会 TLE（超时）。

### 2. 最优解

#### 思路  

暴力的瓶颈在于 **把所有子串都列举出来**，这一步产生了 `O(n²·m²)` 的组合。  
观察题目：我们只需要得到 **最长** 的回文长度，而不是所有回文本身。  
回文的结构有一个重要特性：

> **如果回文的首字符来自 `s[i]`，尾字符必然来自 `t[j]`（或同一个字符串的内部），并且这两字符必须相等。**

基于这个特性，我们可以把答案拆成三类：

1. 完全来自 `s`（只选 `s` 的子串）  
2. 完全来自 `t`（只选 `t` 的子串）  
3. 既有左半段来源于 `s`，又有右半段来源于 `t`，且两端字符相等。

前两类可以单独预处理得到，分别记为  

- `p[i]`：**以 `s[i]` 为左端点的最长回文子串的长度**（子串全部在 `s` 内）。  
- `q[j]`：**以 `t[j]` 为右端点的最长回文子串的长度**（子串全部在 `t` 内）。

这两组信息只需 `O(n²)`、`O(m²)` 的简单枚举即可得到（因为 `n,m ≤ 1000`，这已经够快）。

接下来处理第三类：  
设 `dp[i][j]` 为 **以 `s[i]` 为左端点、以 `t[j]` 为右端点，能够组成的最长回文长度**（左边的字符必须取自 `s[i]`，右边的字符必须取自 `t[j]`，中间可以自由选择）。

递推公式来源于“首尾匹配”这一回文核心：

- **如果 `s[i] != t[j]`**，首尾不相等，无法把这两个字符放进同一个回文。此时只能放弃其中一个端点，答案只能是只使用左边（`p[i]`）或只使用右边（`q[j]`）得到的最大值：
  
  ```
  dp[i][j] = max(p[i], q[j])
  ```

- **如果 `s[i] == t[j]`**，我们可以把这对相等字符放进回文的最外层，剩下的子问题就是 `dp[i+1][j-1]`（左端点往右移一位，右端点往左移一位）。同时也要考虑只取左边或只取右边的情况：

  ```
  dp[i][j] = max(p[i], q[j], 2 + dp[i+1][j-1])
  ```

  当 `i+1` 越界或 `j-1` 越界时，`dp[i+1][j-1]` 视为 `0`（因为内部已经没有字符可选）。

**计算顺序**：`dp[i][j]` 依赖 `dp[i+1][j-1]`，因此我们把 `i` 从后向前遍历，`j` 从前向后遍历即可保证子问题已经求好。

**最终答案**：`max( max(dp[i][j]) , max(p) , max(q) )`。  
因为答案也可能只取单独的 `s` 或 `t` 子串。

> **类比**：把 `s` 看成左边的“拼图块”，`t` 看成右边的“拼图块”。我们先找出每块内部最大的自洽图形（`p[i]`、`q[j]`），然后尝试把左块的最左边和右块的最右边拼在一起，如果颜色相同（字符相等），就可以把它们“贴合”形成更大的图形，递归向内继续贴合。

#### 代码（Python）

```python
def longestPalindrome(s: str, t: str) -> int:
    n, m = len(s), len(t)

    # -------------------------------------------------
    # 1. 预处理 p[i]：以 s[i] 为左端点的最长回文子串长度
    # -------------------------------------------------
    p = [1] * n                     # 至少自己一个字符是回文
    for i in range(n):
        # 以 i 为左端点，向右扩展检查所有子串是否回文
        for j in range(i, n):
            sub = s[i:j + 1]
            if sub == sub[::-1]:    # 是回文
                p[i] = max(p[i], j - i + 1)

    # -------------------------------------------------
    # 2. 预处理 q[j]：以 t[j] 为右端点的最长回文子串长度
    # -------------------------------------------------
    q = [1] * m
    for j in range(m):
        for i in range(0, j + 1):
            sub = t[i:j + 1]
            if sub == sub[::-1]:
                q[j] = max(q[j], j - i + 1)

    # -------------------------------------------------
    # 3. 动态规划 dp[i][j]：左端点 s[i]，右端点 t[j] 的最长回文长度
    # -------------------------------------------------
    # 使用二维列表，初始化为 0
    dp = [[0] * m for _ in range(n)]

    # i 从后往前，j 从前往后遍历
    for i in range(n - 1, -1, -1):
        for j in range(m):
            if s[i] == t[j]:
                # 2 + dp[i+1][j-1] 需要判断下标是否越界
                inner = dp[i + 1][j - 1] if (i + 1 < n and j - 1 >= 0) else 0
                dp[i][j] = max(p[i], q[j], 2 + inner)
            else:
                dp[i][j] = max(p[i], q[j])

    # -------------------------------------------------
    # 4. 取全局最大值
    # -------------------------------------------------
    ans = max(max(p), max(q))               # 只用单个字符串的情况
    for i in range(n):
        for j in range(m):
            ans = max(ans, dp[i][j])        # 同时使用 s 与 t 的情况

    return ans
```

> **代码要点**  
> - `p[i]`、`q[j]` 的预处理都是 **枚举子串 + 判回文**，时间 `O(n²)`、`O(m²)`，在 1000 长度下完全可接受。  
> - `dp` 的递推只看 `dp[i+1][j-1]`，所以遍历顺序必须保证该子状态已经算好。  
> - `inner` 变量处理边界：如果已经没有内部字符可配对，就把内部长度视为 `0`，只加上外层的两个相等字符 `2`。  

#### 复杂度

- **时间复杂度**：`O(n² + m² + n·m)`  
  - `p` 预处理 `O(n²)`，`q` 预处理 `O(m²)`，`dp` 主循环 `O(n·m)`。  
  - 对于本题的上限 1000，最多约 `10⁶` 次基本操作，轻松跑完。

- **空间复杂度**：`O(n·m)`（`dp` 表）+ `O(n+m)`（`p`、`q`）  
  - 只用了一个二维数组来保存子问题的结果，大小为 `1000×1000 ≈ 1 MB`，在 Python 中也不算大。  

> 与暴力解相比，时间从 **指数级** 降到了 **多项式级**，可以在毫秒级得到答案。

## 心得

- **核心技巧**：把“左端点来自 `s`，右端点来自 `t`”的约束抽象为二维 DP，配合预处理的 **单字符回文长度**（`p[i]`、`q[j]`）来避免枚举所有子串。
- **适用的题型**  
  1. 两个序列拼接后要求满足某种对称/匹配条件（如回文、交错相等）。  
  2. “左侧来源 A，右侧来源 B”，可以用 `dp[i][j]` 表示从 `A[i]` 开始、`B[j]` 结束的最优子结构。  
  3. 需要 **前缀** 或 **后缀** 的最长满足条件子串（如最长递增前缀 + 最长递减后缀）。

- **一句话总结解题钥匙**：  
  **“先把每个字符串内部的最长回文预处理出来，然后用二维 DP 只在两端相等时把它们‘贴合’继续扩展”。**

## 反思

- **第一反应**：直接枚举所有子串并检查回文，忽视了输入规模会导致超时。  
- **最容易踩的坑**  
  - 忘记考虑 **空子串** 的情况（答案最小是 `1`，因为任意单字符都是回文）。  
  - 在 DP 递推时没有正确处理边界（`i+1` 超出范围或 `j-1` 为负数），会导致 `IndexError` 或错误的内部长度。  
  - `p[i]`、`q[j]` 的初始化必须至少为 `1`（单字符回文），否则全为 `0` 时会把合法答案遗漏。  
- **下次遇到同类题**：  
  1. **先问自己**：是否可以把答案拆成“左端点在 A，右端点在 B”的形式？  
  2. **预处理**：把每个序列内部的“单侧最优”信息先算好（最长递增前缀、最长回文前缀等）。  
  3. **建立二维 DP**，只在两端满足约束时递推，否则取单侧最优。  

这样一步步把暴力的枚举空间压缩到可接受的多项式规模，就能在 Hard 难度题目中稳稳拿到 AC。
