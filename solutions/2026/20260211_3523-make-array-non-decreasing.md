## 题目（英文原版）

**Description**

You are given an integer array nums. In one operation, you can select a subarray and replace it with a single element equal to its maximum value.
Return the maximum possible size of the array after performing zero or more operations such that the resulting array is non-decreasing.

**Examples**

**Example 1:**

```
Input: nums = [4,2,5,3,5]
Output: 3
Explanation:
One way to achieve the maximum size is:
The final array [4, 5, 5] is non-decreasing with size 3.
```

**Example 2:**

```
Input: nums = [1,2,3]
Output: 3
Explanation:
No operation is needed as the array [1,2,3] is already non-decreasing.
```

**Constraints**

- 1 <= nums.length <= 2 * 105
- 1 <= nums[i] <= 2 * 105

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把所有可能的子数组合并**，然后检查合并后的数组是否是非递减的，记录下最大的长度。

- **子数组**：就像我们把一段连续的数字“装进盒子”，盒子里只留下这段数字的最大值。  
- **暴力枚举**：对每一种“装盒”方式（即每一次操作选择的子数组），都把数组压缩一次，得到一个新数组。继续对新数组再枚举，直到没有更多操作可以做。  
- **检查**：每得到一个新数组，就判断它是否满足`前一个 ≤ 后一个`的条件，如果满足就更新答案。

为什么它是对的？因为我们把**所有**合法的合并序列都遍历了一遍，答案自然会出现在遍历过程中。

然而，这种做法的代价极大：  
- 对长度为 `n` 的数组，子数组的选择数是 `O(n²)`（左端点 × 右端点）。  
- 每一次选择后又会产生新的数组，继续枚举，导致 **指数级** 的组合数。  

> **时间复杂度** 用大白话说就是“几乎不可能在电脑里跑完”。  
> **空间复杂度** 也很高，需要保存大量的中间数组。

#### 代码（Python）

```python
from itertools import product

def is_non_decreasing(arr):
    """判断数组是否非递减"""
    return all(arr[i] <= arr[i + 1] for i in range(len(arr) - 1))

def brute(nums):
    """暴力搜索所有合并方式，返回最大可能长度"""
    n = len(nums)
    best = 1  # 至少可以保留一个元素

    # 用递归模拟每一步的“选子数组 → 合并”
    def dfs(cur):
        nonlocal best
        if is_non_decreasing(cur):
            best = max(best, len(cur))      # 更新答案
        # 枚举所有可能的子数组 (l, r)
        for l in range(len(cur)):
            for r in range(l, len(cur)):
                # 计算子数组的最大值
                mx = max(cur[l:r + 1])
                # 用最大值替换子数组，得到新数组
                nxt = cur[:l] + [mx] + cur[r + 1:]
                # 继续向下搜索
                dfs(nxt)

    dfs(nums)
    return best
```

> **注意**：上面的代码仅用于说明思路，实际运行会在几秒钟内因递归爆炸而崩溃。

#### 复杂度

- **时间复杂度**：`O(2^n)`（指数级）——每一步都有指数级的分支，实际不可接受。  
- **空间复杂度**：`O(n)`（递归栈深度）——虽然每层只保存一个数组，但递归深度最坏会到 `n`。

### 2. 最优解

#### 思路  

从暴力解可以看到，**真正的难点在于**：  
- 我们不需要知道**具体**每一次怎样合并，只需要知道**最终**会保留下多少个元素。  
- 合并的本质是：**把左边的一个元素和右边的若干元素“拼在一起”，使得左边的值不比右边的最大值小**。

换句话说，**如果左边的数字比右边的最大值大，就必须把它们合并**，因为否则最终数组一定会出现下降（左 > 右）。

这提示我们可以 **从右往左遍历**，维护一个**单调递增的栈**（这里的“单调”指栈顶到栈底的数值从小到大），栈里每个元素代表**已经确定好的一个段的最大值**。

遍历过程：

1. 设 `cur = nums[i]` 为当前左侧元素。  
2. **只要栈顶的段最大值小于 `cur`**，说明 `cur` 与栈顶段会产生下降，需要把它们合并。合并后新段的最大值是两者的最大值，即 `max(cur, stack.pop())`，并把这个最大值继续赋给 `cur`。  
3. 循环结束后，把 `cur`（已经和所有需要合并的右侧段融合后的最大值）压入栈中。  
4. 最终栈的长度就是**可以保留下来的最大元素个数**，因为每个栈元素对应一个“不可再合并的段”，它们的最大值已经保证从左到右 **不下降**。

> **类比**：想象每个段是一块“积木”。从右往左搬积木，如果左边的积木比右边的高，就必须把它们粘在一起，形成一块更高的积木。粘完以后再继续向左检查，直到所有积木从左到右都不再出现“高于右边”的情况。最后剩下的积木块数，就是答案。

#### 代码（Python）

```python
def maxSizeNonDecreasing(nums):
    """
    返回在任意次“把子数组替换成其最大值”的操作后，
    能得到的最长非递减数组的长度。
    """
    stack = []                     # 栈中保存每个段的最大值，保持递增

    # 从右往左遍历
    for x in reversed(nums):
        cur = x                     # 当前元素先当成独立的段
        # 若左侧元素比栈顶段的最大值大，需要合并
        while stack and cur > stack[-1]:
            # 合并后段的最大值是两者的较大者
            cur = max(cur, stack.pop())
        stack.append(cur)           # 合并完毕，形成一个新的段

    # 栈的大小 = 最终可以保留下来的元素个数
    return len(stack)
```

**关键行解释**  

- `while stack and cur > stack[-1]:` —— 只要左侧的 `cur` 大于右侧最近段的最大值，就必须把它们合并。  
- `cur = max(cur, stack.pop())` —— 合并后段的最大值是两者的较大者（因为合并后整个段会被替换成它的最大值）。  
- `stack.append(cur)` —— 把已经处理好的段压入栈，保证栈内从下到上是递增的。

#### 复杂度

- **时间复杂度**：`O(n)` —— 每个元素最多被压栈一次、弹栈一次，整个过程线性遍历。相比暴力的指数级，快得多。  
- **空间复杂度**：`O(n)` —— 最坏情况下栈里会存全部元素（比如原数组已经是非递减的），需要线性额外空间。

## 心得

- **核心技巧**：**单调栈 + 贪心**。把“必须合并的情况”转化为“栈顶比当前元素小就弹出”，从而一次遍历完成所有合并决策。  
- **适用题型**  
  1. “把子数组合并成某种聚合值” 类似题（如 “把子数组替换为最小值”）。  
  2. “要求最终序列满足单调性” 的题目（如 “删除最少元素使数组递增”）。  
  3. “区间合并” 的问题（如 “合并石子” 的单调栈变形）。  
- **一句话总结**：**左侧比右侧小的段必须合并，使用从右到左的单调栈一次完成所有合并**。

## 反思

- **第一反应**：把所有子数组的合并方式枚举出来，想要逐一验证。  
- **最容易踩的坑**  
  - 忘记从 **右侧** 开始遍历：从左遍历会导致合并顺序错误。  
  - 栈的单调性写反了：应保持**递增**（从栈底到栈顶），否则会产生错误的合并条件。  
  - 处理相等情况：`cur > stack[-1]`（严格大于）即可，等于时不需要合并，因为非递减允许相等。  
- **下次类似题**：第一步想到“**从右往左、维护单调栈**”，把“需要合并的”转化为“栈顶比当前小就弹”。这样就能快速得到最优解。
