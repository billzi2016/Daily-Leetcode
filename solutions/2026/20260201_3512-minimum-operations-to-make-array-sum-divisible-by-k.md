## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

题目说我们可以**任意次**对数组中的任意一个元素执行「把该元素减 1」的操作，目标是让数组所有元素之和能够被 `k` 整除。  

最直接的想法就是：  
1. 先算出当前数组的总和 `S`。  
2. 检查 `S % k`（余数）是否为 0，若是说明已经满足要求，直接返回 0。  
3. 如果余数不为 0，就不断把数组的第一个元素减 1，`S` 也随之减 1，计数器 `cnt` 加 1，直到 `S % k` 变成 0 为止。  

> **类比**：把 `S` 看成一本书的页码，`k` 是每本书的页数。我们只能「往回翻」一页（减 1），要把当前页码翻到正好是某本书的封底（即能被 `k` 整除），最笨的办法就是一步一步往回翻，直到恰好到达封底。

这个方法一定能得到答案，因为每次操作都让总和减 1，必然会经过所有可能的余数（从原余数一直减到 0），所以一定能在某一步得到可整除的情况。

#### 代码（Python）

```python
def minOperations_bruteforce(nums, k):
    # 计算初始总和
    total = sum(nums)                 # ← 求数组所有元素之和
    cnt = 0                           # ← 记录操作次数

    # 当总和对 k 取余不为 0 时，继续减 1
    while total % k != 0:             # ← 只要不是整除，就继续
        total -= 1                    # ← 把任意一个元素减 1（这里直接对 total 减）
        cnt += 1                      # ← 操作次数加一
    return cnt
```

#### 复杂度  

- **时间复杂度**：`O(answer)`，这里的 `answer` 是最终需要的操作次数。最坏情况下 `answer = k-1`（因为余数最大为 `k-1`），所以可以说是 `O(k)`。用大白话说，就是「我们最多要走 `k-1` 步」。
- **空间复杂度**：`O(1)`，只用了常数个变量来保存总和和计数器。

### 2. 最优解  

#### 思路  

从暴力解可以看到，**瓶颈**在于我们一次只把总和减 1，实际上我们可以一次性算出到底要减多少次才可以让总和整除 `k`。  

设  
- `S = sum(nums)` 为数组的总和  
- `r = S % k` 为 `S` 除以 `k` 的余数（`0 ≤ r < k`）  

如果 `r == 0`，说明已经满足条件，答案是 0。  

如果 `r != 0`，我们每次减 1 相当于把余数也减 1（因为 `(S-1) % k = (r-1) % k`），要把余数变成 0，恰好需要 **减 `r` 次**。  

于是答案就是 `r` 本身。  

> **类比**：想象你在走楼梯，楼梯总共 `k` 步，每一步代表「把总和减 1」。你现在站在第 `r` 步（余数），想要回到地面（第 0 步），只需要走下 `r` 步即可，一步也不必多走。

#### 代码（Python）

```python
def minOperations(nums, k):
    """
    返回最少的操作次数，使得数组和能够被 k 整除。
    思路：直接取余数 r = sum(nums) % k，答案就是 r。
    """
    total = sum(nums)          # 计算总和
    remainder = total % k      # 余数 r
    return remainder           # r 次减 1 即可
```

#### 复杂度  

- **时间复杂度**：`O(n)`，其中 `n = len(nums)`，因为我们只需要一次遍历求和。相对于暴力解的 `O(k)`（最坏 `k≈100`），这里的复杂度取决于数组长度，通常更大，但仍是线性最优。  
- **空间复杂度**：`O(1)`，只用了常数级别的额外空间。

## 心得  

- **核心技巧**：**取模（mod）** —— 只要知道总和对 `k` 的余数，就能直接得到需要的操作次数。  
- **适用的题型**：  
  1. “使数组和满足某个取模条件” 类题目（如 *Minimum Operations to Make Array Sum Divisible by K*）。  
  2. “把数字变成能被 X 整除” 的最少步数问题（如 *Make The Integer Array Divisible*）。  
  3. “求最少增/减次数使得某个属性满足模运算” 的题目。  
- **一句话总结**：**余数就是答案**——把总和对 `k` 取余，直接得到要减（或加）的次数。

## 反思  

- **第一反应**：看到“把数组和变成能被 k 整除”，自然会想到 **取余**，因为整除的本质就是余数为 0。  
- **最容易踩的坑**：  
  - 忘记先判断 `sum % k == 0`，直接返回 0 会导致错误。  
  - 误以为需要 “加” 操作而写成 `(k - r) % k`，但题目要求的是“减 1”。  
  - 边界条件：当 `k = 1` 时，任何整数都能被整除，答案应为 0。  
- **下次遇到同类题**：第一步立刻 **写出 `sum(nums) % k`**，看余数是多少，余数本身往往就是最少操作次数（或其补数），再根据题目要求决定是“加”还是“减”。
