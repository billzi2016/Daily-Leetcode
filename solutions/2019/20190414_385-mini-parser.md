# #385. Mini Parser / Mini Parser

> 难度：中等 · 标签：String、Stack、Depth-First Search · [LeetCode 链接](https://leetcode.com/problems/mini-parser/)

---

## 题目（英文原版）

**Description**

Given a string s represents the serialization of a nested list, implement a parser to deserialize it and return the deserialized NestedInteger.
Each element is either an integer or a list whose elements may also be integers or other lists.

**Examples**

**Example 1:**

```
Input: s = "324"
Output: 324
Explanation: You should return a NestedInteger object which contains a single integer 324.
```

**Example 2:**

```
Input: s = "[123,[456,[789]]]"
Output: [123,[456,[789]]]
Explanation: Return a NestedInteger object containing a nested list with 2 elements:
1. An integer containing value 123.
2. A nested list containing two elements:
    i.  An integer containing value 456.
    ii. A nested list with one element:
         a. An integer containing value 789
```

**Constraints**

- 1 <= s.length <= 5 * 104
- s consists of digits, square brackets "[]", negative sign '-', and commas ','.
- s is the serialization of valid NestedInteger.
- All the values in the input are in the range [-106, 106].

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是把 **字符串直接交给 Python 自己的解析器**，让它帮我们把 `"324"`、`"[123,[456,[789]]]"` 之类的序列化文本变成真正的 Python 数据结构（整数或列表）。  
这一步相当于把题目交给了 **“字典/词典”**——Python 的 `eval` 就像一本查字典的工具书，输入是“词”（这里是完整的字符串），输出是对应的“页码”（已经解析好的 Python 对象）。  

得到 Python 的嵌套列表后，只需要 **递归地把它们搬进 LeetCode 给出的 `NestedInteger` 类** 即可。  

> **为什么能得到正确答案？**  
> - `eval` 能完整地把合法的 JSON‑like 字符串（只包含数字、负号、方括号和逗号）转换成等价的 Python 对象。  
> - 递归遍历这个对象时，遇到整数就调用 `NestedInteger.setInteger`，遇到列表就创建一个新的 `NestedInteger` 并把子元素 `add` 进去，正好对应题目的要求。  

> **时间/空间复杂度大白话**  
> - `eval` 本质上要扫描整条字符串一次，算是 **线性**（`O(n)`）的工作。  
> - 递归把 Python 对象转成 `NestedInteger` 同样需要遍历每一个元素一次，也是 **线性**（`O(n)`）的。  
> - 额外的空间主要是递归栈和 `NestedInteger` 本身的存储，也是 **线性**（`O(n)`）的。  

> **注意**：在真实的面试或 LeetCode 环境中，这种做法会因为使用了 `eval`（相当于直接把题目答案拷贝进来）而 **被判为违规**，但它能帮助我们快速理清“把字符串变成结构化数据”这一步的本质。

#### 代码（Python）  

```python
# 下面的代码仅用于演示思路，实际提交时请不要使用 eval
import sys
sys.setrecursionlimit(10**6)          # 防止递归层数太深导致栈溢出

# ---------- LeetCode 给出的接口（这里自行简化实现） ----------
class NestedInteger:
    def __init__(self, value=None):
        if value is None:
            self._list = []          # 保存子元素的列表
            self._integer = None
        else:
            self._list = None
            self._integer = value

    def isInteger(self):
        return self._integer is not None

    def add(self, elem):
        if self._list is None:
            self._list = []
        self._list.append(elem)

    def setInteger(self, value):
        self._integer = value
        self._list = None

    def getInteger(self):
        return self._integer

    def getList(self):
        return self._list
# ------------------------------------------------------------------

def build_nested(obj):
    """
    把 Python 的 int / list 递归转换成 NestedInteger
    """
    if isinstance(obj, int):
        return NestedInteger(obj)
    # obj 是 list
    cur = NestedInteger()
    for sub in obj:
        cur.add(build_nested(sub))
    return cur

def deserialize(s: str) -> NestedInteger:
    """
    暴力版：直接让 Python 把字符串变成对象，再搬进去
    """
    # 1. 使用 eval 把字符串变成原生 Python 对象
    #    eval 的安全性在 LeetCode 环境下不被允许，这里仅作演示
    py_obj = eval(s)                 # 例如 "[123,[456]]" → [123, [456]]
    # 2. 把 Python 对象递归包装成 NestedInteger
    return build_nested(py_obj)
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 需要遍历字符串一次（`eval`）再遍历得到的结构一次（递归），整体是线性时间。  
- **空间复杂度**：`O(n)` — 递归生成的 `NestedInteger` 对象以及递归调用栈都与输入长度成正比。

### 2. 最优解  

#### 思路  

暴力解的“慢点”其实不在时间上，而在 **合规性**：使用 `eval` 违背了题目要求的“自己实现解析”。  
真正需要的解析器必须 **手动逐字符读取**，并在适当的时候构造 `NestedInteger`。  
从暴力思路出发，我们可以把 **“遇到左括号就开启一个新层级，遇到右括号就关闭当前层级”** 抽象为 **栈（stack）** 的典型用法：

1. **遇到 `[`**  
   - 创建一个空的 `NestedInteger`（代表一个新列表）。  
   - 把它压入栈顶，表示我们进入了更深一层的嵌套。  

2. **遇到 `]`**  
   - 当前栈顶的 `NestedInteger` 已经完整，弹出它。  
   - 弹出后栈顶（如果还有的话）就是它的父列表，把弹出的对象 `add` 到父列表中。  
   - 如果弹出后栈空，说明我们已经完成了解析，返回这个对象。  

3. **遇到数字或负号**  
   - 连续读取所有数字字符（可能有负号），形成完整的整数 `num`。  
   - 把 `num` 包装成 `NestedInteger(num)`。  
   - 如果栈不为空，则把它 `add` 到栈顶的列表；  
   - 否则（整个字符串本身就是一个整数，没有任何 `[`），直接返回这个单独的 `NestedInteger`。  

4. **遇到 `,`**  
   - 逗号只起到分隔作用，直接跳过即可。  

**核心数据结构**：**栈**。可以把栈想象成 **“装东西的箱子”**，每打开一个 `[` 就往箱子里再放一个小箱子；`]'` 相当于把最里面的小箱子封好并搬到外面的大箱子里。  

**为什么是线性 O(n)？**  
- 每个字符只会被 **读取一次**，不会出现重复扫描。  
- 入栈、出栈、以及整数的拼接都是 **常数时间** 的操作。  

**空间**：最坏情况下字符串全是左括号，栈的深度会和字符数成正比，故为 **O(n)**。

#### 代码（Python）  

```python
# ---------- LeetCode 给出的接口（这里自行简化实现） ----------
class NestedInteger:
    def __init__(self, value=None):
        if value is None:
            self._list = []
            self._integer = None
        else:
            self._list = None
            self._integer = value

    def isInteger(self):
        return self._integer is not None

    def add(self, elem):
        if self._list is None:
            self._list = []
        self._list.append(elem)

    def setInteger(self, value):
        self._integer = value
        self._list = None

    def getInteger(self):
        return self._integer

    def getList(self):
        return self._list
# ------------------------------------------------------------------

def deserialize(s: str) -> NestedInteger:
    """
    栈 + 逐字符解析，时间 O(n)，空间 O(n)
    """
    # 特例：整个字符串就是一个整数（没有任何 []）
    if s[0] != '[':                     # 直接返回单个整数的 NestedInteger
        return NestedInteger(int(s))

    stack = []                          # 用来保存尚未完成的 NestedInteger
    num = 0                             # 正在读取的数字
    negative = False                    # 是否是负数
    have_num = False                    # 标记当前是否已经读取到数字（防止空列表 [] 时误加入）

    for ch in s:
        if ch == '-':                   # 负号只会出现在数字前面
            negative = True
        elif ch.isdigit():
            num = num * 10 + int(ch)    # 累计构造整数，例如 "123" -> 1*10+2 -> 12*10+3 -> 123
            have_num = True
        elif ch == '[':
            # 遇到左括号，开启一个新层级
            stack.append(NestedInteger())
        elif ch == ',' or ch == ']':
            # 逗号或右括号前，如果刚才读取到了数字，需要先把数字封装进 NestedInteger
            if have_num:
                cur = NestedInteger(-num if negative else num)
                stack[-1].add(cur)      # 把数字加入当前层级的列表
                # 重置数字相关的状态，准备读取下一个数
                num = 0
                negative = False
                have_num = False
            # 当遇到右括号时，当前层级完成，弹出并交给上一层
            if ch == ']':
                completed = stack.pop()  # 完成的 NestedInteger
                if not stack:            # 栈空说明这是最外层，直接返回
                    return completed
                stack[-1].add(completed) # 把完成的列表加入父列表
        # 其他字符（如空格）在题目中不存在，这里不做处理

    # 理论上不会走到这里，因为题目保证合法输入
    return NestedInteger()
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 每个字符只遍历一次，所有栈操作、整数拼接均是常数时间。相较于暴力解，**不依赖语言自带的解析器**，完全手写，且仍然是线性最快。  
- **空间复杂度**：`O(n)` — 最坏情况下所有左括号都压在栈里，栈深度随输入长度线性增长。

## 心得  

- 这道题的核心技巧是 **“栈模拟递归的层次结构”**，即 **在遇到左括号时进入新层，右括号时退出层**。  
- 该技巧常用于处理 **带有嵌套结构的字符串**，例如：  
  1. `Valid Parentheses`（判断括号是否合法）  
  2. `Binary Tree Preorder Traversal` 的字符串序列化/反序列化  
  3. `Expression Evaluation`（中缀表达式转后缀或直接计算）  
- **一句话总结解题钥匙**：**用栈把“打开的‘[’”和“关闭的‘]’”配对，数字在遇到分隔符时即时封装加入当前层**。  

## 反思  

- **第一反应**：把字符串交给 `eval`，直接得到 Python 的列表结构。  
- **最容易踩的坑**：  
  - **负数**的处理：负号只会出现在数字前，需要单独记住它的状态。  
  - **连续的右括号**：如 `"]]"`，必须在处理右括号前先把前面的数字（如果有）加入当前层，否则会丢失最后一个整数。  
  - **单独整数**的情况：输入没有任何方括号时，需要提前返回一个只包含整数的 `NestedInteger`。  
- **下次遇到类似题**，第一步应该想到：**“这是一棵隐式的树/嵌套结构，能否用栈来模拟深度？”**，然后再决定是 **递归** 还是 **显式栈** 实现。
