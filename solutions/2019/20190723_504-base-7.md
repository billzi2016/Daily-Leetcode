## 题目（英文原版）

**Description**

Given an integer num, return a string of its base 7 representation.

**Examples**

**Example 1:**

```
Input: num = 100
Output: "202"
```

**Example 2:**

```
Input: num = -7

```

**示例 1**

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直观的想法是**把数字拆成 7 的幂**，从最高位往低位一步步「凑」出来：

1. 先求出 `|num|`（绝对值）最大的 7 的幂 `7^k`，满足 `7^k ≤ |num| < 7^{k+1}`。  
   - 这一步可以把 `k` 想象成「楼层」，`7^k` 就是「这层的天花板」。
2. 从最高幂 `7^k` 开始，依次用**整除**得到该位的数字 `digit = |num| // 7^k`，再用 **取模** 更新剩余的数 `|num| = |num| % 7^k`。  
   - 这相当于「把一大块糖果（`|num|`）先装进最大容量的盒子（`7^k`），装多少就记下来，然后把剩下的继续装进下一个稍小的盒子」。
3. 把每一位的 `digit` 按顺序拼成字符串；如果原始 `num` 为负数，再在最前面加上 `-`。

> 为什么这个方法一定能得到正确答案？  
> 因为十进制、二进制、七进制等进位制的本质都是**把一个整数表示成若干个不同权值的系数之和**。我们从最高权值往下依次确定系数（即每一位的数字），恰好完成了这种「系数求解」的过程。

**时间/空间复杂度**  
- 计算最高幂 `k` 需要循环 `k` 次（`k ≈ log₇|num|`），随后每一位也要遍历一次，所以整体时间是 **O(log₇|num|)**。  
  - 用大白话说，就是「数字越大，需要的位数就越多，位数大约是对数级别的增长」。
- 我们只使用了几个整数变量和最终的结果字符串，空间是 **O(log₇|num|)**（存放结果的字符数），额外的临时空间是常数 O(1)。

#### 代码（Python）

```python
def convertToBase7_brutal(num: int) -> str:
    # 0 是个特殊情况，直接返回 "0"
    if num == 0:
        return "0"

    negative = num < 0               # 记录符号，负数需要在最后加 '-'
    n = -num if negative else num    # 只处理正数，方便后面的除法

    # ---------- 第一步：找最高的 7 的幂 ----------
    power = 1          # 7^0 = 1
    while power * 7 <= n:   # 循环直到 7^{k+1} 超过 n
        power *= 7

    # ---------- 第二步：从高位往低位取每一位 ----------
    digits = []        # 用列表收集每一位，最后再 join 成字符串
    while power > 0:
        digit = n // power          # 当前位的数字
        digits.append(str(digit))   # 把数字转成字符加入列表
        n %= power                  # 剩余未处理的部分
        power //= 7                 # 进入下一位（权值除以 7）

    # ---------- 第三步：加上符号 ----------
    result = "".join(digits)
    return "-" + result if negative else result
```

#### 复杂度

- **时间复杂度**：`O(log₇|num|)` — 这里的 `log₇|num|` 表示「把数字拆成多少位」，位数越多，循环就跑得越久，但增长非常慢，远比线性 `O(n)` 快得多。
- **空间复杂度**：`O(log₇|num|)` — 需要存放最终的字符序列，长度正好等于位数。额外的临时变量只有常数个，算作 O(1)。

### 2. 最优解

#### 思路  

从暴力解可以看到，**最大瓶颈在于先找最高幂再倒着算**，这一步虽然已经是对数级别，但我们可以把过程再简化：直接用**“除 7，取余”**的循环，从低位向高位一次算完，然后再把得到的低位序列反转即可。

核心技巧是**“把整数不断除以基数，余数就是当前位的数字”**，这正是所有进制转换的通用方法。我们只需要：

1. 处理 `0` 和负号（和上面一样）。
2. 用 `while n > 0:` 循环  
   - `digit = n % 7` → 余数就是当前最低位。  
   - `n //= 7` → 把已经算好的最低位去掉，准备算下一位。  
   - 把 `digit` 加到结果列表的**末尾**（因为先得到的是低位）。
3. 循环结束后，列表里的数字顺序是 **低 → 高**，用 `[::-1]` 反转成 **高 → 低**，再拼成字符串。  

> 类比：想象把糖果一次只能装进 **7** 个人的盒子，先把最小的盒子装满（余数），剩下的继续装进下一个盒子，直到装不下为止。装完后，我们把盒子从最小排到最大的顺序**倒过来**，就得到从最高位到最低位的表示。

这套做法只需要一次除法/取模循环，省掉了找最高幂的那一步，代码更简洁，且在实际运行时略快。

#### 代码（Python）

```python
def convertToBase7(num: int) -> str:
    # 特殊情况：0 的七进制就是 "0"
    if num == 0:
        return "0"

    negative = num < 0               # 记录是否为负数
    n = -num if negative else num    # 只处理正数，便于除法

    digits = []                      # 用列表收集余数（低位在前）
    while n > 0:
        digits.append(str(n % 7))    # 余数即当前位的数字，转成字符
        n //= 7                      # 去掉已经算好的最低位

    # 现在 digits 是 ["低位","次低位",...]，需要反转成高位在前
    result = "".join(reversed(digits))
    return "-" + result if negative else result
```

#### 复杂度

- **时间复杂度**：`O(log₇|num|)` — 每次循环把 `n` 除以 7，循环次数等于结果的位数。相比暴力解省去了找最高幂的那一步，常数因子更小。
- **空间复杂度**：`O(log₇|num|)` — 只需要保存每一位的字符，同样是位数大小的空间。

## 心得

- **核心技巧**：进制转换 → “不断除基数，余数即当前位”。  
- **适用的题型**：  
  1. 任意整数转二进制、八进制、十六进制（如 LeetCode 191. Number of 1 Bits）。  
  2. 把十进制数转为任意自定义进制（如 Excel 列号转换）。  
  3. 大数的进制加减（如 “加法字符串” 进制版）。  
- **一句话总结解题钥匙**：**“除基取余、逆序输出”**。

---

## 反思

- **第一反应**：先把负号单独处理，然后想 “怎么把整数拆成 7 的幂？” 于是想到循环除以 7。
- **最容易踩的坑**：  
  - 忘记 `num == 0` 的特殊处理，会导致返回空字符串。  
  - 负数没有加上 `-`，输出会错误。  
  - 直接把余数加入字符串而不逆序，会得到倒着的结果。  
- **下次遇到同类题**：第一步先 **“除基取余，记录余数”**，再 **“逆序拼接”**，并记得处理 `0` 与符号。
