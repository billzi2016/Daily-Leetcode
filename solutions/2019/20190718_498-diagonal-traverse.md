# #498. 对角线遍历 / Diagonal Traverse

> 难度：中等 · 标签：Array、Matrix、Simulation · [LeetCode 链接](https://leetcode.com/problems/diagonal-traverse/)

## 题目（英文原版）

**Description**

Given an m x n matrix mat, return an array of all the elements of the array in a diagonal order.

**Examples**

**Example 1:**

```
Input: mat = [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,4,7,5,3,6,8,9]
```

**Example 2:**

```
Input: mat = [[1,2],[3,4]]
Output: [1,2,3,4]
```

**Constraints**

- m == mat.length
- n == mat[i].length
- 1 <= m, n <= 104
- 1 <= m * n <= 104
- -105 <= mat[i][j] <= 105

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

我们先把矩阵里所有的元素按照「所在对角线」分组。  
对角线的特点是：同一条对角线上的元素满足 `行索引 + 列索引 = 常数`（比如左上角的 `0+0=0`，右上角的 `0+2=2`，左下角的 `2+0=2`）。  

**步骤**  
1. 先遍历整个矩阵，把每个元素放进以 `i+j` 为键的哈希表（字典）中。这里的哈希表可以想象成一本“对角线词典”，`key` 是对角线编号，`value` 是该对角线上出现的所有数字。  
2. 按照对角线编号从小到大取出每一组数字。题目要求奇数编号的对角线（从 0 开始计数）要 **反向** 输出，而偶数编号保持原顺序。  
3. 把所有取出的数字依次连起来，就是答案。

> **为什么正确？**  
> - 所有元素都会被放进对应的 `i+j` 组，保证不遗漏。  
> - 题目规定的遍历顺序恰好是：先第 0 条对角线（只含左上角），再第 1 条（需要反向），再第 2 条（正向）……这正好对应我们对 `i+j` 的顺序遍历并在奇数组上翻转。

#### 代码（Python）

```python
from collections import defaultdict
from typing import List

def findDiagonalOrder(mat: List[List[int]]) -> List[int]:
    m, n = len(mat), len(mat[0])
    # 哈希表：key = i + j（对角线编号），value = 该对角线上的元素列表
    diag = defaultdict(list)

    # 1️⃣ 把每个元素放进对应的对角线组
    for i in range(m):
        for j in range(n):
            diag[i + j].append(mat[i][j])          # 这里 i+j 就像“词典的页码”

    result = []
    # 2️⃣ 按对角线编号顺序取出元素，奇数编号需要翻转
    for k in range(m + n - 1):                    # 对角线总数是 m+n-1 条
        if k % 2 == 0:                           # 偶数编号 → 正序
            result.extend(diag[k])
        else:                                    # 奇数编号 → 反序
            result.extend(reversed(diag[k]))
    return result
```

#### 复杂度

- **时间复杂度**：`O(m * n)`  
  我们遍历矩阵一次（`m*n` 次）把元素放进字典，再遍历 `m+n-1` 条对角线收集结果。整体仍是线性时间。可以把 `O(m*n)` 想象成“和矩阵里每个格子都聊一次”。  
- **空间复杂度**：`O(m * n)`  
  需要额外的字典来存放所有元素，最坏情况下会保存和原矩阵一样多的数字。

### 2. 最优解

#### 思路  

暴力解已经是 `O(m*n)` 的时间，但它用了 `O(m*n)` 的额外空间。我们可以 **在遍历的同时直接写入答案**，只用常数级别的额外空间。

**核心点**：  
- 采用**方向标记**（向上右 / 向下左）来决定下一步怎么走。  
- 当走到矩阵边界时，需要“换方向”并“跳到合法位置”。  
- 换方向的规则可以归纳为四种情况（上右走到顶或右边界、下左走到底或左边界）。

**类比**：想象你在玩“弹珠”在棋盘上斜着弹，碰到墙就会弹回另一条斜线。每次碰墙后，你只需要把弹珠“搬到”下一个合法的起点，然后继续沿新的方向走。

**步骤**  
1. 用两个指针 `(r, c)` 表示当前所在的行、列，初始在左上角 `(0,0)`。  
2. 用一个布尔变量 `up` 表示当前是向上右 (`True`) 还是向下左 (`False`)。  
3. 把当前位置的元素写入答案数组。  
4. 根据 `up` 的值计算下一步的坐标：  
   - **向上右**：`r-1, c+1`  
   - **向下左**：`r+1, c-1`  
5. 检查新坐标是否越界：  
   - **向上右** 越界情况  
     - `r < 0`（到达第一行） → 把行恢复到 `0`，列向右移动一步 `c += 1`。  
     - `c >= n`（到达最右列） → 把列恢复到 `n-1`，行向下移动一步 `r += 1`。  
   - **向下左** 越界情况  
     - `c < 0`（到达第一列） → 把列恢复到 `0`，行向下移动一步 `r += 1`。  
     - `r >= m`（到达最底行） → 把行恢复到 `m-1`，列向右移动一步 `c += 1`。  
6. 只要没有遍历完所有 `m*n` 个格子，就循环步骤 3~5。  
7. 每次换方向时，把 `up` 取反。

这样我们只需要一个结果数组（`O(m*n)`）和几个指针变量（`O(1)`）。

#### 代码（Python）

```python
from typing import List

def findDiagonalOrder(mat: List[List[int]]) -> List[int]:
    if not mat:
        return []

    m, n = len(mat), len(mat[0])
    result = [0] * (m * n)          # 预分配结果列表，避免在循环里不断 append
    idx = 0                         # result 的写入下标
    r, c = 0, 0                     # 当前坐标
    up = True                       # True 表示向上右，False 表示向下左

    while idx < m * n:
        result[idx] = mat[r][c]     # 把当前格子写进答案
        idx += 1

        # 计算下一格的坐标
        if up:                      # 向上右走
            nr, nc = r - 1, c + 1
        else:                       # 向下左走
            nr, nc = r + 1, c - 1

        # 处理越界情况并决定是否换方向
        if nr < 0 or nr >= m or nc < 0 or nc >= n:   # 任何一种越界都需要“撞墙”
            if up:                                   # 向上右时撞墙
                if c == n - 1:                       # 碰到最右边界
                    r += 1                           # 往下走一格
                else:                                # 碰到上边界
                    c += 1
            else:                                    # 向下左时撞墙
                if r == m - 1:                       # 碰到最底边界
                    c += 1
                else:                                # 碰到左边界
                    r += 1
            up = not up                               # 换方向
        else:
            r, c = nr, nc                             # 正常移动到下一个格子

    return result
```

#### 复杂度

- **时间复杂度**：`O(m * n)`  
  每个格子只访问一次，和矩阵大小成正比。可以把它想象成“走遍棋盘的每一格，步数正好等于格子数”。  
- **空间复杂度**：`O(1)`（不计返回的答案）  
  只用了常数个额外变量（行、列、方向标记），不需要额外的哈希表或二维结构。

## 心得

- 这道题的核心技巧是 **“交替的斜向遍历 + 边界换向”**，属于**模拟**（Simulation）类题目。  
- 类似思路还能用于：  
  1. **Z 字形变换**（把字符串按 Z 字形写，再按行读取）  
  2. **螺旋矩阵**（顺时针螺旋遍历）  
  3. **蛇形填充矩阵**（按蛇形路径往矩阵里写数字）  
- **一句话总结**：**“把矩阵看成弹珠的弹道，遇墙就换方向并跳到下一个合法起点”。**

## 反思

- **第一反应**：看到“对角线顺序”，马上想到 “行+列相同的格子是一条对角线”。于是想到用 `i+j` 分组。  
- **最容易踩的坑**：  
  - 忘记在奇数编号的对角线上要 **翻转**顺序，导致答案顺序错误。  
  - 换方向时的边界判断写错，尤其是同时撞到两面墙的情况（如右上角）。  
  - 在最优解里忘记把 `up` 取反，导致一直沿同一方向跑死循环。  
- **下次遇到同类题**：第一步先 **明确移动方向的规律**（是斜向、是直向还是环形），再 **思考碰到边界时的“换位+换向”规则**，然后用几个指针模拟即可。
