## 题目（中文翻译）

给定一个整数数组（integer array） `nums`，返回数组中逆序对（reverse pair）的数量。  
逆序对是满足 `i < j` 且 `nums[i] > 2 * nums[j]` 的下标对 `(i, j)`。

### 示例 1
**输入:** `nums = [1,3,2,3,1]`  
**输出:** `2`  
**解释:** 逆序对为：
- `(1, 4)` → `nums[1] = 3, nums[4] = 1, 3 > 2 * 1`
- `(3, 4)` → `nums[3] = 3, nums[4] = 1, 3 > 2 * 1`

### 示例 2
**输入:** `nums = [2,4,3,5,1]`  
**输出:** `3`  
**解释:** 逆序对为：
- `(1, 4)` → `nums[1] = 4, nums[4] = 1, 4 > 2 * 1`
- `(2, 4)` → `nums[2] = 3, nums[4] = 1, 3 > 2 * 1`
- `(3, 4)` → `nums[3] = 5, nums[4] = 1, 5 > 2 * 1`

### 约束条件
- `1 <= nums.length <= 5 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有可能的下标组合 `(i, j)`（满足 `i < j`）都枚举一遍，然后检查  
`nums[i] > 2 * nums[j]` 是否成立，成立就把计数器加一。  

- **使用的数据结构**：只需要原数组 `nums` 本身以及一个整数计数器 `cnt`。  
  - 可以把数组想象成一排排编号的盒子，盒子里放着数字。我们把左边的盒子当作 `i`，右边的盒子当作 `j`，逐个比较是否满足 “左盒子的数字 大于 右盒子数字的两倍”。  
- **为什么正确**：因为我们把所有合法的 `(i, j)` 都检查了一遍，漏掉的可能性为零，自然得到的计数就是答案。  

#### 代码（Python）  

```python
def reversePairs(nums):
    n = len(nums)
    cnt = 0                         # 计数器，记录满足条件的逆序对数量
    for i in range(n):              # 外层循环遍历左指针 i
        for j in range(i + 1, n):   # 内层循环遍历右指针 j，保证 i < j
            # 如果左边的数大于右边数的两倍，就算一个逆序对
            if nums[i] > 2 * nums[j]:
                cnt += 1
    return cnt
```

#### 复杂度  

- **时间复杂度**：`O(n²)`  
  - “`O(n²)`” 的含义是：如果数组长度是 `n`，最坏情况下需要比较的次数大约是 `n × n`，比如 `n=10,000` 时要进行约一亿次比较，显然会超时。  
- **空间复杂度**：`O(1)`  
  - 只用了常数级别的额外变量（计数器 `cnt`），不随输入规模增长。

### 2. 最优解  

#### 思路  

暴力解的瓶颈在于**大量重复的比较**。我们可以借助**归并排序（Merge Sort）**的思想，把数组逐层拆分、排序的同时，利用已经排好序的子数组快速统计满足条件的逆序对。  

归并排序的核心步骤：

1. **分治**：把数组不断对半切分，直到每段只剩一个元素（单个元素天然有序）。  
2. **合并**：把两个有序子数组合并成一个有序数组。在合并的过程中，我们可以利用子数组的有序性，快速统计跨区间的逆序对。  

**跨区间逆序对的计数方法**（关键点）：

- 假设左半部分是 `left = nums[l..mid]`（已经排好序），右半部分是 `right = nums[mid+1..r]`（已经排好序）。  
- 用一个指针 `j` 从 `mid+1` 开始遍历右半部分。对左半部分的每个元素 `left[i]`，我们寻找**右半部分中第一个**不满足 `left[i] > 2 * right[j]` 的位置。  
- 因为右半部分是递增的，一旦 `right[j]` 太大，后面的 `right[j+1]、right[j+2]…` 只会更大，必然也不满足条件。所以对同一个 `i`，`j` 只会**单调右移**，整体遍历的时间是线性的 `O(len(right))`。  
- 对于当前的 `i`，满足条件的右半元素个数就是 `j - (mid + 1)`（因为 `j` 指向第一个不满足的下标）。把这个数累加到全局计数器即可。  

这样，每一次合并我们只用了 `O(len(left) + len(right))` 的时间来统计跨区间逆序对，同时完成数组的合并排序。整个归并排序的递归层数是 `log₂ n`，于是总时间是 `O(n log n)`。  

**类比**：把数组看成两排已经排好序的队伍（左队、右队），我们要统计左队里每个人比右队里多少人“太高”。因为两队都是从低到高站好的，只需要让左队的每个人往右队走，看到右队的第一个“不够矮”的人就停下来，停下的位置就是不满足的起点，左边的所有人都是满足的。

#### 代码（Python）  

```python
def reversePairs(nums):
    """
    使用归并排序统计逆序对，时间 O(n log n)，空间 O(n)（用于临时合并数组）。
    """
    def merge_sort(l, r):
        # 递归终止条件：区间长度为 1 时返回 0，单个元素不可能形成逆序对
        if l >= r:
            return 0

        mid = (l + r) // 2
        cnt = merge_sort(l, mid)          # 统计左半部分的逆序对
        cnt += merge_sort(mid + 1, r)     # 统计右半部分的逆序对

        # ------------------- 统计跨区间的逆序对 -------------------
        j = mid + 1
        for i in range(l, mid + 1):
            # 移动指针 j，找到第一个不满足 left[i] > 2 * right[j] 的位置
            while j <= r and nums[i] > 2 * nums[j]:
                j += 1
            cnt += j - (mid + 1)          # 右半部分满足条件的元素个数

        # ------------------- 合并两个有序子数组 -------------------
        # 这里使用临时数组 tmp 来完成归并过程
        tmp = []
        p, q = l, mid + 1
        while p <= mid and q <= r:
            if nums[p] <= nums[q]:
                tmp.append(nums[p])
                p += 1
            else:
                tmp.append(nums[q])
                q += 1
        # 把剩余的部分直接添加到 tmp（因为已经有序）
        while p <= mid:
            tmp.append(nums[p])
            p += 1
        while q <= r:
            tmp.append(nums[q])
            q += 1

        # 把排好序的结果写回原数组
        nums[l:r + 1] = tmp
        return cnt

    return merge_sort(0, len(nums) - 1)
```

#### 复杂度  

- **时间复杂度**：`O(n log n)`  
  - “`O(n log n)`” 的意思是：每一层递归我们都线性遍历一次整个数组（`O(n)`），而递归的层数大约是 `log₂ n`（因为每次都把区间长度减半），两者相乘得到 `n × log n`，这在 `n = 5·10⁴` 时约为 8·10⁵ 次操作，完全可以接受。  
- **空间复杂度**：`O(n)`  
  - 归并排序需要额外的临时数组 `tmp` 来存放合并结果，最坏情况下临时数组的大小等于原数组长度 `n`。递归调用栈的深度是 `log n`，相对于 `n` 可以忽略不计。

## 心得  

- **核心技巧**：利用归并排序的“分治 + 有序合并”特性，在合并阶段用**双指针**一次遍历统计跨区间的逆序对。  
- **适用的题型**：  
  1. **逆序对计数**（LeetCode 493 Reverse Pairs、LeetCode 1512 Number of Good Pairs 等）  
  2. **区间满足不等式的计数**（如 “数组中满足 `nums[i] - nums[j] > k` 的对数”）  
  3. **需要统计“左边元素大于右边元素某个函数”** 的问题，常常可以用类似的合并过程转化为线性计数。  
- **一句话总结解题钥匙**：**在已排序的两段之间，用单调指针一次遍历即可快速统计满足不等式的配对数**。

## 反思  

- **第一反应**：看到“逆序对”会立刻想到暴力枚举；但题目给出的 `n` 达到 5·10⁴，暴力肯定超时，于是想到 “能不能利用排序的结构加速？”  
- **最容易踩的坑**：  
  - **整数溢出**：`2 * nums[j]` 可能超出 32 位整数范围（尤其是负数），在 Python 中不会溢出，但在其他语言要记得使用 `long` 或者先把 `nums[i]` 转成 `long` 再比较。  
  - **负数的比较**：当数组里有负数时，`nums[i] > 2 * nums[j]` 的方向仍然成立，别因为负数把判断写反了。  
  - **指针移动的边界**：`j` 必须在每次外层循环开始时保持在上一次的结束位置，否则会出现重复计数或漏计。  
- **下次遇到同类题**：第一步先问自己 “是否可以把数组分成两部分，使得每部分内部已经有序？”，如果答案是 “可以”，就考虑用 **归并排序** 或 **树状数组 / 线段树** 在合并/查询阶段完成计数。
