# #405. 将数字转换为十六进制 / Convert a Number to Hexadecimal

> 难度：简单 · 标签：Math、String、Bit Manipulation · [LeetCode 链接](https://leetcode.com/problems/convert-a-number-to-hexadecimal/)

## 题目（英文原版）

**Description**

Given a 32-bit integer num, return a string representing its hexadecimal representation. For negative integers, two’s complement method is used.
All the letters in the answer string should be lowercase characters, and there should not be any leading zeros in the answer except for the zero itself.
Note: You are not allowed to use any built-in library method to directly solve this problem.

**Examples**

**Example 1:**

```
Input: num = 26
Output: "1a"
```

**Example 2:**

```
Input: num = -1
Output: "ffffffff"
```

**Constraints**

- -231 <= num <= 231 - 1

---

## 题目（中文翻译）

给定一个 32 位整数 `num`，返回其十六进制（hexadecimal）表示的字符串。对于负整数，使用 **二进制补码**（two’s complement）方法。

答案字符串中的所有字母必须为小写，并且除零本身外，答案中不应出现任何前导零。

**注意：** 禁止使用任何直接完成此任务的内置库函数。

**示例 1**  
输入: `num = 26`  
输出: `"1a"`

**示例 2**  
输入: `num = -1`  
输出: `"ffffffff"`

**约束条件**  
- \(-2^{31} \leq num \leq 2^{31} - 1\)

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

最直接的想法是 **先把整数变成二进制字符串，再把每四位一组转换成十六进制字符**。  

- **二进制 → 十六进制的映射**：十六进制的每一位恰好对应 4 位二进制（因为 2⁴ = 16），就像把一本字典每 4 页装进一本小册子，一页对应一个十六进制字符。  
- **实现步骤**  
  1. 用位运算把 `num` 的每一位取出来，拼成二进制字符串（正数直接取，负数先把它当作 32 位无符号整数处理）。  
  2. 为了保证可以完整地每 4 位划分，如果二进制位数不是 4 的倍数，就在左侧补 `0`（相当于在字典前面加几页空白页）。  
  3. 把二进制字符串从左到右每 4 位切成一段，用事先准备好的映射表把每段转换成对应的十六进制字符。  
  4. 把所有字符连起来后，去掉开头的多余 `0`（就像把小册子最前面的空白页撕掉），唯一例外是答案本身就是 `0`。  

这个方法一定能得到正确答案，因为二进制到十六进制的映射是 **一对一且完整** 的。

#### 代码（Python）  

```python
def toHex_bruteforce(num: int) -> str:
    # 1️⃣ 先把 num 当作 32 位无符号整数取出每一位二进制
    # 对负数使用两补数表示：在 Python 中把负数加上 2**32 再看成正数即可
    if num < 0:
        num += 2 ** 32

    bits = []                     # 用来存放二进制字符 '0' / '1'
    for i in range(32):           # 逐位检查 0~31 位
        # 右移 i 位后取最低位 ( & 1 )
        bits.append(str((num >> i) & 1))
    # bits 目前是低位在前，高位在后，先把它翻转成正常顺序
    bits = bits[::-1]             # 现在 bits[0] 是最高位

    # 2️⃣ 把二进制长度补齐到 4 的倍数（左侧补 0）
    while len(bits) % 4 != 0:
        bits.insert(0, '0')       # 在最左侧插入 '0'

    # 3️⃣ 每 4 位一组，映射到十六进制字符
    hex_map = "0123456789abcdef"
    res = []
    for i in range(0, len(bits), 4):
        four_bits = bits[i:i+4]               # 取出四位
        idx = int(''.join(four_bits), 2)      # 把四位二进制转成十进制下标
        res.append(hex_map[idx])              # 查表得到对应字符

    # 4️⃣ 去掉前导零（但保留单独的 "0"）
    ans = ''.join(res).lstrip('0')
    return ans if ans else '0'
```

#### 复杂度  

- **时间复杂度**：`O(32)` → 大约是常数时间。这里的 `O(32)` 表示我们遍历了 32 位，每位都要做一次位运算和一次列表插入，和输入大小无关。可以把它想象成“跑 32 步”，不管数字多大，步数始终是 32 步。  
- **空间复杂度**：`O(32)` → 需要存放 32 个字符的二进制列表，同样是常数级别的空间。

### 2. 最优解  

#### 思路  

从上面的暴力思路可以看到，**把整个二进制字符串先拼出来再分组其实是多余的**。我们只需要**每次直接取出最低的 4 位**（即一个 “nibble”），立刻把它映射成十六进制字符，然后右移 4 位继续处理。  

- **瓶颈所在**：暴力解在第 1 步把所有 32 位都保存进列表、再一次性遍历，这一步其实可以省掉。  
- **优化手段**：使用 **位掩码** `0xF`（二进制 1111）一次性拿到最低 4 位，用 **右移** `>>= 4` 把已经处理过的位丢掉，继续循环。  
- **核心概念**：  
  - **位掩码**：把不想要的位“遮住”，只留下我们关心的位。想象把一本书的每一页都贴上透明贴纸，只露出我们需要的那几行文字。  
  - **右移**：相当于把书翻页，把已经读过的页移到左边不再看。  

对负数同样使用两补数的技巧：先把负数加上 `2**32`，得到对应的 32 位无符号整数。这样右移时不需要考虑符号位的扩展。  

整个过程最多只会循环 **8 次**（因为 32 位 / 4 = 8），每次只做常数时间的位运算和字符查表，是真正的线性于“十六进制位数”的最优解。

#### 代码（Python）  

```python
def toHex(num: int) -> str:
    # 处理负数：把它当作 32 位无符号整数来看
    if num < 0:
        num += 2 ** 32          # 两补数等价于加 2^32

    if num == 0:                # 单独处理 0，避免后面循环产生空字符串
        return "0"

    hex_map = "0123456789abcdef"
    res = []                    # 用列表收集每一位十六进制字符（逆序）

    while num:                  # 当还有未处理的位时循环
        cur = num & 0xF         # 取最低 4 位（0xF == 1111b）
        res.append(hex_map[cur])  # 查表得到对应字符，放入列表
        num >>= 4               # 右移 4 位，丢掉已经处理的部分

    # 目前 res 中的字符是从低位到高位的逆序，反转后即为正确结果
    return ''.join(reversed(res))
```

#### 复杂度  

- **时间复杂度**：`O(8)` → 实际上是常数时间，因为最多只循环 8 次（每次处理 4 位）。可以把它想象成“最多爬 8 楼梯”，不管数字多大，最多走 8 步。相比暴力解省掉了把全部 32 位存进列表的过程。  
- **空间复杂度**：`O(8)` → 最多存放 8 个字符的结果列表，同样是常数级别。

## 心得  

- **核心技巧**：**位掩码 + 右移**（一次取出 4 位），配合两补数处理负数。  
- **适用的题型**：  
  1. 把整数转换为二进制/八进制/十六进制字符串（类似本题）。  
  2. 判断整数的奇偶性、提取特定位（如「位 1 的个数」）。  
  3. 计算整数的反转、翻转字节序等位运算题。  
- **一句话总结**：**“每次抓走最低的四位，用掩码和右移把它们翻译成字符”** 是解这类进制转换的钥匙。

## 反思  

- **第一反应**：先把数字转换成二进制，再手动分组——这是一种“先画图再找规律”的直觉。  
- **最容易踩的坑**：  
  - 负数的处理不当：直接右移负数会保留符号位，导致结果错误。必须先把负数转成 32 位无符号形式（加 `2**32`）。  
  - 忘记处理 `num == 0` 的情况，循环体会直接跳过，返回空字符串。  
  - 结果需要去掉前导零（除非是唯一的 `0`）。  
- **下次遇到同类题**：第一步先**思考能否直接用位运算一次取出固定宽度的块**（如 4 位、8 位），而不是先把所有位全部展开再处理。这样往往能直接得到最优解。
