## 题目（英文原版）

**Description**

Given the coordinates of four points in 2D space p1, p2, p3 and p4, return true if the four points construct a square.
The coordinate of a point pi is represented as [xi, yi]. The input is not given in any order.
A valid square has four equal sides with positive length and four equal angles (90-degree angles).

**Examples**

**Example 1:**

```
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,1]
Output: true
```

**Example 2:**

```
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,12]
Output: false
```

**Example 3:**

```
Input: p1 = [1,0], p2 = [-1,0], p3 = [0,1], p4 = [0,-1]
Output: true
```

**Constraints**

- p1.length == p2.length == p3.length == p4.length == 2
- -104 <= xi, yi <= 104

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直观的想法是：把四个点的顺序摆好（因为题目说输入顺序是随意的），  
然后逐条检查 **四条边相等且都大于 0**，**四个角都是直角**。  

- **数据结构**：我们只需要把四个点装进一个列表 `pts = [p1, p2, p3, p4]`，  
  再利用 `itertools.permutations` 产生 4! = 24 种排列。  
  `permutations` 就像把四张卡片随意抽出来排成一行，遍历所有可能的顺序。  

- **为什么正确**：如果四个点真的能组成一个正方形，那么一定存在一种排列，使得  
  按顺时针（或逆时针）连起来的四条边长度相等且相邻两条边的夹角为 90°。  
 遍历所有排列后，只要找到这样一种排列，就可以返回 `True`。  

- **时间/空间复杂度**：  
  - **时间**：我们要检查 24 种排列，每种排列要算 4 条边的长度和 4 次向量点积（判断是否垂直），  
    所以总体是常数级别的 `O(24) ≈ O(1)`。  
    为了帮助初学者理解，这里把它称作 **“遍历所有可能的排列，时间随点的个数的阶乘增长”**，  
    即 **O(n!)**（这里 n=4，故实际是 24 次操作）。  
  - **空间**：只用了几个临时变量和一个长度为 4 的列表，空间是 **O(1)**（常数级）。

#### 代码（Python）

```python
import itertools
from typing import List

def distance_sq(a: List[int], b: List[int]) -> int:
    """返回两点之间的欧氏距离的平方，避免使用浮点数"""
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy          # 这里的平方相当于“距离”，不需要开根号

def dot(u: List[int], v: List[int]) -> int:
    """向量点积，若为 0 表示两向量垂直（直角）"""
    return u[0] * v[0] + u[1] * v[1]

def is_square_bruteforce(p1: List[int], p2: List[int],
                         p3: List[int], p4: List[int]) -> bool:
    points = [p1, p2, p3, p4]

    # 枚举所有排列（相当于把四张卡片随意排成一行）
    for perm in itertools.permutations(points):
        a, b, c, d = perm          # 按顺时针（或逆时针）连成四边形

        # 计算四条边的长度的平方
        side1 = distance_sq(a, b)
        side2 = distance_sq(b, c)
        side3 = distance_sq(c, d)
        side4 = distance_sq(d, a)

        # 所有边必须相等且长度大于 0
        if side1 == 0:               # 任何两点重合都不可能是正方形
            continue
        if not (side1 == side2 == side3 == side4):
            continue

        # 检查相邻两条边是否垂直（点积为 0）
        # 向量 ab、bc、cd、da
        ab = [b[0] - a[0], b[1] - a[1]]
        bc = [c[0] - b[0], c[1] - b[1]]
        cd = [d[0] - c[0], d[1] - c[1]]
        da = [a[0] - d[0], a[1] - d[1]]

        if dot(ab, bc) == 0 and dot(bc, cd) == 0 \
           and dot(cd, da) == 0 and dot(da, ab) == 0:
            return True               # 找到一种合法排列

    return False                      # 没有任何排列满足条件
```

#### 复杂度  

- **时间复杂度**：`O(4!) = O(24) ≈ O(1)` —— 只要 24 种排列，常数时间即可判断。  
  用大白话说，就是“即使点的数量再多，这种写法也会指数级爆炸”。  
- **空间复杂度**：`O(1)` —— 只用了几个临时变量，和输入规模无关。

### 2. 最优解

#### 思路  

暴力解的“慢点”其实是 **遍历所有排列**，虽然这里常数很小，但在面试里我们更喜欢 **一次性判断**，不需要枚举。  

观察正方形的几何特性：

1. 正方形有 **4 条相等的边**，长度记为 `s`。  
2. 正方形的 **对角线长度相等**，且每条对角线恰好是两条边的斜边，长度记为 `d`。  
3. 在平面上任意 4 个点，总会产生 **6 条两点之间的距离**（组合数 C(4,2)）。  
4. 对于正方形，这 6 条距离只有 **两种不同的数值**：  
   - 较小的 `s`（出现 4 次，对应四条边）  
   - 较大的 `d`（出现 2 次，对应两条对角线）  
5. 另外，`d` 必须是 `s` 的 **两倍**（因为在直角三角形中，斜边平方 = 两直角边平方之和，故 `d = 2 * s` 在平方意义上成立）。

基于以上观察，只要我们 **把 6 条两点间的距离的平方全部算出来**，然后检查：

- 是否恰好出现 **两种不同的正数**；
- 较小的那种出现 **4 次**，较大的出现 **2 次**；
- 较大的正好是 **2 倍的较小**（因为我们比较的是平方距离，故 `d = 2 * s`）。

这一步只用了常数次循环，时间复杂度是 **O(1)**（严格来说是 `O(1)`，因为点的数量固定为 4），空间同样是 **O(1)**。

> **类比**：把 4 张卡片的相互距离想象成 “邮局之间的邮递距离”。  
> 正方形的邮局之间只有两种距离：邻居之间的短距离（四次），以及对角线的长距离（两次），且长距离恰好是短距离的两倍（在平方意义上）。

#### 代码（Python）

```python
from typing import List
from collections import Counter

def distance_sq(a: List[int], b: List[int]) -> int:
    """返回两点之间距离的平方，避免浮点数误差"""
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy

def is_square_optimal(p1: List[int], p2: List[int],
                      p3: List[int], p4: List[int]) -> bool:
    points = [p1, p2, p3, p4]
    dists = []                     # 存放 6 条两点之间的距离平方

    # 计算所有组合的距离（共 C(4,2) = 6 条）
    for i in range(4):
        for j in range(i + 1, 4):
            d = distance_sq(points[i], points[j])
            if d == 0:              # 任意两点重合，直接不是正方形
                return False
            dists.append(d)

    cnt = Counter(dists)           # 统计每个距离出现的次数
    # 正方形应恰好出现两种距离，且出现次数分别为 4 和 2
    if len(cnt) != 2:
        return False

    side, diag = sorted(cnt.items(), key=lambda x: x[0])  # 按距离大小排序
    side_len, side_cnt = side
    diag_len, diag_cnt = diag

    # 边出现 4 次，斜对角出现 2 次
    if side_cnt != 4 or diag_cnt != 2:
        return False

    # 对角线的平方应是边的平方的两倍（勾股定理）
    if diag_len != 2 * side_len:
        return False

    return True
```

#### 复杂度  

- **时间复杂度**：`O(1)` —— 只做了 6 次距离计算和几次常数级的计数、比较。  
  与暴力解相比，**不需要遍历 24 种排列**，因此更简洁、更快。  
- **空间复杂度**：`O(1)` —— 只用了一个长度为 6 的列表和一个计数器，空间不随输入规模增长。

## 心得  

- **核心技巧**：**利用几何性质把“形状判定”转化为“距离的分布”**，即只看点对之间的距离而不关心它们的顺序。  
- **适用的题型**：  
  1. **Valid Square**（本题）  
  2. **Valid Triangle**（判断三点能否构成等边三角形）  
  3. **Number of Boomerangs**（统计点之间相同距离的组合）  
- **一句话总结解题钥匙**：*“正方形的六条两点距离只能出现两种数值，且出现次数分别是 4 与 2，长的恰是短的两倍（平方意义）”。*

## 反思  

- **第一反应**：看到“正方形”四个点，立刻想到 **“把点排成顺时针/逆时针，检查边相等且角为 90°”**，于是写出了暴力枚举的思路。  
- **最容易踩的坑**：  
  - **点重合**：如果出现两点坐标相同，距离为 0，必须提前返回 `False`，否则会把 0 当作合法的最短边。  
  - **仅比较距离大小而忘记出现次数**：只要出现两种距离但次数不对（例如矩形）会误判。  
  - **忘记使用距离的平方**：直接使用 `sqrt` 会引入浮点误差，比较时应使用整数的平方距离。  
- **下次遇到同类题**：第一步先 **统计所有点对的距离（或距离平方）**，观察出现次数的模式，再依据几何特性（等边、等腰、正方形等）进行判断。这样可以一次性得到答案，避免枚举所有排列。
