# #396. 旋转函数 / Rotate Function

## 题目（英文原版）

**Description**

You are given an integer array nums of length n.
Assume arrk to be an array obtained by rotating nums by k positions clock-wise. We define the rotation function F on nums as follow:
Return the maximum value of F(0), F(1), ..., F(n-1).
The test cases are generated so that the answer fits in a 32-bit integer.

**Examples**

**Example 1:**

```
Input: nums = [4,3,2,6]
Output: 26
Explanation:
F(0) = (0 * 4) + (1 * 3) + (2 * 2) + (3 * 6) = 0 + 3 + 4 + 18 = 25
F(1) = (0 * 6) + (1 * 4) + (2 * 3) + (3 * 2) = 0 + 4 + 6 + 6 = 16
F(2) = (0 * 2) + (1 * 6) + (2 * 4) + (3 * 3) = 0 + 6 + 8 + 9 = 23
F(3) = (0 * 3) + (1 * 2) + (2 * 6) + (3 * 4) = 0 + 2 + 12 + 12 = 26
So the maximum value of F(0), F(1), F(2), F(3) is F(3) = 26.
```

**Example 2:**

```
Input: nums = [100]
Output: 0
```

**Constraints**

- n == nums.length
- 1 <= n <= 105
- -100 <= nums[i] <= 100

## 题目（中文翻译）

给定一个长度为 `n` 的整数数组（integer array）`nums`。  
设 `arr_k` 为将 `nums` **顺时针**（clock‑wise）旋转 `k` 位后得到的数组。我们定义**旋转函数**（rotation function）`F` 如下：

> `F(k) = Σ_{i=0}^{n-1} i * arr_k[i]`

返回 `F(0), F(1), ..., F(n‑1)` 中的最大值。  
测试用例保证答案能够放入 32 位整数。

### 示例

#### 示例 1
```text
Input: nums = [4,3,2,6]
Output: 26
Explanation:
F(0) = (0 * 4) + (1 * 3) + (2 * 2) + (3 * 6) = 0 + 3 + 4 + 18 = 25
F(1) = (0 * 6) + (1 * 4) + (2 * 3) + (3 * 2) = 0 + 4 + 6 + 6 = 16
F(2) = (0 * 2) + (1 * 6) + (2 * 4) + (3 * 3) = 0 + 6 + 8 + 9 = 23
F(3) = (0 * 3) + (1 * 2) + (2 * 6) + (3 * 4) = 0 + 2 + 12 + 12 = 26
因此 `F(0), F(1), F(2), F(3)` 的最大值为 `F(3) = 26`。
```

#### 示例 2
```text
Input: nums = [100]
Output: 0
```

### 约束条件
- `n == nums.length`
- `1 <= n <= 10^5`
- `-100 <= nums[i] <= 100`

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：  
1. 按照题意把数组 `nums` 先“顺时针旋转” `k` 位，得到 `arr_k`。  
   - 这里的旋转可以想象成把一列排好的书往右搬几本，搬到最右边的书又从左边重新出现。  
2. 按公式把每个位置的下标乘以对应的元素求和，得到 `F(k)`。  
3. 把所有 `k = 0 … n‑1` 的结果都算出来，取最大值。

> **数据结构**：这里只需要 **数组**（list），因为我们只在数组上做下标访问和遍历。数组就像一本顺序排好的笔记本，想找第 i 页直接看下标就行，时间很快。

> **为什么正确**：暴力方法把题目要求的每一种旋转情况都完整地算了一遍，必然能得到真正的最大值。

> **时间/空间复杂度**：  
> - 对每个 `k`（一共有 `n` 种）我们都要遍历整个数组（`n` 次），所以总共要做 `n × n = n²` 次基本操作。  
>   - **O(n²)** 的意思是：如果数组长度翻倍，工作量会变成原来的 **四倍**（因为平方关系）。  
> - 只用了常数个额外变量（比如保存结果的列表），所以空间是 **O(1)**（不随 `n` 增长）。

#### 代码（Python）

```python
from typing import List

def maxRotateFunction_bruteforce(nums: List[int]) -> int:
    n = len(nums)
    if n == 0:
        return 0

    # 记录所有 F(k) 的最大值
    max_val = float('-inf')

    # 依次枚举 k = 0 … n-1
    for k in range(n):
        cur = 0                     # 当前的 F(k)
        # 计算旋转后第 i 位对应的原始下标
        # 旋转 k 位相当于把原数组右移 k，左边的元素会跑到后面
        for i in range(n):
            # (i - k) % n 把下标映射回原数组的位置
            orig_idx = (i - k) % n
            cur += i * nums[orig_idx]
        max_val = max(max_val, cur)

    return max_val
```

> 关键行解释（中文注释）已写在代码里，直接可以运行。

#### 复杂度  

- **时间复杂度**：`O(n²)` —— 需要两层循环，外层 `n` 次，内层也 `n` 次。  
- **空间复杂度**：`O(1)` —— 只用了几个整数变量，额外空间不随 `n` 增长。

### 2. 最优解  

#### 思路  

暴力解的瓶颈在于：**我们每次都完整遍历一遍数组**，而其实相邻的两个旋转结果 `F(k-1)` 与 `F(k)` 只差很小，可以利用**递推**来快速算出。  

下面一步步推导出递推式：

1. **记住两个常量**  
   - `sumAll = Σ nums[i]`（所有元素的和）  
   - `F(0) = Σ i * nums[i]`（不旋转时的函数值）  

2. **观察旋转的影响**  
   把数组顺时针旋转一次（`k` 从 `0` 变到 `1`），相当于把最后一个元素 `nums[n‑1]` 移到最前面，其余元素整体向右移动一位。  

   设 `F(k-1)` 已知，求 `F(k)`：

   ```
   F(k-1) = 0*nums[n-1] + 1*nums[0] + 2*nums[1] + … + (n-1)*nums[n-2]
   F(k)   = 0*nums[n-2] + 1*nums[n-1] + 2*nums[0] + … + (n-1)*nums[n-3]
   ```

   把两式相减，几乎所有项都抵消，只剩下两部分：

   - **所有元素的和** `sumAll`（因为每个元素的系数整体都加了 1）  
   - **被移动到最前面的元素** `nums[n-k]`（在 `F(k-1)` 中乘了 `0`，在 `F(k)` 中乘了 `n-1`，相当于多了 `-(n)*nums[n-k]`）

   整理后得到 **递推公式**：

   ```
   F(k) = F(k-1) + sumAll - n * nums[n-k]
   ```

   这里的 `n-k` 可以写成 `(n - k) % n`，方便在循环里直接使用。

3. **利用递推求最大值**  
   - 先算出 `sumAll` 与 `F(0)`（一次遍历即可）。  
   - 再从 `k = 1` 到 `n-1`，用上面的公式逐步更新 `F(k)`，同时记录最大值。  
   - 只需要 **O(n)** 的时间和 **O(1)** 的额外空间。

> **核心算法**：**递推 + 前缀和的思想**（这里的 `sumAll` 类似前缀和的整体和）。  
> **数据结构**：仍然只用数组和几个整数。  

> **类比**：想象你在一排排队的同学中，每个人的分数乘以他所在的位置编号。每次把最后一个同学搬到最前面，整体分数的变化只跟**总分**和**搬走的同学的分数**有关，其他人的相对位置不变。于是我们只需要关注这两件事，就能快速算出新分数。

#### 代码（Python）

```python
from typing import List

def maxRotateFunction(nums: List[int]) -> int:
    n = len(nums)
    if n == 0:
        return 0

    total_sum = sum(nums)               # Σ nums[i]，所有元素的和
    f = sum(i * num for i, num in enumerate(nums))  # F(0)
    max_val = f                         # 当前最大的 F(k)

    # 逐步计算 F(1), F(2), …, F(n-1)
    # 这里的 nums[n - k] 正好是本次被“搬到最前面”的元素
    for k in range(1, n):
        # 根据递推式更新 f
        f = f + total_sum - n * nums[n - k]
        max_val = max(max_val, f)

    return max_val
```

> 关键行解释已写在代码里，直接可运行。

#### 复杂度  

- **时间复杂度**：`O(n)` —— 只遍历数组两遍（一次求和一次递推），不随 `k` 的增加而再次遍历。  
  - 与暴力的 `O(n²)` 对比：如果 `n` 从 10⁴ 增长到 10⁵，暴力会慢到几秒甚至超时，而线性算法仍然在毫秒级完成。  
- **空间复杂度**：`O(1)` —— 只用了常数个额外整数（`total_sum`, `f`, `max_val`），不随数组长度增长。

## 心得  

- **核心技巧**：**递推关系 + 整体求和**。通过观察相邻两次旋转的差别，发现可以用一个常数时间的公式把 `F(k)` 从 `F(k‑1)` 推导出来。  
- **适用的题型**  
  1. **旋转数组类**（如 LeetCode 189、Rotate Array）——常用“一次遍历+数学关系”求最优。  
  2. **滑动窗口求和/乘积**（如 209、713）——相邻窗口只差进出一个元素，递推同理。  
  3. **循环移位的线性函数**（如 396、Maximum Sum of 3 Non‑Overlapping Subarrays）——利用整体和或前缀和做快速更新。  
- **一句话总结**：**把“每次全盘重新计算”改成“只更新受影响的那一点”，就能把二次暴力降到线性。**

## 反思  

- **第一反应**：看到公式 `F(k) = Σ i * arr_k[i]`，第一时间想到把数组真正旋转，然后逐个算，导致想到暴力解。  
- **最容易踩的坑**  
  1. **下标越界**：旋转时要用模运算 `(i - k) % n` 或者 `nums[n - k]`，否则会出现负数下标。  
  2. **整数溢出**：在某些语言（如 C/C++）需要注意 32 位整数范围，Python 自动大整数，但题目保证答案在 32 位范围。  
  3. **空数组**：虽然约束 `n ≥ 1`，但写代码时仍要防御性地检查 `n == 0`。  
- **下次遇到同类题**：**先问自己**“相邻两次状态之间有什么只改变少数元素的关系？”如果答案是“只改变一个元素”，就尝试写出递推公式，往往能把复杂度从 `O(n²)` 降到 `O(n)`。
