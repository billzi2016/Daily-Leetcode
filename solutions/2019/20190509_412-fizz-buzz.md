# #412. Fizz Buzz / Fizz Buzz

> 难度：简单 · 标签：Math、String、Simulation · [LeetCode 链接](https://leetcode.com/problems/fizz-buzz/)

---

## 题目（英文原版）

**Description**

Given an integer n, return a string array answer (1-indexed) where:

**Examples**

**Example 1:**

```
Input: n = 3
Output: ["1","2","Fizz"]
```

**Example 2:**

```
Input: n = 5
Output: ["1","2","Fizz","4","Buzz"]
```

**Example 3:**

```
Input: n = 15
Output: ["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]
```

**Constraints**

- 1 <= n <= 104

---

## 题目（中文翻译）

给定一个整数 `n`，返回一个字符串数组（string array）`answer`（下标从 1 开始），其中第 `i` 项满足以下规则：

- 若 `i` 能被 3 整除且不能被 5 整除，则 `answer[i] = "Fizz"`；
- 若 `i` 能被 5 整除且不能被 3 整除，则 `answer[i] = "Buzz"`；
- 若 `i` 同时能被 3 与 5 整除，则 `answer[i] = "FizzBuzz"`；
- 其余情况下，`answer[i]` 为整数 `i` 的字符串形式。

**示例**

示例 1  
输入: `n = 3`  
输出: `["1","2","Fizz"]`

示例 2  
输入: `n = 5`  
输出: `["1","2","Fizz","4","Buzz"]`

示例 3  
输入: `n = 15`  
输出: `["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]`

**约束条件**

- `1 <= n <= 10^4`

---

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  
最直接的想法就是把 1 到 n 的每一个整数都检查一遍，判断它是否能被 3、5 整除，然后把对应的文字放进答案数组。  

- **使用的数据结构**：  
  - **列表（list）**：就像装东西的盒子，顺序放入每一次的结果，最后一次性返回。  
  - **字符串（str）**：每个结果都是一段文字，`"Fizz"`、`"Buzz"` 或者数字本身的字符串。  

- **为什么正确**：  
  - 题目要求的规则只和当前数字是否能被 3、5 整除有关，遍历所有数字并按规则转化，必然得到题目规定的顺序和内容。  

- **时间/空间复杂度的大白话**：  
  - **时间复杂度 O(n)**：我们要看每个数字一次，n 越大，就要做的检查越多，工作量和 n 成正比。  
  - **空间复杂度 O(n)**：答案要保存 n 条字符串，存的东西和 n 成正比。  

#### 代码（Python）  

```python
def fizzBuzz(n: int) -> list[str]:
    """
    返回长度为 n 的字符串列表，按照 FizzBuzz 规则转换每个数字。
    """
    ans = []                               # 用列表收集结果，类似装东西的盒子
    for i in range(1, n + 1):              # 从 1 遍历到 n（包括 n）
        if i % 15 == 0:                    # 同时能被 3 和 5 整除（15 的倍数）
            ans.append("FizzBuzz")         # 放入 "FizzBuzz"
        elif i % 3 == 0:                   # 只能被 3 整除
            ans.append("Fizz")
        elif i % 5 == 0:                   # 只能被 5 整除
            ans.append("Buzz")
        else:                              # 两个都不能整除，直接放数字本身的字符串
            ans.append(str(i))
    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n)` —— 代码里有一个长度为 n 的循环，里面的判断都是 `O(1)` 的常数操作。  
- **空间复杂度**：`O(n)` —— 需要一个长度为 n 的列表来存放返回的字符串。

### 2. 最优解  

#### 思路  
对这道 **Easy** 题目来说，暴力解已经是最优的线性解法。唯一可以再“优化”的地方是把 **if‑elif‑else** 写得更简洁，或者使用 **列表推导式**（list comprehension）一次性生成答案。核心仍然是 **取模运算（%）** 来判断能否被 3、5 整除，这就像检查一本词典里某个单词是否在特定的页码上。  

- **瓶颈在哪里？**  
  - 暴力解的唯一循环已经是 `O(n)`，没有多余的嵌套循环或递归，几乎不可能再把时间再降下来。  
- **优化思路**：  
  - 用 `i % 3`、`i % 5` 直接得到布尔值，再拼接字符串，省去两次 `if` 判断。  
  - 采用列表推导式，让代码更紧凑，执行速度几乎相同。  

#### 代码（Python）  

```python
def fizzBuzz_opt(n: int) -> list[str]:
    """
    采用列表推导式的写法，逻辑与上面的暴力解相同，代码更紧凑。
    """
    return [
        ("Fizz" * (i % 3 == 0) + "Buzz" * (i % 5 == 0)) or str(i)
        for i in range(1, n + 1)
    ]
```

> **解释关键行**：  
> - `("Fizz" * (i % 3 == 0) + "Buzz" * (i % 5 == 0))`：  
>   - `i % 3 == 0` 为 `True` 时等价于 `1`，`False` 等价于 `0`。  
>   - `"Fizz" * 1` → `"Fizz"`，`"Fizz" * 0` → `""`（空串）。  
>   - 同理得到 `"Buzz"` 或空串，二者相加得到 `"FizzBuzz"`、`"Fizz"`、`"Buzz"` 或 `""`。  
> - `or str(i)`：如果上一步得到的空串（即既不能被 3 整除也不能被 5 整除），就返回数字本身的字符串。  

#### 复杂度  

- **时间复杂度**：`O(n)` —— 仍然只遍历一次 `1..n`，每次的运算都是常数时间。  
- **空间复杂度**：`O(n)` —— 需要保存 n 条结果的列表。  

相比暴力写法，时间和空间并没有本质变化，只是 **代码更简洁、常数因子略小**。

## 心得  

- **核心技巧**：**取模运算**（`%`）判断能否被整数整除，配合字符串拼接即可完成规则映射。  
- **该技巧适用的题型**：  
  1. **判断奇偶数**：如“只输出偶数”。  
  2. **数字分类**：如“输出 1~n 中能被 2 或 3 整除的数字”。  
  3. **周期性输出**：如“每 4 步输出一次 `Ping`”。  
- **一句话总结解题钥匙**：**“用 `%` 把数字映射到对应文字，再把所有结果按顺序装进列表”**。

## 反思  

- **拿到题目第一反应**：直接想到遍历 `1..n`，用 `if i%3==0`、`if i%5==0` 判断，写出对应的字符串。  
- **最容易踩的坑**：  
  - **忘记先判断 15 的倍数**（即同时能被 3、5 整除），导致输出 `"Fizz"` 或 `"Buzz"` 而不是 `"FizzBuzz"`。  
  - **返回值类型**：题目要求返回 **字符串数组**，不能返回整数。  
  - **边界条件**：`n=1` 时只返回 `["1"]`，代码要能处理最小输入。  
- **下次遇到同类题，第一步该想到**：**“先把所有数字逐个遍历，然后用取模判断属于哪一种情况，最后统一收集到列表中返回”。**
