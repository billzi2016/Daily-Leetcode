## 题目（中文翻译）

给定一个字符串数组 `words`，返回所有可以仅使用 **美国键盘（American keyboard）** 中同一行的字母输入的单词。  
需要注意，字符串的大小写不敏感，同一个字母的大小写形式视为位于同一行。

在美国键盘中，字母布局如下（从上到下）：

- 第一行：`q w e r t y u i o p`
- 第二行：`a s d f g h j k l`
- 第三行：`z x c v b n m`

示例  

**示例 1**  
```text
Input: words = ["Hello","Alaska","Dad","Peace"]
Output: ["Alaska","Dad"]
Explanation:
由于大小写不敏感，字符 "a" 与 "A" 均位于美国键盘的第 2 行。
```

**示例 2**  
```text
Input: words = ["omk"]
Output: []
```

**示例 3**  
```text
Input: words = ["adsdf","sfd"]
Output: ["adsdf","sfd"]
```

**约束条件**  

- `1 <= words.length <= 20`
- `1 <= words[i].length <= 100`
- `words[i]` 只包含英文字母（大小写均可）。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把键盘的每一行都记下来**，然后把每个单词的所有字母都和这些行对应起来，只要整条单词的字母全部落在同一行，就把它留下。

- **数据结构**：这里用到的主要是 **哈希表（字典）**，它就像一本**查字典**，把每个字母（key）对应到它所在的行号（value），查询速度快，像在字典里找页码一样 O(1)。
- **正确性**：因为字母只可能出现在键盘的三行之一，只要把每个字母映射到它所在的行号，检查整条单词的行号是否全相同即可。若相同，则说明所有字母都在同一行，符合题意。
- **时间/空间复杂度**：  
  - **时间**：我们要遍历 `words` 中的每个单词（记为 `n`），每个单词再遍历它的每个字符（记为 `m`，单词最长 100），所以总共是 `O(n·m)`。这里的 `O` 符号可以想象成“随着输入规模增长，耗时会线性增长”。  
  - **空间**：只需要保存字母到行号的映射表，大小是固定的 26（英文字母），所以是 `O(1)`，即常数空间。

#### 代码（Python）

```python
from typing import List

def findWords(words: List[str]) -> List[str]:
    # 1. 建立字母 → 行号 的映射，像查字典一样
    row_map = {}
    rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"]      # 键盘的三行（全小写）
    for i, r in enumerate(rows):
        for ch in r:
            row_map[ch] = i          # 把每个字母映射到 0、1、2 三个行号之一

    ans = []                         # 用来保存符合条件的单词
    for w in words:
        # 把单词全部转成小写，大小写不影响行号
        lower = w.lower()
        # 取第一个字符所在的行号，作为基准
        first_row = row_map[lower[0]]
        # 检查所有字符的行号是否都和基准相同
        if all(row_map[ch] == first_row for ch in lower):
            ans.append(w)            # 符合条件，加入答案

    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n·m)` —— 遍历每个单词的每个字符，随输入规模线性增长。  
- **空间复杂度**：`O(1)` —— 只用了固定大小的字典（26 条映射），不随输入大小改变。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈在于每次都要遍历整条单词的所有字符**。但因为键盘只有三行，实际上我们可以把每一行的字母集合预先准备好，用**集合（set）**的“包含”操作一次性判断整个单词是否全部在同一行，省去逐字符比较的循环。

**优化步骤**：

1. 把每一行的字母分别存进 `set`，相当于“把每行的字母装进不同的盒子”。  
2. 对每个单词，同样转成小写后，检查它的所有字母集合是否是这三个盒子中的任意一个的子集（`issubset`），如果是，则说明它只使用了该行的字母。  
3. 这种检查只需要一次集合运算，内部实现已经是高效的哈希查找，整体仍是 `O(n·m)`，但常数更小，更简洁。

**核心概念解释**：

- **集合（set）**：类似于**装有唯一元素的口袋**，可以快速判断一个元素是否在里面（时间复杂度 O(1)），也可以快速判断“所有元素是否全部在另一个集合里”。  
- **子集（subset）**：把一个小盒子装进大盒子，问“小盒子里的东西是不是全部都在大盒子里”。如果答案是“是”，说明所有字母都在同一行。

#### 代码（Python）

```python
from typing import List

def findWords(words: List[str]) -> List[str]:
    # 1. 把键盘的三行分别放进 set，像装在三个不同的盒子里
    row1 = set("qwertyuiop")
    row2 = set("asdfghjkl")
    row3 = set("zxcvbnm")
    rows = [row1, row2, row3]

    ans = []
    for w in words:
        lower = w.lower()
        # 把单词的所有字符放进一个 set，去掉重复字母
        chars = set(lower)
        # 只要有一个键盘行的集合能够“容下”这些字符，就符合要求
        if any(chars.issubset(row) for row in rows):
            ans.append(w)

    return ans
```

#### 复杂度  

- **时间复杂度**：`O(n·m)` —— 仍然需要把每个单词的字符放进集合，但集合的 `issubset` 操作在内部是 O(k)（k 为字符种类数），整体仍随输入线性增长。相比逐字符比较，常数更小。  
- **空间复杂度**：`O(1)` —— 三个行集合大小固定，额外的 `chars` 集合最多 26 个字符，也算常数空间。

## 心得

- **核心技巧**：使用**哈希表（字典）或集合**把字母映射到键盘行，并利用**子集判断**一次性验证整个单词。  
- **适用的题型**：  
  1. 判断字符串是否只由特定字符集合组成（如 “valid word” 类题）。  
  2. “字符分组” 类问题，例如 “将字符串划分为只含元音/辅音的子串”。  
  3. 使用集合快速过滤符合条件的元素（如 “找出只出现一次的字符”）。
- **一句话总结解题钥匙**：**把键盘每行的字母预先装进集合，用子集检查一次搞定整条单词**。

## 反思

- **第一反应**：看到“只能用键盘同一行的字母”，立刻想到把每个字母对应到行号，逐字符比较。  
- **最容易踩的坑**：  
  - 忽视大小写：题目说不区分大小写，需要先统一转成小写或大写。  
  - 直接比较字符而不是行号，导致代码冗长且易出错。  
  - 对空字符串没有考虑（虽然约束里长度 ≥ 1）。  
- **下次思路**：遇到“只能使用某类字符”的限制时，第一步就把**合法字符集合准备好**（或映射），再用**集合操作**一次性过滤，避免逐字符的重复工作。
