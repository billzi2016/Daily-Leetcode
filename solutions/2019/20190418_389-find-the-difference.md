# #389. 找出不同的字符 / Find the Difference

> 难度：简单 · 标签：Hash Table、String、Bit Manipulation、Sorting · [LeetCode 链接](https://leetcode.com/problems/find-the-difference/)

---

## 题目（英文原版）

**Description**

You are given two strings s and t.
String t is generated by random shuffling string s and then add one more letter at a random position.
Return the letter that was added to t.

**Examples**

**Example 1:**

```
Input: s = "abcd", t = "abcde"
Output: "e"
Explanation: 'e' is the letter that was added.
```

**Example 2:**

```
Input: s = "", t = "y"
Output: "y"
```

**Constraints**

- 0 <= s.length <= 1000
- t.length == s.length + 1
- s and t consist of lowercase English letters.

---

## 题目（中文翻译）

你得到两个字符串 `s` 和 `t`。  
字符串 `t` 是通过对字符串 `s` 随机洗牌（random shuffling）后，在任意位置再插入一个字母（letter）得到的。  
请返回被插入到 `t` 中的那个字母。

**示例 1**  
输入: `s = "abcd", t = "abcde"`  
输出: `"e"`  
解释: `'e'` 是被添加的字母。

**示例 2**  
输入: `s = "", t = "y"`  
输出: `"y"`  
解释: `'y'` 是被添加的字母。

**约束条件**  

- `0 <= s.length <= 1000`  
- `t.length == s.length + 1`  
- `s` 和 `t` 仅由小写英文字母组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：把字符串 `t` 的每一个字符都在 `s` 里找一遍，找到就把 `s` 中对应的字符标记为「已经用过」；如果在 `s` 里找不到，就说明这个字符是多出来的。  

- **用到的数据结构**：我们可以用一个列表 `used`（长度等于 `s`）记录每个字符是否已经匹配。把 `used[i]` 当成「字典里的页码」——`True` 表示这页已经被翻过去了，`False` 表示还在。
- **为什么正确**：因为 `t` 只比 `s` 多一个字符，遍历 `t` 时必定能在 `s` 中找到所有原本的字符（只要把已经匹配的那一位排除），剩下的那个找不到的字符就是答案。

#### 代码（Python）

```python
def findTheDifference_bruteforce(s: str, t: str) -> str:
    # 用一个列表记录 s 中每个字符是否已经被匹配
    used = [False] * len(s)          # 初始全是 False，表示「字典里还没翻到这页」
    
    # 遍历 t 中的每个字符
    for ch in t:
        found = False                # 标记这次是否在 s 中找到匹配的字符
        # 在 s 中逐个查找，跳过已经标记为 True 的位置
        for i, sc in enumerate(s):
            if not used[i] and sc == ch:
                used[i] = True       # 找到后把这位标记为「已经用过」
                found = True
                break                # 只匹配一次就好，直接跳出内层循环
        # 如果整趟 s 都没有匹配成功，说明 ch 是多出来的字符
        if not found:
            return ch
    # 理论上不会走到这里，因为一定有一个多余字符
    return ''
```

#### 复杂度

- **时间复杂度**：`O(n²)`（这里的 `n` 代表 `s` 的长度）。因为对 `t` 的每个字符都要在 `s` 里遍历一次，最坏情况相当于「把每本字典的每一页都翻一遍」。
- **空间复杂度**：`O(n)`。额外用了一个长度为 `len(s)` 的布尔数组 `used`，相当于「记录了每页是否已经翻过」。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于 **重复遍历** `s`，导致二次方时间。我们可以把「找字符」的过程换成 **一次遍历** 并且不需要额外的记录结构。这里有两种常见且高效的思路：

1. **哈希计数（频率表）**  
   - 把 `s` 中每个字母出现的次数记在一个长度为 26 的数组里（因为只涉及小写英文字母）。  
   - 再遍历 `t`，把对应位置的计数减 1；当计数变成负数时，说明这个字母在 `t` 中出现的次数比 `s` 多，正是我们要找的字符。  
   - 这相当于「把字典的每一页都贴上标签，看看哪一页的标签多了一张」。

2. **位运算 XOR**（更简洁）  
   - XOR 有两个重要性质：`a ^ a = 0`（相同的数异或得 0）以及 `a ^ 0 = a`（和 0 异或不变）。  
   - 把 `s` 和 `t` 中所有字符的 ASCII 码依次做 XOR，成对相同的字符会相互抵消，最后剩下的就是唯一多出的那个字符的 ASCII 码。  
   - 想象成「把所有字母的编号放进一个盒子里，成对的会相互消失，只剩下孤单的那一个」。

下面给出 **XOR** 的实现，因为它代码最短、空间最省，并且不需要显式的哈希表。

#### 代码（Python）

```python
def findTheDifference(s: str, t: str) -> str:
    # 先把所有字符的 ASCII 码异或起来，初始值为 0
    xor_val = 0                     # 0 就像「空盒子」，什么都不影响
    
    # 把 s 中的字符全部放进去
    for ch in s:
        xor_val ^= ord(ch)          # ord(ch) 把字符转成对应的整数（ASCII 码）
    
    # 再把 t 中的字符全部放进去
    for ch in t:
        xor_val ^= ord(ch)
    
    # 最后剩下的整数就是多余字符的 ASCII 码，转回字符返回
    return chr(xor_val)             # chr 把整数再变回字符
```

> **代码说明**  
> - `ord(ch)`：把字符 `ch` 转成对应的整数值（相当于给每个字母贴上编号）。  
> - `xor_val ^= ord(ch)`：把编号放进「盒子」里，遇到相同的编号会相互抵消。  
> - `chr(xor_val)`：把剩下的编号再翻译成字符，得到答案。

#### 复杂度

- **时间复杂度**：`O(n)`（只遍历两遍字符串，各自一次）。这里的 `n = len(t)`，相当于「一次性把所有字母都放进盒子」。
- **空间复杂度**：`O(1)`（只用了一个整数变量 `xor_val`），不依赖于字符串长度，等价于「盒子大小固定」。

## 心得

- **核心技巧**：利用 **XOR 异或** 的抵消特性，或者使用 **固定大小的频率表**（哈希计数）来一次遍历解决字符差异问题。  
- **适用的题型**  
  1. 两个数组/字符串，仅有一个元素出现次数不同（如 LeetCode 389 “Find the Difference”）。  
  2. 找出只出现一次的数字（LeetCode 136 “Single Number”）。  
  3. 两个集合的差集，仅差一个元素的情形。  
- **一句话总结**：**“成对相消，留下孤儿”**——用 XOR 或计数表把相同的字符抵消，只剩下多出来的那一个。

## 反思

- **第一反应**：看到 “t 是 s 打乱后再加一个字符”，第一时间会想到 **哈希计数**，因为计数最直观。  
- **最容易踩的坑**  
  - 忘记考虑 `s` 为空的情况（此时直接返回 `t[0]`），但 XOR 方法天然兼容。  
  - 如果使用字符的 **Unicode 编码** 而不是 **ASCII**，仍然可以工作，只是题目限定为小写英文字母，直接用 `ord`/`chr` 即可。  
- **下次第一步**：先判断 **“是否可以用一次遍历把两集合的差异抵消”**，若可以，考虑 XOR 或固定大小计数表；若不行，再考虑排序或哈希表等通用方法。
