# #344. 反转字符串 / Reverse String

> 难度：简单 · 标签：Two Pointers、String · [LeetCode 链接](https://leetcode.com/problems/reverse-string/)

---

## 题目（英文原版）

**Description**

Write a function that reverses a string. The input string is given as an array of characters s.
You must do this by modifying the input array in-place with O(1) extra memory.

**Examples**

**Example 1:**

```
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

**Example 2:**

```
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

**Constraints**

- 1 <= s.length <= 105
- s[i] is a printable ascii character.

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是：把原来的字符数组 **全部复制** 到一个新数组里，然后把新数组倒着写回原数组。  
- **使用的数据结构**：额外的 Python 列表（相当于我们平时用的“备份本”，就像把一本书全部抄写到另一册）。  
- **为什么正确**：把字符顺序全部倒过来再写回去，自然就实现了“逆序”。  
- **复杂度分析**：  
  - **时间**：我们要遍历一次原数组（`n` 次）再遍历一次新数组（`n` 次），所以总共是 `2n` 次操作，用大 O 表示就是 **O(n)**。这里的 `n` 代表字符个数，想象成 1000 个字符要跑 2000 步。  
  - **空间**：因为额外创建了一个长度为 `n` 的数组，空间使用和字符数是线性关系，记作 **O(n)**，即需要和原数组等量的额外记忆本。

#### 代码（Python）

```python
def reverseString_brute(s: list[str]) -> None:
    """
    暴力解法：使用额外的列表保存逆序结果，再写回原数组
    """
    n = len(s)                     # 记录字符个数
    # 1. 复制并倒序
    reversed_copy = [s[i] for i in range(n-1, -1, -1)]   # 从后往前取字符，生成新列表

    # 2. 把新列表写回原数组
    for i in range(n):
        s[i] = reversed_copy[i]    # 原地改写，每个位置都换成倒序后的字符
```

#### 复杂度

- **时间复杂度**：O(n) — 只要遍历两遍字符就能完成，和字符数量成正比。
- **空间复杂度**：O(n) — 需要额外一个同样大小的列表来存放倒序的字符。

---

### 2. 最优解

#### 思路  
从暴力解可以看到，**额外的列表是浪费** 的。题目要求**原地（in‑place）** 修改且只能使用 **O(1) 额外空间**，所以我们必须在原数组内部完成交换。  
- **慢在哪里**：暴力解每次都往新列表里写，空间开销大，且要两遍遍历。  
- **优化思路**：使用 **双指针**（Two Pointers）技术。把指针 `left` 放在最左边，指针 `right` 放在最右边，**同时向中间移动**，每次把 `left` 与 `right` 位置的字符互换。这样只需要 **一次遍历**，不需要额外空间。  
- **核心概念解释**：  
  - **双指针** 就像我们让两个小朋友站在一根绳子的两端，手里各拿一块糖果。老师说“交换位置”，于是他们把手里的糖果互相递过去，然后一起往中间走，直到相遇为止。  
  - **原地交换**：用 Python 的多元赋值 `s[left], s[right] = s[right], s[left]`，相当于一次性把两块糖果换手，不需要临时的第三块糖果（即 **O(1)** 的额外空间）。

#### 代码（Python）

```python
def reverseString(s: list[str]) -> None:
    """
    最优解：双指针原地翻转字符数组
    只使用常数级别的额外空间（O(1)）
    """
    left, right = 0, len(s) - 1   # left 指向最左，right 指向最右

    while left < right:           # 当 left 与 right 未相遇时继续
        # 交换 left 与 right 位置的字符
        s[left], s[right] = s[right], s[left]   # Python 的元组拆包，一行搞定

        left += 1                 # left 向右移动一步
        right -= 1                # right 向左移动一步
```

#### 复杂度

- **时间复杂度**：O(n) — 每次循环都让两个指针向中间靠拢，最多进行 `n/2` 次交换，仍然和字符数量成正比。和暴力解的时间相同，但没有额外的遍历和复制，常数因子更小。  
- **空间复杂度**：O(1) — 只用了几个整数变量 `left`、`right`，不随 `n` 增长，符合题目“常数级额外空间”要求。

## 心得

- **核心技巧**：双指针（Two Pointers）在数组/字符串的头尾同时操作，实现原地翻转或筛选。  
- **适用的题型**：  
  1. `Palindrome String`（判断回文）——用双指针比较两端字符是否相同。  
  2. `Move Zeroes`（把所有 0 移到数组末尾）——双指针分别指向“当前处理位置”和“下一个非零位置”。  
  3. `Valid Palindrome`（判断字符串是否是回文，忽略非字母字符）——同样是头尾双指针遍历。  
- **一句话总结**：**“让两头的指针相向而行，边走边交换”，就是原地翻转的钥匙。**

## 反思

- **第一反应**：看到“原地逆序”，马上想到“用额外数组复制倒序”。这满足功能但不符合空间要求。  
- **最容易踩的坑**：  
  - 忘记 **左指针 < 右指针** 的停止条件，导致指针交叉后仍然交换，使数组恢复原样。  
  - 直接使用 `s.reverse()`（Python 内置）虽然也满足 O(1) 空间，但在面试或某些平台会被视为**不符合“手写算法”** 的要求。  
- **下次第一步**：先在纸上画出 **“双指针从两端向中间移动”** 的示意图，确认每一步的交换和指针移动，再动手写代码。这样可以迅速定位到最省空间、最直接的实现方式。
