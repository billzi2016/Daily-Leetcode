# #387. 字符串中的第一个唯一字符 / First Unique Character in a String

> 难度：简单 · 标签：Hash Table、String、Queue、Counting · [LeetCode 链接](https://leetcode.com/problems/first-unique-character-in-a-string/)

---

## 题目（英文原版）

**Description**

Given a string s, find the first non-repeating character in it and return its index. If it does not exist, return -1.

**Examples**

**Example 1:**

```
Input: s = "leetcode"
Output: 0
Explanation:
The character 'l' at index 0 is the first character that does not occur at any other index.
```

**Example 2:**

```
Input: s = "loveleetcode"
Output: 2
```

**Example 3:**

```
Input: s = "aabb"
Output: -1
```

**Constraints**

- 1 <= s.length <= 105
- s consists of only lowercase English letters.

---

## 题目（中文翻译）

给定一个字符串（string） `s`，找出其中第一个不重复字符（non-repeating character）并返回其索引（index）。如果不存在这样的字符，返回 `-1`。

### 示例

**示例 1**  
输入: `s = "leetcode"`  
输出: `0`  
解释: 索引 0 处的字符 `'l'` 是第一个在其他位置不出现的字符。

**示例 2**  
输入: `s = "loveleetcode"`  
输出: `2`

**示例 3**  
输入: `s = "aabb"`  
输出: `-1`

### 约束条件

- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：从字符串的第一个字符开始，逐个检查它在后面的子串里出现了几次。如果只出现一次（即不重复），直接返回它的下标；如果出现多次，就继续检查下一个字符。  

- **用到的数据结构**：我们只需要遍历字符串本身，不需要额外的数据结构。可以把每一次“在后面子串里找”想象成在一本书里用手指从当前页往后翻，寻找同一个单词是否再出现。  
- **为什么正确**：因为我们是从左到右依次检查的，一旦遇到第一个只出现一次的字符，它必然是“首个不重复字符”。  
- **时间/空间复杂度**：  
  - 对于每个字符，我们都要再遍历一次剩余的字符来计数。设字符串长度为 `n`，第一轮检查 `n` 次，第二轮检查 `n‑1` 次，…，最后一次检查 1 次，总次数大约是 `n + (n‑1) + … + 1 = n·(n+1)/2`，这在数量级上是 **O(n²)**。  
  - 只用了常数级别的额外空间（几个计数变量），所以空间复杂度是 **O(1)**。  
  - 用大白话说，`O(n²)` 就像你在一个 10,000 人的队伍里，每找一个人都要把后面所有人重新数一遍，工作量会非常大。

#### 代码（Python）

```python
def firstUniqChar_brute(s: str) -> int:
    n = len(s)                     # 字符串长度
    for i in range(n):            # 从左到右遍历每个字符
        cnt = 0                    # 计数该字符出现的次数
        for j in range(n):        # 再次遍历整个字符串统计次数
            if s[i] == s[j]:       # 如果相同，就加一
                cnt += 1
        if cnt == 1:               # 只出现一次，说明是不重复的
            return i               # 返回它的下标
    return -1                      # 全部字符都有重复，返回 -1
```

#### 复杂度

- **时间复杂度**：`O(n²)` — 对每个字符都要遍历整个字符串，工作量随 `n` 的平方增长。  
- **空间复杂度**：`O(1)` — 只用了几个整数变量，不随输入规模扩大而增长。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于**重复遍历**：我们每次都要从头再数一遍。可以把“计数”这一步提前完成，只做一次遍历，记录每个字符出现的次数。随后再一次遍历字符串，找到第一个计数为 1 的字符即可。

实现细节：

1. **第一次遍历**：使用 **哈希表**（在 Python 中是 `dict`，也可以直接用长度为 26 的列表）统计每个字符出现的次数。  
   - 类比：哈希表就像一本“字典”，左边是单词（这里是字符），右边是对应的页码（这里是出现次数）。查找或写入的速度非常快，几乎是 **O(1)**。  
2. **第二次遍历**：从左到右检查每个字符的计数，如果等于 1，则它是第一个不重复字符，直接返回下标。  
3. 如果遍历结束仍未找到，则返回 `-1`。

因为字符集只包含小写英文字母（共 26 种），我们甚至可以用长度为 26 的整数数组代替哈希表，进一步提升常数因子。

#### 代码（Python）

```python
def firstUniqChar_opt(s: str) -> int:
    # ① 统计每个字符出现次数，使用长度为 26 的列表代替哈希表
    cnt = [0] * 26                     # cnt[i] 表示字符 chr(ord('a') + i) 出现的次数
    for ch in s:                       # 第一次遍历，O(n)
        idx = ord(ch) - ord('a')       # 把字符映射到 0~25 的下标
        cnt[idx] += 1                  # 出现一次就加一

    # ② 再次遍历字符串，寻找计数为 1 的字符
    for i, ch in enumerate(s):         # 第二次遍历，O(n)
        if cnt[ord(ch) - ord('a')] == 1:   # 若该字符只出现一次
            return i                       # 返回它的下标

    return -1                           # 没有不重复字符，返回 -1
```

#### 复杂度

- **时间复杂度**：`O(n)` — 两次线性遍历，工作量随字符串长度线性增长。相比暴力的 `O(n²)`，速度提升巨大。  
- **空间复杂度**：`O(1)` — 只用了长度固定为 26 的数组，大小不随输入 `n` 变化。即使使用 `dict`，空间仍然是 `O(1)`（因为字符种类上限是 26）。

## 心得

- **核心技巧**：**一次计数 + 再遍历**（利用哈希表或固定大小数组统计频次）。  
- **适用的题型**：  
  1. “找出出现一次的数字/字符” 类题（如 LeetCode 387 `First Unique Character in a String`、260 `Single Number`）。  
  2. “统计出现次数并按顺序返回满足条件的元素” 类题（如 169 `Majority Element` 的计数思路）。  
- **一句话总结**：先把“出现几次”这件事一次性搞定，再顺序挑出第一个满足条件的即可——这就是解这类“首个唯一”问题的钥匙。

## 反思

- **第一反应**：直接遍历并逐个计数（暴力）。  
- **最容易踩的坑**：  
  - 忽略字符集限制，直接用 `dict` 仍然可以，但如果忘记初始化计数，可能导致 `KeyError`。  
  - 边界情况：全部字符都重复时要返回 `-1`，而不是 0 或其他值。  
  - 输入长度上限 `10⁵`，如果使用 `O(n²)` 的方案会超时。  
- **下次遇到同类题的第一步**：先问自己“是否可以一次遍历把所有信息（出现次数）收集完”，然后再决定是否需要第二遍查找。这样就能快速定位到最优思路。
