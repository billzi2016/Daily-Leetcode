# #231. 2 的幂 / Power of Two

> 难度：简单 · 标签：Math、Bit Manipulation、Recursion · [LeetCode 链接](https://leetcode.com/problems/power-of-two/)

---

## 题目（英文原版）

**Description**

Given an integer n, return true if it is a power of two. Otherwise, return false.
An integer n is a power of two, if there exists an integer x such that n == 2x.

**Examples**

**Example 1:**

```
Input: n = 1
Output: true
Explanation: 20 = 1
```

**Example 2:**

```
Input: n = 16
Output: true
Explanation: 24 = 16
```

**Example 3:**

```
Input: n = 3
Output: false
```

**Constraints**

- -231 <= n <= 231 - 1

---

## 题目（中文翻译）

给定一个整数（integer）`n`，如果它是 **2 的幂（power of two）**，返回 `true`；否则返回 `false`。  
如果存在整数（integer）`x` 使得 `n == 2^x`，则整数 `n` 是 **2 的幂（power of two）**。

**示例 1**  
**输入**: `n = 1`  
**输出**: `true`  
**解释**: `2^0 = 1`

**示例 2**  
**输入**: `n = 16`  
**输出**: `true`  
**解释**: `2^4 = 16`

**示例 3**  
**输入**: `n = 3`  
**输出**: `false`

**约束条件**  
- `-2^31 <= n <= 2^31 - 1`

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是把「2 的幂」这一系列数列枚举出来，看看 `n` 是否出现在里面。  
可以从 `1`（2⁰）开始，每次把当前值乘以 `2`，一直乘到大于等于 `n` 为止：

- 如果在这个过程中恰好等于 `n`，说明 `n` 是 2 的某次方，返回 `True`；
- 否则一直乘到超过 `n`，仍未相等，就说明 `n` 不是 2 的幂，返回 `False`。

这里用到的唯一数据结构是 **整数**，没有额外的容器。  
把「乘以 2」想象成「把水杯里倒入相同体积的水」一次又一次，直到水量超过目标容量。

**为什么正确**：  
所有正整数的 2 的幂形成的序列是严格递增的（1, 2, 4, 8, …），所以只要遍历到不小于 `n`，就一定能判断出 `n` 是否在序列中。

**复杂度分析**：  
- 乘以 2 的次数大约是 `log₂ n`（因为每次都把值翻倍），所以时间复杂度是 **O(log n)**。  
  用大白话说，就是「只需要几次操作就能把数字从 1 变到 2ⁿ，次数随 n 增长得很慢」。
- 只用了常数个变量（`cur`、`n`），空间复杂度是 **O(1)**，即「几块纸巾的空间」。


#### 代码（Python）

```python
def isPowerOfTwo_bruteforce(n: int) -> bool:
    # 负数、零根本不可能是 2 的幂，直接返回 False
    if n <= 0:
        return False

    cur = 1           # 从 2⁰ 开始
    while cur < n:    # 只要 cur 还没追上 n，就继续翻倍
        cur <<= 1     # 等价于 cur = cur * 2，左移一位更快
        # 这里可以加一个调试打印，帮助理解过程
        # print(f"cur = {cur}")

    # 循环结束后，cur 要么等于 n，要么大于 n
    return cur == n
```

#### 复杂度

- **时间复杂度**：`O(log n)` — 随着 `n` 增大，循环次数只会增加对数级别，实际操作非常少。
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和 `n` 的大小无关。

### 2. 最优解

#### 思路  
暴力解的瓶颈在于需要循环 `log n` 次，虽然已经很快，但我们可以用 **位运算** 把它一步到位。

二进制里，2 的幂有一个非常显著的特征：  
- `1` 的二进制是 `0001`  
- `2` 的二进制是 `0010`  
- `4` 的二进制是 `0100`  
- `8` 的二进制是 `1000`  

每个 2 的幂 **恰好只有一个 `1` 位**，其余全是 `0`。  

如果把一个数 `n` 与 `n-1` 做按位与（`&`）运算，会把最右侧的 `1` 变成 `0`，其左边的位保持不变。例如：

```
n      = 01000   (8)
n - 1  = 00111   (7)
n & (n-1) = 00000
```

- 当 `n` 本身是 2 的幂时，`n & (n-1)` 的结果一定是 `0`；
- 当 `n` 不是 2 的幂时，结果会保留至少一个 `1`，不等于 `0`。

此外，需要排除 `n <= 0` 的情况，因为负数或零的二进制表示里会出现多个 `1`，不符合「只有一个 `1`」的特征。

**核心技巧**：**位运算**（`&`） + **唯一的 `1` 位** 判定。  
把它想象成「检查一本字典里是否只有一个词条」——如果只有一个词条，那么把它删掉（`n-1`）后，字典就空了（`0`）。

#### 代码（Python）

```python
def isPowerOfTwo_optimal(n: int) -> bool:
    # 先排除非正数
    if n <= 0:
        return False

    # n & (n-1) 为 0 当且仅当 n 是 2 的幂
    return (n & (n - 1)) == 0
```

#### 复杂度

- **时间复杂度**：`O(1)` — 只做一次位运算和一次比较，和 `n` 的大小毫无关系。  
  用大白话说，就是「不管 n 有多大，都只需要一次快速的检查」。
- **空间复杂度**：`O(1)` — 只用了常数个变量。

## 心得

- **核心技巧**：利用二进制唯一 `1` 位的特性，配合 `n & (n-1)` 判断。
- **适用的题型**  
  1. 判断是否是 4 的幂、8 的幂（同理，只要改成 `n & (n-1) == 0` 并且 `n` 能被相应的基数整除）。  
  2. 判断一个数是否是 **奇数**（`n & 1 == 1`）。  
  3. 判断两个数是否 **不相交**（`a & b == 0`，常用于子集 DP）。
- **一句话总结解题钥匙**：**“二进制里只有一个 1 的数，必是 2 的幂”。**

## 反思

- **第一反应**：先想到枚举 2 的幂或不断除以 2，这是最自然的数学思路。  
- **最容易踩的坑**  
  - 忽略负数和零的情况，直接做位运算会得到错误的 `True`（例如 `n = 0` 时 `0 & -1 == 0`）。  
  - 在某些语言里左移会产生溢出，导致错误结果；Python 的整数不受限制，但仍需注意。  
- **下次类似题的第一步**：先检查 **“二进制唯一 1 位”** 的特征，看看是否能用 `&`、`|`、`^` 等位运算一次性判断。
