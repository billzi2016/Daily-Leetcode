# #434. 字符串中的单词数 / Number of Segments in a String

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/number-of-segments-in-a-string/)

---

## 题目（英文原版）

**Description**

Given a string s, return the number of segments in the string.
A segment is defined to be a contiguous sequence of non-space characters.

**Examples**

**Example 1:**

```
Input: s = "Hello, my name is John"
Output: 5
Explanation: The five segments are ["Hello,", "my", "name", "is", "John"]
```

**Example 2:**

```
Input: s = "Hello"
Output: 1
```

**Constraints**

- 0 <= s.length <= 300
- s consists of lowercase and uppercase English letters, digits, or one of the following characters "!@#$%^&*()_+-=',.:".
- The only space character in s is ' '.

---

## 题目（中文翻译）

**描述**  
给定一个字符串 `s`，返回该字符串中的段落（segment）数量。  
段落被定义为由连续的非空格字符组成的子序列（contiguous sequence of non-space characters）。

**示例 1**  
**输入**: `s = "Hello, my name is John"`  
**输出**: `5`  
**解释**: 这五个段落分别是 `["Hello,", "my", "name", "is", "John"]`

**示例 2**  
**输入**: `s = "Hello"`  
**输出**: `1`  
**解释**: 只有一个段落 `["Hello"]`

**约束条件**  
- `0 <= s.length <= 300`  
- `s` 只包含小写字母、大写字母、数字，或以下字符之一：`!@#$%^&*()_+-=',.:`  
- `s` 中唯一的空格字符为 `' '`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是把字符串按照空格 `' '` 切成若干子串，然后把非空的子串数出来。  
- **用到的数据结构**：Python 的 `list`（列表）相当于装满了切好的单词，就像我们把一段文字拆成一本本小册子。  
- **为什么正确**：题目把“段”（segment）定义为**连续的非空格字符**。`str.split(' ')` 会在每个空格处把字符串拆开，得到的每一段正好对应题目要求的段。只要把空串（连续空格产生的）过滤掉，剩下的就是所有合法段的数量。  
- **时间/空间复杂度**：  
  - **时间**：遍历整个字符串一次进行切割，再遍历得到的列表一次过滤，整体是 `O(n)`，这里的 `n` 是字符串长度。  
  - **空间**：切割后会产生一个包含所有子串的列表，最坏情况下每个字符都是非空格，列表里会有 `n` 个元素，空间复杂度是 `O(n)`。  
> 大白话解释：如果字符串有 1000 个字符，程序大约会看 1000 次字符（时间），并且在内存里临时多占用大约 1000 个“小盒子”来存每个单词（空间）。

#### 代码（Python）

```python
def count_segments_bruteforce(s: str) -> int:
    """
    直觉解：先把字符串按空格切开，再统计非空子串的个数。
    """
    # 1. 用空格把 s 切成若干段，得到一个列表
    parts = s.split(' ')                 # 列表中可能会出现空串，例如 "a  b" 会得到 ["a", "", "b"]
    
    # 2. 过滤掉空串，只保留真正的段
    non_empty_parts = [p for p in parts if p]   # p 为真值时表示非空
    
    # 3. 段的数量就是列表的长度
    return len(non_empty_parts)
```

#### 复杂度

- **时间复杂度**：`O(n)` — 只需要遍历一次字符串（切割）再遍历一次得到的列表（过滤），和字符串长度成线性关系。  
- **空间复杂度**：`O(n)` — 需要额外的列表来存放所有切好的子串，最坏情况下每个字符都成为单独的子串。

### 2. 最优解

#### 思路  
暴力解虽然已经是 `O(n)`，但它额外创建了很多子串（占用额外空间），而我们其实只需要**计数**，不必真的把每段文字保存下来。  
- **慢在哪里**：`split` 会把每段文字复制到新的字符串对象，导致额外的内存开销和拷贝时间。  
- **优化思路**：一次遍历字符串，遇到“从空格变成非空格”的位置就说明出现了一个新段。具体来说：  
  1. 用一个布尔变量 `in_word` 表示当前是否正处在一个段内部。  
  2. 当遍历到字符 `c`：  
     - 如果 `c` 不是空格且 `in_word` 为 `False`，说明刚进入一个新段，计数器 `cnt` 加一，并把 `in_word` 设为 `True`。  
     - 如果 `c` 是空格，则把 `in_word` 设为 `False`，准备好捕捉下一个段的开始。  
- **核心算法/数据结构**：只用到**两个整型变量**（计数器和状态标记），不需要额外的数据结构。  
- **类比**：想象你在走一条路，路上有若干块草坪（段），空格相当于道路。只要每次从道路跨进草坪时记一次数，就能得到草坪的数量，而不必把每块草坪拍照保存。  

#### 代码（Python）

```python
def count_segments_optimal(s: str) -> int:
    """
    最优解：一次遍历，使用状态变量判断是否进入了新段。
    """
    cnt = 0            # 记录段的数量
    in_word = False    # 当前是否在一个非空格序列中

    for ch in s:       # 逐字符遍历
        if ch != ' ':               # 遇到非空格字符
            if not in_word:         # 之前不在段内，说明进入了新段
                cnt += 1            # 段计数加一
                in_word = True      # 标记进入段
        else:                        # 遇到空格字符
            in_word = False          # 离开段，等待下一个段的开始

    return cnt
```

#### 复杂度

- **时间复杂度**：`O(n)` — 只遍历一次字符串，和字符串长度线性相关。与暴力解的时间相同，但常数更小（没有额外的拷贝）。  
- **空间复杂度**：`O(1)` — 只用了常数个变量（计数器、状态标记），不随输入规模增长。  
> 与暴力解对比：时间相当，但空间从 `O(n)` 降到了 `O(1)`，在大数据或内存受限的环境下更友好。

## 心得

- **核心技巧**：**一次遍历+状态机**（判断是否在单词内部），适用于所有需要统计“连续块”数量的题目。  
- **适用的题型**：  
  1. **单词计数**（本题）  
  2. **统计二进制字符串中连续 1 的块数**（LeetCode 485）  
  3. **统计数组中连续递增子数组的个数**（变形）  
- **一句话总结**：**只要能把“进入新块”这件事捕捉到，就不需要真的把块保存下来**。

## 反思

- **第一反应**：看到“段（segment）”和“空格”，立刻想到 `split()`，因为它是 Python 里最直接的切割方式。  
- **最容易踩的坑**：  
  - 连续多个空格会产生空串，需要过滤掉。  
  - 空字符串或全是空格的情况，计数应为 0。  
  - 注意只把普通空格 `' '` 当作分隔符，题目明确说明没有其他空白字符。  
- **下次遇到同类题**：第一步先思考“段的开始”是什么（从空格到非空格的转变），然后决定是直接用语言自带的切割函数，还是手动遍历做状态记录，以达到更优的空间或时间表现。
