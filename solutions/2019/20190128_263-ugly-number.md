# #263. 丑数 / Ugly Number

> 难度：简单 · 标签：Math · [LeetCode 链接](https://leetcode.com/problems/ugly-number/)

---

## 题目（英文原版）

**Description**

An ugly number is a positive integer which does not have a prime factor other than 2, 3, and 5.
Given an integer n, return true if n is an ugly number.

**Examples**

**Example 1:**

```
Input: n = 6
Output: true
Explanation: 6 = 2 × 3
```

**Example 2:**

```
Input: n = 1
Output: true
Explanation: 1 has no prime factors.
```

**Example 3:**

```
Input: n = 14
Output: false
Explanation: 14 is not ugly since it includes the prime factor 7.
```

**Constraints**

- -231 <= n <= 231 - 1

Input: n = 14

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把 n 的所有因子都列出来**，然后判断这些因子里是否出现了除 2、3、5 之外的质数。  
可以把这个过程想象成“检查一箱水果里有没有不合格的水果”：我们把箱子里所有水果（所有因子）都挑出来，逐一对照合格名单（{2,3,5}），只要发现一个不在名单里的，就说明不合格（不是丑数）。

实现上，常见的做法是：

1. 如果 n ≤ 0，直接返回 `False`（题目说丑数必须是正整数）。
2. 枚举所有可能的因子 `i`（从 2 到 `sqrt(|n|)`），如果 `i` 能整除 `n`，说明 `i` 是 `n` 的一个因子。
3. 判断 `i` 是否是质数且不在 {2,3,5} 中；如果是，直接返回 `False`。
4. 同理检查对应的另一个因子 `n // i`（因为如果 `i` 是因子，`n//i` 也是因子）。
5. 循环结束后，没有发现不合格的因子，说明 `n` 只包含 2、3、5 的因子，返回 `True`。

**为什么正确**  
如果一个正整数的所有因子（包括自身）都只由 2、3、5 这三个质数乘积得到，那么它一定是题目定义的“丑数”。枚举所有因子并逐个检查，能够确保不漏掉任何不合格的质因子。

**复杂度分析**  
- 时间复杂度：我们最多遍历到 `sqrt(n)`，所以是 **O(√n)**。这里的 `√n` 可以理解为“把 n 的大小压缩到一个正方形的边长”，遍历的次数随 n 的增大而慢慢增加，但增长幅度比直接遍历到 n 小很多。
- 空间复杂度：只用了常数级别的额外变量，**O(1)**。

#### 代码（Python）

```python
import math

def is_ugly_brute(n: int) -> bool:
    # 1. 丑数必须是正整数
    if n <= 0:
        return False

    # 2. 特殊情况：1 没有质因子，直接算是丑数
    if n == 1:
        return True

    # 3. 枚举可能的因子 i（从 2 到 sqrt(n)）
    limit = int(math.isqrt(n))          # sqrt(n) 的整数部分
    for i in range(2, limit + 1):
        if n % i == 0:                  # i 能整除 n，说明 i 是因子
            # 检查 i 本身是否是 2、3、5 之外的质数
            if i not in (2, 3, 5) and is_prime(i):
                return False            # 出现不合格的质因子，直接返回 False
            # 检查配对因子 n // i
            pair = n // i
            if pair not in (2, 3, 5) and is_prime(pair):
                return False

    # 4. 循环结束，没有发现不合格的因子，说明是丑数
    return True

def is_prime(x: int) -> bool:
    """判断 x 是否为质数（仅用于暴力解的辅助函数）"""
    if x < 2:
        return False
    for d in range(2, int(math.isqrt(x)) + 1):
        if x % d == 0:
            return False
    return True
```

#### 复杂度

- **时间复杂度**：`O(√n)` — 需要检查到 `n` 的平方根，想象一下把一个大正方形划成很多小格子，格子数随边长的增长呈平方关系，遍历到边长就够了。
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和 `n` 的大小无关。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈在于我们遍历了大量无关的数**（所有可能的因子），而实际上我们只关心“是否只含有 2、3、5”。  
如果一个数只由 2、3、5 乘积得到，那么把它不断 **除掉** 这三个因子后，最后剩下的一定是 1。  
因此我们可以：

1. 先排除 `n <= 0` 的情况（负数或 0 直接不是丑数）。
2. 当 `n` 能被 2 整除时，循环除以 2；同理对 3、5 重复这个过程。
3. 最后检查剩下的 `n` 是否等于 1：  
   - 等于 1 → 说明所有因子都被 2、3、5 消掉，**是丑数**。  
   - 大于 1 → 说明还有别的质因子（比如 7），**不是丑数**。

**核心概念——“不断剔除因子”**  
可以把这个过程想象成“把一堆糖果分装进只装 2、3、5 粒的盒子”。我们一次把可以装进的盒子装满（除以 2、3、5），剩下的糖果如果还能装进任何盒子，就说明它本身就是 1；否则剩下的糖果就是不合格的因子。

**为什么是最优**  
每次除法操作都把 `n` 的大小至少减半（除以 2 时），最多只会执行 `log₂ n` 次（对 2 的除法），对 3、5 同理。因此总的时间是 **O(log n)**，远快于遍历 `√n` 的暴力做法。

#### 代码（Python）

```python
def is_ugly(n: int) -> bool:
    """
    判断 n 是否为 Ugly Number（只含 2、3、5 这三个质因子）。
    思路：不断除掉 2、3、5，最后看是否剩下 1。
    """
    # 1. 丑数必须是正整数
    if n <= 0:
        return False

    # 2. 依次除去 2、3、5
    for factor in (2, 3, 5):
        # 当 n 能被当前因子整除时，循环除下去
        while n % factor == 0:
            n //= factor   # 整除后更新 n，等价于把 factor 从因子列表中剔除

    # 3. 如果最后 n 变成 1，说明只剩下 2、3、5 的乘积
    return n == 1
```

#### 复杂度

- **时间复杂度**：`O(log n)` — 每次除以 2、3、5 至少把数值缩小一半，类似把一根绳子不断折半，折多少次能折到长度为 1，次数就是对数级别。相比暴力的 `O(√n)`，速度提升明显。
- **空间复杂度**：`O(1)` — 只用了常数个变量，和输入规模无关。

## 心得

- **核心技巧**：不断除去已知的因子（2、3、5），看剩余是否为 1。  
- **适用的题型**：  
  1. 判定只含特定质因子的数（如 “判断是否是 7‑smooth 数”）。  
  2. “把数字拆分成若干固定因子”的问题（如 “是否能用 2 和 3 完全表示某数”）。  
- **一句话总结解题钥匙**：**“把所有允许的因子都剔除干净，最后剩不剩 1”。**

---

## 反思

- **第一反应**：直接枚举因子检查是否出现 2、3、5 之外的质数。  
- **最容易踩的坑**：  
  - 忘记处理 `n <= 0` 的情况（负数、0 都不是丑数）。  
  - 忽视 `n == 1`，它没有任何质因子，按照定义应返回 `True`。  
  - 在除法循环里忘记更新 `n`，导致死循环。  
- **下次遇到同类题**：第一步先**思考能否通过“消除已知因子”直接把问题化简**，如果可以，就立刻转向 O(log n) 的除法思路。
