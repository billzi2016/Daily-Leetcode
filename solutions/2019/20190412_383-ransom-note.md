# #383. 赎金信 / Ransom Note

> 难度：简单 · 标签：Hash Table、String、Counting · [LeetCode 链接](https://leetcode.com/problems/ransom-note/)

---

## 题目（英文原版）

**Description**

Given two strings ransomNote and magazine, return true if ransomNote can be constructed by using the letters from magazine and false otherwise.
Each letter in magazine can only be used once in ransomNote.

**Examples**

**Example 1:**

```
Input: ransomNote = "a", magazine = "b"
Output: false
```

**Example 2:**

```
Input: ransomNote = "aa", magazine = "ab"
Output: false
```

**Example 3:**

```
Input: ransomNote = "aa", magazine = "aab"
Output: true
```

**Constraints**

- 1 <= ransomNote.length, magazine.length <= 105
- ransomNote and magazine consist of lowercase English letters.

---

## 题目（中文翻译）

给定两个字符串 `ransomNote` 和 `magazine`，若可以仅使用 `magazine` 中的字母构造出 `ransomNote`，则返回 `true`，否则返回 `false`。`magazine` 中的每个字母在构造 `ransomNote` 时只能使用一次。

**示例 1**  
**输入**: `ransomNote = "a", magazine = "b"`  
**输出**: `false`

**示例 2**  
**输入**: `ransomNote = "aa", magazine = "ab"`  
**输出**: `false`

**示例 3**  
**输入**: `ransomNote = "aa", magazine = "aab"`  
**输出**: `true`

**约束条件**  

- `1 <= ransomNote.length, magazine.length <= 10^5`  
- `ransomNote` 和 `magazine` 仅由小写英文字母组成。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把 magazine 当成一本字典**，把每个字符当成一个词条，查找 ransomNote 中的每个字符是否在这本字典里。  
具体做法：

1. 把 `magazine` 中的每个字母依次放进一个 **哈希表**（在 Python 里可以用 `dict` 或 `collections.Counter`），键（key）是字母，值（value）是该字母出现的次数。  
   - 哈希表就像查字典：把字母看成“词”，出现次数看成“页码”。  
2. 再遍历 `ransomNote`，每遇到一个字母，就在哈希表里找对应的键：
   - 如果找不到（键不存在），说明 `magazine` 没有这个字母，直接返回 `False`。  
   - 如果找得到，但对应的次数已经是 0，说明该字母已经被用光，也返回 `False`。  
   - 否则把次数减 1，表示这一次使用了这个字母。  
3. 所有字母都检查完毕后，说明可以拼出 `ransomNote`，返回 `True`。

> 为什么这个方法一定正确？  
> 因为我们严格按照 “每个字母只能使用一次” 的限制，把 `magazine` 中每个字母的可用次数记录下来，只有在次数足够时才允许使用，恰好对应题目的要求。

#### 代码（Python）

```python
def canConstruct(ransomNote: str, magazine: str) -> bool:
    # 1️⃣ 统计 magazine 中每个字母出现的次数，放进哈希表
    freq = {}
    for ch in magazine:
        freq[ch] = freq.get(ch, 0) + 1   # get() 相当于查字典，找不到返回 0

    # 2️⃣ 逐个检查 ransomNote 的字母
    for ch in ransomNote:
        if ch not in freq or freq[ch] == 0:
            # 没有这个字母，或者已经被用光
            return False
        freq[ch] -= 1   # 用掉一个，次数减 1

    # 3️⃣ 所有字母都匹配成功
    return True
```

#### 复杂度

- **时间复杂度**：`O(n + m)`  
  - `n` 为 `magazine` 长度，`m` 为 `ransomNote` 长度。我们各遍历一次字符串，所以总操作次数和两个字符串的长度之和成正比。  
  - 用大白话说，就是如果两本书一共 10 万个字母，最多做 10 万次“看字典”操作。

- **空间复杂度**：`O(σ)`，其中 `σ` 是字符种类数（这里最多 26）  
  - 哈希表最多存放 26 个键（a~z），每个键对应一个计数，和字符串长度无关。

### 2. 最优解

#### 思路  

从暴力解可以看到，**瓶颈其实不在时间**（已经是线性），而是 **实现的简洁度** 与 **常数因子**。  
如果想让代码更简洁、可读性更高，我们可以直接使用 Python 标准库 `collections.Counter`——它本质上就是一个「字符计数的哈希表」，已经帮我们把「统计」这一步封装好了。

优化步骤：

1. 用 `Counter` 一行代码得到 `magazine` 中每个字符的出现次数。  
2. 再遍历 `ransomNote`，对每个字符直接在 `Counter` 中做减法。`Counter` 的减法会自动把计数降到负数，但我们只需要检查是否出现负数即可。  
3. 如果遍历结束都没有出现负数，说明所有字符都有足够的供应，返回 `True`；一旦出现负数，立刻返回 `False`。

> 这里的核心技巧是 **计数 + 直接比较**，不必手动写 `dict.get`、`if` 判断等繁琐代码。  

#### 代码（Python）

```python
from collections import Counter

def canConstruct(ransomNote: str, magazine: str) -> bool:
    # 1️⃣ 用 Counter 统计 magazine 中每个字符的数量
    counter = Counter(magazine)   # 类似于 {'a': 3, 'b': 2, ...}

    # 2️⃣ 逐个消耗 ransomNote 中的字符
    for ch in ransomNote:
        counter[ch] -= 1          # 把对应字符的计数减 1
        if counter[ch] < 0:       # 如果已经小于 0，说明不够用了
            return False

    # 3️⃣ 所有字符都有足够的供应
    return True
```

#### 复杂度

- **时间复杂度**：`O(n + m)`（与暴力解相同）  
  - 只多了一次 `Counter` 的内部遍历（也是线性），所以整体仍然是线性时间。  
  - 与暴力解对比：常数因子更小，代码更简洁。

- **空间复杂度**：`O(σ)`（同样是 26）  
  - `Counter` 只保存 26 种字母的计数。

## 心得

- **核心技巧**：字符计数（哈希表 / Counter） + 逐个检查是否满足需求。  
- **适用的题型**  
  1. **两字符串计数比较**：如 `Valid Anagram`（验证字母异位词）。  
  2. **字母库存类问题**：如 `Check If a String Contains All Characters of Another String`。  
  3. **频率限制类**：如 `Maximum Number of Balloons`（用字符拼气球）。  
- **一句话总结解题钥匙**：**把“能否用”转化为“每种字符的库存是否足够”。**

## 反思

- **第一反应**：看到“每个字母只能使用一次”，立刻想到统计出现次数，然后逐个消耗——这是一种最自然的“把需求映射到资源库存”的思路。  
- **最容易踩的坑**  
  1. **忽略大小写或非字母字符**：本题限定全是小写字母，但如果题目改动，需要先统一字符集。  
  2. **忘记把已使用的字符计数减 1**：只检查是否存在而不减计数，会导致重复使用同一个字母。  
  3. **边界情况**：空字符串。`ransomNote` 为空应返回 `True`（不需要任何字母），`magazine` 为空但 `ransomNote` 非空应返回 `False`。  
- **下次遇到同类题，第一步该想到**：**建立字符计数表（哈希表/Counter），再把需求字符串的每个字符在计数表中“扣除”。**如果扣除过程中出现负数，说明资源不足，直接返回 `False`。
