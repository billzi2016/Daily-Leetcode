# #283. 移动零 / Move Zeroes

> 难度：简单 · 标签：Array、Two Pointers · [LeetCode 链接](https://leetcode.com/problems/move-zeroes/)

---

## 题目（英文原版）

**Description**

Given an integer array nums, move all 0's to the end of it while maintaining the relative order of the non-zero elements.
Note that you must do this in-place without making a copy of the array.

**Examples**

**Example 1:**

```
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

**Example 2:**

```
Input: nums = [0]
Output: [0]
```

**Constraints**

- 1 <= nums.length <= 104
- -231 <= nums[i] <= 231 - 1

---

## 题目（中文翻译）

给定一个整数数组 `nums`，将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序不变。  
**注意**：必须原地（in-place）完成此操作，不能创建数组的副本。

## 示例

**示例 1**  
输入：`nums = [0,1,0,3,12]`  
输出：`[1,3,12,0,0]`

**示例 2**  
输入：`nums = [0]`  
输出：`[0]`

## 约束条件

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是：**先把所有非零元素挑出来，放到一个新数组里，再把剩下的空位填上 0**。  
- **数据结构**：我们可以使用 Python 列表（list）来暂存非零元素。把它想象成“收纳盒”，把所有“有价值的东西”（非零数）装进去，空出来的空间再放上“垃圾”（0）。
- **正确性**：因为我们把所有非零元素的相对顺序保持不变地搬进了新数组的前面，随后再把 0 填在后面，最终得到的序列正好满足题目要求——所有 0 都在末尾，且非零元素顺序未变。
- **时间/空间复杂度**：  
  - 我们遍历一次原数组（`O(n)`），把非零元素加入新数组，同样是 `O(n)` 的操作，总体仍是线性时间。  
  - 但是我们用了额外的列表来存放非零元素，最坏情况下需要 `n` 个位置，空间复杂度是 `O(n)`（相当于再新建一个和原数组等大的盒子）。  

> **大白话解释**：  
> - `O(n)` 就是“跟数组长度成正比”。如果数组有 1000 个数，程序大约会做 1000 次左右的基本操作。  
> - `O(n²)`（平方）则是“跟长度的平方成正比”，比如 1000 × 1000 = 1 000 000 次操作，明显会慢很多。这里我们的暴力解是 `O(n)`，已经算是线性了，只是占用了额外的空间。

#### 代码（Python）

```python
def moveZeroes_brute(nums):
    """
    暴力解：使用额外的列表保存非零元素，然后把 0 填回去。
    该函数会直接修改传入的 nums（因为题目要求原地修改），
    但实现思路上仍然借助了额外空间。
    """
    # 1️⃣ 把所有非零元素收集到一个新列表里
    non_zero = []                     # 新的“收纳盒”
    for x in nums:                    # 遍历原数组
        if x != 0:                     # 只挑非零的
            non_zero.append(x)        # 放进收纳盒

    # 2️⃣ 把收纳盒的内容写回原数组的前面
    for i in range(len(non_zero)):
        nums[i] = non_zero[i]          # 覆盖原来的位置

    # 3️⃣ 剩下的地方全部填 0
    for i in range(len(non_zero), len(nums)):
        nums[i] = 0                    # 把“垃圾”填进去
```

#### 复杂度

- **时间复杂度**：`O(n)` — 只遍历了两遍原数组（一次收集，一次写回），操作次数和数组长度成正比。
- **空间复杂度**：`O(n)` — 需要额外的列表 `non_zero`，最坏情况下存放所有元素（当数组里没有 0 时）。

### 2. 最优解

#### 思路  
暴力解的 **瓶颈** 在于使用了额外的存储空间，而题目明确要求 **原地（in‑place）** 完成。  
我们需要在 **同一个数组** 里把非零元素“往前搬”，随后把剩余的位置统一设为 0。

**双指针**（Two Pointers）是一种常用的原地移动技巧：

1. **慢指针 `slow`**：指向下一个应该放非零元素的位置。它只会向右移动，从左到右依次“占领”数组的前部。
2. **快指针 `fast`**：遍历整个数组，寻找非零元素。当 `nums[fast] != 0` 时，说明找到了一个需要搬运的“有价值的东西”。此时把它放到 `slow` 位置上，然后 `slow` 前进一步。

遍历结束后，`slow` 之后的所有位置一定都是原来被“搬空”的地方，这里统一填 0 即可。

**类比**：想象你在搬家，把所有有用的东西（非零）从左到右搬到新房的前面（`slow`），空出来的空间自然就是垃圾（0）要放的地方。

**步骤图示（文字版）**：

```
原数组: [0, 1, 0, 3, 12]
fast遍历: ^          （指向第一个元素 0）
slow指向: ^          （第一个空位）

fast走到 1，发现非零 → nums[slow]=1，slow右移
数组变为: [1, 1, 0, 3, 12]   （前面的 1 已经就位）

继续 fast...
fast走到 3 → nums[slow]=3，slow右移
数组变为: [1, 3, 0, 3, 12]

fast走到 12 → nums[slow]=12，slow右移
数组变为: [1, 3, 12, 3, 12]

遍历结束，slow=3，后面的下标 3、4 统一填 0
最终结果: [1, 3, 12, 0, 0]
```

这样只用了 **一次遍历**，没有额外的数组，空间复杂度是 `O(1)`。

#### 代码（Python）

```python
def moveZeroes(nums):
    """
    双指针原地算法
    - slow: 下一个放非零元素的位置
    - fast: 扫描整个数组
    """
    slow = 0                         # 初始化慢指针在最左边
    for fast in range(len(nums)):    # fast 从左到右遍历
        if nums[fast] != 0:          # 找到一个非零元素
            nums[slow] = nums[fast]  # 把它搬到 slow 指向的位置
            slow += 1                # slow 前进一步，准备放下一个

    # 此时 [0, slow) 区间已经全部是非零元素，后面的全部设为 0
    for i in range(slow, len(nums)):
        nums[i] = 0                  # 把“垃圾”填进去
```

#### 复杂度

- **时间复杂度**：`O(n)` — 只遍历一次数组，`n` 是数组长度。相比暴力解的两遍遍历，实际操作次数更少（但仍是线性级别）。
- **空间复杂度**：`O(1)` — 只用了常数个额外变量（`slow`、`fast`），没有额外的随 `n` 增长的存储空间。

## 心得

- **核心技巧**：双指针原地移动（Two‑Pointer In‑Place）。
- **适用的题型**：
  1. 删除数组中的特定元素（如 LeetCode 27 `Remove Element`）。
  2. 合并两个有序数组的前半段（LeetCode 88 `Merge Sorted Array`）。
  3. 删除有序数组中的重复项（LeetCode 26 `Remove Duplicates from Sorted Array`）。
- **一句话总结解题钥匙**：**“用一个指针记录‘已整理好’的边界，用另一个指针寻找下一个需要搬运的元素”。**

---

## 反思

- **第一反应**：先想到了用额外数组把非零元素收集起来——最直观但不符合“原地”要求。
- **最容易踩的坑**：
  - 忘记在遍历结束后把剩余位置全部置零，导致旧的非零值残留。
  - 在 `fast` 与 `slow` 同时指向同一个非零元素时，直接覆盖会导致数据丢失（这里我们先写再移动指针，避免了这个问题）。
- **下次遇到同类题**：第一步想到“是否可以用双指针，一个负责写入，一个负责读取”，再根据题目要求决定是“左移/右移”或“从后往前”操作。
