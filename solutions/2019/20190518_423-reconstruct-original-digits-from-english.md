# #423. 从英文重建原始数字 / Reconstruct Original Digits from English

> 难度：中等 · 标签：Hash Table、Math、String · [LeetCode 链接](https://leetcode.com/problems/reconstruct-original-digits-from-english/)

---

## 题目（英文原版）

**Description**

Given a string s containing an out-of-order English representation of digits 0-9, return the digits in ascending order.

**Examples**

**Example 1:**

```
Input: s = "owoztneoer"
Output: "012"
```

**Example 2:**

```
Input: s = "fviefuro"
Output: "45"
```

**Constraints**

- 1 <= s.length <= 105
- s[i] is one of the characters ["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"].
- s is guaranteed to be valid.

---

## 题目（中文翻译）

给定一个字符串 `s`，其中包含顺序打乱的数字 0-9 的英文表示（English representation），返回这些数字的升序排列。

示例 1:  
Input: s = "owoztneoer"  
Output: "012"

示例 2:  
Input: s = "fviefuro"  
Output: "45"

约束条件：
- 1 <= s.length <= 10^5
- s[i] 是字符 `["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"]` 中的任意一个。
- s 保证是有效的。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**把所有可能的数字拼起来，再和给定的字母串做对比**。  
具体做法可以概括为：

1. 先准备好 0‒9 每个数字对应的英文单词（"zero", "one", …, "nine"）。  
2. 统计输入字符串 `s` 中每个字母出现的次数（相当于我们手里有一张“字母统计表”，就像查字典时先把所有词条的字母频率记下来）。  
3. 对每一个数字 `d`（0~9）尝试 **把它的单词从统计表里“减掉”**，如果能够成功（即所有需要的字母都有足够的数量），就说明这个数字在原始数字序列中出现过。  
4. 为了得到所有可能的组合，我们可以 **穷举所有数字出现的次数**（比如 0 出现 0 次、1 次、2 次…），每一种组合都尝试把对应的单词从统计表里减去，最后看统计表是否恰好清空。  

> 这里的“穷举”其实是把 **所有排列**（permutations）都尝试一遍，等价于把 `s` 的所有字母重新排成 10 种单词的任意顺序。

**为什么正确**：只要我们找到了一个能够把所有字母恰好匹配完的数字多重集合，这个集合就是唯一的（题目保证输入合法），所以暴力搜索一定能找到答案。

**时间/空间分析**：

- 对每一种可能的数字出现次数组合，都要检查 10 个单词并更新字母计数。  
- 组合的数量在最坏情况下是指数级的（类似 `O(n^10)`），因为我们需要遍历每个数字可能出现的次数。  
- 因此 **时间复杂度** 大约是 **指数级**，对 10⁵ 长度的字符串根本不可接受。  
- **空间复杂度** 只需要保存字母计数（26 个字母）和常数级的临时变量，故为 **O(1)**。

> 用大白话说，指数级就像在找一把钥匙，要尝试上万上万把钥匙才能确定哪把能开锁，显然太慢了。

#### 代码（Python）

```python
from collections import Counter
import itertools

def original_digits_bruteforce(s: str) -> str:
    # 0~9 对应的英文单词
    words = ["zero", "one", "two", "three", "four",
             "five", "six", "seven", "eight", "nine"]
    # 把输入的每个字母计数，类似“字典”
    total_cnt = Counter(s)

    # 为了演示，这里只做一次简单的穷举（实际会超时）
    # 我们尝试所有数字出现次数之和不超过 len(s)//3（因为最短单词 length 为 3）
    max_len = len(s) // 3
    for counts in itertools.product(range(max_len + 1), repeat=10):
        # 计算这组数字出现次数对应的字母需求
        need = Counter()
        for d, c in enumerate(counts):
            need.update({ch: c for ch in words[d] for _ in (0,)})
        # 如果需求正好等于已有的统计，则找到了答案
        if need == total_cnt:
            # 按升序输出数字
            result = []
            for d, c in enumerate(counts):
                result.extend([str(d)] * c)
            return "".join(result)
    return ""   # 理论上不会走到这里
```

> **注意**：上述代码仅用于说明暴力思路，实际运行会因为组合数太大而卡死。

#### 复杂度

- **时间复杂度**：`O(k^10)`（`k` 为每个数字可能的最大出现次数），指数级，几乎不可接受。  
- **空间复杂度**：`O(1)`，只用了固定大小的计数表（26 个字母）。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于 **“穷举所有数字出现次数”**。  
我们需要 **直接从字母计数中推断每个数字出现了多少次**，而不是试错。

关键观察：

1. 某些字母在英文数字单词中是 **唯一出现** 的，例如  
   - `'z'` 只在 **zero**（0）里出现  
   - `'w'` 只在 **two**（2）里出现  
   - `'u'` 只在 **four**（4）里出现  
   - `'x'` 只在 **six**（6）里出现  
   - `'g'` 只在 **eight**（8）里出现  

   这就像字典里有 **专属页码**，看到 `'z'` 就一定能确定有一个 0。

2. 确定了上述 5 个数字后，**把它们对应的字母从计数表里减去**，其余数字的唯一字母就会显现出来。例如：
   - `'h'` 本来出现在 **three**（3）和 **eight**（8）里，等我们把 8（通过 `'g'`）去掉后，剩下的 `'h'` 必然来自 3。  
   - 同理 `'f'`（four & five）、`'s'`（six & seven）以及 `'i'`（five, six, eight, nine）都可以逐步解锁。

3. 具体顺序（常见的写法）：

| 唯一字母 | 对应数字 | 需要在计数表里减去的单词 |
|----------|----------|--------------------------|
| `'z'`    | 0        | "zero"                   |
| `'w'`    | 2        | "two"                    |
| `'u'`    | 4        | "four"                   |
| `'x'`    | 6        | "six"                    |
| `'g'`    | 8        | "eight"                  |
| `'h'`    | 3        | "three"（在去掉 8 后）   |
| `'f'`    | 5        | "five"（在去掉 4 后）    |
| `'s'`    | 7        | "seven"（在去掉 6 后）   |
| `'i'`    | 9        | "nine"（在去掉 5,6,8 后）|
| `'o'`    | 1        | "one"（在去掉 0,2,4 后） |

4. **实现步骤**：

   1. 用 `Counter` 统计所有字母出现次数（相当于一本“字母频率表”）。  
   2. 按上表顺序，读取每个唯一字母对应的计数，即得到该数字出现的次数。  
   3. 把该数字对应单词的每个字母的计数 **减去** 已知的出现次数（因为这些字母已经被使用）。  
   4. 最后把每个数字按出现次数输出，记得升序排列。

> 类比：把字母表想象成一盒子彩色积木，每种颜色对应一个字母。我们先把只有一种颜色的积木（唯一字母）挑出来，确定对应的数字，然后把这些数字的所有积木都从盒子里取走，剩下的积木再继续挑，层层推进，最后盒子里会空的。

#### 代码（Python）

```python
from collections import Counter

def original_digits(s: str) -> str:
    """
    将打乱顺序的英文数字字符还原为升序的数字字符串
    """
    # 1. 统计所有字母出现次数
    cnt = Counter(s)

    # 2. 按唯一字母的顺序求每个数字出现的次数
    #   数组下标对应数字本身
    num_cnt = [0] * 10
    num_cnt[0] = cnt['z']          # zero
    num_cnt[2] = cnt['w']          # two
    num_cnt[4] = cnt['u']          # four
    num_cnt[6] = cnt['x']          # six
    num_cnt[8] = cnt['g']          # eight

    # 3. 处理依赖于前面数字的字母
    num_cnt[3] = cnt['h'] - num_cnt[8]          # three，去掉 eight 用掉的 h
    num_cnt[5] = cnt['f'] - num_cnt[4]          # five，去掉 four 用掉的 f
    num_cnt[7] = cnt['s'] - num_cnt[6]          # seven，去掉 six 用掉的 s
    num_cnt[9] = cnt['i'] - num_cnt[5] - num_cnt[6] - num_cnt[8]  # nine
    num_cnt[1] = cnt['o'] - num_cnt[0] - num_cnt[2] - num_cnt[4]  # one

    # 4. 按升序拼接结果
    res = []
    for digit in range(10):
        res.append(str(digit) * num_cnt[digit])   # 把同一个数字重复出现的次数拼在一起
    return "".join(res)
```

> 关键行解释（中文注释已在代码中）：
> - `cnt['z']` 直接告诉我们有多少个 0，因为只有零里有 `'z'`。  
> - `cnt['h'] - num_cnt[8]`：先把所有 `'h'` 的计数取出来，然后减去已经被 8（`'g'`）占用的 `'h'`，剩下的就是 3 的数量。  

#### 复杂度

- **时间复杂度**：`O(n)`，只遍历一次输入字符串统计字母，随后进行常数次的数组操作。  
  - 用大白话讲，就是 **线性**，输入多大，时间就随之线性增长，最多几千万字符也能在一秒左右搞定。  
- **空间复杂度**：`O(1)`，我们只用了固定大小的计数表（26 个字母）和长度为 10 的数组，和输入规模无关。

## 心得

- **核心技巧**：利用**唯一字符**把问题一步步拆解，属于“计数 + 消除”类思路。  
- **适用的题型**：
  1. “重新排列字母得到目标单词”——如 *Find the Original Array*（利用唯一元素定位）  
  2. “从混合字符中恢复原始信息”——如 *Alien Dictionary*（拓扑排序）  
  3. “字符计数恢复数字/单词”——如 *Decode String*（计数+栈）  

- **一句话总结**：**找出每个数字的“专属字母”，先确定它们，再逐层剔除，最后剩下的自然就是答案。**

## 反思

- **第一反应**：看到“英文字母乱序表示数字”，马上想到把每个数字的英文单词列出来，然后**计数**。  
- **最容易踩的坑**：
  - 忽略了某些字母在多个数字中出现，导致直接计数出错（比如 `'o'` 同时在 0、1、2、4 中）。  
  - 没有按照 **唯一字母的顺序** 消除，导致后面的计数被提前污染。  
  - 边界情况：全部是同一个数字（如 `"zzzz"`）时，仍需保证计数表不越界。  
- **下次遇到同类题**：第一步先**找唯一标识**（唯一字符、唯一频率），把它们对应的对象确定下来，再**逐层消除**，最后用剩余信息完成答案。
