## 题目（中文翻译）

**描述**  
设计一个映射（map），使你能够执行以下操作：

- `insert(key, val)`: 将键 `key` 与整数值 `val` 关联。如果 `key` 已经存在，则更新对应的值为 `val`。  
- `sum(prefix)`: 返回所有以字符串 `prefix` 为前缀的键对应的值的总和。

实现 `MapSum` 类，使其支持上述两种操作。

**示例**  
```text
输入
["MapSum", "insert", "sum", "insert", "sum"]
[[], ["apple", 3], ["ap"], ["app", 2], ["ap"]]
输出
[null, null, 3, null, 5]

解释
MapSum mapSum = new MapSum();
mapSum.insert("apple", 3);  
mapSum.sum("ap");           // 返回 3（apple = 3）
mapSum.insert("app", 2);    
mapSum.sum("ap");           // 返回 5（apple + app = 3 + 2 = 5）
```

**约束条件**  

- `1 <= key.length, prefix.length <= 50`
- `key` 和 `prefix` 只包含小写英文字母。
- `1 <= val <= 1000`
- 至多调用 `insert` 和 `sum` 共 50 次。

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是把所有键值对保存在一个普通的 Python `dict`（字典）里。  
- **数据结构**：字典就像一本“查词典”，`key` 是单词，`value` 是对应的解释（这里是整数）。  
- **`insert`**：直接把 `key` 与 `val` 写进去，如果 `key` 已经存在就覆盖（因为题目要求后来的值会覆盖之前的值）。  
- **`sum`**：遍历字典的所有键，挑出以给定 `prefix` 开头的键，把它们对应的值相加。  

这套思路一定能得到正确答案，因为我们把所有信息都完整保存了，查询时只要把符合条件的值累加即可。

#### 代码（Python）  
```python
class MapSum:
    def __init__(self):
        # 用字典保存键值对，key -> val
        self.store = {}

    def insert(self, key: str, val: int) -> None:
        # 直接写入或覆盖
        self.store[key] = val

    def sum(self, prefix: str) -> int:
        total = 0
        # 遍历所有键，检查是否以 prefix 开头
        for k, v in self.store.items():
            if k.startswith(prefix):   # 字符串的 startswith 就像“检查前缀”
                total += v
        return total
```

#### 复杂度  
- **时间复杂度**：  
  - `insert` 为 O(1)，因为字典写入是常数时间。  
  - `sum` 为 O(N)（N 为当前已插入的键数），因为要逐个检查每个键是否匹配前缀。可以把 O(N) 想象成“要把所有钥匙都拿出来对比”。  
- **空间复杂度**：O(N)，我们把每个键都保存下来，空间随键的数量线性增长。

### 2. 最优解  

#### 思路  
暴力解的瓶颈在 `sum`：每次查询都要遍历全部键，最坏情况下会很慢。  
我们需要一种**能在前缀层面直接得到累计和**的数据结构。  
- **Trie（前缀树）** 正好适合这类“前缀”操作。可以把每个字符看成树的一个节点，从根到叶子形成一个完整的单词。  
- 为了让 `sum(prefix)` 快速返回，我们在每个节点额外维护一个 `sum`，表示**所有以该节点为前缀的键的值之和**。  
- **插入时的细节**：如果某个 `key` 已经存在，需要先把旧值的贡献从沿路径的 `sum` 中减掉，再加上新值。为此我们维护一个外部 `hash map`（字典）`key2val`，记录每个键当前的值。  

实现步骤  
1. 创建 Trie 节点类，属性有 `children`（子节点字典）和 `prefix_sum`（以该节点为前缀的累计值）。  
2. `insert(key, val)`  
   - 读取 `old = key2val.get(key, 0)`，计算 `delta = val - old`（本次需要在路径上增加的差值）。  
   - 更新 `key2val[key] = val`。  
   - 从根节点开始遍历 `key` 的每个字符：如果子节点不存在就新建，随后把 `delta` 加到该子节点的 `prefix_sum`。  
3. `sum(prefix)`  
   - 沿着前缀走到对应的节点，如果途中缺少节点直接返回 0（说明没有任何键以该前缀开头）。  
   - 到达最后一个字符所在的节点后，返回它的 `prefix_sum`。  

这样 `sum` 只需要 O(L) 的时间（L 为前缀长度），而不是遍历全部键。  

#### 代码（Python）  
```python
class TrieNode:
    """Trie 的节点"""
    def __init__(self):
        # children: {字符: TrieNode}
        self.children = {}
        # prefix_sum: 以当前节点为前缀的所有键的值之和
        self.prefix_sum = 0


class MapSum:
    def __init__(self):
        # 根节点不存任何字符，只是一个入口
        self.root = TrieNode()
        # 记录每个完整键当前对应的值，用于处理覆盖的情况
        self.key2val = {}

    def insert(self, key: str, val: int) -> None:
        # 计算这次插入对累计和的影响
        old_val = self.key2val.get(key, 0)   # 之前的值，若不存在则为 0
        delta = val - old_val                # 需要在路径上增减的差值
        # 更新记录
        self.key2val[key] = val

        node = self.root
        for ch in key:
            # 若该字符的子节点不存在就创建
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            # 把差值累加到每个经过的节点的 prefix_sum 上
            node.prefix_sum += delta

    def sum(self, prefix: str) -> int:
        node = self.root
        for ch in prefix:
            if ch not in node.children:   # 前缀不存在
                return 0
            node = node.children[ch]
        # 此时 node 正好是前缀对应的节点，直接返回累计和
        return node.prefix_sum
```

#### 复杂度  
- **时间复杂度**：  
  - `insert` 为 O(L)，L 为键的长度（最多 50），因为只需要沿键的路径走一遍。  
  - `sum` 也是 O(L)，只遍历前缀长度的节点。相较于暴力解的 O(N)（遍历全部键），这里的 L 通常远小于 N。  
- **空间复杂度**：  
  - 最坏情况下每个不同的键都不共享前缀，需要在 Trie 中创建 `len(key)` 个节点，所以总体是 O(T)，T 为所有键字符总数（≤ 50 × 50 = 2500），在本题的约束下非常小。  
  - 额外的 `key2val` 字典也占 O(N) 空间，用来记录键对应的值。

## 心得  

- **核心技巧**：利用 **Trie（前缀树)** 并在每个节点维护前缀累计和，实现前缀求和的 O(L) 查询。  
- **适用的题型**：  
  1. “前缀计数”类，如 LeetCode 208. Implement Trie (Prefix Tree)。  
  2. “前缀加权求和”类，如 LeetCode 1124. Longest Well‑Performing Interval（可以改用前缀和思路）。  
  3. “自动补全”类题目，需要快速获取以某前缀开头的所有单词或统计信息。  
- **一句话总结**：**把“前缀”信息提前聚合在树的每个节点上，查询时直接读取即可**。

## 反思  

- **第一反应**：把键值对存进字典，遍历全部键求和。  
- **最容易踩的坑**：  
  - **键被覆盖**：`insert` 时若不处理旧值，会导致累计和重复计数。  
  - **前缀不存在**：在 `sum` 时要及时返回 0，防止访问空的子节点导致错误。  
  - **字符范围**：只考虑小写字母，可直接用字典存子节点，无需额外的数组大小。  
- **下次类似题的第一步**：先判断是否可以把“查询的目标（前缀、区间等）”提前聚合到数据结构的节点上；如果可以，就考虑使用 Trie、线段树或前缀和等预处理手段。
