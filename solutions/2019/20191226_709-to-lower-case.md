## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的办法就是把字符串交给 Python 自带的 `str.lower()` 方法，让它帮我们把所有大写字母一次性全部变成小写。  
- **使用的数据结构**：Python 的 `str` 本身就是字符数组的抽象，可以把它想象成一排排字母卡片。  
- **为什么正确**：`lower()` 会遍历每一个字符，遇到大写字母就把它换成对应的小写字母，其他字符保持不变，正好满足题目要求。  
- **复杂度分析**：  
  - **时间**：需要看一遍全部字符，记作 **O(n)**（n 是字符串长度），这里的 O(n) 就是“线性”，意思是字符越多，耗时就线性增长。  
  - **空间**：Python 会返回一个新字符串，长度和原串相同，所以占用 **O(n)** 的额外空间。  

> 小提示：虽然直接调用库函数是最省事的，但面试里往往希望你能手写实现，展示对字符编码的理解。

#### 代码（Python）

```python
def to_lower_case_brute(s: str) -> str:
    """
    暴力解：直接调用 Python 内置的 lower() 方法。
    """
    # 直接返回转换后的新字符串
    return s.lower()
```

#### 复杂度

- **时间复杂度**：O(n) — 需要遍历一次全部字符，字符越多花的时间就越多，呈线性增长。  
- **空间复杂度**：O(n) — 需要额外存放一个和原字符串等长的新字符串。  

---

### 2. 最优解

#### 思路  

从暴力解出发，唯一的“慢点”其实是 **调用库函数的内部实现**，但对我们来说，真正的核心是 **如何利用 ASCII 码的规律自行完成大小写转换**。  

1. **找规律**  
   - 大写字母的 ASCII 码范围是 65（'A'）到 90（'Z'）。  
   - 小写字母的 ASCII 码范围是 97（'a'）到 122（'z'）。  
   - 两者相差恰好 **32**（即 `'a' = 'A' + 32`），所以只要把大写字母的码值加 32，就得到对应的小写字母。  

2. **实现步骤**  
   - 初始化一个空列表 `res` 用来收集转换后的字符（列表比直接拼接字符串更高效）。  
   - 对字符串 `s` 中的每个字符 `ch`：  
     - 通过 `ord(ch)` 取出它的 ASCII 码 `code`。  
     - 判断 `code` 是否在 `[65, 90]` 之间（即是否是大写字母）。  
     - 如果是，则 `code += 32`，再用 `chr(code)` 把码值转回字符；否则保持原字符。  
     - 把得到的字符加入 `res`。  
   - 最后用 `''.join(res)` 把列表合并成结果字符串返回。  

3. **为什么更好**  
   - 只用了最基本的整数运算和字符转换，没有额外的函数调用，时间常数更小。  
   - 代码展示了对 ASCII 表的理解，面试官更容易看到你的思考过程。  

> **类比**：把大写字母想象成左手写的字，右手写的对应小写字母只需要把手往右平移 32 个格子。

#### 代码（Python）

```python
def to_lower_case_opt(s: str) -> str:
    """
    最优解：手动利用 ASCII 码的规律把大写字母转成小写。
    """
    res = []                     # 用列表收集字符，避免频繁创建新字符串
    for ch in s:                 # 逐个遍历原字符串
        code = ord(ch)           # 把字符转换成对应的 ASCII 码（整数）
        if 65 <= code <= 90:     # 判断是否是大写字母（'A'~'Z'）
            code += 32           # 大写转小写，只需加上 32
            ch = chr(code)       # 再把整数码转回字符
        # 如果不是大写字母，ch 保持原样
        res.append(ch)           # 把处理后的字符放进列表
    return ''.join(res)          # 把列表拼成最终的字符串
```

#### 复杂度

- **时间复杂度**：O(n) — 仍然只遍历一次字符，但每一步只有几条简单的整数运算，常数更小。  
- **空间复杂度**：O(n) — 需要一个同等长度的列表来保存结果字符，最终合并成新字符串。

## 心得

- **核心技巧**：利用 ASCII 码的固定偏移（大写 → 小写相差 32）进行字符转换。  
- **适用的题型**：  
  1. 字符串大小写互转（如 “To Upper Case”）。  
  2. 判断字符是否为字母或数字（通过 ASCII 范围）。  
  3. 实现自定义的字符映射（如 ROT13 加密）。  
- **一句话总结**：**掌握 ASCII 码的数值关系，就能用最简洁的算术把大小写互相转换。**

## 反思

- **第一反应**：直接想到 Python 的 `lower()`，因为它最省事。  
- **最容易踩的坑**：  
  - 忘记只对大写字母加 32，其他字符（如空格、标点）如果也加会得到错误字符。  
  - 对非 ASCII 字符（如中文）使用此方法会出错，但题目已限制为可打印的 ASCII。  
- **下次思路**：看到“字符转换”这类关键词时，第一步先回忆 **ASCII 码的相邻关系**，判断是否可以用固定的数值偏移来实现。
