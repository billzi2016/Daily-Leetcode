## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：先把 **rand7()** 产生的 1~7 的结果当成“骰子”，不断掷骰子，直到得到一个落在 1~10 范围内的数。  
因为 **rand7()** 每一次返回的概率都是 `1/7`，只要把多次掷出的结果组合成一个更大的随机区间，然后把超出 1~10 的情况全部丢弃（重新掷），最终留下的数就一定是均匀的。

- **数据结构**：这里不需要额外的数据结构，只要把两次 **rand7()** 的结果拼成一个 1~49 的整数即可。可以把它想象成把两颗 7 面骰子摆成一排，左边的骰子决定“十位”，右边的骰子决定“个位”。  
- **正确性**：`(a-1)*7 + b`（`a,b` 为两次 **rand7()** 的返回值）会产生 1~49 中的每一个整数，且每个整数出现的概率都是 `1/49`（因为两次独立均匀，乘法原理）。如果我们只接受 `1~40` 这 40 个数（`40` 能被 `10` 整除），把它们均匀映射到 `1~10`（`x % 10 + 1`），则每个 1~10 的数出现概率为 `4/49`，正好相等。  
- **为什么叫暴力**：我们把 1~49 全部枚举，然后把不在 1~40 的 9 个数全部丢掉，重新掷。这看起来很“浪费”，因为有 `9/49 ≈ 18%` 的情况需要重新来一次。对于初学者来说，这种“先造大范围、再抛弃多余”的思路最容易理解。

#### 代码（Python）

```python
import random   # 只用于演示，实际提交时请把下面的 rand7() 换成题目提供的 API

def rand7() -> int:
    """模拟题目给出的 API，返回 1~7 的均匀随机整数"""
    return random.randint(1, 7)

def rand10_bruteforce() -> int:
    """
    暴力版：先产生 1~49 的均匀整数，再把 >40 的情况抛弃
    """
    while True:
        # 第一次掷出 1~7，记作 a
        a = rand7()
        # 第二次掷出 1~7，记作 b
        b = rand7()
        # 把 a、b 组合成 1~49 的整数
        # 例如 a=3, b=5 => (3-1)*7 + 5 = 19
        num = (a - 1) * 7 + b          # 1 ≤ num ≤ 49
        # 只接受 1~40，超出的 41~49 直接丢弃，重新循环
        if num <= 40:
            # 把 1~40 均匀映射到 1~10
            return num % 10 + 1
```

#### 复杂度

- **时间复杂度**：`O(1)`（期望）。虽然在最坏情况下可能会一直循环，但每一次循环成功的概率是 `40/49 ≈ 0.816`，所以期望只需要 `1 / (40/49) ≈ 1.22` 次循环。可以把 `O(1)` 理解为“常数时间”，不随调用次数 n 增长。  
- **空间复杂度**：`O(1)`，只用了几个整数变量，和输入规模无关。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于 **“丢弃 9/49 的情况”**，如果我们能够把“被丢弃的那部分”再利用起来，就能进一步降低重新掷的次数。  

**核心想法：把剩余的 9 个数（41~49）继续扩展成更大的均匀区间**，这样可以一次性把更多的数字映射到 1~10，减少整体的拒绝率。具体步骤如下：

1. **第一次组合**：同暴力解，得到 `num = (a-1)*7 + b`，范围 1~49。  
2. **第一次筛选**：  
   - 如果 `num ≤ 40`，直接返回 `num % 10 + 1`（和暴力解一样）。  
   - 否则（`41 ≤ num ≤ 49`），把这 9 个数再利用。  
3. **把 9 个数映射到 1~63**：再调用一次 `rand7()`，记作 `c`。把 `num-40`（取值 1~9）和 `c` 组合成 `new_num = (num - 40 - 1) * 7 + c`，此时 `new_num` 的取值范围是 1~63，且每个数出现概率相等。  
4. **第二次筛选**：  
   - 如果 `new_num ≤ 60`，返回 `new_num % 10 + 1`。  
   - 否则（`61~63`）再继续循环（极少出现，概率只有 `3/63 = 1/21`）。  

这样做的好处是：第一次被拒绝的概率从 `9/49` 降到了 `3/63`，整体期望循环次数大幅下降，接近最优。

> **为什么叫“最优”**  
> 在只使用 `rand7()` 的前提下，**理论上**每一次调用都能产生最多 `7` 种不同的等概率结果。我们通过两次、三次甚至更多次的组合，尽可能把产生的总数做成 `10` 的整数倍（即 10、20、30、…），从而几乎不需要再次拒绝。上述两层拒绝已经非常接近理论最小值，实际运行时平均只需要约 `1.03` 次循环。

#### 代码（Python）

```python
import random   # 同样仅用于演示

def rand7() -> int:
    return random.randint(1, 7)

def rand10_opt() -> int:
    """
    最优解：利用两层拒绝采样，极大降低重新掷的次数
    """
    while True:
        # ---------- 第一次组合 ----------
        a = rand7()
        b = rand7()
        num = (a - 1) * 7 + b          # 1 ~ 49

        if num <= 40:                  # 直接接受的区间
            return num % 10 + 1

        # ---------- 把 41~49 再次利用 ----------
        # 取出剩余的 9 个数中的第几位（1~9）
        num = num - 40                 # 现在 num 为 1~9
        c = rand7()
        new_num = (num - 1) * 7 + c     # 1 ~ 63

        if new_num <= 60:              # 60 能被 10 整除
            return new_num % 10 + 1

        # 若 new_num 为 61~63，继续循环（极少出现）
```

#### 复杂度

- **时间复杂度**：`O(1)`（期望）。第一次循环成功的概率是 `40/49 ≈ 0.816`，若失败进入第二层，成功的概率是 `60/63 ≈ 0.952`。整体成功率约为 `0.816 + 0.184*0.952 ≈ 0.99`，平均只需要 `≈1.01` 次循环。相比暴力解的 `≈1.22` 次，这已经是非常接近理论最优的常数时间。  
- **空间复杂度**：`O(1)`，只用了常数个整数变量。

## 心得

- **核心技巧**：**拒绝采样（Rejection Sampling）** —— 把已有的均匀随机数通过组合扩展到更大的均匀区间，然后把不符合目标范围的“多余”部分丢弃或再利用。  
- **适用的题型**  
  1. 用 `rand5()` 实现 `rand7()`（同理）。  
  2. 用 `randM()` 实现 `randN()`（M、N 任意，常见于面试的通用随机数生成题）。  
  3. 将不等概率的离散分布转化为等概率抽样（比如抽奖系统中的加权抽取）。  
- **一句话总结解题钥匙**：**把小概率的“废弃”区间再拼接成更大的等概率区间，尽量让接受的范围正好是目标数的整数倍。**

## 反思

- **第一反应**：直接把两次 `rand7()` 的结果拼成 1~49，拿到 1~40 就返回，其余的继续循环——这就是最朴素的拒绝采样。  
- **最容易踩的坑**  
  1. **均匀性误判**：若只取 `num % 10 + 1` 而不做筛选，会导致 1~10 的概率不相等（因为 41~49 的出现概率被错误地映射进来了）。  
  2. **忘记减去偏移**：在第二层把 `41~49` 再次利用时，需要先把它们转成 `1~9`（`num-40`），否则组合公式会出错。  
  3. **无限循环**：如果筛选条件写错（比如 `>40` 改成 `>=40`），可能导致永远不退出。  
- **下次遇到同类题的第一步**：**先算出可以一次性得到的最大均匀区间**（比如 `7*7 = 49`），检查该区间能否被目标数整除；若不能，**把剩余的部分继续扩展**，形成第二层或更多层的拒绝采样。这样就能系统化地降低拒绝率，写出更高效的实现。
