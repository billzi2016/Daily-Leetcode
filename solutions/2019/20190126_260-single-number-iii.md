# #260. 只出现一次的数字 III / Single Number III

## 题目（英文原版）

**Description**

Given an integer array nums, in which exactly two elements appear only once and all the other elements appear exactly twice. Find the two elements that appear only once. You can return the answer in any order.
You must write an algorithm that runs in linear runtime complexity and uses only constant extra space.

**Examples**

**Example 1:**

```
Input: nums = [1,2,1,3,2,5]
Output: [3,5]
Explanation:  [5, 3] is also a valid answer.
```

**Example 2:**

```
Input: nums = [-1,0]
Output: [-1,0]
```

**Example 3:**

```
Input: nums = [0,1]
Output: [1,0]
```

**Constraints**

- 2 <= nums.length <= 3 * 104
- -231 <= nums[i] <= 231 - 1
- Each integer in nums will appear twice, only two integers will appear once.

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是把数组里每个数都“检查一遍”，看它到底出现了几次。  
- **数据结构**：我们可以用 **哈希表**（在 Python 中是 `dict`）来统计每个数出现的次数。哈希表就像一本 **查字典**，把数字当作单词，出现的次数当作页码，查找或插入的时间都非常快（常数时间）。
- **正确性**：遍历一次数组，把每个数的计数加 1；再遍历一次哈希表，挑出计数为 1 的两个数，这两个数正是题目要求的“只出现一次”的元素。

#### 代码（Python）

```python
def singleNumber(nums):
    # 第一次遍历：统计每个数出现的次数
    cnt = {}                         # 哈希表，key 是数字，value 是出现次数
    for x in nums:                   # 遍历每个元素
        cnt[x] = cnt.get(x, 0) + 1   # 如果 x 已经在表里就加 1，不在就当成 0 加 1

    # 第二次遍历：找出出现一次的两个数
    res = []
    for num, c in cnt.items():       # items() 同时得到键和值
        if c == 1:                   # 只出现一次的
            res.append(num)
            if len(res) == 2:        # 找到两个就可以提前结束
                break
    return res
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  解释：我们只遍历了两遍数组（`n` 为数组长度），每一步的操作都是常数时间，所以整体是线性时间。  
- **空间复杂度**：`O(n)`  
  解释：最坏情况下，哈希表要保存所有不同的数字。因为题目说只有两个数出现一次，其他都是成对出现，实际占用的空间仍然是与 `n` 成正比的。

### 2. 最优解

#### 思路  

暴力解已经是 `O(n)` 的时间，但它用了 `O(n)` 的额外空间。题目要求 **常数额外空间**，于是我们需要 **不使用哈希表**，只用几次遍历和位运算来完成。

1. **找出两个单独出现的数的异或结果**  
   - 把所有数全部异或（`^`），相同的数会两两抵消（因为 `a ^ a = 0`），只剩下两个只出现一次的数 `x` 与 `y` 的异或值 `xor = x ^ y`。  
   - 这一步只需要一次遍历，且只用一个整数变量保存 `xor`，空间是 `O(1)`。

2. **把 `xor` 中的任意一个为 1 的位挑出来**  
   - `xor` 必然不为 0，因为 `x != y`。设 `diff = xor & (-xor)`，这会得到 `xor` 最低位的 1（即二进制表示中最右侧的不同位）。  
   - 这一步的原理是：负数的二进制是原数取反后加 1，和原数做与运算会留下最低位的 1。

3. **根据这位将数组分成两组**  
   - 把所有数再次遍历，依据 `num & diff` 是否为 0 把它们分到 **两组**。  
   - 同一个数的两个拷贝一定会落在同一组，因为它们的所有位都相同。于是，**只出现一次的两个数会被分到不同的组**。  

4. **在每组内部再做一次异或**  
   - 对第一组做异或，得到的就是 `x`（或 `y`），因为组内的成对数字都抵消了，只剩下唯一的那个。  
   - 同理，第二组的异或结果就是另一个数。  

整个过程只用了 **两次遍历**，且只用了常数个整数变量。

> **类比**：想象有一堆成对的袜子（相同颜色），把它们全放进洗衣机里翻滚，成对的会相互抵消（消失），只剩下两只单只的袜子。我们再用一根细绳（`diff` 那一位）把这两只袜子分开，分别再把每堆袜子里的配对袜子拉掉，最后每堆只剩下那只单只袜子——就是我们要的答案。

#### 代码（Python）

```python
def singleNumber(nums):
    # 1️⃣ 把所有数异或，得到 x ^ y
    xor = 0
    for n in nums:
        xor ^= n               # 异或累计

    # 2️⃣ 取 xor 最低位的 1，作为分组依据
    diff = xor & -xor          # -xor 是 xor 的二进制取反后加 1

    # 3️⃣ 根据 diff 把数组分成两组，并在各自组内再异或
    a = 0                      # 组 1 的结果（会是 x 或 y）
    b = 0                      # 组 2 的结果（会是另一个数）
    for n in nums:
        if n & diff:           # 该位为 1，放进组 1
            a ^= n
        else:                  # 该位为 0，放进组 2
            b ^= n

    return [a, b]              # 任意顺序都可以
```

#### 复杂度

- **时间复杂度**：`O(n)`  
  解释：我们只遍历了两遍数组，每一步都是常数时间，和数组长度呈线性关系。相比暴力解的时间没有提升，但满足了 **常数空间** 的要求。

- **空间复杂度**：`O(1)`  
  解释：只用了几个整数变量 `xor、diff、a、b`，不随输入规模增长而增加，符合题目“只能使用常数额外空间”的限制。

## 心得

- **核心技巧**：**异或（XOR）消除相同元素 + 通过最低位的 1 将数组划分**。  
- **适用的题型**  
  1. *Single Number*（只出现一次的数）系列：  
     - `Single Number`（只出现一次的数）  
     - `Single Number II`（出现三次的数）  
  2. *数组中出现奇数次的数*（如找出只出现奇数次的元素）。  
- **一句话总结**：`xor` 把配对的数全部抵消，挑出任意不同位把剩余的两个数“强行分开”，再各自 `xor` 就能得到答案。

## 反思

- **第一反应**：看到“只出现一次的两个数”，立刻想到用哈希表计数，虽然满足时间要求，但忽略了空间限制。  
- **最容易踩的坑**  
  - **负数的异或**：Python 的整数是无限位的，需要注意 `-xor` 的二进制表示仍然有效，`xor & -xor` 能正常得到最低位的 1。  
  - **分组依据的位**必须是 `xor` 中为 1 的位，若误用了为 0 的位会导致两个唯一数落在同一组，结果出错。  
- **下次遇到同类题**：第一步先思考“能否用位运算把配对元素抵消”，如果答案是“是”，再寻找一种方式把剩余的元素区分开（比如取最低位的 1、最高位的 1、或利用掩码）。这样就能快速锁定常数空间的解法。
