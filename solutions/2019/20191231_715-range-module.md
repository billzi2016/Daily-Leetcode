# #715. 区间模块 / Range Module

## 题目（英文原版）

**Description**

A Range Module is a module that tracks ranges of numbers. Design a data structure to track the ranges represented as half-open intervals and query about them.
A half-open interval [left, right) denotes all the real numbers x where left <= x < right.
Implement the RangeModule class:

**Examples**

**Example 1:**

```
Input
["RangeModule", "addRange", "removeRange", "queryRange", "queryRange", "queryRange"]
[[], [10, 20], [14, 16], [10, 14], [13, 15], [16, 17]]
Output
[null, null, null, true, false, true]

Explanation
RangeModule rangeModule = new RangeModule();
rangeModule.addRange(10, 20);
rangeModule.removeRange(14, 16);
rangeModule.queryRange(10, 14); // return True,(Every number in [10, 14) is being tracked)
rangeModule.queryRange(13, 15); // return False,(Numbers like 14, 14.03, 14.17 in [13, 15) are not being tracked)
rangeModule.queryRange(16, 17); // return True, (The number 16 in [16, 17) is still being tracked, despite the remove operation)
```

**Constraints**

- 1 <= left < right <= 109
- At most 104 calls will be made to addRange, queryRange, and removeRange.

## 题目（中文翻译）

**描述**  
区间模块（Range Module）用于跟踪一系列数值区间。设计一种数据结构来记录以半开区间（half-open interval）形式表示的区间，并支持对这些区间的查询。

半开区间 `[left, right)` 表示所有满足 `left <= x < right` 的实数 `x`。

实现 `RangeModule` 类，使其能够：

- 添加区间 `addRange(left, right)`  
- 删除区间 `removeRange(left, right)`  
- 查询区间 `queryRange(left, right)`，返回 `true` 当且仅当 `[left, right)` 内的每个数都被当前追踪。

**示例 1**

```text
Input
["RangeModule", "addRange", "removeRange", "queryRange", "queryRange", "queryRange"]
[[], [10, 20], [14, 16], [10, 14], [13, 15], [16, 17]]

Output
[null, null, null, true, false, true]

Explanation
RangeModule rangeModule = new RangeModule();
rangeModule.addRange(10, 20);
rangeModule.removeRange(14, 16);
rangeModule.queryRange(10, 14);   // 返回 true，([10, 14) 内的每个数都被追踪)
rangeModule.queryRange(13, 15);   // 返回 false，([13, 15) 中的 14、14.03、14.17 等数未被追踪)
rangeModule.queryRange(16, 17);   // 返回 true，尽管执行了删除操作，区间 [16, 17) 中的数 16 仍被追踪
```

**约束条件**

- `1 <= left < right <= 10^9`
- 最多会调用 `addRange`、`removeRange`、`queryRange` 共计 `10^4` 次。

## 解题过程  

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有已经被“追踪”的区间全部存到一个 **列表** 里。  
- 每一次 `addRange(left, right)`：把 `[left, right)` 直接追加到列表中。  
- 每一次 `removeRange(left, right)`：遍历列表，把每个已有区间和 `[left, right)` 做交集判断，手动把被删掉的部分切成不相交的子区间再放回列表。  
- 每一次 `queryRange(left, right)`：遍历列表，只要找到 **任意** 一个区间完全覆盖 `[left, right)`，就返回 `True`，否则返回 `False`。

> **类比**：把列表想成一本“区间日记”。每写进一本新日记（`addRange`），就直接把它贴在最后；要把某段日记擦掉（`removeRange`），只能一本一本翻，找到相关的页码后把那页撕下来或剪成几段再粘回去。查询（`queryRange`）也是一本一本翻，看看有没有一本整整覆盖了我们要的时间段。

这种方法之所以 **正确**，是因为我们没有对区间进行任何合并或压缩，所有原始的添加和删除操作都完整保留下来，查询时只要有一段完整覆盖就一定能找到。

#### 代码（Python）

```python
class RangeModule:
    def __init__(self):
        # 用一个普通列表保存所有已添加的区间，格式为 (left, right)
        self.intervals = []

    # 暴力添加：直接把新区间放进去，不做合并
    def addRange(self, left: int, right: int) -> None:
        self.intervals.append((left, right))

    # 暴力删除：遍历所有区间，手动裁剪掉被删除的部分
    def removeRange(self, left: int, right: int) -> None:
        new_intervals = []
        for l, r in self.intervals:
            if r <= left or l >= right:
                # 完全不在删除区间范围内，直接保留
                new_intervals.append((l, r))
            else:
                # 有交集，需要切割
                if l < left:               # 保留左侧未被删掉的部分
                    new_intervals.append((l, left))
                if r > right:              # 保留右侧未被删掉的部分
                    new_intervals.append((right, r))
        self.intervals = new_intervals

    # 暴力查询：只要有任意一个区间完整覆盖目标区间，就返回 True
    def queryRange(self, left: int, right: int) -> bool:
        for l, r in self.intervals:
            if l <= left and r >= right:
                return True
        return False
```

#### 复杂度  

- **时间复杂度**  
  - `addRange`：O(1) —— 只往列表尾部加一个元素。  
  - `removeRange`：O(N) —— 必须遍历所有已有区间，N 为当前区间数量。  
  - `queryRange`：O(N) —— 也需要遍历所有区间查找是否有完整覆盖。  
  > 这里的 **O(N)** 可以理解为“最坏情况下要看完所有本子”，如果本子有 10 万页，就得翻 10 万次。

- **空间复杂度**  
  - O(N) —— 所有区间都原封不动地保存在列表里，最坏情况下会有和操作次数一样多的区间。

### 2. 最优解  

#### 思路  

暴力解的瓶颈在于 **查询和删除都需要线性遍历所有区间**。  
我们可以利用 “区间不相交、按左端点排好序” 这一特性，把区间压缩成 **互不重叠的有序集合**（类似字典的键值对，只存左端点和右端点）。这样可以：

1. **快速定位**：二分查找（`bisect`）在有序集合中定位到可能覆盖或相交的区间，只检查极少数几个邻近区间，时间降到 `O(log M)`（M 为当前不相交区间数）。  
2. **合并/切割**：在 `addRange` 和 `removeRange` 时，只对 **真正受影响的区间**（即与 `[left, right)` 有交集的那几段）进行合并或拆分，复杂度为 `O(K)`，其中 K 是受影响的区间数，通常远小于总数。

核心数据结构：**有序列表 + 二分查找**。  
- 列表 `self.intervals` 中的每个元素都是 `[l, r)`，且满足 `l1 < l2 < …` 且两两不相交。  
- `bisect_left` 可以在 `O(log M)` 时间找到第一个左端点 **≥** `left` 的位置。  
- 为了处理左端点可能在 **左侧** 且仍然覆盖 `left` 的情况，需要检查前一个区间。

> **类比**：把所有区间想成一本“有序的章节目录”。每章都有起止页码，章节之间不重叠。想找某页属于哪一章，只要二分查找目录，就能在几步（对数级）内定位到对应章节，而不必把整本书翻遍。

下面分别给出 `addRange`、`removeRange`、`queryRange` 的实现细节。

1. **addRange(left, right)**  
   - 用二分查找定位到可能的起始位置 `i`（第一个左端点 ≥ `left`）。  
   - 检查 `i-1` 是否与 `[left, right)` 相交（即 `intervals[i-1][1] >= left`），如果相交则把 `left` 向左扩展到 `intervals[i-1][0]`，并把 `i-1` 也计入需要合并的区间。  
   - 同样向右遍历，合并所有左端点 ≤ `right` 且右端点 ≥ `left` 的区间，记录最大的右端点 `new_right`。  
   - 最后把 `[new_left, new_right)` 替换掉这些被合并的区间。

2. **removeRange(left, right)**  
   - 同样二分定位。遍历所有与 `[left, right)` 相交的区间。  
   - 对每个相交区间 `[l, r)`，可能产生最多 **两段** 不被删除的子区间：  
        - 左侧保留 `[l, left)`（如果 `l < left`）  
        - 右侧保留 `[right, r)`（如果 `r > right`）  
   - 把这些子区间重新放入列表，删除原来的相交区间。  

3. **queryRange(left, right)**  
   - 二分定位到第一个左端点 **大于** `left` 的位置 `i`。真正可能覆盖 `left` 的区间是 `i-1`（如果存在）。  
   - 检查 `i-1` 的右端点是否 ≥ `right`，若是则说明 `[left, right)` 完全被追踪。  

#### 代码（Python）

```python
import bisect

class RangeModule:
    def __init__(self):
        # 保存不相交且左端点升序的区间列表，形如 [[l1, r1], [l2, r2], ...]
        self.intervals = []

    # ---------- 添加区间 ----------
    def addRange(self, left: int, right: int) -> None:
        # 1. 找到插入位置（第一个左端点 >= left）
        i = bisect.bisect_left(self.intervals, [left, right])
        # 2. 可能需要向左合并：检查 i-1 是否与新区间相交
        if i != 0 and self.intervals[i - 1][1] >= left:
            i -= 1                     # 把左侧相交的区间也纳入合并范围
            left = min(left, self.intervals[i][0])
            right = max(right, self.intervals[i][1])
        # 3. 向右遍历所有与 [left, right) 相交的区间，统一合并
        j = i
        while j < len(self.intervals) and self.intervals[j][0] <= right:
            right = max(right, self.intervals[j][1])
            j += 1
        # 4. 用合并后的新区间替换掉旧的相交区间
        self.intervals[i:j] = [[left, right]]

    # ---------- 删除区间 ----------
    def removeRange(self, left: int, right: int) -> None:
        i = bisect.bisect_left(self.intervals, [left, right])
        # 处理左侧可能相交的区间
        new_parts = []
        if i != 0 and self.intervals[i - 1][1] > left:
            l, r = self.intervals[i - 1]
            if l < left:                # 保留左侧未被删除的部分
                new_parts.append([l, left])
            if r > right:               # 保留右侧未被删除的部分
                new_parts.append([right, r])
            i -= 1                       # 把这个区间也标记为要删除

        # 处理右侧相交的连续区间
        j = i
        while j < len(self.intervals) and self.intervals[j][0] < right:
            l, r = self.intervals[j]
            if r > right:               # 只保留右侧超出删除区间的部分
                new_parts.append([right, r])
            j += 1

        # 用保留下来的子区间替换掉原来的相交区间
        self.intervals[i:j] = new_parts

    # ---------- 查询区间 ----------
    def queryRange(self, left: int, right: int) -> bool:
        # 找到第一个左端点 > left 的位置
        i = bisect.bisect_right(self.intervals, [left, float('inf')])
        if i == 0:
            return False
        # 检查前一个区间是否能够覆盖到 right
        return self.intervals[i - 1][0] <= left and self.intervals[i - 1][1] >= right
```

> **代码要点解释**  
> - `bisect_left` / `bisect_right` 在有序列表中实现二分查找，时间是 `O(log M)`。  
> - `self.intervals[i:j] = [...]` 用切片一次性替换掉 **所有** 受影响的区间，避免逐个 `pop` 带来的额外开销。  
> - 删除时最多产生两段新区间（左侧、右侧），所以 `new_parts` 长度永远 ≤ 2。  

#### 复杂度  

- **时间复杂度**  
  - `addRange`：`O(K + log M)`，其中 `K` 为与新区间相交的旧区间数（一般远小于总数），`log M` 来自二分定位。  
  - `removeRange`：`O(K + log M)`，同理只处理相交的 `K` 个区间。  
  - `queryRange`：`O(log M)`，仅一次二分查找即可得到答案。  
  > 与暴力解相比，查询从遍历全部 `N` 降到对数级 `log M`，在 10⁴ 次操作的规模下提升非常明显。

- **空间复杂度**  
  - `O(M)`，只保存互不相交的区间。因为相邻或重叠的区间会在 `addRange` 时合并，所以 `M` 不会超过实际被追踪的区间段数，最坏也就是所有操作交错导致的最多 `2·10⁴` 条区间，仍在可接受范围。

## 心得  

- **核心技巧**：维护**有序且不相交的区间集合**，配合二分查找实现快速定位。  
- **适用的题型**（类似思路）  
  1. **Range Sum Query - Mutable**（线段树/树状数组）  
  2. **My Calendar I / II / III**（预约日历冲突检测）  
  3. **Count of Smaller Numbers After Self**（离线处理 + 有序集合）  
- **一句话总结解题钥匙**：**把所有区间压缩成“无缝拼接的章节”，用二分定位章节所在，局部合并/拆分即可**。

## 反思  

- **第一反应**：直接把每次操作的区间保存下来，等需要时再遍历检查——这就是暴力解。  
- **最容易踩的坑**  
  - **边界条件**：区间是 **左闭右开** `[l, r)`，所以在判断相交、覆盖时要注意 `<=` 与 `<` 的区别。  
  - **二分查找的返回值**：`bisect_left` 与 `bisect_right` 的细微差别会影响“前一个区间是否可能覆盖左端点”。  
  - **删除后可能产生的两段子区间**：忘记把右侧剩余部分重新放回会导致数据缺失。  
- **下次遇到同类题**：第一步就**思考如何把数据结构保持有序且不重叠**，然后利用**二分**把需要处理的局部区间快速找出来，再在局部做合并/拆分。这样既能保证正确性，又能把复杂度控制在对数或线性（相交区间数）级别。
