# #520. **检测大写字母使用情况** / Detect Capital

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/detect-capital/)

---

## 题目（英文原版）

**Description**

We define the usage of capitals in a word to be right when one of the following cases holds:
Given a string word, return true if the usage of capitals in it is right.

**Examples**

**Example 1:**

```
Input: word = "USA"
Output: true
```

**Example 2:**

```
Input: word = "FlaG"
Output: false
```

**Constraints**

- 1 <= word.length <= 100
- word consists of lowercase and uppercase English letters.

---

## 题目（中文翻译）

我们定义一个单词（word）中大写字母（capital）的使用是正确的，当且仅当满足以下任意一种情况：  

给定一个字符串（string）`word`，如果其中的大写字母使用符合上述任意一种情况，返回 `true`，否则返回 `false`。

**示例 1**  
**输入:** `word = "USA"`  
**输出:** `true`

**示例 2**  
**输入:** `word = "FlaG"`  
**输出:** `false`

**约束条件**

- `1 <= word.length <= 100`
- `word` 只包含小写和大写英文字母。

---

## 解题过程  

### 1. 直觉解（暴力）  

#### 思路  

把单词里每个字母的大小写都 **检查一遍**，统计大写字母的个数。  
根据题目给出的三条合法规则：

1. 全部都是大写（比如 `"USA"`）  
2. 全部都是小写（比如 `"leetcode"`）  
3. 只有首字母是大写，其余都是小写（比如 `"Google"`）  

我们只要把统计得到的“大写字母数” 和 “单词长度” 对比，就能判断哪条规则成立。  

- **数据结构**：只需要一个整数 `cnt` 来记录大写字母的数量。  
  > 把它想象成 **计数器**，像超市里统计商品数量的收银机一样，每看到一个大写字母，就把计数器加一。  

- **正确性**：  
  - 若 `cnt == n`（`n` 为单词长度），说明每个字符都是大写，满足规则 1。  
  - 若 `cnt == 0`，说明全部是小写，满足规则 2。  
  - 若 `cnt == 1` 且 `word[0]` 是大写，说明只有首字母大写，满足规则 3。  
  - 其余情况必定不合法，返回 `False`。  

- **时间/空间复杂度**：  
  - 我们要遍历一次单词的每个字符，**时间复杂度是 O(n)**（n 为单词长度）。  
    > 用大白话说，就是“走一遍单词”，每走一步都要检查一次字母的大小写。  
  - 只用了一个整数计数器，**空间复杂度是 O(1)**（常数级别），不随输入规模增长。  

#### 代码（Python）

```python
def detectCapitalUse_bruteforce(word: str) -> bool:
    """
    暴力思路：遍历整个单词，统计大写字母的数量，然后根据三条规则判断是否合法。
    """
    n = len(word)                # 单词长度
    upper_cnt = 0                # 大写字母计数器

    # 逐个字符检查是否是大写字母
    for ch in word:
        if 'A' <= ch <= 'Z':     # 判断字符是否在大写字母的 ASCII 范围内
            upper_cnt += 1      # 大写字母计数器加一

    # 三种合法情况的判断
    if upper_cnt == n:                       # 全部大写
        return True
    if upper_cnt == 0:                       # 全部小写
        return True
    if upper_cnt == 1 and 'A' <= word[0] <= 'Z':   # 只有首字母大写
        return True

    # 其余情况都是不合法的
    return False
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 需要遍历单词的每个字符一次。  
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和单词长度无关。

### 2. 最优解  

#### 思路  

上面的暴力解已经是 **线性时间、常数空间**，已经非常高效。  
我们可以把代码写得更简洁、更易读，利用 Python 内置的字符串方法 `isupper()`、`islower()` 以及切片来一次性判断三条规则，而不需要显式计数。  

优化点在于 **不再手动遍历计数**，而是让语言本身一次性完成判断，这在实际面试中常被认为是“最优写法”。  

核心概念（对初学者的解释）：

- `str.isupper()`：检查整个字符串是否 **全部是大写**。想象成把单词全部放进“大写检验机”，只要每个字母都是大写，就会返回 `True`。  
- `str.islower()`：检查整个字符串是否 **全部是小写**。类似的，小写检验机。  
- `word[0].isupper() and word[1:].islower()`：先检查首字符是否大写，再检查剩余部分是否全部小写。相当于把单词切成两段，分别放进对应的检验机。  

这三种检查只要有一种成立，单词的大小写使用就是合法的。  

#### 代码（Python）

```python
def detectCapitalUse_optimal(word: str) -> bool:
    """
    最优写法：利用 Python 的字符串方法直接判断三条合法规则。
    """
    # 规则 1：全部大写
    if word.isupper():
        return True

    # 规则 2：全部小写
    if word.islower():
        return True

    # 规则 3：首字母大写，其余小写
    # 先检查第一个字符是大写，再检查后面的子串全部小写
    if word[0].isupper() and word[1:].islower():
        return True

    # 以上都不满足，则为非法用法
    return False
```

#### 复杂度  

- **时间复杂度**：`O(n)` — 虽然代码看起来只写了几行判断，但每个 `isupper` / `islower` 实际上都要遍历对应的子串。最坏情况下仍然是遍历一次单词（和暴力解等价），但常数因子更小。  
- **空间复杂度**：`O(1)` — 只使用了常数个临时变量，未额外开辟与输入规模相关的空间。  

与暴力解对比：时间上同样是线性，空间上同样是常数；不同的是实现更简洁，易于阅读和维护。

## 心得  

- **核心技巧**：对字符串大小写的三种合法组合进行**分类讨论**，并利用语言提供的 **全大写 / 全小写** 判断函数快速验证。  
- **适用的题型**：  
  1. 判断字符串是否满足特定模式（如密码强度检测）。  
  2. 检查单词是否符合特定的字母排列规则（比如回文、字母顺序）。  
  3. 需要对字符集合进行“全部相同”或“除首字符外全部相同”这类判定的题目。  
- **一句话总结解题钥匙**：**把所有可能的合法情况列举清楚，然后逐个快速验证**。

## 反思  

- **第一反应**：看到题目立刻想到“统计大写字母的数量”，因为只要知道大写有几位，就能判断是哪种合法情况。  
- **最容易踩的坑**：  
  - 忽略了长度为 1 的单词。此时无论是大写还是小写，都应该返回 `True`。  
  - 在手动遍历时，判断 “只有首字母大写” 时可能写成 `upper_cnt == 1` 而忘记检查首字符是否真的大写。  
- **下次遇到同类题的第一步**：**先列出所有合法的“模式”**（比如全部大写、全部小写、首字母大写），然后思考语言提供的快捷方法能否直接判断这些模式，从而避免不必要的循环。
