# #447. 回旋镖的数量 / Number of Boomerangs

> 难度：中等 · 标签：Array、Hash Table、Math · [LeetCode 链接](https://leetcode.com/problems/number-of-boomerangs/)

---

## 题目（英文原版）

**Description**

You are given n points in the plane that are all distinct, where points[i] = [xi, yi]. A boomerang is a tuple of points (i, j, k) such that the distance between i and j equals the distance between i and k (the order of the tuple matters).
Return the number of boomerangs.

**Examples**

**Example 1:**

```
Input: points = [[0,0],[1,0],[2,0]]
Output: 2
Explanation: The two boomerangs are [[1,0],[0,0],[2,0]] and [[1,0],[2,0],[0,0]].
```

**Example 2:**

```
Input: points = [[1,1],[2,2],[3,3]]
Output: 2
```

**Example 3:**

```
Input: points = [[1,1]]
Output: 0
```

**Constraints**

- n == points.length
- 1 <= n <= 500
- points[i].length == 2
- -104 <= xi, yi <= 104
- All the points are unique.

## 题目（中文翻译）

给定平面上 **n** 个互不相同的点，`points[i] = [xi, yi]`。  
回旋镖是一个点的元组（tuple）`(i, j, k)`，满足点 **i** 与点 **j** 之间的距离（distance）等于点 **i** 与点 **k** 之间的距离（distance），且元组的顺序不同视为不同的回旋镖。  

返回回旋镖的数量。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把所有可能的三元组 `(i, j, k)` 都枚举一遍，检查 `i` 到 `j` 的距离是否和 `i` 到 `k` 的距离相等。  
这里用到的唯一数据结构是 **列表**（`list`），因为题目已经把点存成了二维列表 `points`，我们只需要按下标取值即可。  

可以把它想象成在一群小朋友里挑选 **领头的小朋友 i**，然后在剩下的小朋友里随便挑两个 **伙伴 j、k**，看这两对的距离是不是相同。如果相同，就算一条 “回旋镖”。因为 **顺序重要**，`(i, j, k)` 与 `(i, k, j)` 被视为不同的回旋镖。

**为什么正确**：我们把所有合法的三元组都检查了一遍，只要满足条件就计数，漏掉的情况不存在。

**复杂度分析**：  
- 外层遍历 `i`：`n` 次。  
- 中层遍历 `j`：每个 `i` 要遍历 `n-1` 次。  
- 内层遍历 `k`：每个 `(i, j)` 再遍历 `n-2` 次。  

所以总的操作次数约为 `n³`，即 **时间复杂度 O(n³)**。  
空间上我们只用了常数级的变量（计数器、临时距离），所以 **空间复杂度 O(1)**。  
> 大白话解释：如果有 100 个点，暴力解要检查大约 `100³ = 1,000,000` 次，这在电脑眼里已经算是“很慢”。

#### 代码（Python）

```python
from typing import List

def numberOfBoomerangs_bruteforce(points: List[List[int]]) -> int:
    n = len(points)
    ans = 0

    # 枚举领头点 i
    for i in range(n):
        xi, yi = points[i]

        # 枚举第一个伙伴 j
        for j in range(n):
            if i == j:          # 不能和自己配对
                continue
            xj, yj = points[j]

            # 计算 i 与 j 的欧氏距离的平方（避免开根号的浮点误差）
            d_ij = (xi - xj) ** 2 + (yi - yj) ** 2

            # 枚举第二个伙伴 k
            for k in range(n):
                if k == i or k == j:   # 不能重复使用点
                    continue
                xk, yk = points[k]
                d_ik = (xi - xk) ** 2 + (yi - yk) ** 2

                # 距离相等，则构成一个回旋镖
                if d_ij == d_ik:
                    ans += 1

    return ans
```

#### 复杂度

- **时间复杂度**：`O(n³)` — 需要三层循环，点的数量每多一次，检查次数就会乘以约 `n`。
- **空间复杂度**：`O(1)` — 只用了几个整数变量，和 `n` 的大小无关。

### 2. 最优解

#### 思路  

从暴力解可以看到 **瓶颈** 出在第三层循环：对每个 `i` 我们都在 **所有点对** `(j, k)` 上做重复的距离比较。  
实际上，对于固定的领头点 `i`，只要知道 **每个距离出现了多少次**，我们就可以直接算出有多少合法的 `(i, j, k)`。

> 类比：想象你在一条直线上站着，手里有一把尺子，想找所有与自己等距的伙伴。只要先把所有伙伴到你的距离记下来，统计每个距离出现了几次，后面就不需要再两两比较了。

具体步骤：

1. **遍历每个点 `i` 作为领头**。  
2. 用一个 **哈希表（字典）** `cnt` 记录 `i` 到其它点的 **距离的平方**（因为平方根不影响相等性，且能避免浮点数）。键是距离，值是出现次数。  
   - 哈希表可以类比为 **查字典**：词是“距离”，对应的页码是“有多少个点在这个距离”。  
3. 对于哈希表中的每个距离 `d`，如果出现次数为 `m`，则从这 `m` 个点中任选两个作为 `(j, k)`，且顺序不同会产生 `m * (m - 1)` 种回旋镖（先选 `j` 再选 `k`）。  
4. 把所有 `i` 的贡献累计，就是答案。

**为什么正确**：  
- 对于固定的 `i`，如果有 `m` 个点与 `i` 的距离相同，那么这 `m` 个点两两组合（顺序计）恰好是所有满足题意的 `(i, j, k)`。  
- 我们对每个 `i` 都这样统计，且每个三元组只会在它的领头点 `i` 那里被计数一次，因而不重复也不遗漏。

**核心算法/数据结构**：  
- **哈希表（字典）**：`O(1)` 平均时间的键值存取，用来快速统计相同距离的点数。  
- **前缀思路**：我们不需要再遍历 `k`，只用计数公式 `m * (m - 1)` 即可。

**复杂度分析**：  
- 外层遍历 `i`：`n` 次。  
- 内层遍历其他点计算距离：每次 `n-1` 次，整体是 `O(n²)`。  
- 哈希表的插入/查询均摊为 `O(1)`，所以总时间是 **`O(n²)`**。  
- 额外空间只需要存放一次哈希表，最多会有 `n-1` 条不同的距离，空间为 **`O(n)`**。

> 大白话解释：如果有 500 个点，最优解只会做约 `500² = 250,000` 次距离计算，比暴力的 `125,000,000` 次少了 **500 倍**，运行时间瞬间可以接受。

#### 代码（Python）

```python
from typing import List
from collections import defaultdict

def numberOfBoomerangs(points: List[List[int]]) -> int:
    n = len(points)
    ans = 0

    # 枚举每个点 i 作为回旋镖的“领头”
    for i in range(n):
        xi, yi = points[i]

        # cnt[d] 表示距离 i 为 d 的点有多少个
        cnt = defaultdict(int)   # 默认值 0 的字典，类似“查字典”

        # 统计 i 与其它所有点的距离（平方）
        for j in range(n):
            if i == j:
                continue
            xj, yj = points[j]
            d = (xi - xj) ** 2 + (yi - yj) ** 2   # 距离的平方
            cnt[d] += 1      # 同一个距离出现一次，计数加一

        # 对每个出现次数为 m 的距离，贡献 m * (m-1) 条回旋镖
        for m in cnt.values():
            if m > 1:                     # 至少两个点才会产生回旋镖
                ans += m * (m - 1)        # 先选 j 再选 k，顺序不同计两次

    return ans
```

#### 复杂度

- **时间复杂度**：`O(n²)` — 两层循环遍历所有点对，`n ≤ 500` 时非常快。  
- **空间复杂度**：`O(n)` — 每次循环需要的哈希表最多存 `n-1` 条不同距离。

## 心得

- 这道题核心考察 **“同一点到其它点的距离分组计数”** 的技巧。  
- 该技巧常在 **“以某点为中心统计相等关系”** 的题目中出现，如  
  1. *Number of Good Pairs*（统计数组中相等元素的对数）  
  2. *Largest Triangle Area*（需要对同一点的斜率或距离做分组）  
  3. *Maximum Number of Points with Same X-Coordinate*（类似的哈希计数）  
- **解题钥匙**：先把“相等的东西”聚在一起，用哈希表计数，然后用组合公式直接算出答案。

## 反思

- **第一反应**：直接三层循环枚举所有三元组，代码最容易写出来。  
- **最容易踩的坑**：  
  - **距离比较**：使用欧氏距离的平方避免浮点误差，直接比较整数。  
  - **顺序计数**：回旋镖是有序三元组，需要 `m * (m-1)` 而不是组合数 `C(m,2)`。  
  - **边界条件**：点数少于 2 时直接返回 0，防止除零或空字典错误。  
- **下次类似题**，第一步应该想到 **“以每个点为中心，统计它到其它点的某种属性（距离、斜率、差值）出现的次数”**，再用计数公式求答案。
