# #921. 使括号有效的最少添加次数 / Minimum Add to Make Parentheses Valid

> 难度：中等 · 标签：String、Stack、Greedy · [LeetCode 链接](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/)

---

## 题目（英文原版）

**Description**

A parentheses string is valid if and only if:
You are given a parentheses string s. In one move, you can insert a parenthesis at any position of the string.
Return the minimum number of moves required to make s valid.

**Examples**

**Example 1:**

```
Input: s = "())"
Output: 1
```

**Example 2:**

```
Input: s = "((("
Output: 3
```

**Constraints**

- 1 <= s.length <= 1000
- s[i] is either '(' or ')'.

---

## 题目（中文翻译）

一个括号字符串仅在满足以下条件时才是有效的：
- 它是空字符串，或者
- 它可以写成 AB （A 与 B 的连接），其中 A 和 B 均为有效字符串，或者
- 它可以写成 (A) ，其中 A 为有效字符串。

给定一个仅由字符 `'('` 和 `')'` 组成的字符串 `s`。在一次操作中，你可以在字符串的任意位置插入一个括号。  
返回使 `s` 变为有效字符串所需的最少操作次数。

**示例 1**  
``` 
Input: s = "())"
Output: 1
```  
**解释**：在字符串开头插入一个 `'('`，得到 `"(() )"`，此时字符串有效。

**示例 2**  
``` 
Input: s = "((("
Output: 3
```  
**解释**：在字符串末尾依次插入三个 `')'`，得到 `"((()))"`，此时字符串有效。

**约束条件**  
- `1 <= s.length <= 1000`  
- `s[i]` 为 `'('` 或 `')'`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直观的想法是把字符串看成一串“左括号”和“右括号”，我们要把它们两两配对。  
把**栈**想象成一个“临时放置左括号的箱子”：

- 当遇到左括号 `(` 时，我们把它放进箱子（`push`），因为它还有机会和后面的右括号配对。  
- 当遇到右括号 `)` 时，我们先检查箱子里有没有左括号：
  - 若箱子不空（`stack` 有元素），说明可以和箱子里最近放进去的左括号配对，于是把左括号取出来（`pop`）。  
  - 若箱子空了，说明这个右括号前面没有左括号可以配对，这时只能**在左边补一个左括号**，记一次插入操作。

遍历结束后，箱子里剩下的左括号都没有对应的右括号，需要在右边各补一个右括号。  
把“补左括号的次数” + “箱子里剩余左括号的个数” 就是最少的插入次数。

> 为什么这样一定对？  
> 因为每次我们都尽可能地把左、右括号配对，只在配不了的情况下才“强行补”。任何合法的括号序列都必须满足左括号数量≥右括号数量（从左到右遍历的任何前缀），所以每一次缺少左括号的右括号都必须补左括号；同理，遍历结束后剩余的左括号也必须各补一个右括号，才能让整体平衡。

#### 代码（Python）

```python
def minAddToMakeValid_brute(s: str) -> int:
    stack = []                 # 用列表当栈，存放左括号 '('
    insert_cnt = 0             # 记录需要插入的左括号数量

    for ch in s:
        if ch == '(':
            stack.append(ch)   # 左括号入栈，等待配对
        else:  # ch == ')'
            if stack:
                stack.pop()    # 栈非空，直接配对一个左括号
            else:
                # 栈空，说明当前右括号前没有左括号，必须在左边补一个 '('
                insert_cnt += 1

    # 遍历结束后，栈里剩下的都是没有配对的左括号，需要在右边各补一个 ')'
    insert_cnt += len(stack)
    return insert_cnt
```

#### 复杂度

- **时间复杂度：** `O(n)` —— 需要遍历一次字符串，`n` 为字符串长度。可以想象成“看完每个字符只需要一步”，如果 `n = 1000`，大约只会执行 1000 次基本操作，几乎是瞬间完成的。  
- **空间复杂度：** `O(n)` —— 最坏情况下字符串全是左括号，栈会保存全部 `n` 个字符，需要 `n` 的额外空间。

### 2. 最优解

#### 思路  

暴力解的瓶颈在 **空间**：我们用栈保存所有未配对的左括号。其实我们只需要知道“还有多少左括号等待配对”，而不必记住它们的具体位置。于是可以用一个整数 `balance` 来代替栈：

- `balance` 表示当前左括号的“净数量”。遇到 `(` 时 `balance += 1`（左括号增多），遇到 `)` 时 `balance -= 1`（尝试配对一个左括号）。
- 当 `balance` 变成 **-1** 时，说明出现了一个左括号不足的右括号，此时只能在左边**补一个左括号**，插入次数 `ans += 1`，并把 `balance` 重置为 `0`（因为我们已经假设在左边补了一个左括号，使得当前右括号得到了配对）。

遍历结束后，`balance` 只可能是非负的，它表示还有多少左括号没有配对，需要在右边各补一个右括号，最终答案为 `ans + balance`。

> **为什么只用一个计数就够了？**  
> 想象从左到右读取字符时，左括号像“欠银行的钱”，右括号像“还钱”。`balance` 记录当前欠多少钱。只要欠钱（`balance < 0`），我们立刻“去银行借一块钱”（补左括号），把欠款归零；如果最后还有欠款（`balance > 0`），就去“银行再拿几块钱”（补右括号）把账目平衡。整个过程只需要两次计数，既快又省空间。

#### 代码（Python）

```python
def minAddToMakeValid(s: str) -> int:
    ans = 0        # 已经需要插入的左括号数量
    balance = 0    # 当前左括号的净数量（左-右）

    for ch in s:
        if ch == '(':
            balance += 1          # 左括号出现，等待配对的数量加 1
        else:  # ch == ')'
            balance -= 1          # 尝试配对一个左括号
            if balance == -1:     # 出现了右括号多于左括号的情况
                ans += 1          # 必须在左边补一个 '('
                balance = 0      # 把 balance 重置为 0，表示已经配对成功

    # 遍历结束后，balance 只可能是 >= 0，表示还有多少 '(' 没配对
    return ans + balance
```

#### 复杂度

- **时间复杂度：** `O(n)` —— 仍然只需要一次遍历，每个字符做常数次操作。与暴力解的时间相同，但因为没有额外的数据结构，实际跑得更快。  
- **空间复杂度：** `O(1)` —— 只用了两个整数 `ans`、`balance`，不随输入规模增长，几乎不占内存。

## 心得

- 这道题考察的核心技巧是 **贪心 + 前缀计数**（用 `balance` 记录当前左括号的净数），本质是把“配对”过程转化为“计数”过程。  
- 该技巧常用于 **括号匹配类**、**有效字符序列** 等题目，例如  
  1. **921. Minimum Add to Make Parentheses Valid**（本题）  
  2. **921. Longest Valid Parentheses**（需要找最长合法子串）  
  3. **921. Valid Parenthesis String**（带通配符的合法性判断）  
- **一句话总结解题钥匙：** “只要维护一个左括号的净计数，左括号不足时立刻补，遍历结束后把剩余左括号补完即可。”

## 反思

- **第一反应**：看到“只包含 '(' 和 ')' 的字符串，需要最少插入次数”，第一时间想到用栈把括号配对，统计缺少的部分。  
- **最容易踩的坑**  
  - 忘记在遍历结束后把栈里剩余的左括号全部计入答案（或者忘记把 `balance` 加到最终答案）。  
  - 在贪心实现里，`balance` 为 `-1` 时只加一次插入，而不是每次都把 `balance` 设为负数后继续累加。  
  - 边界情况：空字符串、全是左括号或全是右括号，都必须返回对应的字符数。  
- **下次遇到同类题**，第一步应该想到：“从左到右维护一个‘未配对左括号数量’的计数器，左括号不足时立即补，最后把剩余的左括号补完”。这样即可得到最优解。
