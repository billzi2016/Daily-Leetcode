## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是把 **所有字母** 先挑出来，反转顺序后再塞回原来的位置。可以把它想象成：

- **字母** 就像一袋子糖果，我们先把糖果全部倒出来（用列表保存），再把这袋糖果倒回去时把顺序翻转。
- 其它字符（数字、符号）相当于 **不参与游戏的石子**，它们一直原地不动。

实现步骤：

1. **遍历原字符串**，把每个字母 (`a`‑`z`、`A`‑`Z`) 收集到 `letters` 列表中。  
2. 把 `letters` 列表整体翻转（`letters[::-1]`），得到倒序的字母序列。  
3. 再次遍历原字符串，遇到字母时从翻转后的 `letters` 中取出下一个字符，放进结果；遇到非字母时直接复制。

这样就保证了所有字母位置被逆序，而其它字符保持不动。

> 为什么它是对的？因为我们只改变了字母的相对顺序，而字母的 **出现次数** 与原字符串完全相同，非字母根本没有被触碰。

#### 代码（Python）

```python
def reverseOnlyLetters_bruteforce(s: str) -> str:
    # 1️⃣ 把所有字母挑出来，放进列表
    letters = [ch for ch in s if ch.isalpha()]   # isalpha() 判断是否为字母

    # 2️⃣ 把字母列表整体翻转
    letters.reverse()   # 原地翻转，等价于 letters = letters[::-1]

    # 3️⃣ 重新构造答案
    res = []             # 用列表收集字符，最后一次性 join，效率高
    for ch in s:
        if ch.isalpha():            # 是字母，就从翻转后的列表里取一个
            res.append(letters.pop(0))   # pop(0) 取出最前面的字母
        else:                       # 不是字母，直接保留
            res.append(ch)
    return ''.join(res)   # 把列表合并成字符串
```

> **关键行解释**  
> - `ch.isalpha()`：就像在字典里查“这个字符是不是单词”，是则返回 `True`。  
> - `letters.reverse()`：把装好糖果的袋子倒置。  
> - `letters.pop(0)`：从袋子最前面取出一个糖果（这里是字母），放回新位置。

#### 复杂度

- **时间复杂度：O(n²)（最坏情况）**  
  - `pop(0)` 在列表最前端删除元素会导致后面的元素全部左移，平均需要 O(n) 时间。遍历整个字符串共 n 次，整体是 O(n²)。  
  - 用 `pop()`（默认弹出最后一个）可以降到 O(n)，但为了保持思路的“最直接”，这里展示的是最笨的写法。

- **空间复杂度：O(n)**  
  - 需要额外的 `letters` 列表存放所有字母，最坏情况下字母数等于字符串长度 n。

### 2. 最优解

#### 思路  

暴力解的瓶颈在于 **频繁的列表头部删除**（`pop(0)`），每次都要把后面的元素往前搬。我们可以把这一步改成 **双指针**（Two Pointers）：

1. **左指针 `i`** 从字符串左侧向右移动，**右指针 `j`** 从右侧向左移动。  
2. 当 `i` 指向的字符不是字母时，`i` 向右跳过（相当于 “这块石子我们不动”。）  
3. 当 `j` 指向的字符不是字母时，`j` 向左跳过。  
4. 当两指针都指向字母时，交换这两个字母，然后 `i++`、`j--`，继续向中间逼近。  

整个过程只遍历一次字符串，**不需要额外的存储**（可以在原字符数组上原地交换），因此时间 O(n)，空间 O(1)。

> 类比：想象有一条装满糖果和石子的管子，两端各有一只手。左手只抓糖果，右手也只抓糖果。每次左手抓到糖果后，右手也抓到糖果，然后把两颗糖果换位置，继续往中间走。石子永远不被手碰到。

#### 代码（Python）

```python
def reverseOnlyLetters_optimal(s: str) -> str:
    # 把字符串转换成列表，列表是可变的，方便原地交换字符
    chars = list(s)
    i, j = 0, len(chars) - 1          # 左右指针初始位置

    while i < j:
        # ① 左指针遇到非字母，直接跳过
        while i < j and not chars[i].isalpha():
            i += 1
        # ② 右指针遇到非字母，直接跳过
        while i < j and not chars[j].isalpha():
            j -= 1

        # ③ 两指针都指向字母，交换它们
        if i < j:
            chars[i], chars[j] = chars[j], chars[i]   # Python 中的元组交换
            i += 1
            j -= 1

    # 把列表再拼成字符串返回
    return ''.join(chars)
```

> **关键行解释**  
> - `not chars[i].isalpha()`：判断当前字符是不是“石子”，如果是，就让指针继续前进。  
> - `chars[i], chars[j] = chars[j], chars[i]`：一次性把两颗糖果（字母）换位，既简洁又高效。  

#### 复杂度

- **时间复杂度：O(n)**  
  - 每个字符最多被左指针或右指针检查一次，整体线性遍历。  
  - 与暴力解的 O(n²) 相比，快了很多，尤其在字符串很长时差距明显。

- **空间复杂度：O(1)**（不计输出字符）  
  - 只用了常数个指针变量 `i、j`，没有额外随输入规模增长的存储（把字符串转成列表是必须的，因为 Python 字符串不可变，但这部分视作输出空间）。

## 心得

- **核心技巧**：双指针（Two Pointers）在“只处理一部分元素、其余保持不动”时非常强大。  
- **适用的题型**：  
  1. *删除数组中的特定元素*（如 “Remove Element”）  
  2. *移动零到数组末尾*（如 “Move Zeroes”）  
  3. *回文检查（忽略非字母/数字）*（如 “Valid Palindrome”）  
- **解题钥匙**：**把“要处理的东西”放在两端，用指针把它们拉向中间，遇到不需要处理的直接跳过**。

## 反思

- **第一反应**：把所有字母收集出来、翻转后再填回去——这就是最自然的 “先抽出来、后放回去” 思路。  
- **最容易踩的坑**：  
  - **判断字母**：要使用 `isalpha()`，而不是简单的 `'a' <= ch <= 'z'`，因为后者会漏掉大写字母。  
  - **指针越界**：在循环里必须同时检查 `i < j`，否则在只剩一个字符时会出现无限循环。  
  - **字符串不可变**：直接在字符串上交换会报错，需要先转成列表或使用额外数组。  
- **下次类似题的第一步**：先问自己 “哪些位置需要保留原样，哪些需要移动”。如果是“只移动特定类型的元素”，立刻想到 **双指针** 或 **一次遍历 + 栈/队列** 的方案。
