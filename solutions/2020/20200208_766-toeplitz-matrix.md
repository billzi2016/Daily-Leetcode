# #766. 托普利茨矩阵 / Toeplitz Matrix

> 难度：简单 · 标签：Array、Matrix · [LeetCode 链接](https://leetcode.com/problems/toeplitz-matrix/)

## 题目（英文原版）

**Description**

Given an m x n matrix, return true if the matrix is Toeplitz. Otherwise, return false.
A matrix is Toeplitz if every diagonal from top-left to bottom-right has the same elements.
Follow up:

**Examples**

**Example 1:**

```
Input: matrix = [[1,2,3,4],[5,1,2,3],[9,5,1,2]]
Output: true
Explanation:
In the above grid, the diagonals are:
"[9]", "[5, 5]", "[1, 1, 1]", "[2, 2, 2]", "[3, 3]", "[4]".
In each diagonal all elements are the same, so the answer is True.
```

**Example 2:**

```
Input: matrix = [[1,2],[2,2]]
Output: false
Explanation:
The diagonal "[1, 2]" has different elements.
```

**Constraints**

- m == matrix.length
- n == matrix[i].length
- 1 <= m, n <= 20
- 0 <= matrix[i][j] <= 99

## 题目（中文翻译）

给定一个 **m × n** 的矩阵（matrix），如果矩阵是托普利茨的则返回 `true`，否则返回 `false`。  
当且仅当每条从左上角到右下角的对角线（diagonal）上的所有元素都相同，矩阵才是托普利茨的。

## 示例

### 示例 1
**输入**  
```text
matrix = [[1,2,3,4],
          [5,1,2,3],
          [9,5,1,2]]
```
**输出**  
```text
true
```
**解释**  
在上述矩阵中，各对角线为：  
`[9]`、`[5, 5]`、`[1, 1, 1]`、`[2, 2, 2]`、`[3, 3]`、`[4]`。  
每条对角线上的元素全部相同，因此答案为 `true`。

### 示例 2
**输入**  
```text
matrix = [[1,2],
          [2,2]]
```
**输出**  
```text
false
```
**解释**  
对角线 `[1, 2]` 中的元素不相同。

## 约束条件
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 20`
- `0 <= matrix[i][j] <= 99`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把每条左上‑右下的对角线全部列出来，再检查每条对角线上的元素是否全部相同**。  

- **数据结构**：我们可以把矩阵看成一张“表格”，对角线就像从左上角往右下角划的斜线。把同一条斜线的所有数字收集到一个列表（list）里，就像把同一个单词的所有解释都写在字典的同一页上，方便统一检查。  
- **为什么正确**：题目要求“每条对角线的元素必须相同”。只要我们把每条对角线的所有元素都取出来，然后判断列表里是否全部相等，就能完整覆盖题意。  
- **复杂度分析**：  
  - 对角线的起点有 `m + n - 1` 条（上边第一行的每个格子 + 左边第一列的每个格子，左上角算一次）。  
  - 对于每条对角线，我们会沿着矩阵走一步一步到底，最坏情况下走 `min(m, n)` 步。  
  - 因此总的时间大概是 `O((m+n) * min(m,n))`，在最坏情况下约等于 `O(m * n)` 的常数倍（因为 `m,n ≤ 20`，这里的差别不大）。  
  - 额外空间我们需要存每条对角线的元素，最多是一条最长对角线的长度 `min(m,n)`，所以空间是 `O(min(m,n))`。

#### 代码（Python）

```python
from typing import List

def isToeplitzMatrix_brute(matrix: List[List[int]]) -> bool:
    m, n = len(matrix), len(matrix[0])

    # 1️⃣ 从第一行的每一列开始遍历（不包括最右边的那列，因为它已经是单独的对角线）
    for start_col in range(n):
        i, j = 0, start_col          # 当前坐标
        val = matrix[i][j]           # 这条对角线的基准值
        # 沿对角线向下右移动，直到走出矩阵
        while i < m and j < n:
            if matrix[i][j] != val:  # 只要出现不相等，直接返回 False
                return False
            i += 1
            j += 1

    # 2️⃣ 再从左侧的每一行开始遍历（不包括最上面的那行，已经在上面检查过）
    for start_row in range(1, m):
        i, j = start_row, 0          # 当前坐标
        val = matrix[i][j]           # 这条对角线的基准值
        while i < m and j < n:
            if matrix[i][j] != val:
                return False
            i += 1
            j += 1

    # 所有对角线都符合要求
    return True
```

#### 复杂度

- **时间复杂度**：`O(m * n)`  
  - “遍历每个格子一次”，就像把整张表格的每个格子都检查了一遍，虽然我们把它们分成了多条对角线，但总共仍然是 `m·n` 次比较。  
- **空间复杂度**：`O(1)`（不计输入矩阵本身）  
  - 只用了常数个额外变量 `i, j, val`，没有额外的数组或列表。  

> **注意**：虽然在思路里提到了“把每条对角线的所有元素收集到列表”，但实际实现中我们直接在遍历时比较，无需额外存储列表，这样可以把空间降到 `O(1)`。

### 2. 最优解

#### 思路  

从暴力思路可以看到，**真正的耗时点不是遍历对角线，而是重复比较同一个元素的次数**。如果我们把检查方式改成“每个格子只和它左上角的邻居比较一次”，就可以一次遍历就完成所有对角线的验证。

- **慢在哪里**：在暴力解里，我们对每条对角线都从头走到尾，导致同一个格子可能被检查多次（尤其是位于矩阵中心的格子会被多条对角线重复遍历）。  
- **优化思路**：观察对角线的定义：如果矩阵是 Toeplitz，那么任意一个格子 `matrix[i][j]` 必须等于它左上角的格子 `matrix[i-1][j-1]`（如果左上角存在的话）。换句话说，只要**每个格子都和左上角的格子相同**，整张矩阵就一定满足 Toeplitz。  
- **核心算法**：一次遍历整个矩阵（从第二行第二列开始），检查 `matrix[i][j] == matrix[i-1][j-1]`。这就是**单次扫描 + 常数空间**的解法。  
- **类比**：把矩阵想象成一本日历，每一天的数字必须和左上一天的数字相同（如果有左上一天的话），只要每一天都满足这个“左上相同”规则，整本日历就“对齐”了。

#### 代码（Python）

```python
from typing import List

def isToeplitzMatrix_opt(matrix: List[List[int]]) -> bool:
    m, n = len(matrix), len(matrix[0])

    # 从第二行第二列开始，因为第一行和第一列没有左上邻居
    for i in range(1, m):
        for j in range(1, n):
            # 若当前元素不等于左上角元素，则不满足 Toeplitz
            if matrix[i][j] != matrix[i - 1][j - 1]:
                return False

    return True
```

#### 复杂度

- **时间复杂度**：`O(m * n)`  
  - 只遍历一次矩阵的每个格子，和暴力解的时间量级相同，但实际运行更快，因为每个格子只比较一次，避免了重复遍历对角线的开销。  
- **空间复杂度**：`O(1)`  
  - 只使用了几个计数变量 `i, j`，不需要额外的存储。

> 与暴力解的对比：  
> - **时间**：理论上相同的 `O(mn)`，但最优解的常数更小，实际更快。  
> - **空间**：最优解直接 `O(1)`，而最原始的“收集列表”实现需要 `O(min(m,n))` 的额外空间。

## 心得

- **核心技巧**：利用**左上邻居相等**的性质，把对角线的全局约束转化为局部相等检查。  
- **适用的题型**：  
  1. **矩阵行列关系类**（如 “判断矩阵是否为对称矩阵”）  
  2. **二维网格的局部一致性**（如 “判断每个 2×2 子矩阵的四个数是否相等”）  
  3. **一维数组的相邻元素关系**（如 “判断数组是否为等差数列”）  
- **一句话总结**：**把全局的“每条对角线相同”化简为“每个格子和左上格子相同”。**

## 反思

- **第一反应**：把每条对角线拆出来逐个检查，写成多个循环或递归。  
- **最容易踩的坑**：  
  - 忘记处理矩阵只有一行或一列的情况（这时直接返回 `True`）。  
  - 在遍历时越界：要确保 `i-1`、`j-1` 在矩阵范围内，故从第二行第二列开始检查。  
- **下次类似题的第一步**：先思考**是否可以把“整条线/整块区域的要求”转化为“相邻元素之间的局部要求”。如果能，就可以用一次遍历的方式完成验证。
