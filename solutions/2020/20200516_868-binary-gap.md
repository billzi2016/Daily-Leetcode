# #868. 二进制间距 / Binary Gap

> 难度：简单 · 标签：Bit Manipulation · [LeetCode 链接](https://leetcode.com/problems/binary-gap/)

---

## 题目（英文原版）

**Description**

Given a positive integer n, find and return the longest distance between any two adjacent 1's in the binary representation of n. If there are no two adjacent 1's, return 0.
Two 1's are adjacent if there are only 0's separating them (possibly no 0's). The distance between two 1's is the absolute difference between their bit positions. For example, the two 1's in "1001" have a distance of 3.

**Examples**

**Example 1:**

```
Input: n = 22
Output: 2
Explanation: 22 in binary is "10110".
The first adjacent pair of 1's is "10110" with a distance of 2.
The second adjacent pair of 1's is "10110" with a distance of 1.
The answer is the largest of these two distances, which is 2.
Note that "10110" is not a valid pair since there is a 1 separating the two 1's underlined.
```

**Example 2:**

```
Input: n = 8
Output: 0
Explanation: 8 in binary is "1000".
There are not any adjacent pairs of 1's in the binary representation of 8, so we return 0.
```

**Example 3:**

```
Input: n = 5
Output: 2
Explanation: 5 in binary is "101".
```

**Constraints**

- 1 <= n <= 109

## 题目（中文翻译）

给定一个正整数 `n`，求并返回其二进制表示中任意两个相邻 `1` 之间的最长距离。如果不存在两个相邻的 `1`，返回 `0`。  
两个 `1` 被称为相邻，当且仅当它们之间仅有 `0`（可以没有 `0`）相隔。两个 `1` 的距离定义为它们所在位的位置差的绝对值。例如，二进制串 `"1001"` 中的两个 `1` 的距离为 `3`。

**示例 1**  
**输入**: `n = 22`  
**输出**: `2`  
**解释**: 22 的二进制为 `"10110"`。  
- 第一个相邻的 `1` 对是 `"10110"`，距离为 `2`。  
- 第二个相邻的 `1` 对是 `"10110"`，距离为 `1`。  
答案取这两个距离的最大值，即 `2`。  
注意，`"10110"` 中间的 `1` 将其两侧的 `1` 分隔开，因此不能构成一对相邻的 `1`。

**示例 2**  
**输入**: `n = 8`  
**输出**: `0`  
**解释**: 8 的二进制为 `"1000"`。二进制表示中没有相邻的 `1`，因此返回 `0`。

**示例 3**  
**输入**: `n = 5`  
**输出**: `2`  
**解释**: 5 的二进制为 `"101"`，唯一的一对相邻 `1` 的距离为 `2`。

**约束条件**  
- `1 <= n <= 10^9`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是先把整数 `n` 的二进制表示写成一串字符（比如 `10110`），然后把所有出现的 `'1'` 的下标记下来，逐对比较它们之间的距离，找出最大的那个。

- **使用的数据结构**：  
  - **字符串**：把二进制看成一行文字，像我们平时读的句子一样。  
  - **列表**：把每个 `'1'` 出现的位置（下标）存进去，就像把词典里出现的页码记下来。

- **为什么正确**：  
  二进制的每一位都对应一个固定的“位置”。只要把所有 `'1'` 的位置找出来，两两之间的距离就是题目要求的“相邻 1 之间的距离”。遍历所有可能的相邻对，取最大值，自然得到答案。

- **复杂度分析**（用大白话解释）  
  - 假设二进制长度是 `b`（`b ≈ log₂ n`，最大约 30 位，因为 `n ≤ 10⁹`）。  
  - 把 `'1'` 的位置全部找出来是一次遍历，`O(b)`。  
  - 接下来把这些位置两两比较，最坏情况是每个 `'1'` 都要和后面的每个 `'1'` 比一次，时间就是 `O(k²)`，其中 `k` 是 `'1'` 的个数，`k ≤ b`。  
  - 空间上我们需要一个列表保存所有 `'1'` 的下标，最多 `b` 个，`O(b)`。

#### 代码（Python）

```python
def binary_gap_brute(n: int) -> int:
    # 把整数转成二进制字符串，去掉前面的 '0b' 前缀
    bits = bin(n)[2:]

    # 记录所有出现 '1' 的下标（从左到右，左边是高位）
    ones_idx = []
    for i, ch in enumerate(bits):
        if ch == '1':
            ones_idx.append(i)          # i 就是这位的“位置”

    # 如果不足两个 1，直接返回 0
    if len(ones_idx) < 2:
        return 0

    # 暴力两两比较，找最大距离
    max_dist = 0
    for i in range(len(ones_idx)):
        for j in range(i + 1, len(ones_idx)):
            # 两个 1 之间的距离 = 下标差值
            dist = ones_idx[j] - ones_idx[i]
            if dist > max_dist:
                max_dist = dist

    return max_dist
```

#### 复杂度

- **时间复杂度**：`O(k²)`（最坏情况下 `k = b`，约为 `O(b²)`），意思是如果二进制里有很多 `1`，我们要比较的次数会像平方一样多。  
- **空间复杂度**：`O(b)`，因为我们把所有 `1` 的位置存进了列表，最多占用和二进制位数相同的空间。

### 2. 最优解

#### 思路  
暴力解的慢点在于**两两比较**——我们其实不需要把每一对都算一遍，只要记住**最近一次出现的 `1` 在哪儿**，当前再出现 `1` 时，直接算一次距离就够了。

**优化步骤**：

1. **一次遍历二进制**：用位运算把 `n` 的最低位（最右边）依次取出来，像把硬币一枚枚翻面。  
2. **记录上一次出现 `1` 的位置**：用一个变量 `prev` 保存上一次看到 `1` 时的“位序号”。  
3. **当前位是 `1` 时**：用当前位序号 `pos` 减去 `prev`，得到相邻两 `1` 的距离，更新最大值 `ans`。随后把 `prev` 更新为当前的 `pos`。  
4. **继续右移**：把 `n` 右移一位 (`n >>= 1`)，位序号 `pos` 加一，重复上面过程，直到 `n` 变成 `0`。

**核心数据结构/技巧**：

- **位运算**：`n & 1` 能快速判断当前最低位是不是 `1`，相当于“检查字典里当前词是否存在”。  
- **单指针**：只用两个整数 `prev`、`pos`，不需要额外的列表，空间常数。

**类比**：想象你在走一条路，路上有灯柱（`1`），每走到一个灯柱，就记录下它和上一个灯柱之间的距离，最后把最大的距离记下来。你不需要把所有灯柱的位置全写下来，只要记住最近的一个就行。

#### 代码（Python）

```python
def binary_gap_optimal(n: int) -> int:
    """
    使用位运算一次遍历，时间 O(log n)，空间 O(1)。
    """
    # 记录上一次出现 1 的位序号，初始为 -1 表示还没出现过
    prev = -1
    # 当前遍历到的位序号（从 0 开始，表示最低位）
    pos = 0
    # 最大距离
    ans = 0

    while n > 0:
        # 判断当前最低位是否为 1
        if n & 1:                     # n & 1 == 1 表示这位是 1
            if prev != -1:            # 之前已经出现过 1
                ans = max(ans, pos - prev)   # 更新最大距离
            prev = pos                # 当前位成为最新的 “上一次 1”
        # 右移一位，准备检查下一位
        n >>= 1                         # 相当于把二进制往右滑动
        pos += 1                        # 位序号加一

    return ans
```

#### 复杂度

- **时间复杂度**：`O(log n)`，因为整数的二进制位数大约是 `log₂ n`，我们只遍历一次每个位。相当于“只走了一遍路”。  
- **空间复杂度**：`O(1)`，只用了几个整数变量，和输入大小无关，像是只带了一个小背包。

## 心得

- **核心技巧**：一次遍历二进制并用“上一次出现的 1 的位置”来即时计算相邻距离——这是一种**状态压缩**的思路，常用于位运算题。  
- **适用的题型**：  
  1. “二进制中连续 1 的最长子串” (`LeetCode 485 – Max Consecutive Ones`)  
  2. “统计二进制中 1 的个数” (`LeetCode 191 – Number of 1 Bits`)  
  3. “二进制翻转后得到的最大连续 1 的长度” (`LeetCode 487 – Max Consecutive Ones II`)  
- **一句话总结**：**只要记住最近一次出现的关键位置，遍历一次即可得到答案**。

## 反思

- **第一反应**：把数字转成二进制字符串，然后手动数距离——这自然想到但会用到额外的空间。  
- **最容易踩的坑**：  
  - 忘记把位序号从 **0**（最低位）开始计数，导致距离少算了 1。  
  - 当整数只有一个 `1` 时，需要返回 `0`，别把初始化的最大值写成 `-1`。  
- **下次思路**：遇到“相邻”或“距离”这类二进制问题时，第一步就想到**一次位遍历 + 记录上一次出现的位置**，避免不必要的额外存储。
