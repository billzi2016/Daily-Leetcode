# #1108. IP 地址的防炸化 / Defanging an IP Address

> 难度：简单 · 标签：String · [LeetCode 链接](https://leetcode.com/problems/defanging-an-ip-address/)

---

## 题目（英文原版）

**Description**

Given a valid (IPv4) IP address, return a defanged version of that IP address.
A defanged IP address replaces every period "." with "[.]".

**Examples**

**Example 1:**

```
Input: address = "1.1.1.1"
Output: "1[.]1[.]1[.]1"
```

**Example 2:**

```
Input: address = "255.100.50.0"
Output: "255[.]100[.]50[.]0"
```

**Constraints**

- The given address is a valid IPv4 address.

---

## 题目（中文翻译）

**题目描述**  
给定一个有效的 IPv4 地址（IP address），返回该地址的防炸化（defanged）版本。  
防炸化的 IP 地址需要将每个句点 `.` 替换为 `[.]`。

**示例 1**  
```text
Input: address = "1.1.1.1"
Output: "1[.]1[.]1[.]1"
```

**示例 2**  
```text
Input: address = "255.100.50.0"
Output: "255[.]100[.]50[.]0"
```

**约束条件**  
- 给定的 `address` 是一个合法的 IPv4 地址。

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法就是把原始的 IP 地址字符串逐字符扫描，一旦遇到 `'.'`（句点），就把它换成 `"[.]"`，其余字符保持不变。  
- **用到的数据结构**：Python 的字符串（`str`）本质上是字符数组，遍历它就像把一串珠子一个一个拿出来检查。  
- **生活化类比**：把 IP 地址想象成一串珠子，其中有几颗是蓝色的点（`.`），我们要把每颗蓝色点换成一块特殊的装饰牌（`[.]`），其它珠子保持原样。  
- **为什么正确**：题目只要求把每个 `'.'` 替换为 `"[.]"`，不涉及位置移动或删除，只要遍历完整个字符串并按规则输出，就一定得到答案。  

#### 代码（Python）

```python
def defangIPaddr(address: str) -> str:
    # 用一个列表收集处理后的字符，列表的拼接效率高于直接在字符串上 +=
    result = []
    for ch in address:               # 逐个字符遍历
        if ch == '.':                # 碰到句点
            result.append("[.]")     # 用 "[.]" 替代
        else:
            result.append(ch)        # 其它字符保持原样
    # 把列表中的片段一次性合并成最终字符串
    return "".join(result)
```

#### 复杂度  

- **时间复杂度**：`O(n)` —— 需要遍历一次长度为 `n` 的输入字符串，`n` 就是 IP 地址的字符数（一般 ≤ 15）。  
- **空间复杂度**：`O(n)` —— 需要额外的列表来保存转换后的字符，最终的输出字符串也占 `n` 的空间。

---

### 2. 最优解

#### 思路  

从暴力解出发，唯一的瓶颈在于我们手动遍历并逐字符构造结果。实际上 Python 已经为我们提供了 **字符串的批量替换** 方法 `str.replace(old, new)`，它内部实现了同样的线性遍历，但用 C 语言写得更快、更简洁。  
- **核心技巧**：一次性把所有 `'.'` 替换成 `"[.]"`。  
- **为什么更好**：代码行数更少，易读性更高，且在实际运行时略快于手写循环（因为底层是 C 实现的）。  
- **类比**：相当于我们把整串珠子一次性交给专业工匠，让他一次性把所有蓝色点换成装饰牌，而不是我们自己一个个手工替换。

#### 代码（Python）

```python
def defangIPaddr(address: str) -> str:
    # 使用字符串的 replace 方法，一次性完成所有替换
    # old = '.'   new = '[.]'
    return address.replace(".", "[.]")
```

#### 复杂度  

- **时间复杂度**：`O(n)` —— `replace` 仍然需要遍历整个字符串一次。  
- **空间复杂度**：`O(n)` —— 生成的新字符串需要额外的 `n` 空间。  
与暴力解相比，时间和空间阶数相同，只是常数因子更小，代码更简洁。

---

## 心得

- **核心技巧**：利用语言自带的批量替换函数（`str.replace`）进行字符映射。  
- **适用的题型**：  
  1. 替换字符串中的特定字符或子串（如把空格换成 `%20`）。  
  2. 简单的字符过滤或格式化（如把电话号码中的 `-` 去掉）。  
- **一句话总结**：**把“每个点 → [.]”的映射交给 `replace`，代码简洁且高效**。

## 反思

- **第一反应**：直接想到遍历字符串并手动构造新字符串。  
- **最容易踩的坑**：  
  - 忘记把所有 `'.'` 都替换，导致遗漏。  
  - 在手动拼接时使用 `+=`，在大数据时会导致 `O(n²)` 的时间开销（虽然本题规模很小）。  
- **下次遇到同类题**：第一步先检查语言是否提供了直接的替换/过滤 API，若有则优先使用。
