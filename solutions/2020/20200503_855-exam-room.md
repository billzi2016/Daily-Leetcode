# #855. 考场座位 / Exam Room

## 题目（英文原版）

**Description**

There is an exam room with n seats in a single row labeled from 0 to n - 1.
When a student enters the room, they must sit in the seat that maximizes the distance to the closest person. If there are multiple such seats, they sit in the seat with the lowest number. If no one is in the room, then the student sits at seat number 0.
Design a class that simulates the mentioned exam room.
Implement the ExamRoom class:

**Examples**

**Example 1:**

```
Input
["ExamRoom", "seat", "seat", "seat", "seat", "leave", "seat"]
[[10], [], [], [], [], [4], []]
Output
[null, 0, 9, 4, 2, null, 5]

Explanation
ExamRoom examRoom = new ExamRoom(10);
examRoom.seat(); // return 0, no one is in the room, then the student sits at seat number 0.
examRoom.seat(); // return 9, the student sits at the last seat number 9.
examRoom.seat(); // return 4, the student sits at the last seat number 4.
examRoom.seat(); // return 2, the student sits at the last seat number 2.
examRoom.leave(4);
examRoom.seat(); // return 5, the student sits at the last seat number 5.
```

**Constraints**

- 1 <= n <= 109
- It is guaranteed that there is a student sitting at seat p.
- At most 104 calls will be made to seat and leave.

## 题目（中文翻译）

有一个考场 (exam room)，里面有 `n` 个座位 (seat) 排成一排，编号从 `0` 到 `n-1`。  
当有学生进入考场时，他必须坐在能够使 **到最近的已坐学生的距离最大化** 的座位上。如果有多个座位满足该条件，则选择编号最小的那个座位。如果考场里没有任何学生，则该学生坐在座位 `0`。

设计一个类来模拟上述考场的行为。

实现 `ExamRoom` 类，使其支持以下操作：

- `ExamRoom(int n)`：构造函数，初始化一个有 `n` 个座位的考场。
- `int seat()`：让一名学生进入考场并返回他坐下的座位编号。
- `void leave(int p)`：学生离开座位 `p`（保证座位 `p` 上一定有学生）。

**示例**

```text
输入
["ExamRoom", "seat", "seat", "seat", "seat", "leave", "seat"]
[[10], [], [], [], [], [4], []]

输出
[null, 0, 9, 4, 2, null, 5]

解释
ExamRoom examRoom = new ExamRoom(10);
examRoom.seat(); // 返回 0，考场为空，学生坐在座位 0。
examRoom.seat(); // 返回 9，学生坐在最后一个座位 9。
examRoom.seat(); // 返回 4，学生坐在座位 4，使其与最近的学生的距离最大。
examRoom.seat(); // 返回 2，学生坐在座位 2。
examRoom.leave(4); // 学生离开座位 4。
examRoom.seat(); // 返回 5，学生坐在座位 5。
```

**约束条件**

- `1 <= n <= 10^9`
- 保证在调用 `leave(p)` 时，座位 `p` 上一定有学生。
- `seat` 和 `leave` 的调用次数总计不超过 `10^4`。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是：**把已经坐好的学生位置全部保存下来**（比如放进一个列表），每当有新学生要坐时，遍历所有座位 `0 … n‑1`，计算该座位到最近已坐学生的距离，挑选距离最大的座位。  

- **数据结构**：使用 Python 的 `list`（或 `set`）保存已占座位。可以把它想象成一本“座位登记簿”，每一行记录一个坐了人的座位号。  
- **为什么正确**：我们把所有可能的座位都检查一遍，必然能找到使“到最近人的距离”最大的那一个（如果有多个，同样会把最左边的那一个挑出来）。  
- **复杂度**：  
  - 对每一次 `seat()`，我们要遍历 `n` 个座位，每个座位再去找最近的已占座位（线性扫描已占座位列表），最坏情况是 `O(n·k)`，其中 `k` 是当前已坐学生数。因为 `k ≤ n`，最坏可以写成 `O(n²)`。  
  - 对 `leave(p)`，只需要在列表中把 `p` 删除，时间 `O(k)`（在列表里找位置），最坏 `O(n)`。  
  - 空间上，只需要存放已经坐的座位，最多 `n` 个，`O(n)`。

> **大白话解释**：  
> - `O(n²)` 就像在一个 1000 人的教室里，每次坐人都要把教室里每一个座位都检查一遍，还要把每个人的距离算一遍，时间会爆炸。  

#### 代码（Python）

```python
import bisect

class ExamRoom:
    def __init__(self, n: int):
        self.n = n                     # 教室总座位数
        self.seated = []               # 已占座位，保持有序（类似排好序的登记簿）

    # 让学生坐下，返回坐的位置
    def seat(self) -> int:
        # 如果教室空，直接坐最左边 0 号座位
        if not self.seated:
            self.seated.append(0)
            return 0

        # 记录最佳座位和对应的最大最小距离
        best_seat = 0
        max_dist = self.seated[0]      # 左边第一个空位到最近人的距离（只能坐在 0 号）

        # 检查每两个相邻已占座位之间的空隙
        for i in range(len(self.seated) - 1):
            left = self.seated[i]
            right = self.seated[i + 1]
            # 两个人之间的中点（向左取整）是候选座位
            cand = (left + right) // 2
            # 这个候选座位到最近人的距离是 min(cand-left, right-cand)
            dist = min(cand - left, right - cand)
            if dist > max_dist:        # 找到更大的距离就更新
                max_dist = dist
                best_seat = cand
        # 检查最右边的空位（只能坐在 n-1）
        if self.n - 1 - self.seated[-1] > max_dist:
            best_seat = self.n - 1

        # 把新座位插入有序列表（保持有序，方便以后二分查找）
        bisect.insort(self.seated, best_seat)
        return best_seat

    # 学生离开座位 p
    def leave(self, p: int) -> None:
        # 在已占座位列表中找到 p 并删除
        idx = bisect.bisect_left(self.seated, p)
        if idx < len(self.seated) and self.seated[idx] == p:
            self.seated.pop(idx)
```

#### 复杂度

- **时间复杂度**：`seat()` 最坏 `O(n²)`（遍历所有座位并在已占座位中线性搜索），`leave()` 最坏 `O(n)`（在列表中找并删除）。  
- **空间复杂度**：`O(n)`，因为最多需要保存所有已占座位。

---

### 2. 最优解

#### 思路  

暴力解的瓶颈在于 **每次坐人都要遍历所有座位**。我们可以把“每两个相邻学生之间的空隙”抽象成 **区间**，只在这些区间上做选择，而不是遍历每个具体座位。

**核心想法**：

1. **把每段空白区间记下来**。  
   - 区间用左端点 `l`（已占座位）和右端点 `r`（已占座位）表示，区间内部都是空的。  
   - 区间的“价值”是：如果在该区间坐人，能得到的最大最小距离。  
     - 对于两端都有学生的普通区间 `(l, r)`，最佳坐标是中点 `mid = (l + r) // 2`，得到的距离是 `(r - l) // 2`（向下取整，因为左边坐的学生可能更近）。  
     - 对于最左侧的特殊区间 `(-1, r)`（左边没有学生），最佳坐标是 `0`，距离是 `r`。  
     - 对于最右侧的特殊区间 `(l, n)`（右边没有学生），最佳坐标是 `n-1`，距离是 `n-1-l`。

2. **用最大堆（priority queue）把区间按“价值”排序**。  
   - 堆顶总是价值最高的区间，即新学生应该坐的地方。  
   - 堆的比较规则：  
     - 先比较距离（大的优先），  
     - 距离相同则比较左端点（左端点小的区间意味着坐的座位更左，符合题目“坐标最小”的要求）。  
   - 这相当于把“最有价值的空位”放进一个“抢座位的排队系统”，每次直接弹出最优的。

3. **坐下时**：  
   - 从堆里弹出最优区间 `(l, r)`，计算实际坐的座位 `seat`（如上面的规则），把 `seat` 加入已占集合。  
   - 产生两个新区间：`(l, seat)` 与 `(seat, r)`（如果它们仍然有空位），把它们重新放进堆。

4. **离开时**：  
   - 当学生离开座位 `p`，我们需要把 `p` 左右相邻的两个区间合并成一个更大的区间。  
   - 为了快速找到左、右相邻的已占座位，我们用一个 **有序集合**（`SortedList`/`TreeSet`），这里用 Python 的 `bisect` 在有序列表上实现。  
   - 合并后，把新的大区间加入堆。

5. **延迟删除**：  
   - 堆里可能残留已经失效的旧区间（因为学生离开后原来的区间仍在堆里）。弹出时检查该区间的左右端点在当前已占集合中是否仍然相邻；若不相邻则说明已经过时，直接丢弃继续弹出下一个。

**为什么会快**：  
- 每次 `seat()` 只弹出堆顶（`O(log m)`），`m` 为区间数量，最多 `2 * 已占座位数 + 2`，远小于 `n`。  
- `leave()` 只做几次二分查找和一次堆插入，同样是 `O(log m)`。  
- 整体时间从 `O(n²)` 降到 `O(log n)`（对每次调用），空间只保存已占座位和区间，`O(k)`，`k` 为当前学生数，最多 `10⁴`（题目限制）。

> **类比**：  
> - 把每段空白想象成“跑道”，跑道的“宽度”就是学生坐下后能得到的最小距离。我们用一个“跑道排行榜”（最大堆）随时挑选最宽的跑道。  

#### 代码（Python）

```python
import heapq
import bisect
from typing import List, Tuple

class ExamRoom:
    def __init__(self, n: int):
        self.n = n                              # 座位总数
        self.seats: List[int] = []              # 已占座位，保持有序
        self.heap: List[Tuple[int, int, int]] = []  # 最大堆，元素为 (-dist, left, right)

        # 初始时，整个教室是一个空区间 ( -1 , n )
        # 对于两端都有“哨兵” -1 和 n，计算的距离为 (n-1 - 0) // 2，等价于 n-1
        # 这里直接把整个区间放入堆，后面会统一用统一的计算公式
        self._add_interval(-1, n)

    # ----- 私有工具函数 -------------------------------------------------
    def _distance(self, left: int, right: int) -> int:
        """
        计算区间 (left, right) 内坐下后能得到的最小距离。
        left、right 分别是已占座位的下标，左开右开。
        """
        if left == -1:                 # 最左侧特殊区间
            return right
        if right == self.n:            # 最右侧特殊区间
            return self.n - 1 - left
        # 两端都有学生的普通区间，距离是区间长度的一半（向下取整）
        return (right - left) // 2

    def _add_interval(self, left: int, right: int) -> None:
        """把区间 (left, right) 放入堆中，使用负距离实现最大堆。"""
        if left + 1 >= right:          # 区间里没有空位直接舍弃
            return
        dist = self._distance(left, right)
        # heapq 默认是最小堆，用负数实现“最大堆”。第二、第三个字段保证
        # 距离相同情况下左端点更小的区间优先（即坐更左边的座位）。
        heapq.heappush(self.heap, (-dist, left, right))

    def _is_valid(self, left: int, right: int) -> bool:
        """
        判断堆中弹出的区间 (left, right) 是否仍然有效。
        只要 left 与 right 在当前已占座位中相邻即可。
        """
        # 在有序 seats 中寻找 left、right 的位置
        i = bisect.bisect_left(self.seats, left)
        j = bisect.bisect_left(self.seats, right)
        # left 可能是 -1（哨兵），此时 i == 0；right 可能是 n（哨兵），此时 j == len(seats)
        # 有效的区间要求 left 在 seats[i-1]（如果 left != -1）且 right 在 seats[j]（如果 right != n）
        # 简单判断：两者在 seats 中的相邻下标应相差 1
        return (i < len(self.seats) and self.seats[i] == left) or left == -1 and i == 0 and \
               (j < len(self.seats) and self.seats[j] == right) or right == self.n and j == len(self.seats) and \
               (i == j - 1)   # left 与 right 在 seats 中相邻

    # ----- 公共接口 -----------------------------------------------------
    def seat(self) -> int:
        # 从堆中取出当前最优、且仍然有效的区间
        while self.heap:
            neg_dist, left, right = heapq.heappop(self.heap)
            # 检查区间是否已经失效（因为之前的 leave 可能把它拆了）
            if self._is_valid(left, right):
                break
        else:
            # 理论上不会到这里，因为一定会有可坐的区间
            raise RuntimeError("No available seat")

        # 根据区间类型决定坐的位置
        if left == -1:
            seat = 0
        elif right == self.n:
            seat = self.n - 1
        else:
            seat = (left + right) // 2

        # 将新座位加入有序列表（保持有序）
        bisect.insort(self.seats, seat)

        # 把新产生的两个子区间重新放进堆
        self._add_interval(left, seat)
        self._add_interval(seat, right)

        return seat

    def leave(self, p: int) -> None:
        # 在有序 seats 中找到 p 的位置并删除
        idx = bisect.bisect_left(self.seats, p)
        self.seats.pop(idx)

        # 找到 p 左右最近的已占座位（可能是哨兵 -1 / n）
        left = self.seats[idx - 1] if idx - 1 >= 0 else -1
        right = self.seats[idx] if idx < len(self.seats) else self.n

        # 合并成一个更大的区间并放入堆
        self._add_interval(left, right)
```

> **代码要点注释**  
> - `self.heap` 使用负距离实现最大堆，`(-dist, left, right)` 的排序顺序正好满足“距离大 → 左端点小”。  
> - `self.seats` 用有序列表模拟平衡树，`bisect` 能在 `O(log k)` 时间完成插入、查找、删除。  
> - `leave` 只需要找到左右相邻的学生，然后把两段区间合并成一个大区间。  
> - 为防止堆中残留失效的旧区间，`seat` 时会循环弹出直到找到仍然有效的区间（**延迟删除**）。

#### 复杂度

- **时间复杂度**：  
  - `seat()`：堆弹出/插入 `O(log m)`，二分插入 `O(log k)`，整体 `O(log n)`（因为 `m、k ≤ n`）。  
  - `leave()`：二分查找+删除 `O(log k)`，堆插入 `O(log m)`，同样 `O(log n)`。  
  与暴力解相比，从 `O(n²)` 降到 `O(log n)`，即使 `n` 达到 `10⁹` 也能轻松应对。

- **空间复杂度**：`O(k)`，只保存当前已坐学生的位置和区间，最多 `10⁴`（题目限制），远小于 `n`。

## 心得

- **核心技巧**：**把“最大最小距离”抽象成区间的“价值”，用最大堆维护最有价值的区间**。  
- **适用的题型**：  
  1. **餐厅座位 / 电影院座位**（类似的“最大距离”选择问题）。  
  2. **动态分配资源**（如内存分配、文件系统的空闲块管理）。  
  3. **“在区间里放点”**的贪心类问题（比如 “最大化最小距离” 的 k‑个点放置）。  
- **一句话总结**：**把每段空白看成“跑道”，用堆始终挑最宽的跑道，就能在对数时间内完成座位分配**。

## 反思

- **第一反应**：直接遍历所有座位，写一个看似很容易的暴力实现。  
- **最容易踩的坑**：  
  - **边界区间的处理**：左侧没有学生时应该坐 `0`，右侧没有学生时坐 `n‑1`，距离的计算方式不同。  
  - **堆中残留失效区间**：离开后旧区间仍在堆里，需要在弹出时检查有效性（延迟删除）。  
  - **大数 `n`（可达 10⁹）**：不能真的创建长度为 `n` 的数组，只能用“哨兵”`-1`、`n` 和有序集合来间接表示。  
- **下次遇到同类题**：第一步先思考 **“能否把连续的空位压缩成一个区间并用优先队列管理”**，这样往往能把暴力的 `O(n)` 下降到 `O(log n)`。
