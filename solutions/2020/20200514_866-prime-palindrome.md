# #866. 素数回文 / Prime Palindrome

> 难度：中等 · 标签：Math、Number Theory · [LeetCode 链接](https://leetcode.com/problems/prime-palindrome/)

---

## 题目（英文原版）

**Description**

Given an integer n, return the smallest prime palindrome greater than or equal to n.
An integer is prime if it has exactly two divisors: 1 and itself. Note that 1 is not a prime number.
An integer is a palindrome if it reads the same from left to right as it does from right to left.
The test cases are generated so that the answer always exists and is in the range [2, 2 * 108].

**Examples**

**Example 1:**

```
Input: n = 6
Output: 7
```

**Example 2:**

```
Input: n = 8
Output: 11
```

**Example 3:**

```
Input: n = 13
Output: 101
```

**Constraints**

- 1 <= n <= 108

---

## 题目（中文翻译）

给定一个整数（integer） `n`，返回大于等于 `n` 的最小素数回文（prime palindrome）。

如果一个整数（integer）仅有恰好两个除数（divisor）：`1` 和它本身，则称其为素数（prime）。注意，`1` 不是素数。

如果一个整数（integer）正序和倒序读完全相同，则称其为回文数（palindrome）。

测试用例保证答案一定存在，且答案的取值范围在 `[2, 2 * 10^8]` 之间。

**示例 1**  
输入: `n = 6`  
输出: `7`

**示例 2**  
输入: `n = 8`  
输出: `11`

**示例 3**  
输入: `n = 13`  
输出: `101`

**约束条件**  

- `1 <= n <= 10^8`

---

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的想法是**从 n 开始一直往后枚举**，每枚举一个数就检查两件事：

1. **它是回文吗？**  
   把整数转换成字符串，正着读和倒着读相等即为回文。  
   （可以把它想象成照镜子，左边和右边完全对称。）

2. **它是质数吗？**  
   质数的定义是只能被 1 和它本身整除。最常见的检验方法是**试除法**：从 2 开始，一直除到 `sqrt(x)`（因为若 `x = a * b`，必有 `a ≤ sqrt(x)`），只要出现一次能整除的情况，就说明不是质数。

只要找到第一个同时满足“回文”和“质数”的数，就把它返回。

> **为什么这个方法一定能得到答案？**  
> 题目保证答案在 `[2, 2·10⁸]` 之间，而我们的枚举会一直往上走，必然会在这个区间内碰到答案。

#### 代码（Python）

```python
import math

def is_palindrome(x: int) -> bool:
    """判断一个整数是否是回文（把它当作字符串来看）"""
    s = str(x)
    return s == s[::-1]          # 正读和倒读相等

def is_prime(x: int) -> bool:
    """试除法判断质数，时间复杂度约为 O(sqrt(x))"""
    if x < 2:        # 0、1 都不是质数
        return False
    if x == 2:       # 2 是唯一的偶数质数
        return True
    if x % 2 == 0:   # 其他偶数直接判为非质数
        return False
    # 只需要除到 sqrt(x)，且只除奇数
    limit = int(math.isqrt(x))
    for d in range(3, limit + 1, 2):
        if x % d == 0:
            return False
    return True

def primePalindrome_bruteforce(n: int) -> int:
    """从 n 开始逐个检查，找到第一个既是回文又是质数的数"""
    x = n
    while True:
        if is_palindrome(x) and is_prime(x):
            return x
        x += 1
```

#### 复杂度

- **时间复杂度**：`O(k * √m)`  
  - `k` 是从 `n` 到答案之间的整数个数（最坏情况下可能接近 10⁸）。  
  - 对每个数我们最多做 `√m` 次除法（`m` 为当前检查的数）。  
  - 用大白话说，就是“**每检查一个数要花根号大小的时间**”，如果要检查很多数，整体就会很慢。

- **空间复杂度**：`O(1)`  
  只用了常数级别的变量，没有额外的数据结构。

### 2. 最优解

#### 思路  

暴力解的**瓶颈**在于**大量不必要的枚举**：  
- 大多数整数既不是回文也不是质数，我们却要把它们一个个尝试。  
- 试除法本身已经是对单个数的最简检查，再往下优化只能**减少需要检查的数的数量**。

**关键观察 1：**  
> **除 11 之外，所有偶数位数的回文数都能被 11 整除**。  
> 例如 1221 = 11 × 111， 3443 = 11 × 313。  
> 因此，除了唯一的例外 `11`，我们只需要考虑**奇数位数的回文数**（1、3、5、7 位）。

**关键观察 2：**  
> 回文数的生成可以**只构造左半部分**，然后镜像得到完整的数。  
> 把左半部分当作“种子”，比如种子 `123`，镜像后得到 `12321`（奇数位回文）。  
> 这就像把一个词的前半段写下来，再把它倒着贴在后面，形成对称的句子。

**核心思路**  
1. **枚举所有可能的奇数位回文数**，从最小位数开始，直到超过上限 `2·10⁸`。  
   - 生成方式：遍历长度为 `1、3、5、7` 的回文数。  
   - 对每一种长度，遍历所有可能的左半部分（不含最高位的 0），把它镜像得到完整回文。  
2. **对每个生成的回文数判断是否是质数**。  
   - 仍然使用试除法，但可以稍微加速：只除到 `sqrt(x)`，且只检查 `6k±1` 形式的数（因为除了 2、3，所有质数都可以写成 `6k±1`）。  
3. **在枚举的过程中，一旦遇到第一个 `≥ n` 且是质数的回文数，就返回**。  
   - 因为我们是按数值从小到大生成的，第一次满足条件的就是答案。

**为什么只需要生成奇数位回文？**  
- 偶数位回文数（除 11）一定能被 11 整除，必然不是质数。跳过它们可以把检查次数从几万降到几千。

**生成回文的实现细节**  
- 对于长度 `len`（奇数），左半部分的位数是 `(len // 2) + 1`。  
- 用 `for prefix in range(start, end)` 枚举左半部分，其中 `start = 10^{(half-1)}`（保证最高位不为 0），`end = 10^{half}`（不包括）。  
- 把 `prefix` 转成字符串，去掉最后一位再翻转，拼接得到完整回文。

#### 代码（Python）

```python
import math

def is_prime(x: int) -> bool:
    """更高效的质数判定，只除到 sqrt(x) 且只检查 6k±1 的数"""
    if x < 2:
        return False
    if x in (2, 3):
        return True
    if x % 2 == 0 or x % 3 == 0:
        return False
    # 只检查形如 6k±1 的数，步长 6
    limit = int(math.isqrt(x))
    i = 5
    while i <= limit:
        if x % i == 0 or x % (i + 2) == 0:
            return False
        i += 6
    return True

def generate_palindromes(limit: int):
    """生成所有 ≤ limit 的奇数位回文数（包括 11）"""
    # 长度 1、3、5、7（因为答案 ≤ 2*10^8，最多 8 位，奇数位最多 7 位）
    for length in (1, 3, 5, 7, 9):   # 9 位在 2*10^8 以内也可能出现（如 100030001）
        half_len = (length // 2) + 1          # 左半部分的位数
        start = 10 ** (half_len - 1)          # 左半部分的最小值，首位不能为 0
        end   = 10 ** half_len                # 左半部分的上界（不含）
        for prefix in range(start, end):
            s = str(prefix)
            # 去掉最右边的字符再翻转，得到奇数位回文
            pal = int(s + s[-2::-1])          # s[-2::-1] = s[:-1][::-1]
            if pal > limit:
                return
            yield pal

def primePalindrome(n: int) -> int:
    """主函数：返回不小于 n 的最小质数回文"""
    # 特殊处理：因为 11 是唯一的偶数位回文质数，需要单独检查
    if 8 <= n <= 11:          # 8~11 之间答案必为 11
        return 11

    # 上限根据题目给出的范围设为 2*10^8
    LIMIT = 200_000_000

    for p in generate_palindromes(LIMIT):
        if p >= n and is_prime(p):
            return p

    # 理论上不会走到这里，因为答案一定存在
    return -1
```

> **代码注释要点**  
> - `s[-2::-1]`：先把左半部分 `s` 去掉最后一位（因为中心字符不需要重复），再整体倒序，完成奇数位回文的拼接。  
> - `if 8 <= n <= 11: return 11`：因为 `11` 是唯一的 **偶数位** 回文质数，若 `n` 落在它前后，需要单独返回。

#### 复杂度

- **时间复杂度**：`O(P * √P)`，其中 `P` 为生成的回文数的个数。  
  - 通过上面的计数可知，`P` 约为 `9 + 90 + 900 + 9000 ≈ 10⁴`（所有奇数位回文数），远小于直接枚举的 `10⁸`。  
  - 对每个回文数的质数检测仍然是 `√p`，但因为 `p ≤ 2·10⁸`，`√p ≤ 1.5·10⁴`，整体运行时间在几百万次以内，完全可以在一秒内结束。  
  - 用大白话说：**我们只检查几千个“可能的答案”，每个检查花几千步，整体还是很快**。

- **空间复杂度**：`O(1)`（不使用额外的列表，只是几个整数变量），即使生成器 `yield` 也是逐个产生，不会一次性占用大量内存。

## 心得

- **核心技巧**：**只枚举奇数位回文数 + 高效的质数判定**。  
  这两点把搜索空间从“所有整数”压缩到“极少数特殊形状的整数”，从而把时间从爆炸式下降到线性可接受。

- **适用的题型**  
  1. **回文数 + 其他属性**（如回文素数、回文平方数）。  
  2. **只需要枚举满足特定“结构”**的数（如回文、回文素数、回文平方、回文斐波那契）。  
  3. **数位 DP / 生成数** 这类需要利用数字的对称性或递推规律的题目。

- **一句话总结解题钥匙**：  
  *“把问题转化为‘生成可能的答案’，而不是‘遍历所有候选’，再配合针对性的快速判定”。*

## 反思

- **第一反应**：直接从 `n` 开始暴力枚举，检查每个数是否回文且是质数。  
  这在概念上最容易想到，却忽略了“回文数本身很稀疏”这一事实。

- **最容易踩的坑**  
  1. **忘记 11 的特殊性**：偶数位回文数几乎都不是质数，唯一例外是 11。若不单独处理，答案会错误。  
  2. **生成回文时的位数溢出**：在 `2·10⁸` 限制内，最高可能出现 9 位回文（如 `100030001`），需要把生成上限设大一点。  
  3. **质数判定的边界**：`1`、`0`、负数都不是质数，务必在 `is_prime` 中先排除。

- **下次遇到类似题目**，第一步应该思考：  
  *“哪些数本身就满足大部分条件（比如回文、对称、特定进制）？”*  
  先**生成这些特殊形态的数**，再逐个验证剩余的约束，就能大幅降低时间消耗。
