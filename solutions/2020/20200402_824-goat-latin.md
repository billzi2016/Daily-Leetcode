# #824. 山羊拉丁文 / Goat Latin

## 题目（英文原版）

**Description**

You are given a string sentence that consist of words separated by spaces. Each word consists of lowercase and uppercase letters only.
We would like to convert the sentence to "Goat Latin" (a made-up language similar to Pig Latin.) The rules of Goat Latin are as follows:
Return the final sentence representing the conversion from sentence to Goat Latin.

**Examples**

**Example 1:**

```
Input: sentence = "I speak Goat Latin"
Output: "Imaa peaksmaaa oatGmaaaa atinLmaaaaa"
```

**Example 2:**

```
Input: sentence = "The quick brown fox jumped over the lazy dog"
Output: "heTmaa uickqmaaa rownbmaaaa oxfmaaaaa umpedjmaaaaaa overmaaaaaaa hetmaaaaaaaa azylmaaaaaaaaa ogdmaaaaaaaaaa"
```

**Constraints**

- 1 <= sentence.length <= 150
- sentence consists of English letters and spaces.
- sentence has no leading or trailing spaces.
- All the words in sentence are separated by a single space.

## 题目（中文翻译）

给定一个字符串 `sentence`，其中的单词以空格分隔。每个单词仅包含大小写英文字母。  
请将该句子转换为 **Goat Latin**（一种类似 Pig Latin 的虚构语言），转换规则如下：

1. 如果单词以元音字母（vowel）开头（不区分大小写），在单词末尾直接追加 `"ma"`。  
2. 如果单词以辅音字母开头，在单词末尾追加该首字母，然后再追加 `"ma"`。  
3. 根据单词在句子中的序号 `i`（从 1 开始），在单词末尾再追加 `i` 个字符 `'a'`。  

返回完成上述转换后的句子。

**示例**

```text
示例 1:
Input: sentence = "I speak Goat Latin"
Output: "Imaa peaksmaaa oatGmaaaa atinLmaaaaa"
```

```text
示例 2:
Input: sentence = "The quick brown fox jumped over the lazy dog"
Output: "heTmaa uickqmaaa rownbmaaaa oxfmaaaaa umpedjmaaaaaa overmaaaaaaa hetmaaaaaaaa azylmaaaaaaaaa ogdmaaaaaaaaaa"
```

**约束条件**

- `1 <= sentence.length <= 150`
- `sentence` 只包含英文字母和空格。
- `sentence` 不含首尾空格。
- `sentence` 中的所有单词均由单个空格分隔。

## 解题过程

### 1. 直觉解（暴力）

#### 思路  

最直接的做法就是把整句话按照空格拆成单词列表，逐个单词按规则改造后再拼回去。  
规则回顾：

1. **以元音开头**（a、e、i、o、u，大小写都算）：在单词后面直接加上 `"ma"`，再再后面加上 `i` 个 `'a'`，其中 `i` 是该单词在句子中的序号（从 1 开始）。  
2. **以辅音开头**：先把首字母移到单词末尾，然后再执行第 1 条的后缀操作。

实现时我们可以：

- 用 `sentence.split(' ')` 把句子拆成 `words` 列表。  
- 用一个循环遍历 `words`，用 `enumerate(words, 1)` 同时得到序号 `i`。  
- 判断首字母是否是元音：把所有元音放进一个 **哈希表**（在 Python 中用 `set`），查询 `c in vowel_set`，这就像在字典里查单词的含义，时间几乎是 **O(1)**。  
- 根据是元音还是辅音，拼接对应的字符串。  
- 最后把所有处理好的单词用空格 `' '` 连接成结果。

> **为什么一定能得到正确答案？**  
> 因为我们严格按照题目给出的每一步规则，对每个单词独立处理，且没有遗漏或顺序错误，最终拼接的顺序正好是原句的顺序。

#### 代码（Python）

```python
def toGoatLatin(sentence: str) -> str:
    # 1. 把所有元音字符放进集合，查询速度快
    vowels = set('aeiouAEIOU')          # 类似查字典，O(1) 判断

    words = sentence.split(' ')         # 按空格拆分成单词列表
    result = []                         # 用来保存每个单词的 Goat Latin 形式

    for idx, word in enumerate(words, 1):   # idx 从 1 开始计数
        first = word[0]                     # 取单词的第一个字符
        if first in vowels:                 # 以元音开头
            transformed = word + 'ma'       # 直接在后面加 "ma"
        else:                               # 以辅音开头
            transformed = word[1:] + first + 'ma'   # 把首字母移到末尾，再加 "ma"
        # 再加上 idx 个 'a'
        transformed += 'a' * idx
        result.append(transformed)          # 把处理好的单词放进列表

    return ' '.join(result)                 # 用空格把所有单词拼回一句话
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - `n` 为句子总字符数。我们只遍历了一遍字符串（拆分、判断、拼接），每一步都是常数时间。  
  - 大白话：不管句子有多长，处理时间大致和字符个数成正比，字符多一点，时间就多一点。

- **空间复杂度**：`O(n)`  
  - 需要额外的存储来保存拆开的单词列表和最终结果字符串，大小同样和原句子长度成正比。  
  - 大白话：我们相当于在原句子旁边再复制了一份（因为要输出新的句子），所以占用的内存和原句子差不多。

### 2. 最优解

#### 思路  

从暴力解可以看到，真正的“瓶颈”并不在算法本身——我们已经是一次线性扫描了。  
唯一可以再提升的地方是**判断元音**的方式。如果每次都用 `if first in "aeiouAEIOU"` 进行线性查找，最坏会是 `O(5)`（常数），但使用 **集合（set）** 可以保证查询时间始终是 `O(1)`，代码更简洁、更直观。  

因此，**最优解**就在于：

1. 用 `set` 预先存储所有元音，查询时直接 `c in vowel_set`。  
2. 其余步骤与暴力解相同：一次遍历、按规则拼接、最后 join。

这已经是该题的最优时间复杂度 `O(n)`，没有更快的办法（因为每个字符必须至少被读一次），空间也只能是 `O(n)` 来保存输出。

#### 代码（Python）

```python
def toGoatLatin(sentence: str) -> str:
    # 预先准备一个元音集合，查询速度是 O(1)
    vowel_set = {'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U'}

    # 直接在原句上分词
    words = sentence.split()
    # 用列表推导式写得更简洁
    goat_words = [
        (w + 'ma' if w[0] in vowel_set else w[1:] + w[0] + 'ma') + 'a' * (i + 1)
        for i, w in enumerate(words)
    ]

    # 用空格把处理好的单词连起来
    return ' '.join(goat_words)
```

#### 复杂度  

- **时间复杂度**：`O(n)`  
  - 仍然是一遍线性扫描，只是把元音判断的常数因子降到了最小。  
  - 与暴力解相比，没有本质提升，但在实际运行时会稍微更快一些。

- **空间复杂度**：`O(n)`  
  - 需要保存输出字符串，同样和原句子长度成正比。

## 心得

- **核心技巧**：**一次遍历 + 哈希集合快速判断**。  
- **适用的题型**  
  1. 需要对每个字符或单词做固定规则的转换（如 Pig Latin、字符翻转等）。  
  2. 需要在遍历过程中频繁判断“属于某类元素”（如元音/辅音、数字/字母、合法字符等）。  
- **解题钥匙**：把“是否属于某集合”这一步提前准备成 `set`，查询永远是 O(1)。

## 反思

- **第一反应**：把句子拆成单词，逐个按规则改造，再拼回去。  
- **最容易踩的坑**  
  1. **忘记序号从 1 开始**，导致 `'a'` 的个数少了一。  
  2. **大小写元音没有一起考虑**，导致大写元音被误判为辅音。  
  3. **拼接 `'a'` 时使用错误的索引**（比如用了 `i` 而不是 `i+1`）。  
- **下次类似题**：第一步想到“把输入拆成最小颗粒（字符或单词）”，然后检查是否可以用 `set`/`dict` 做**快速判定**，再在一次遍历中完成所有转换。
