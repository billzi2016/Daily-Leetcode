# #905. 按奇偶排序数组 / Sort Array By Parity

> 难度：简单 · 标签：Array、Two Pointers、Sorting · [LeetCode 链接](https://leetcode.com/problems/sort-array-by-parity/)

---

## 题目（英文原版）

**Description**

Given an integer array nums, move all the even integers at the beginning of the array followed by all the odd integers.
Return any array that satisfies this condition.

**Examples**

**Example 1:**

```
Input: nums = [3,1,2,4]
Output: [2,4,3,1]
Explanation: The outputs [4,2,3,1], [2,4,1,3], and [4,2,1,3] would also be accepted.
```

**Example 2:**

```
Input: nums = [0]
Output: [0]
```

**Constraints**

- 1 <= nums.length <= 5000
- 0 <= nums[i] <= 5000

---

## 题目（中文翻译）

给定一个整数数组（integer array）`nums`，将所有偶数（even integer）移动到数组的前面，随后是所有奇数（odd integer）。  
返回任意满足此条件的数组。

**示例 1**  
**输入**: `nums = [3,1,2,4]`  
**输出**: `[2,4,3,1]`  
**解释**: 输出 `[4,2,3,1]`、`[2,4,1,3]`、`[4,2,1,3]` 也都被接受。

**示例 2**  
**输入**: `nums = [0]`  
**输出**: `[0]`

**约束条件**  
- `1 <= nums.length <= 5000`  
- `0 <= nums[i] <= 5000`

## 解题过程

### 1. 直觉解（暴力）

#### 思路  
最直接的想法是把「偶数」和「奇数」分别收集到两个临时列表里，最后把偶数列表接在奇数列表前面得到结果。  
- **数据结构**：我们用两个 Python 列表来暂存偶数和奇数。可以把列表想象成「装东西的盒子」，一个盒子专门放偶数，另一个盒子专门放奇数。  
- **正确性**：遍历原数组的每个元素，判断它是偶数还是奇数，然后放进对应的盒子。遍历结束后，所有偶数必然在前面，所有奇数必然在后面，满足题目要求。  
- **复杂度分析**：  
  - 时间上，我们只遍历一次数组，做 **O(1)** 的判断和放入操作，总共是 **O(n)**（n 为数组长度）。  
  - 空间上，需要两个额外的列表来保存元素，最坏情况下会把全部 n 个元素都复制一遍，空间是 **O(n)**。  
  - 用大白话说，`O(n)` 就是「随数组长度线性增长」，如果数组有 1000 个数，操作大概也要 1000 次左右。

#### 代码（Python）
```python
def sortArrayByParity(nums):
    # 用两个列表分别收集偶数和奇数
    evens = []   # 偶数盒子
    odds = []    # 奇数盒子

    for x in nums:               # 遍历原数组的每个元素
        if x % 2 == 0:           # % 2 == 0 表示偶数
            evens.append(x)     # 放进偶数盒子
        else:
            odds.append(x)      # 放进奇数盒子

    # 把偶数盒子和奇数盒子合并成一个新数组返回
    return evens + odds
```

#### 复杂度
- **时间复杂度**：`O(n)` — 随着数组长度线性增长，遍历一次即可。
- **空间复杂度**：`O(n)` — 需要额外的两个列表，最坏情况保存所有元素。

---

### 2. 最优解

#### 思路  
从暴力解可以看到，**额外的空间**是最大的开销。我们可以在原数组上直接交换位置，把偶数搬到左边，奇数搬到右边，这样就不需要额外的列表了。  
- **瓶颈**：暴力解需要额外的 O(n) 空间。  
- **优化思路**：使用 **双指针**（Two Pointers）技术。设定左指针 `i` 从数组左端向右移动，右指针 `j` 从数组右端向左移动。  
  1. 当 `nums[i]` 已经是偶数时，左指针可以直接右移（因为它已经在正确位置）。  
  2. 当 `nums[j]` 已经是奇数时，右指针可以直接左移。  
  3. 若左指针指向奇数、右指针指向偶数，则交换这两个数，使偶数搬到左边、奇数搬到右边。  
  4. 重复上述过程，直到左指针和右指针相遇。  

- **核心概念解释**：  
  - **双指针**可以想象成两个人站在队列两端，左边的人只负责挑选「合格」的偶数，右边的人只负责挑选「合格」的奇数。当两个人各自手里拿的都是「不合格」的数字时，就互换位置，这样两边的队列很快就会变得有序。  
  - 交换是 **原地**（in‑place）进行的，意味着不需要额外的存储空间，只用一个临时变量保存一个数。

#### 代码（Python）
```python
def sortArrayByParity(nums):
    i, j = 0, len(nums) - 1           # i 从左边起，j 从右边起

    while i < j:                     # 当两指针还未相遇时循环
        # 如果左边已经是偶数，直接右移指针
        while i < j and nums[i] % 2 == 0:
            i += 1

        # 如果右边已经是奇数，直接左移指针
        while i < j and nums[j] % 2 == 1:
            j -= 1

        # 此时 nums[i] 是奇数，nums[j] 是偶数，交换它们
        if i < j:
            nums[i], nums[j] = nums[j], nums[i]   # 交换位置
            i += 1
            j -= 1

    return nums   # 原地修改后直接返回
```

#### 复杂度
- **时间复杂度**：`O(n)` — 每个元素最多被指针检查两次，整体仍然是线性增长。相比暴力解的 `O(n)`，这里省去了额外的列表创建和合并步骤，实际运行更快。  
- **空间复杂度**：`O(1)` — 只用了常数个额外变量（`i、j、临时变量`），不随输入规模增长。

## 心得

- 这道题考察的核心技巧是 **双指针的原地分割**（把满足条件的元素搬到数组的一侧）。  
- 类似技巧常出现在：  
  1. **移除数组中的特定元素**（LeetCode 27 Remove Element）  
  2. **排序颜色**（LeetCode 75 Sort Colors）  
  3. **数组的划分**（快速排序的 partition 步骤）  
- 一句话总结解题钥匙：**“用左右指针把不符合位置的数交换，直到指针相遇”。**

## 反思

- **第一反应**：先想到用两个临时列表分别收集偶数和奇数，然后拼接。  
- **最容易踩的坑**：  
  - 忘记在 `while i < j` 循环内部再次检查 `i < j`，导致在指针相遇后仍尝试交换，引发错误。  
  - 对负数或大数的奇偶性判断不熟悉，其实 `% 2` 在 Python 对负数也能正确返回 0 或 1。  
- **下次遇到同类题**：第一步先问自己“是否可以用双指针在原地完成分割”，如果答案是“可以”，就立刻写出指针移动和交换的框架。
